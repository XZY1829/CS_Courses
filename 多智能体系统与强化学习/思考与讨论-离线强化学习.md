# 思考与讨论：离线强化学习

---

## Q1：离线强化学习的动机和核心挑战是什么？

### 动机

在真实环境中从零开始训练 RL 智能体往往不可取：
- **风险较高**：如无人驾驶、智能医疗等
- **十分昂贵**：如机器人控制、推荐系统等

**离线强化学习**：在一个给定的离线数据集上直接训练出智能体策略，训练过程中智能体**不得**和环境做交互。

### 三种 RL 范式对比

| 范式 | 训练时交互？ | 数据来源 |
|------|------------|---------|
| On-Policy（在线策略） | ✅ | 当前策略收集 |
| Off-Policy（离线策略） | ✅ | 可用其他策略数据（但仍能交互） |
| **Offline（离线RL）** | **❌** | 仅固定数据集 D |

关键区别：
- 在线策略学习与离线策略学习的智能体**可以**和环境交互
- 离线强化学习的智能体**不和**环境做交互

### 离线RL与有监督学习的相似性

| | 离线强化学习 | 有监督学习 |
|--|------------|----------|
| 数据 | 固定离线数据集 | 静态训练数据 |
| 评估 | 测试环境 | 测试数据 |
| 共同点 | 均依赖静态数据、避免在线学习的风险 |

**不同点**：
- 离线 RL 需要**奖励信号**，有监督学习只需标签
- 离线 RL 数据包含**次优或随机行为**，有监督学习通常需要正确标签

### 核心挑战：分布偏移（Distribution Shift）

数据集分布和当前策略的分布不一致，导致**外推误差（Extrapolation Error）**：

- 智能体涉足到从没有见过的、远离数据集的状态-动作对
- Q 函数对 OOD（Out-of-Distribution）动作的预测严重脱离真实值

$$Q(s, a) \leftarrow (1-\alpha)Q(s,a) + \alpha(r + \gamma\max_{a'} Q(s', a'))$$

如果 $a'$ 是一个分布外的动作，Q 值估计会不可靠。

### 外推误差如何传播？

```
Q(s, a_OOD) 被虚假高估
       ↓
被用作 TD 目标的一部分（反向传播）
       ↓
传播到其他状态的 Q 值
       ↓
整个 Q 函数被污染 → 策略选择危险动作
```

OOD 区域无法正确推断奖励，策略为了追求虚假的高奖励而选择危险动作。

## Q2：BCQ（批量限制Q学习）算法的原理

### 核心思想

**仅仅使用在数据集支撑上的目标 Q 值做时序差分的计算**——不外推到未见过的动作。

### 表格型 BCQ

$$Q(s,a) \leftarrow (1-\alpha)Q(s,a) + \alpha\left(r + \gamma\max_{a': (s',a')\in\mathcal{B}} Q(s', a')\right)$$

仅仅考虑在数据集支撑上的 $(s', a')$，原本会被使用的 OOD 数据在 BCQ 中不再考虑使用。

### 连续动作 BCQ

对于更广泛的连续动作设置，实现思路如下：

1. **生成模型**：使用变分自动编码器（VAE）$G_\omega(s)$ 来生成距离数据集较近的状态动作对
2. **扰动网络**：$\xi_\Phi(s, a_i, \Phi)$ 在 $[-\Phi, +\Phi]$ 范围内扰动
3. **动作选择**：

$$\pi(s) = \arg\max_{a_i + \xi_\Phi(s, a_i, \Phi)} Q_\theta(s, a_i + \xi_\Phi(s, a_i, \Phi))$$

其中 $\{a_i \sim G_\omega(s)\}_{i=1}^n$，生成模型如 VAE

### BCQ 的 n 和 Φ 的权衡

| 参数选择 | 效果 | 特点 |
|---------|------|------|
| n 和 Φ **越小** | 越接近**模仿学习** | 策略性能可能不好（过于保守） |
| n 和 Φ **越大** | 越接近**强化学习** | 但容易出 OOD 问题 |

形成模仿学习和强化学习之间的一个权衡。

### BCQ 的双 Q 网络

在乐观与保守估计之间平衡：

$$Q_{target} = \lambda\min_{i=1,2}Q_i(s',a') + (1-\lambda)\max_{i=1,2}Q_i(s',a')$$

### BCQ 算法结构

- **VAE** 做模仿学习（生成数据分布内的动作）
- **扰动函数** $\xi$ 像是 Actor（在数据支撑附近微调）
- **双 Q 网络** 做保守-乐观权衡

## Q3：CQL（保守Q学习）算法的原理

### 核心思想

学习一个**保守的、可作为价值下界的 Q 函数**，以避免在 OOD 数据上的过高估计。

### CQL 目标函数

$$Q_{k+1} \leftarrow \arg\min_Q \alpha\left(E_{s\sim D, a\sim\mu(a|s)}[Q(s,a)] - E_{s\sim D, a\sim\hat{\pi}_\beta(a|s)}[Q(s,a)]\right) + \frac{1}{2}E_{s,a,s'\sim D}[(Q(s,a) - \mathcal{B}^\pi\hat{Q}_k(s,a))^2]$$

分解理解：

| 项 | 作用 |
|----|------|
| $\min E_{a\sim\mu}[Q(s,a)]$ | **最小化**分布外动作的 Q 值估计 |
| $\max E_{a\sim\hat{\pi}_\beta}[Q(s,a)]$ | **最大化**分布内动作的 Q 值估计 |
| $\frac{1}{2}(Q - \mathcal{B}^\pi\hat{Q}_k)^2$ | 标准的 TD 误差最小化（MSE） |

### CQL 的进一步形式

使用 $\max_\mu$ 操作来估计当前策略，加上正则：

$$\min_Q \max_\mu \alpha\left(E_{a\sim\mu}[Q(s,a)] - E_{a\sim\hat{\pi}_\beta}[Q(s,a)]\right) + \text{TD损失} + \mathcal{R}(\mu) \quad \text{(CQL(}\mathcal{R}\text{))}$$

经验上使用 $\mu$ 和均匀分布的 KL 散度作为正则项：

$$\mathcal{R}(\mu) = -D_{KL}(\mu, \text{Unif}(a))$$

此时目标简化为（CQL($\mathcal{H}$)）：

$$\min_Q \alpha\left(E_{s\sim D}\left[\log\sum_a\exp(Q(s,a))\right] - E_{a\sim\hat{\pi}_\beta}[Q(s,a)]\right) + \text{TD损失}$$

### CQL 的下界保证

CQL 学到的 Q 值是真实 Q 值的**下界**：宁可低估，不高估。因此策略不会被虚假高 Q 值引诱到 OOD 区域。

### CQL 的策略训练

- CQL 可以直接做基于价值函数的训练
- 如果需要策略训练，则在训练 Q 的同时，使用 **Soft Actor-Critic（SAC）** 算法训练出策略 $\pi$

## Q4：BCQ 和 CQL 的对比

| 维度 | BCQ | CQL |
|------|-----|-----|
| **核心策略** | 限制动作空间（空间约束） | 压低 Q 值（价值压制） |
| **解决 OOD 方式** | 用 VAE 约束动作只在数据分布内 | 正则化压低 OOD 动作的 Q 值 |
| **实现方式** | VAE 生成 + 扰动网络 | Q 函数正则化 |
| **理论保证** | 动作限制在数据支撑内 | Q 值是真实值的下界 |
| **策略训练** | 隐式（扰动网络即 Actor） | 可搭配 SAC 显式训练策略 |
| **超参敏感度** | n 和 Φ 的选择 | α 的选择 |
| **权衡** | 模仿学习 ↔ 强化学习 | 保守 ↔ 激进 |

### 统一视角

两种方法都是为了解决**外推误差**问题，但策略不同：

```
BCQ：让策略"不敢去"OOD 区域（约束动作空间）
CQL：让策略"不想去"OOD 区域（压低 OOD 的 Q 值）
```

### 实验结论

在多个 Gym 环境和不同的数据集采样设置下，CQL 几乎都能取得最好的策略性能，体现了保守 Q 值估计的有效性。

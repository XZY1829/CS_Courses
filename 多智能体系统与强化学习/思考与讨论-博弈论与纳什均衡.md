## Q1：多智能体系统的分类和最优解的设定

### 单智能体 vs 多智能体系统

| | 单智能体 | 多智能体系统 |
|--|---------|------------|
| 交互对象 | 只有一个智能体与环境交互 | 多个智能体在与环境交互 |
| 决策依据 | 观察、测量环境的动态性，进行最优决策 | 观察环境动态的同时，**协同其他智能体的行为**，进行最优决策 |
| 环境特点 | 环境转移相对固定 | 其他智能体的行为也是环境动态的一部分（非平稳） |

### 多智能体系统分类（按奖赏/目标分类）

| 类型 | 奖赏关系 | 目标 | 示例 |
|------|---------|------|------|
| **合作型** | $\mathcal{R} = \mathcal{R}_i = \mathcal{R}_{-i}, \forall i \in N$ | 所有玩家共享同一奖励，协作式地最大化整体目标 | 智能物流、无人集群 |
| **对抗/竞争型** | $\mathcal{R}_i = -\mathcal{R}_{-i}, \forall i \in N$ | 玩家之间奖励相反，竞争式地最大化自身目标 | 棋牌类游戏 |
| **合作-对抗混合型** | 组内共享 $\mathcal{R}_{red} = \mathcal{R}^j_{red}$；组间相反 $\mathcal{R}_{red} = -\mathcal{R}_{blue}$ | 组内玩家共享奖励，组间奖励相反 | 多单位、多人对抗游戏 |

按任务类型进一步细化：

| 类型 | 问题空间 | 决策标准 |
|------|---------|---------|
| 合作型 | 智能体学习目标一致 | 提高学习速度，获得**全局最优解** |
| 竞争型 | 智能体学习目标对立 | **不遗憾（No-regret）** |
| 混合型 | 智能体学习目标相异（非对立） | **收敛、均衡解** |

### 博弈的其他分类方式

| 分类依据 | 类别 |
|---------|------|
| 参与人是否合作 | 合作博弈 / 非合作博弈 |
| 参与人数量 | 两人博弈 / 多人博弈 |
| 博弈结果 | 零和博弈 / 常和博弈 / 变和博弈 |
| 行动先后次序 | 静态博弈 / 动态博弈 |
| 信息获得差异 | 完全信息博弈 / 不完全信息博弈 |

对应的均衡概念：

|  | 完全信息 | 不完全信息 |
|--|---------|----------|
| **静态博弈** | 纳什均衡 | 贝叶斯纳什均衡 |
| **动态博弈** | 子博弈精练纳什均衡 | 精练贝叶斯纳什均衡 |

### 四种最优策略定义

在多智能体环境中，"最优"有不同含义：

#### 1. 社会福利（Social Welfare）

最大化所有参与者的收益和：$\max \sum_{i} r_i$

#### 2. 帕累托优（Pareto Efficiency）

一个方案 $x$ 是帕累托最优，当且仅当不存在另一个方案 $x'$ 满足：
- $\exists$ agent $a_i$: $util_i(x') > util_i(x)$（某人更好）
- $\forall$ agent $a_{i'}$: $util_{i'}(x') \geq util_{i'}(x)$（没有人更差）

即：不考虑跨 Agent 效益比较的情况下满足一个全局最优。社会福利是帕累托最优的一个子集。

#### 3. 纳什均衡（Nash Equilibrium）

没有参与者可以通过单边改变策略而增加自己的收益（详见 Q2）。

#### 4. 优超（Dominant）

不依赖其他参与者的策略——无论对手怎么选，该策略都是最好的。

### 囚徒困境中不同准则下的最优策略

|  | 囚犯B 坦白 | 囚犯B 抗拒 |
|--|-----------|-----------|
| 囚犯A 坦白 | (-5, -5) | (0, -10) |
| 囚犯A 抗拒 | (-10, 0) | (-1, -1) |

| 准则 | 最优策略 |
|------|---------|
| 社会福利 | <抗拒, 抗拒>（总收益 -2 最大） |
| 帕累托优 | 除了 <坦白, 坦白> 之外的其他情况 |
| 纳什均衡 | <坦白, 坦白>（双方都无法单独偏离获利） |
| 优超 | <坦白, 坦白>（坦白是占优策略） |

**关键洞察**：纳什均衡不一定是帕累托最优！（囚徒困境中纳什均衡是社会最差的结果）

## Q2：纳什均衡解的概念

### 定义

给定一个策略组合 $s = (s_1, s_2, ..., s_n) \in S_1 \times S_2 \times \cdots \times S_n$，若对每个智能体 $i$：

$$r_i(s_i, s_{-i}) \geq r_i(s_i', s_{-i}), \quad \forall s_i' \in S_i$$

则策略组合 $s$ 是一个**纳什均衡**。

**直觉**：任何玩家都不能通过独自改变策略而获益的策略组合——所有玩家均处于最佳应对（Best Response）的策略组合。

### 纳什均衡的重要性质

1. **稳定性**：没有参与者有单边偏离的动机
2. **不一定唯一**：可能存在多个纳什均衡
3. **不一定社会最优**：囚徒困境中纳什均衡是社会最差结果
4. **纯策略纳什均衡可能不存在**：如石头剪刀布

### 纯策略纳什均衡可能不存在

石头剪刀布博弈：

|  | 石头 | 剪刀 | 布 |
|--|------|------|---|
| 石头 | (0,0) | (1,-1) | (-1,1) |
| 剪刀 | (-1,1) | (0,0) | (1,-1) |
| 布 | (1,-1) | (-1,1) | (0,0) |

不存在纯策略纳什均衡——任何确定性策略组合都有玩家想偏离。

### 混合策略纳什均衡

- **混合策略**：一个概率分布 $(p_1, p_2, ..., p_k)$，$p_i$ 表示选择动作 $i$ 的概率
- **混合策略纳什均衡**：一个混合策略组合，任何玩家都不能通过独自改变混合策略而使自身**期望收益**提高

石头剪刀布的混合策略纳什均衡：
- 玩家1：(1/3, 1/3, 1/3)
- 玩家2：(1/3, 1/3, 1/3)

**定理**：任一博弈，必存在一个混合策略纳什均衡（Nash, 1950）。

### 多个纳什均衡的例子：恋爱博弈

|  | 女孩：球赛 | 女孩：电影 |
|--|-----------|-----------|
| 男孩：球赛 | (2, 1) | (0, 0) |
| 男孩：电影 | (0, 0) | (1, 2) |

纳什均衡有两个：<球赛, 球赛> 和 <电影, 电影>——都是稳定的，但玩家偏好不同。

### Stackelberg 均衡

当玩家行动有先后次序时的均衡概念：在规定了行动先后次序的情况下，任何玩家都不能通过独自改变策略而获益的策略组合。与纳什均衡不同，先行者可以利用信息优势。

### 纳什均衡在多智能体 RL 中的意义

多智能体 RL 不只是求单个最优策略，而是求**稳定的策略组合**：
- 其他智能体也在学习 → 环境非平稳
- 需要均衡概念描述"什么样的学习结果是稳定的"
- 以纳什均衡为目标：$\forall i \in N, s \in S, \forall \pi_i \in \Pi: V_i^{\pi^*}(s) \geq V_i^{(\pi_i, \pi^*_{-i})}(s)$

## Q3：Nash-Q 学习算法

### 马尔可夫博弈模型

数学模型 $\langle N, S, A, P, R, \gamma \rangle$：
- 状态转移概率受环境和智能体**共同影响**
- 稳定联合策略下值函数满足 Bellman 方程：

$$V_i^\pi(s) = E_{a\sim\pi}[r(s,a) + \gamma\sum_{s'\sim P}P(s'|s,a)V_i^\pi(s')]$$

### Nash-Q 学习

**核心思想**：用纳什均衡值替代单智能体 Q-Learning 中的 $\max$ 操作。

给定纳什策略 $\pi^*$，纳什价值函数为：

$$V^{Nash}(s) = (V_1^{\pi^*}(s), V_2^{\pi^*}(s), ..., V_n^{\pi^*}(s))$$

智能体 $i$ 在状态-动作对 $(s, a)$ 下的 Q 值：

$$Q_i(s, a) = r_i(s, a) + \gamma E_{s'\sim P}[V_i^{Nash}(s')]$$

### Nash-Q 算法流程

Nash-Q 不断进行以下两步操作直到收敛：
1. 基于当前每个状态的 Q 值表，**求解纳什均衡** $\pi^*$，以及每个状态的 $V^{Nash}$
2. 基于纳什均衡价值 $V^{Nash}$，使用 TD 更新 Q 值表：

$$Q_i(s, a_1,...,a_n) \leftarrow Q_i(s,a_1,...,a_n) + \alpha[r_i + \gamma V_i^{Nash}(s') - Q_i(s,a_1,...,a_n)]$$

### Nash-Q 的优缺点

| 优点 | 缺点 |
|------|------|
| 以纳什均衡为学习目标，理论完备 | **非常高的计算复杂度**（每步需求解纳什均衡） |
| 完全中心化，信息完整 | **无法处理非合作的博弈场景** |
| 多智能体系统的自然推广 | 需要观测所有智能体的动作和奖励 |

### 相关算法对比

| 算法 | 适用场景 | 核心操作 |
|------|---------|---------|
| **Minimax-Q** | 零和博弈 | $V^*(s) = \max_{\pi_i}\min_{a_{-i}} Q(s, a_i, a_{-i})$ |
| **Nash-Q** | 一般和博弈 | 每步求解纳什均衡更新 Q 值 |
| **Friend-or-Foe Q** | 一般和博弈 | 将其他智能体分为 friend 和 foe 两组 |

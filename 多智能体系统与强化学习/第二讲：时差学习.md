# 第二讲：时差学习 —— MC、TD、SARSA、Q-Learning与TD(λ)

> 参考教材：Sutton & Barto《Reinforcement Learning: An Introduction》第5-7, 12章

## 一、从动态规划到无模型学习

### 1.1 动态规划的局限

动态规划（DP）需要**完全已知**的MDP模型（$\delta$ 和 $R$），但在实际问题中：
- 状态转移概率往往**未知**
- 奖赏函数可能**未知**
- 状态空间可能**非常大**

因此需要**无模型（Model-Free）**的方法——通过**采样（Sampling）**来学习。

### 1.2 Bootstraps与Sampling

| | Bootstraps（自举） | Sampling（采样） |
|--|-------------------|-----------------|
| 含义 | 用**估计值**更新估计值 | 用**实际经验**更新 |
| 动态规划 | ✅ 使用 | ❌ 不使用 |
| 蒙特卡罗 | ❌ 不使用 | ✅ 使用 |
| 时差学习 | ✅ 使用 | ✅ 使用 |

---

## 二、蒙特卡罗方法（Monte Carlo, MC）

### 2.1 MC策略评估

**核心思想**：智能体在访问状态 $s$ 后，对其所获得的**完整轨迹返回值**进行平均。

#### Every-Visit MC

在一次经验中，对**每次**访问到的 $s$ 都进行平均：

$$
V(s_t) \leftarrow V(s_t) + \alpha \left[R_t - V(s_t)\right]
$$
其中 $R_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots + \gamma^T r_{t+T}$ 是从 $s_t$ 开始的**完整返回值**。

#### First-Visit MC

在一次经验中，只对**首次**访问到的 $s$ 进行平均。

### 2.2 MC最优控制

- **策略评估**：用MC方法估计值函数
- **策略改进**：根据 $Q$ 函数，采用贪心策略

$$
\pi(s) \leftarrow \arg\max_a Q(s, a)
$$
### 2.3 MC方法的特点

| 优点 | 缺点 |
|------|------|
| 无偏估计 | 必须等到episode结束才能更新 |
| 不需要环境模型 | 高方差 |
| 概念简单 | 只适用于有终止状态的问题 |

## 三、时差学习（Temporal Difference, TD）

### 3.1 TD(0)：最简单的TD方法

**核心思想**：不等整个episode结束，每一步都用**即时奖赏 + 下一状态的估计值**来更新：

$$
V(s_t) \leftarrow V(s_t) + \alpha \left[\underbrace{r_t + \gamma V(s_{t+1})}_{\text{TD目标}} - V(s_t)\right]
$$
- **TD误差（TD Error）**：$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$
- **关键**：用 $r_t + \gamma V(s_{t+1})$ 来**估计/替代**完整的返回值 $R_t$

### 3.2 MC vs TD 对比

| 比较维度 | MC | TD |
|---------|----|----|
| 更新时机 | episode结束后 | 每一步都可更新 |
| 偏差 | 无偏 | 有偏（因为Bootstrap） |
| 方差 | 高方差 | 低方差 |
| 是否需终止 | 是 | 否（可用于连续任务） |
| 收敛速度 | 慢 | 通常更快 |
| 使用信息 | 完整轨迹 | 单步转移 |

### 3.3 DP vs MC vs TD 统一视角

```
     DP：V(s) ← E[r + γV(s')]          需要模型，用所有可能的s'
     MC：V(s) ← V(s) + α[R_t - V(s)]   不需模型，用一条完整采样轨迹
     TD：V(s) ← V(s) + α[r + γV(s') - V(s)]  不需模型，用一步采样
```

## 四、强化学习算法设计

### 4.1 算法设计的三个核心议题

1. **值函数的表达**：V函数 vs Q函数
2. **随机动作选择**：探索(Exploration) vs 利用(Exploitation)的平衡
3. **值函数更新方式**：在策略(On-Policy) vs 离策略(Off-Policy)

### 4.2 ε-贪心策略

$$
a = \begin{cases} \arg\max_a Q(s, a) & \text{以概率 } 1 - \varepsilon \\ \text{均匀随机选择} & \text{以概率 } \varepsilon \end{cases}
$$
- $\varepsilon$ 随学习过程**逐渐衰减**
- 初期：倾向探索（$\varepsilon$ 大）
- 后期：强调利用（$\varepsilon$ 小）

## 五、SARSA：在策略TD学习

### 5.1 算法原理

**SARSA = State-Action-Reward-State-Action**

在策略（On-Policy）：对当前Q值，采用**下一状态实际选择的动作**的Q值更新：

$$
Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha\left[r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)\right]
$$
### 5.2 算法流程

```
初始化 Q(s, a) 任意值
对每个 episode:
    初始化 s
    根据 Q 和 ε-贪心选择动作 a
    对 episode 中每一步:
        执行动作 a，观察 r, s'
        根据 Q 和 ε-贪心选择 a'     ← 关键：用当前策略选下一个动作
        Q(s,a) ← Q(s,a) + α[r + γQ(s',a') - Q(s,a)]
        s ← s', a ← a'
    直到 s 为终止状态
```

### 5.3 特点

- **保守**：因为更新时考虑了探索动作带来的惩罚
- 适合需要**安全探索**的场景（如悬崖行走问题）

---

## 六、Q-Learning：离策略TD学习

### 6.1 算法原理

离策略（Off-Policy）：对当前Q值，采用**下一状态Q值的最大值**更新（与当前策略无关）：

$$
Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha\left[r_{t+1} + \gamma \max_a Q(s_{t+1}, a) - Q(s_t, a_t)\right]
$$
### 6.2 算法流程

```
初始化 Q(s, a) 任意值
对每个 episode:
    初始化 s
    对 episode 中每一步:
        根据 Q 和 ε-贪心选择动作 a
        执行动作 a，观察 r, s'
        Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]   ← 关键：用max
        s ← s'
    直到 s 为终止状态
```

### 6.3 SARSA vs Q-Learning 对比

| 特性 | SARSA | Q-Learning |
|------|-------|------------|
| 类型 | 在策略（On-Policy） | 离策略（Off-Policy） |
| 更新目标 | $r + \gamma Q(s', a')$ 其中 $a'$ 由当前策略选择 | $r + \gamma \max_a Q(s', a)$ |
| 行为 | 保守，受探索影响 | 激进，直接学最优 |
| 收敛到 | 当前策略的Q值 | 最优Q值（$Q^*$） |
| 行为策略与目标策略 | 相同 | 可以不同 |

## 七、N步TD与TD(λ)

### 7.1 N步TD预测

在TD(0)和MC之间取折中——看"更远的未来"：

$$
R_t^{(n)} = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots + \gamma^{n-1} r_{t+n-1} + \gamma^n V(s_{t+n})
$$
更新规则：

$$
\Delta V(s_t) = \alpha \left[R_t^{(n)} - V(s_t)\right]
$$
| $n$ | 方法 | 说明 |
|-----|------|------|
| $n=1$ | TD(0) | 只看一步 |
| $n=2$ | 2步TD | $R_t^{(2)} = r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2})$ |
| $n \to \infty$ | MC | 看到episode结束 |

**误差缩减性质**：

$$
\left|E_\pi[R_t^{(n)} | s_t = s] - V^\pi(s)\right| \leq \gamma^n \max_s |V(s) - V^\pi(s)|
$$
### 7.2 TD(λ)：平均所有N步回报

#### λ-返回

$$
R_t^\lambda = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} R_t^{(n)}
$$
- 权重 $(1-\lambda)\lambda^{n-1}$ 随步数指数衰减
- **$\lambda = 0$**：退化为 TD(0)
- **$\lambda = 1$**：退化为 MC

#### 前向视角

在每一个状态，向未来看，以"每个状态值函数+已获得的奖赏"来更新当前状态的值函数。

#### 后向视角：资格迹（Eligibility Trace）

定义资格迹 $e_t(s)$：

$$
e_t(s) = \begin{cases} \gamma\lambda \cdot e_{t-1}(s) & \text{if } s \neq s_t \\ \gamma\lambda \cdot e_{t-1}(s) + 1 & \text{if } s = s_t \end{cases}
$$
- 当前访问的状态资格 +1
- 所有状态的资格随时间按 $\gamma\lambda$ 衰减
- 资格越高的状态获得越大的更新量

### 7.3 TD(λ)算法

```
1. 初始化 V(s), e(s) = 0
2. 对每一个 episode:
     初始化 s
     对 episode 中的每一步:
         根据 ε-贪心选择动作 a
         执行动作 a，获得 r 和 s'
         δ ← r + γV(s') - V(s)        // TD误差
         e(s) ← e(s) + 1               // 更新资格迹
         对于所有 s:
             V(s) ← V(s) + αδe(s)      // 按资格迹加权更新
             e(s) ← γλe(s)             // 资格迹衰减
         s ← s'
     直到 s 为终止状态
```

### 核心公式速查

| 名称 | 公式 |
|------|------|
| MC更新 | $V(s_t) \leftarrow V(s_t) + \alpha[R_t - V(s_t)]$ |
| TD(0)更新 | $V(s_t) \leftarrow V(s_t) + \alpha[r_t + \gamma V(s_{t+1}) - V(s_t)]$ |
| SARSA | $Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha[r_{t+1} + \gamma Q(s_{t+1},a_{t+1}) - Q(s_t,a_t)]$ |
| Q-Learning | $Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha[r_{t+1} + \gamma\max_a Q(s_{t+1},a) - Q(s_t,a_t)]$ |
| N步返回 | $R_t^{(n)} = \sum_{k=0}^{n-1}\gamma^k r_{t+k} + \gamma^n V(s_{t+n})$ |
| λ-返回 | $R_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}R_t^{(n)}$ |
| 资格迹 | $e_t(s) = \gamma\lambda e_{t-1}(s) + \mathbf{1}[s = s_t]$ |
| TD(λ)更新 | $V(s) \leftarrow V(s) + \alpha\delta_t e_t(s)$ |

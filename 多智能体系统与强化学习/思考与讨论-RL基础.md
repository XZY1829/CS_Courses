## Q1：回报函数和值函数

### 什么是回报函数（Return）？

回报函数定义了智能体从某时刻起能获得的**累积奖赏总和**，是衡量一条轨迹好坏的标准。

三种常见形式：

| 类型 | 公式 | 适用场景 |
|------|------|----------|
| 有限窗口 | $\sum_{i=0}^{H}R(s_i,a_i)$ | 固定步数任务 |
| 无穷窗口+折扣 | $\sum_{i=0}^{\infty}\gamma^i R(s_i,a_i)$ | **最常用** |
| 平均奖赏 | $\lim_{N\to\infty}\frac{1}{N}\sum_{i=0}^{N-1}R(s_i,a_i)$ | 持续任务 |

折扣因子 $\gamma \in [0,1)$ 的作用：
- $\gamma$ 小 → 短视，只关注近期奖赏
- $\gamma$ 大 → 远视，重视长期奖赏
- 数学上保证无穷级数**收敛**

### 什么是值函数（Value Function）？

值函数是回报函数的**期望**，度量"在某状态/状态-动作对下，遵循某策略所能获得的期望累积奖赏"。

- **状态值函数**：$V^\pi(s) = E\left[\sum_{t=0}^{\infty}\gamma^t r_t \mid s_0=s, \pi\right]$
- **动作值函数**：$Q^\pi(s,a) = R(s,a) + \gamma\sum_{s'}\delta(s,a,s')V^\pi(s')$
- **二者关系**：$V^\pi(s) = Q^\pi(s, \pi(s))$
- **最优值函数**：$V^*(s) = \max_\pi V^\pi(s)$

### 回报函数和值函数的本质区别？

| | 回报函数 | 值函数 |
|---|---|---|
| 本质 | 一条具体轨迹的累积奖赏（随机变量） | 累积奖赏的**期望值** |
| 用途 | 描述一次经历的好坏 | 评价一个状态/策略的整体优劣 |
| 是否确定 | 随轨迹变化，具有随机性 | 给定策略后是确定的函数 |

## Q2：动态规划和蒙特卡罗采样的区别

### 动态规划（DP）的核心思想是什么？

- **前提**：MDP 模型完全已知（转移概率 $\delta$ 和奖赏 $R$ 已知）
- **核心工具**：Bellman 等式
- **更新公式**：$V(s) \leftarrow R(s,\pi(s)) + \gamma\sum_{s'}\delta(s,\pi(s),s')V(s')$
- 遍历所有可能的后继状态，精确计算期望

### 蒙特卡罗（MC）的核心思想是什么？

- **前提**：模型未知，通过与环境交互采样学习
- **核心思想**：等到 episode 结束，用完整返回值 $G_t$ 更新
- **更新公式**：$V(s_t) \leftarrow V(s_t) + \alpha[G_t - V(s_t)]$
- 其中 $G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots$

### DP 和 MC 的关键区别？

| 维度 | 动态规划（DP） | 蒙特卡罗（MC） |
|------|---------------|---------------|
| **模型需求** | 需要模型完全已知 | **无模型**，只需交互采样 |
| **更新依据** | Bellman 方程，遍历所有后继状态 | 完整轨迹的实际返回值 $G_t$ |
| **Bootstrap** | ✅ 用估计值更新估计值 | ❌ 直接用实际回报 |
| **Sampling** | ❌ 穷举所有转移 | ✅ 只用采样到的路径 |
| **偏差** | 精确计算，无偏差问题 | **无偏**估计 |
| **方差** | 无方差问题 | **高方差**（轨迹随机性累积） |
| **适用场景** | 小规模、模型已知 | 模型未知、有终止状态 |

**一句话总结**：DP 靠"算"（已知模型精确计算期望），MC 靠"试"（未知模型通过采样估计期望）。

## Q3：SARSA 和 Q-Learning 算法的区别

### SARSA 的更新规则是什么？

SARSA 是 **On-Policy** TD 控制方法，用当前策略实际选择的下一个动作 $a'$ 来更新：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha[r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t,a_t)]$$

其中 $a_{t+1}$ 由当前策略（如ε-贪心）实际选出。

### Q-Learning 的更新规则是什么？

Q-Learning 是 **Off-Policy** TD 控制方法，不管当前策略选什么，直接用 $\max$ 操作更新：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha[r_{t+1} + \gamma\max_a Q(s_{t+1},a) - Q(s_t,a_t)]$$

### SARSA 和 Q-Learning 的核心区别？

| 特性 | SARSA | Q-Learning |
|------|-------|------------|
| 策略类型 | **On-Policy**（行为策略 = 目标策略） | **Off-Policy**（行为策略 ≠ 目标策略） |
| 更新目标中的下一动作 | 实际执行的 $a'$（来自ε-贪心） | 虚拟的 $\max$ 动作 |
| 收敛目标 | 当前策略的 Q 值 | 最优 Q 值 $Q^*$ |
| 行为特征 | **保守/安全**（受探索惩罚影响） | **激进/乐观**（直接学最优） |
| 行为策略=目标策略？ | 是 | 否 |

### 悬崖行走（Cliff Walking）案例如何体现区别？

- **SARSA** 会避开悬崖边缘走远路——因为它考虑了在ε-贪心下有概率随机跌落悬崖的惩罚
- **Q-Learning** 会贴着悬崖走最短路——因为 $\max$ 假设下一步永远选最优动作，忽视了探索带来的坠崖风险

## Q4：TD(λ) 算法

### TD(λ) 的动机是什么？

TD(0) 只看一步未来（低方差但有偏），MC 看到结束（无偏但高方差）。TD(λ) 通过参数 $\lambda$ 在两者之间平滑过渡，兼顾偏差和方差。

### N步TD回报如何定义？

$$R_t^{(n)} = r_t + \gamma r_{t+1} + \cdots + \gamma^{n-1}r_{t+n-1} + \gamma^n V(s_{t+n})$$

| $n$ | 方法 | 说明 |
|-----|------|------|
| 1 | TD(0) | 只看一步 |
| 2 | 2步TD | 看两步 + Bootstrap |
| $\infty$ | MC | 看到 episode 结束 |

### λ-返回是如何将所有N步回报统一起来的？

用指数衰减权重加权所有 N 步回报：

$$R_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}R_t^{(n)}$$

- 权重 $(1-\lambda)\lambda^{n-1}$ 随步数指数衰减，归一化到1
- $\lambda=0$：退化为 **TD(0)**
- $\lambda=1$：退化为 **MC**
- $0 < \lambda < 1$：平滑过渡

### 什么是资格迹（Eligibility Trace）？

资格迹是 TD(λ) 后向视角的关键机制，记录"哪些状态该为当前 TD 误差负责"：

$$e_t(s) = \begin{cases}\gamma\lambda\cdot e_{t-1}(s) + 1 & \text{if } s = s_t \\ \gamma\lambda\cdot e_{t-1}(s) & \text{if } s \neq s_t\end{cases}$$

- 当前访问的状态资格 +1
- 所有状态资格按 $\gamma\lambda$ 衰减
- 资格越高 → 越该为当前 TD 误差负责 → 更新量越大

### TD(λ) 的完整算法流程？

```
初始化 V(s), e(s)=0
对每个 episode:
    初始化 s
    对每一步:
        选择动作 a（ε-贪心）
        执行 a → 观察 r, s'
        δ ← r + γV(s') - V(s)        // 计算TD误差
        e(s) ← e(s) + 1               // 当前状态资格+1
        对所有状态 s:
            V(s) ← V(s) + αδe(s)      // 按资格加权更新
            e(s) ← γλe(s)             // 所有资格衰减
        s ← s'
```

### 前向视角和后向视角有什么区别？

| 视角 | 实现方式 | 特点 |
|------|---------|------|
| 前向 | 从当前看未来，加权所有N步回报 | 概念直观，但需整条轨迹（离线） |
| 后向 | 用资格迹 + TD误差每步更新所有状态 | **可在线实现**，数学上与前向等价 |

### TD(λ) 的注意事项？

- 每步计算代价为 $O(|S|)$（需更新所有状态的值和资格迹）
- 实际中常用稀疏实现优化
- $\lambda$ 是重要超参数，控制偏差-方差权衡

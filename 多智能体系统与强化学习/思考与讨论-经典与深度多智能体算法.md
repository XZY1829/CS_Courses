# 第十讲：经典多智能体算法

## Q1：联合动作学习者（JAL）的收敛性能够保证吗？

### 什么是联合动作学习者？

JAL（Joint Action Learner）学习联合动作的 Q 值表：

$$Q_i(s, a_1, a_2, ..., a_n)$$

显式考虑所有智能体的动作，缓解了独立学习者（IL）面临的非平稳性问题。

### 收敛性分析

**JAL 的收敛性不能无条件保证**，原因如下：

| 问题 | 说明 |
|------|------|
| **联合动作空间指数增长** | $n$ 个智能体各有 $k$ 个动作 → $k^n$ 种联合动作，探索困难 |
| **非平稳性未完全消除** | 所有智能体同时在学习，各自策略仍在变化 |
| **多重均衡** | 博弈中可能存在多个纳什均衡，不同初始化可能收敛到不同均衡 |
| **相对过度泛化（RO）** | 即使 JAL 能看到联合动作，也可能被局部奖励吸引到次优解 |

**有限条件下的收敛**：
- 在**合作型**博弈 + 所有智能体使用相同学习算法 + 充分探索条件下，部分 JAL 变体可收敛
- 在**零和博弈**中，Minimax-Q 有收敛保证
- 一般情况下（混合博弈、多均衡），收敛到何种解取决于学习动态

### IL vs JAL 的权衡

| | IL（独立学习） | JAL（联合动作学习） |
|--|--------------|-------------------|
| 状态-动作空间 | $|S| \times |A_i|$ | $|S| \times |A_1| \times ... \times |A_n|$ |
| 非平稳性 | 严重（其他智能体视为环境） | 缓解（显式建模联合动作） |
| 可扩展性 | **好** | **差**（指数增长） |
| 收敛保证 | 无（环境非平稳） | 有限条件下有 |

## Q2：除了差分奖励还有其他的信度分配算法吗？

### 信度分配问题是什么？

在合作多智能体系统中，团队获得一个**共享奖励**，但需要判断每个智能体对团队成功的**个体贡献**——即信度分配（Credit Assignment）。

### 差分奖励（Difference Reward）

$$D_i = G(z) - G(z_{-i})$$

其中 $G(z)$ 是有智能体 $i$ 参与的全局收益，$G(z_{-i})$ 是去掉智能体 $i$ 的全局收益。衡量智能体 $i$ 的**边际贡献**。

### 其他信度分配算法

| 方法 | 核心思想 | 特点 |
|------|---------|------|
| **COMA（反事实基线）** | $Adv_i = Q(s, a) - \sum_{a_i'}\pi(a_i')Q(s, (a_i', a_{-i}))$；将智能体 $i$ 的实际贡献与其"平均动作贡献"对比 | 不需要去掉智能体，用反事实推理 |
| **VDN（值分解）** | $Q_{tot} = \sum_i Q_i$；线性分解全局 Q 值到个体 | 简单但表达力有限 |
| **QMIX（单调混合）** | $Q_{tot} = f(Q_1,...,Q_n)$，$\frac{\partial Q_{tot}}{\partial Q_i} > 0$ | 比 VDN 表达力强 |
| **Shapley Value** | 从合作博弈论出发，计算每个智能体在所有可能联盟中的平均边际贡献 | 理论最公平但计算复杂 $O(2^n)$ |
| **极化策略梯度** | 通过中心化 Critic 直接为每个 Actor 提供个性化梯度信号 | 适合策略梯度框架 |
| **注意力机制** | 用注意力权重衡量不同智能体交互对 Q 值的贡献 | 可学习的动态信度分配 |

## Q3：多智能体强化学习如何解决 RO（相对过度泛化）问题？

### 什么是相对过度泛化（Relative Overgeneralization）？

在合作博弈中，一个**次优的联合动作**由于在与对手各种策略配对时能获得**较好的平均回报**，而被误判为更优——导致系统收敛到次优均衡，而非全局最优。

**本质**：即使全局最优解回报更高，但它对合作伙伴策略的要求更严格（方差更大），而次优解"稳定得多"（对伙伴策略变化不敏感），学习者被"安全"的次优解吸引。

### 解决 RO 的方法

#### 1. Lenient Q-Learning（宽容学习）

- **思想**：训练早期对负面反馈持宽容态度——即使获得了低奖励，也不急于降低该动作的 Q 值
- **机制**：维护温度参数，高温时忽略低奖励的 TD 更新；温度逐渐衰减恢复标准学习
- **效果**：给智能体更多时间探索全局最优协作策略

#### 2. Hysteretic Q-Learning（滞后学习）

- **思想**：对正 TD 误差快学，对负 TD 误差慢学

$$\alpha = \begin{cases} \alpha^+ & \text{if } \delta \geq 0 \text{（正更新）} \\ \alpha^- < \alpha^+ & \text{if } \delta < 0 \text{（负更新）} \end{cases}$$

- **效果**：乐观偏置使智能体不轻易放弃高回报动作

#### 3. WoLF（Win or Learn Fast）

- **思想**：赢的时候慢学（维持好策略），输的时候快学（快速适应）
- **效果**：防止在找到好策略后被噪声扰动离开

#### 4. rFMQ（Frequency Maximum Q-value）

- **思想**：结合动作的最大回报和该最大回报出现的频率来选择动作
- **效果**：不仅关注回报大小，还关注回报的可靠程度

#### 5. Lenient-DQN

- 将宽容学习扩展到深度 Q 网络
- 用温度衰减实现从探索到利用的过渡

# 第十一讲：深度多智能体强化学习

## Q4：理解集中式训练分布式执行（CTDE）

### 核心思想

**训练阶段**可以使用所有可用信息（集中式），**执行阶段**每个智能体只用局部信息独立决策（分布式）。

```
训练阶段（集中式）               执行阶段（分布式）
┌─────────────────┐           ┌─────────────┐
│ 可用信息：         │           │ 可用信息：     │
│ · 全局状态 s      │           │ · 局部观测 o_i │
│ · 所有智能体观测   │           │              │
│ · 所有智能体动作   │           │ 输出：        │
│ · 全局奖励        │           │ · 局部策略 π_i │
└─────────────────┘           └─────────────┘
```

### 为什么需要 CTDE？

| 纯分布式 | 纯集中式 | CTDE |
|---------|---------|------|
| 训练时无法利用全局信息 → 非平稳 | 执行时需要全部同步 → 不现实 | 训练时集中获取信息 → 学得好 |
| 但执行时可独立 | 计算开销大 | 执行时分散独立 → 部署方便 |

### 代表算法

- **COMA**：集中式 Critic + 分布式 Actor
- **MADDPG**：集中式 Q 函数训练 + 分布式确定性策略执行
- **QMIX**：集中式训练混合网络 + 分布式个体 Q 网络执行

## Q5：理解 VDN 和 QMIX 的区别

### VDN（Value Decomposition Network）

**核心假设**：全局 Q 值是个体 Q 值的**线性加和**：

$$Q_{tot}(s, a) = \sum_{i=1}^n Q_i(\tau_i, a_i)$$

- 每个智能体有独立的 Q 网络 $Q_i$，只接收局部历史 $\tau_i$
- 简单直接，保证 IGM（Individual-Global-Max）

### QMIX

**核心假设**：全局 Q 值是个体 Q 值的**单调非线性混合**：

$$Q_{tot} = f_{mix}(Q_1, Q_2, ..., Q_n; s)$$

约束：$\frac{\partial Q_{tot}}{\partial Q_i} > 0, \quad \forall i$

- 混合网络的权重由**超网络（Hypernetwork）**根据全局状态 $s$ 生成
- 权重非负保证单调性

### 核心区别

| 维度 | VDN | QMIX |
|------|-----|------|
| 分解方式 | **线性加和** | **单调非线性混合** |
| 表达能力 | 弱（只能表示加性分解） | **强**（能表示任何单调组合） |
| 全局状态利用 | 不使用 | 通过超网络利用全局状态 |
| 个体 Q 之间关系 | 完全独立、等权 | 可以有不同权重、非线性交互 |
| IGM 保证 | ✅ | ✅ |
| 局限性 | 无法表达智能体间协同效应 | 仍受单调性限制 |

### 举例说明表达力差异

假设两个智能体，最优联合动作要求 $Q_1$ 高而 $Q_2$ 低（非单调依赖）：
- VDN 无法表达（加和不允许 $Q_2$ 低对 $Q_{tot}$ 高）
- QMIX 也无法表达（单调性要求 $Q_i$ 增则 $Q_{tot}$ 增）
- 需要 QTRAN 等更通用的方法

## Q6：理解集中式评论家/价值函数的作用

### 什么是集中式评论家？

训练时使用**额外全局信息**来评估联合行为的 Critic：

$$Q_{centralized}(s, a_1, a_2, ..., a_n)$$

或者：

$$V_{centralized}(s)$$

执行时只用各自的 Actor $\pi_i(a_i | o_i)$。

### 为什么需要？

- **解决信度分配**：集中式 Critic 能看到所有智能体的动作，判断谁贡献大
- **减少方差**：比独立 Critic 有更准确的评估
- **不破坏分散执行**：Critic 只在训练时使用，执行时不需要

### COMA 中的反事实基线

COMA 用集中式 Critic 计算反事实优势：

$$Adv_i(h_i, z, a) = Q(h_i, z, a; \theta) - \sum_{a_i'}\pi(a_i' | h_i; \phi_i)Q(h_i, z, (a_i', a_{-i}); \theta)$$

**含义**：智能体 $i$ 的实际动作的 Q 值 vs 如果 $i$ 按其策略分布随机选动作的平均 Q 值。正优势说明该动作高于 $i$ 的平均贡献。

## Q7：理解 IGM 的原理

### IGM（Individual-Global-Max）

$$\arg\max_a Q_{tot}(s, a) = \begin{pmatrix} \arg\max_{a_1} Q_1(\tau_1, a_1) \\ \vdots \\ \arg\max_{a_n} Q_n(\tau_n, a_n) \end{pmatrix}$$

**含义**：每个智能体分别对自己的 $Q_i$ 做贪心选择动作，联合起来恰好是全局 $Q_{tot}$ 的贪心最优联合动作。

### 为什么重要？

- **分散执行的保证**：每个智能体只需最大化自己的 $Q_i$ 就能实现全局最优——不需要通信
- **训练-执行一致性**：训练时学到的分解在执行时仍然正确

### 如何保证 IGM？

- **VDN**：$Q_{tot} = \sum Q_i$ → 加和的最大值 = 各项最大值之和 ✅
- **QMIX**：$\frac{\partial Q_{tot}}{\partial Q_i} > 0$（单调性）→ 各 $Q_i$ 增大则 $Q_{tot}$ 增大 ✅
- **无约束网络**：不保证 IGM → 分散执行可能次优 ❌

## Q8：理解均衡选择问题

### 什么是均衡选择问题？

当博弈存在**多个纳什均衡**时，不同智能体可能"瞄准"不同的均衡，导致最终收敛到**次优但安全**的均衡。

### 经典例子：协调博弈

| | 动作 A | 动作 B |
|--|--------|--------|
| 动作 A | **(10, 10)** | (0, 0) |
| 动作 B | (0, 0) | **(5, 5)** |

- 均衡1：(A, A) → 回报 (10, 10)（帕累托最优）
- 均衡2：(B, B) → 回报 (5, 5)（风险更低）

### 为什么会收敛到次优均衡？

1. 探索阶段，对方随机选择 → 选 A 时有 50% 概率得 0
2. 选 B 时有 50% 概率得 5 → B 的**平均回报更高**
3. 学习者被 B 的"安全性"吸引 → 收敛到 (B, B)
4. 这就是**相对过度泛化**的又一表现

### 解决方法

- **宽容学习**：早期不惩罚失败的协调尝试
- **通信机制**：让智能体协商选择同一均衡
- **Lenient-DQN**：温度衰减给予足够探索时间
- **社会约定/预训练**：通过先验知识引导到帕累托最优均衡

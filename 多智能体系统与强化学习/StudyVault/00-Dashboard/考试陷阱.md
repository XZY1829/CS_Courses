# 考试陷阱

1. SARSA 是 on-policy，Q-learning 是 off-policy。
2. PPO 的 clip 是限制更新幅度，不是单纯提高回报上限。
3. 离线 RL 的核心难点是 OOD 动作导致 Q 高估。
4. 纳什均衡不一定社会福利最大，也不一定帕累托最优。
5. IL 简单但非平稳；JAL 纳入联合动作但空间爆炸。
6. Lenient/Hysteretic/WoLF/rFMQ 主要缓解协同探索或相对过度泛化，不是信度分配算法。
7. 差分奖励、COMA、VDN、QMIX 都与信度分配有关，但机制不同。
8. CTDE 不是集中式执行。执行阶段仍是局部信息。
9. VDN 是线性分解，QMIX 是单调非线性分解。
10. DPO 不需要显式 Reward Model 和 Critic，但仍依赖 chosen/rejected 偏好数据。
11. RLVR 的奖励来自规则或环境验证，不等于 RLHF 的人工偏好。
12. GRPO 用组内归一化优势替代 Critic，但采样成本和冷启动要求仍然存在。

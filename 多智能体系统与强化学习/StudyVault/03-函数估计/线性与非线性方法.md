# 线性与非线性方法（★★★）

#rl #function-approx

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 线性方法 | $\hat{V}(s,\mathbf{w}) = \mathbf{w}^T\mathbf{x}(s)$，梯度简单，收敛有保证 |
| 非线性方法 | 神经网络，表达力强但收敛不保证 |
| 致命三要素 | 函数逼近 + 自举 + 离策略 → 可能发散 |
| Q函数逼近 | $\hat{Q}(s,a,\mathbf{w})$，直接用于动作选择 |

## 线性值函数

$$
\hat{V}(s,\mathbf{w}) = \mathbf{w}^T\mathbf{x}(s) = \sum_{j=1}^d w_j x_j(s)
$$

梯度极其简单：
$$
\nabla_\mathbf{w}\hat{V}(s,\mathbf{w}) = \mathbf{x}(s)
$$

### 线性TD(0)更新

$$
\Delta\mathbf{w} = \alpha(r_t + \gamma\mathbf{w}^T\mathbf{x}(s_{t+1}) - \mathbf{w}^T\mathbf{x}(s_t))\mathbf{x}(s_t)
$$

### 收敛性保证

| 方法 | 表格型 | 线性函数逼近 |
|------|--------|-------------|
| MC | ✅ 全局最优 | ✅ 全局最优 |
| TD(0) | ✅ 全局最优 | ✅ TD不动点 |
| TD(λ) | ✅ | ✅ |

**TD不动点误差界**：
$$
\|\hat{V}_{TD} - V^\pi\| \leq \frac{1}{\sqrt{1-\gamma}}\min_\mathbf{w}\|\hat{V}_\mathbf{w} - V^\pi\|
$$

> [!tip] 含义
> 线性TD收敛到的解最多比最优线性逼近差 $\frac{1}{\sqrt{1-\gamma}}$ 倍。

## 非线性函数逼近（神经网络）

$$
\hat{V}(s,\mathbf{w}) = f_{\text{NN}}(s;\mathbf{w})
$$

梯度通过**反向传播**计算。

### 挑战

| 挑战 | 说明 |
|------|------|
| 不保证收敛 | 非线性 + TD → 可能发散 |
| 过拟合 | 参数多、数据有限 |
| 灾难性遗忘 | 学新忘旧 |
| 训练不稳定 | 样本相关+目标非平稳 |

## 致命三要素（Deadly Triad）

当以下三个条件**同时满足**时，学习可能发散：

```
┌──────────────────────┐
│   1. 函数逼近         │ ← 非表格型
│   2. 自举(Bootstrap)  │ ← TD而非MC
│   3. 离策略学习       │ ← Off-Policy
└──────────────────────┘
         ↓ 同时满足
    学习可能发散！
```

> [!important] DQN正好满足这三个条件
> 所以DQN需要**经验回放**和**目标网络**来稳定训练。

## 状态-动作值函数逼近

$$
\hat{Q}(s,a,\mathbf{w}) \approx Q^\pi(s,a)
$$

线性形式：$\hat{Q}(s,a,\mathbf{w}) = \mathbf{w}^T\mathbf{x}(s,a)$

TD更新：
$$
\Delta\mathbf{w} = \alpha(r + \gamma\max_a\hat{Q}(s',a,\mathbf{w}) - \hat{Q}(s,a,\mathbf{w}))\nabla_\mathbf{w}\hat{Q}(s,a,\mathbf{w})
$$

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "线性逼近的梯度" | $\nabla_\mathbf{w}\hat{V} = \mathbf{x}(s)$ |
| "致命三要素是什么" | 函数逼近 + 自举 + 离策略 |
| "去掉哪个条件安全" | 去任何一个都行：用表格、用MC、用On-Policy |
| "线性TD收敛到什么" | TD不动点（非全局最优，但有误差界） |

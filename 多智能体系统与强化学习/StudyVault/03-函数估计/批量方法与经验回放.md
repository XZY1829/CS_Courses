# 批量方法与经验回放（★★）

#rl #function-approx #experience-replay

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 经验回放 | 存储经验→随机采样→打破相关性+复用数据 |
| LSTD | 线性函数逼近的直接求解方法 |
| 核心价值 | 提高样本效率、稳定训练 |

## 经验回放（Experience Replay）

**问题**：连续采样的数据具有强时序相关性，违反SGD的i.i.d.假设。

**解决方案**：
1. 将经验 $(s, a, r, s')$ 存入**缓冲区（Replay Buffer）**
2. 训练时从缓冲区**随机均匀采样**小批量数据

**效果**：
- 打破样本间的**时序相关性** → 稳定训练
- 重复利用历史数据 → 提高**样本效率**
- 可以从多种策略的数据中学习（支持Off-Policy）

> [!warning] 经验回放的代价
> - 需要额外内存存储缓冲区
> - 旧数据可能与当前策略不匹配（数据过时）
> - 不适用于On-Policy方法（如SARSA）

## 最小二乘TD（LSTD）

对线性函数逼近，可以直接求解最优参数（无需步长 $\alpha$）：

$$
\mathbf{w} = \left(\sum_t\mathbf{x}(s_t)(\mathbf{x}(s_t) - \gamma\mathbf{x}(s_{t+1}))^T\right)^{-1}\sum_t r_{t+1}\mathbf{x}(s_t)
$$

| 优点 | 缺点 |
|------|------|
| 样本效率最高 | 计算代价 $O(d^2)$ 每步 |
| 无需调步长 | 只适用线性逼近 |
| 不需多次迭代 | 矩阵求逆可能数值不稳定 |

## 批量方法 vs 在线方法

| 特性 | 在线方法 | 批量方法 |
|------|---------|---------|
| 数据使用 | 用一次就丢 | 存储并重复使用 |
| 计算效率 | 高（每步O(d)） | 较低（需要矩阵运算或多次遍历） |
| 样本效率 | 低 | **高** |
| 适用场景 | 计算资源有限 | 样本珍贵（真实环境交互昂贵） |

# 值函数逼近框架（★★★）

#rl #function-approx

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 动机 | 表格型方法无法处理大/连续状态空间 |
| 核心思想 | 用参数化函数 $\hat{V}(s,\mathbf{w})$ 近似真实值函数 |
| 好处 | 泛化、压缩、处理连续空间 |
| 训练方法 | 随机梯度下降（SGD） |

## 为什么需要函数逼近？

表格型方法的局限：
- 围棋：$10^{170}$ 种状态 → 无法存储
- 连续状态：无穷多状态 → 表格无法枚举
- 无泛化：未见状态的值函数无法推断

**解决方案**：$\hat{V}(s,\mathbf{w}) \approx V^\pi(s)$，$|\mathbf{w}| \ll |S|$

## 目标函数

$$
J(\mathbf{w}) = E_\pi\left[(V^\pi(s) - \hat{V}(s,\mathbf{w}))^2\right]
$$

## SGD更新规则

$$
\Delta\mathbf{w} = \alpha(V^\pi(s) - \hat{V}(s,\mathbf{w}))\nabla_\mathbf{w}\hat{V}(s,\mathbf{w})
$$

> [!important] 真实值未知
> $V^\pi(s)$ 未知，需要用**替代目标**：
> - MC → $G_t$（无偏）
> - TD(0) → $r + \gamma\hat{V}(s',\mathbf{w})$（有偏，半梯度）
> - TD(λ) → $R_t^\lambda$

## 不同替代目标

| 方法 | 替代目标 | 特点 |
|------|---------|------|
| MC | $G_t$ | 无偏但高方差 |
| TD(0) | $r + \gamma\hat{V}(s',\mathbf{w})$ | 有偏低方差，**半梯度** |
| TD(λ) | $R_t^\lambda$ | 折中 |

> [!warning] 半梯度（Semi-Gradient）
> TD目标 $r + \gamma\hat{V}(s',\mathbf{w})$ 本身依赖 $\mathbf{w}$，但求梯度时被当作常数。因此称为"半梯度"，不是真正的梯度下降。

## 特征向量表示

状态 $s$ → 特征向量 $\mathbf{x}(s) = (x_1(s), x_2(s), ..., x_d(s))^T$

常见特征构造：

| 方法 | 公式 | 特点 |
|------|------|------|
| 多项式基 | $x_j(s) = s^j$ | 简单，高阶过拟合 |
| 傅里叶基 | $x_j(s) = \cos(j\pi s)$ | 周期性特征 |
| RBF | $x_j(s) = e^{-\|s-c_j\|^2/2\sigma_j^2}$ | 局部响应 |
| Tile Coding | 多层重叠网格 | 稀疏高效，适合在线学习 |
| 状态聚合 | 相似状态分组 | 最简单的函数逼近 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "为什么需要函数逼近" | 大/连续状态空间，表格型不可行+无泛化 |
| "SGD更新公式" | $\Delta\mathbf{w} = \alpha(\text{target} - \hat{V})\nabla_\mathbf{w}\hat{V}$ |
| "半梯度含义" | TD目标依赖w但被当常数 |
| "Tile Coding优势" | 特征稀疏、计算高效、适合在线学习 |

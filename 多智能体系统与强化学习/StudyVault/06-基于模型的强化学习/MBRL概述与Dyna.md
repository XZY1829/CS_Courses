# MBRL概述与Dyna（★★）

#rl #model-based #dyna

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| MBRL核心 | 从经验中学习环境模型→从模型中规划 |
| 优势 | 样本效率高、支持长期规划 |
| 劣势 | 模型误差可能累积 |
| Dyna | 集成真实经验和模拟经验的框架 |

## Model-based vs Model-free

| 维度 | Model-free | Model-based |
|------|-----------|-------------|
| 学什么 | 直接学值函数/策略 | 先学模型，再规划 |
| 样本效率 | **低** | **高** |
| 模型需求 | 不需要 | 需要学习/给定 |
| 长期规划 | 不支持多步预测 | 支持 |
| 风险 | — | 模型误差影响决策 |

## 环境模型

学习两个组件：
- **状态动态模型**：$\hat{f}(s,a) \approx s'$（预测下一状态）
- **奖励模型**：$\hat{R}(s,a) \approx r$（预测奖励）

```
真实环境              环境模型
状态动态 P(s'|s,a)    状态动态 P̂(s'|s,a)
奖励函数 R(s,a)       奖励函数 R̂(s,a)
    ↕ 从真实到虚拟
    交互
```

## 模型学习

**查找表模型**：统计转移频率和平均奖励
- $\hat{P}(s'|s,a) = \frac{\text{count}(s,a,s')}{\text{count}(s,a)}$
- $\hat{R}(s,a) = \text{mean}(r|s,a)$

**参数化模型**：用神经网络拟合动态函数。

## Dyna框架

**核心思想**：同时使用**真实经验**（直接RL）和**模拟经验**（从学到的模型采样）来更新值函数。

```
              经验集成
    ┌─────────────────────────┐
    │  真实经验 → 直接RL       │  (Model-free部分)
    │  真实经验 → 模型学习     │  (学习模型)
    │  模拟经验 → 规划        │  (Model-based部分)
    └─────────────────────────┘
```

## Dyna-Q算法

```
初始化 Q(s,a), Model(s,a)
对每一步:
    选择 a（ε-贪心）
    执行 a → r, s'
    
    [直接RL]
    Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]
    
    [模型学习]
    Model(s,a) ← (r, s')    // 记录转移
    
    [规划] 重复N次：
        随机选择之前访问过的 (s̃, ã)
        (r̃, s̃') ← Model(s̃, ã)    // 模拟经验
        Q(s̃,ã) ← Q(s̃,ã) + α[r̃ + γ max_a Q(s̃',a) - Q(s̃,ã)]
```

> [!important] 规划步骤数N的影响
> N越大 → 每步学得越多（样本效率高），但对模型准确性依赖越大。

## 模型不准确问题

- 模型永远是近似的
- 使用不准确模型做规划 → 可能学到次优甚至有害的策略
- **解决思路**：限制规划视野、MPC、模型集成

# 轨迹优化与MPC（★★）

#rl #model-based #mpc

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 轨迹优化 | 学模型→优化整条轨迹的动作序列 |
| MPC | 优化轨迹→只执行第一步→重新规划 |
| MBPO | 模型学习+模型展开+策略优化 |
| 核心挑战 | 模型误差沿轨迹累积 |

## 轨迹优化算法演进

### 算法1：基础版

```
步骤1：运行随机策略收集数据 D
步骤2：学习动态模型 f̂(s,a)（监督学习最小化预测误差）
步骤3：通过 f̂ 规划优化动作序列
```

> [!warning] 问题
> 微小模型误差沿轨迹**指数级累积** → 长期预测不可靠

### 算法2：迭代改进

```
运行随机策略收集 D₀
循环：
    学习动态模型 f̂
    通过 f̂ 规划动作序列
    执行动作，将新数据加入 D  ← 迭代收集更多数据
```

但问题：先规划完所有动作再执行，后面的动作误差大。

### 算法3：MPC（模型预测控制）

```
运行随机策略收集 D₀
循环每N步：
    学习动态模型 f̂
    循环每步：
        规划整条轨迹
        只执行第一个动作  ← MPC核心
        观察真实结果
        将新数据加入 D
```

**MPC三步骤**：
1. **预测**：基于当前状态+模型预测未来行为
2. **优化**：求解满足约束的最优控制序列
3. **滚动执行**：只执行第一步，下一时刻重新规划

> [!tip] MPC的关键优势
> 每步都重新观察真实状态并重新规划 → 有机会**纠正**模型误差带来的偏差。

### 算法4：模型+策略联合学习

```
运行随机策略收集 D₀
循环：
    学习动态模型 f̂
    通过 f̂ 反向传播到策略网络 π_θ
    运行 π_θ 收集新数据加入 D
```

## MBPO（Model-Based Policy Optimization）

**三个阶段**：
1. **模型学习**：从真实数据学习动态模型
2. **模型展开（Rollout）**：从真实状态出发，用模型生成短轨迹
3. **策略优化**：用模拟数据做策略梯度更新

> [!important] 短视野展开
> MBPO只做短步展开（如1-5步），避免长期模型误差累积。

## MBRL总结

| 特性 | Model-free | Model-based |
|------|-----------|-------------|
| 样本效率 | 低 | **高** |
| 计算效率 | 高（直接更新） | 较低（需要规划） |
| 渐近性能 | 可能更好 | 受限于模型精度 |
| 适用场景 | 大量交互廉价 | 交互昂贵（机器人、医疗） |

# RL基础与MDP（★★★）

#rl #mdp

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 核心问题 | 智能体如何通过与环境交互最大化长期累积奖赏 |
| 数学框架 | 马尔可夫决策过程（MDP） |
| 关键区别 | RL的数据分布是**策略依赖**的（非i.i.d.） |
| 核心挑战 | 探索与利用的折衷（Exploration vs Exploitation） |

## 强化学习的本质

强化学习通过**试错（Trial and Error）**学习：

```
   action ──► Environment ──► state
   reward ◄──            
       ▲
   RL Agent
```

- 智能体观察**状态** → 选择**动作** → 获得**奖赏** → 转移到新状态
- 核心与监督学习的区别：数据分布随策略变化而变化

| 特性 | 监督学习 | 强化学习 |
|------|----------|----------|
| 数据 | 带标签、i.i.d. | 交互产生、策略依赖 |
| 反馈 | 即时正确答案 | 延迟奖赏信号 |
| 目标 | 预测/分类 | 最大化累积奖赏 |

## MDP定义

$$
\text{MDP} = \langle S, A, \delta, R \rangle
$$

| 符号 | 含义 |
|------|------|
| $S$ | 状态集合（$|S|=n$） |
| $A$ | 动作集合（$|A|=k$） |
| $\delta(s,a,s')$ | 状态转移概率 |
| $R(s,a)$ | 即时奖赏函数 |

> [!important] 马尔可夫性质
> 下一状态只依赖于当前状态和动作，与历史无关：$P(s_{t+1}|s_t,a_t) = P(s_{t+1}|s_0,...,s_t,a_0,...,a_t)$

## 策略（Policy）

- **确定性策略**：$a = \pi(s)$
- **随机性策略**：$\pi(a|s) = P(a|s)$

> [!tip] 关键定理
> 对任何有限MDP，**必然存在确定性最优策略**。

## 返回函数（Return）

| 类型 | 公式 | 适用场景 |
|------|------|----------|
| 有限窗口 | $\sum_{i=0}^{H}R(s_i,a_i)$ | 固定步数任务 |
| 无穷窗口+折扣 | $\sum_{i=0}^{\infty}\gamma^i R(s_i,a_i)$ | **最常用** |
| 平均奖赏 | $\lim_{N\to\infty}\frac{1}{N}\sum_{i=0}^{N-1}R(s_i,a_i)$ | 持续任务 |

折扣因子 $\gamma \in [0,1)$：
- $\gamma$ 小 → 短视，关注近期
- $\gamma$ 大 → 远视，关注长期
- 保证无穷级数**收敛**

## 值函数

$$
V^\pi(s) = E\left[\sum_{t=0}^{\infty}\gamma^t r_t \mid s_0=s, \pi\right]
$$

$$
Q^\pi(s,a) = R(s,a) + \gamma\sum_{s'}\delta(s,a,s')V^\pi(s')
$$

**关系**：$V^\pi(s) = Q^\pi(s, \pi(s))$

**最优值函数**：$V^*(s) = \max_\pi V^\pi(s)$

# 离线RL与分布偏移（★★★）

#rl #offline-rl

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 离线RL | 训练时**完全不与环境交互**，只用静态数据集 |
| 动机 | 真实环境交互风险高/昂贵（自动驾驶、医疗） |
| 核心挑战 | 分布偏移 → 外推误差 → Q值过高估计 |
| BC对比 | 行为克隆是监督学习，不用奖励信号 |

## 三种RL范式

| 范式 | 训练时交互？ | 数据来源 |
|------|------------|---------|
| On-Policy | ✅ | 当前策略收集 |
| Off-Policy | ✅ | 可用其他策略数据 |
| **Offline** | ❌ | 仅固定数据集 |

```
On-Policy:   π_θ ←→ Environment（实时交互）
Off-Policy:  π_θ ←→ Environment + Replay Buffer
Offline:     π_θ ←  固定数据集 D（不交互！）
```

## 分布偏移（Distribution Shift）

**问题**：训练数据由行为策略 $\pi_\beta$ 收集，但学到的策略 $\pi_\theta$ 可能访问**数据中未覆盖的区域（OOD）**。

## 外推误差（Extrapolation Error）

$$
Q(s, a_\text{OOD}) = \text{?}
$$

对于数据集中**从未见过的状态-动作对**：
- Q网络被迫**外推**（而非内插）
- 外推通常不可靠 → 可能给出**虚假的高Q值**
- 策略选择了这些虚假高Q值的动作 → **灾难性决策**

> [!warning] "草地陷阱"比喻
> RL看到马路平坦→奖励高，于是外推认为旁边的草地也平坦→奖励更高。实际上开上草地会翻车。

## 外推误差的传播

```
Q(s, a_OOD) 被高估
       ↓
被用作 TD目标的一部分
       ↓
反向传播到其他状态
       ↓
整个Q函数被污染
```

## 行为克隆（Behavioral Cloning）

最简单的离线数据利用方式 — 纯监督学习：

$$
\pi_\theta = \arg\min_\theta E_{(s,a)\sim D}[-\log\pi_\theta(a|s)]
$$

- 完全不关心"为什么做"或"后果"
- 只在统计上模仿数据中的动作分布

## 离线RL vs 行为克隆

| 维度 | 行为克隆 | 离线RL |
|------|---------|--------|
| 学习信号 | 状态→动作映射 | **奖励信号** |
| 能否超越数据 | 不能（最多等于数据策略） | **能**（利用奖励寻找更优策略） |
| 数据要求 | 需要专家数据 | 可用次优/随机数据 |
| 关键挑战 | 复合误差 | 外推误差 |

> [!important] 核心区别
> 行为克隆只学"怎么做"（模仿），离线RL学"怎么做更好"（优化奖励）。

## 模仿学习与热启动

- BC可作为离线RL的**热启动**（初始化策略）
- 先BC模仿，再用RL fine-tune

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "离线RL和Off-Policy区别" | 离线完全不交互；Off-Policy仍可交互 |
| "外推误差的原因" | Q网络对OOD动作的预测不可靠 |
| "BC和离线RL区别" | BC用监督学习模仿；离线RL用奖励优化 |
| "为什么外推误差会传播" | 高估的Q值被TD目标引用→污染其他状态 |

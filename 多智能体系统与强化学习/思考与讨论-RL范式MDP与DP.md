# 思考与讨论：RL范式、MDP模型与动态规划

---

## Q1：理解强化学习范式和监督学习范式的不同

### 监督学习范式

```
训练数据集 {(x₁,y₁), (x₂,y₂), ...}  →  学习模型 f(x)  →  预测 ŷ = f(x)
```

- **数据**：预先收集的带标签数据集，样本之间独立同分布（i.i.d.）
- **反馈**：即时正确答案（标签）
- **目标**：最小化预测误差（如分类/回归）
- **学习过程**：数据固定，模型被动地从数据中学习映射关系

### 强化学习范式

```
Agent ──action──► Environment ──state, reward──► Agent（循环交互）
```

- **数据**：通过与环境交互**在线产生**，数据分布随策略变化（非 i.i.d.）
- **反馈**：延迟的奖赏信号（不直接告诉"正确动作"是什么）
- **目标**：最大化长期累积奖赏
- **学习过程**：数据动态产生，智能体主动试错探索

### 核心区别对比

| 维度 | 监督学习 | 强化学习 |
|------|---------|---------|
| **数据来源** | 预先收集的静态数据集 | 与环境**交互产生**，动态变化 |
| **数据分布** | 独立同分布（i.i.d.） | **策略依赖**（非 i.i.d.） |
| **反馈信号** | 即时、精确的标签 | **延迟**的奖赏信号 |
| **反馈性质** | 告诉"正确答案是什么" | 只告诉"做得好不好"（评价性） |
| **学习目标** | 最小化预测误差 | 最大化**长期**累积奖赏 |
| **学习方式** | 被动学习（数据固定） | **主动探索**（试错学习） |
| **核心挑战** | 泛化能力 | **探索与利用的折衷** |
| **时序依赖** | 样本间通常无时序关系 | 决策有**长期后果**（当前动作影响未来状态） |

### 为什么数据分布"策略依赖"是本质区别？

- 监督学习中，训练数据的分布与模型无关——无论模型怎么变，数据不变
- 强化学习中，智能体的策略决定了它看到什么数据——策略改变 → 访问的状态分布改变 → 训练数据改变
- 这导致 RL 无法直接套用 SL 的 SGD 假设，需要特殊技巧（如经验回放、重要性采样等）

### 延迟奖赏带来的挑战

在监督学习中，每个样本的"正确答案"是即时可知的；而在 RL 中：
- 一个动作的好坏可能要很久之后才能体现（如下棋的一步影响最终胜负）
- 需要**信度分配**：从最终结果反推每一步的贡献

## Q2：理解离散型 MDP 模型中各个要素

### MDP 的定义

$$\text{MDP} = \langle S, A, \delta, R \rangle$$

### 四大要素详解

#### 1. 状态集合 $S$（State Space）

- 描述环境所有可能的**状态**，$|S| = n$
- 例如：棋盘格局、机器人位置、游戏画面
- 离散型 MDP 中 $S$ 是有限集合

#### 2. 动作集合 $A$（Action Space）

- 智能体在每个状态下可以选择的**动作**，$|A| = k$
- 例如：上下左右移动、出牌选择
- 离散型 MDP 中 $A$ 是有限集合

#### 3. 状态转移概率 $\delta(s, a, s')$（Transition Function）

- $\delta(s, a, s') = P(s_{t+1} = s' | s_t = s, a_t = a)$
- 在状态 $s$ 执行动作 $a$ 后转移到状态 $s'$ 的概率
- 满足：$\sum_{s'} \delta(s, a, s') = 1, \quad \forall s, a$
- 体现了环境的**随机性**（即使相同状态相同动作，结果可能不同）

#### 4. 即时奖赏函数 $R(s, a)$（Reward Function）

- 在状态 $s$ 执行动作 $a$ 获得的即时奖赏
- 定义了"什么是好的行为"——是 RL 唯一的指导信号
- 设计奖赏函数是 RL 应用中的关键问题

### 马尔可夫性质（Markov Property）

$$P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, s_1, a_1, ..., s_t, a_t)$$

**含义**：下一状态**只依赖**于当前状态和动作，与历史无关。"未来只取决于现在，不取决于过去。"

### 其他重要概念

#### 策略（Policy）$\pi$

- **确定性策略**：$a = \pi(s)$，每个状态确定地选一个动作
- **随机性策略**：$\pi(a|s) = P(a|s)$，每个状态按概率分布选动作
- **关键定理**：对任何有限 MDP，必然存在**确定性最优策略**

#### 返回函数（Return）

$$G_t = \sum_{i=0}^{\infty} \gamma^i R(s_{t+i}, a_{t+i})$$

折扣因子 $\gamma \in [0, 1)$：
- 保证无穷级数**收敛**
- $\gamma$ 小 → 短视（关注近期）；$\gamma$ 大 → 远视（关注长期）

#### 值函数（Value Function）

- **状态值函数**：$V^\pi(s) = E[G_t | s_0 = s, \pi]$
- **动作值函数**：$Q^\pi(s,a) = R(s,a) + \gamma\sum_{s'}\delta(s,a,s')V^\pi(s')$
- **最优值函数**：$V^*(s) = \max_\pi V^\pi(s)$

## Q3：掌握动态规划方法

### 动态规划的前提和核心工具

- **前提条件**：MDP 模型**完全已知**（转移概率 $\delta$ 和奖赏 $R$ 已知）
- **核心工具**：Bellman 等式
- **两大任务**：
  - 策略评估（Prediction）：给定策略 $\pi$，求 $V^\pi$
  - 最优控制（Control）：求最优策略 $\pi^*$

### Bellman 等式

$$V^\pi(s) = R(s, \pi(s)) + \gamma\sum_{s'}\delta(s, \pi(s), s')V^\pi(s')$$

- 将值函数分解为"即时奖赏 + 折扣后继值"的递推关系
- 构成 $n$ 个未知数（$n$ 个状态的值）、$n$ 个方程的**线性方程组**
- 可通过矩阵求逆或迭代法求解

### Bellman 最优性等式

$$V^*(s) = \max_a\left\{R(s,a) + \gamma\sum_{s'}\delta(s,a,s')V^*(s')\right\}$$

### 策略评估（迭代法）

给定策略 $\pi$，反复迭代直到收敛：

$$V_{k+1}(s) = R(s, \pi(s)) + \gamma\sum_{s'}\delta(s, \pi(s), s')V_k(s')$$

### 策略改进

利用 Q 函数进行贪心改进：

$$\pi'(s) = \arg\max_a Q^\pi(s,a) = \arg\max_a\left\{R(s,a) + \gamma\sum_{s'}\delta(s,a,s')V^\pi(s')\right\}$$

### 算法一：策略迭代（Policy Iteration）

交替进行评估和改进：

$$\pi_0 \xrightarrow{\text{评估}} V^{\pi_0} \xrightarrow{\text{改进}} \pi_1 \xrightarrow{\text{评估}} V^{\pi_1} \xrightarrow{\text{改进}} \cdots \to \pi^*$$

```
初始化 π 为任意策略
重复：
    [策略评估] 计算 V^π（求解 Bellman 方程组）
    [策略改进] π'(s) = argmax_a {R(s,a) + γΣ δ(s,a,s')V^π(s')}
    如果 π' = π，停止（已收敛）
    否则 π ← π'
```

**收敛保证**：有限 MDP 的策略数有限 → 策略迭代必在有限步内收敛到最优策略。

### 算法二：值迭代（Value Iteration）

直接迭代更新值函数（不显式维护策略）：

$$V_{i+1}(s) \leftarrow \max_a\left\{R(s,a) + \gamma\sum_{s'}\delta(s,a,s')V_i(s')\right\}$$

收敛后提取最优策略：$\pi^*(s) = \arg\max_a Q^*(s,a)$

```
初始化 V(s) = 0，对所有 s
重复：
    对每个状态 s：
        V(s) ← max_a {R(s,a) + γΣ δ(s,a,s')V(s')}
    直到 V 变化量小于阈值
提取策略：π*(s) = argmax_a {R(s,a) + γΣ δ(s,a,s')V(s')}
```

### 策略迭代 vs 值迭代

| 维度 | 策略迭代 | 值迭代 |
|------|---------|--------|
| 每轮操作 | **完整评估**（求解线性方程组）+ 改进 | **一步 max 更新** |
| 收敛速度 | 通常迭代次数**更少** | 每轮计算量**更小** |
| 中间产物 | 完整的 $V^\pi$ | 逐步逼近 $V^*$ |
| 内存需求 | 需要存储策略 | 只需值函数 |
| 适用场景 | 状态空间中等 | 状态空间较大时更实用 |

### ε-贪心策略（探索与利用）

$$\pi(s) = \begin{cases}\arg\max_a Q^\pi(s,a) & \text{概率 } 1-\varepsilon \\ \text{随机动作} & \text{概率 } \varepsilon\end{cases}$$

- 以 $1-\varepsilon$ 的概率利用（选当前最优）
- 以 $\varepsilon$ 的概率探索（随机尝试）
- $\varepsilon$ 通常随训练逐渐衰减

### 动态规划的局限性

| 局限 | 说明 |
|------|------|
| 需要完全模型 | 必须知道 $\delta$ 和 $R$，现实中往往不可得 |
| 状态空间爆炸 | 每步需遍历所有状态，大规模问题不可行 |
| 无法处理连续空间 | 离散枚举不适用连续状态/动作 |

→ 这些局限催生了无模型方法（MC、TD）和函数逼近方法。

## Q1：特征与值函数估计器

### 为什么需要值函数估计器？

表格型方法的局限性：
- 围棋有 $10^{170}$ 种状态 → 无法存储
- 连续状态空间有无穷多状态 → 表格无法枚举
- 未见状态无法泛化

**解决方案**：用参数化函数 $\hat{V}(s,\mathbf{w}) \approx V^\pi(s)$ 逼近真实值函数，其中 $|\mathbf{w}| \ll |S|$。

### 什么是特征（Feature）？

特征是将原始状态映射为特征向量的函数：

$$\mathbf{x}(s) = (x_1(s), x_2(s), ..., x_d(s))^T$$

特征的作用是将高维/连续的状态空间映射到适合学习的低维表示。

### 常见的特征构造方法有哪些？

| 方法 | 公式/描述 | 特点 |
|------|-----------|------|
| 指示函数（值表） | $x_i(s) = \mathbb{1}(s = s_i)$ | 最简单，退化为表格型 |
| 粗编码（Coarse Coding） | 通过感受野对状态聚合（在感受野内=1，否则=0） | 泛化与区分的权衡 |
| 瓦片编码（Tile Coding） | 多层重叠网格划分状态空间 | 稀疏高效，适合在线学习 |
| 傅里叶基 | $x_i(s) = \cos(i\pi s)$ | 基于万能逼近定理 |
| 核函数（RBF） | $x_i(s) = \exp\left(-\frac{\|s-c_i\|^2}{2\sigma_i^2}\right)$ | 局部响应，从低维到高维 |
| 专家手工定义 | 如俄罗斯方块中的空洞数、下落高度等 | 依赖领域知识 |

### 特征设计中泛化与区分的权衡？

以粗编码为例：
- **窄泛化**（小感受野）：弱泛化、强区分 → 精度高但学习慢
- **宽泛化**（大感受野）：强泛化、弱区分 → 学习快但精度低
- **纵横泛化**（不同方向大小不同）：自适应泛化与区分

### 值表可以看作特征的特殊情况？

是的。值表型方法是线性值函数估计的特殊形式：

$$\mathbf{x}_{table}(s) = \begin{pmatrix} \mathbb{1}(s=s_1) \\ \vdots \\ \mathbb{1}(s=s_n) \end{pmatrix}$$

此时 $\hat{V}(s,\mathbf{w}) = \mathbf{x}_{table}(s)^T\mathbf{w}$，每个 $w_i$ 恰好对应一个状态的值。

### 常见的值函数估计器有哪些？

- 特征的线性组合
- 决策树
- 神经网络
- 核函数
- ……

## Q2：强化学习中的值函数估计更新与监督学习中有什么不同

### 监督学习的训练模式是什么？

```
输入 → 监督学习系统 → 输出
训练样本 = {输入, 目标输出}
误差 = (目标输出 − 实际输出)
```

目标输出是**已知的真实标签**，数据是独立同分布的。

### 从监督学习视角看值函数更新？

值表型 TD 更新可以写成监督学习的形式：

$$V(s_t) \leftarrow V(s_t) + \alpha[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)]$$

对应训练样本为：$\{s_t的描述,\; r_{t+1} + \gamma V(s_{t+1})\}$，其中状态描述是输入，TD目标是"目标输出"。

### 关键区别是什么？

| 维度 | 监督学习 | 强化学习值函数估计 |
|------|---------|-------------------|
| **目标值** | 真实标签已知且固定 | 真实值 $V^\pi(s)$ 未知，需用替代目标（$G_t$、$r+\gamma\hat{V}(s')$） |
| **数据分布** | i.i.d.（独立同分布） | **非 i.i.d.**，样本有时序相关性 |
| **目标稳定性** | 目标固定不变 | **非平稳**（目标随参数 $\mathbf{w}$ 变化而变化） |
| **偏差问题** | 无偏（标签正确） | TD目标有偏（用估计更新估计=Bootstrap） |
| **梯度** | 真正的梯度下降 | **半梯度**（TD目标依赖 $\mathbf{w}$ 但被当常数） |
| **训练数据来源** | 预先收集的数据集 | 在线交互产生，策略改变则分布改变 |

### 这些区别带来什么后果？

1. **非平稳目标**：TD 方法中的目标 $r + \gamma\hat{V}(s',\mathbf{w})$ 本身会随着 $\mathbf{w}$ 的更新而变化，形成"追逐移动目标"的问题
2. **非 i.i.d. 数据**：连续采样的状态强相关，违反 SGD 的基本假设 → 需要经验回放等技巧
3. **半梯度问题**：TD 更新不是真正的梯度下降（目标依赖参数但被当常数），收敛性不如真正梯度方法有保证
4. **致命三要素（Deadly Triad）**：函数逼近 + 自举（Bootstrap）+ 离策略 → 同时满足可能发散

### 存在两个逼近过程？

课件强调了值函数估计存在**两层逼近**：
1. **RL 逼近**：用替代目标（MC回报/TD目标）代替未知的真实值函数
2. **FA 逼近**：用参数化函数逼近目标值函数，泛化到整个状态空间

这是与监督学习的本质区别——监督学习只有第二层。

## Q3：写出利用线性值函数的强化学习算法

### 线性值函数的基本形式

$$\hat{V}(s,\mathbf{w}) = \mathbf{w}^T\mathbf{x}(s) = \sum_{i=1}^n w_i x_i(s)$$

梯度极其简单：$\nabla_\mathbf{w}\hat{V}(s,\mathbf{w}) = \mathbf{x}(s)$

对于状态-动作值函数：

$$\hat{Q}(s,a,\mathbf{w}) = \mathbf{w}^T\mathbf{x}(s,a) = \sum_{i=1}^n w_i x_i(s,a)$$

### 算法1：线性MC策略评估

```
输入：策略π，特征函数x(s)，步长α
初始化：w = 0
对每个 episode:
    生成轨迹 s₀, a₀, r₁, s₁, a₁, r₂, ..., sT
    对 t = 0, 1, ..., T-1:
        G_t ← r_{t+1} + γr_{t+2} + ... + γ^{T-t-1}r_T    // 计算回报
        w ← w + α(G_t - w^T x(s_t)) x(s_t)               // 更新参数
```

### 算法2：线性TD(0)策略评估

```
输入：策略π，特征函数x(s)，步长α
初始化：w = 0
对每个 episode:
    初始化 s
    对每一步:
        选择动作 a = π(s)
        执行 a → 观察 r, s'
        δ ← r + γ w^T x(s') - w^T x(s)        // TD误差
        w ← w + α δ x(s)                       // 半梯度更新
        s ← s'
```

### 算法3：线性TD(λ)策略评估（后向视角）

```
输入：策略π，特征函数x(s)，步长α，参数λ
初始化：w = 0
对每个 episode:
    初始化 s，E = 0（资格迹向量）
    对每一步:
        选择动作 a = π(s)
        执行 a → 观察 r, s'
        δ ← r + γ w^T x(s') - w^T x(s)        // TD误差
        E ← γλE + x(s)                         // 更新资格迹
        w ← w + α δ E                          // 按资格迹加权更新
        s ← s'
```

### 算法4：线性SARSA（On-Policy控制）

```
输入：特征函数x(s,a)，步长α，探索率ε
初始化：w = 0
对每个 episode:
    初始化 s，用ε-贪心选择 a
    对每一步:
        执行 a → 观察 r, s'
        用ε-贪心根据Q选择 a'
        δ ← r + γ w^T x(s',a') - w^T x(s,a)   // TD误差
        w ← w + α δ x(s,a)                     // 更新参数
        s ← s', a ← a'
```

### 算法5：线性Q-Learning（Off-Policy控制）

```
输入：特征函数x(s,a)，步长α，探索率ε
初始化：w = 0
对每个 episode:
    初始化 s
    对每一步:
        用ε-贪心根据Q选择 a
        执行 a → 观察 r, s'
        a* ← argmax_a' w^T x(s',a')             // 贪心动作
        δ ← r + γ w^T x(s',a*) - w^T x(s,a)    // TD误差（用max）
        w ← w + α δ x(s,a)                      // 更新参数
        s ← s'
```

### 收敛性总结

| On/Off-Policy | 算法 | 值表 | 线性 | 非线性 |
|------|------|------|------|------|
| On-Policy | MC | ✓ | ✓ | ✓ |
| On-Policy | TD(0) | ✓ | ✓ | ✗ |
| On-Policy | TD(λ) | ✓ | ✓ | ✗ |
| Off-Policy | MC | ✓ | ✓ | ✓ |
| Off-Policy | TD(0) | ✓ | ✗ | ✗ |
| Off-Policy | TD(λ) | ✓ | ✗ | ✗ |

线性TD的误差界（TD不动点）：

$$\|\hat{V}_{TD} - V^\pi\| \leq \frac{1}{\sqrt{1-\gamma}}\min_\mathbf{w}\|\hat{V}_\mathbf{w} - V^\pi\|$$

即线性 TD 收敛到的解最多比最优线性逼近差 $\frac{1}{\sqrt{1-\gamma}}$ 倍。

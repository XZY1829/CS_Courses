# 思考与讨论：基于模型的强化学习

---

## Q1：理解基于模型/无模型强化学习算法区别

### 无模型强化学习（Model-free RL）

- 无需事先知道模型
- 从经验中**直接**学习值函数/策略函数
- 代表算法：Q-Learning、DQN、PPO、A3C

### 基于模型强化学习（Model-based RL）

- 从经验中**学习一个环境模型**
- 从模型中**规划**一个值函数/策略函数
- 代表算法：Dyna-Q、MBPO、MPC

### 学习什么样的模型？

环境模型由两个组件构成：
- **状态动态模型**：$\hat{P}(s'|s,a)$（预测下一状态）
- **奖励模型**：$\hat{R}(s,a)$（预测即时奖励）

```
真实环境                 环境模型
状态动态 P(s'|s,a)      状态动态 P̂(s'|s,a)
奖励函数 R(s,a)         奖励函数 R̂(s,a)
        ↕ 从真实到虚拟 ↕
```

### 核心区别对比

| 维度 | 无模型（Model-free） | 基于模型（Model-based） |
|------|---------------------|------------------------|
| 学什么 | 直接学值函数/策略 | 先学模型，再从模型中规划 |
| 样本效率 | **低**（依赖大量试错） | **高**（模型可反复利用） |
| 模型需求 | 不需要 | 需要学习或给定 |
| 长期规划 | 不支持多步预测 | 支持长期规划 |
| 主要风险 | — | **模型误差**可能累积影响决策 |
| 适用场景 | 交互廉价（模拟器） | 交互昂贵（机器人、自动驾驶、医疗） |

### MBRL 的优势总结（PPT slide 26）

无模型强化学习的问题：
- 数据样本效率非常低
- 依赖试错学习
- 不支持多步预测和长期规划

基于模型的强化学习优势：
- **样本效率高**（模型可多次采样）
- **支持长期规划**（通过模型模拟未来）
- 但可能会引入**模型误差**

### 两种经验来源

| 经验类型 | 来源 | 特点 |
|---------|------|------|
| 真实经验 | 从真实环境/MDP 中采样 | 无误差，但获取成本高 |
| 模拟经验 | 从学到的模型/近似MDP 中采样 | 成本低，但可能有模型误差 |

### Dyna 框架：经验集成

Dyna 框架将真实经验和模拟经验统一使用：

```
┌──────────────────────────────┐
│  真实经验 → 直接RL（Model-free部分）  │
│  真实经验 → 模型学习                  │
│  模拟经验 → 规划（Model-based部分）   │
└──────────────────────────────┘
```

**Dyna-Q 算法**结合三个组件：
1. **直接 RL**：用真实经验直接更新 Q 值
2. **模型学习**：用真实经验学习环境模型
3. **规划**：从模型中采样模拟经验，再次更新 Q 值（重复 N 次）

## Q2：理解 MBPO 算法

### MBPO（Model-Based Policy Optimization）

MBPO 是基于模型的**策略优化**算法，包含三个阶段：

#### 阶段一：模型学习

- 从真实环境交互收集的数据中，学习一个动态模型 $\hat{f}(s,a) \approx s'$
- 使用监督学习方法（如神经网络），最小化预测误差

#### 阶段二：模型展开（Rollout）

- 从**真实状态**出发，用学到的模型生成**短轨迹**
- 关键：只做短步展开（如 1-5 步），避免长期模型误差累积

#### 阶段三：策略优化

- 使用模拟生成的数据计算策略梯度
- 用无模型的策略优化方法（如 SAC）更新策略

### MBPO 的设计动机

从算法 1 到算法 4 的演进过程揭示了 MBPO 的设计逻辑：

| 算法 | 思路 | 问题 |
|------|------|------|
| 算法1 | 学模型 → 规划动作序列 | 模型误差沿轨迹指数级累积 |
| 算法2 | 迭代收集新数据+重新学模型 | 先规划完所有动作再执行，后面动作误差大 |
| 算法3（MPC） | 优化轨迹但只执行第一步，重新规划 | 每步都需在线优化，计算开销大 |
| 算法4 | 模型+策略联合学习，反向传播 | 需要可微模型 |
| **MBPO** | 短视野展开 + 策略梯度优化 | 兼顾样本效率和鲁棒性 |

### MBPO 为什么有效？

1. **短视野展开**：限制模型展开步数，控制累积误差上界
2. **策略优化**：结合无模型方法的渐近性能优势
3. **真实状态起点**：从真实观测状态开始展开，减少分布偏移

## Q3：可以通过哪些方式构建模型？

根据 PPT 内容，构建环境模型的方式包括：

### 方式一：查找表模型（Tabular Model）

- 统计转移频率和平均奖励
- $\hat{P}(s'|s,a) = \frac{\text{count}(s,a,s')}{\text{count}(s,a)}$
- $\hat{R}(s,a) = \text{mean}(r | s, a)$
- 适用于小规模离散状态空间

### 方式二：参数化模型（监督学习）

- 使用神经网络拟合动态函数 $\hat{f}_\phi(s,a) \approx s'$
- 以监督学习方式训练，最小化最小二乘误差：

$$\min_\phi \sum_i \|\hat{f}_\phi(s_i, a_i) - s'_i\|^2$$

- 训练数据来自真实环境交互收集的 $(s, a, s')$ 三元组
- 适用于连续状态/动作空间

### 方式三：概率模型/集成模型

- 不仅预测下一状态的均值，还预测**不确定性**
- 模型集成（Ensemble）：训练多个模型取平均/方差
- 可以量化模型预测的置信度，辅助决策

### 方式四：与最优控制结合的系统动力学模型

- 控制理论使用系统动力学方程 $s_{t+1} = f(s_t, a_t)$ 描述状态迁移
- 将状态转移方程作为**优化问题的约束条件**
- 适用于已知物理规律的系统（如机器人运动学）

### 模型使用方式总结

| 模型使用方式 | 方法 | 说明 |
|-------------|------|------|
| 基于模型的值优化 | Dyna-Q | 用模型生成模拟经验 → 更新值函数 |
| 轨迹优化 | MPC | 用模型预测 → 优化动作序列 → 只执行第一步 |
| 基于模型的策略优化 | MBPO | 用模型短步展开 → 策略梯度更新 |
| 反向传播到策略 | 算法4 | 通过可微模型直接反传梯度到策略网络 |

### 模型不准确问题与应对

| 问题 | 应对方法 |
|------|---------|
| 误差沿轨迹累积 | 限制规划视野（短步展开） |
| 早期数据不足 | 迭代收集数据+重新训练模型 |
| 后续动作误差大 | MPC：只执行第一步，重新规划 |
| 单模型过拟合 | 模型集成（Ensemble） |

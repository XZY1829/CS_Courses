# 思考与讨论：策略梯度

---

## Q1：基于值和基于策略算法的区别是什么？

### 三大类方法概览

| 类别 | 学习对象 | 代表算法 |
|------|---------|---------|
| 基于值（Value-Based） | 学习值函数，用值函数生成策略（如ε-贪心） | Q-Learning, DQN |
| 基于策略（Policy-Based） | 直接学习策略，没有值函数 | REINFORCE |
| 演员-评论家（Actor-Critic） | 同时学习值函数和策略 | QAC, A2C, PPO |

### 基于值的方法

- 学习 $Q(s,a)$ 或 $V(s)$
- 策略通过值函数间接导出：$\pi(s) = \arg\max_a Q(s,a)$（或 ε-贪心）
- 天然产生**确定性策略**

### 基于策略的方法

- 直接参数化策略 $\pi_\theta(a|s)$
- 通过梯度上升优化策略参数 $\theta$
- 天然支持**随机策略**

### 关键区别对比

| 维度 | 基于值 | 基于策略 |
|------|--------|---------|
| 动作空间 | 主要适合离散动作（连续空间中 $\arg\max$ 困难） | **天然支持连续动作** |
| 策略类型 | 确定性策略 | **可学随机策略** |
| 策略变化 | 值函数微小变化 → 策略可能剧烈变化（不连续） | 策略变化**平滑**连续 |
| 收敛性 | 可能振荡或不收敛（非线性逼近） | **更好的收敛性**（梯度上升有保证） |
| 最优性 | 能找全局最优（如Q-Learning收敛到 $Q^*$） | 容易收敛到**局部最优** |
| 方差 | 方差较小 | **方差大**（采样估计梯度） |
| 效率 | 通常更高效（样本利用率高） | 策略评估效率较低 |

### 经典案例：重名格子世界（Aliased Gridworld）

两个灰色状态无法区分（特征相同）：

- **基于值的方法**：学习到确定性策略 $a = \arg\max_a Q(\text{灰色}, a) = \text{向左}$，ε-贪心策略在走廊上徘徊很长时间，永远找不到钻石
- **基于策略的方法**：学习到随机策略 $\pi(\text{灰色}, \text{向左}) = \pi(\text{灰色}, \text{向右}) = 0.5$，以较高概率通过少量步数找到钻石

**结论**：在状态别名（部分可观测）场景下，随机策略优于确定性策略。

## Q2：方差和偏差的含义和区别是什么？

### 偏差（Bias）的含义

偏差是估计值的**期望**与**真实值**之间的差距：

$$\text{Bias} = E[\hat{\theta}] - \theta^*$$

在策略梯度中，偏差表现为：**存在一个期望非零的梯度分量**，使得即使接近最优点，梯度也不为零，导致无法收敛到正确的解。

- 当用 Critic 估计的 $Q_w(s,a)$ 代替真实 $Q^\pi(s,a)$ 时，若 $Q_w$ 有估计误差，则引入偏差
- 偏差导致：最终解可能偏离真实最优策略

### 方差（Variance）的含义

方差是估计值在不同采样下的**波动程度**：

$$\text{Variance} = E[(\hat{\theta} - E[\hat{\theta}])^2]$$

在策略梯度中，方差表现为：**样本奖励波动使得实际更新后的策略分布差异过大**，导致学习不稳定。

- REINFORCE 使用 MC 返回 $G_t$，整条轨迹的随机性累积导致高方差
- 方差导致：学习过程振荡大、收敛慢

### 直观理解

以策略梯度更新 $\nabla_\theta J = \nabla_\theta \log\pi_\theta(a|s) \cdot \Psi_t$ 为例：

- **方差问题**：$\Psi_t$ 的绝对值（回报）使得梯度差别过大。例如使用 $Q$ 值时，所有回报都为正，好坏动作只是大小区别，更新方向差异过大
- **偏差问题**：$\Psi_t$ 的期望 $E[\nabla\log\pi \cdot b(s,a)]$ 不为零，接近最优点时梯度不消失，无法正确收敛

### 方差与偏差的权衡

| $\Psi_t$ 的选择 | 算法 | 偏差 | 方差 |
|-----------------|------|------|------|
| $G_t$（MC返回） | REINFORCE | **无偏** | **高** |
| $G_t - b(s)$（带基线） | REINFORCE+Baseline | **无偏** | 较低 |
| $Q_w(s,a)$ | Q Actor-Critic | 有偏 | 中 |
| $A_w(s,a) = Q_w - V_w$ | Advantage AC | 有偏 | 较低 |
| $\delta_t = r + \gamma V_w(s') - V_w(s)$ | TD Actor-Critic | 有偏 | **最低** |

```
高方差、无偏 ◄─────────────────────► 低方差、有偏
    MC返回 G_t        ←→        TD误差 δ_t
```

### 降低方差的手段

1. **减去基线 $b(s)$**：当 $b(s)$ 仅依赖状态时，不改变梯度期望（不引入偏差），但显著降低方差。常用 $b(s) = V^\pi(s)$
2. **使用 Critic**：用值函数估计代替 MC 采样（引入偏差但大幅降方差）
3. **优势函数**：$A(s,a) = Q(s,a) - V(s)$，将绝对值变为相对值

### 为什么基线不引入偏差？

$$E_{\pi_\theta}[b(s)\nabla_\theta\log\pi_\theta(a|s)] = b(s)\nabla_\theta\sum_a\pi_\theta(a|s) = b(s)\nabla_\theta 1 = 0$$

任何只依赖状态的函数 $b(s)$ 作为基线，其贡献的梯度期望为零。

## Q3：AC方法和REINFORCE算法的区别是什么？

### REINFORCE 算法

- 使用**蒙特卡罗返回** $G_t$ 作为 $Q^\pi(s,a)$ 的无偏估计
- 更新公式：$\theta \leftarrow \theta + \alpha\gamma^t G_t\nabla_\theta\log\pi_\theta(a_t|s_t)$
- **没有 Critic**，纯策略方法

```
初始化策略参数 θ
对每个 episode:
    用 π_θ 采样轨迹 {s₁,a₁,r₁, s₂,a₂,r₂, ..., sT,aT,rT}
    计算每个时刻的回报 G_t = Σ γ^(t'-t) r_{t'}
    更新 θ = θ + α Σ_t γ^t G_t ∇_θ log π_θ(a_t|s_t)
```

### Actor-Critic（QAC）算法

- **Critic** 使用 TD 更新状态-动作值函数参数 $w$
- **Actor** 根据 Critic 的值估计来计算策略梯度更新策略参数 $\theta$

```
初始化 Actor参数θ, Critic参数w
对每个 episode:
    用 π_θ 采样轨迹 {s₁,a₁,r₁, s₂,a₂,r₂, ...}
    对每步计算 δ_t = r_t + γQ_w(s_{t+1},a_{t+1}) - Q_w(s_t,a_t)
    更新 Actor: θ = θ + β Σ_t ∇_θ log π_θ(a_t|s_t) · Q_w(s_t,a_t)
    更新 Critic: w = w + α Σ_t δ_t ∇_w Q_w(s_t,a_t)
```

### 核心区别对比

| 特性 | REINFORCE | Actor-Critic |
|------|----------|--------------|
| 是否有 Critic | **无**（纯策略方法） | **有**（值函数网络） |
| 梯度估计用什么 | MC 返回 $G_t$ | Critic 估计的 $Q_w(s,a)$ 或 $\delta_t$ |
| 偏差 | **无偏**（$G_t$ 是 $Q^\pi$ 的无偏估计） | **有偏**（Critic 估计存在误差） |
| 方差 | **高**（整条轨迹随机性累积） | **低**（Critic 提供稳定评估信号） |
| 更新时机 | 必须等 **episode 结束** | **每步可更新**（在线学习） |
| Bootstrap | 否 | 是（TD 更新 Critic） |
| 适用任务 | 仅限有终止的回合任务 | **也适用连续任务** |
| 收敛速度 | 慢（高方差振荡） | 快（低方差稳定） |

### 进一步：Advantage Actor-Critic（A2C）

在 QAC 基础上使用优势函数 $A(s,a)$，进一步降低方差：

- Actor 更新：$\theta \leftarrow \theta + \beta\nabla_\theta\log\pi_\theta(a_t|s_t) \cdot \delta_t$
- Critic 更新：$w \leftarrow w + \alpha\delta_t\nabla_w V_w(s_t)$
- 其中 $\delta_t = r_t + \gamma V_w(s_{t+1}) - V_w(s_t)$ 作为优势函数的近似

**关键优势**：只需一个 $V$ 网络（不需要同时估计 $Q$ 和 $V$），因为 $A \approx \delta_t$。

### 策略梯度算法总结

$$\nabla_\theta J(\theta) = E_{\pi_\theta}[\nabla_\theta\log\pi_\theta(a|s) \cdot \Psi_t]$$

| $\Psi_t$ | 对应算法 |
|-----------|---------|
| $G_t$ | REINFORCE |
| $Q^\pi(s,a)$ | Q Actor-Critic |
| $A^\pi(s,a) = Q^\pi - V^\pi$ | Advantage Actor-Critic |
| $\delta_t = r + \gamma V(s') - V(s)$ | TD Actor-Critic |
| $G_t^\lambda - V(s)$ | TD(λ) Actor-Critic |
| $\nabla_a Q(s,a)|_{a=\mu(s)} \cdot \nabla_\theta\mu(s,\theta)$ | 确定性策略梯度（DPG） |

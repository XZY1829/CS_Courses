## 什么是操作系统

操作系统是软件和硬件之间的中间层，核心职责：

- **隐藏**复杂底层硬件细节
- **提供**更简单的编程概念（如进程、文件）
- **管理**CPU、内存、磁盘等资源（正确性 + 高效性）
- 通过**系统调用**（system call）向用户程序暴露接口

## 三大核心

### 虚拟化（Virtualization）
将**物理资源**（CPU、内存、磁盘）转换为更通用、更强大的**虚拟形式**。

- **CPU 虚拟化**：时分共享 → 多个进程看似同时运行
- **内存虚拟化**：每个进程拥有独立的虚拟地址空间

### 并发（Concurrency）
处理多线程程序中的数据一致性和同步问题。

- 共享数据 + 非原子操作 → **竞态条件**
- 解决方案：锁、信号量、条件变量

### 持久化（Persistence）
在断电后仍保存数据（DRAM 是易失性的）。

- 硬件：硬盘、SSD
- 软件：**文件系统**管理磁盘
- 关键技术：日志（journaling）、写时复制（copy-on-write）

## 设计目标

| 目标 | 说明 |
|------|------|
| **抽象** | 让系统方便易用 |
| **高性能** | 最小化 OS 开销（时间 + 空间） |
| **保护/隔离** | 防止程序间相互干扰 |
| **可靠性** | OS 不间断运行 |
| 其他 | 能源效率、安全性、移动性 |

## OS 历史简述

```
真空管(1945-55) → 晶体管/批处理(1955-65) → 集成电路/多道程序(1965-80) → 个人电脑/移动(1980-至今)
```

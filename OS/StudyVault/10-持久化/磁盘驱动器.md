# 磁盘驱动器（★★）

#persistence #disk

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 接口 | 扇区（sector）数组，通常 512 字节/扇区 |
| 组件 | 盘片(Platter)、主轴(Spindle)、磁道(Track)、扇区(Sector)、磁头 |
| I/O 耗时 | 寻道时间 + 旋转延迟 + 数据传输时间 |
| 核心差距 | 顺序吞吐量 >> 随机吞吐量（可差 100 倍+） |

## 磁盘组件

```
盘片 → 多个表面 → 每个表面有多个同心磁道 → 磁道上划分扇区
     → 多个盘面相同半径的磁道组成柱面
磁头安装在可移动臂上，能访问每个表面
```

## I/O 耗时三部分

| 部分 | 含义 |
|------|------|
| **寻道时间** | 磁头移动到目标磁道 |
| **旋转延迟** | 等待目标扇区旋转到磁头下方 |
| **传输时间** | 实际读写数据 |

**总耗时 = 寻道 + 旋转 + 传输**

## 磁盘调度

| 策略 | 做法 | 特点 |
|------|------|------|
| **FCFS** | 按请求到达顺序 | 简单但性能差 |
| **SSTF** | 选择离当前磁头**最近**的请求 | 性能好但可能**饥饿** |
| **SCAN（电梯）** | 磁头单方向扫描，到头后反向 | 解决饥饿 |
| **SPTF** | 选择定位时间（寻道+旋转）最短的 | 最优但需知旋转位置 |

---

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "随机 vs 顺序差异" | 随机读写受寻道+旋转影响巨大，吞吐量低 100 倍+ |
| "SSTF 的问题" | 可能**饥饿**远处的请求 |
| "SCAN 如何解决饥饿" | 磁头**单向扫描到底再反向**，所有位置终会被服务 |

# 文件系统（★★★）

#persistence #file-system

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 两大抽象 | **文件**（字节数组+元数据）+ **目录**（名称→inode 映射） |
| 三种命名 | inode 编号、路径名、文件描述符 |
| 布局 | 超级块 + inode位图 + 数据位图 + inode表 + 数据区 |

## 抽象1：文件

| 属性 | 说明 |
|------|------|
| 文件数据 | 字节序列 |
| 元数据(inode) | 大小、所有者、权限、时间、数据块位置 |
| inode 编号 | 文件系统内部唯一标识 |

### 文件描述符（FD）
- 进程级别的整数编号 → 指向系统打开文件表项
- 避免每次读写都路径解析+权限检查
- 默认：0=stdin, 1=stdout, 2=stderr

### 打开文件表

```
进程FD表 → 系统打开文件表（offset, 模式, inode指针, 引用计数）→ inode表
```

| 场景 | 行为 |
|------|------|
| `open()` | 不同进程打开同一文件 → 不同系统表项，**独立 offset** |
| `fork()` | 父子进程**共享**同一系统表项，**共享 offset** |
| `dup()` | 同一进程复制 FD → **共享**同一系统表项 |

### 文件系统接口

| API | 功能 |
|-----|------|
| `open()` | 打开/创建文件，返回 FD |
| `read(fd, buf, n)` | 读取 n 字节，推进 offset |
| `write(fd, buf, n)` | 写入 n 字节，推进 offset |
| `close(fd)` | 关闭 FD |
| `lseek(fd, offset, whence)` | 移动文件指针 |
| `fsync(fd)` | 强制刷盘，防止数据丢失 |

## 抽象2：目录

- 特殊文件，存储 `<文件名, inode编号>` 对
- 根目录 inode 通常为 **2**
- 路径解析：从根目录逐级查找

### 链接

| 类型 | 硬链接 | 符号链接 |
|------|--------|----------|
| 创建 | `ln a.txt b.txt` | `ln -s a.txt b.txt` |
| 原理 | 新名称指向**同一 inode** | 新文件存储**目标路径字符串** |
| 跨文件系统 | ❌ | ✅ |
| 链接目录 | ❌（避免环） | ✅ |
| 删除原文件 | 引用计数-1，不影响 | **悬空引用** |

## 文件系统布局

```
| 超级块S | inode位图 | 数据位图 | inode表 | 数据区 |
```

| 组件 | 功能 |
|------|------|
| **超级块** | 文件系统类型、inode/数据块数量、inode 表起始地址 |
| **位图** | 标记 inode 和数据块的使用/空闲状态 |
| **inode表** | 存储所有文件的元信息 |
| **数据区** | 存储实际文件数据 |

### inode 定位
`磁盘地址 = inode编号 × inode大小 + inode表起始地址`

## 文件组织方式

| 方式 | 思想 | 优点 | 缺点 |
|------|------|------|------|
| **连续分配** | 文件占连续数据块 | 顺序读写快 | 外部碎片、需预知大小 |
| **链表分配** | 每块存下一块指针 | 无外部碎片 | 随机访问慢、指针占空间 |
| **FAT** | 指针集中在文件分配表 | 随机访问快（缓存FAT） | FAT本身可能很大 |
| **索引分配** | 索引块记录数据块号 | 随机访问快 | 索引块大小选择难 |
| **多级索引** | 直接+间接+二级+三级指针 | 小文件快、大文件也支持 | 实现复杂 |

### 多级索引容量
- 12 个直接指针 → 12 × 4KB = **48KB**
- 1 个一级间接 → 1024 × 4KB = **4MB**
- 1 个二级间接 → 1024² × 4KB = **4GB**
- 1 个三级间接 → 1024³ × 4KB = **4TB**

## 空闲空间管理

| 方式 | 特点 |
|------|------|
| **位图** | 每个块 1 bit，易找连续空间 |
| **空闲列表** | 链表，不浪费空间但分配效率低 |

## 性能优化

| 技术 | 方法 |
|------|------|
| **缓存** | 将频繁访问数据放内存（inode、FAT等） |
| **写缓冲** | 延迟写回（write-back）提高性能，风险是崩溃丢数据 |
| **FFS** | 磁盘分 block groups，相关数据放同一组 |
| **预取** | 顺序访问时提前读取后续块 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "inode 存储什么" | 元数据：大小、权限、时间、**数据块位置** |
| "open vs fork 共享区别" | open→独立offset；fork→**共享**offset（同一系统表项） |
| "硬链接 vs 符号链接" | 硬链接=同一inode（不能跨FS/链目录）；符号链接=存路径 |
| "多级索引最大文件" | 12直接+间接+二间接+三间接 ≈ **4TB**（4KB页面） |
| "FAT 的问题" | 1TB磁盘+4KB块 → FAT 表约 **1GB** |
| "FFS 核心思想" | 相关文件/目录放在**同一 block group** 减少寻道 |

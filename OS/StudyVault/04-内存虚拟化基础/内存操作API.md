# 内存操作 API（★★★）

#virtualization #memory

## 概览表（一目了然）

| API | 功能 | 返回值 |
|-----|------|--------|
| `malloc(size)` | 在堆上分配 size 字节 | 成功→void* 指针；失败→NULL |
| `free(ptr)` | 释放 malloc 分配的内存 | 无 |
| `calloc(num, size)` | 分配并**清零** | 同 malloc |
| `realloc(ptr, size)` | 改变已分配块大小 | 可能返回新地址 |

## 栈 vs 堆

| 特性 | 栈（Stack） | 堆（Heap） |
|------|-------------|-----------|
| 管理方式 | **隐式**（编译器PUSH/POP） | **显式**（malloc/free） |
| 生命周期 | 短（函数返回即销毁） | 长（需手动释放） |
| 存储内容 | 函数参数、局部变量、返回地址 | 动态分配的数据结构 |

## 七种常见内存错误

| # | 错误 | 后果 | 示例 |
|---|------|------|------|
| 1 | **忘记分配** | 段错误 | 直接对未分配指针 strcpy |
| 2 | **分配不足** | 缓冲区溢出 | malloc(strlen(s)) 少了 +1 |
| 3 | **忘记初始化** | 未定义读取 | 读取 malloc 后未赋值的内存 |
| 4 | **内存泄漏** | 内存耗尽 | 忘记 free |
| 5 | **悬空指针** | 未定义行为 | free 后继续使用指针 |
| 6 | **双重释放** | 崩溃 | free(p) 两次 |
| 7 | **无效释放** | 崩溃 | free 栈变量地址 |

> [!tip] sizeof() 注意事项
> - `sizeof(指针)` = 4字节(32位) 或 8字节(64位)
> - `sizeof(数组)` = 数组总大小
> - 字符串分配：`malloc(strlen(s) + 1)` → 别忘 `\0`

## 内存检测工具

- **valgrind**：`valgrind --leak-check=full ./program`
- 可检测：内存泄漏、无效访问、未初始化使用

## 底层系统调用

| 调用 | 说明 |
|------|------|
| `brk()`/`sbrk()` | 改变堆的 break 位置（早期方式，不应直接使用） |
| `mmap()` | 创建匿名内存区域（现代 malloc 实现常用） |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "malloc vs calloc" | calloc 分配后**自动清零**，malloc 不会 |
| "free 不需要 size 参数" | 因为 allocator 在**头部块**中记录了大小 |
| "悬空指针" | free 后指针仍指向已释放内存 → 使用它是未定义行为 |
| "如何检测内存泄漏" | 使用 **valgrind** 工具 |

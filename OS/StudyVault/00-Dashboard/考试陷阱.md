# 考试陷阱与易错点

#exam-traps #operating-system

> 汇集各章节最容易出错的考试陷阱。每条包含"陷阱描述 → 正确理解"。

---

## 绪论与进程

### 陷阱 1：系统调用 ≠ 函数调用
- **错误认知**：系统调用和普通函数调用一样。
- **正确理解**：系统调用涉及**用户态→内核态**切换（trap 指令），开销远大于函数调用。
- 相关笔记：[[操作系统概述]] [[受限直接执行]]

### 陷阱 2：fork() 返回值
- **错误认知**：fork 只返回一次。
- **正确理解**：fork 返回**两次**——父进程收到子进程 PID，子进程收到 **0**。
- 相关笔记：[[进程API]]

### 陷阱 3：wait() 和 exec() 的顺序
- **错误认知**：exec 返回后继续执行原程序。
- **正确理解**：exec **不返回**（除非失败），它用新程序替换当前地址空间。wait 在父进程中调用来等待子进程结束。
- 相关笔记：[[进程API]]

## CPU 调度

### 陷阱 4：SJF ≠ STCF
- **错误认知**：SJF 和 STCF 一样。
- **正确理解**：SJF 是**非抢占**的（进程开始就一直运行）；STCF 是**抢占**的（新来短作业可以抢占当前长作业）。
- 相关笔记：[[基础调度策略]]

### 陷阱 5：RR 的周转时间 vs 响应时间
- **错误认知**：RR 在所有指标上都好。
- **正确理解**：RR 的**响应时间**好但**周转时间**很差（所有作业几乎同时完成）。
- 相关笔记：[[基础调度策略]]

### 陷阱 6：MLFQ 规则 4 的"累计"
- **错误认知**：只要在时间片快结束时放弃 CPU 就不会降级。
- **正确理解**：改进后的 MLFQ 按**累计使用时间**计算，无论分多少次用完时间片，累计耗尽即降级。
- 相关笔记：[[MLFQ与比例份额调度]]

## 内存虚拟化

### 陷阱 7：虚拟地址 ≠ 物理地址
- **错误认知**：程序中看到的地址就是物理地址。
- **正确理解**：程序看到的全是**虚拟地址**，由 MMU 硬件翻译。物理地址 = base + 虚拟地址（基址方案）或查页表。
- 相关笔记：[[地址转换与动态重定位]]

### 陷阱 8：页表大小计算
- **错误认知**：页表大小 = 页面数。
- **正确理解**：页表大小 = 2^(地址位数 - 页偏移位数) × 每个 PTE 的大小。32位地址+4KB页+4B PTE = 4MB/进程。
- 相关笔记：[[分页基础]]

### 陷阱 9：多级页表地址解析
- **错误认知**：多级页表只查一次。
- **正确理解**：**每一级**都需要一次内存访问。两级页表：查页目录(1次) → 查页表页(1次) → 访问数据(1次) = 3次内存访问。
- 相关笔记：[[较小的页表]]

### 陷阱 10：TLB Miss ≠ Page Fault
- **错误认知**：TLB Miss 和缺页一样。
- **正确理解**：TLB Miss 只是缓存未命中 → 查页表即可。**Page Fault** 是页面不在物理内存中 → 需要从磁盘加载。
- 相关笔记：[[TLB快速地址转换]] [[超越物理内存]]

### 陷阱 11：栈段地址转换的方向
- **错误认知**：所有段的偏移都是正的。
- **正确理解**：栈向低地址增长 → 偏移量为**负数** → 物理地址 = base - |offset|。
- 相关笔记：[[分段]]

## 并发

### 陷阱 12：while vs if 等待条件变量
- **错误认知**：`if(condition)` 检查一次即可。
- **正确理解**：必须用 **while** 循环。Mesa 语义下 signal 后条件可能已被其他线程改变；还有虚假唤醒。
- 相关笔记：[[条件变量]]

### 陷阱 13：生产者-消费者只用一个 CV
- **错误认知**：一个条件变量够用。
- **正确理解**：一个CV会导致消费者唤醒消费者 → 全部休眠 → **死锁**。必须用**两个CV**。
- 相关笔记：[[条件变量]]

### 陷阱 14：信号量初值的含义
- **错误认知**：信号量初值随便设。
- **正确理解**：初值=1→互斥锁；初值=0→排序/同步；初值=N→允许N个并发访问（如N个缓冲区槽位）。
- 相关笔记：[[信号量]]

### 陷阱 15：死锁四条件"缺一不可"
- **错误认知**：满足任一条件就会死锁。
- **正确理解**：四个条件必须**同时满足**才会死锁。只需破坏其中一个即可预防。
- 相关笔记：[[常见并发问题]]

### 陷阱 16：自旋锁在单处理器上的问题
- **错误认知**：自旋锁在任何场景都可以用。
- **正确理解**：单处理器上，持有锁的线程被抢占 → 等待线程自旋整个时间片 → 极度浪费。自旋锁适合**多处理器+短临界区**。
- 相关笔记：[[锁]]

## 持久化

### 陷阱 17：inode 不包含文件名
- **错误认知**：文件名存在 inode 中。
- **正确理解**：文件名存在**目录**的数据块中（目录项 = 文件名 + inode 号）。inode 只有元数据 + 数据块指针。
- 相关笔记：[[文件系统]]

### 陷阱 18：创建文件的 I/O 次数
- **错误认知**：创建文件只写一次磁盘。
- **正确理解**：至少 5 次 I/O（读写 inode 位图、写 inode、读写目录）。写数据还需额外I/O。
- 相关笔记：[[文件系统]]

### 陷阱 19：DMA 不是让设备直接访问 CPU
- **错误认知**：DMA 让外设控制 CPU。
- **正确理解**：DMA 是专用硬件，代替 CPU 在内存和设备之间搬运数据。CPU 只需设置 DMA 参数然后去做其他事。
- 相关笔记：[[IO设备]]

### 陷阱 20：Belady 异常只在 FIFO 中出现
- **错误认知**：所有页面替换算法都可能有 Belady 异常。
- **正确理解**：Belady 异常只在非栈类算法（如 **FIFO**）中出现。LRU 等栈算法不会出现。
- 相关笔记：[[超越物理内存]]

## 一、虚拟化 — CPU
→ [[基础调度策略]] [[MLFQ与比例份额调度]] [[多处理器调度]]

### 调度算法对比

| 算法 | 抢占 | 优化目标 | 饥饿 | 特点 |
|------|------|----------|------|------|
| FCFS | 否 | — | 否 | 护航效应 |
| SJF | 否 | 周转时间 | 可能 | 非抢占最优 |
| STCF | 是 | 周转时间 | 可能 | 抢占版 SJF |
| RR | 是 | 响应时间 | 否 | 时间片轮转 |
| MLFQ | 是 | 兼顾 | 有优先级提升 | 5 条规则 |
| 彩票 | 是 | 按比例公平 | 概率性 | 随机调度 |
| CFS | 是 | 加权公平 | 否 | vruntime+红黑树 |

### MLFQ 五规则
1. Priority(A) > Priority(B) → A 运行
2. 同优先级 → RR 轮转
3. 新进程 → 最高优先级
4. 累计消耗完时间片 → 降级
5. 周期 S → 全部提升到最高

### 周转/响应时间公式
- **周转时间** = 完成时间 − 到达时间
- **响应时间** = 首次运行时间 − 到达时间

## 二、虚拟化 — 内存
→ [[地址空间]] [[地址转换与动态重定位]] [[分段]] [[分页基础]] [[TLB快速地址转换]] [[较小的页表]] [[超越物理内存]] [[空闲空间管理]]

### 地址转换公式

| 方案 | 公式 |
|------|------|
| 基址+界限 | PA = VA + base（VA < bound） |
| 分段 | PA = base_seg + offset（offset < bound_seg） |
| 分页 | PA = PFN × PageSize + offset |
| 多级页表 | 逐级查页目录 → 页表页 → PFN |

### 页表大小计算
```
PTE 数量 = 2^(地址位数 − log₂(页面大小))
页表大小 = PTE 数量 × PTE 大小
```
示例：32位地址 / 4KB页 / 4B PTE → 2²⁰ × 4 = **4MB/进程**

### 页面替换算法对比

| 算法 | 原理 | 优劣 |
|------|------|------|
| OPT | 替换未来最久不用 | 理论最优（不可实现） |
| FIFO | 替换最早进入 | 简单但有 Belady 异常 |
| LRU | 替换最近最久未用 | 效果好但实现开销大 |
| 时钟 | Use Bit 近似 LRU | 实用折衷 |

### 空闲空间管理策略

| 策略 | 搜索方式 | 碎片 | 速度 |
|------|----------|------|------|
| Best-Fit | 全遍历找最小够用 | 小碎片多 | 慢 |
| Worst-Fit | 全遍历找最大 | 大碎片 | 慢 |
| First-Fit | 找到第一个够用 | — | 快 |
| Buddy | 2的幂分割 | 内部碎片 | 合并快 |

## 三、并发
→ [[并发与线程]] [[锁]] [[基于锁的并发数据结构]] [[条件变量]] [[信号量]] [[常见并发问题]] [[基于事件的并发]]

### 锁实现对比

| 方案 | 正确 | 公平 | 性能 |
|------|------|------|------|
| 关中断 | ✓（单核） | ✗ | ✗ |
| Test-And-Set | ✓ | ✗ | 自旋浪费 |
| Compare-And-Swap | ✓ | ✗ | 自旋浪费 |
| Ticket Lock | ✓ | ✓ FIFO | 自旋浪费 |
| 两阶段锁 | ✓ | ✗ | 折衷最优 |

### 同步原语速查

| 原语 | 核心操作 | 典型用途 |
|------|----------|----------|
| 互斥锁 | lock/unlock | 临界区互斥 |
| 条件变量 | wait/signal/broadcast | 等待特定条件 |
| 信号量(1) | wait/post | 互斥（=锁） |
| 信号量(0) | wait/post | 排序/同步 |
| 信号量(N) | wait/post | 生产者-消费者 |

### 生产者-消费者（信号量版）
```
sem_t empty=N, full=0, mutex=1;

Producer:           Consumer:
  wait(empty)         wait(full)
  wait(mutex)         wait(mutex)
  put(item)           get(item)
  post(mutex)         post(mutex)
  post(full)          post(empty)
```

### 死锁四条件
1. **互斥** — 资源独占
2. **持有并等待** — 持一求二
3. **不可抢占** — 不能强夺
4. **循环等待** — 等待环路

预防 → 破坏任一条件（最常用：定义**锁序**破坏循环等待）

## 四、持久化
→ [[IO设备]] [[磁盘驱动器]] [[文件系统]]

### I/O 交互方式

| 方式 | 机制 | 适用场景 |
|------|------|----------|
| 轮询 | CPU 循环检查状态 | 快速设备 |
| 中断 | 设备完成后通知 | 慢速设备 |
| DMA | 专用硬件搬数据 | 大数据传输 |

### 磁盘访问时间
```
T_IO = T_seek + T_rotation + T_transfer
```
- 顺序访问远快于随机访问
- 调度算法：SSTF、SCAN、C-SCAN

### 文件系统布局（vsfs）
```
| Super | i-bmap | d-bmap | Inodes | Data blocks |
```
- inode：元数据 + 直接/间接指针
- 目录：(名称, inode号) 列表

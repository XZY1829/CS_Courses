# 蒙特卡洛与路径追踪（★★★）

#computer-graphics #ray-tracing #path-tracing #monte-carlo #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| MC积分 | ∫f(x)dx ≈ (1/N)Σf(Xi)/p(Xi) |
| 路径追踪 | 每次弹射采样1个方向(N=1) |
| Russian Roulette | 概率P继续，结果/P，无偏 |

## 蒙特卡洛积分

$$\int f(x)dx \approx \frac{1}{N}\sum_{i=1}^{N} \frac{f(X_i)}{p(X_i)}, \quad X_i \sim p(x)$$

- 只需能采样 + 知道 PDF
- N 越大方差越小（1/√N 收敛）

## 路径追踪

### 解渲染方程

对半球均匀采样 ωi ~ p(ω) = 1/(2π)：

$$L_o \approx \frac{1}{N}\sum \frac{L_i(\omega_i) \cdot f_r \cdot \cos\theta_i}{p(\omega_i)}$$

### 为什么 N=1？

N>1 → 每次反射产生 N 条光线 → 指数爆炸（N^bounces）

**N=1**：每次弹射只随机采样 1 个方向 → 每条路径是一条链。通过**每像素多条路径**取平均降低噪声。

## Russian Roulette (RR)

解决无限递归问题：
- 以概率 **P** 继续追踪，结果除以 P
- 以概率 **1-P** 停止，贡献为 0

$$E[L_o] = P \cdot (L_o/P) + (1-P) \cdot 0 = L_o \quad \text{→ 无偏！}$$

> [!important] RR 只增加方差，不引入系统偏差。

## 对光源采样优化

半球均匀采样效率低（大多数方向打不到光源）。

**转换**：对光源面积 A 采样

$$d\omega = \frac{dA \cdot \cos\theta'}{|x'-p|^2}$$

最终：
$$L_o = \int_A L_i \cdot f_r \cdot \frac{\cos\theta \cdot \cos\theta'}{|x'-p|^2} \, dA$$

### 最终算法
```
shade(p, wo):
    # 直接光照（对光源采样，无需RR）
    均匀采样光源面积 → x', pdf = 1/A
    如果 p 到 x' 无遮挡:
        L_dir = Li * fr * cosθ * cosθ' / |x'-p|² / pdf

    # 间接光照（对半球采样 + RR）
    以概率 P_RR 继续:
        均匀采样半球方向 wi
        追踪光线，打到非光源物体 q:
        L_indir = shade(q, -wi) * fr * cosθ / pdf / P_RR

    return L_dir + L_indir
```

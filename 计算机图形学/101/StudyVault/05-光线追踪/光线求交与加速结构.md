## 光线方程

$$\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}, \quad 0 \leq t < \infty$$

## 光线-隐式表面求交

代入 f(p)=0，解 f(o+td)=0 求 t。例如球面：解二次方程 at²+bt+c=0。

## 光线-三角形求交：Möller-Trumbore

用重心坐标直接联立求解：

$$\mathbf{o} + t\mathbf{d} = (1-b_1-b_2)\mathbf{P}_0 + b_1\mathbf{P}_1 + b_2\mathbf{P}_2$$

解线性方程组（Cramer 法则），同时得到 t 和重心坐标 (b₁,b₂)。
有交条件：t>0，b₁>0，b₂>0，1-b₁-b₂>0。

## AABB (轴对齐包围盒)

三对平面的交集。对每对面计算：
- 进入时间 tmin 和离开时间 tmax
- **tenter = max(所有 tmin)**
- **texit = min(所有 tmax)**
- 有交：**tenter < texit 且 texit ≥ 0**

> [!important] 特殊情况
> tenter < 0 < texit → 光线起点在盒内。tenter < texit < 0 → 盒在光线背后。

## 加速结构

### 空间划分
| 方法 | 说明 | 缺点 |
|------|------|------|
| 均匀网格 | 规则划分空间 | 空旷场景浪费 |
| KD-Tree | 交替按轴划分 | 物体可跨区域 |
| Oct-Tree | 八叉树 | 高维效率低 |

### 物体划分 — BVH
- 每次将**物体**分两组，分别计算包围盒
- 每个物体只属于一个节点
- 包围盒可能重叠（但不影响正确性）
- **分割策略**：选最长轴，取中位数物体分割

### BVH 遍历
```
如果光线与节点包围盒无交 → 返回
如果是叶节点 → 对所有物体求交
否则 → 递归左右子节点，取最近交点
```

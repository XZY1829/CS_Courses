# 渲染方程与全局光照（★★★）

#computer-graphics #ray-tracing #rendering-equation #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 反射方程 | Lo = ∫ Li·fr·cosθ dω |
| 渲染方程 | Lo = Le + ∫ Li·fr·cosθ dω |
| 全局光照 | 直接光 + 所有间接光(multi-bounce) |
| 算子形式 | L = E + KE + K²E + ... |

## 反射方程

$$L_o(p, \omega_o) = \int_{\Omega^+} L_i(p, \omega_i) \, f_r(p, \omega_i, \omega_o) \, \cos\theta_i \, d\omega_i$$

积分域 Ω⁺ = 上半球（法线方向）

## 渲染方程 (Kajiya 1986)

$$L_o(p, \omega_o) = L_e(p, \omega_o) + \int_{\Omega^+} L_i(p, \omega_i) \, f_r(p, \omega_i, \omega_o) \, \cos\theta_i \, d\omega_i$$

加上了自发光项 Le（光源表面自身发光）。

## 递归性质

Li 本身也满足渲染方程 → 递归定义

### 算子形式
$$L = E + KL \implies L = (I-K)^{-1}E = E + KE + K^2E + \cdots$$

| 项 | 含义 |
|----|------|
| E | 直接看到光源（自发光） |
| KE | 直接光照（一次反射） |
| K²E | 两次反射（间接光照） |
| K³E + ... | 更多次反射 |

## 全局光照

$$\text{全局光照} = \text{直接光照} + \text{间接光照} = E + KE + K^2E + K^3E + \cdots$$

> [!important] 光栅化只做了 E + KE（自发光+直接光），光线追踪可以做所有 bounce。

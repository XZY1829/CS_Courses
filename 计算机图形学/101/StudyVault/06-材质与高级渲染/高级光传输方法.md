# 高级光传输方法（★★）

#computer-graphics #ray-tracing #materials #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| BDPT | 双向路径追踪，适合复杂光路 |
| MLT | Markov Chain 采样，擅长难采样路径 |
| Photon Mapping | 有偏但一致 |
| VPL | 光子落点作虚拟点光源 |

## 无偏方法

**BDPT (双向路径追踪)**
- 从相机和光源各追踪子路径，连接端点
- 适合光源侧光传输复杂的场景

**MLT (Metropolis Light Transport)**
- 用 Markov Chain 在路径空间采样
- 从已知好路径出发，局部扰动找到相似路径
- 擅长焦散等难采样光路
- 缺点：收敛速度难预测，每像素独立导致图像"脏"

## 有偏方法

**Photon Mapping (光子映射)**
- Phase 1：从光源发射光子，记录光子落点
- Phase 2：从相机追踪，在交点处统计附近光子
- **有偏但一致** (biased but consistent)：N→∞ 时收敛

**VCM**：结合 BDPT 和光子映射

## Instant Radiosity (VPL)

光子落点作为虚拟点光源(VPL)，用直接光照近似间接光照。

## 有偏 vs 无偏

| | 无偏 | 有偏 |
|---|------|------|
| 期望 | 始终正确 | 有系统误差 |
| 一致 | — | N→∞时误差→0 |
| 例子 | BDPT, MLT | Photon Mapping |

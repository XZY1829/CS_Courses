# 着色频率与图形管线（★★）

#computer-graphics #shading #shading-frequency #graphics-pipeline #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| Flat | 每三角形一个法线，一个颜色 |
| Gouraud | 每顶点着色 → 插值颜色 |
| Phong | 插值法线 → 每像素着色 |
| 图形管线 | 顶点→三角形→光栅化→片段→帧缓冲 |

## 三种着色频率

| 方法 | 着色单元 | 法线 | 效果 |
|------|----------|------|------|
| **Flat** | 三角形 | 面法线 | 棱角明显 |
| **Gouraud** | 顶点 | 顶点法线 | 平滑但高光可能丢失 |
| **Phong** | 像素 | 插值法线 | 最好，计算最多 |

**顶点法线**：相邻面法线的加权平均（按面积加权后归一化）。

**逐像素法线**：用重心坐标插值顶点法线，**必须重新归一化**。

> [!warning] 当网格足够密时，Flat 也能达到好效果。着色频率的选择取决于模型精度。

## 图形管线 (Graphics Pipeline)

```
顶点数据 → 顶点处理 → 三角形处理 → 光栅化 → 片段处理 → 帧缓冲操作
          (MVP变换)   (组装三角形)  (采样覆盖)  (着色/纹理)  (深度测试/混合)
```

### Shader

- **顶点着色器 (Vertex Shader)**：每顶点操作（变换、光照）
- **片段着色器 (Fragment Shader)**：每像素操作（纹理、着色）
- GPU 高度并行执行

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "高光丢失" | **Gouraud shading**（顶点间插值可能跳过高光） |
| "插值法线后" | **必须归一化** |
| "顶点法线计算" | **邻面法线面积加权平均** |

### 小点 1：采样无处不在；走样现象清单

#### 课件依据
Rasterization = Sample 2D positions；照片/视频也是采样。Artifacts：Jaggies（空间）、Moiré、Wagon wheel（时间）等。原因：信号变化太快（高频），采样太慢。

#### StudyVault 参考
可用。

#### 完善后的学习笔记
走样 = 采样错误导致的「假信号/假图案」。三角形边锯齿是空间走样的典型。

#### 手写/画图建议

### 小点 2：反走样思想——先模糊（滤波）再采样；为何不能先采样

#### 课件依据
Antialiasing idea: **Blurring (Pre-Filtering) Before Sampling**。对比错误做法：Sample then filter = Blurred Aliasing。正确：Filter then sample。滤波去掉高于 Nyquist 的频率再采样。

#### StudyVault 参考
强调顺序；Nyquist：采样频率 ≥ 2× 最高频率。

#### 完善后的学习笔记
**冲突与裁决**
- 原笔记：「解决？采样之前先做模糊」「为什么不能先采样」——与课件完全一致，保留追问语气。
- Vault：同。
- **采用**：正确顺序永远是 **低通滤波 → 采样**；先采样再模糊只是把锯齿抹糊，高频折叠已经发生。

#### 手写/画图建议
两列对照图：错误（锯齿被模糊）vs 正确（边缘呈中间色、无高频折叠）。

#### 易错点
把「后处理模糊」当成与预滤波等价。

#### 可能追问
什么是 Nyquist 频率？不满足会怎样？

### 小点 3：傅里叶、滤波、卷积；时域卷积=频域乘

#### 课件依据
Fourier：信号分解为不同频率正弦。高通≈提取边界；低通≈模糊。卷积实现滤波；时域卷积 ↔ 频域相乘。采样在频域表现为频谱复制；过稀采样 → 复制重叠 → 走样。

#### StudyVault 参考
可用；写清「采样=频谱周期复制」。

#### 完善后的学习笔记
手写一条逻辑链：
1. 图像有高频（边缘）
2. 采样 = 乘冲激串 → 频谱复制
3. 复制重叠 = aliasing
4. 先低通缩小频谱支撑，再采样避免重叠

不必在笔记里重推全部傅里叶公式；抓住「频率 / 复制 / 重叠 / 低通」。

#### 手写/画图建议
画「频谱复制并重叠」示意图（一维即可）。

#### 易错点
死记「卷积」却说不出它在反走样里扮演「局部平均/低通」。

#### 可能追问
为什么说卷积能实现模糊？

### 小点 4：提高采样率 vs 先模糊；MSAA；FXAA；TAA；超分/DLSS

#### 课件依据
增加采样率理想但昂贵。实践：用像素内多样位点估计覆盖率（MSAA 思路）≈ 对指示函数做区域平均。你笔记中的 FXAA（后处理找边替换）、TAA（时间复用）、DLSS（超分）——课件主线是采样理论 + 实践 AA；后几项多为扩展，**标注清楚来源层次**。

#### StudyVault 参考
MSAA/FXAA/TAA 表可用；DLSS 作扩展。

#### 完善后的学习笔记
| 方法 | 思路 | 备注 |
|------|------|------|
| 提高分辨率/采样率 | 更接近 Nyquist | 贵 |
| **MSAA** | 像素内多样本，算覆盖率再着色/解析 | 课件实践核心；≈滤波+采样的折中 |
| FXAA | 图像空间后期找边平滑 | 快；非严格预滤波 |
| TAA | 多帧不同子像素位置复用 | 时间维 |
| 超分/DLSS | 由低分预测高分细节 | **补充/工业**；非 L06 推导重点 |

结合 MSAA 与 Z-Buffer：每个**样本**都要有深度（你原 07 笔记已有）——正确。

#### 手写/画图建议
一个像素划成 4 个子样本，三角形盖住 3/4，颜色按覆盖率混合。

#### 易错点
以为 MSAA = 简单把整图渲染到 4 倍分辨率再缩回（相关但不等于定义）。

#### 可能追问
MSAA 如何体现「先平均再输出一个像素色」？

### 小点 5：可见性——画家算法 vs Z-Buffer

#### 课件依据
Visibility / occlusion：Z-buffering。画家算法：由远到近画；深度排序困难，存在循环遮挡。Z-Buffer：同步维护 framebuffer + depth buffer；对每个像素保留最近深度；复杂度相对三角形数量线性；与三角形提交顺序无关。

#### StudyVault 参考
伪代码与陷阱（初值 +∞、取 min、不透明假设）可用。

#### 完善后的学习笔记
**把原 07 开头迁入本章：**
- 画家算法问题：如何定义「远近」？环状遮挡无法排序。
- Z-Buffer：
  ```
  初始化 depth[x][y] = +∞
  对每个三角形覆盖的像素:
    if z < depth[x][y]:
      depth = z; color = 该片元颜色
  ```
- 时间：O(三角形覆盖的像素总量)，实务说 O(n) 量级相对图元；**与顺序无关**。
- 与 MSAA：每样本独立深度。

**局限（Vault/补充）**：半透明混合不能只靠「取最近」；通常先画不透明再处理透明。

#### 手写/画图建议
三块互相遮挡的循环；Z-Buffer 逐像素比较草图。

#### 易错点
depth 初值设 0；比较方向（更近是更小还是更大）与 NDC 约定不一致。

#### 可能追问
Z-Buffer 为何对透明物体不直接适用？

## 本章重写版笔记

# 06. 反走样与 Z-Buffer

## A. 走样
采样过慢 + 信号过快 → jaggies / moiré / wagon wheel …
光栅化点采样像素中心 → 三角形边锯齿。

## B. 频域直觉（手写版）
Fourier 分解频率；采样 → 频谱复制；重叠 → 走样。  
Nyquist：采样率 ≥ 2× 最高频。

## C. 反走样原则
**先低通（模糊/平均）再采样。**  
先采样再模糊 = blurred aliasing（错）。

卷积 = 滤波；时域卷积 ↔ 频域乘。

## D. 实践
- 提采样率（贵）
- MSAA：子样本覆盖率 ≈ 像素面积平均
- FXAA / TAA / 超分：了解定位即可

## E. 可见性
- 画家算法：排序脆弱
- **Z-Buffer**：每像素保留最小深度 + 对应颜色；顺序无关；MSAA 时每样本一份深度

## F. 与管线衔接
光栅化采样 →（AA）→ Z 测试写入 → 下一章着色（Shading is local…）

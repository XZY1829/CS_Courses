## 原笔记逐点完善

### 小点 1：视锥 = 长宽比 + 垂直可视角度

#### 课件依据
近平面可用 l,r,b,t；也可用 **fovY** + **aspect = width/height** 换算：\(t=|n|\tan(\mathrm{fovY}/2)\)，\(r=\mathrm{aspect}\cdot t\)。

#### StudyVault 参考
写在投影篇；本章保留作为光栅化前的参数接口。

#### 完善后的学习笔记
视锥形状由「看见多宽多高」决定：垂直张开角 fovY + 画幅比 aspect。对称时常取 \(l=-r,\;b=-t\)。

#### 手写/画图建议
侧面画 fovY/2 与近平面半高 t。

#### 易错点
aspect 用 height/width 反了。

#### 可能追问
fov 变大时近平面上下范围如何变？

---

### 小点 2：光栅化定义；屏幕；像素；屏幕空间；像素中心 +0.5

#### 课件依据
Rasterize = 画到屏幕。屏幕 = 像素数组（分辨率）。像素暂理解为均匀颜色的小方块，RGB。像素索引整数 (x,y)；**像素 (x,y) 中心在 (x+0.5,y+0.5)**；屏幕覆盖约 [0,width]×[0,height]。

#### StudyVault 参考
完全可用。

#### 完善后的学习笔记
保留你的定义链：光栅化＝把东西画在屏幕上 → 屏幕＝2D 数组 → 像素＝带 RGB 的小方块 → 采样点取像素中心。

#### 手写/画图建议
画 3×3 像素网格，标出 (0,0) 中心 (0.5,0.5)。

#### 易错点
把像素中心当成整数坐标 (x,y)。

#### 可能追问
像素 (2,3) 的采样中心是多少？

---

### 小点 3：视口变换：[-1,1]^3 → 屏幕；先缩放再平移；先不管 z

#### 课件依据
Canonical cube 的 xy 映到屏幕；z 可另行处理（深度缓冲用）。本质：缩放 + 平移。

#### StudyVault 参考
给出近似矩阵
\[
M_{viewport}=\begin{pmatrix}w/2&0&0&w/2\\ 0&h/2&0&h/2\\ 0&0&1&0\\ 0&0&0&1\end{pmatrix}
\]

#### 完善后的学习笔记
\[
x_{screen}= \tfrac{w}{2}x_{ndc}+\tfrac{w}{2},\quad
y_{screen}= \tfrac{h}{2}y_{ndc}+\tfrac{h}{2}
\]
（ndc 为规范坐标）。原笔记「先不管 z」：可见性留给 Z-Buffer。

#### 手写/画图建议
把 [-1,1]² 正方形画到屏幕矩形。

#### 易错点
y 轴向上/向下与帧缓冲存储方向不一致时出现「上下颠倒」（作业常见，**补充推断**）。

#### 可能追问
写出视口变换对应的齐次矩阵。

---

### 小点 4：采样 inside；叉积；包围盒；锯齿引入

#### 课件依据
简单方法：对像素中心做 point-in-triangle；叉积同侧；用 bounding box 限制循环。走样：锯齿，采样率不够——下一讲系统讲。

#### StudyVault 参考
可用；提到 top-left rule（边界归属，**补充级**）。

#### 完善后的学习笔记
伪代码：
```
for 每个三角形:
  算 bounding box
  for 盒内每个像素中心 p:
    if inside(tri, p): 写颜色
```
inside：三边叉积符号一致（复习第 02 章）。

**为何三角形？**（课件/Vault）最少顶点多边形、保证平面、内外清晰、可拼任意多边形、便于插值。

#### 手写/画图建议
一个三角形盖住像素网格；标哪些中心 inside；故意画出锯齿边缘。

#### 易错点
用顶点坐标整数像素而非中心；边界像素归属规则不统一导致缝。

#### 可能追问
包围盒能否保证正确性？它优化的是什么？

## 本章重写版笔记

# 05. 三角形光栅化

## 1. 从投影参数到视锥
fovY + aspect → 近平面 t,r（及对称 l,b）。

## 2. 屏幕与像素
屏幕 = 像素数组；采样点 = 像素中心 \((x+0.5,y+0.5)\)。

## 3. 视口变换
\([-1,1]^2\to[0,w]\times[0,h]\)（缩放+平移）；z 留给深度测试。

## 4. 光栅化 = 采样
对像素中心做 inside(三角形)；叉积同号；bounding box 加速。

## 5. 遗留问题
边缘锯齿 = 走样 → 第 06 章。

## 6. 管线位置记忆
Model → View → Projection → **Viewport** → 三角形遍历/采样 →（Z-Buffer）→ 着色

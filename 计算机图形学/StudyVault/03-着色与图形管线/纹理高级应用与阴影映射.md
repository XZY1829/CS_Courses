# 纹理高级应用与阴影映射（★★）

#computer-graphics #texture #shadow-mapping #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 环境贴图 | 记录环境光照，Sphere/Cube Map |
| 凹凸贴图 | 修改法线，不改几何 |
| 位移贴图 | 实际移动顶点位置 |
| 阴影映射 | 两趟渲染，只能做硬阴影 |

## 环境贴图 (Environment Map)

假设光照来自无限远，记录在球面/立方体上。

- **Spherical Map**：球面展开，顶部/底部有扭曲
- **Cube Map**：6 面立方体，扭曲小

## 凹凸贴图 (Bump Mapping)

用纹理修改表面法线（不改变实际几何）：
- 纹理存储高度扰动 h(u,v)
- 通过 h 的梯度计算新法线方向

## 位移贴图 (Displacement Mapping)

实际改变顶点位置：
- 需要足够密的网格
- 效果比凹凸贴图真实（轮廓和阴影都正确）
- DirectX 的动态曲面细分可配合使用

## 其他纹理应用

- **3D 纹理**：三维噪声函数（Perlin Noise），如大理石、木纹
- **体积渲染**：3D 纹理存储体数据（如 CT/MRI）
- **预计算着色**：将光照结果"烘焙"到纹理中

## 阴影映射 (Shadow Mapping)

### 两趟算法
1. **从光源渲染**深度图（Shadow Map）
2. **从相机渲染**时，将每个可见点投影到光源空间，比较深度

如果点到光源距离 > Shadow Map 中的深度 → **在阴影中**

### 局限
- 只能做**硬阴影**（点光源）
- **Shadow acne**：数值精度问题（自遮挡）→ 加 bias
- **分辨率**：Shadow Map 分辨率有限 → 锯齿状阴影边缘

> [!tip] 硬阴影 vs 软阴影
> 点光源 → 硬阴影（清晰边界）；面光源 → 软阴影（本影+半影）

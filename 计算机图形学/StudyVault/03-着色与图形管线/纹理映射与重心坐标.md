## 纹理映射

每个三角形顶点对应纹理坐标 (u,v)，u,v ∈ [0,1]。通过插值得到每个像素的 (u,v)，查询纹理颜色。

## 重心坐标 (Barycentric Coordinates)

三角形内任意点表示为三顶点的加权组合：

$$(x,y) = \alpha A + \beta B + \gamma C, \quad \alpha+\beta+\gamma=1$$

- α, β, γ 为对面小三角形面积与总面积之比
- 三角形重心：α = β = γ = 1/3

**应用**：插值任何属性（颜色、法线、纹理坐标、深度）

> [!warning] 投影后重心坐标不保持！
> 3D 空间的重心坐标 ≠ 2D 屏幕空间的重心坐标。需要**透视矫正插值**。

## 纹理放大 (Magnification)

一个像素对应纹理中不到一个 texel：

| 方法 | 效果 |
|------|------|
| 最近邻 | 锯齿、马赛克 |
| **双线性 (Bilinear)** | 取最近 4 个 texel，两次线性插值 |
| 双三次 (Bicubic) | 取最近 16 个 texel，更平滑 |

## 纹理缩小 (Minification) — Mipmap

一个像素对应纹理中大面积 → 需要范围查询。

### Mipmap
- 预计算纹理金字塔：每级长宽减半
- 存储开销仅多 **1/3**（1/4 + 1/16 + ...）
- 根据像素在纹理空间覆盖的面积选择层级 D

### 三线性插值 (Trilinear)
双线性(层内) + 线性(层间) → 连续的 D 值

> [!warning] Mipmap 的问题
> 只能做正方形范围查询 → **过度模糊** (overblur)。
> 解决：各向异性过滤 (Ripmap，开销 3 倍) 或 EWA 过滤。

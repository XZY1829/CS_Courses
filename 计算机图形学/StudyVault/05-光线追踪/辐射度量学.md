# 辐射度量学（★★★）

#computer-graphics #ray-tracing #radiometry #concept

## 概览表（一目了然）
| 量 | 符号 | 单位 | 含义 |
|----|------|------|------|
| Radiant Flux | Φ | W / lm | 单位时间能量 |
| Intensity | I | W/sr | per 立体角 |
| Irradiance | E | W/m² | per 面积 |
| Radiance | L | W/(sr·m²) | per 立体角 per 投影面积 |

## 立体角 (Solid Angle)

$$\Omega = A / r^2 \quad [\text{sr}]$$

微分立体角：$d\omega = \sin\theta \, d\theta \, d\phi$

整个球面积分：$\int d\omega = 4\pi$

## Radiant Intensity

$$I(\omega) = \frac{d\Phi}{d\omega}$$

均匀点光源：$I = \Phi / (4\pi)$

> [!important] Intensity 与距离无关！它描述的是每立体角的功率。

## Irradiance

$$E(\mathbf{x}) = \frac{d\Phi(\mathbf{x})}{dA}$$

- **Lambert 余弦定律**：$E = E_0 \cos\theta$
- **距离衰减**：$E = \Phi/(4\pi r^2)$（Irradiance 衰减，而非 Intensity）

## Radiance

$$L(\mathbf{p}, \omega) = \frac{d^2\Phi}{d\omega \, dA\cos\theta}$$

- Irradiance per unit solid angle
- Intensity per unit projected area
- **沿光线传播时 Radiance 不变**（真空中）

### Irradiance vs Radiance

$$dE(\mathbf{p}) = L(\mathbf{p}, \omega) \cos\theta \, d\omega$$

$$E(\mathbf{p}) = \int_{H^2} L(\mathbf{p}, \omega) \cos\theta \, d\omega$$

## BRDF 定义

$$f_r(\omega_i, \omega_o) = \frac{dL_r(\omega_o)}{dE(\omega_i)} = \frac{dL_r(\omega_o)}{L_i(\omega_i)\cos\theta_i \, d\omega_i}$$

描述表面如何将入射光反射到各方向。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "Intensity 随距离" | **不变**（per solid angle） |
| "Irradiance 随距离" | **1/r² 衰减** |
| "Radiance 沿光线" | **不变** |
| "BRDF 的输入输出" | **入射方向 → 出射 Radiance 比 入射 Irradiance** |

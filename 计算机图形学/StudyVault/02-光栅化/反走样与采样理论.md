# 反走样与采样理论（★★★）

#computer-graphics #rasterization #antialiasing #sampling #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 走样本质 | 采样频率不足以捕获高频成分 |
| Nyquist | 采样频率 ≥ 2×最高频率 |
| 频域 | 采样=频谱复制；走样=频谱重叠 |
| 反走样 | 先滤波（低通）再采样 |
| MSAA | 多采样点近似像素覆盖率 |

## 走样现象

- **锯齿** (Jaggies)：空间采样不足
- **摩尔纹** (Moiré)：周期信号欠采样
- **车轮效应**：时间采样不足

本质：不同频率信号在给定采样率下无法区分。

## 频域分析

- **傅里叶变换**：任何信号分解为不同频率正弦波之和
- **采样** = 信号 × 冲激函数 → 频域中频谱**周期复制**
- **走样** = 复制后频谱**重叠**
- 采样间隔大 → 频域复制密 → 容易重叠

### Nyquist-Shannon 定理
**采样频率 ≥ 2 × 最高频率** → 可完美重建原始信号

## 反走样方法

### 核心思路
**先滤波（低通），再采样** ✓ — 先采样再滤波 ✗

滤波 = 卷积 = 截断高频 = 模糊

### 具体方法

| 方法 | 原理 | 特点 |
|------|------|------|
| 高分辨率 | 提高采样率 | 本质解决，成本高 |
| **MSAA** | 每像素 N 个采样点 → 覆盖率 | 近似面积平均 |
| FXAA | 后处理检测并平滑边缘 | 快速，图像空间 |
| TAA | 时间维度复用不同采样位置 | 利用帧间信息 |

> [!important] MSAA 不是简单提高分辨率
> 通过多采样点近似"面积平均"（低通滤波），每像素输出一个颜色。

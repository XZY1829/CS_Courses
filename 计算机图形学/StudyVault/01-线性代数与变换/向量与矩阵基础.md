# 向量与矩阵基础（★★）

| 条目 | 要点 |

## 向量 (Vectors)

**向量**表示方向和长度，与起点位置无关。

- **归一化**：â = a/|a|，得到单位向量
- **加法**：平行四边形法则或三角形法则
- **笛卡尔坐标**：a = (x, y)ᵀ（2D）或 (x, y, z)ᵀ（3D）

## 点积 (Dot Product)

$$a \cdot b = |a||b|\cos\theta = x_ax_b + y_ay_b + z_az_b$$

**应用**：
- **判断方向**：a·b > 0 同向，= 0 垂直，< 0 反向
- **计算投影**：b 在 a 上的投影 = (a·b/|a|²)·a
- **计算夹角**：cosθ = â·b̂

## 叉积 (Cross Product)

$$a \times b = |a||b|\sin\theta \cdot \hat{n}$$

- 结果垂直于 a、b 所在平面，方向由**右手定则**确定
- **反交换律**：a×b = -(b×a)

**应用**：
- **判断左右**：a×b 的 z 分量 > 0 → b 在 a 左侧
- **判断内外**：三角形三边叉积符号一致 → 点在内部
- **构建坐标系**：已知两个轴叉积得第三个

**矩阵形式**：a×b = A*b，其中 A 是 a 的反对称矩阵

```
A = [  0   -az   ay ]
    [  az   0   -ax ]
    [ -ay   ax   0  ]
```

## 矩阵 (Matrices)

- **乘法**：(M×N) · (N×P) = (M×P)
- **不满足交换律**：AB ≠ BA（一般情况）
- **结合律**：(AB)C = A(BC)
- **转置**：(AB)ᵀ = BᵀAᵀ
- **逆矩阵**：AA⁻¹ = I，(AB)⁻¹ = B⁻¹A⁻¹

> [!important] 变换 = 矩阵乘法
> 旋转、缩放、平移等变换都可以用矩阵乘法表示。

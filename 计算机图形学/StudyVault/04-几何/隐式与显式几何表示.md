# 隐式与显式几何表示（★★）

#computer-graphics #geometry #implicit #explicit #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 隐式 | f(x,y,z)=0；容易判断内外 |
| 显式 | 参数化/点云；容易枚举点 |
| CSG | 布尔运算组合基本形体 |
| SDF | 距离函数，可做形状融合 |

## 隐式表示

f(x,y,z) = 0 定义表面。

| 方法 | 说明 |
|------|------|
| 代数曲面 | 多项式方程 |
| CSG | ∪ ∩ − 组合基本形体 |
| 距离函数 SDF | 每点到表面最近距离 |
| 水平集 | 网格上存储函数值，等值线/面 |
| 分形 | 自相似递归结构 |

**优点**：判断点在内/外/上容易、布尔运算自然、光线求交简单
**缺点**：难以枚举表面上的点

## 显式表示

直接给出或参数化表面上的点。

| 方法 | 说明 |
|------|------|
| 点云 | 点的列表 (x,y,z) |
| 多边形网格 | 顶点+面（最常用） |
| 参数曲面 | f(u,v) → (x,y,z) |

**优点**：容易枚举/采样表面点
**缺点**：难以判断点是否在表面上

> [!important] 没有"最好"的表示
> 根据需求选择：判断内外用隐式，渲染用显式。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "判断点在物体内" | **隐式：f(p)<0** |
| "枚举表面点" | **显式：参数化采样** |
| "两个球的并集" | **CSG：∪ 运算** |
| "形状渐变/融合" | **SDF 插值** |

## 本章重写版笔记

# 01. 绪论

## 0. 开场动机（保留原口语）
画面「好看」——亮不亮、有没有全局光照——是图形学一路在追的感觉问题，不是定义。后面分别用光栅化（局部）和光线追踪（全局）回答。

## 1. CG 是什么（难定义）
闫老师课件观点：很难给 Computer Graphics 一个无歧义定义。实用对照：

| | 输入 | 输出 |
|---|---|---|
| CG（渲染） | 模型 / 场景 MODEL | 图像 IMAGE |
| CV | 图像 IMAGE | 对世界的理解 MODEL |

边界并不清晰；还有 Modeling、Simulation、Image Processing 等交叉。

## 2. 应用地图
游戏 · 电影/动画 · 设计/CAD · 可视化 · VR/AR · 插画 · 仿真 · GUI · Typography（字体）

缩写：CAD / CG / GUI / Typography。

## 3. 为何学
- **智力挑战**：创造并与虚拟世界交互；要理解物理世界多方面；催生新计算方法与显示技术。
- **技术挑战**：透视投影与曲线曲面数学；光照着色物理；三维形状表示与操作；动画/模拟；软硬件。
- 课件金句：Forget previous reasons — **Computer Graphics is AWESOME!**

## 4. 课程四大板块（主地图）

| 板块 | 一句话 | 实时/离线角色 | 对应你笔记 |
|------|--------|---------------|------------|
| Rasterization | 几何投影到屏幕并变成像素 | 游戏实时金标准 | 05–09（及 Z-Buffer） |
| Curves and Meshes | 几何如何表示与处理 | 贯穿建模与渲染 | 10–12 |
| Ray Tracing | 沿光线求交与着色，可弹射 | 影视离线金标准 | 13–18 |
| Animation / Simulation | 运动与物理模拟 | 两者皆可 | **原笔记缺，待补 21–22** |

光栅化：三维图元 → 屏幕片段。实时目标常谈 30/60 fps（**补充推断**）；课件只强调 real-time。

光线追踪：相机经像素打光线 → 交点与着色 → 可弹射。慢但易出真实感；「实时光追」属后续发展（**补充推断**）。

## 5. 本课明确不学什么
- 不用 OpenGL / DirectX / **Vulkan** 当主课内容（它们是 API）
- 不是 Maya / Blender 建模课，也不是 Unity / Unreal 开发课
- 不是 Computer Vision / Deep Learning（如 XYZ-GAN）

学的是 Graphics 原理；API 与工具可课后自学。

## 6. 学习导航
下一章起：线性代数工具 → 变换 → 观测/投影 → 光栅化 → 着色……  
动画两章在课程末尾；你原笔记尚未覆盖，后续单独补。

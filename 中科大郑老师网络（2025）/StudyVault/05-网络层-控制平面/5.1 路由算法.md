# 路由算法（重要性: ★★★）

#networking #network-layer #routing-algorithm #link-state #distance-vector #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 路由目标 | 为所有路由器找到到各子网的**最优路径**（汇集树） |
| 信息范围 | **全局**（LS）vs **分布式**（DV） |
| 更新速度 | **动态**（链路变化时更新）vs **静态**（极少变化） |
| LS 算法 | Dijkstra，O(n²) 消息/计算 |
| DV 算法 | Bellman-Ford，邻居交换距离矢量 |
| DV 缺陷 | **无穷计数**、路由环路；RIP 用**毒性逆转**缓解 |

## 路由算法分类

| 维度 | 全局（链路状态 LS） | 分布式（距离矢量 DV） |
|------|---------------------|----------------------|
| 拓扑信息 | 所有路由器拥有**完整拓扑**和链路代价 | 仅知道**邻居**及邻居声称的代价 |
| 代表算法 | **Dijkstra** | **Bellman-Ford** |
| 信息交换 | LS 分组**泛洪** | 与邻居**周期性/触发式**交换 DV |
| 更新触发 | 动态：周期性或链路代价变化 | 动态：局部链路变化或收到邻居 DV |

| 维度 | 动态路由 | 静态路由 |
|------|----------|----------|
| 变化速度 | 路由变化**很快** | 路由随时间改变**非常慢** |
| 适用 | 互联网实际部署 | 小型/稳定网络 |

## 链路状态（LS）路由：五步过程

```
[1 发现邻居] → [2 测量代价] → [3 组装LS分组] → [4 泛洪扩散] → [5 Dijkstra计算]
     ↑________________________ 协议实现（非算法本身）________________________↑
```

### 步骤 1–4（协议层）

| 步骤 | 内容 |
|------|------|
| 1 | 上电后向所有接口发 **HELLO**，邻居应答告知名字（网络号） |
| 2 | **实测**延迟：发分组要求对方立即 ECHO 响应 |
| 3 | 组装 LS 分组：发送者名称、序号、年龄、邻居列表及代价 |
| 4 | **可靠泛洪**：用 (源, 序号) 防重复；**年龄 age** 字段防循环/崩溃后序号归零 |

### 步骤 5：Dijkstra 算法（完整）

**符号**：`c(x,y)` 直连代价（非邻居=∞）；`D(v)` 源到 v 的当前最优代价；`p(v)` 前序节点；`N'` 已确定最优路径的节点集合。

```
初始化:
  N' = {u}                          /* u 为源节点 */
  for all v:
    if v adjacent to u: D(v) = c(u,v)
    else:               D(v) = ∞

Loop:
  find w ∉ N' such that D(w) is minimum
  add w to N'
  for each v adjacent to w and v ∉ N':
    D(v) = min( D(v), D(w) + c(w,v) )
  until all nodes in N'
```

**课件实例 1**（源 u，图 u-y-x-w-v-z）：

| Step | N' | D(v),p(v) | D(w),p(w) | D(x),p(x) | D(y),p(y) | D(z),p(z) |
|------|-----|-----------|-----------|-----------|-----------|-----------|
| 0 | u | 5,u | ∞ | 1,u | 2,u | ∞ |
| 1 | ux | 4,x | 3,x | — | 2,u | ∞ |
| 2 | uxy | 4,x | 3,x | — | — | 4,y |
| 3 | uxyv | — | 3,x | — | — | 4,y |
| 4 | uxyvw | — | — | — | — | 4,y |
| 5 | uxyvwz | — | — | — | — | — |

**u 的转发表**：到 v 走 (u,v)；到 x/y/w/z 均走 (u,x)。

**课件实例 2**（源 u，7 节点图）：最终 N' 序列为 u→w→x→v→y→z，通过 p(v) 回溯构建汇集树。

> [!warning]
> 当链路代价**依赖流量**时，LS 可能发生**路由振荡**（a-d-c-b 四节点振荡示例）。

## 距离矢量（DV）路由

### Bellman-Ford 方程

```
Dx(y) = min over all neighbors v { cx,v + Dv(y) }
```

- `Dx(y)`：x 到 y 的最小代价路径代价
- 实现 min 的邻居 v 即为到 y 的**下一跳**

### DV 算法流程（分布式、自终止）

```
每个节点:
  等待(本地链路代价改变 或 邻居DV消息)
  用收到的邻居DV重新计算自己的DV
  if 到任何目标的DV改变:
    向邻居通告自己的DV
  else:
    不采取行动
```

### DV 计算实例（节点 J 到 G）

| 邻居 | c(J,·) | D(·,G) | J 经该邻居到 G |
|------|--------|--------|----------------|
| A | 8 ms | 18 ms | 26 ms |
| I | 10 ms | 31 ms | 41 ms |
| H | 12 ms | 6 ms | **18 ms** ← 最小 |
| K | 6 ms | 31 ms | 37 ms |

→ J 更新：到 G 代价 18 ms，下一跳 **H**。

### 三节点 x-y-z 收敛示例

```
t=0: 各节点仅知直连代价
t=1: 交换DV后
  Dx(y)=min{2+0, 7+1}=2,  Dx(z)=min{2+1, 7+0}=3
  Dy(x)=2, Dy(z)=1
  Dz(y)=1, Dz(x)=7
→ 收敛: Dx=[0,2,3], Dy=[2,0,1], Dz=[7,1,0]
```

### 信息扩散速度

c 在 t=0 的状态影响范围：t=1 影响 1 跳，t=2 影响 2 跳……最多 d 跳后全网感知。

## 无穷计数与毒性逆转

**好消息传得快**（链路代价降低）：y→z 链路 4→1，2 轮收敛。

**坏消息传得慢**（链路代价升高）：

```
x—y—z，y 到 x 代价从 4 变为 60
y 认为经 z 到 x 代价 6 → 通告 z
z 认为经 y 到 x 代价 7 → 通告 y
… 代价递增，永不收敛（无穷计数）
```

**RIP 毒性逆转（poison reverse）**：
- 不可达距离设为 **16 跳**（max=15）
- 若 180 秒未收到通告 → 邻居/链路失效
- 向该邻居**通告不可达**（跳数=16），阻止 ping-pong 回路

## LS vs DV 对比

| 对比项 | LS | DV |
|--------|----|----|
| 消息复杂度 | O(n²) | 邻居间交换，收敛时间**不定** |
| 收敛 | O(n²)，可能振荡 | 可能路由环路、无穷计数 |
| 健壮性 | 仅影响本节点路由表 | 错误 DV 会在网络中**散播**（黑洞效应） |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "全局拓扑" | **链路状态 LS + Dijkstra** |
| "仅知邻居" | **距离矢量 DV + Bellman-Ford** |
| "坏消息慢" | **无穷计数问题** |
| "RIP 防环路" | **毒性逆转，跳数=16 表示不可达** |
| "Dijkstra 更新规则" | **D(v)=min(D(v), D(w)+c(w,v))** |
| "DV 更新规则" | **Dx(y)=min{cx,v+Dv(y)}** |

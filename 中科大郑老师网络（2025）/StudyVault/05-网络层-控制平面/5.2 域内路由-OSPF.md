# 域内路由：OSPF（重要性: ★★★）

#networking #network-layer #ospf #link-state #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| AS | 自治系统，通常属于一个 ISP，用 **ASN** 唯一标识 |
| 域内协议 | RIP（DV）、**OSPF**（LS）、EIGRP（思科私有 DV） |
| OSPF 特点 | 开放、LS 泛洪、Dijkstra、多代价指标、报文认证 |
| 层次化 | **区域 area** + **骨干区域 backbone** |
| IS-IS | ISO 标准，本质与 OSPF 相同（非 RFC） |

## 为什么需要层次化路由

平面路由（所有路由器地位平等）的问题：

| 问题 | 说明 |
|------|------|
| 不可扩展 | 百万目标需存储/交换全部可达信息 |
| 管理自主性 | 各网络管理者希望**自主控制**路由方式 |

**解决方案**：将 Internet 划分为**自治系统（AS / domain）**

```
Internet = AS₁ + AS₂ + AS₃ + …
           ↑         ↑
      域内路由    域间路由
     (IGP/内部)   (EGP/外部)
```

## 自治系统（AS）概念

| 概念 | 说明 |
|------|------|
| AS | 一组路由器集合，通常**一个 ISP 对应一个 AS** |
| ASN | AS Number，唯一标识 |
| 网关路由器 | AS **边缘**路由器，连接其他 AS |
| 域内路由 | 决定 AS **内部**如何到达各子网（含网关） |
| 域间路由 | 决定通过**哪个网关**到达其他 AS 的网络 |

**层次路由优点**：
- **规模**：新增 AS 对其他 AS 仅增加一个表项
- **管理**：各 AS 可运行不同 IGP，隐藏内部细节

## 内部网关协议（IGP）对比

| 协议 | 算法 | 特点 |
|------|------|------|
| **RIP** | DV | 每 30 秒交换；cost=跳数，**max 15**；UDP 传输；route-d 守护进程 |
| **EIGRP** | DV（增强） | 思科私有，2013 开放 RFC 7868 |
| **OSPF** | **LS** | 开放标准 RFC 2328；直接 IP 传输；Dijkstra |
| **IS-IS** | LS | ISO 标准，与 OSPF 本质相同 |

### RIP 要点（课件补充）

```
RIP 通告格式: (目标子网, 子网掩码) + 跳数
- 每次通告最多 25 个子网
- 180 秒无通告 → 邻居失效
- 毒性逆转: 不可达 = 跳数 16
- 实现: 应用层进程 route-d，经 UDP 发送
```

## OSPF 协议特点

| 特点 | 说明 |
|------|------|
| **开放** | 公开可获得（Open Shortest Path First） |
| 算法 | 经典 **LS**：泛洪 OSPF 链路状态通告 |
| 传输 | **直接 IP**（非 TCP/UDP） |
| 代价指标 | 带宽、延迟等多种可选 |
| 计算 | 各路由器获全局拓扑，**Dijkstra** 算转发表 |
| 安全 | 所有 OSPF 报文**认证** |

## OSPF 层次化路由

```
        ┌──────── backbone（骨干区域）────────┐
        │    area border routers（边界）     │
   area 1          area 2          area 3
   local routers   local routers   local routers
```

| 路由器类型 | 角色 |
|------------|------|
| **local routers** | 区域内泛洪 LS，计算区域内路由，经边界路由器转发到其他区域 |
| **backbone router** | 在骨干区域运行 OSPF |
| **area border routers** | **汇总**本区域距离，通告给骨干区域 |
| **boundary router (ASBR)** | 连接到**其他 AS** |

**LS 泛洪范围**：本区域或骨干区域；节点仅知本区域详细拓扑，对其他区域知**大致方向**。

## IS-IS 简介

- **ISO 标准**（非 RFC），与 OSPF **本质上相同**
- 同样基于链路状态算法
- 在运营商网络中广泛使用

> [!warning]
> RIP 已**不再被广泛应用**；OSPF 是 modern AS 内路由的主流 LS 协议。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "AS 内 LS 协议" | **OSPF**（开放、Dijkstra） |
| "AS 内 DV 协议" | **RIP**（30 秒、max 15 跳） |
| "与 OSPF 本质相同" | **IS-IS** |
| "区域间汇总" | **area border router** |
| "连接其他 AS" | **boundary router / ASBR** |
| "RIP 传输层" | **UDP**（应用层 route-d） |

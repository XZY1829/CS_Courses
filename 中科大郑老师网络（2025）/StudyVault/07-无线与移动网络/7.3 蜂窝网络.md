# 蜂窝网络 4G/5G（重要性: ★★★）

#networking #wireless #cellular #4g-5g #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 标准 | 3GPP；4G=**LTE**；5G=IMT-2020 |
| 4G 网元 | **eNodeB**, **MME**, **HSS**, **S-GW**, **P-GW** |
| 平面分离 | **控制平面**（MME/HSS）vs **数据平面**（S-GW/P-GW） |
| 隧道 | **GTP-U** 封装，支持移动性 |
| 5G 变化 | 云化、NFV、切片、毫米波、控制/用户面分离 |

## 4G/5G 与有线 Internet 对比

| 相同点 | 不同点 |
|--------|--------|
| 网络边缘/核心之分 | 不同无线链路层 |
| 全球网络的网络 | **移动性**为第一类服务 |
| 使用 HTTP/DNS/TCP/UDP/IP/NAT | 用户有**身份标识(SIM/IMSI)** |
| 数据/控制平面分离、SDN、隧道 | 归属/被访网络、运营商商业模式 |

## 4G LTE 架构网元

```
                    all-IP Enhanced Packet Core (EPC)
    ┌──────────┐    ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐
UE ─┤ eNode-B  ├───→│ MME │  │ HSS │  │S-GW │  │P-GW │──→ Internet
    └──────────┘    └─────┘  └─────┘  └─────┘  └─────┘
      无线接入         控制平面              数据平面
```

| 网元 | 平面 | 功能 |
|------|------|------|
| **UE** | — | 移动设备；SIM 存 **64-bit IMSI** |
| **eNode-B** | 边缘 | 管理蜂窝无线资源；类似 AP 但**主动参与移动性管理**；与周边基站协调 |
| **HSS** | 控制 | 存储订户信息；所在网络为设备**归属网络**；认证时与 MME 协调 |
| **MME** | 控制 | 设备-网络**双向认证**；与 HSS 协调；切换/寻呼/跟踪；**建立 M 到 P-GW 隧道（MME 不在隧道路径上）** |
| **S-GW** | 数据 | 数据进出路径；移动时隧道 BS 端变化，S-GW 与 P-GW 间隧道不变 |
| **P-GW** | 数据 | 蜂窝网络**网关**；类似 Internet 网关；提供 **NAT** |

## 4G 数据平面

### 第一跳协议栈（UE ↔ eNode-B）

| 层 | 功能 |
|----|------|
| Packet Data Convergence | 头部压缩、加密 |
| RLC | 分片/重组、可靠传输 |
| MAC | 请求/使用无线时隙 |
| Physical | OFDM（下行 FDM+TDM） |

- 每活跃 UE 分配 2+ 个 0.5 ms 上行时隙（12 频段中）
- 每设备可达 ~100 Mbps

### 分组核心隧道

```
UE ──[IP 载荷]──→ eNode-B ── GTP-U/UDP/IP ──→ S-GW ── GTP-U/UDP/IP ──→ P-GW ──→ Internet
                              └──── 隧道封装 ────┘      └──── 再封装 ────┘
```

| 要点 | 说明 |
|------|------|
| **GTP** | GPRS 隧道协议；原始 IP 报文封装在 UDP 内 |
| 移动性支持 | UE 切换 BS 时，**仅隧道 BS 端变化**；S-GW↔P-GW 隧道不变 |
| 封装层次 | 最上层是业务载荷（IP 或语音分组） |

## 4G 控制平面

```
控制平面: MME ↔ HSS（认证、移动性管理、安全）
数据平面: eNode-B ↔ S-GW ↔ P-GW（IP tunnels，支持 TE）
```

### 与 BS 建立关联（4 步）

1. BS 每 5 ms 广播同步信号 → M 发现主/辅同步信号
2. M 获取 BS 信息（带宽、配置、运营商）
3. M 选择 BS（优先归属运营商）
4. 认证、建立状态、配置数据平面隧道

### 休眠模式

| 模式 | 行为 |
|------|------|
| 轻休眠 | 100 ms 非活跃；周期性醒来监测下行 |
| 深度休眠 | 5–10 s 非活跃；醒来时可能已切换蜂窝，需重新关联 |

## 全球蜂窝网络

```
归属运营商网络 ←── IPX ──→ 被访运营商网络 ←──→ 公共 Internet
     HSS                    P-GW / MME
     SIM: 全局身份 + 归属网络标识
```

- **全 IP**：运营商间通过 **IPX** 互联
- HSS 存储身份、服务信息及订户当前在归属还是被访网络

## 5G 架构变化

| 维度 | 4G | 5G |
|------|----|----|
| 峰值速率 | ~100 Mbps | **10×**（若干 Gbps） |
| 延迟 | — | **10× 减少** |
| 容量 | — | **100× 流量** |
| 频段 | — | 3 频段含**毫米波**（高带宽、小覆盖、受天气影响） |
| 基站 | 宏站 | **微基站** 10–100 m，密集部署 |
| 天线 | — | **Massive MIMO**、波束成形 |
| 兼容 | — | **不对 4G 向后兼容**，须重新部署 |
| 架构 | EPC | **全面云化**；NFV/SDN/编排器；**网络切片** |
| 业务 | — | **eMBB** / **URLLC** / **mMTC** |
| RAN | — | **CloudRAN**；控制面/用户面分离 |
| 边缘 | — | **MEC** 多接入边缘计算 |

5G 三层体系架构重新整合 4G 网元，规范接口，支持基于服务的网络功能动态部署。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "4G 控制平面网元" | **MME + HSS** |
| "4G 数据平面网元" | **S-GW + P-GW** |
| "eNode-B 类似?" | **802.11 AP**，但更主动参与移动性 |
| "GTP 隧道作用" | 封装移动数据报，**BS 切换时 S-GW↔P-GW 不变** |
| "P-GW 功能" | 蜂窝**网关**、NAT |
| "IMSI 存哪" | **SIM 卡** |
| "5G 毫米波特点" | 高速率、**小覆盖**、易受天气影响 |
| "5G 三大业务" | **eMBB / URLLC / mMTC** |

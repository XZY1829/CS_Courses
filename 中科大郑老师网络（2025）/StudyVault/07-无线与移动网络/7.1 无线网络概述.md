# 无线网络概述（重要性: ★★★）

#networking #wireless #mobility #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 三大组件 | **无线主机**、**基站(base station)**、**无线链路** |
| 分类维度 | 有/无基础设施 × 单跳/多跳 |
| 链路特征 | 路径损耗、多径、干扰 → 通信更"困难" |
| SNR 与 BER | 高 SNR → 低 BER；高速率调制 → 高 BER |
| 组网问题 | **隐藏终端**（漏检冲突）、**暴露终端**（误抑制发送） |

## 无线网络组件

无线网络由三类核心组件构成，通常通过**有线网络基础设施**与 Internet 相连：

| 组件 | 说明 |
|------|------|
| **无线主机** | 笔记本、智能手机、IoT；运行应用与协议栈；可静止或移动 |
| **基站 (base station)** | 连接有线网络，协调覆盖区内移动节点的收发与信道资源；如蜂窝塔、802.11 AP |
| **无线链路** | 连接移动站点与基站（有时也作骨干）；MAP 协调接入；速率/距离/频段各异 |

> [!warning] 常见简化
> "无线"并不总意味着"移动"——固定 WiFi 主机也是无线节点。

## 无线网络分类

```
                    有基础设施              无基础设施
              ┌─────────────────┬─────────────────────┐
    单跳      │ WiFi, 蜂窝,     │ Bluetooth, ad hoc     │
              │ WiMAX → Internet│ (不连更大 Internet)   │
              ├─────────────────┼─────────────────────┤
    多跳      │ mesh net        │ MANET, VANET          │
              │ (经中继到Internet)│ (经中间节点中继)      │
              └─────────────────┴─────────────────────┘
```

| 模式 | 特征 |
|------|------|
| **基础设施模式** | 基站将无线节点连入有线网络；节点间不直接通信；**切换(handoff)** 改变接入基站 |
| **自组织模式** | 无基站；节点在链路覆盖范围内直接传输；自动组织路由 |

基础设施模式下的移动性管理核心问题：**编址**（位置无关）、**寻址**（如何找到移动站点）、**会话连续性**（切换时不中断）。

## 无线链路特征

与有线链路的重要差别：

| 特征 | 说明 |
|------|------|
| **路径损耗** | 信号通过物体/开放空间衰减；大致随距离平方反比；与材料、频率有关 |
| **干扰** | 2.4 GHz 等频段与无绳电话等共享；电磁噪声（电机等） |
| **多径传播** | 信号经反射到达目标，时间差使信号模糊；移动物体使多径时变 |

### SNR 与 BER 权衡

- **SNR（信噪比）**：20lg(S/N) 分贝；**更大 SNR → 更容易从噪声提取信号**
- 给定调制方案：增加信号强度 → 增加 SNR → **降低 BER**
- 给定 SNR：高速率调制方案 → **较高 BER**
- SNR 随移动性变化 → **自适应调整**物理层调制方案（速率 vs 出错率 vs 能耗）

```
控制目标：出错率可接受 + 减少能耗 + 提高速率
控制手段：调制方案 + 信号强度
  固定调制 → 调信号强度（能耗↔出错率）
  固定信号强度 → 调调制方案（速率↔出错率）
```

| 调制示例 | 速率 | SNR 要求 |
|----------|------|----------|
| BPSK | 1 Mbps | 低 |
| QAM16 | 4 Mbps | 中 |
| QAM256 | 8 Mbps | 高 |

## 隐藏终端与暴露终端

### 隐藏终端 (Hidden Terminal)

```
        A ──── B ──── C
     (A,C 互不可闻，但都在 B 附近)
     
A 的信号强度 ─────╲
                  ╲___ 在 B 处叠加 → 冲突
C 的信号强度 ─────╱
```

- B 与 A、C 均能相互听到；**A 与 C 互不可闻**
- A、C 可能意识不到彼此在 B 附近的**相互干扰**
- 即使 CSMA 侦听"空闲"，接收端仍可能因隐藏终端而失败

### 暴露终端 (Exposed Terminal)

```
A ── B    C ── D
     ↑ B 侦听到 C 发送，认为有冲突，抑制向 A 发送
     实际上 B→A 与 C→D 本可并行 → 影响效率
```

- C 向 D 发送时，B 侦听到 C，**误以为冲突**而不向 A 发送
- **降低信道利用率**（非传输失败）

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "无线 vs 移动" | **无线≠移动**；移动需处理切换与路由 |
| "路径损耗" | 信号衰减，约**距离平方反比** |
| "SNR↑ → BER?" | **BER↓** |
| "同 SNR 高速率调制" | **BER↑** |
| "A、C 听不到彼此，在 B 处冲突" | **隐藏终端** |
| "B 听到 C 就不发，但本可并行" | **暴露终端** |
| "有 AP 连 Internet" | **基础设施 + 单跳** |
| "MANET/VANET" | **无基础设施 + 多跳** |

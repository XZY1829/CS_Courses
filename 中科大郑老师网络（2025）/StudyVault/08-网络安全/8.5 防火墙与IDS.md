# 防火墙与 IDS（重要性: ★★★）

#networking #security #firewall #ids #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 防火墙 | 隔离内外网，按规则允许/阻塞分组 |
| 三类 | **无状态** / **有状态** / **应用网关** |
| ACL | (action, condition) 规则表，自上而下匹配 |
| IDS | 深度检查内容 + 分组间相关性 |
| IPS | （课件提及 IDS 传感器；IDS 检测，IPS 可主动阻断） |

## 防火墙

将组织**内部网络**与 Internet 隔离，按规则允许或阻塞分组进出。

### 必要性

| 目标 | 示例 |
|------|------|
| 阻止 DoS | SYN flooding 耗尽服务器资源 |
| 阻止非法修改 | 攻击者替换网页 |
| 访问控制 | 仅认证用户访问内部资源 |

### 三种类型

```
┌─────────────────┬──────────────────────────────────────┐
│ 无状态分组过滤   │ 逐包检查 IP/TCP/UDP/ICMP 字段        │
├─────────────────┼──────────────────────────────────────┤
│ 有状态分组过滤   │ + 跟踪 TCP 连接状态（SYN/FIN）       │
├─────────────────┼──────────────────────────────────────┤
│ 应用网关         │ 按**应用层内容**过滤（如 telnet 代理）│
└─────────────────┴──────────────────────────────────────┘
```

## 无状态分组过滤器

配置在边界**路由器**，逐包匹配字段决定转发/丢弃：

| 匹配字段 | 示例 |
|----------|------|
| 源/目的 IP | 阻塞特定网段 |
| TCP/UDP 端口 | 阻塞 telnet(23) |
| ICMP 类型 | 阻塞广播 ICMP |
| TCP flag | SYN、ACK bits |

### 规则示例

| 策略 | 规则 | 效果 |
|------|------|------|
| 阻塞 telnet | proto=17(UDP) 或 port=23 | 阻塞 telnet 相关 |
| 防外部主动连入 | 阻塞 ACK=0 的进入 TCP 段 | 允许内部主动建连，阻外部 SYN |
| 防 smurf | 阻塞到广播地址的 ICMP | 防 DoS 利用 |
| 隐藏拓扑 | 阻塞外出 TTL-expired ICMP | 防 traceroute 探测 |

## Access Control Lists (ACL)

规则表，**自上而下**匹配 `(action, condition)`，类似 OpenFlow 流表：

| flag | dest port | src port | proto | dest addr | src addr | action |
|------|-----------|----------|-------|-----------|----------|--------|
| ACK | 80 | >1023 | TCP | outside 222.22/16 | 222.22/16 | allow |
| — | 53 | >1023 | UDP | outside | 222.22/16 | allow |
| all | all | all | all | all | all | **deny** |

## 有状态分组过滤

**问题**：无状态允许 ACK=1, dest=80 的包通过，即使**连接从未建立**。

**解决**：维护**连接状态表**，跟踪 TCP 连接建立(SYN)和拆除(FIN)；仅允许属于已建立连接的分组；非活跃连接超时。

```
ACL 规则 + check connection（查状态表）→ allow/deny
```

## 应用网关

按**应用数据内容**过滤（不仅 IP/TCP/UDP 头）。

**Telnet 网关示例**：
1. 所有 telnet 用户须经网关
2. 网关验证用户后，与目标建立 telnet 连接并**中继**
3. 路由器过滤非来自网关的 telnet 分组

| 局限 | 说明 |
|------|------|
| 多应用需多个网关 | 每种应用一个 |
| 客户端须配置代理 | 如浏览器设代理 IP |
| UDP 难精细过滤 | 通常全过或全不过 |
| IP 欺骗 | 路由器无法验证源 IP 真实性 |

## 入侵检测系统 (IDS)

| 对比 | 分组过滤 | IDS |
|------|----------|-----|
| 检查深度 | TCP/IP 头部 | **分组内容**（特征码匹配） |
| 相关性 | 无 | **分组间时间序列** |
| 检测能力 | — | 端口扫描、网络映射、DoS |

```
Internet ── firewall ── DMZ(Web/FTP/DNS) ── IDS sensors ── internal network
```

- 多个 IDS 传感器部署于不同网段，按需不同类型检查
- **IPS（入侵防御）**：在 IDS 基础上可**主动阻断**攻击流量（课件 IDS 章节延伸概念）

> [!warning] 局限
> 即使高度保护的站点仍可能受攻击；防火墙是**便利性 vs 安全级别**的折中。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "无状态 vs 有状态" | 有状态**跟踪 TCP 连接** |
| "ACK=0 规则" | 阻外部**主动建连** |
| "应用网关" | 按**应用层内容**过滤 |
| "ACL 匹配顺序" | **自上而下**，先 match 先执行 |
| "IDS vs 防火墙" | IDS **深度内容**+时序分析 |
| "IPSec VPN SA 数" | 总部+分支+n销售 = **2+2n** |
| "防火墙局限" | **IP 欺骗**、UDP 粗过滤 |

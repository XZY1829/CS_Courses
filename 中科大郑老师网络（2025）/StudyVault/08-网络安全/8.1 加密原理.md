# 加密原理（重要性: ★★★）

#networking #security #encryption #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 四大目标 | **机密性**、**认证**、**完整性**、**可用性** |
| 对称加密 | DES/3DES/AES；共享同一密钥 |
| 公钥加密 | RSA；公钥加密、私钥解密 |
| CBC | 第 i 块明文与前块密文异或，防重复块 |
| 实践模式 | RSA 交换**会话密钥**，数据用对称加密 |

## 网络安全四大目标

| 目标 | 含义 |
|------|------|
| **机密性** | 仅发送方和指定接收方能理解报文；加密/解密 |
| **认证** | 确认对方身份 |
| **完整性** | 确认报文传输中未被篡改 |
| **可用性** | 服务可接入、对用户可用 |

攻击者(Trudy)可：窃听、插入、伪装源地址、劫持连接、拒绝服务。

## 对称密钥加密

Bob 和 Alice **共享同一密钥** K_S：

```
明文 m ── K_S 加密 ──→ 密文 K_S(m) ── K_S 解密 ──→ m
```

| 算法 | 要点 |
|------|------|
| **DES** | 56-bit 密钥，64-bit 明文块；16 轮；已被暴力破解 |
| **3DES** | 3 个 key、3 重 DES 运算，增强安全 |
| **AES** | 128-bit 块；128/192/256-bit 密钥；替换 DES 标准 |

> DES 暴力破解：56-bit 密钥短语不到一天可破。AES：若 DES 需 1 秒，AES 需约 **149 万亿年**。

**密钥分发问题**：Bob 和 Alice 如何首次就密钥达成一致（尤其从未见面）？

## 密码块链 (CBC)

| 问题 | CBC 解决 |
|------|----------|
| 相同明文块 → 相同密文块 | 第 i 块输入 = m(i) ⊕ c(i-1) |

```
m(1) ──→ [block cipher] ──→ c(1)
              ↑
m(i) ⊕ c(i-1) ──→ [block cipher] ──→ c(i)
```

## 公开密钥加密 (RSA)

发送方和接收方**无需共享密钥**；公钥公开，私钥仅接收方持有。

```
m = K_B^-(K_B^+(m))    // 公钥加密，私钥解密
```

### RSA 密钥生成步骤

1. 选大质数 **p, q**（各约 1024 bit）
2. 计算 **n = pq**，**z = (p-1)(q-1)**
3. 选 **e < n**，e 与 z **互素**
4. 选 **d** 使得 **ed mod z = 1**
5. **公钥 (n, e)**，**私钥 (n, d)**

### RSA 加密/解密

- 加密：c = **m^e mod n**（m < n）
- 解密：m = **c^d mod n**

### RSA 计算例题（课件）

```
p=5, q=7 → n=35, z=24
e=5（与 z 互素）, d=29（ed-1 被 z 整除）

明文 m=12 (00001100):
  加密: c = 12^5 mod 35 = 24832 mod 35 = 17
  解密: m = 17^29 mod 35 = 12  ✓
```

### RSA 重要特性

**K_B^-(K_B^+(m)) = K_B^+(K_B^-(m)) = m** — 公钥/私钥可互换使用 → 用于**数字签名**。

### RSA 安全性

已知公钥 (n,e)，求私钥 d 等价于**分解大整数 n**（困难）。

### RSA 实践：会话密钥

- RSA 指数运算代价大；DES 比 RSA 快 **≥100 倍**
- 用 RSA **交换对称会话密钥 K_S**，之后用 K_S 加密数据

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "DES 密钥长度" | **56 bit** |
| "AES 块大小" | **128 bit** |
| "CBC 作用" | 明文块与前密文块**异或**，防相同块 |
| "RSA 公钥" | **(n, e)** |
| "ed mod z" | **= 1** |
| "RSA 安全基础" | **大整数分解**困难 |
| "混合加密" | RSA 换 **K_S**，数据用对称加密 |

# 认证与数字签名（重要性: ★★★）

#networking #security #authentication #digital-signature #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 认证演进 | ap1.0 → ap5.0，逐步修补漏洞 |
| ap4.0 | **nonce + 对称密钥**加密，防重放 |
| ap5.0 | **nonce + 公钥**签名；有中间人漏洞 |
| 数字签名 | 私钥签摘要 **K_B^-(H(m))** |
| 摘要算法 | **MD5**(128-bit)、**SHA-1**(160-bit) |

## 认证协议演进

目标：Bob 需 Alice **证明**身份。

### ap1.0：声明身份

```
Alice ── "I am Alice" ──→ Bob
```
**漏洞**：Trudy 可直接声明 "I am Alice"（Bob 看不到 Alice）。

### ap2.0：声明 + IP 地址

```
Alice ── "I am Alice" + IP_A ──→ Bob
```
**漏洞**：Trudy 可**伪造源 IP 地址**。

### ap3.0：声明 + 密码

```
Alice ── "I am Alice" + password ──→ Bob
```
**漏洞**：**重放攻击(playback)** — Trudy 记录 Alice 分组后重放。

### ap3.0 升级版：加密密码

```
Alice ── "I am Alice" + E(password) ──→ Bob
```
**漏洞**：重放攻击**仍然有效**（记录加密密码后重放）。

### ap4.0：nonce + 对称密钥

```
Alice ── "I am Alice" ──→ Bob
Bob ── R (nonce) ──→ Alice
Alice ── K_{A-B}(R) ──→ Bob
```

| 机制 | 效果 |
|------|------|
| **nonce 一次性** | 防重放 |
| 仅 Alice 知 K_{A-B} | 证明身份 |

**缺点**：需预先共享对称密钥。

### ap5.0：nonce + 公钥加密

```
Alice ── "I am Alice" ──→ Bob
Bob ── "Send me your public key" ──→ Alice
Alice ── K_A^+(R) 或 K_A^-(R) ──→ Bob
Bob 验证: K_A^+(K_A^-(R)) = R
```

**优点**：无需预共享对称密钥；仅 Alice 有私钥 K_A^-。

### ap5.0 漏洞：中间人攻击 (MITM)

```
Alice ←── Trudy(假Bob) ──→ Bob
         Trudy(假Alice)
```

| 步骤 | Trudy 行为 |
|------|-----------|
| 1 | 截获 Bob 的 "Send public key" |
| 2 | 发送 **Trudy 的公钥 K_T^+** 给 Bob（冒充 Alice） |
| 3 | 获取 Alice 真公钥，转发/解密通信 |
| 4 | Bob 认证 Trudy 为 Alice；Alice/Bob  unaware |

**本质**：Bob **没有拿到真正 Alice 的公钥**。

> 修复方向：需要**可认证的公钥** → CA 证书体系（见 [[8.3 密钥管理与证书]]）。

## 数字签名

Bob 用**私钥**对报文 m 签署：**K_B^-(m)** 或更常用 **K_B^-(H(m))**。

| 性质 | 说明 |
|------|------|
| **可验证性** | Alice 用 K_B^+ 验证 K_B^+(K_B^-(m)) = m |
| **不可伪造** | 仅 Bob 有私钥 |
| **不可抵赖** | Alice 可持 m 和签名上法庭证明 Bob 签署 |

## 报文摘要 (Hash)

| 特性 | 说明 |
|------|------|
| 多对 1 | 不同报文可能同摘要 |
| 固定长度 | MD5: 128-bit；SHA-1: 160-bit |
| 单向 | 给定 H(m)，反推 m **计算不可行** |

Internet 校验和：固定长度但**弱**（易构造碰撞，如 "IOU 100.99 BOB" vs "IOU 900.19 BOB"）。

## 数字签名 + 摘要

```
发送: m, K_B^-(H(m))
验证: H(m) ?= K_B^+(K_B^-(H(m)))
```

| 优势 | 说明 |
|------|------|
| 效率 | 只对固定长度摘要做公钥运算 |
| 完整性 | 改 m 则 H(m) 变，验证失败 |
| 认证 | 签名者必拥有 Bob 私钥 |

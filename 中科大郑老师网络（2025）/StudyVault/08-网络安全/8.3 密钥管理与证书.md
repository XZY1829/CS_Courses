# 密钥管理与证书（重要性: ★★★）

#networking #security #authentication #encryption #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| CA 证书 | 捆绑实体身份与公钥，**CA 私钥签署** |
| 信任树 | 根证书带外获取 → 信任链 |
| KDC | 密钥分发中心（对称密钥场景） |
| Diffie-Hellman | 协商共享密钥，**非 RSA 算法** |

## 公钥认证问题

Trudy 可冒充 Bob 发披萨订单：用自己的私钥签名，告诉披萨店"这是 Bob 的公钥" → 需**可认证的公钥**。

## 认证中心 (CA)

CA 将**公钥与实体 E 捆绑**，CA 用私钥签署证书：

```
Certificate = { E 身份信息, K_B^+ }  +  K_CA^-(上述内容)
```

| 步骤 | 说明 |
|------|------|
| 注册 | E 带外向 CA 提供身份证据 + 公钥 |
| 获取 Bob 公钥 | Alice 获 Bob 证书 → 用 **K_CA^+** 验证 → 提取 K_B^+ |
| CA 公钥 | 带外获取（OS 预装、可信下载）；CA 证书**自签名** |

## 互联网信任树

```
根 CA（带外信任）
  ├── 中间 CA 证书（根 CA 签署）
  │     └── 机构证书（中间 CA 签署）
  └── ...
```

- **根证书**：自签名或未被其他 CA 签署
- 信任根 → 可可靠获取根签发的下级机构公钥

## 密钥分发中心 (KDC)

对称加密场景：KDC 为通信双方分发共享会话密钥（课件在认证 ap4.0 背景下提及需预共享密钥；KDC 是经典对称密钥分发机制）。

| 角色 | 功能 |
|------|------|
| KDC | 可信第三方，维护用户-密钥映射 |
| 通信方 | 向 KDC 请求会话密钥，KDC 用各自 master key 加密分发 |

> [!warning] 与 CA 区别
> KDC 分发**对称密钥**；CA 认证**公钥**绑定。二者解决不同层面的密钥管理问题。

## Diffie-Hellman 密钥协商

与 RSA **不同的算法**；双方无需显式传输共享密钥即可计算出相同值。

### 步骤

1. Bob 选公开值：大素数 **p**，元根 **g**（g < p），发给 Alice
2. Alice 选私有 **S_A**，Bob 选私有 **S_B**
3. Alice 公钥：**K_A^+ = g^{S_A} mod p** → 发给 Bob
4. Bob 公钥：**K_B^+ = g^{S_B} mod p** → 发给 Alice
5. 共享密钥：
   - Alice 计算：**(K_B^+)^{S_A} mod p = g^{S_A S_B} mod p**
   - Bob 计算：**(K_A^+)^{S_B} mod p = g^{S_A S_B} mod p**

### DH 计算例题

```
公开: p=97, g=5
Alice: S_A=36 → K_A^+ = 5^36 mod 97 = 50
Bob:   S_B=58 → K_B^+ = 5^58 mod 97 = 44

Alice: key = 44^36 mod 97 = 75
Bob:   key = 50^58 mod 97 = 75  ✓ 相同
```

> TLS 1.3 采用 DH 进行密钥交换（不仅 RSA）。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "CA 作用" | 捆绑**身份+公钥**，私钥签署 |
| "验证证书" | 用 **CA 公钥**解密签名 |
| "根证书获取" | **带外**（OS 预装等） |
| "DH 共享密钥" | **g^{S_A S_B} mod p** |
| "DH vs RSA" | DH **协商**对称密钥；RSA **加密** |
| "ap5.0 修复" | 需要 **CA 证书** |

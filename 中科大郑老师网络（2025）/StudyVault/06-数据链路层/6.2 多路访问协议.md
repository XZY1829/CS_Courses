# 多路访问协议（重要性: ★★★）

#networking #link-layer #multiple-access #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 问题 | 广播信道上多节点同时发送 → **碰撞** |
| 三大类 | **信道划分**、**随机访问**、**轮次** |
| 理想 MAP | 单节点全速 R；M 节点各 R/M；分布式、简单 |
| 以太网 MAC | **CSMA/CD** + 二进制指数退避 |
| 效率公式 | CSMA/CD: **1 / (1 + 5·t_prop/t_trans)** |

## 广播信道与 MAP

```
共享信道: 节点 A、B、C 同时发送 → 碰撞（接收方无法分辨）
MAP: 分布式算法，决定"何时可以发送"
约束: 协调必须借助信道本身（无带外信道）
```

| 链路类型 | 示例 |
|----------|------|
| **点到点** | 路由器间专线、交换机-主机 |
| **广播式** | 老式总线以太网、HFC 上行、WiFi、4G/5G |

## 理想多路访问协议

给定速率 R 的 MAC 信道，理想特性：
1. 单节点发送 → 速率 **R**
2. M 节点发送 → 各 **R/M**
3. **完全分布式**（无特殊节点、无时隙同步）
4. **简单**

> 无单一协议能完美满足全部四条。

## 三大类 MAC 协议

| 类型 | 思想 | 代表 |
|------|------|------|
| **信道划分** | 划分时隙/频段/码，独享分片 | TDMA、FDMA、CDMA |
| **随机访问** | 允许碰撞，有恢复机制 | ALOHA、S-ALOHA、CSMA、CSMA/CD |
| **轮次** | 轮流发送 | 轮询、令牌传递 |

### 负载特性对比

| 类型 | 低负载 | 高负载 |
|------|--------|--------|
| 信道划分 | **低效**（仅 1/N 带宽即使用户少） | 高效、公平 |
| 随机访问 | **高效**（单活跃节点全速） | 反复碰撞、浪费严重 |
| 轮次 | 兼具二者优点 | 兼具二者优点 |

## 信道划分

### TDMA（时分多路复用）

```
帧: [时隙1][时隙2][时隙3][时隙4][时隙5][时隙6]
     站点1  空闲   站点3  站点4  空闲   空闲
```

- 每站点每轮获固定时隙（= 包发送时间）
- 未使用时隙**空闲浪费**；需时间同步

### FDMA（频分多路复用）

- 频谱分为频带，每站点固定频带
- 未使用频带浪费

### CDMA（码分多路复用）

- 课件总结中提及，与 TDMA/FDMA 并列

## 随机访问

### 纯 ALOHA

```
帧到达 → 立即发送（无同步）
碰撞窗口: [t0-1, t0+1] 内其他帧开始传输 → 碰撞
最大效率: **18.5%** (≈ 1/2e)
```

### 时隙 ALOHA（Slotted ALOHA）

| 假设 | 说明 |
|------|------|
| 帧等长 | 时间分为时隙（= 帧传输时间） |
| 同步 | 仅在时隙**开始**传输 |
| 碰撞 | 同时隙多节点 → 全检测为碰撞 |
| 恢复 | 下一时隙以概率 p 重传，直到成功 |

**效率**（N 节点，各以 p 发送）：

```
单节点成功: p(1-p)^(N-1)
信道成功:   Np(1-p)^(N-1)
N→∞ 最优:   最大效率 = 1/e ≈ **37%**
```

### CSMA（载波侦听多路访问）

```
发送前侦听:
  信道空闲 → 立即发送整个帧
  信道忙碌 → 推迟直到空闲
```

- **先听后说**；但传播延迟仍可能导致碰撞

### CSMA/CD（碰撞检测）

```
CS: 先听后说
CD: 边听边说 → 检测到碰撞 → 立即中止 + 发 jam 信号
```

**以太网 CSMA/CD 算法（完整 5 步）**：

```
1. NIC 从网络层收数据报，创建帧
2. 检测信道:
     空闲 → 立即传输
     忙碌 → 侦听至空闲后传输
3. 传输中 CD: 无碰撞 → 成功完成（无需 ACK）
4. 检测到碰撞 → 放弃，发 jam 信号
5. 二进制指数退避:
     第 m 次碰撞后，K ∈ {0,1,…,2^m-1} 随机选取
     等待 K×512 位时后返回步骤 2
     超过 10 次连续碰撞 → 报错
```

**退避示例**：

| 碰撞次数 m | K 范围 | 等待 |
|------------|--------|------|
| 1 | {0,1} | K×512 bit |
| 2 | {0,1,2,3} | K×512 bit |
| 10 | {0,…,1023} | K×512 bit |

### CSMA/CD 效率公式

```
efficiency = 1 / (1 + 5 · t_prop / t_trans)
```

| 符号 | 含义 |
|------|------|
| t_prop | LAN 中两站点**最大传播延迟** |
| t_trans | **最大帧**传输时间 |

- t_prop→0 或 t_trans→∞ 时 efficiency→1
- 比 ALOHA 性能好；简单、便宜、分布式

> [!warning]
> **CSMA/CD 用于有线**（易检测碰撞）；WLAN 用 **CSMA/CA**（难检测碰撞）。

## 轮次协议

### 轮询（Polling）

```
master ──poll──→ slave1 ──data──→ master ──poll──→ slave2 …
```

| 关注点 | 说明 |
|--------|------|
| 优点 | 无碰撞 |
| 缺点 | 轮询开销、延迟（等 master 轮询）、**单点故障**（master） |

### 令牌传递（Token Passing）

```
T → 节点截获令牌 → 发送数据 → 传完恢复令牌 T → 下游节点
```

| 关注点 | 说明 |
|--------|------|
| 应用 | 蓝牙、FDDI、令牌环 |
| 缺点 | 令牌开销、延迟、**单点故障**（令牌丢失） |

## 有线接入网络综合示例（DOCSIS）

```
下行: FDM 分多个 40Mbps 信道
上行: FDM 分多个 30Mbps 信道 → TDM 微时隙
      部分微时隙分配（数据）+ 部分竞争（预约请求）
```

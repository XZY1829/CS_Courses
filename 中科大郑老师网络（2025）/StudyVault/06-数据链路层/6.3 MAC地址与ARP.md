# MAC 地址与 ARP（重要性: ★★★）

#networking #link-layer #arp #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| MAC 地址 | **48 位**，IEEE 管理，烧入 NIC ROM |
| IP vs MAC | IP=层次化逻辑地址；MAC=**平面**物理地址 |
| ARP | 已知 IP → 解析 MAC；**广播查询、单播响应** |
| ARP 表 | `<IP, MAC, TTL>`，典型 TTL **20 分钟** |
| 跨子网 | 帧目标 MAC = **默认网关**（非目标主机 MAC） |

## MAC 地址

| 属性 | 说明 |
|------|------|
| 长度 | **48 位**（大多数 LAN） |
| 表示 | 十六进制，如 `1A-2F-BB-76-09-AD` |
| 分配 | **IEEE** 管理，厂商购买地址段保证全球唯一 |
| 存储 | 烧入 NIC ROM，有时可软件设置 |
| 作用 | 在 LAN 内区分网卡，用于帧的源/目的地址 |
| 平面性 | 可跨 LAN 移动网卡，**MAC 不变** |

### IP 与 MAC 对比

| 对比 | IP 地址 | MAC 地址 |
|------|---------|----------|
| 层次 | **分层**（网络号+主机号） | **平面** |
| 范围 | 全球路由 | 单个 LAN 内 |
| 可移动性 | 取决于所连子网 | 网卡可移动，MAC 不变 |
| 类比 | 邮政地址 | 身份证号 |

### 地址分离的好处

| 好处 | 说明 |
|------|------|
| a) 换网卡 | MAC 变、**IP 不变** |
| b) 多协议 | 物理网上可运行 IPX、AppleTalk 等 |

> [!warning]
> 若 IP 与 MAC 捆绑：只能选 IP 协议；每帧都需上交 IP 层判断，**代价大**。

## ARP（Address Resolution Protocol）

**问题**：已知接口 IP 地址，如何确定其 MAC 地址？

### ARP 表

每个 LAN 上的 IP 节点（主机、路由器）维护：

```
< IP address ; MAC address ; TTL >
TTL 典型 20 分钟后老化
```

## ARP 请求/响应过程（同一子网）

**场景**：A(137.196.7.23) 发 IP 数据报给 B(137.196.7.14)，A 的 ARP 表无 B 的 MAC。

```
步骤 1: A 广播 ARP 查询
  ┌─────────────────────────────────────┐
  │ 以太网帧 dst MAC: FF-FF-FF-FF-FF-FF  │
  │ ARP: Target IP = 137.196.7.14       │
  │      Source IP = 137.196.7.23       │
  │      Source MAC = 71-65-F7-2B-08-53 │
  └─────────────────────────────────────┘
         ↓ 广播，所有 LAN 节点收到

步骤 2: B 单播 ARP 响应给 A
  ┌─────────────────────────────────────┐
  │ 以太网帧 dst MAC: 71-65-F7-2B-08-53 │
  │ ARP: Target IP = 137.196.7.14       │
  │      Target MAC = 58-23-D7-FA-20-B0 │
  └─────────────────────────────────────┘

步骤 3: A 更新 ARP 表
  137.196.7.14 → 58-23-D7-FA-20-B0, TTL=500
```

## 跨子网寻址

**场景**：A(111.111.111.111) 经路由器 R 发数据报到 B(222.222.222.222)

```
A 创建 IP 数据报: src=A, dest=B（IP 始终端到端不变）

第一跳（A→R）:
  MAC src = A 的 MAC
  MAC dest = R 接入 A 子网的接口 MAC（通过 ARP 获得，非 B 的 MAC！）

R 解封装 IP，查路由，创建新帧（R→B）:
  MAC src = R 接入 B 子网接口 MAC
  MAC dest = B 的 MAC（R 通过 ARP 获得）
```

| 层次 | 同一子网 | 跨子网 |
|------|----------|--------|
| IP dest | 目标主机 | 目标主机（不变） |
| MAC dest | **目标主机 MAC** | **下一跳路由器 MAC** |
| ARP 查询对象 | 目标主机 IP | **默认网关 IP** |

> [!warning]
> 常见错误：跨子网时将帧 MAC 设为目标主机 MAC。实际上 MAC 仅负责**当前一跳**的链路层交付。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "MAC 长度" | **48 位** |

# 以太网（重要性: ★★★）

#networking #link-layer #ethernet #multiple-access #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 地位 | 占主导的有线 LAN 技术 |
| 帧结构 | 前导码 + 目的/源 MAC + 类型 + 数据 + **CRC** |
| 特性 | **无连接、不可靠**；MAC = CSMA/CD |
| 拓扑 | 总线（历史）→ **星型交换**（现行） |
| 速率 | 10 Mbps → 400/800 Gbps |
| 编码 | 10BaseT: **Manchester**；100BaseT: **4b5b** |

## 以太网概述

| 特点 | 说明 |
|------|------|
| 历史 | 第一个广泛使用的 LAN 技术 |
| 优势 | **更简单、便宜** |
| 速率演进 | 10 → 100 → 1000 Mbps → 10/40/100/400/800 Gbps |
| 标准 | 802.3：一致 MAC 和帧格式，不同物理层 |

## 物理拓扑

| 拓扑 | 特点 | 现状 |
|------|------|------|
| **总线型** | 同轴电缆，所有节点同一**碰撞域** | 90 年代流行 |
| **集线器** | 盒中总线，仍是共享碰撞域 | 已淘汰 |
| **交换型** | 交换机主动转发，每端口独立碰撞域 | **现行主导** |

```
总线/集线器:  [A]──[B]──[C]── 同一碰撞域，同时仅一节点发送
交换型:       [A]─SW─[B]  每链路独立，A-B 与 C-D 可并行
```

## 以太网帧格式

```
┌──────────┬──────────┬──────────┬──────┬──────────┬─────┐
│ preamble │ dest MAC │ src MAC  │ type │  data    │ CRC │
│ 7+1 字节 │ 6 字节   │ 6 字节   │ 2 字节│ 46-1500 │ 4 字节│
└──────────┴──────────┴──────────┴──────┴──────────┴─────┘
```

| 字段 | 说明 |
|------|------|
| **前导码** | 7 字节 `10101010` + 1 字节 `10101011`；**时钟同步** |
| **目的地址** | 6 字节目标 MAC；本节点或广播则接收 |
| **源地址** | 6 字节源 MAC |
| **类型/长度** | ≥1536 为**类型**（多路解复用，如 IP=0x0800）；≤1500 为长度 |
| **数据** | 封装 IP 数据报或其他网络层 PDU |
| **CRC** | 接收方校验；出错→**丢弃帧** |

## 无连接、不可靠

| 特性 | 说明 |
|------|------|
| **无连接** | 发送前无需握手 |
| **不可靠** | 无 ACK/NAK；出错丢弃，发送方不恢复 |
| 上层恢复 | TCP 可恢复丢失段；UDP 可能丢数据 |
| MAC 协议 | 非时隙 **CSMA/CD** + 二进制指数退避 |

## 802.3 标准结构

```
application / transport / network
         ↓
    link: MAC 协议 + 帧格式（统一）
         ↓
    physical: 多种物理层
         100BASE-TX, 100BASE-FX, 1000BASE-T, …
```

| 速率标准 | 物理介质 |
|----------|----------|
| 10BASE-T | 双绞线 |
| 100BASE-TX/T4 | 双绞线 |
| 100BASE-FX/SX | 光纤 |
| 1000BASE-T | 双绞线，8b10b 编码 |

## 物理层编码

### Manchester 编码（10BaseT）

```
每个 bit 位时中间有一次信号跳变
→ 收发时钟同步，无需全局时钟
10 Mbps → 信号占 20M 带宽，效率 50%
```

### 4b5b 编码（100BaseT）

- 每 4 数据位映射为 5 编码位
- 保证足够跳变供时钟同步
- 课件映射表（部分）：

| 4bit | 5bit | 4bit | 5bit |
|------|------|------|------|
| 0000 | 11110 | 1000 | 10010 |
| 0001 | 01001 | 1001 | 10011 |
| 0010 | 10100 | … | … |

### 千兆以太网

| 要点 | 说明 |
|------|------|
| 帧格式 | 标准以太网帧 |
| 全双工点对点 | 专用信道，**无冲突**，效率高 |
| 共享模式 | 仍用 CSMA/CD，需短距离 |
| 编码 | **8b10b** |
| 速率 | 已达 800 Gbps |

> [!warning]
> 全双工交换以太网**不使用 CSMA/CD**（无碰撞）；CSMA/CD 仅用于半双工/共享模式。

# 交换机与 VLAN（重要性: ★★★）

#networking #link-layer #switch #vlan #mpls #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 交换机 | 链路层**主动**设备，自学习 MAC-端口映射 |
| vs 路由器 | 交换机查 **MAC**；路由器查 **IP** |
| VLAN | 逻辑划分广播域，基于端口或 MAC |
| Trunk | 802.1Q 标签跨交换机承载 VLAN |
| MPLS | 固定长度**标签**快速转发，保留 IP 地址 |
| 数据中心 | TOR → Tier-2 → Tier-1 → 边界路由器 |

## 以太网交换机

| 特点 | 说明 |
|------|------|
| 角色 | 链路层设备，**存储转发**以太网帧 |
| 透明 | 主机/路由器 IP 层**不知道**交换机存在 |
| 即插即用 | **自学习**，无需配置 |
| 转发 | 查目标 MAC → 对应端口；广播则泛洪 |
| 全双工 | 主机-交换机专有连接 → **无冲突** |

### 多路同时传输

```
       ┌─── SW ───┐
  A ──1      4── A'
  B ──2      5── B'
  C ──3      6── C'

A→A' 与 B→B' 可同时进行（不同端口）
A→A' 与 C→A' 不能同时（争用端口 4）
```

## 交换表与自学习

### 交换表结构

```
(MAC 地址, 到达接口/端口, 时戳)
```

### 自学习过程

```
1. 帧到达 → 记录 (源 MAC, 进入端口)
2. 查目标 MAC:
   - 找到且端口 ≠ 进入端口 → 转发到该端口
   - 找到且端口 = 进入端口 → 丢弃
   - 未找到 → 泛洪（除进入端口外所有端口）
```

### 自学习转发示例

```
初始: 交换表为空
A→A': 未知 A' → 泛洪; 学习 A 在端口 1
A'→A: 未知 A  → 泛洪; 学习 A' 在端口 4
后续 A→A': 已知 A' 在 4 → 仅向端口 4 转发
```

### 交换机互联

- 自学习交换机可**级联**
- 原理与单交换机相同：C→I 帧逐步填充各交换机表项

## 交换机 vs 路由器

| 对比 | 交换机 | 路由器 |
|------|--------|--------|
| 层次 | **链路层**（查 MAC 头） | **网络层**（查 IP 头） |
| 转发表 | 自学习/泛洪，基于 **MAC** | 路由算法，基于 **IP** |
| 转发范围 | 同一广播域内 | 跨子网/AS |
| 共同 | 均为**存储转发**设备 | |

## VLAN（Virtual LAN）

### 动机

| 问题 | 说明 |
|------|------|
| 广播域扩展 | 级联交换机后所有端口仍属**一个广播域** |
| ARP/DHCP | 二层广播流量穿越整个 LAN → 效率/安全/隐私问题 |
| 管理 | 用户物理移动但希望逻辑归属不变（CS 用户移到 EE 端口） |

### 基于端口的 VLAN

```
物理交换机 → 配置为多个虚拟交换机

端口 1-8:   EE VLAN（广播限于 1-8）
端口 9-15:  CS VLAN（广播限于 9-15）
```

| 特性 | 说明 |
|------|------|
| 流量隔离 | 1-8 端口帧仅到 1-8 |
| VLAN 间转发 | 需**路由器**（三层交换：一次路由多次交换） |
| 动态成员 | 可动态分配端口；也可基于 **MAC 地址**定义 |
| 802.1Q | Trunk 端口帧携带 **VLAN ID** |

### 802.1Q 帧格式

```
标准以太网帧 + 4 字节标签:
  TPID = 0x8100
  TCI: 3bit PCP + 1bit DEI + 12bit VLAN ID
  重新计算 CRC
```

### 跨交换机 VLAN

```
S1 端口 2,3,5 ─ EE VLAN    S2 端口 4,6,7,8 ─ EE VLAN
         ↕ trunk (802.1Q) ↕
干线端口转发带 VLAN ID 的帧
```

## MPLS（多协议标签交换）

| 要点 | 说明 |
|------|------|
| 目标 | 固定长度**标签**快速转发，替代 IP 最长前缀匹配 |
| 特点 | 借鉴虚电路；但 **IP 地址仍保留** |
| 路由器 | 标签交换路由器（LSR）仅查**标签**转发 |
| 灵活性 | 转发路径可与 IP 路由不同（**流量工程**） |
| 快速重路由 | 链路失效时用预计算备份路径 |

### MPLS vs IP 路径

```
IP 路由:   路径仅由目标地址决定
MPLS 路由: 入口路由器可基于源/目标 IP 等选不同标签路径
```

### MPLS 信令

- 修改 OSPF/IS-IS 泛洪携带带宽等信息
- 入口路由器用 **RSVP-TE** 在下游设置 MPLS 转发

### MPLS 转发表（示例）

```
入标签 → 出标签, 目的, 出接口
10 → 6, A, 1
12 → 9, D, 0
```

## 数据中心网络

### 规模与挑战

- 1 万–10 万台主机，紧耦合
- 高可靠性、负载均衡、避免瓶颈

### 网元层次

```
服务器刀片 (20-40/机柜)
    ↕ 40-100Gbps
TOR 交换机 (Top-of-Rack，每机柜一个)
    ↕
Tier-2 交换机 (~16 TORs)
    ↕
Tier-1 交换机 (~16 Tier-2)
    ↕
边界路由器 → 外部网络
```

### 设计特点

| 特点 | 说明 |
|------|------|
| 多路径 | 阵列间丰富互联，增加吞吐和冗余 |
| 负载均衡 | 应用层路由（隐藏内部结构） |
| SDN | 内部广泛使用 SDN 管理 |
| 协议创新 | RoCE（RDMA over Ethernet）、ECN/DCTCP 拥塞控制 |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "未知 MAC" | **泛洪**（除进入端口） |
| "自学习依据" | **源 MAC + 进入端口** |
| "VLAN 间通信" | 需**路由器/三层交换** |
| "跨交换机 VLAN" | **802.1Q trunk** |
| "MPLS 查什么" | **标签**（非 IP 地址） |
| "交换机查什么" | **MAC 地址** |

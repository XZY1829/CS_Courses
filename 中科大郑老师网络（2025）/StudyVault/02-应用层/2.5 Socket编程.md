# Socket 编程（重要性: ★★）

#networking #application-layer #socket #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 目标 | 借助传输层 **Socket API** 构建 C/S 应用 |
| UDP | 无连接；sendto/recvfrom；每报文指定对方地址 |
| TCP | 面向连接；connect/accept；welcome + connection Socket |
| 示例 | 客户端发字符串 → 服务器转大写 → 返回 |

## Socket 概念回顾

Socket = 分布式应用进程之间的"**门**"，由 OS 控制，应用开发者通过 API 使用。

```
Internet
  ┌─ OS 控制 ─┐         ┌─ OS 控制 ─┐
  │ App       │         │       App │
  │  ↕Socket  │         │  Socket↕  │
  │ Transport │         │ Transport │
  └───────────┘         └───────────┘
```

## 关键数据结构

### sockaddr_in

```c
struct sockaddr_in {
    short sin_family;      // AF_INET
    u_short sin_port;      // 端口号
    struct in_addr sin_addr; // IP 地址
    char sin_zero[8];      // 对齐
};
```

标识进程间通信的一个**端节点**（IP + Port）。

### hostent（DNS 解析结果）

```c
struct hostent {
    char *h_name;       // 主机域名
    char **h_aliases;   // 别名列表
    char **h_addr_list; // IP 地址列表
};
```

配合 `gethostbyname()` 将域名转为 IP，拷贝到 `sockaddr_in`。

## UDP Socket 编程

### 特点

- **无连接**：发送前无握手
- Socket 仅与本地 (IP, Port) 绑定
- 发送：`sendto()` 须显式指定对方端点
- 接收：`recvfrom()` 提取发送方端点
- 数据报可能**丢失或失序**

### 交互流程

```
客户端                              服务器
  │                                    │
  │ Socket()                           │ Socket()
  │ (隐式 bind 本地端口)                │ bind(serverSocket, port=x)
  │                                    │
  │ sendto(msg, 服务器IP:port) ────────→│ recvfrom() ← 提取客户端地址
  │                                    │ 处理（如转大写）
  │ recvfrom() ←───────────────────────│ sendto(reply, 客户端地址)
  │                                    │
  │ close()                            │ (循环等待)
```

### 客户端关键步骤

```c
clientSocket = Socket(PF_INET, SOCK_DGRAM, 0);
// 设置 sad: sin_family, sin_port, sin_addr (via gethostbyname)
sendto(clientSocket, Sentence, ..., &sad, addr_len);
recvfrom(clientSocket, modifiedSentence, ..., &sad, &addr_len);
close(clientSocket);
```

### 服务器关键步骤

```c
serverSocket = Socket(PF_INET, SOCK_DGRAM, 0);
sad.sin_addr.s_addr = INADDR_ANY;  // 监听所有接口
sad.sin_port = htons(port);
bind(serverSocket, (struct sockaddr *)&sad, sizeof(sad));
while(1) {
    recvfrom(serverSocket, clientSentence, ..., &cad, &addr_len);
    // 处理
    sendto(serverSocket, capitalizedSentence, ..., &cad, addr_len);
}
```

## TCP Socket 编程

### 特点

- **面向连接**：connect/accept 握手
- 服务器：**welcome Socket**（监听）+ **connection Socket**（通信）
- 一个端口可通过不同 connection Socket 服务多个客户端
- 可靠、保序的**字节流**

### 交互流程

```
客户端                              服务器
  │                                    │
  │ Socket()                           │ welcomeSocket = Socket()
  │ connect(服务器IP:port) ────────────→│ bind(welcomeSocket, port=x)
  │         TCP 三次握手                │ listen(welcomeSocket, 10)
  │                                    │ connectionSocket = accept() ← 阻塞解除
  │ write(request) ────────────────────→│ read(connectionSocket)
  │                                    │ 处理
  │ read(reply) ←──────────────────────│ write(connectionSocket, reply)
  │ close()                            │ close(connectionSocket)
  │                                    │ (循环 accept 下一客户端)
```

### 客户端关键步骤

```c
clientSocket = Socket(PF_INET, SOCK_STREAM, 0);
// 设置 sad (服务器 IP:port)
connect(clientSocket, (struct sockaddr *)&sad, sizeof(sad));  // 隐式 bind
write(clientSocket, Sentence, strlen(Sentence)+1);
read(clientSocket, modifiedSentence, sizeof(modifiedSentence));
close(clientSocket);
```

### 服务器关键步骤

```c
welcomeSocket = Socket(PF_INET, SOCK_STREAM, 0);
bind(welcomeSocket, (struct sockaddr *)&sad, sizeof(sad));
listen(welcomeSocket, 10);
while(1) {
    connectionSocket = accept(welcomeSocket, (struct sockaddr *)&cad, &alen);
    read(connectionSocket, clientSentence, ...);
    // 处理
    write(connectionSocket, capitalizedSentence, ...);
    close(connectionSocket);
}
```

### TCP 连接建立（课件时序）

```
服务器:                          客户端:
1. 运行                          1. 运行
2. welcome Socket bind 80        2. C_Socket bind 本地端口
3. accept() 阻塞等待             3. connect(服务器:80) 阻塞
4. accept 返回 connection Socket 4. connect 解除阻塞
5. 通过 connection Socket 收发   5. 通过 C_Socket 收发
```

> [!warning]
> 一个 TCP Port 上可以有**多个** connection Socket（不同客户端源 IP:Port 区分）。

## UDP vs TCP 编程对比

| | UDP | TCP |
|---|-----|-----|
| Socket 类型 | SOCK_DGRAM | SOCK_STREAM |
| 连接 | 无（sendto/recvfrom） | connect/accept |
| 服务器 Socket | 1 个 serverSocket | welcomeSocket + connectionSocket |
| 地址指定 | 每报文显式指定 | connect 时指定 |
| 可靠性 | 不保证 | 可靠字节流 |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "UDP 服务器第一步" | Socket → **bind** → recvfrom 循环 |
| "TCP 服务器 Socket 两个" | **welcomeSocket**（监听）+ **connectionSocket**（通信） |
| "TCP 客户端关键调用" | Socket → **connect** → write/read |
| "gethostbyname 作用" | **域名→IP**，填入 sockaddr_in |
| "UDP 为何 sendto" | 无连接，每报文须指定**对方地址** |

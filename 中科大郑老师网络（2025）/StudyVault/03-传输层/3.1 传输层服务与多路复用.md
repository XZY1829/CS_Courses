# 传输层服务与多路复用（重要性: ★★★）

#networking #transport-layer #multiplexing #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 传输层服务 | 为**进程间**提供逻辑通信（非主机间） |
| 运行位置 | **端系统**中；发送端分段、接收端重组 |
| 互联网协议 | **TCP**（可靠字节流）与 **UDP**（无连接数据报） |
| 多路复用 | 发送方：多 socket → 一个传输层实体 |
| 解复用 | 接收方：根据头部字段将段交付给正确 socket |

## 传输层服务

传输层为不同主机上运行的**应用进程**提供它们之间的**逻辑通信**。传输层协议在端系统中运行：

- **发送方**：将应用层报文分割成**报文段**，确定头部信息，交给 IP
- **接收方**：从 IP 收到段，检查头部，解封装后通过 **socket** 交给应用进程

互联网可用的两个传输层协议：**TCP** 和 **UDP**。

| 协议 | 特点 |
|------|------|
| **TCP** | 可靠、保序（字节流）、拥塞控制、流量控制、连接建立 |
| **UDP** | 不可靠、不保序（数据报）、不在 IP 尽力而为服务上扩展 |
| **二者均不提供** | 延迟保证、带宽保证、安全保证 |

## 传输层 vs 网络层

| 层次 | 通信对象 | 类比（家庭通信） |
|------|----------|------------------|
| **网络层** | **主机**之间 | 邮政服务 |
| **传输层** | **进程**之间 | 屋内负责复用/解复用的 Ann 和 Bill |

传输层**依赖**网络层，并**加强**其服务：

| 可加强的服务 | 不可加强的服务 |
|--------------|----------------|
| 不可靠 → **可靠**、安全 | **带宽**、**延迟** |

## 多路复用与解复用

**多路复用（Multiplexing）**：发送端多个 socket 的数据由传输层实体统一处理，加上传输层头部后交给网络层。

**解复用（Demultiplexing）**：接收端根据段头部信息，将数据交付给正确的 socket。

```
发送方多路复用:                    接收方解复用:
  P1 ─┐                              ┌─→ P2 (socket)
  P2 ─┼→ [传输层] → IP 段           IP 段 → [传输层] ─┤
  P3 ─┘                              └─→ P4 (socket)
```

### 解复用工作原理

主机收到 IP 数据报 → 每个数据报携带传输层段 → 每个段含**源端口**和**目的端口** → 主机用 IP 地址 + 端口号确定交付目标。

| 协议 | 解复用键 | 说明 |
|------|----------|------|
| **UDP** | **二元组**：目的 IP + **目的端口号** | 同目的端口的不同源 IP/源端口 → 同一 socket |
| **TCP** | **四元组**：源 IP、源端口、目的 IP、目的端口 | 同端口可支持多个连接，每连接独立 socket |

### UDP 无连接解复用

创建 socket 时必须指定**本地端口号**。接收时检查**目的端口号**，导向对应 socket。发送时必须指定**目标 IP** 和**目标端口号**。

> [!warning]
> 只要具有相同**目的端口号**的 UDP 数据报，即使源 IP/源端口号不同，都会被导向接收主机的**同一个** socket。

### TCP 面向连接解复用

TCP socket 由**四元组**标识；服务器在同一端口上可同时支持多个 socket，每个对应不同远程客户端。解复用使用全部 4 个值。

## 端口号

| 范围 | 用途 |
|------|------|
| 0–1023 | **熟知端口**（well-known），如 HTTP 80、DNS 53 |
| 1024–49151 | 注册端口 |
| 49152–65535 | 动态/私有端口 |

Socket 地址结构（`sockaddr_in`）：`sin_family` + `sin_port` + `sin_addr`（IP）。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "传输层 vs 网络层通信对象" | 网络层=**主机**；传输层=**进程** |
| "UDP 解复用依据" | **目的 IP + 目的端口号**（二元组） |
| "TCP 解复用依据" | **四元组**（源/目的 IP + 源/目的端口） |
| "传输层可加强什么" | **可靠性**；不可加强**带宽/延迟** |
| "TCP/UDP 都不提供" | 延迟、带宽、安全保证 |

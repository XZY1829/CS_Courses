## Ch1 网络概述 → [[1.4 性能指标]]、[[1.5 协议层次与服务模型]]

| 概念 | 要点 |
|------|------|
| 分组交换 vs 线路交换 | 分组交换：统计复用、无预留；线路交换：FDM/TDM、有预留 → [[1.3 网络核心]] |
| 传输延时 | d_trans = L / R（L=分组长度, R=链路带宽） |
| 传播延时 | d_prop = d / s（d=链路物理长度, s=传播速度） |
| 节点总延时 | d_nodal = d_proc + d_queue + d_trans + d_prop |
| 流量强度 | La/R（L=分组长度, a=平均到达速率, R=链路带宽）→ 趋近1时延时趋于∞ |
| 端到端吞吐量 | min(R1, R2, ..., Rn)，由**瓶颈链路**决定 |
| 五层协议栈 | 应用→传输→网络→链路→物理 → [[1.5 协议层次与服务模型]] |

### 必知公式

| 公式 | 说明 |
|------|------|
| `d_trans = L / R` | 传输延时 |
| `d_prop = d / s` | 传播延时（s ≈ 2×10⁸ m/s 铜线, 3×10⁸ m/s 光纤） |
| `存储转发延时 = N × L/R` | N 条链路上端到端延时（忽略传播和排队） |

## Ch2 应用层 → [[2.2 HTTP协议]]、[[2.3 Email与DNS]]

| 概念 | 要点 |
|------|------|
| HTTP 非持久连接响应时间 | **2RTT + 文件传输时间**（每个对象） → [[2.2 HTTP协议]] |
| HTTP/1.1 流水线 | 所有被引用对象在 1 RTT 内请求完毕 |
| HTTP/2 | 多路复用（单TCP连接中交替传送帧）、服务器推送 |

| P2P 分发时间 | max{F/u_s, F/d_min, NF/(u_s + Σu_i)} → [[2.4 P2P与CDN]] |

## Ch3 传输层 → [[3.3 可靠数据传输原理]]、[[3.6 拥塞控制]]

| 概念 | 要点 |
|------|------|
| UDP 解复用 | 目的 IP + 目的端口（**二元组**） → [[3.1 传输层服务与多路复用]] |
| TCP 解复用 | 源IP + 源端口 + 目的IP + 目的端口（**四元组**） |
| rdt 演进 | 1.0(可靠信道) → 2.0(+校验和/ACK/NAK) → 2.1(+序号) → 2.2(ACK带序号) → 3.0(+定时器) |
| 停等协议利用率 | U = L/R / (RTT + L/R) → [[3.3 可靠数据传输原理]] |
| GBN vs SR | GBN：累积确认、全部重传；SR：逐个确认、选择重传 |
| TCP 超时计算 | EstRTT = (1-α)×EstRTT + α×SampleRTT（α=0.125） |
|  | DevRTT = (1-β)×DevRTT + β×\|SampleRTT-EstRTT\|（β=0.25） |
|  | TimeoutInterval = EstRTT + 4×DevRTT |
| 快速重传 | 收到 **3 个冗余 ACK** → 立即重传 |
| rwnd 流量控制 | rwnd = RcvBuffer - [LastByteRcvd - LastByteRead] → [[3.5 TCP可靠传输与流量控制]] |

### TCP 拥塞控制关键值 → [[3.6 拥塞控制]]

| 阶段 | cwnd 变化 | 触发条件 |
|------|-----------|----------|
| 慢启动 (SS) | 每 ACK cwnd += 1 MSS（指数增长） | cwnd < ssthresh |
| 拥塞避免 (CA) | 每 RTT cwnd += 1 MSS（线性增长） | cwnd ≥ ssthresh |
| 超时 | ssthresh = cwnd/2, cwnd = 1 MSS | 超时事件 |
| 3冗余ACK (Reno) | ssthresh = cwnd/2, cwnd = ssthresh + 3 → 快恢复 | 3 dup ACK |
| 3冗余ACK (Tahoe) | ssthresh = cwnd/2, cwnd = 1 MSS → 慢启动 | 3 dup ACK |

## Ch4 网络层-数据平面 → [[4.3 IP协议与编址]]、[[4.2 路由器结构]]

| 概念 | 要点 |
|------|------|
| 转发 vs 路由 | 转发=数据平面（本地）；路由=控制平面（全局） → [[4.1 网络层概述]] |
| 最长前缀匹配 | 多条匹配时选最长前缀 → [[4.2 路由器结构]] |
| 三种交换机构 | 内存 < 总线 < 交叉开关（crossbar） |
| IP 分片 | MTU 限制；fragflag=1 表示后面还有分片；offset = 字节偏移/8 |
| CIDR 记法 | a.b.c.d/x，x = 网络前缀位数 → [[4.3 IP协议与编址]] |
| 子网主机数 | 2^(32-x) - 2（减去网络地址和广播地址） |
| NAT | 内网私有地址 ↔ 公网地址+端口映射 → [[4.4 NAT与IPv6]] |
| IPv6 | 128位地址、固定40字节头部、无分片、无校验和 |

### 调度策略对比 → [[4.2 路由器结构]]

| 策略 | 特点 |
|------|------|
| FCFS/FIFO | 先到先服务 |
| 优先权 | 按类别排队，高优先级先发 |
| Round Robin | 循环服务各类队列 |
| WFQ | 加权 RR，类 i 获得 wi/Σwj 的带宽份额 |

## Ch5 网络层-控制平面 → [[5.1 路由算法]]、[[5.3 域间路由-BGP]]

| 概念 | 要点 |
|------|------|
| Dijkstra (LS) | 全局算法，O(n²)，每轮选最小代价未确认节点 → [[5.1 路由算法]] |
| Bellman-Ford (DV) | Dx(y) = min_v{c(x,v) + Dv(y)}，分布式迭代 |
| 无穷计数 | DV 的坏消息传播慢 → 毒性逆转（部分解决） |
| OSPF | 域内路由、LS 算法、层次化（区域/骨干） → [[5.2 域内路由-OSPF]] |
| BGP 路由选择 | 本地偏好 > 最短 AS-PATH > 最近 NEXT-HOP（热土豆） > BGP ID → [[5.3 域间路由-BGP]] |
| eBGP vs iBGP | eBGP：跨 AS 边界；iBGP：AS 内部传播外部路由 |

## Ch6 数据链路层 → [[6.2 多路访问协议]]、[[6.3 MAC地址与ARP]]

| 概念 | 要点 |
|------|------|
| CRC 计算 | 数据 D 后附 r 个零 → 除以生成多项式 G → 余数即 CRC → [[6.1 链路层导论与检错纠错]] |
| 时隙 ALOHA 效率 | 最大 1/e ≈ 37%；纯 ALOHA：1/(2e) ≈ 18% → [[6.2 多路访问协议]] |
| CSMA/CD 效率 | 1 / (1 + 5t_prop/t_trans) |
| 二进制指数退避 | 第 m 次碰撞：K ∈ {0,1,...,2^m-1}，等待 K×512 位时 |
| MAC 地址 | **48 位**，烧录在 NIC 中，全球唯一 → [[6.3 MAC地址与ARP]] |
| ARP | 同子网：广播 ARP 请求 → 单播 ARP 响应 |
| 以太网帧 | 前导码(8B) + 目的MAC(6B) + 源MAC(6B) + 类型(2B) + 数据(46-1500B) + CRC(4B) |
| 交换机 vs 路由器 | 交换机：L2、自学习、MAC 表；路由器：L3、路由算法、IP 表 → [[6.5 交换机与VLAN]] |

## Ch7 无线与移动网络 → [[7.2 WiFi-802.11]]、[[7.4 移动性管理]]

| 概念 | 要点 |
|------|------|
| SNR vs BER | SNR↑ → BER↓；高 SNR 可用高速调制 → [[7.1 无线网络概述]] |
| 隐藏终端 | A→B, C→B，A/C 互不可闻 → 需 RTS-CTS |

## Ch8 网络安全 → [[8.1 加密原理]]、[[8.4 安全协议]]

| 概念 | 要点 |
|------|------|
| 对称 vs 非对称 | 对称：共享密钥（DES/AES），快；非对称：公钥/私钥（RSA），慢 → [[8.1 加密原理]] |
| RSA | n=pq, z=(p-1)(q-1), ed mod z=1, 加密: c=m^e mod n, 解密: m=c^d mod n |
| 认证协议漏洞 | ap1.0(伪装) → ap2.0(IP欺骗) → ap3.0(重放) → ap4.0(需共享密钥) → ap5.0(中间人) → [[8.2 认证与数字签名]] |
| 数字签名 | 私钥签名 K⁻(H(m))，公钥验证 K⁺ → [[8.2 认证与数字签名]] |
| CA 证书 | 将实体公钥与身份绑定，由 CA 用 CA 私钥签名 → [[8.3 密钥管理与证书]] |
| TLS | 握手（证书+密钥协商）→ 密钥派生 → 数据传输（对称加密+MAC）→ 关闭 → [[8.4 安全协议]] |
| IPSec | 传输模式：保护载荷；隧道模式：保护整个原始 IP 数据报 |
| 防火墙类型 | 无状态（ACL）、有状态（跟踪连接）、应用网关 → [[8.5 防火墙与IDS]] |

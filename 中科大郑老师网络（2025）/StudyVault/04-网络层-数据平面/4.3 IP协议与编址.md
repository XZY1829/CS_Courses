# IP 协议与编址（重要性: ★★★）

#networking #network-layer #ip #addressing #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| IP 地址 | 32 位，标识**接口**（非主机） |
| 编址演进 | 有类地址 → **CIDR**（无类域间路由） |
| 子网 | 相同地址前缀的设备，无需路由器可达 |
| 转发算法 | (IP Des addr) & mask == destination |
| DHCP | 动态获取 IP、网关、DNS、子网掩码 |

## IP 数据报格式

```
 0                   16                  31
+--+-+---+-----+-----+-------------------+
|ver|头长| TOS |      总长度 (16)       |
+--+-+---+-----+-----+-------------------+
|        标识 (16)    |标志| 片偏移(13)  |
+-----+-----+-----+-----+-----------------+
|  TTL(8)  | 协议(8)|    头部校验和(16)  |
+-----+-----+-----+-----+-----------------+
|           源 IP 地址 (32)              |
+---------------------------------------+
|          目的 IP 地址 (32)             |
+---------------------------------------+
|        选项 (若有) + 数据 (载荷)        |
+---------------------------------------+
```

| 字段 | 含义 |
|------|------|
| **版本/头长** | IPv4=4；头长以 4 字节为单位 |
| **TOS** | diffserv(0:5)、**ECN**(6:7) |
| **总长度** | 数据报总字节数（最大 64K，典型 ≤1500） |
| **标识/标志/片偏移** | **分片与重组** |
| **TTL** | 每经一跳减 1，为 0 则丢弃 |
| **协议** | 上层协议（6=TCP，17=UDP） |
| **头部校验和** | 仅校验头部 |
| **源/目的 IP** | 各 32 位 |

典型开销：20B IP 头 + 20B TCP 头 = 40B + 应用数据。

## IP 分片与重组

- 链路 **MTU** 限制最大帧载荷
- 大 IP 数据报需**分片**；各片独立传输；**目标端重组**
- 标识符、标志（MF/DF）、片偏移（以 8 字节为单位）用于标识和排序

**例子**：4000 字节数据报，MTU=1500 → 3 片（1480+1480+1040 载荷）

```
片1: ID=x, offset=0,   fragflag=1, len=1500
片2: ID=x, offset=185, fragflag=1, len=1500  (1480/8=185)
片3: ID=x, offset=370, fragflag=0, len=1040
```

> [!warning]
> IPv6 **不支持**路由器分片/重组；仅源端可分片。

## IPv4 编址

- **IP 地址**：32 位，标识主机/路由器的**接口**
- **点分十进制**：如 223.1.1.1 = 11011111.00000001.00000001.00000001

### 子网

- **子网**：无需路由器介入即可直接到达的设备集合；**相同地址前缀**
- 结构：**子网部分**（高位）+ **主机部分**（低位）
- 表示：223.1.1.0/24（前 24 位为子网号）

### 有类地址（历史）

| 类别 | 网络数 | 主机数 |
|------|--------|--------|
| **A** | 126 | 16M |
| **B** | 16382 | 64K |
| **C** | 2M | 254 |
| **D** | 多播 | — |
| **E** | 预留 | — |

### CIDR（Classless Inter-Domain Routing）

- 任意长度子网前缀：**a.b.c.d/x**（x = 子网部分 bit 数）
- 例：200.23.16.0/23

### 子网掩码

| 表示 | 含义 |
|------|------|
| **点分十进制** | 1=子网位，0=主机位 |
| **/x 前缀** | 前 x 位为子网部分 |

| 有类 | 默认掩码 |
|------|----------|
| A | 255.0.0.0 (/8) |
| B | 255.255.0.0 (/16) |
| C | 255.255.255.0 (/24) |

### 特殊地址

| 约定 | 含义 |
|------|------|
| 子网部分全 0 | 本网络 |
| 主机部分全 0 | 本主机 |
| 主机部分全 1 | **广播**地址 |

### 专用（内网）地址

| 范围 | 掩码 |
|------|------|
| 10.0.0.0–10.255.255.255 | /8 |
| 172.16.0.0–172.31.255.255 | /12 |
| 192.168.0.0–192.168.255.255 | /24 |

路由器**不转发**目的为专用地址的分组。

## 转发算法

对每个转发表项：
\[
(\text{IP Des addr}) \ \& \ (\text{mask}) == \text{destination}
\]
匹配则按接口转发；均无匹配则用**默认路由**。

配合**最长前缀匹配**选最优表项。

## DHCP

**Dynamic Host Configuration Protocol**：主机加入网络时动态获取 IP。

### 四步交互

```
1. 客户端广播 DHCP discover  (src:0.0.0.0:68 → dest:255.255.255.255:67)
2. 服务器广播 DHCP offer     (含 yiaddr=分配的 IP, lifetime)
3. 客户端广播 DHCP request   (请求使用该 IP)
4. 服务器广播 DHCP ack       (确认)
```

步骤 1-2 可跳过（客户端记住之前地址时 [RFC 2131]）。

### DHCP 不仅分配 IP

| 返回信息 | 说明 |
|----------|------|
| **IP 地址** | 子网内分配 |
| **默认网关** | 第一跳路由器地址 |
| **DNS 服务器** | 域名和 IP |
| **子网掩码** | 网络号/主机号划分 |

DHCP 服务器通常与**路由器捆绑**，服务其连接的所有子网。

### 层次编址与路由聚集

ISP 获得地址块（如 200.23.16.0/20）后划分给各组织（/23）。**路由聚集**使上游只需一条前缀路由，减少全球路由表规模。

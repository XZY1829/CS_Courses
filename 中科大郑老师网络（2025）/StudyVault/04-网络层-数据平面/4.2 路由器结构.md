## 路由器四大组件

```
        ┌─────────────────────────────────────┐
        │         路由处理器 (软件)            │
        │    路由、管理、控制平面              │
        └─────────────────────────────────────┘
  输入端口 ──→ [ 交换机构 switching fabric ] ──→ 输出端口
  (线速查表)         (高速转发)              (排队+调度)
```

| 组件 | 功能 | 时间尺度 |
|------|------|----------|
| **输入端口** | 物理/链路层接收；查转发表；输入排队 | 数据平面（硬件） |
| **交换机构** | 将分组从输入缓冲转到输出端口 | 数据平面 |
| **输出端口** | 缓冲、调度、链路层发送 | 数据平面 |
| **路由处理器** | 运行路由协议、SDN 通信、管理 | 控制平面（软件） |

### 输入端口功能

1. **物理层**：比特级接收
2. **链路层**：如 Ethernet 帧解封装
3. **查表转发**：根据头部在转发表中查找输出端口（**匹配+行动**）
4. **输入排队**：到达速率 > 交换速率时排队

目标：以**线速**完成处理。

### 最长前缀匹配

给定目的 IP，在转发表中查找时使用**最长前缀匹配（LPM）**：

```
转发表:
  11001000 00010111 00010***  → 接口 0
  11001000 00010111 00011000  → 接口 1
  11001000 00010111 00011***  → 接口 2
  otherwise                  → 接口 3

11001000 00010111 00011000 10101010 → 匹配接口 1（21 位前缀）
11001000 00010111 00010110 10100001 → 匹配接口 0（19 位前缀）
```

**硬件实现**：TCAM（三态内容可寻址存储器），一个时钟周期完成匹配（Cisco Catalyst 约 100 万条表项）。

## 三种交换机构

| 类型 | 原理 | 特点 |
|------|------|------|
| **经内存交换** | CPU 控制，分组拷入系统内存再拷出 | 受内存带宽限制；第一代路由器 |
| **经总线交换** | 共享总线连接输入/输出 | 总线竞争；32 Gbps 总线适合接入路由器 |
| **经互联网络** | Crossbar/Clos 等多级交换 | 并行性高；Cisco CRS 可达 100 Tbps |

**理想交换速率**：N 个输入端口时，交换速度 = 输入线路速度的 **N 倍**，避免成为瓶颈。

```
经总线:     输入 ──bus──→ 输出
经互联网:   输入 ──crossbar/Clos──→ 输出（多级并行）
```

## 输入/输出排队

### 输入端口排队

- 交换机构慢于输入组合速率 → **输入排队**
- **输出端口竞争**：同一时刻仅一个分组可转到某输出端口
- **HOL 阻塞（Head-of-the-Line）**：队头分组被阻塞，阻止后面分组前进（即使目标端口不同）

```
队列: [红→port2] [绿→port3] [蓝→port3]
       ↑ 红色阻塞 → 绿色也被阻塞（HOL）
```

### 输出端口排队

- 交换机构到达速率 > 输出链路速率 → **输出缓冲**
- 缓存耗尽 → **分组丢失**
- 需**丢弃策略**和**调度策略**

### 缓存大小

**RFC 3439 经验规则**：
\[
\text{缓存大小} = \text{RTT} \times C
\]
例：C=10 Gbps，RTT=250ms → 2.5 Gbit 缓冲

**较新推荐**（N 个流）：
\[
\text{缓存大小} = \frac{\text{RTT} \times C}{\sqrt{N}}
\]

> [!warning]
> 缓存过大虽减少丢失，但增加延迟，影响实时应用和基于延迟的拥塞控制。

## 分组调度

| 策略 | 说明 |
|------|------|
| **FCFS/FIFO** | 先来先服务 |
| **优先级** | 分类排队；从最高优先级非空队列取 |
| **RR（轮询）** | 循环扫描各类队列，每类取一个 |
| **WFQ（加权公平队列）** | 泛化 RR；类型 i 权重 w_i，获得 w_i/Σw_j 的服务量 |

**缓存管理**：丢弃（满时丢哪个）、优先级（基于优先级丢弃/标记 ECN/RED）。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "路由器四大组件" | 输入端口、**交换机构**、输出端口、**路由处理器** |
| "最长前缀匹配" | 选**最长**匹配前缀的表项 |
| "HOL 阻塞" | 队头分组阻塞导致**后续分组**无法前进 |
| "三种交换机构" | 经**内存**、经**总线**、经**互联网络** |
| "理想交换速率" | 输入线路速度 × **N**（N=端口数） |
| "缓存大小经验公式" | **RTT × C**（或 RTT×C/√N） |

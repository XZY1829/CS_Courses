# NAT 与 IPv6（重要性: ★★★）

#networking #network-layer #nat #ipv6 #addressing #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| NAT | 本地专用地址 ↔ 单一公网 IP+端口 |
| NAT 表 | (内网IP,内网端口) ↔ (外网IP,新端口) |
| IPv6 | 128 位地址；固定头；无校验和/分片/选项 |
| 过渡 | **隧道**：IPv6 载荷封装在 IPv4 数据报中 |
| 争议 | 违反端到端原则，但已广泛部署 |

## NAT 工作原理

**Network Address Translation**：从外界看，本地网络所有设备共享**一个 IPv4 公网地址**。

```
本地网络 10.0.0/24                    Internet
  10.0.0.1 ─┐
  10.0.0.2 ─┼─ [NAT 路由器] ──────── 138.76.29.7 (公网)
  10.0.0.3 ─┘     转换表
```

### NAT 路由器必须（透明地）

| 方向 | 动作 |
|------|------|
| **外出** | 替换（源 IP, 源端口）→（NAT 外网 IP, **新端口**）；记入转换表 |
| **进入** | 查表，将（目标外网 IP, 新端口）→（源内网 IP, 源端口） |

### 示例

```
1. 内网 10.0.0.1:3345 → 128.119.40.186:80
2. NAT 改为 138.76.29.7:5001 → 128.119.40.186:80
   表项: 138.76.29.7,5001 ↔ 10.0.0.1,3345
3. 响应到达 138.76.29.7:5001
4. NAT 改回 10.0.0.1:3345
```

### NAT 好处

| 好处 | 说明 |
|------|------|
| 地址节约 | 只需 ISP 分配 **1 个**公网 IP |
| 灵活 | 内网地址变更无需通知外界 |
| 换 ISP | 外网地址变，内网不变 |
| 安全 | 内网设备不可被外界直接寻址 |

### NAT 争议

| 争议点 | 说明 |
|--------|------|
| 层次违规 | 路由器"应"只处理 ≤3 层，**端口是 4 层** |
| 端到端原则 | 复杂性应在边缘，NAT 在网络层改端口 |
| 地址短缺 | 应由 **IPv6** 解决 |
| NAT 穿越 | 客户端主动连 NAT 后服务器困难 |

> [!warning]
> NAT 备受争议但已是**事实标准**——广泛存在于家庭、机构、4G/5G 网络。

## IPv6

### 动机

- 32 位 IPv4 地址空间**已耗尽**（ICANN 2011 年分配完最后一块）
- 固定长度头部 → 加速处理与转发
- 支持对"流"的不同网络层处理

### IPv6 数据报格式

```
 0                   16                  31
+--+-+-+-+-----+-----+-------------------+
|ver|pri| 流标签(20)  | 载荷长度(16)     |
+--+-+-+-+-----+-----+-------------------+
| 下一头部(8) | 跳限制(8)|               |
+-----+-----+---------------------------+
|        源地址 (128 bits)                |
+---------------------------------------+
|        目的地址 (128 bits)              |
+---------------------------------------+
|              载荷 (数据)               |
+---------------------------------------+
```

| 与 IPv4 对比 | IPv6 变化 |
|--------------|-----------|
| 地址 | **128 位** |
| 校验和 | **无**（加速路由器处理） |
| 分片/重组 | **无**（路由器不分片） |
| 选项 | **无**（通过"下一头部"链扩展） |

### IPv4 到 IPv6 过渡：隧道技术

无法所有路由器同时升级 → **隧道（Tunneling）**：

```
IPv6 路由器 A ──→ [IPv4 网络] ──→ IPv6 路由器 F

B→C 段: IPv6 数据报封装在 IPv4 数据报载荷中
        (IPv6 inside IPv4)
```

- 隧道端路由器将 IPv6 数据报作为 IPv4 **有效载荷**封装
- 中间 IPv4 路由器仅看到 IPv4 外层
- 4G/5G 等环境也广泛使用隧道

**注意**：封装后外层 IPv4 源/目的地址是隧道端点，内层 IPv6 源/目的不变。

### IPv6 部署

- Google：约 30% 客户端通过 IPv6 访问
- 部署缓慢（25+ 年），NAT 缓解了 IPv4 压力

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "NAT 转换什么" | **(源IP,源端口) ↔ (外网IP,新端口)** |
| "NAT 为何争议" | 路由器处理**4层端口**；违反**端到端** |
| "IPv6 地址长度" | **128 位** |
| "IPv6 相对 IPv4 去掉" | 校验和、分片、选项 |
| "IPv4→IPv6 过渡" | **隧道**（IPv6 封装在 IPv4 中） |
| "专用地址范围" | 10/8, 172.16/12, 192.168/16 |

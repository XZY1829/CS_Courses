# Internet 与协议（重要性: ★★★）

#networking #overview #internet #protocol #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 构成视角 | 节点（主机+交换设备）+ 边（链路）+ 协议 |
| 服务视角 | 为分布式应用提供传输层编程接口（Socket） |
| 协议定义 | 报文格式、次序、发送/接收动作的规则 |
| 标准化 | **RFC** 文档；**IETF** 制定 Internet 标准 |

## Internet：从具体构成角度

Internet 是"**网络的网络**"——互联的 ISP 构成全球基础设施。

| 组件 | 说明 |
|------|------|
| **端系统（主机）** | 数以亿计互联计算设备，在边缘运行网络应用 |
| **分组交换设备** | 路由器、交换机、SDN 交换机，转发分组（数据块） |
| **通信链路** | 光纤、同轴电缆、无线电、卫星；**传输速率 = 带宽（bps）** |
| **网络** | 设备+链路的集合，由机构管理（家庭/企业/ISP/数据中心/内容提供商） |

```
mobile ─┐
home ───┼─ local/regional ISP ── tier-1 ISP ── content provider
enterprise┘                              │
                                    datacenter
```

## Internet：从服务角度

- **基础设施为应用提供服务**：Web、流媒体、Email、游戏、电商、社交媒体等
- **编程接口**：允许发送/接收进程使用 Internet **传输层**提供的服务（类似邮政：面向连接 vs 无连接）
- **应用交互方式**：**C/S** 或 **P2P**

## 什么是协议？

协议定义在两个或多个通信实体之间交换的**报文格式和次序**，以及在报文传输/接收或其他事件方面所采取的动作。

| 对比 | 人类协议 | 网络协议 |
|------|----------|----------|
| 示例 | "几点了？" → "2:00" | TCP 握手 → GET HTTP 请求 |
| 规则 | 发送特定格式消息；收到消息/事件时采取约定行动 | 同上，由软件实现 |

```
客户端                    服务器
  │── TCP connection request ──→│
  │←─ TCP connection response ─│
  │── GET http://... ──────────→│
  │←─ <file> ──────────────────│
```

## RFC 与标准化组织

| 术语 | 含义 |
|------|------|
| **RFC** | Request for Comments，Internet 标准文档 |
| **IETF** | Internet Engineering Task Force，制定 Internet 标准 |

协议无所不在：HTTP、TCP、IP、WiFi、4G、Ethernet 等各层次。

> [!warning]
> 并非所有协议都是开放标准。Skype 等使用**私有协议**；开放协议（HTTP、SMTP）由 RFC 定义，允许互操作。

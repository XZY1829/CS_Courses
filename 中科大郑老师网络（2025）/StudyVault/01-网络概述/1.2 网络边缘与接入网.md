# 网络边缘与接入网（重要性: ★★★）

#networking #overview #internet #isp #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 网络边缘 | 客户端 + 服务器（常部署在数据中心） |
| 接入网任务 | 将端系统连接到边缘路由器 |
| 接入类型 | 住宅（DSL/HFC）、企业、无线（WLAN/蜂窝）、数据中心 |
| 物理媒体 | 导引型（双绞线/同轴/光纤）vs 非导引型（无线） |

## 网络边缘：端系统

| 类型 | 特点 |
|------|------|
| **客户端** | PC、平板、手机、智能车、IoT 设备 |
| **服务器** | 常置于**数据中心**；提供文件存储、通用/智能计算 |

主机发送功能：将应用报文切分为**分组**（L bits），以速率 R bps 在接入网发送。

**传输延迟**（推出 L bits 到链路）：`d_trans = L/R`

## 接入网络

核心问题：**如何将端系统连接到边缘路由器？**

### 住宅接入

| 技术 | 特点 | 典型速率 |
|------|------|----------|
| **HFC（线缆）** | 混合光纤同轴；数据/TV 用 **FDM** 不同频段；上行**共享** | 下行 40 Mbps–1.2 Gbps；上行 30–100 Mbps |
| **DSL** | 复用已有电话线到 CO 的**独享**线路；语音/数据不同频段 | 下载 24–52 Mbps；上传 3.5–16 Mbps |
| **家庭网络** | cable/DSL modem → router/NAT/firewall → 有线 Ethernet + WiFi | LAN 1 Gbps；WiFi 54–9600 Mbps |

### 无线接入

| 类型 | 覆盖 | 速率 |
|------|------|------|
| **WLAN（WiFi）** | 建筑物内/周边 ~100 ft | 802.11a/b/g/n/ac/ax：11 Mbps–9.6 Gbps |
| **广域蜂窝（4G/5G）** | ~10 km | 10 Mbps–若干 Gbps |

### 企业接入网络

- 有线 + 无线混合；Ethernet 交换机 + 路由器
- Ethernet：100 Mbps / 1 Gbps / 10 Gbps
- 典型分层：终端层 → 接入层 → 汇聚层 → 核心层 → 出口区 + 数据中心

### 数据中心网络

- **高带宽链路**（10s–400s Gbps）连接成千上万台服务器
- 向外提供云计算和存储服务

## 物理媒体

| 类型 | 介质 | 特点 |
|------|------|------|
| **导引型** | 双绞线 TP | Cat5: 100M/1G；Cat6: 10G Ethernet |
| | 同轴电缆 | 双向、宽带、多频段信道（各 100s Mbps） |
| | **光纤** | 光脉冲传 bit；10s–Tbps；安全、低出错率、中继间隔远 |
| **非导引型** | 无线电磁波 | 广播、半双工；反射/遮挡/干扰；WiFi、4G/5G、蓝牙、卫星（270 ms 延迟） |

```
导引型:  [主机]══双绞线/光纤/同轴══[路由器]
非导引型: [主机] ~~~ 无线电 ~~~ [基站/AP]
```

> [!warning]
> 课件中 FDM 在接入网（HFC 多信道）和线路交换（电路复用）两处均出现，含义相同但应用场景不同。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "DSL vs HFC 带宽特性" | DSL **独享**线路；HFC 上行**共享** |
| "传输延迟公式" | **L/R**（L=分组长度 bits，R=链路速率 bps） |
| "光纤优势" | 高速、安全、低出错率、不受电磁噪声影响 |
| "WiFi 标准" | 802.11 系列 |
| "企业网络分层" | 终端→接入→汇聚→核心→出口 |

# 网络核心（重要性: ★★★）

#networking #overview #packet-switching #circuit-switching #isp #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 核心功能 | **路由**（全局路径）+ **转发**（本地交换） |
| 交换方式 | **分组交换**（Internet 采用）vs **线路交换**（传统电话） |
| 分组交换关键 | 存储转发、统计复用、排队/丢包 |
| ISP 结构 | 接入 ISP → 区域 ISP → Tier-1 ISP + IXP + 内容提供商 |

## 分组交换 vs 线路交换

| 对比项 | 线路交换 | 分组交换 |
|--------|----------|----------|
| 资源分配 | 端到端**预约/专用** | **按需共享**，传输时使用全部带宽 |
| 复用方式 | **FDM**（频段）或 **TDM**（时隙） | 无固定片，统计复用 |
| 连接建立 | 需要（时间长） | 不需要 |
| 适合场景 | 传统电话 | **突发数据**（计算机通信） |
| 缺点 | 空闲时资源浪费；不适合突发 | 可能**拥塞**（排队延迟、丢包） |

### FDM 与 TDM

```
FDM: 频率轴分割 ──[用户1频段][用户2频段][用户3频段]──
TDM: 时间轴分割 ──[时隙1][时隙2][时隙3][时隙1]...──
     各呼叫在专属时隙内使用链路全部频带
```

### 容量对比（课件例题）

- 1 Gbps 链路，每用户活跃时 100 Mb/s，10% 时间活跃
- **电路交换**：10 用户（每用户独占 100 Mb/s）
- **分组交换**：35 用户（同时 ≥10 用户活跃概率 < 0.04%）

> [!warning]
> 分组交换"胜利"是有条件的：过度使用会导致拥塞，需可靠传输协议和拥塞控制。

## 分组交换：存储转发

```
源 ──[L bits]──→ 路由器1 ──→ 路由器2 ──→ 目的
                  L/R        L/R        L/R
```

- **存储转发**：分组一段段传输，仅在传输时段占用链路资源
- 每跳传输延迟 = **L/R**
- 例：L=10 Kbits，R=100 Mbps → 一跳延迟 = 0.1 ms

## 排队与丢包

```
     A ──100Mb/s──→ [队列] ──1.5Mb/s──→ E
                    ↑
     B,C 输入速率 > 输出速率 → 排队
     队列满 → 分组丢弃（丢失）
```

## 路由与转发

| 功能 | 范围 | 说明 |
|------|------|------|
| **转发（forwarding）** | 本地 | 查**转发表**，将分组从输入链路转到输出链路 |
| **路由（routing）** | 全局 | **路由算法**决定源到目的的路径 |

## Internet / ISP 结构

Internet = "**网络的网络**"

```
演进过程:
  全互联 O(N²) 不可扩展
    → 全球中转 ISP（客户-提供商商业合约）
    → 竞争者互联（IXP peering）
    → 区域 ISP
    → 内容提供商自建网络（Google 等）
```

| 层级 | 说明 | 示例 |
|------|------|------|
| **Tier-1 ISP** | 国家级/国际覆盖，高带宽 | Level 3, Sprint, AT&T, NTT |
| **Regional ISP** | 区域差异化接入 | — |
| **Local/Access ISP** | 住宅/企业接入 | — |
| **IXP** | Internet Exchange Point，ISP 对等互联 | — |
| **Content Provider** | 自建网络，DC 间专网，绕过 Tier-1 | Google, Facebook |

分组穿越多个网络：Tier-1 ↔ Tier-2 ↔ Tier-3 ↔ local ISP。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "电路交换不适合计算机通信" | 建立时间长；**突发通信浪费**资源；空闲时片不可共享 |
| "FDM vs TDM" | FDM 分**频段**；TDM 分**时隙**，时隙内用全部频带 |
| "存储转发每跳延迟" | **L/R** |
| "排队何时发生" | 输入速率 > 输出链路速率 |
| "转发 vs 路由" | 转发=**本地**转发表；路由=**全局**路径算法 |
| "Tier-1 ISP" | 少量大型国家级/国际 ISP |

# 性能指标（重要性: ★★★）

#networking #overview #delay #throughput #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 节点总延迟 | d_nodal = d_proc + d_queue + d_trans + d_prop |
| 确定 vs 不确定 | 传输/传播/处理**确定**；排队**不确定** |
| 丢包 | 队列满 → 丢弃；可能重传或不重传 |
| 吞吐量 | 受**瓶颈链路**限制；min(Rs, Rc, R/N) |

## 四种延迟

```
A ═══════[处理][排队][传输][传播]═══════→ B
         d_proc d_queue d_trans d_prop
```

| 延迟 | 符号 | 公式/说明 | 特点 |
|------|------|-----------|------|
| **节点处理** | d_proc | 检查 bit 错误、决定输出链路 | 通常 < ms |
| **排队** | d_queue | 在输出链路等待传输 | 取决于拥塞程度，**不确定** |
| **传输** | d_trans | **L/R**（L=分组长度 bits，R=链路速率 bps） | 将 L bits **推入**链路的时间 |
| **传播** | d_prop | **d/s**（d=物理长度，s≈2×10⁸ m/s） | 比特在介质中**传播**的时间 |

> [!warning]
> **d_trans ≠ d_prop**：传输延迟是"推出"分组；传播延迟是比特在链路上的物理传播。二者 very different。

### 车队类比

- 10 辆车（10-bit 分组），收费站服务每车 12 秒（传输），100 km/h 传播
- 推完车队：12×10 = 120 秒；最后一辆车传播：60 分钟
- **总时间 ≈ 传输 + 传播 = 62 分钟**

若传播 6 分钟、传输 1 分钟/车：推完整个车队时间 > 头车到达第二收费站时间（Yes）。

## 排队延迟与流量强度

**流量强度** I = **La/R**

- a = 分组到达速率；L = 分组长度；R = 链路带宽
- **La/R ~ 0**：平均排队延迟很小
- **La/R → 1**：平均排队延迟很大
- **La/R > 1**：到达速率 > 服务速率，延迟**无限大**

## 丢包

- 路由器缓冲区容量**有限**
- 到达时分组队列已满 → **丢弃（丢失）**
- 丢失分组：前一节点/源节点**重传**，或**不重传**

## 吞吐量

- **定义**：源到目的穿过整个路径的 bit 速率（bps）
- **瞬间吞吐量** vs **平均吞吐量**

```
服务器(Rs) ════════ 链路 ════════ 客户端(Rc)
```

| 条件 | 平均端到端吞吐量 |
|------|------------------|
| Rs < Rc | **Rs** |
| Rs > Rc | **Rc** |

**瓶颈链路**：限制端到端吞吐量的路径上最慢链路。

### 多连接共享场景

10 个连接公平共享骨干链路 R：
- 每个连接吞吐量 = **min(Rc, Rs, R/10)**
- 通常 Rc 或 Rs 不是瓶颈

## 延时计算示例

N 跳路径，每跳链路速率 R，分组长度 L，忽略 d_proc 和 d_queue：

**端到端延迟 ≈ N × (L/R + d_prop)**

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "节点总延迟公式" | **d_proc + d_queue + d_trans + d_prop** |
| "传输延迟" | **L/R** |
| "传播延迟" | **d/s**，s≈2×10⁸ m/s |
| "不确定的延迟" | **排队延迟** |
| "流量强度" | **La/R** |
| "瓶颈链路" | 路径上**最小**带宽链路决定吞吐量 |
| "Rs=2Mbps, Rc=1Mbps" | 吞吐量 = **1 Mbps** |

# Day 01｜闭卷测试：复杂度、数组、链表与双指针

> 共 8 题，每题 10 分。先完整作答，再结束测试。

## 1｜复杂度推导

分析下列代码的时间复杂度，并写出求和过程，而不只写最终数量级。

```cpp
for (int i = 1; i <= n; i *= 2) {
    for (int j = 0; j < i; ++j) work();
}
```

## 2｜结构选择

某系统维护 50 万个元素，主要操作是按下标随机读取，偶尔在末尾追加；另一系统频繁在已知节点后插入，但几乎不随机访问。分别选择顺序表还是链表，并从理论复杂度、缓存局部性和额外空间三方面说明。

## 3｜链表追踪

对链表 `1→2→3→4→null` 执行原地反转。逐轮写出 `prev`、`curr`、暂存后继以及已经反转的链，并指出忘记暂存后继会造成什么后果。

## 4｜局部代码补全

补全有序数组去重的关键条件和写入语句，保证空数组可正确处理。

```cpp
int removeDuplicates(vector<int>& a) {
    if (__________) return 0;
    int slow = 1;
    for (int fast = 1; fast < a.size(); ++fast) {
        if (____________________) {
            ____________________;
        }
    }
    return slow;
}
```

## 5｜不变量

给定升序数组和目标值，使用左右指针求两数之和。写出循环开始时必须保持的不变量，以及为什么“和偏小移动左指针、和偏大移动右指针”不会漏掉可行解。

## 6｜边界与溢出

一个二分式循环使用 `mid=(left+right)/2`。说明什么时候可能出错，并给出更稳妥的写法。再列出链表删除倒数第 N 个节点时至少三个必须考虑的边界。

## 7｜均摊分析

动态数组容量每次翻倍。解释为什么 `push_back` 的均摊复杂度可以是 O(1)，但单次最坏复杂度仍是 O(n)。要求用一次扩容序列说明。

## 8｜压力追问

面试官说：“链表在已知位置插入是 O(1)，所以它一定比数组适合频繁插入。”请在 90 秒内反驳，至少讨论定位成本、内存分配、缓存命中和工程常数。

# Day 06｜闭卷测试：递归、回溯与搜索

> 共 8 题，每题 10 分。搜索题需明确状态、选择和恢复。

## 1｜递归四要素

以“翻转单链表”或“计算树高”为例，写出递归函数的定义、终止条件、规模缩小方式和返回值语义。指出只会写递归表达式但不定义返回语义的风险。

## 2｜全排列追踪

画出 `[1,2,3]` 全排列的搜索树。至少追踪一条完整路径中的 `choose → recurse → undo`，并说明为何必须撤销选择。

## 3｜重复元素去重

对 `[1,1,2]` 生成不重复排列。说明排序、`used` 数组以及“同层跳过”条件分别解决什么问题；给出错误跳过可能漏解的例子。

## 4｜网格代码补全

补全关键位置，目标是在单词搜索中当前路径失败后允许其他路径再次使用该格。

```cpp
bool dfs(int r, int c, int k) {
    if (____________________) return true;
    if (越界或字符不匹配或已访问) return false;
    ____________________;
    bool ok = dfs(r+1,c,k+1) || dfs(r-1,c,k+1)
           || dfs(r,c+1,k+1) || dfs(r,c-1,k+1);
    ____________________;
    return ok;
}
```

## 5｜DFS 与 BFS

对于无权迷宫最短步数，为什么 BFS 通常更直接？如果使用 DFS，需要增加什么机制才可能保证最短？比较二者空间风险。

## 6｜访问标记恢复

分别说明以下场景是否恢复 `visited`：图遍历判断连通；排列回溯；网格中每条路径不能重复格子但不同路径可以；有向图三色判环。每项都给理由。

## 7｜剪枝正确性

组合和候选均为正数且已排序。提出两个剪枝条件，说明它们为何不会漏解。若允许负数，哪些剪枝不再安全？

## 8｜压力追问

估算 n 个不同元素全排列的时间与递归深度。面试官要求优化时，区分“降低常数/剪枝”和“改变指数级本质”，说明不能做出的虚假承诺。

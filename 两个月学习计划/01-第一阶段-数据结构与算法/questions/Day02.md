# Day 02｜闭卷测试：栈、队列、哈希与窗口

> 共 8 题，每题 10 分。所有题完成前不要查资料。

## 1｜括号栈追踪

逐字符处理 `([{}])()`，写出每一步栈内容。然后对 `([)]` 指出首次能够判定失败的位置，以及为什么不能只比较左右括号总数。

## 2｜循环队列

数组容量为 5，采用“牺牲一个单元”区分队满与队空。写出队空、队满条件和最多可存元素数；从 `front=rear=0` 开始手推：入 A、B、C、D，出两次，入 E、F。

## 3｜哈希取舍

需要判断一个长度为 n 的整数数组是否存在重复元素。比较哈希表、排序后扫描和位图三种方案的时间、空间、适用前提与风险。

## 4｜滑动窗口追踪

对 `s="abba"` 手推最长无重复子串：每一步写出右端字符、左端位置、窗口内容和当前最优值。说明当第二个 `b` 出现时，左端为何不能无条件跳到旧位置加一。

## 5｜框架补全

补全“长度最小且和至少为 target 的连续子数组”核心循环，并写出这个框架成立所依赖的数组元素条件。

```cpp
for (int right = 0; right < n; ++right) {
    ____________________;
    while (____________________) {
        best = min(best, right - left + 1);
        ____________________;
        ++left;
    }
}
```

## 6｜单调栈识别

“对每个温度，找右侧第一个更高温度”为什么适合单调栈？说明栈中存值还是下标、保持何种单调性、每个元素最多进出栈几次。

## 7｜字符串匹配

朴素匹配在什么输入上容易退化？KMP 中前缀信息解决的核心浪费是什么？不要求写完整 KMP，但要解释失配后为什么不用把文本指针回退到本次起点之后一个位置。

## 8｜压力追问

面试官问：“`unordered_map` 查找不是 O(1) 吗？为什么线上仍可能很慢？”请从碰撞、负载因子、扩容、哈希质量、内存局部性和对抗输入中选至少四点回答。

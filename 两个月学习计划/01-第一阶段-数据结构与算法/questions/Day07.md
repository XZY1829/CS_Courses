# Day 07｜综合测试：DP、贪心与模式选择

> 共 14 题，每题 10 分。前 12 题闭卷书面完成，第 13、14 题进行压力口述。

## 1｜DP 四步法

为“打家劫舍”写出状态定义、转移方程、初始化和遍历顺序，并说明状态为何满足无后效性。

## 2｜记忆化与递推

比较朴素递归、记忆化搜索和自底向上 DP 在斐波那契问题上的调用/状态数量、额外空间和执行顺序。

## 3｜0/1 背包遍历顺序

一维数组优化 0/1 背包时，容量为什么通常倒序？用一个只有一件物品的最小例子说明正序会发生什么。

## 4｜完全背包

完全背包的一维容量为什么可以正序？它与 0/1 背包在“当前轮能否再次使用同一物品”上的含义有什么不同？

## 5｜贪心反例

硬币为 `[1,3,4]`，目标为 6。分析“每次选最大可用硬币”的结果，并用它说明贪心策略需要什么证明，而不能只凭直觉。

## 6｜模式选择：连续区间

从“滑动窗口、前缀和+哈希、动态规划、双指针”中为以下问题选择方法并写前提：全为正数的最短子数组和；可含负数的子数组和等于 K；最长无重复子串。

## 7｜模式选择：树

判断以下树题更偏自顶向下还是自底向上，并定义递归参数/返回值：验证路径和；求最大深度；求最大直径；验证 BST。

## 8｜模式选择：图

分别选择算法：岛屿数量、课程依赖判环、动态加入边后的连通性、非负权单源最短路。说明核心状态和复杂度。

## 9｜复杂度综合

比较以下方案：排序后双指针求三数之和；哈希求两数之和；大小为 K 的堆求 Top K；回溯枚举全排列。写时间、额外空间和主导因素。

## 10｜代码诊断

下面的二分代码试图找第一个大于等于 target 的位置。指出区间/更新上的问题，并修正核心部分。

```cpp
int l = 0, r = a.size() - 1;
while (l < r) {
    int m = (l + r) / 2;
    if (a[m] < target) l = m;
    else r = m - 1;
}
return l;
```

## 11｜不变量迁移

分别为链表反转、滑动窗口、单调栈、Dijkstra 写出一句核心不变量。要求表述能用于检查代码正确性。

## 12｜工程取舍

在理论复杂度相同的情况下，列出至少四个仍会影响数据结构/算法选择的因素，并各举一个例子。

## 13｜压力口述：陌生题拆解

面试官给出：“返回数组中最长连续序列的长度，要求 O(n)。”请不写完整代码，在 3 分钟内完成：澄清输入 → 排除排序方案 → 选择结构 → 定义遍历起点 → 证明不重复工作 → 复杂度与边界。

## 14｜压力口述：失败复盘

任选本周一道红题，在 3 分钟内完成：第一次为什么错 → 错误属于模式识别/不变量/边界/实现哪一类 → 正确方案 → 如何用最小反例自测 → 以后看到什么信号会触发正确模式。

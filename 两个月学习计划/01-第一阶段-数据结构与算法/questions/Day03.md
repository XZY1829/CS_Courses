# Day 03｜闭卷测试：树、BST 与堆

> 共 8 题，每题 10 分。画图和推演均计入作答。

## 1｜遍历与重建信息

给定二叉树层序 `[3,9,20,null,null,15,7]`，画树并写出前序、中序、后序和层序。再说明仅有前序为何通常不能唯一重建二叉树。

## 2｜递归返回值

求二叉树直径时，递归函数应该向父节点返回什么？全局结果在当前节点如何更新？解释为什么直接向父节点返回“当前子树最大直径”会丢失父节点所需信息。

## 3｜迭代遍历补全

补全中序遍历核心逻辑，并写出栈中元素在循环开始时代表什么。

```cpp
while (cur != nullptr || !st.empty()) {
    while (cur != nullptr) {
        __________;
        __________;
    }
    cur = st.top(); st.pop();
    visit(cur);
    __________;
}
```

## 4｜BST 合法性

构造一棵“每个节点都满足左孩子小、右孩子大，但整棵树不是合法 BST”的树。给出正确验证时需要携带的信息或利用的遍历性质。

## 5｜平衡的价值

同一组升序键依次插入普通 BST 和 AVL 树，树高可能分别是多少？搜索、插入的复杂度如何变化？AVL 为维持平衡付出什么代价？

## 6｜堆追踪

用大小为 3 的小顶堆维护数据流 `[5,1,9,3,7,8]` 中最大的 3 个值。每读入一个值后记录堆内容，并说明堆顶的语义。

## 7｜Top K 方案选择

从 1 亿个整数中找最大的 100 个，内存受限且数据以流形式到达。比较全排序、大小为 K 的堆和快速选择；选择一种并给出复杂度及理由。

## 8｜压力追问

“堆是完全二叉树且父节点有序，所以中序遍历会得到有序序列。”判断这句话，并用一个最小反例或性质说明。

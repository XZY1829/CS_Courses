# Day 06｜讲解与评分要点

> 对应测试与知识来源见 [Day 06 问题文件](../questions/Day06.md) 末尾的“本套题依据”。

## 1｜递归四要素

以树高为例：`height(node)` 返回以 node 为根的树高；空节点返回 0；问题缩小为左右子树；返回 `1+max(height(left),height(right))`。若返回语义不清，容易把“边数/节点数”、局部结果/全局结果混用，组合阶段失效。

## 2｜全排列追踪

根路径空，依次选择未使用的 1、2、3。路径 `[]→[1]→[1,2]→[1,2,3]` 记录后，撤销 3，再尝试其他选择；每层返回都要撤销当前层选择。否则状态会泄漏到兄弟分支，导致漏解或错误路径。

## 3｜重复元素去重

先排序让相同值相邻；`used[i]` 防止同一路径重复使用同一元素；条件 `i>0 && nums[i]==nums[i-1] && !used[i-1]` 跳过同一层的重复选择。若把 `!used[i-1]` 写反，会把同一路径中合法使用两个 1 的情况也跳过。

## 4｜网格代码补全

```cpp
if (k == word.size()) return true;
visited[r][c] = true;
// 四方向递归
visited[r][c] = false;
```

也可临时修改字符并恢复。访问标记必须在递归前设置、所有分支后恢复；时间最坏与分支数和单词长度指数相关，递归空间 O(L)。边界顺序要避免先访问越界位置。

## 5｜DFS 与 BFS

BFS 按层首次到达即最短，直接记录层数。DFS 首次到达不保证最短，必须枚举所有可行路径并维护最小值，配合剪枝/距离状态。BFS 可能保存整层，宽图空间大；DFS 主要保存递归深度，但深图有栈溢出风险。

## 6｜访问标记恢复

图连通遍历：不恢复，全局避免重复。排列：恢复，让兄弟分支可选。单词路径：恢复，不同候选路径可再次用格子。有向图三色判环：离开节点从“访问中”变“已完成”，不是简单清零；灰色回边判环，黑色表示无需重复搜索。

## 7｜剪枝正确性

正数且有序时：剩余目标 `<0` 可停止；当前候选已大于剩余目标时，后续更大候选也不可行，可 break。若允许负数，当前和超目标后仍可能被负数拉回，以上基于单调增长的剪枝不安全。

## 8｜压力追问

共有 n! 个输出，每个输出复制长度 n 时下界为 Ω(n·n!)；递归深度 O(n)，状态通常 O(n)。排序去重、上下界和可行性检查能减少实际分支，但一般不能把必须枚举全部排列的输出规模变成多项式。

## 评分

每题 10 分。第 3、6、7 题重点考状态隔离与剪枝安全性；若只背模板而不能解释为何恢复/不恢复，最多 5 分。

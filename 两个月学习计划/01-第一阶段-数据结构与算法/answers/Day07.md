# Day 07｜讲解与评分要点

> 对应测试与知识来源见 [Day 07 问题文件](../questions/Day07.md) 末尾的“本套题依据”。

## 1｜DP 四步法

定义 `dp[i]` 为只考虑前 `0..i` 间房屋可取得的最大金额；转移 `dp[i]=max(dp[i-1],dp[i-2]+nums[i])`；初始化首项和前两项；从左到右。未来决策只依赖已汇总的最优值，不需知道更早具体选择，满足无后效性。

## 2｜记忆化与递推

朴素递归重复计算，调用数量指数级、栈深 O(n)。记忆化每个状态一次，时间 O(n)，缓存 O(n)+栈 O(n)，按需求自顶向下。递推时间 O(n)，数组 O(n) 或滚动 O(1)，按依赖顺序自底向上。

## 3｜0/1 背包遍历顺序

倒序保证 `dp[c-w]` 仍来自上一轮物品。若一件重量 1、价值 2 的物品且容量 2，正序先更新 `dp[1]=2`，再用已更新的 `dp[1]` 得 `dp[2]=4`，等于同一件物品用了两次，违反 0/1 限制。

## 4｜完全背包

完全背包允许同一物品使用多次，容量正序使 `dp[c-w]` 可以包含当前物品，正好表达重复选择。0/1 背包必须阻止本轮值继续传播，因此倒序。

## 5｜贪心反例

目标 6，最大优先得到 `4+1+1` 共 3 枚；最优为 `3+3` 共 2 枚。贪心必须证明贪心选择性质与最优子结构，常用交换论证；一个局部看起来最大/最小的选择不自动保证全局最优。

## 6｜模式选择：连续区间

正数最短子数组和：可变长滑动窗口，依赖单调性。含负数且和等于 K：前缀和+哈希，查找此前是否出现 `prefix-K`。最长无重复子串：滑动窗口+最近位置/频次，左边界不后退。DP 和普通左右夹逼不自然。

## 7｜模式选择：树

路径和：自顶向下携带剩余和。最大深度：自底向上返回子树高度。最大直径：自底向上返回单边高度并更新全局。验证 BST：可自顶向下携带上下界，也可中序检查严格递增。

## 8｜模式选择：图

岛屿数量：DFS/BFS 染色，O(mn)。课程判环：拓扑排序 O(V+E) 或三色 DFS。动态加边连通：并查集，近似常数均摊。非负单源最短路：Dijkstra，堆优化约 O((V+E)logV)。

## 9｜复杂度综合

三数之和：排序 O(n log n)+枚举/双指针 O(n²)，主导 O(n²)，额外空间视排序而定。两数哈希：期望 O(n) 时间/O(n) 空间。Top K 小顶堆：O(n log K)/O(K)。全排列：输出规模 n!，通常 O(n·n!)/O(n) 路径空间（不计输出）。

## 10｜代码诊断

原代码 `l=m` 可能不收缩，`r=m-1` 又与寻找左边界的保留规则冲突。左闭右开写法：

```cpp
int l = 0, r = a.size();
while (l < r) {
    int m = l + (r - l) / 2;
    if (a[m] < target) l = m + 1;
    else r = m;
}
return l;
```

## 11｜不变量迁移

- 链表反转：`prev` 指向已反转前缀，`curr` 指向未处理后缀首节点。
- 滑动窗口：窗口内始终满足题设合法条件，左侧已排除位置不能产生更优合法窗口。
- 单调栈：栈保存尚未结算、并按指定值保持单调的下标。
- Dijkstra：已确定集合中的距离是最终最短距离；依赖非负边。

## 12｜工程取舍

缓存局部性（vector 常优于链表）、常数（小 n 插入排序）、内存上限（流式 Top K 用小堆）、稳定性（多关键字排序）、输入分布（快排枢轴退化）、是否在线（数据流不能整体快速选择）、实现可靠性和并发访问模式等。

## 13｜压力口述：陌生题拆解

用哈希集合存所有值。只从“没有前驱 `x-1`”的数开始向后扩展，避免每个序列被重复扫描；每个数最多作为序列成员访问有限次，期望 O(n) 时间/O(n) 空间。处理空数组、重复值、整数边界（检查 `x-1/x+1` 溢出）。若排序则 O(n log n)，不满足目标。

## 14｜压力口述：失败复盘

本题无唯一内容。合格口述必须包含：具体首次错误而非“粗心”；归类到可行动的错误类型；正确不变量/方案；一个能击穿旧方案的最小反例；未来触发信号。只复述正确代码但不解释迁移规则，最多 5 分。

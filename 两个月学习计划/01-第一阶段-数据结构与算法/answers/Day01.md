# Day 01｜讲解与评分要点

> 对应测试与知识来源见 [Day 01 问题文件](../questions/Day01.md) 末尾的“本套题依据”。

## 1｜复杂度推导

外层取 `1,2,4,...,2^k≤n`。总工作量为 `1+2+4+...+2^k=2^(k+1)-1<2n`，所以时间复杂度是 Θ(n)，不是 Θ(n log n)。每轮内层规模不同，不能简单相乘。

## 2｜结构选择

第一种选顺序表：随机访问 O(1)，尾部追加均摊 O(1)，连续内存缓存友好；扩容会有偶发 O(n)。第二种在“已知节点”前提下选链表：插入只改指针 O(1)，但每节点有指针开销、分配分散且缓存较差。若节点位置还需搜索，整体仍可能 O(n)。

## 3｜链表追踪

初始 `prev=null,curr=1`。每轮先存 `next=curr->next`，再令 `curr->next=prev`，最后 `prev=curr,curr=next`。四轮后 `prev` 指向 `4→3→2→1→null`。若先改指针而未存后继，将失去原链剩余部分的入口。

## 4｜局部代码补全

```cpp
if (a.empty()) return 0;
// ...
if (a[fast] != a[slow - 1]) {
    a[slow++] = a[fast];
}
```

不变量：`[0,slow)` 始终是已处理前缀的去重结果；`fast` 扫描尚未判断的元素。时间 O(n)，额外空间 O(1)。

## 5｜不变量

搜索区间 `[l,r]` 中仍包含所有尚未排除的可能配对。数组升序时，若 `a[l]+a[r]` 偏小，固定 `l` 与任何 `≤r` 元素的和都不会更大，因此 `l` 不可能参与可行解；偏大时同理可排除 `r`。前提是有序，若无序该单调性不存在。

## 6｜边界与溢出

`left+right` 可能超出整数范围，使用 `left+(right-left)/2`。删除倒数第 N 个节点要考虑：空链、删除头节点、N 等于长度、N 非法大于长度、单节点、快指针推进 N 步时为空。哑节点可统一删除头节点的逻辑。

## 7｜均摊分析

容量按 1、2、4、8 扩展，插入 n 个元素发生的搬移总数小于 `1+2+4+...+n/2<n`，再加 n 次写入，总成本 O(n)，平均到每次为 O(1)。触发扩容的那一次仍需搬移当前所有元素，所以最坏 O(n)。

## 8｜压力追问

O(1) 只描述“已知位置后改指针”。若需找到位置先 O(n)；每节点分配和指针增加空间；节点离散导致缓存未命中和预取困难；分配器/碎片/指针追踪有显著常数。元素较小且数组移动代价低时，连续数组频繁插入也可能更快。应依据完整操作链和数据规模实测，而非只看单项渐进复杂度。

## 评分

每题 10 分：核心结论 4 分，依据/不变量 3 分，复杂度或边界 3 分。第 1、5、7 题核心结论错误视为红题。

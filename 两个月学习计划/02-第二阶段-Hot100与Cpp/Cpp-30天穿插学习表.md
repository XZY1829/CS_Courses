# C++｜30 天穿插学习表（Day 8—37）

## 使用原则

C++ 已有基础，因此不重复语法入门。每天围绕一个面试主题形成一个可检查产出：对象布局图、生命周期追踪、最小代码、对比表或 3 分钟口述。算法任务较重时，C++ 只保留最小闭环；未完成产出不能只凭“看过”勾选。

## 每日任务

| 进度 | Day | 深入主题 | 必须产出与验收 |
|---|---:|---|---|
| [ ] | Day 8 | 对象、存储期与生命周期 | 区分自动、静态、线程、动态存储期；画一个对象从构造到析构的时间线 |
| [ ] | Day 9 | 栈、自由存储区与 RAII | 写一个资源类，说明构造获取、析构释放以及提前返回时的安全性 |
| [ ] | Day 10 | 左值/右值、引用折叠与移动 | 为 6 个表达式判断值类别；解释 `std::move` 本身不移动什么 |
| [ ] | Day 11 | Rule of 0/3/5 与拷贝控制 | 为拥有动态资源的类判断需定义哪些特殊成员；找出浅拷贝风险 |
| [ ] | Day 12 | `vector`/`deque`/`list` 布局 | 画出连续/分段/节点式存储；列出扩容和插删的失效规则 |
| [ ] | Day 13 | 迭代器与 `<algorithm>` | 用算法库改写一段手写循环；解释迭代器类别如何限制算法 |
| [ ] | Day 14 | 模板、`auto`、`decltype` | 写出 6 个类型推导结果；解释万能引用与普通右值引用的区别 |
| [ ] | Day 15 | 裸指针、观察者与所有权 | 给一段多指针代码标注 owner/observer；指出释放责任 |
| [ ] | Day 16 | `unique_ptr/shared_ptr/weak_ptr` | 画引用计数与弱引用图；用 `weak_ptr` 拆除循环引用 |
| [ ] | Day 17 | 异常安全保证 | 区分无抛出、强保证、基本保证；用 copy-and-swap 说明强保证 |
| [ ] | Day 18 | 分配、对齐、对象大小 | 用 `sizeof/alignof/offsetof` 做最小实验；解释 padding 来源 |
| [ ] | Day 19 | 虚函数、vptr 与动态绑定 | 画一个可能的对象布局；区分静态类型、动态类型和调用决议 |
| [ ] | Day 20 | 继承、多态与虚析构 | 构造通过基类指针删除派生对象的例子；说明何时必须虚析构 |
| [ ] | Day 21 | C++ 类型转换 | 为 `static/dynamic/const/reinterpret_cast` 各写一个合适或危险场景 |
| [ ] | Day 22 | lambda 与函数对象 | 写出捕获值/引用/this 的生命周期风险；比较 lambda 与 `std::function` 开销 |
| [ ] | Day 23 | `map/set` 与红黑树语义 | 说明有序性、复杂度、节点稳定性；选择三个使用场景 |
| [ ] | Day 24 | `unordered_map/set` | 解释桶、哈希、负载因子、rehash 与最坏退化；记录失效规则 |
| [ ] | Day 25 | `string/string_view` | 写出悬空 `string_view` 反例；区分拥有字符串与只读视图 |
| [ ] | Day 26 | 线程、数据竞争与 happens-before | 找出一段共享计数代码的数据竞争；说明为何“看起来原子”不等于安全 |
| [ ] | Day 27 | mutex、RAII 锁与死锁 | 写出 `lock_guard/scoped_lock` 版本；列出死锁四条件和规避顺序 |
| [ ] | Day 28 | 条件变量与原子 | 写出带谓词的等待循环；解释虚假唤醒和原子不等于复合操作安全 |
| [ ] | Day 29 | 内存序概念 | 只要求区分 relaxed 与 acquire-release 的可见性；画生产者/消费者顺序图 |
| [ ] | Day 30 | 异步任务与线程生命周期 | 比较 thread、async/future；说明 join/detach 和捕获对象寿命风险 |
| [ ] | Day 31 | 现代 C++ 核心特性 | 从 `constexpr`、结构化绑定、concepts、ranges 中选三项写适用场景 |
| [ ] | Day 32 | 编译、链接、ODR 与头文件 | 解释声明/定义、inline、模板放头文件；诊断一个重复定义问题 |
| [ ] | Day 33 | UB 与排错意识 | 列出悬空、越界、未初始化、有符号溢出等 6 类 UB；为每类给最小例子 |
| [ ] | Day 34 | 缓存局部性与性能 | 比较 vector/list 遍历；说明 false sharing 与数据布局的影响 |
| [ ] | Day 35 | 高频知识串联 | 完成 15 分钟口述：生命周期→所有权→多态→容器→并发 |
| [ ] | Day 36 | 薄弱点补强 | 从前 28 天黄/红项中选 3 个，闭卷重答并写最小代码验证 |
| [ ] | Day 37 | C++ 模拟面试 | 完成 10 个快问快答 + 2 个深挖题；记录追问断点和修正表述 |

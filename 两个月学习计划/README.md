# 两个月 C++ 面试基础与 Hot100 训练计划

这是一套以“完成学习任务并通过当天验收”为准的训练包，不以打卡时长为目标。建议把每个七日循环的第 6、7 天放在周末；如果起始日不同，可整体平移 Day 编号，但不要打乱同一阶段的先后依赖。

## 使用顺序

1. 先打开 [00-总计划.md](00-总计划.md)，只勾选真正完成并通过验收的 Day。
2. 第一阶段每天依次使用 `learning-units/` 和 `questions/`；完成整份问题后，再主动打开同日 `answers/`。
3. 第二阶段按题型地图建立框架，按 30 天任务表刷题，同时完成当日 C++ 深入任务。
4. 第三阶段先完成 Day 38—44；只有阶段验收未达标，才进入 Day 45—51。

## 完成定义

- “看懂”不算完成；必须留下当天要求的口述、手写推演、代码片段或错题记录。
- 首次不会做的问题标红；看过提示后完成标黄；不看提示且能说明复杂度和边界条件才标绿。
- 一道算法题只有在“能识别模式、能解释不变量、能写出可运行实现、能分析复杂度”四项均成立时才算掌握。
- 问题与答案物理隔离。测试时不要预览 `answers/`，也不要边做边核对。

## 目录

- `01-第一阶段-数据结构与算法/`：Day 1—7，学习单元、测试题、答案分离。
- `02-第二阶段-Hot100与Cpp/`：Day 8—37，Hot100 全量首刷、复刷与 C++ 深入。
- `03-第三阶段-计网OS设计模式/`：Day 38—44 核心冲刺，Day 45—51 可选强化。

# 计网、OS 与设计模式冲刺任务表

## 阶段策略

Day 38—44 是必须完成的七日核心冲刺，计网占 5 天，OS 与设计模式占 2 天，反映当前计网/OS 较薄弱的优先级。每天都要形成“结构图 + 高频口述 + 场景追问”三类产出。Day 45—51 仅在 Day 44 验收不通过时启用。

## 核心冲刺（Day 38—44）

### Day 38｜网络分层与一次报文旅程

- [ ] 用自己的话解释五层模型每层的职责、服务对象和典型协议/设备。
- [ ] 画“浏览器访问同网段 Web 服务”的封装/解封装过程：应用数据、段、包、帧。
- [ ] 区分带宽、吞吐量、时延、RTT；写出端到端时延的组成。
- [ ] 闭卷口述：交换机、路由器、端口号、IP、MAC 各解决什么寻址问题。
- [ ] 验收：不看图连续讲清一个报文从应用到链路再返回的全过程。

来源：[网络分层](../../中科大郑老师网络（2025）/StudyVault/01-网络概述/1.5%20协议层次与服务模型.md)、[性能指标](../../中科大郑老师网络（2025）/StudyVault/01-网络概述/1.4%20性能指标.md)

### Day 39｜IP、子网、ARP 与路由

- [ ] 完成 5 道 CIDR/子网划分计算，能求网络地址、广播地址和可用主机范围。
- [ ] 画同网段通信与跨网段通信的 ARP/MAC/IP 变化。
- [ ] 解释最长前缀匹配、默认网关、NAT、ICMP 的职责。
- [ ] 压力追问：目标 IP 在外网时，主机为何 ARP 网关 MAC，而不是目标主机 MAC？
- [ ] 验收：子网计算正确率 80%，并能解释路由表的一次查找。

来源：[IP 协议与编址](../../中科大郑老师网络（2025）/StudyVault/04-网络层-数据平面/4.3%20IP协议与编址.md)、[NAT 与 IPv6](../../中科大郑老师网络（2025）/StudyVault/04-网络层-数据平面/4.4%20NAT与IPv6.md)、[MAC 与 ARP](../../中科大郑老师网络（2025）/StudyVault/06-数据链路层/6.3%20MAC地址与ARP.md)

### Day 40｜TCP、UDP 与可靠传输

- [ ] 对比 TCP/UDP：连接、可靠性、顺序、边界、拥塞控制、典型场景。
- [ ] 用序号、确认、校验、超时重传解释可靠传输，不得只说“TCP 可靠”。
- [ ] 区分字节流与报文边界，说明粘包概念来自哪里、应用层如何定界。
- [ ] 手推一次丢包、重复 ACK、超时重传的序号变化。
- [ ] 验收：能为实时音视频、文件传输、DNS 查询分别作协议选择并说明取舍。

来源：[UDP](../../中科大郑老师网络（2025）/StudyVault/03-传输层/3.2%20UDP协议.md)、[可靠传输](../../中科大郑老师网络（2025）/StudyVault/03-传输层/3.3%20可靠数据传输原理.md)、[TCP 可靠传输与流控](../../中科大郑老师网络（2025）/StudyVault/03-传输层/3.5%20TCP可靠传输与流量控制.md)

### Day 41｜TCP 建连、断连、流控与拥塞控制

- [ ] 画三次握手，逐步写 SYN/ACK、序号和双方状态；解释为什么不是两次。
- [ ] 画四次挥手，解释半关闭、TIME_WAIT、2MSL 和“为什么主动关闭方等待”。
- [ ] 区分流量控制与拥塞控制：保护谁、依据信号、维护窗口。
- [ ] 说明慢启动、拥塞避免、快重传/快恢复的核心触发关系。
- [ ] 验收：完成 10 个 TCP 快问快答，正确率至少 8/10。

来源：[TCP 报文与连接管理](../../中科大郑老师网络（2025）/StudyVault/03-传输层/3.4%20TCP报文与连接管理.md)、[拥塞控制](../../中科大郑老师网络（2025）/StudyVault/03-传输层/3.6%20拥塞控制.md)

### Day 42｜HTTP、HTTPS、DNS 与 Socket

- [ ] 从输入 URL 到页面返回，串联 DNS、ARP、TCP、TLS、HTTP、服务端处理与连接复用。
- [ ] 对比 HTTP/1.1、HTTP/2 的关键差异；了解 HTTP/3 运行在 QUIC/UDP 之上。
- [ ] 解释 HTTPS 如何结合证书、非对称/对称加密、摘要与身份认证。
- [ ] 画递归/迭代 DNS 查询与缓存层级。
- [ ] 写出 TCP 服务端 socket 调用顺序和客户端调用顺序。
- [ ] 验收：完成一次 15 分钟“输入 URL 后发生什么”连续口述，经追问仍能回到分层主线。

来源：[HTTP](../../中科大郑老师网络（2025）/StudyVault/02-应用层/2.2%20HTTP协议.md)、[Email 与 DNS](../../中科大郑老师网络（2025）/StudyVault/02-应用层/2.3%20Email与DNS.md)、[Socket 编程](../../中科大郑老师网络（2025）/StudyVault/02-应用层/2.5%20Socket编程.md)、[安全协议](../../中科大郑老师网络（2025）/StudyVault/08-网络安全/8.4%20安全协议.md)

### Day 43｜进程、线程、IPC 与同步

- [ ] 对比进程/线程的资源、地址空间、切换、隔离和故障影响。
- [ ] 列出管道、消息队列、共享内存、socket 的适用场景与取舍。
- [ ] 画进程状态与一次上下文切换；区分用户态/内核态、系统调用/函数调用。
- [ ] 用互斥锁、条件变量、信号量分别解决一个小场景，说明等待条件。
- [ ] 解释死锁四条件，并给出锁顺序、一次性申请、超时等规避方法。
- [ ] 验收：能诊断一个生产者消费者伪代码中的数据竞争、虚假唤醒和死锁风险。

来源：[进程抽象](../../OS/StudyVault/02-进程/进程抽象.md)、[并发与线程](../../OS/StudyVault/07-并发基础/并发与线程.md)、[锁](../../OS/StudyVault/07-并发基础/锁.md)、[条件变量](../../OS/StudyVault/08-并发同步/条件变量.md)、[信号量](../../OS/StudyVault/08-并发同步/信号量.md)

### Day 44｜虚拟内存、I/O、设计模式与核心验收

- [ ] 画虚拟地址经页表/TLB 到物理地址的转换，解释缺页与换页。
- [ ] 区分页、段、内部碎片、外部碎片；说明多级页表为何节省页表空间。
- [ ] 解释用户态缓冲、内核页缓存、系统调用、阻塞/非阻塞、同步/异步的维度差异。
- [ ] 掌握 Strategy、Observer、Factory、Decorator、Adapter、Singleton 的意图、结构、适用场景和滥用风险。
- [ ] 为自己的 C++ 项目选 3 个真实场景，说明为何用某模式而不是 if/继承/全局对象。
- [ ] 完成 [阶段验收清单](阶段验收清单.md)，决定结束还是进入强化周。

来源：[地址空间](../../OS/StudyVault/04-内存虚拟化基础/地址空间.md)、[分页基础](../../OS/StudyVault/05-内存管理机制/分页基础.md)、[TLB](../../OS/StudyVault/06-高级内存管理/TLB快速地址转换.md)、[文件系统](../../OS/StudyVault/10-持久化/文件系统.md)、[I/O 设备](../../OS/StudyVault/10-持久化/IO设备.md)、[设计模式代码库](../../design_patterns/Cpp-Design-Patterns/)

# 排序算法综合比较（★★★）

#data-structure #sort #time-complexity #space-complexity #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **稳定排序** | 直接插入、折半插入、冒泡、归并 |
| **不稳定排序** | Shell、快速、直接选择、堆 |
| **最优平均** | 快排、堆排序、归并 — 均 O(nlog₂n) |
| **原地排序** | 直接插入、Shell、冒泡、快排、直接选择、堆 |
| **需额外空间** | 归并 O(n)、锦标赛 O(n)、快排 O(logn) 栈 |

## 全面比较表

| 算法 | 最好时间 | 最坏时间 | 平均时间 | 空间 | 稳定 |
|------|----------|----------|----------|------|------|
| **直接插入** | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| **折半插入** | O(nlog₂n) | O(n²) | O(n²) | O(1) | ✅ |
| **Shell** | — | — | O(n^1.3) | O(1) | ❌ |
| **冒泡** | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| **快速排序** | O(nlog₂n) | **O(n²)** | **O(nlog₂n)** | O(log₂n) | ❌ |
| **直接选择** | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| **锦标赛** | O(nlog₂n) | O(nlog₂n) | O(nlog₂n) | O(n) | ✅ |
| **堆排序** | O(nlog₂n) | O(nlog₂n) | **O(nlog₂n)** | O(1) | ❌ |
| **归并排序** | O(nlog₂n) | O(nlog₂n) | **O(nlog₂n)** | O(n) | ✅ |

---

## 按特性分类

### 按时间复杂度

| 级别 | 算法 |
|------|------|
| **O(n²)** | 直接插入、折半插入、冒泡、直接选择 |
| **O(nlog₂n)** | 快排（平均）、堆排序、归并、锦标赛 |
| **介于两者** | Shell 排序 O(n^1.3) |

### 按稳定性

| 稳定 | 不稳定 |
|------|--------|
| 直接插入、折半插入、冒泡、归并、锦标赛 | Shell、快排、直接选择、堆排序 |

> [!tip] 记忆口诀
> **不稳定**：**"快 选 Shell 堆"**（快速排序、选择排序、Shell排序、堆排序）

### 按空间开销

| O(1) 原地 | O(logn) | O(n) |
|-----------|---------|------|
| 直接插入、折半插入、Shell、冒泡、直接选择、堆排序 | 快排（栈） | 归并、锦标赛 |

---

## 适用场景建议

| 场景 | 推荐算法 | 理由 |
|------|----------|------|
| **小规模数据 (n ≤ 50)** | 直接插入 | 简单，常数小 |
| **基本有序** | 直接插入 / 冒泡 | 接近 O(n) |
| **大规模随机数据** | 快速排序 | 平均最快 |
| **要求最坏 O(nlogn)** | 堆排序 / 归并 | 不退化 |
| **要求稳定** | 归并排序 | 稳定 + O(nlogn) |
| **空间受限** | 堆排序 | O(1) + O(nlogn) |
| **外排序** | 归并排序 | 顺序访问，适合磁盘 |

---

## 排序下界定理

> [!important] 基于比较的排序下界
> 任何基于比较的排序算法，其最坏情况下的比较次数至少为 **Ω(nlog₂n)**。
> 因此快排、堆排序、归并排序在渐进意义上是**最优**的。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "哪些排序平均 O(nlogn)" | **快排、堆排序、归并排序** |
| "空间 O(1) 且 O(nlogn)" | **堆排序** |
| "稳定且 O(nlogn)" | **归并排序** |
| "最坏 O(n²) 的 nlogn 排序" | **快速排序** |
| "基本有序时最快" | **直接插入排序 O(n)** |
| "不稳定的排序有哪些" | **快排、直接选择、Shell、堆排序** |
| "排序下界" | **Ω(nlog₂n)（基于比较）** |
| "n 较小适合什么排序" | **直接插入排序** |

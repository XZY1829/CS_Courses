# 插入排序与交换排序（★★★）

#data-structure #sort #insertion-sort #exchange-sort #quick-sort #concept

## 概览表（一目了然）
| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定 |
|------|------|------|------|------|------|
| **直接插入** | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| **折半插入** | O(nlog₂n) | O(n²) | O(n²) | O(1) | ✅ |
| **Shell** | — | — | O(n^1.3)~O(n²) | O(1) | ❌ |
| **冒泡** | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| **快速排序** | O(nlog₂n) | O(n²) | **O(nlog₂n)** | O(log₂n) | ❌ |

## 排序基本概念

- **排序**：将一组数据按排序码的某种顺序排列
- **排序码（Key）**：用作排序依据的属性域
- **稳定性**：相等排序码的元素在排序后保持原相对顺序 → **稳定**；否则 → **不稳定**
- **内排序 vs 外排序**：数据全在内存 vs 需内外存交换

## 直接插入排序

**思想**：将第 i 个元素插入到前面已排好序的 V[0..i-1] 中的正确位置。

```
InsertSort(L, left, right):
  for i = left+1 to right:
    if L[i] < L[i-1]:
      temp = L[i], j = i-1
      while j ≥ left AND temp < L[j]:
        L[j+1] = L[j], j--
      L[j+1] = temp
```

**示例**：排序 [21, 25, 49, 25*, 16, 08]

```
初始: [21, 25, 49, 25*, 16, 08]
i=1: [21, 25, 49, 25*, 16, 08]  (25≥21, 不动)
i=2: [21, 25, 49, 25*, 16, 08]  (49≥25, 不动)
i=3: [21, 25, 25*, 49, 16, 08]  (25*插入25后)
i=4: [16, 21, 25, 25*, 49, 08]  (16插入最前)
i=5: [08, 16, 21, 25, 25*, 49]  (08插入最前)
```

| 复杂度 | 比较次数 | 移动次数 |
|--------|----------|----------|
| **最好**（已有序） | n-1 | 0 |
| **最坏**（逆序） | n(n-1)/2 | (n+4)(n-1)/2 |
| **平均** | ≈ n²/4 | ≈ n²/4 |

## 折半插入排序

**改进**：用折半搜索代替顺序搜索确定插入位置（减少比较次数，移动次数不变）。

- **比较次数**：≈ n·log₂n（与初始排列**无关**）
- **移动次数**：与直接插入相同（依赖初始排列）
- **稳定**：是

> [!warning] 折半插入 vs 直接插入
> 折半插入在**已有序**情形下比较次数**多于**直接插入（直接插入只需 n-1 次比较）。

## Shell 排序（缩小增量排序）

**思想**：取递减增量序列 gap₁ > gap₂ > ... > 1，每次按间隔 gap 将元素分组，对各组做直接插入排序。

```
ShellSort(L, left, right):
  gap = (right-left+1) / 2
  while gap > 0:
    for i = left+gap to right:
      temp = L[i], j = i-gap
      while j ≥ left AND temp < L[j]:
        L[j+gap] = L[j], j -= gap
      L[j+gap] = temp
    gap = gap / 2
```

- **不稳定**：不同组的排序可能改变相等元素顺序
- **时间复杂度**：取决于增量序列，一般 **O(n^1.3)**
- 最后一趟 gap=1 等价于直接插入排序，但此时序列已基本有序

## 冒泡排序

**思想**：相邻元素两两比较，逆序则交换，每趟将最大元素"冒泡"到末端。

```
BubbleSort(L, left, right):
  for i = 0 to n-2:
    swapped = false
    for j = 0 to n-2-i:
      if L[j] > L[j+1]:
        swap(L[j], L[j+1])
        swapped = true
    if not swapped: break  // 无交换则已有序
```

| 复杂度 | 值 |
|--------|----|
| **最好** | O(n)（已有序，一趟无交换） |
| **最坏** | O(n²)（逆序） |
| **稳定** | ✅ |

## 快速排序（★★★ 重点）

**思想**：选基准元素，划分为左（≤基准）右（>基准）两部分，递归排序。

### SPLIT（划分）算法

```
SPLIT(A, low, high):
  x = A[low]          // 基准元素
  while low < high:
    while low < high AND A[high] > x: high--
    A[low] = A[high]
    while low < high AND A[low] ≤ x: low++
    A[high] = A[low]
  A[low] = x
  return low           // 基准的新位置
```

### 快速排序主算法

```
QuickSort(A, low, high):
  if low < high:
    w = SPLIT(A, low, high)
    QuickSort(A, low, w-1)
    QuickSort(A, w+1, high)
```

### 复杂度分析

| 情形 | 递推方程 | 复杂度 |
|------|----------|--------|
| **最好/平均**（均匀划分） | T(n) = 2T(n/2) + Θ(n) | **O(nlog₂n)** |
| **最坏**（已排序/逆序） | T(n) = T(n-1) + Θ(n) | **O(n²)** |

- **空间复杂度**：O(log₂n)（递归栈深度）；最坏 O(n)
- **不稳定**：划分过程可能改变相等元素顺序

> [!tip] 快速排序优化
> - **随机化选基准**：避免最坏情况
> - **三数取中**：取首/中/尾的中位数作基准
> - 小规模子数组切换到插入排序

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "直接插入最好情况" | **已有序，比较 n-1 次，移动 0 次** |
| "Shell 排序稳定吗" | **不稳定** |
| "快排最坏情况何时出现" | **已排序或逆序数组** |
| "快排平均时间" | **O(nlog₂n)** |
| "快排一趟划分后的结果" | **基准元素到达最终位置** |
| "哪些排序是稳定的" | **直接插入、折半插入、冒泡、归并** |

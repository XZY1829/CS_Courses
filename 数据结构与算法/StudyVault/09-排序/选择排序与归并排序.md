# 选择排序与归并排序（★★★）

#data-structure #sort #selection-sort #merge-sort #heap #concept

## 概览表（一目了然）
| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定 |
|------|------|------|------|------|------|
| **直接选择** | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| **锦标赛** | O(nlog₂n) | O(nlog₂n) | O(nlog₂n) | O(n) | ✅ |
| **堆排序** | O(nlog₂n) | O(nlog₂n) | **O(nlog₂n)** | O(1) | ❌ |
| **归并排序** | O(nlog₂n) | O(nlog₂n) | **O(nlog₂n)** | O(n) | ✅ |

## 直接选择排序

**思想**：每趟从未排序部分选出最小元素，与未排序部分首元素交换。

```
SelectSort(L, left, right):
  for i = left to right-1:
    k = i
    for j = i+1 to right:
      if L[j] < L[k]: k = j
    if k ≠ i: swap(L[i], L[k])
```

- **比较次数**：始终 n(n-1)/2（与初始排列**无关**）
- **移动次数**：最好 0，最坏 3(n-1)
- **不稳定**：交换可能改变相等元素顺序

---

## 锦标赛排序（树形选择排序）

**思想**：将 n 个元素建成**完全二叉树**，两两比较（类似淘汰赛），胜者（最小值）上升到根。输出根后将对应叶设为 ∞，沿路径重新比较。

- **时间复杂度**：O(nlog₂n)（每次选最小需 log₂n 次比较）
- **空间复杂度**：O(n)（需额外的树结点存储）
- **稳定**：是

> [!warning] 锦标赛排序的缺点
> 辅助空间大（约 2n 个结点），且多次比较中有大量冗余比较。实际中更常用**堆排序**。

---

## 堆排序（★★★ 重点）

利用**堆**结构进行排序，是对锦标赛排序的改进。

### 排序过程（以最大堆为例）

```
HeapSort(L):
  1. 建堆：将 L[0..n-1] 调整为最大堆
  2. for i = n-1 downto 1:
     a. swap(L[0], L[i])     // 堆顶（最大）与末尾交换
     b. siftDown(L, 0, i-1)  // 对 L[0..i-1] 重新筛选
```

### 筛选法建堆

从最后一个非叶结点 ⌊n/2⌋-1 开始，逐个向前做**下滤（siftDown）**：

```
siftDown(L, start, end):
  i = start, j = 2*i + 1  // j 为左子女
  temp = L[i]
  while j ≤ end:
    if j < end AND L[j] < L[j+1]: j++  // 取较大子女
    if temp ≥ L[j]: break
    L[i] = L[j], i = j, j = 2*i + 1
  L[i] = temp
```

**建堆时间**：**O(n)**（非 O(nlogn)）

### 堆排序复杂度

| 项目 | 值 |
|------|----|
| **建堆** | O(n) |
| **n-1 次筛选** | 每次 O(log₂n) |
| **总时间** | **O(nlog₂n)**（最好/最坏/平均相同） |
| **空间** | **O(1)**（原地排序） |
| **稳定性** | **不稳定** |

> [!tip] 堆排序 vs 快速排序
> 堆排序最坏情况 O(nlog₂n) 优于快排的 O(n²)，但快排平均常数因子更小，实际更快。

## 归并排序（★★★ 重点）

**思想**：将序列不断二分，直到单元素（天然有序），再**两两归并**成有序序列。

### MERGE 操作

将两个有序子数组 A[p..q] 和 A[q+1..r] 合并为一个有序数组：

```
MERGE(A, p, q, r):
  s = p, t = q+1, k = p
  while s ≤ q AND t ≤ r:
    if A[s] ≤ A[t]: B[k++] = A[s++]
    else: B[k++] = A[t++]
  // 拷贝剩余部分
  A[p..r] = B[p..r]
```

### 递归归并排序

```
MergeSort(A, low, high):
  if low < high:
    mid = ⌊(low+high)/2⌋
    MergeSort(A, low, mid)
    MergeSort(A, mid+1, high)
    MERGE(A, low, mid, high)
```

### 迭代归并排序

从长度 1 开始，每轮将相邻的有序段两两归并，段长依次 1→2→4→...→n。

### 归并排序复杂度

| 项目 | 值 |
|------|----|
| **递推方程** | T(n) = 2T(n/2) + O(n) |
| **时间** | **O(nlog₂n)**（所有情况） |
| **空间** | **O(n)**（辅助数组 B） |
| **稳定性** | **✅ 稳定** |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "比较次数与初始排列无关的排序" | **直接选择排序（比较始终 n(n-1)/2）** |
| "原地排序且 O(nlogn)" | **堆排序**（空间 O(1)） |
| "稳定的 O(nlogn) 排序" | **归并排序** |
| "建堆的时间复杂度" | **O(n)**（不是 O(nlogn)） |
| "堆排序第一步" | **建最大堆，然后交换堆顶与末尾** |
| "归并排序空间开销" | **O(n) 辅助数组** |

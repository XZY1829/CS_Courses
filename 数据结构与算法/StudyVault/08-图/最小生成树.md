# 最小生成树（★★★）

#data-structure #graph #mst #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **MST** | 连通带权无向图的权值和最小的生成树 |
| **Prim** | 从顶点扩展；适合**稠密图**；O(n²) |
| **Kruskal** | 按边权排序逐边加入；适合**稀疏图**；O(eloge) |
| **性质** | n 个顶点的 MST 恰有 **n-1** 条边 |

## MST 概念

**最小生成树**（Minimum Spanning Tree）：连通带权无向图 G 的一棵**权值和最小**的生成树。

- 含 n 个顶点 → 恰有 **n-1** 条边
- MST 可能**不唯一**（权值相同的边）
- MST 的权值和是唯一的

---

## Prim 算法

**策略**：从一个顶点开始，每次选择连接已选顶点集合和未选顶点集合之间**权值最小**的边，将新顶点加入已选集合。

```
Prim(G, v₀):
  MST = {v₀}, 其余顶点在 V-MST 中
  for each u ∈ V-MST: lowcost[u] = Edge[v₀][u]
  repeat n-1 times:
    找 V-MST 中 lowcost 最小的顶点 k
    将 k 加入 MST，输出对应边
    for each u ∈ V-MST:
      if Edge[k][u] < lowcost[u]:
        lowcost[u] = Edge[k][u]
```

### Prim 复杂度

| 项目 | 值 |
|------|----|
| **时间** | **O(n²)**（与边数无关） |
| **空间** | O(n) |
| **适用** | **稠密图**（边多） |

---

## Kruskal 算法

**策略**：将所有边按权值排序，依次选权值最小的边加入 MST，但跳过会形成**回路**的边（用**并查集**检测）。

```
Kruskal(G):
  按权值对所有边排序
  MST = ∅
  for each edge (u,v,w) in sorted order:
    if Find(u) ≠ Find(v):  // 不在同一连通分量
      MST = MST ∪ {(u,v,w)}
      Union(u, v)
    if |MST| == n-1: break
```

### Kruskal 复杂度

| 项目 | 值 |
|------|----|
| **排序** | O(eloge) |
| **并查集操作** | 近似 O(eα(n)) ≈ O(e) |
| **总时间** | **O(eloge)** |
| **适用** | **稀疏图**（边少） |

---

## Prim vs Kruskal

| 比较维度 | Prim | Kruskal |
|---------|------|---------|
| **策略** | 顶点扩展（贪心） | 边排序选择（贪心） |
| **时间** | O(n²) | O(eloge) |
| **适合** | **稠密图** (e ≈ n²) | **稀疏图** (e ≪ n²) |
| **辅助结构** | lowcost 数组 | 并查集 |
| **是否需排序** | 否 | 需对边排序 |

> [!tip] 选择依据
> 稠密图 e ≈ n² 时 Prim 更优；稀疏图 e ≈ n 时 Kruskal 更优。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "Prim 时间复杂度" | **O(n²)** |
| "Kruskal 时间复杂度" | **O(eloge)** |
| "稠密图求 MST" | **Prim** |
| "稀疏图求 MST" | **Kruskal** |
| "Kruskal 怎么判断回路" | **并查集：Find(u) ≠ Find(v)** |
| "MST 边数" | **n-1** |
| "画出 MST 过程" | **Prim 每步加一个顶点；Kruskal 每步加一条边** |

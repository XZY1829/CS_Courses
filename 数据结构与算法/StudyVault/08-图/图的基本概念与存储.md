# 图的基本概念与存储（★★★）

#data-structure #graph #adjacency #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **图** | G = (V, E)；V 顶点集，E 边集 |
| **有向/无向** | <x,y> 有序对 vs (x,y) 无序对 |
| **完全图** | 无向 n(n-1)/2 条边；有向 n(n-1) 条边 |
| **邻接矩阵** | n×n 数组；空间 O(n²)；适合稠密图 |
| **邻接表** | 顶点表 + 边链表；空间 O(n+e)；适合稀疏图 |

## 图的定义

**图** G = (V, E)
- **V** = {x | x ∈ 某数据对象}，顶点的有穷**非空**集合
- **E**：顶点间关系的有穷集合（边集合）

### 有向图与无向图

| 类型 | 边的表示 | 说明 |
|------|---------|------|
| **无向图** | (x, y) 无序对 | x, y 互为邻接顶点 |
| **有向图** | <x, y> 有序对 | x→y 有方向，x 为始点，y 为终点 |

### 完全图

| 类型 | 边数 |
|------|------|
| **完全无向图** | n(n-1)/2 |
| **完全有向图** | n(n-1) |

---

## 基本术语

| 术语 | 定义 |
|------|------|
| **邻接顶点** | (u,v) ∈ E → u, v 互为邻接 |
| **子图** | V' ⊆ V 且 E' ⊆ E |
| **权/网络** | 边附加数值 → 带权图（网络） |
| **顶点的度** | 无向图 TD(v) = 关联边数；有向图 TD = ID + OD |
| **入度 ID(v)** | 以 v 为终点的有向边数 |
| **出度 OD(v)** | 以 v 为始点的有向边数 |
| **路径** | 顶点序列 (v₁, v₂, ..., vₖ)，相邻顶点有边 |
| **路径长度** | 非带权图：边数；带权图：边权之和 |
| **简单路径** | 各顶点不重复 |
| **回路（环）** | 首尾顶点相同的路径 |

### 连通性

| 术语 | 定义 |
|------|------|
| **连通图** | 无向图中任意两点有路径 |
| **连通分量** | 非连通图的**极大连通子图** |
| **强连通图** | 有向图中任意两点互相可达 |
| **强连通分量** | 有向图的极大强连通子图 |
| **生成树** | 连通图的极小连通子图，n 顶点 n-1 条边 |

> [!important] 关键性质
> - 无向图所有顶点度之和 = **2e**（e 为边数）
> - 有向图所有顶点入度之和 = 出度之和 = **e**
> - 生成树加一条边必产生**回路**

## 邻接矩阵

用 n×n 二维数组 `Edge[i][j]` 存储：

**无向图/有向图**：
```
Edge[i][j] = 1, 若 (i,j) ∈ E 或 <i,j> ∈ E
             0, 否则
```

**带权图（网络）**：
```
Edge[i][j] = W(i,j), 若 i≠j 且边存在
             ∞,      若 i≠j 且边不存在
             0,      若 i==j
```

### 邻接矩阵特点

| 特点 | 说明 |
|------|------|
| 无向图矩阵**对称** | 存储可压缩为三角矩阵 |
| 第 i 行 1 的个数 | 有向图：顶点 i **出度** |
| 第 j 列 1 的个数 | 有向图：顶点 j **入度** |
| 空间复杂度 | **O(n²)**，与边数无关 |
| 适用场景 | **稠密图** |

---

## 邻接表

每个顶点维护一个**边链表**，链表中每个结点表示一条边。

```
顶点表: [data | adj指针]
边结点: [dest | cost | link]
```

### 无向图邻接表

每条边 (u,v) 在 u 和 v 的边链表中**各出现一次**。

### 有向图

| 表类型 | 存储内容 | 可直接求 |
|--------|---------|---------|
| **邻接表（出边表）** | 从每个顶点出发的边 | **出度** |
| **逆邻接表（入边表）** | 到达每个顶点的边 | **入度** |

### 邻接表特点

| 特点 | 说明 |
|------|------|
| 空间复杂度 | 无向图 O(n + 2e)；有向图 O(n + e) |
| 适用场景 | **稀疏图** |
| 求邻接顶点 | 遍历边链表即可 |

---

## 两种存储方式比较

| 比较维度 | 邻接矩阵 | 邻接表 |
|---------|----------|--------|
| **空间** | O(n²) | O(n+e) |
| **判断边是否存在** | O(1) | O(度) |
| **求顶点的度** | O(n) | O(度) |
| **遍历所有边** | O(n²) | O(n+e) |
| **适合图类型** | 稠密图 | 稀疏图 |
| **无向图存储冗余** | 对称矩阵 | 每条边两个结点 |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "n 个顶点完全无向图边数" | **n(n-1)/2** |
| "邻接矩阵判断边" | **O(1) 查 Edge[i][j]** |
| "邻接表空间复杂度" | **O(n+e)** |
| "无向图度之和" | **2e** |
| "有向图邻接矩阵行和" | **该顶点出度** |
| "稠密图用什么存储" | **邻接矩阵** |
| "生成树边数" | **n-1** |

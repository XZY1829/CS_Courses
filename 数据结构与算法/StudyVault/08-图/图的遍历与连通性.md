# 图的遍历与连通性（★★★）

#data-structure #graph #dfs #bfs #traversal #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **DFS** | 深度优先，用**栈**（递归），类似树的前序遍历 |
| **BFS** | 广度优先，用**队列**，类似树的层次序遍历 |
| **visited[]** | 辅助数组防止重复访问 |
| **连通分量** | 对非连通图多次调用 DFS/BFS |
| **复杂度** | 邻接表 O(n+e)；邻接矩阵 O(n²) |

## 图遍历基本思想

从某顶点出发，沿边访问所有顶点，且每个顶点**仅访问一次**。

由于图可能有回路，需设 `visited[n]` 数组标记已访问顶点。

---

## 深度优先搜索（DFS）

### 一句话理解

**"一条路走到黑，走不通再回头换路"**——就像走迷宫时，你始终选一个方向一直走，碰到死胡同才往回退，换一条没走过的路继续。

### 核心规则

1. 访问当前顶点，标记为已访问
2. 找到它的一个**未访问的邻居**，立刻跳过去（递归/压栈）
3. 如果所有邻居都访问过了 → **回退**到上一个顶点，继续检查它的其他邻居
4. 直到所有可达顶点都被访问

### 分步图解

用以下无向图演示，从顶点 A 开始（邻接顺序按字母序）：

```
        A
       / \
      B   C
     / \   \
    D   E   F
        |
        G
```

```
步骤 1: 访问 A        标记: {A}
        栈: [A]
        A 的未访问邻居: B, C → 选 B

步骤 2: 访问 B        标记: {A, B}
        栈: [A, B]
        B 的未访问邻居: D, E → 选 D

步骤 3: 访问 D        标记: {A, B, D}
        栈: [A, B, D]
        D 的未访问邻居: 无 → ★ 回退到 B

步骤 4: 回到 B         标记: {A, B, D}
        栈: [A, B]
        B 的未访问邻居: E → 选 E

步骤 5: 访问 E        标记: {A, B, D, E}
        栈: [A, B, E]
        E 的未访问邻居: G → 选 G

步骤 6: 访问 G        标记: {A, B, D, E, G}
        栈: [A, B, E, G]
        G 的未访问邻居: 无 → ★ 回退到 E

步骤 7: 回到 E → 无未访问邻居 → ★ 回退到 B
步骤 8: 回到 B → 无未访问邻居 → ★ 回退到 A

步骤 9: 回到 A         标记: {A, B, D, E, G}
        栈: [A]
        A 的未访问邻居: C → 选 C

步骤10: 访问 C        标记: {A, B, D, E, G, C}
        栈: [A, C]
        C 的未访问邻居: F → 选 F

步骤11: 访问 F        标记: {A, B, D, E, G, C, F}
        栈: [A, C, F]
        F 的未访问邻居: 无 → 逐层回退，结束
```

**DFS 序列：A → B → D → E → G → C → F**

> [!tip] 观察规律
> DFS 像一棵树的**前序遍历**：先访问根，然后一头扎进左子树到底，再回来处理右子树。"栈"天然支持这种"先进后出"的回退行为。

### 伪代码

```
DFS(G, v, visited[]):
    visit(v)                              // 访问顶点 v
    visited[v] = true                     // 标记已访问
    w = G.getFirstNeighbor(v)             // 取 v 的第一个邻居
    while w ≠ -1:                         // 遍历 v 的所有邻居
        if not visited[w]:                // 如果邻居 w 未被访问
            DFS(G, w, visited)            //   递归深入 w
        w = G.getNextNeighbor(v, w)       // 取 v 的下一个邻居
```

### DFS 特性

| 特性 | 说明 |
|------|------|
| **数据结构** | **栈**（递归调用栈；也可用显式栈改写为非递归） |
| **行为特征** | 尽量深入，走到头再回退 |
| **生成树** | 遍历过程中经过的边构成 **DFS 生成树** |
| **时间复杂度** | 邻接表 **O(n+e)**；邻接矩阵 **O(n²)** |
| **空间复杂度** | O(n)（visited 数组 + 递归栈深度） |

## 广度优先搜索（BFS）

### 一句话理解

**"先把身边的人全认识一遍，再让他们各自介绍朋友"**——像往水里扔石子，波纹一圈一圈往外扩。

### 核心规则

1. 访问起始顶点，标记为已访问，放入**队列**
2. 从队列取出一个顶点，依次访问它的**所有未访问邻居**，每个邻居都标记并入队
3. 重复步骤 2 直到队列为空

### 分步图解

同一个图，从顶点 A 开始：

```
        A
       / \
      B   C
     / \   \
    D   E   F
        |
        G
```

```
步骤 1: 访问 A，入队      标记: {A}
        队列: [A]

步骤 2: 出队 A            标记: {A}
        A 的未访问邻居: B, C
        → 访问 B，入队     标记: {A, B}
        → 访问 C，入队     标记: {A, B, C}
        队列: [B, C]

        ── 第 1 层（距 A = 1）的顶点全部入队 ──

步骤 3: 出队 B            标记: {A, B, C}
        B 的未访问邻居: D, E
        → 访问 D，入队     标记: {A, B, C, D}
        → 访问 E，入队     标记: {A, B, C, D, E}
        队列: [C, D, E]

步骤 4: 出队 C            标记: {A, B, C, D, E}
        C 的未访问邻居: F
        → 访问 F，入队     标记: {A, B, C, D, E, F}
        队列: [D, E, F]

        ── 第 2 层（距 A = 2）的顶点全部入队 ──

步骤 5: 出队 D            D 的未访问邻居: 无
        队列: [E, F]

步骤 6: 出队 E            标记: {A, B, C, D, E, F}
        E 的未访问邻居: G
        → 访问 G，入队     标记: {A, B, C, D, E, F, G}
        队列: [F, G]

步骤 7: 出队 F            F 的未访问邻居: 无
        队列: [G]

步骤 8: 出队 G            G 的未访问邻居: 无
        队列: []  ← 空，结束
```

**BFS 序列：A → B → C → D → E → F → G**

> [!tip] 观察规律
> BFS 严格按**层次**推进：先访问距起点 1 步的所有顶点，再访问距起点 2 步的，以此类推。这就是为什么 BFS 能求**无权图的最短路径**——第一次访问到某个顶点时，走的一定是最短路。

### 伪代码

```
BFS(G, v, visited[]):
    visit(v)                              // 访问起始顶点
    visited[v] = true                     // 标记已访问
    Q.enqueue(v)                          // 入队
    while Q is not empty:                 // 队列不空就继续
        v = Q.dequeue()                   //   出队一个顶点
        w = G.getFirstNeighbor(v)         //   取它的第一个邻居
        while w ≠ -1:                     //   遍历所有邻居
            if not visited[w]:            //     如果邻居未访问
                visit(w)                  //       访问它
                visited[w] = true         //       标记
                Q.enqueue(w)              //       入队（等待后续展开）
            w = G.getNextNeighbor(v, w)   //     取下一个邻居
```

### BFS 特性

| 特性 | 说明 |
|------|------|
| **数据结构** | **队列**（先进先出，保证按层推进） |
| **行为特征** | 逐层扩展，像水波纹 |
| **生成树** | 遍历过程中经过的边构成 **BFS 生成树** |
| **时间复杂度** | 邻接表 **O(n+e)**；邻接矩阵 **O(n²)** |
| **最短路径** | 无权图中 BFS 可求最短路径（第一次到达即最短） |

## DFS vs BFS 直观对比

用同一张图，一目了然：

```
        A                           A
       / \                         / \
      B   C                       B   C
     / \   \                     / \   \
    D   E   F                   D   E   F
        |                           |
        G                           G

DFS 访问顺序（深入优先）：       BFS 访问顺序（逐层扩展）：
A → B → D → E → G → C → F      A → B → C → D → E → F → G
   ↓深入     ↑回退                第1层  第2层    第3层
```

| 比较维度 | DFS | BFS |
|---------|-----|-----|
| **辅助结构** | 栈（后进先出） | 队列（先进先出） |
| **遍历顺序** | 一条路走到黑，再回头 | 一圈一圈往外扩 |
| **类似树遍历** | 前序遍历 | 层次序遍历 |
| **时间复杂度** | 邻接表 O(n+e)；邻接矩阵 O(n²) | 相同 |
| **求最短路径** | 不适合 | ✅（无权图） |
| **回路检测** | ✅ | ✅ |
| **典型应用** | 连通性判断、拓扑排序、迷宫求解 | 最短路径、层次遍历、社交网络扩散 |

## 连通分量与遍历

对于**非连通图**，一次 DFS/BFS 只能访问一个连通分量。需要对所有顶点循环：

```
Components(G):
  for v = 0 to n-1: visited[v] = false
  for v = 0 to n-1:
    if not visited[v]:
      DFS(G, v, visited)  // 或 BFS
      // 每次调用找到一个连通分量
```

调用 DFS/BFS 的**次数** = **连通分量数**。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "DFS 用什么数据结构" | **栈（递归调用栈）** |
| "BFS 用什么数据结构" | **队列** |
| "邻接表上 DFS 复杂度" | **O(n+e)** |
| "邻接矩阵上遍历复杂度" | **O(n²)** |
| "给出某图的 DFS/BFS 序列" | **按邻接顺序，DFS 尽量深入，BFS 逐层** |
| "非连通图遍历" | **多次调用 DFS/BFS，次数 = 连通分量数** |
| "无权图最短路径" | **BFS** |

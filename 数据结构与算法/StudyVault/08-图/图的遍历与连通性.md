# 图的遍历与连通性（★★★）

#data-structure #graph #dfs #bfs #traversal #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **DFS** | 深度优先，用**栈**（递归），类似树的前序遍历 |
| **BFS** | 广度优先，用**队列**，类似树的层次序遍历 |
| **visited[]** | 辅助数组防止重复访问 |
| **连通分量** | 对非连通图多次调用 DFS/BFS |
| **复杂度** | 邻接表 O(n+e)；邻接矩阵 O(n²) |

## 图遍历基本思想

从某顶点出发，沿边访问所有顶点，且每个顶点**仅访问一次**。

由于图可能有回路，需设 `visited[n]` 数组标记已访问顶点。

---

## 深度优先搜索（DFS）

**策略**：访问起始顶点 v，然后从 v 的一个未访问邻接顶点出发递归深度搜索；回退时检查其他未访问邻接顶点。

```
DFS(G, v, visited[]):
  visit(v), visited[v] = true
  w = G.getFirstNeighbor(v)
  while w ≠ -1:
    if not visited[w]: DFS(G, w, visited)
    w = G.getNextNeighbor(v, w)
```

**遍历示例**：

```
图:  A --- B --- E
     |    |     |
     D --- C --- G
     |         |
     F --- H --- I

DFS(A): A → B → E → G → C → D → F → H → I
```

### DFS 特性

| 特性 | 说明 |
|------|------|
| **数据结构** | **栈**（递归调用栈） |
| **生成树** | DFS 生成树 |
| **时间复杂度** | 邻接表 **O(n+e)**；邻接矩阵 **O(n²)** |
| **空间复杂度** | O(n)（visited + 递归栈） |

---

## 广度优先搜索（BFS）

**策略**：访问起始顶点 v，然后依次访问 v 的所有未访问邻接顶点，再依次访问这些顶点的邻接顶点…（按层扩展）。

```
BFS(G, v, visited[]):
  visit(v), visited[v] = true
  Q.enqueue(v)
  while Q is not empty:
    v = Q.dequeue()
    w = G.getFirstNeighbor(v)
    while w ≠ -1:
      if not visited[w]:
        visit(w), visited[w] = true
        Q.enqueue(w)
      w = G.getNextNeighbor(v, w)
```

### BFS 特性

| 特性 | 说明 |
|------|------|
| **数据结构** | **队列** |
| **生成树** | BFS 生成树 |
| **时间复杂度** | 邻接表 **O(n+e)**；邻接矩阵 **O(n²)** |
| **最短路径** | 非带权图中 BFS 可求最短路径 |

---

## DFS vs BFS 比较

| 比较维度 | DFS | BFS |
|---------|-----|-----|
| **辅助结构** | 栈 | 队列 |
| **遍历顺序** | 尽量深入 | 逐层扩展 |
| **类似树遍历** | 前序遍历 | 层次序遍历 |
| **时间复杂度** | 相同 | 相同 |
| **求最短路径** | 不适合 | ✅（无权图） |
| **回路检测** | ✅ | ✅ |

---

## 连通分量与遍历

对于**非连通图**，一次 DFS/BFS 只能访问一个连通分量。需要对所有顶点循环：

```
Components(G):
  for v = 0 to n-1: visited[v] = false
  for v = 0 to n-1:
    if not visited[v]:
      DFS(G, v, visited)  // 或 BFS
      // 每次调用找到一个连通分量
```

调用 DFS/BFS 的**次数** = **连通分量数**。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "DFS 用什么数据结构" | **栈（递归调用栈）** |
| "BFS 用什么数据结构" | **队列** |
| "邻接表上 DFS 复杂度" | **O(n+e)** |
| "邻接矩阵上遍历复杂度" | **O(n²)** |
| "给出某图的 DFS/BFS 序列" | **按邻接顺序，DFS 尽量深入，BFS 逐层** |
| "非连通图遍历" | **多次调用 DFS/BFS，次数 = 连通分量数** |
| "无权图最短路径" | **BFS** |

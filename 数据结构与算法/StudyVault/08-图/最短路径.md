# 最短路径（★★★）

#data-structure #graph #shortest-path #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **Dijkstra** | 单源最短路径；贪心；**O(n²)**；不能有负权边 |
| **Floyd** | 所有顶点对最短路径；DP；**O(n³)** |

## 最短路径问题

在带权有向图（网络）中，从顶点 u 到 v 的**权值和最小**的路径称为最短路径。

---

## Dijkstra 算法（单源最短路径）

**问题**：给定源点 v₀，求 v₀ 到所有其他顶点的最短路径。

**策略**：维护已确定最短路径的顶点集合 S，每次从 V-S 中选**dist 最小**的顶点 u 加入 S，并用 u 更新其他顶点的 dist。

```
Dijkstra(G, v₀):
  S = {v₀}, dist[v₀] = 0
  for each v ∈ V-{v₀}: dist[v] = Edge[v₀][v]
  repeat n-1 times:
    选 V-S 中 dist 最小的顶点 u
    S = S ∪ {u}
    for each w ∈ V-S:
      if dist[u] + Edge[u][w] < dist[w]:
        dist[w] = dist[u] + Edge[u][w]
        path[w] = u  // 记录前驱
```

### 复杂度

| 项目 | 值 |
|------|----|
| **时间** | **O(n²)**（可用优先队列优化到 O((n+e)logn)） |
| **空间** | O(n) |

> [!warning] Dijkstra 不能处理负权边
> 若图中存在负权边，Dijkstra 可能得到错误结果。需使用 Bellman-Ford 算法。

---

## Floyd 算法（所有顶点对最短路径）

**问题**：求所有顶点对之间的最短路径。

**策略**：动态规划，依次以每个顶点 k 作为中转站，检查是否能缩短 i→j 的距离。

```
Floyd(G):
  A[i][j] = Edge[i][j]  // 初始化为邻接矩阵
  for k = 0 to n-1:       // 中转顶点
    for i = 0 to n-1:
      for j = 0 to n-1:
        if A[i][k] + A[k][j] < A[i][j]:
          A[i][j] = A[i][k] + A[k][j]
```

### 复杂度

| 项目 | 值 |
|------|----|
| **时间** | **O(n³)** |
| **空间** | O(n²) |

> [!tip] Floyd 可以处理负权边（但不能有负权回路）

---

## Dijkstra vs Floyd

| 比较维度 | Dijkstra | Floyd |
|---------|----------|-------|
| **问题** | 单源最短路径 | 所有顶点对 |
| **策略** | 贪心 | 动态规划 |
| **时间** | O(n²) | O(n³) |
| **负权边** | ❌ 不可 | ✅ 可以 |
| **使用** | 求某点到其他所有点 | 求所有点之间 |
| **多次单源** | n 次 Dijkstra = O(n³) | 直接 Floyd O(n³) |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "单源最短路径算法" | **Dijkstra** |
| "所有顶点对最短路径" | **Floyd** |
| "Dijkstra 时间复杂度" | **O(n²)** |
| "Floyd 时间复杂度" | **O(n³)** |
| "负权边用什么算法" | **Floyd（或 Bellman-Ford），不能用 Dijkstra** |
| "Dijkstra 每步选哪个顶点" | **V-S 中 dist 最小的顶点** |
| "Floyd 的核心操作" | **A[i][j] = min(A[i][j], A[i][k]+A[k][j])** |

| 条目 | 要点 |
|------|------|
| **AOV 网络** | 顶点表示活动；有向边表示先后关系 |
| **拓扑排序** | 输出所有顶点使得先后关系满足；O(n+e) |

## AOV 网络与拓扑排序

### AOV 网络

**AOV 网络**（Activity On Vertices）：用**顶点**表示活动，用**有向边**表示活动间的先后关系。

- 若 <vᵢ, vⱼ> ∈ E，则 vᵢ 必须在 vⱼ **之前**完成
- AOV 网络**不能有回路**（否则活动无法完成——A 要在 B 前面，B 又要在 A 前面，矛盾）

### 拓扑排序是什么

**一句话理解**：把一张"谁先谁后"的依赖关系图，排成一条**直线队伍**，使得所有箭头都朝同一个方向（从左到右）。

**生活例子**：选课。"数据结构"要求先修"C语言"，"算法"要求先修"数据结构"。拓扑排序就是帮你排出一个合法的选课顺序，比如：C语言 → 数据结构 → 算法。

### 算法核心思想

> [!important] 关键直觉
> **入度为 0** 的顶点 = **没有任何前置依赖**的活动 = 现在就可以做的事。
> 每次选一个"现在就能做"的事做掉，做完后把它对别人的约束解除（后继入度减 1），这样可能又有新的事变成"现在就能做"了。

算法只需不断重复两个动作：
1. **找到**一个入度为 0 的顶点 → 输出它
2. **删掉**这个顶点和它的所有出边（即让后继入度减 1）

### 分步图解

用一个选课依赖的例子：

```
原始 DAG（有向无环图）：

  C0 ──→ C1 ──→ C3
  │             ↗
  ↓           /
  C2 ──→ C4
          ↓
          C5

  边的含义：箭头前的课是箭头后的课的先修课
  C0: 高等数学    C1: 线性代数    C2: C语言
  C3: 机器学习    C4: 数据结构    C5: 操作系统
```

初始入度表：

```
  顶点:  C0  C1  C2  C3  C4  C5
  入度:   0   1   1   2   1   1
               ↑       ↑
            (C0→C1) (C1→C3, C4→C3)
```

逐步执行：

```
 ┌──────────────────────────────────────────────────────┐
 │  步骤 1                                              │
 │  入度为 0 的顶点: C0 ← 选它输出                       │
 │                                                      │
 │  删除 C0 的出边: C0→C1, C0→C2                        │
 │  C1 入度: 1→0  ★ 变成 0 了，入栈                      │
 │  C2 入度: 1→0  ★ 变成 0 了，入栈                      │
 │                                                      │
 │  输出序列: [C0]                                       │
 │  栈: {C1, C2}                                        │
 │  入度:  C0  C1  C2  C3  C4  C5                       │
 │         ×   0   0   2   1   1                        │
 └──────────────────────────────────────────────────────┘

 ┌──────────────────────────────────────────────────────┐
 │  步骤 2                                              │
 │  从栈中取出: C1（或 C2，顺序不唯一）                    │
 │                                                      │
 │  删除 C1 的出边: C1→C3                                │
 │  C3 入度: 2→1                                        │
 │                                                      │
 │  输出序列: [C0, C1]                                   │
 │  栈: {C2}                                            │
 │  入度:  C0  C1  C2  C3  C4  C5                       │
 │         ×   ×   0   1   1   1                        │
 └──────────────────────────────────────────────────────┘

 ┌──────────────────────────────────────────────────────┐
 │  步骤 3                                              │
 │  从栈中取出: C2                                       │
 │                                                      │
 │  删除 C2 的出边: C2→C4                                │
 │  C4 入度: 1→0  ★ 变成 0 了，入栈                      │
 │                                                      │
 │  输出序列: [C0, C1, C2]                               │
 │  栈: {C4}                                            │
 │  入度:  C0  C1  C2  C3  C4  C5                       │
 │         ×   ×   ×   1   0   1                        │
 └──────────────────────────────────────────────────────┘

 ┌──────────────────────────────────────────────────────┐
 │  步骤 4                                              │
 │  从栈中取出: C4                                       │
 │                                                      │
 │  删除 C4 的出边: C4→C3, C4→C5                        │
 │  C3 入度: 1→0  ★ 变成 0 了，入栈                      │
 │  C5 入度: 1→0  ★ 变成 0 了，入栈                      │
 │                                                      │
 │  输出序列: [C0, C1, C2, C4]                           │
 │  栈: {C3, C5}                                        │
 │  入度:  C0  C1  C2  C3  C4  C5                       │
 │         ×   ×   ×   0   ×   0                        │
 └──────────────────────────────────────────────────────┘

 ┌──────────────────────────────────────────────────────┐
 │  步骤 5                                              │
 │  从栈中取出: C3                                       │
 │  C3 无出边                                            │
 │  输出序列: [C0, C1, C2, C4, C3]                       │
 └──────────────────────────────────────────────────────┘

 ┌──────────────────────────────────────────────────────┐
 │  步骤 6                                              │
 │  从栈中取出: C5                                       │
 │  C5 无出边                                            │
 │  输出序列: [C0, C1, C2, C4, C3, C5]  ← 完成！        │
 │  输出了 6 个顶点 = n，无回路 ✓                         │
 └──────────────────────────────────────────────────────┘
```

验证结果：**C0 → C1 → C2 → C4 → C3 → C5**（高数 → 线代 → C语言 → 数据结构 → 机器学习 → 操作系统），所有先修关系都满足。

> [!tip] 为什么结果不唯一？
> 步骤 2 中栈里有 C1 和 C2 两个入度为 0 的顶点，先取谁都行。选 C2 先取就得到另一个合法序列 C0 → C2 → C1 → C4 → C3 → C5，同样正确。

### 如何检测回路？

如果图中有回路（如 A→B→C→A），那么回路上的顶点入度**永远不会变成 0**——你等我我等你，谁也出不来。最终输出的顶点数 < n，说明有回路。

```
有回路的例子:

  A ──→ B
  ↑     |        A, B, C 入度都 ≥ 1
  |     ↓        永远不会有入度为 0 的
  └── C          → 它们都不会被输出
                 → 输出顶点数 < n → 检测到回路！
```

### 伪代码

```
TopologicalSort(G):
    计算所有顶点入度 InDegree[]
    将所有入度为 0 的顶点入栈 S
    count = 0
    while S 不空:
        v = S.pop()                    // 取一个"无前置依赖"的顶点
        输出 v                          // 排入结果序列
        count++
        for each w in v 的所有后继:     // 遍历 v 的出边
            InDegree[w]--              //   解除 v 对 w 的约束
            if InDegree[w] == 0:       //   w 的所有前置都已完成？
                S.push(w)              //     w 也"可以做了"，入栈
    if count < n:
        报告"图中有回路！"               // 有些顶点因回路永远无法输出
```

> [!note] 栈还是队列？
> 这里用栈或队列都可以，都能产生合法的拓扑序列，只是输出顺序不同。用栈是教材常见写法；BFS 风格的拓扑排序（Kahn 算法）用队列，效果一样。

### 拓扑排序特性

| 特性 | 说明 |
|------|------|
| **前提条件** | 图必须是 **DAG**（有向无环图） |
| **时间复杂度** | **O(n+e)**（每个顶点入栈/出栈一次，每条边处理一次） |
| **唯一性** | 拓扑序列一般**不唯一**（多个入度为 0 时选谁都行） |
| **检测回路** | 若输出顶点数 < n，则存在回路 |
| **应用** | 课程安排、编译依赖、任务调度、死锁检测 |

## AOE 网络与关键路径

### AOE 网络

**AOE 网络**（Activity On Edges）：用**边**表示活动（附带时间），用**顶点**表示事件（里程碑）。

- **源点**：入度为 0（工程开始）
- **汇点**：出度为 0（工程结束）

### 关键路径概念

| 术语 | 记号 | 含义 |
|------|------|------|
| **事件最早发生时间** | Ve(j) | 从源点到 j 的**最长路径**长度 |
| **事件最晚发生时间** | Vl(j) | 不推迟工期前提下最晚发生时间 |
| **活动最早开始时间** | Ae(i) | 活动所在边起点的 Ve |
| **活动最晚开始时间** | Al(i) | 活动所在边终点的 Vl - 活动时间 |
| **松弛时间** | Al(i) - Ae(i) | 可推迟的时间量 |
| **关键活动** | Al(i) - Ae(i) = 0 | **不可推迟**的活动 |

### 计算步骤

```
1. 拓扑排序，正向计算 Ve[]（取前驱的 max）
   Ve[j] = max{Ve[i] + dur<i,j>}  (所有 i→j)

2. 逆拓扑排序，反向计算 Vl[]（取后继的 min）
   Vl[i] = min{Vl[j] - dur<i,j>}  (所有 i→j)
   Vl[汇点] = Ve[汇点]

3. 对每条边 <i,j>:
   Ae = Ve[i]
   Al = Vl[j] - dur<i,j>
   若 Ae == Al → 关键活动

4. 关键活动组成的路径 = 关键路径
```

### 关键路径特性

- **关键路径长度** = 工程的**最短工期**
- 关键路径可能**不唯一**
- 只有缩短关键路径上的活动才能缩短工期

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "拓扑排序时间复杂度" | **O(n+e)** |
| "如何检测有向图是否有回路" | **拓扑排序，若输出顶点数 < n 则有回路** |
| "关键路径是什么" | **源点到汇点的最长路径** |
| "关键活动的判定条件" | **Al(i) - Ae(i) = 0（松弛时间为 0）** |
| "缩短工期应缩短什么" | **关键路径上的关键活动** |
| "Ve 的计算方向" | **正向（拓扑序），取 max** |
| "Vl 的计算方向" | **反向（逆拓扑序），取 min** |

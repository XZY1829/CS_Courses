# 活动网络与拓扑排序（★★★）

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **AOV 网络** | 顶点表示活动；有向边表示先后关系 |
| **拓扑排序** | 输出所有顶点使得先后关系满足；O(n+e) |
| **AOE 网络** | 边表示活动（带时间）；顶点表示事件 |
| **关键路径** | 从源点到汇点的**最长路径**；决定工程最短工期 |

## AOV 网络与拓扑排序

### AOV 网络

**AOV 网络**（Activity On Vertices）：用**顶点**表示活动，用**有向边**表示活动间的先后关系。

- 若 <vᵢ, vⱼ> ∈ E，则 vᵢ 必须在 vⱼ **之前**完成
- AOV 网络**不能有回路**（否则活动无法完成）

### 拓扑排序算法

**目标**：将 AOV 网络中所有顶点排成线性序列，使得先后关系满足。

```
TopologicalSort(G):
  计算所有顶点入度 InDegree[]
  将所有入度为 0 的顶点入栈
  count = 0
  while 栈不空:
    v = pop()
    输出 v, count++
    for each w adjacent from v:
      InDegree[w]--
      if InDegree[w] == 0: push(w)
  if count < n: 图中有回路!
```

### 拓扑排序特性

| 特性 | 说明 |
|------|------|
| **时间复杂度** | **O(n+e)** |
| **唯一性** | 拓扑序列一般**不唯一** |
| **检测回路** | 若输出顶点数 < n，则存在回路 |
| **应用** | 课程安排、编译依赖、任务调度 |

## AOE 网络与关键路径

### AOE 网络

**AOE 网络**（Activity On Edges）：用**边**表示活动（附带时间），用**顶点**表示事件（里程碑）。

- **源点**：入度为 0（工程开始）
- **汇点**：出度为 0（工程结束）

### 关键路径概念

| 术语 | 记号 | 含义 |
|------|------|------|
| **事件最早发生时间** | Ve(j) | 从源点到 j 的**最长路径**长度 |
| **事件最晚发生时间** | Vl(j) | 不推迟工期前提下最晚发生时间 |
| **活动最早开始时间** | Ae(i) | 活动所在边起点的 Ve |
| **活动最晚开始时间** | Al(i) | 活动所在边终点的 Vl - 活动时间 |
| **松弛时间** | Al(i) - Ae(i) | 可推迟的时间量 |
| **关键活动** | Al(i) - Ae(i) = 0 | **不可推迟**的活动 |

### 计算步骤

```
1. 拓扑排序，正向计算 Ve[]（取前驱的 max）
   Ve[j] = max{Ve[i] + dur<i,j>}  (所有 i→j)

2. 逆拓扑排序，反向计算 Vl[]（取后继的 min）
   Vl[i] = min{Vl[j] - dur<i,j>}  (所有 i→j)
   Vl[汇点] = Ve[汇点]

3. 对每条边 <i,j>:
   Ae = Ve[i]
   Al = Vl[j] - dur<i,j>
   若 Ae == Al → 关键活动

4. 关键活动组成的路径 = 关键路径
```

### 关键路径特性

- **关键路径长度** = 工程的**最短工期**
- 关键路径可能**不唯一**
- 只有缩短关键路径上的活动才能缩短工期

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "拓扑排序时间复杂度" | **O(n+e)** |
| "如何检测有向图是否有回路" | **拓扑排序，若输出顶点数 < n 则有回路** |
| "关键路径是什么" | **源点到汇点的最长路径** |
| "关键活动的判定条件" | **Al(i) - Ae(i) = 0（松弛时间为 0）** |
| "缩短工期应缩短什么" | **关键路径上的关键活动** |
| "Ve 的计算方向" | **正向（拓扑序），取 max** |
| "Vl 的计算方向" | **反向（逆拓扑序），取 min** |

## 队列的定义（3.3）

**队列（Queue）**：只允许在**一端删除**、**另一端插入**的线性表。
- **队头 front**：删除端
- **队尾 rear**：插入端
- 特性：**先进先出 FIFO**（First In First Out）

```
出队 ←  a₁  a₂  a₃ … aₙ  → 入队
      front          rear
```

与栈对比：栈**限制同一端**；队列**限制两端且方向相反**。

---

## 顺序队列与假溢出

用数组 `elements[]` 存储，初始 front = rear = 0：
- **EnQueue**：elements[rear] = x; rear++
- **DeQueue**：x = elements[front]; front++
- **队空**：front == rear
- **队满（非循环）**：rear == maxSize - 1

**假溢出**：rear 已到数组末尾但 front 之前仍有空位，无法继续入队。

**解决**：将数组视为**首尾相接的环** → **循环队列**。

---

## 循环队列（Circular Queue）

```
       rear
    ┌──↓──┐
  0 │ A B │ 6
    └──↑──┘
      front
    （逻辑环状）
```

| 操作/条件 | 公式 |
|-----------|------|
| 初始化 | front = rear = 0 |
| 队头指针进 1 | front = (front+1) % maxSize |
| 队尾指针进 1 | rear = (rear+1) % maxSize |
| **队空** | front == rear |
| **队满** | **(rear+1) % maxSize == front** |
| 元素个数 | (rear - front + maxSize) % maxSize |

> [!warning] 牺牲一个存储单元
> 循环队列用 **(rear+1)%maxSize == front** 判满，需**牺牲一个数组单元**以区分队空与队满。若 front==rear 既可能空也可能满，必须二选一约定或引入 size 计数。

### 核心操作

```c
EnQueue(x):  if 满 return false;
             elements[rear] = x;
             rear = (rear+1) % maxSize;

DeQueue(x):  if 空 return false;
             x = elements[front];
             front = (front+1) % maxSize;
```

---

## 链式队列

```
front → [a₁|•] → [a₂|•] → … → [aₙ|•] ← rear
```

- **队头在链头，队尾在链尾**
- **无队满问题**（除非内存耗尽）
- **队空**：front == NULL
- EnQueue：rear→link = newNode; rear = newNode（注意首结点特殊处理）
- DeQueue：x = front→data; front = front→link; delete p

---

## 队列的应用：杨辉三角形

打印第 i 行系数时，利用**队列**保存上一行相邻两数之和：
- 入队 1, 1 作为第 1 行
- 对第 i 行：先 EnQueue(0)，循环 DeQueue 得 t，EnQueue(s+t)，s=t，输出 s
- 相邻元素之和生成下一行（二项式系数性质）

## 优先级队列（3.4）

**优先级队列（Priority Queue）**：不同于 FIFO，每次取出**优先级最高**（或最低，依约定）的元素。

| 任务 | 优先级 |
|------|--------|
| 1 | 20 |
| 2 | 0 |
| 3 | 40 |
| … | … |

执行顺序按优先级：**数字越小优先级越高**（本课程约定）。

- 相同优先级 → 按 **FIFO** 处理
- 应用：**任务调度**——优先处理高优先级任务

### 存储实现

| 实现 | 说明 |
|------|------|
| **数组（本章）** | 有序或半有序数组，Insert 后 adjust，RemoveMin 取首 |
| **堆（第5章）** | 更高效的 Insert/DeleteMin |

### 数组实现要点（PQueue）

- `pqelements[]` 存放元素，`count` 为元素数
- **Insert(x)**：放到 count-1 位置，**adjust()** 从后向前找插入位置（类似插入排序的一步）
- **RemoveMin(x)**：x = pqelements[0]，其余元素前移，count--

例：有序 `[10,20,40,50,70,90]` 插入 60 → adjust 后 `[10,20,40,50,60,70,90]`

> [!warning] 实现差异
> 不同教材对"优先级高"的定义可能相反（大数优先 vs 小数优先）。本课程：**数字越小优先级越高**，RemoveMin 取出 pqelements[0]。

## 单调队列（Monotone Deque）

### 定义

**单调队列**：用**双端队列（deque）**维护元素的单调性，同时支持从队头移除过期元素。通常队列中存储的是**下标**，元素值保持单调递减或递增。

```
求滑动窗口最大值，维护单调递减队列（队头最大）：

数组: [1, 3, -1, -3, 5, 3, 6, 7], 窗口 k=3

窗口 [1,3,-1]:  deque=[3,-1]  → 最大=3
窗口 [3,-1,-3]: deque=[3,-1,-3] → 最大=3
窗口 [-1,-3,5]: deque=[5]     → 最大=5
...
```

### 解决的核心问题

**滑动窗口内的最值查询**：在 O(1) 时间获取当前窗口的最大/最小值，总体 O(n) 完成整个数组的滑动窗口最值。

### 与单调栈的区别

| | 单调栈 | 单调队列 |
|---|---|---|
| 数据结构 | 栈（一端操作） | 双端队列（两端操作） |
| 移除过期 | 不需要 | 队头移除超出窗口的元素 |
| 典型问题 | 下一个更大元素 | 滑动窗口最值 |
| 共同点 | 维护单调性，入栈/队时弹出违反者 |

### 工作原理

维护**单调递减**队列（求窗口最大值）：
1. **入队**：新元素从队尾进入前，弹出所有 ≤ 它的队尾元素（它们被"遮挡"，不可能再成为最大值）
2. **出队**：检查队头元素下标是否已超出窗口范围，若超出则从队头移除
3. **取最值**：队头元素即为当前窗口最大值

### 模板（C++，滑动窗口最大值）

```cpp
vector<int> maxSlidingWindow(const vector<int>& nums, int k) {
    vector<int> result;
    deque<int> dq; // 存下标，对应值从队头到队尾单调递减
    
    for (int i = 0; i < (int)nums.size(); i++) {
        // 移除超出窗口的队头
        while (!dq.empty() && dq.front() <= i - k)
            dq.pop_front();
        // 维护单调性：弹出队尾所有 ≤ nums[i] 的
        while (!dq.empty() && nums[dq.back()] <= nums[i])
            dq.pop_back();
        dq.push_back(i);
        // 窗口形成后记录答案
        if (i >= k - 1)
            result.push_back(nums[dq.front()]);
    }
    return result;
}
```

### 复杂度

| | 时间 | 空间 |
|---|---|---|
| 滑动窗口最值 | O(n)（每元素至多入出队各一次） | O(k)（窗口大小） |

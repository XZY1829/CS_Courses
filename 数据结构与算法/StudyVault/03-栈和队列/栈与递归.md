| 条目 | 要点 |
|------|------|

| **顺序栈** | 数组 + top 指针；空：top=-1；满：top=maxSize-1 |

## 栈的定义（3.1）

**栈（Stack）**：只允许在**一端**进行插入和删除操作的线性表。
- **栈顶（top）**：允许插入删除的一端
- **栈底（bottom）**：固定不变的一端
- **Push（进栈）**：在栈顶插入
- **Pop（出栈）**：删除栈顶元素
- 特性：**后进先出 LIFO**（Last In First Out）= 先进后出 FILO

```
进栈 →  │ an   │ ← 栈顶 top
        │ ...  │
        │ a1   │ ← 栈底
出栈 ←
```

栈与队列、线性表同属**线性结构**，但**限制了存取位置**（仅栈顶）。

---

## 顺序栈（数组实现）

用数组 `elements[]` 存储，整型 **top** 指示栈顶：
- **栈空**：top = -1
- **栈满**：top = maxSize - 1
- **Push**：先 `++top`，再 `elements[top] = x`
- **Pop**：取 `elements[top]`，再 `top--`

### 溢出处理

| 类型 | 条件 | 现象 |
|------|------|------|
| **上溢 Overflow** | 已有 maxSize 个元素再 Push | 栈满仍进栈 |
| **下溢 Underflow** | 空栈 Pop | 栈空仍出栈 |

**扩容策略**：栈满时创建 2×maxSize 新数组，复制元素，替换指针。

### 双栈共享空间

两栈共用数组 V，栈底分别在两端，栈顶向中间延伸：
- b[0]=-1, b[1]=maxSize；t[0] 从左向右，t[1] 从右向左
- **栈满**：t[0]+1 == t[1]
- 空间利用率高，适合两栈大小互补的场景

---

## 链式栈

- 用单链表实现，**栈顶 = 链头（top 指针）**
- **无栈满问题**，空间可动态扩充
- Push：`top = new StackNode(x, top)`
- Pop：暂存 top，top = top→link，释放结点
- 适合**多栈操作**或空间需求不确定的场景

---

## 栈的应用

### 1. 括号匹配检验

扫描表达式，遇左括号 Push，遇右括号 Pop 并与栈顶匹配：
- 栈空或不匹配 → false
- 扫描结束栈空 → true

### 2. 表达式表示与求值

| 表示 | 形式 | 例 |
|------|------|-----|
| **中缀 infix** | 操作数 运算符 操作数 | A+B |
| **前缀 prefix** | 运算符 操作数 操作数 | +AB |
| **后缀 postfix** | 操作数 操作数 运算符 | AB+ |

**后缀求值**（推荐）：
```
从左到右扫描：
  遇操作数 → 压栈
  遇运算符 → 弹出两个操作数运算，结果压栈
最终栈顶即为结果
```

例：`12 6 2 / 0.5 - *` → 30

**中缀求值**：维护**运算符栈 optr** 和 **操作数栈 opnd**，按栈内外优先级比较决定压栈或计算。

运算符优先级表（数值越大越高）：

| 运算符 | 栈内 | 栈外 |
|--------|------|------|
| = | 0 | 0 |
| ( | 1 | 6 |
| *, / | 5 | 4 |
| +, - | 3 | 2 |
| ) | 6 | 1 |

**中缀转后缀**：按优先级加括号，将运算符移到右括号后，再去括号。
例：`(A+B)*D-E/(F+A*D)+C` → `AB+D*EFAD*+/-C+`

## 栈与递归（3.2）

### 递归的定义

- **定义递归**：对象部分包含自身（如阶乘 n! = n×(n-1)!）
- **结构递归**：数据结构包含同类型结构（如单链表：结点+指向链表的指针）
- **解法递归**：问题分解为更小的同类子问题（汉诺塔、分治法）

### 递归三要素与出口

```
Function F(参数) {
  if (初始/终止条件) return 基准值;  // 出口
  else return F(缩小的问题);       // 递归调用
}
```

**必须有出口**，否则无限递归。

### 递归工作栈

每次递归调用分配**活动记录**（返回地址、局部变量、参数），按 **LIFO** 组织成**递归工作栈**：

```
main → fact(4) → fact(3) → fact(2) → fact(1) → fact(0)
                                              ↓ return 1
         ← 24 ← 6 ← 2 ← 1 ← 1        （回归求值）
```

- 外部调用：主程序第一次调用
- 内部调用：递归过程调用自身

### 递归改非递归

| 方法 | 适用 | 说明 |
|------|------|------|
| **迭代** | 单向递归、尾递归 | 用循环替代，如 Fib 迭代 O(n) |
| **显式栈** | 一般递归 | 手动模拟递归工作栈 |

**尾递归**：递归调用是过程最后一句 → 可改为 while 循环。

> [!warning] Fib 递归效率
> `Fib(n)=Fib(n-1)+Fib(n-2)` 存在大量重复计算，调用次数 NumCall(k) = **2×Fib(k+1)-1**，指数级。应改用**迭代**或**动态规划**。

## 单调栈（Monotone Stack）

### 定义

**单调栈**：维护栈内元素**单调递增或单调递减**的栈。每次新元素入栈前，将违反单调性的栈顶元素弹出。

```
单调递减栈（栈底到栈顶递减）：
入栈 3: [3]
入栈 1: [3, 1]
入栈 2: 弹出 1（1 < 2 违反递减），[3, 2]
入栈 5: 弹出 2, 弹出 3，[5]
```

### 解决的核心问题

**下一个更大/更小元素（Next Greater/Smaller Element）**

给定数组，对每个元素找到它右边（或左边）第一个比它大（或小）的元素。

```
数组:  [2, 1, 2, 4, 3]
NGE:   [4, 2, 4, -1, -1]   (右边第一个更大元素)
```

### 为什么单调栈有效

暴力做法对每个元素向右扫描，O(n²)。单调栈利用一个关键性质：**如果 a 在 b 左边且 a ≥ b，则 a 永远不可能是 b 右边任何元素的"下一个更小"**——a 被 b 遮挡了。弹出这些被遮挡的元素，每个元素最多入栈/出栈各一次，总 O(n)。

### 模板（C++，求右边第一个更大元素）

```cpp
vector<int> nextGreater(const vector<int>& nums) {
    int n = nums.size();
    vector<int> result(n, -1);
    stack<int> stk; // 存下标，维护从栈底到栈顶值递减
    
    for (int i = 0; i < n; i++) {
        while (!stk.empty() && nums[stk.top()] < nums[i]) {
            result[stk.top()] = nums[i];
            stk.pop();
        }
        stk.push(i);
    }
    return result;
}
```

### 问题结构特征

遇到以下特征时考虑单调栈：
- 求**下一个更大/更小**元素
- 求**左/右第一个**满足条件的位置
- **柱状图最大矩形**（每个柱子找左右第一个更矮的）
- **接雨水**（每个位置找左右最高柱子）
- 问题要求 O(n) 且具有"遮挡/淘汰"性质

### 复杂度

| | 时间 | 空间 |
|---|---|---|
| 单调栈遍历 | O(n)（每元素至多入出栈各一次） | O(n) |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "栈的特性" | **LIFO** 后进先出 |
| "顺序栈空/满条件" | top=-1 / top=maxSize-1 |
| "链式栈栈顶位置" | **链头** |
| "上溢/下溢" | 满再 Push / 空再 Pop |
| "后缀表达式求值" | 遇操作数压栈，遇运算符弹两个计算 |
| "中缀转后缀思路" | 加括号 → 运算符移右括号后 → 去括号 |
| "括号匹配" | 左括号 Push，右括号 Pop 匹配 |
| "递归必要条件" | 必须有**终止出口** |
| "递归实现依赖" | 系统**递归工作栈**（活动记录 LIFO） |
| "汉诺塔 n 盘" | 分三步：移 n-1 到 B，最大盘 A→C，移 n-1 到 C |

| "单调栈解决什么问题" | **下一个更大/更小元素**，左/右第一个满足条件的位置 |
| "单调栈时间复杂度" | **O(n)**，每个元素最多入栈出栈各一次 |
| "单调栈 vs 暴力" | 暴力 O(n²) 逐个扫描；单调栈利用遮挡性淘汰无效候选 |

# 集合与并查集（★★★）

#data-structure #search #set #union-find #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **集合** | 互不相同成员的群集；元素类型一致 |
| **基本运算** | 并 A∪B、交 A∩B、差 A-B |
| **位向量** | 全集合 {0,…,n-1} 子集；每位 0/1 表示属于否 |
| **并查集** | Union + Find；双亲表示；每集合一棵树 |
| **路径压缩** | Find 时将路径上结点直接挂到根 |
| **按秩合并** | 按结点个数或树高度合并，小树挂大树下 |

## 集合基本概念

**集合**是成员（元素）的群集，成员互不相同，同一集合中元素**类型一致**。
- 成员可为整数、字符、字符串、指针等
- 成员通常**无序**；可定义线性序 "<" 用于有序表示

### 集合运算

| 运算 | 符号 | 含义 |
|------|------|------|
| **并** | A∪B 或 A+B | 属于 A 或 B |
| **交** | A∩B 或 A×B | 属于 A 且 B |
| **差** | A-B | 属于 A 不属于 B |

---

## 位向量表示

当全集合为 **{0, 1, …, n-1}** 且 n 不大时，用**位向量**实现：
- 1 = 元素在集合中，0 = 不在
- 16 位无符号短整数数组 `bitVector[]`

**位运算实现**：
```
并: temp[i] = this[i] | R[i]
交: temp[i] = this[i] & R[i]
差: temp[i] = this[i] & ~R[i]
子集: 若 (this[i] & ~R[i]) 任一位非 0 则 false
```

**优点**：并/交/差按字**并行**位运算，O(⌈n/w⌉)（w 为字长）。
**缺点**：n 很大或元素非连续整数时不适用。

---

## 有序链表表示

结点按**升序**链接，可表示无穷全集的子集；并/交/差需归并式扫描。

## 等价类

**等价关系** "≡" 满足：
1. **自反性**：x ≡ x
2. **对称性**：x ≡ y → y ≡ x
3. **传递性**：x ≡ y 且 y ≡ z → x ≡ z

集合 S 可划分为互不相交的**等价类** S₁, S₂, …，其并为 S。

**示例** S={0,…,11}，等价对：0≡4, 3≡1, 6≡10, 8≡9, 7≡4, 6≡8, 3≡5, 2≡11, 11≡0

```
初始: {0}{1}{2}…{11}
0≡4:  {0,4}{1}…
…
最终: {0,2,4,7,11}, {1,3,5}, {6,8,9,10}
```

## 并查集（Union-Find）

**并查集**支持动态维护不相交集合：

| 操作 | 功能 |
|------|------|
| **UFSets(s)** | 构造 s 个单元素集合 |
| **Find(x)** | 找 x 所属集合的根 |
| **Union(r1, r2)** | 合并两集合（r1,r2 为根） |

### 双亲表示

`parent[i]` 表示元素 i 所在树的双亲；**根**的 parent[i] < 0，绝对值为**集合元素个数**。

```
S1={0,6,7,8}: parent[0]=-4, parent[6]=0, parent[7]=0, parent[8]=0
S2={1,4,9}:  parent[1]=-3, parent[4]=1, parent[9]=4
S3={2,3,5}:  parent[2]=-3, parent[3]=2, parent[5]=2
```

### 基本算法

```cpp
// 构造函数
for (i=0; i<size; i++) parent[i] = -1;

// Find
int Find(int x) {
    if (parent[x] < 0) return x;
    else return Find(parent[x]);
}

// Union（简单版）
void Union(int Root1, int Root2) {
    parent[Root1] += parent[Root2];  // 更新总数（负数相加）
    parent[Root2] = Root1;           // Root2 挂到 Root1 下
}
```

### 性能问题

连续 Union(0,1), Union(1,2), … 产生**退化链**，Find 最坏 O(n)，n 次 Find 总 O(n²)。

---

## 优化策略

### 1. 按结点个数合并（WeightedUnion）

```cpp
if (parent[Root2] < parent[Root1]) {  // Root2 结点更多（更负）
    parent[Root1] = Root2;
    parent[Root2] += parent[Root1];
} else { /* Root1 作根 */ }
```

**小树挂大树**，树高 O(log n)。

### 2. 按树高度合并（UnionByHeight）

维护树高，高树作根；高度相同时才 +1。

### 3. 路径压缩（Path Compression）

Find 时将路径上所有结点**直接指向根**：

```cpp
int Find(int x) {
    if (parent[x] < 0) return x;
    else {
        parent[x] = Find(parent[x]);  // 路径压缩
        return parent[x];
    }
}
```

**Union + 路径压缩**：均摊接近 **O(1)**；m 次操作 O(m·α(n))，α 为反 Ackermann 函数。

---

## 等价类求解流程

```
1. UFSets(n) 初始化 n 个单元素集
2. 对每个等价对 (i,j):
     x = Find(i); y = Find(j)
     if (x != y) Union(x, y)
3. 相同 Find 值的元素属同一等价类
```

# AVL 树（★★★）

#data-structure #search #tree #avl #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **定义** | 高度平衡的 BST：左右子树均为 AVL 树，高度差绝对值 ≤ 1 |
| **平衡因子 bf** | bf = 右子树高度 − 左子树高度；AVL 树中 bf ∈ {-1, 0, 1} |
| **搜索** | O(log₂n)（保证平衡 → 高度 O(log₂n)） |
| **旋转** | 4 种：左单旋(LL)、右单旋(RR)、先左后右(LR)、先右后左(RL) |
| **插入** | 插入后沿路径回溯，发现不平衡即旋转 |

## AVL 树定义

**AVL 树**（Adelson-Velsky & Landis）：或为空树，或满足：
1. 是一棵**二叉搜索树**
2. 左子树和右子树都是 AVL 树
3. **|左子树高度 − 右子树高度| ≤ 1**

**平衡因子**（Balance Factor）：

$$bf(v) = height(v.right) - height(v.left)$$

AVL 树中每个结点的 bf 只能取 **-1、0、1**。

> [!important] AVL 树的高度保证
> n 个结点的 AVL 树高度为 **O(log₂n)**，因此搜索、插入、删除均为 **O(log₂n)**。

## 四种平衡化旋转

插入新结点后，沿插入路径回溯检查平衡因子。发现不平衡时，取**三个关键结点**进行旋转：

### 判断旋转类型

| 不平衡形状 | 三结点关系 | 旋转类型 |
|-----------|-----------|----------|
| 右子树的右子树高 (bf=+2, 右子bf=+1) | **一条直线（右-右）** | **左单旋转** |
| 左子树的左子树高 (bf=-2, 左子bf=-1) | **一条直线（左-左）** | **右单旋转** |
| 左子树的右子树高 (bf=-2, 左子bf=+1) | **折线（左-右）** | **先左后右双旋转** |
| 右子树的左子树高 (bf=+2, 右子bf=-1) | **折线（右-左）** | **先右后左双旋转** |

### 左单旋转（RotateLeft）—— 右-右型

```
    A(+2)              C(0)
   / \               /   \
  B   C(+1)  -->   A(0)   E
     / \          / \
    D   E        B   D
```

**操作**：C 上升替代 A；A 成为 C 的左子女；D 成为 A 的右子女。

```
RotateL(ptr):          // ptr 指向 A
  subL = ptr           // A
  ptr = subL.right     // C 上升
  subL.right = ptr.left // D → A.right
  ptr.left = subL      // A → C.left
  ptr.bf = subL.bf = 0
```

### 右单旋转（RotateRight）—— 左-左型

```
      A(-2)           B(0)
     / \             /   \
   B(-1) E  -->    D    A(0)
   / \                  / \
  D   C                C   E
```

**操作**：B 上升替代 A；A 成为 B 的右子女；C 成为 A 的左子女。

### 先左后右双旋转（RotateLR）—— 左-右型

```
      A(-2)          A(-2)          E(0)
     / \            / \            /   \
   B(+1) G  -->  E(-1) G  -->  B(0)  A(0)
   / \           / \            / \   / \
  D  E(?)      B   F          D   C F   G
    / \       / \
   C   F     D   C
```

**两步**：先对 B 做左单旋转，再对 A 做右单旋转。

### 先右后左双旋转（RotateRL）—— 右-左型

与 LR 镜像对称：先对右子女做右单旋转，再对根做左单旋转。

## AVL 树插入流程

```
1. 按 BST 规则插入新结点（叶结点）
2. 从插入点沿路径向根回溯
3. 更新各结点的平衡因子
4. 若某结点 |bf| = 2：
   a. 判断旋转类型（LL/RR/LR/RL）
   b. 执行对应旋转
   c. 旋转后子树高度恢复 → 停止回溯
```

> [!tip] 插入只需一次旋转
> AVL 树插入至多执行**一次旋转**（单旋或双旋）即可恢复平衡。

---

## AVL 树 vs 普通 BST

| 比较维度 | BST | AVL 树 |
|---------|-----|--------|
| **最坏搜索** | O(n)（退化为链） | **O(log₂n)** |
| **插入复杂度** | O(h) | O(log₂n) + 旋转 O(1) |
| **删除复杂度** | O(h) | O(log₂n) + 可能多次旋转 |
| **实现复杂度** | 简单 | 需维护平衡因子 + 旋转 |
| **适用场景** | 随机数据 | 需保证最坏性能 |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "判断是否为 AVL 树" | **检查每个结点 \|bf\| ≤ 1** |
| "插入后需要哪种旋转" | **看三结点是直线（单旋）还是折线（双旋）** |
| "左-右型不平衡" | **先左后右双旋转（LR 旋转）** |
| "AVL 树搜索最坏复杂度" | **O(log₂n)**（不会退化） |
| "画出依次插入序列后的 AVL 树" | **每次插入后检查平衡，必要时旋转** |
| "bf = 右子树高 - 左子树高" | **注意定义方向，有些教材相反** |

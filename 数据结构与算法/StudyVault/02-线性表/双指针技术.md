# 双指针技术（★★★）

#data-structure #linear #two-pointer #algorithm-technique

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **核心思想** | 用两个指针协同遍历，避免嵌套循环，将 O(n²) 降为 O(n) |
| **快慢指针** | 同起点，不同速度前进；用于链表环检测、找中点、找倒数第 k 个 |
| **左右指针** | 分居两端，向中间靠拢；用于有序数组求和、容器盛水、回文判断 |
| **同向双指针** | 同起点同方向，一快一慢；用于原地去重、滑动窗口 |
| **前提条件** | 通常要求数据有序或具有单调性；不满足时双指针可能失效 |

## 一、快慢指针（Fast-Slow Pointer）

### 原理

两个指针从同一位置出发，fast 每次走 2 步（或更多），slow 每次走 1 步。

### 典型应用

#### 1. 链表环检测（Floyd 判圈法）

```cpp
bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

**不变量**：每轮迭代后，fast 与 slow 在环内的距离差减少 1。

**为什么一定能相遇？** 设环长为 C。当 slow 刚进环时，fast 已在环内某处，两者距离为 d（0 ≤ d < C）。每轮距离减 1，恰好 d 轮后距离变为 0，即相遇。

#### 2. 找环入口

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            // 相遇后：一个从 head 出发，一个从相遇点出发，都走 1 步
            ListNode* p = head;
            while (p != slow) {
                p = p->next;
                slow = slow->next;
            }
            return p;
        }
    }
    return nullptr;
}
```

**数学推导**：设起点到环入口距离为 a，环入口到相遇点距离为 b，相遇点回到环入口距离为 c。相遇时 slow 走了 a+b，fast 走了 a+b+k(b+c)。因为 fast 速度是 slow 的 2 倍：2(a+b) = a+b+k(b+c) → a = (k-1)(b+c)+c。所以从 head 和相遇点同时出发，各走 1 步，必在**环入口**相遇。

#### 3. 找链表中点

```cpp
ListNode* findMiddle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow; // fast 到末尾时，slow 恰好在中间
}
```

## 二、左右指针（对撞指针）

### 原理

两个指针分别从**最左端**和**最右端**出发，根据条件向中间靠拢。

### 前提条件

数据通常需要**有序**或具有某种**单调性**。如果无序，左右指针的移动方向就没有依据。

### 典型应用

#### 1. 有序数组两数之和

```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left < right) {
        int sum = nums[left] + nums[right];
        if (sum == target) return {left, right};
        else if (sum < target) left++;   // 和太小，左指针右移增大
        else right--;                     // 和太大，右指针左移减小
    }
    return {};
}
```

**不变量**：答案（如果存在）一定在 `nums[left..right]` 范围内。

**为什么正确？** 当 `sum < target` 时，`nums[left] + nums[right]` 已经是 left 能配对的最大值了（right 在最右端），所以 left 不可能是答案的一部分，可以安全右移。反之同理。

**暴力法**需要 O(n²) 枚举所有对；利用有序性 + 双指针只需 **O(n)**。

#### 2. 判断回文串

```cpp
bool isPalindrome(string& s) {
    int left = 0, right = s.size() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++;
        right--;
    }
    return true;
}
```

#### 3. 盛最多水的容器

```cpp
int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1, ans = 0;
    while (left < right) {
        int area = min(height[left], height[right]) * (right - left);
        ans = max(ans, area);
        if (height[left] < height[right]) left++;
        else right--;
    }
    return ans;
}
```

**为什么移动短板？** 面积 = min(h_l, h_r) × 宽度。移动长板 → 宽度减小，min 不会增大 → 面积只会更小。所以只有移动短板才可能得到更大面积。

## 三、同向双指针（读写指针/滑动窗口）

### 原理

两个指针同方向移动：一个"读"（fast/right），一个"写"（slow/left）。

### 典型应用

#### 1. 有序数组原地去重

```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
```

**不变量**：`nums[0..slow]` 互不重复，且包含 `nums[0..fast-1]` 中所有不同值。

#### 2. 移除指定值

```cpp
int removeElement(vector<int>& nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.size(); fast++) {
        if (nums[fast] != val) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;
}
```

**不变量**：`nums[0..slow-1]` 中不含 val。

## 四、双指针能把 O(n²) 降到 O(n) 的根本原因

暴力法用两层循环枚举所有 (i, j) 对 → O(n²)。

双指针之所以能降为 O(n)，是因为利用了**问题的单调性**来**排除大量无效组合**：

- **左右指针**：有序数组中 sum < target 时，left 右移后 sum 只增不减，所以之前 left 配更小 right 的组合全部可以跳过
- **快慢指针**：已扫描过的元素不需要回头重新比较

> [!warning] 双指针失效的情况
> 如果数据**无序**且问题不具备单调性，双指针的"跳过"逻辑不成立，此时不能用双指针替代暴力枚举。例如无序数组的两数之和就不能用左右指针（需要先排序或用哈希表）。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "快慢指针判环" | fast 走 2 步、slow 走 1 步，**相遇即有环** |
| "找环入口" | 相遇后从 head 和相遇点各走 1 步，**再次相遇即入口** |
| "找链表中点" | fast 到尾时 slow 在中间 |
| "有序数组两数之和 O(n)" | **左右指针**对撞 |
| "原地去重返回新长度" | **同向双指针**，slow 写、fast 读 |
| "双指针为何能降低复杂度" | 利用**单调性排除无效组合** |
| "双指针前提条件" | 数据有序或问题具有**单调性** |

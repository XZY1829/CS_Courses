`LOC(i,j) = LOC(0,0) + (i×n + j) × d`

**对称矩阵压缩**（下三角，k 从 0 起）：
`k = i(i+1)/2 + j`（i ≥ j）

## 第5章 树与二叉树 → [[树的基本概念与二叉树]]、[[二叉树遍历与线索化]]、[[堆]]、[[Huffman树与编码]]

**二叉树 5 性质**：

| # | 性质 |
|---|------|
| 1 | 第 i 层最多 **2^(i-1)** 个结点 |
| 2 | 深度 k 的二叉树最多 **2^k - 1** 个结点 |
| 3 | **n₀ = n₂ + 1**（叶结点 = 度2结点 + 1） |
| 4 | n 个结点完全二叉树深度 **⌈log₂(n+1)⌉** |
| 5 | 完全二叉树编号：父 ⌊i/2⌋，左子 2i，右子 2i+1 |

**遍历**：前序(根左右) / 中序(左根右) / 后序(左右根) / 层次序(BFS)

**堆**：建堆 O(n)；插入/删除 O(logn)

**Huffman**：WPL 最小；构造取两最小合并；前缀编码

## 第6章 集合与字典 → [[集合与并查集]]、[[字典与散列]]

**并查集**：Find O(α(n)) ≈ O(1)（路径压缩+按秩合并）

**散列函数**：除留余数法 h(k) = k mod p（p 取素数）

**冲突解决**：线性探测 / 二次探测 / 双散列 / 链地址法

**装载因子** α = n/m；ASL 与 α 相关

## 第7章 搜索结构 → [[静态搜索与二叉搜索树]]、[[AVL树]]

| 方法 | ASL | 条件 |
|------|-----|------|
| 顺序搜索 | (n+1)/2 | 无序 |
| 折半搜索 | ≈ log₂(n+1)-1 | 有序数组 |
| BST | O(logn)~O(n) | BST |

**AVL 旋转**：直线→单旋(LL/RR)；折线→双旋(LR/RL)

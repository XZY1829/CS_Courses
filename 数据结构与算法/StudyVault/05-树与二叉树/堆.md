# 堆（★★★）

#data-structure #tree #heap #binary-tree #time-complexity #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **最小堆** | 完全二叉树，Ki ≤ K₂ᵢ₊₁ 且 Ki ≤ K₂ᵢ₊₂ |
| **最大堆** | Ki ≥ K₂ᵢ₊₁ 且 Ki ≥ K₂ᵢ₊₂ |
| **存储** | 下标 0 起的一维数组（完全二叉树顺序表示） |
| **建堆** | **筛选法**（自底向上 siftDown）O(n)；**插入法**逐元素 siftUp |
| **插入** | 末尾加入 → siftUp，O(log n) |
| **删除** | 根与末尾交换 → siftDown，O(log n) |
| **堆排序** | 建最大堆 + 反复取顶放到末尾并调整 |

## 堆的定义

**堆**是一种特殊的**完全二叉树**，用数组存储。

| 类型 | 堆序性质 |
|------|----------|
| **最小堆** | Kᵢ ≤ K₂ᵢ₊₁ 且 Kᵢ ≤ K₂ᵢ₊₂ |
| **最大堆** | Kᵢ ≥ K₂ᵢ₊₁ 且 Kᵢ ≥ K₂ᵢ₊₂ |

根结点为**最小/最大**元素，适合实现**优先级队列**（参见 [[队列与优先级队列]]）。

### 下标关系（0 基数组）

| 结点 i | 关系 |
|--------|------|
| i = 0 | 根，无双亲 |
| i > 0 | **父** ⌊(i-1)/2⌋ |
| 2i+1 ≤ n-1 | **左子女** 2i+1 |
| 2i+2 ≤ n-1 | **右子女** 2i+2 |

---

## 建堆

### 筛选法（Floyd 建堆，推荐）

从**最后一个分支结点** ⌊(n-2)/2⌋ 开始，自底向上对每个结点执行 **siftDown**。

```
初始: 53 17 23 45 78 65 87 09
      currentPos = 3 → 2 → 1 → 0，逐步 siftDown
结果: 09 17 23 45 78 65 87 53  (最小堆)
```

**时间复杂度 O(n)**（优于 n 次插入的 O(n log n)）。

### 插入法

逐个元素插入堆尾并 siftUp，共 n 次，**O(n log n)**。

---

## siftDown（向下筛选）

用于建堆和删除后调整（最小堆）：

```cpp
void siftDown(int start, int m) {
    i = start; j = 2*i+1; temp = heap[i];
    while (j <= m) {
        if (j < m && heap[j] > heap[j+1]) j++;  // 指向较小子女
        if (temp <= heap[j]) break;
        heap[i] = heap[j]; i = j; j = 2*j+1;
    }
    heap[i] = temp;
}
```

```
siftDown(0):  09
             /  \
           17    23    →  与较小子女交换，逐层下沉
          / \   / \
        45 78 65 87
```

---

## siftUp（向上筛选）

用于插入（最小堆）：

```cpp
void siftUp(int start) {
    j = start; i = (j-1)/2; temp = heap[j];
    while (j > 0) {
        if (heap[i] <= temp) break;
        heap[j] = heap[i]; j = i; i = (i-1)/2;
    }
    heap[j] = temp;
}
```

**插入 11** 到最小堆：末尾 → siftUp 与 09 交换 → 到根。

## 堆的插入与删除

### 插入 Insert(x)

1. heap[currentSize] = x
2. siftUp(currentSize)
3. currentSize++
4. **O(log₂ n)**

### 删除 Remove(x) — 删除堆顶

1. x = heap[0]（最小元素）
2. heap[0] = heap[currentSize-1]；currentSize--
3. siftDown(0, currentSize-1)
4. **O(log₂ n)**

```
删除前: 09/11/17/53/23/45/78/65/87
输出 09 → 11 移到根 → siftDown → 新堆 11/23/17/53/87/45/78/65
```

---

## 堆排序简介

基于**最大堆**（参见 [[排序算法综合比较]]）：

```
1. 对 n 个元素建最大堆          O(n)
2. for i = n-1 down to 1:
       swap(heap[0], heap[i])   // 最大元放到末尾
       siftDown(0, i-1)         // 调整剩余部分
总时间 O(n log n)，空间 O(1)（原地）
```

> [!warning] 稳定性
> 堆排序是**不稳定**排序。

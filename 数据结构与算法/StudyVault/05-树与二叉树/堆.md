# 堆（★★★）

#data-structure #tree #heap #binary-tree #priority-queue #time-complexity #concept

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| **结构条件** | 堆首先是一棵**完全二叉树**，因此适合用数组顺序存储 |
| **最小堆** | 每个父结点都不大于它的孩子，堆顶是全局最小值 |
| **最大堆** | 每个父结点都不小于它的孩子，堆顶是全局最大值 |
| **局部有序** | 只保证父子路径上的顺序，不保证兄弟之间、左右子树之间整体有序 |
| **访问堆顶** | `O(1)` |
| **插入** | 末尾加入，再 `siftUp`，时间 `O(log n)` |
| **删除堆顶** | 末尾元素补到根，再 `siftDown`，时间 `O(log n)` |
| **Floyd 建堆** | 从最后一个非叶结点开始自底向下调整，时间 `O(n)` |
| **逐个插入建堆** | 依次插入并向上调整，最坏时间 `O(n log n)` |
| **典型用途** | 优先级队列、Top K、第 K 大、合并有序序列、任务调度、堆排序 |

## 1. 堆到底是什么

堆需要同时满足两个条件：

1. **结构条件**：它是一棵完全二叉树。
2. **顺序条件**：任意父结点与其孩子满足统一的大小关系。

设数组下标从 `0` 开始，只对实际存在的孩子讨论：

- 最小堆：`heap[parent] <= heap[child]`
- 最大堆：`heap[parent] >= heap[child]`

因为从任意结点沿父链走到根都保持堆序，所以：

- 最小堆的根一定是全局最小值；
- 最大堆的根一定是全局最大值。

> [!warning] 堆不是“完全排好序的数组”
> 最小堆只保证祖先不大于后代。兄弟结点之间没有顺序要求，左子树的元素也不一定都小于右子树的元素。
>
> 例如 `[1, 8, 3, 10, 9, 6, 5]` 是最小堆，但数组本身并非升序。

### 堆、二叉搜索树和有序数组的区别

| 结构 | 主要保证 | 取最小值 | 插入 | 查找任意值 |
|------|----------|----------|------|------------|
| 最小堆 | 父结点不大于孩子 | `O(1)` | `O(log n)` | `O(n)` |
| 平衡二叉搜索树 | 左子树 < 根 < 右子树 | `O(log n)` | `O(log n)` | `O(log n)` |
| 有序数组 | 整体有序 | `O(1)` | `O(n)` | `O(log n)` |

堆擅长的是“不断取出当前最优元素”，不适合查找一个任意元素是否存在。

## 2. 为什么堆通常用数组存储

完全二叉树除最后一层外都是满的，最后一层又从左向右连续，因此按层序放入数组不会留下空洞，也不需要保存左右孩子指针。

### 0 基数组下标关系

设堆中共有 `n` 个元素，当前结点下标为 `i`：

| 关系 | 公式 | 存在条件 |
|------|------|----------|
| 父结点 | `(i - 1) / 2`（整数除法） | `i > 0` |
| 左孩子 | `2 * i + 1` | `2 * i + 1 < n` |
| 右孩子 | `2 * i + 2` | `2 * i + 2 < n` |
| 最后一个非叶结点 | `n / 2 - 1` | `n >= 2` |
| 第一个叶结点 | `n / 2` | `n > 0` |

> [!tip] 为什么最后一个非叶结点是 `n / 2 - 1`
> 下标从 `n / 2` 到 `n - 1` 的结点都没有左孩子，因此都是叶结点；其前一个位置就是最后一个可能有孩子的结点。

### 数组与树的对应

最小堆：

```text
下标:  0   1   2   3   4   5   6   7
数组: [9, 17, 23, 45, 78, 65, 87, 53]

                 9(0)
              /       \
          17(1)       23(2)
          /   \       /   \
      45(3) 78(4) 65(5) 87(6)
       /
    53(7)
```

每个父结点都不大于自己的孩子，但 `17` 与 `23`、`78` 与 `65` 之间不需要满足任何固定顺序。

## 3. 核心操作一：siftUp（向上调整）

### 什么时候使用

向最小堆插入新元素时，先把它放到数组末尾。完全二叉树的结构仍然成立，但新元素可能比父结点小，破坏父子堆序，因此需要沿父链向上调整。

### 最小堆调整规则

1. 记录新元素 `value` 和它的下标 `child`。
2. 若 `value >= heap[parent]`，堆序已经恢复，停止。
3. 否则把父结点下移到孩子位置，继续检查更上一层。
4. 最后把 `value` 写入停止位置。

采用“移动父结点、最后写一次新值”的方式，比每层都执行三次赋值的 `swap` 更省操作。

### 示例：插入 11

原最小堆：

```text
[9, 17, 23, 45, 78, 65, 87, 53]
```

把 `11` 放到末尾，下标为 `8`：

```text
[9, 17, 23, 45, 78, 65, 87, 53, 11]
```

上浮过程：

1. `parent(8) = 3`，`11 < 45`，越过 `45`；
2. 当前下标变为 `3`，`parent(3) = 1`，`11 < 17`，越过 `17`；
3. 当前下标变为 `1`，`parent(1) = 0`，`11 >= 9`，停止。

最终结果：

```text
[9, 11, 23, 17, 78, 65, 87, 53, 45]
```

> [!warning] 易错点
> `11` 不会与根结点 `9` 交换。向上调整只在孩子比父结点更小时继续。

### 复杂度

完全二叉树高度为 `O(log n)`。最坏情况下新元素从叶结点一路到根，因此插入是 `O(log n)`；最好情况下无需移动，为 `O(1)`。

## 4. 核心操作二：siftDown（向下调整）

### 什么时候使用

- 删除堆顶后，把末尾元素移到根；
- Floyd 建堆时，调整每一棵局部子树；
- 堆排序中交换堆顶与末尾元素后，恢复剩余区间的堆序。

### 最小堆调整规则

1. 比较左右孩子，找到其中**较小的孩子**。
2. 若当前值不大于较小孩子，说明它也不大于另一个孩子，可以停止。
3. 否则把较小孩子上移，当前值继续向下寻找位置。

> [!important] 为什么必须选择较小的孩子
> 如果与较大的孩子交换，较小孩子仍可能小于新的父结点，交换后堆序依然不成立。

### 示例：删除堆顶 9

原堆：

```text
[9, 17, 23, 45, 78, 65, 87, 53]
```

删除 `9`，用末尾的 `53` 补到根：

```text
[53, 17, 23, 45, 78, 65, 87]
```

向下调整：

1. 根的孩子是 `17` 和 `23`，选择较小的 `17` 上移；
2. `53` 到达下标 `1`，孩子是 `45` 和 `78`，选择 `45` 上移；
3. `53` 到达下标 `3`，已经没有孩子，停止。

最终结果：

```text
[17, 45, 23, 53, 78, 65, 87]
```

### 只有左孩子怎么办

完全二叉树中，一个结点如果只有一个孩子，这个孩子一定是左孩子。循环只要先判断左孩子是否存在，再单独判断右孩子，就不会越界。

### 复杂度

最坏情况下元素从根下沉到叶结点，经过树高 `O(log n)` 层，因此删除堆顶是 `O(log n)`。

## 5. 建堆

给定一个无序数组，目标是在原数组上重新排列，使其满足堆序。

### 方法一：逐个插入

从空堆开始，依次把 `n` 个元素插入：

```text
第 1 个元素调整 O(log 1)
第 2 个元素调整 O(log 2)
...
第 n 个元素调整 O(log n)
```

总时间上界为 `O(n log n)`。这种方法适合数据逐个到达的在线场景。

### 方法二：Floyd 自底向上建堆

数组中的叶结点天然就是合法的小堆，因此只需从最后一个非叶结点 `n / 2 - 1` 开始，逆序对每个结点执行 `siftDown`。

以无序数组为例：

```text
[53, 17, 23, 45, 78, 65, 87, 9]
```

从 `i = 3` 开始：

```text
i = 3: [53, 17, 23,  9, 78, 65, 87, 45]
i = 2: [53, 17, 23,  9, 78, 65, 87, 45]  // 23 已不大于孩子
i = 1: [53,  9, 23, 17, 78, 65, 87, 45]
i = 0: [ 9, 17, 23, 45, 78, 65, 87, 53]
```

最终得到最小堆。

### 为什么 Floyd 建堆是 O(n)

不能简单地说“有 `n/2` 个结点，每个都调整 `log n` 层”，因为靠近叶子的绝大多数结点只能下沉很少几层：

- 高度为 `0` 的叶结点约有 `n/2` 个，不需要调整；
- 高度为 `1` 的结点最多约有 `n/4` 个，每个最多下沉 `1` 层；
- 高度为 `2` 的结点最多约有 `n/8` 个，每个最多下沉 `2` 层；
- 依此类推。

总工作量可估计为：

```text
T(n) <= n/4 * 1 + n/8 * 2 + n/16 * 3 + ...
     = n * (1/4 + 2/8 + 3/16 + ...)
     < n
     = O(n)
```

关键原因是：**需要调整很多层的结点很少，而数量很多的结点离叶子很近。**

> [!question] 为什么循环从 `n / 2` 递减而不是直接写无符号下标 `i >= 0`
> C++ 的 `std::size_t` 是无符号类型，`0 - 1` 会下溢成一个巨大整数。安全写法是 `for (std::size_t i = n / 2; i > 0; --i) siftDown(i - 1);`。

## 6. 可直接运行的 C++ 最小堆

下面的实现覆盖批量建堆、查询堆顶、插入和删除堆顶，并处理空堆、单元素堆与重复元素。

<!-- heap-example:start -->
```cpp
#include <cassert>
#include <cstddef>
#include <functional>
#include <iostream>
#include <queue>
#include <stdexcept>
#include <utility>
#include <vector>

class MinHeap {
private:
    std::vector<int> data_;

    void siftUp(std::size_t child) {
        const int value = data_[child];

        while (child > 0) {
            const std::size_t parent = (child - 1) / 2;
            if (data_[parent] <= value) {
                break;
            }

            data_[child] = data_[parent];
            child = parent;
        }

        data_[child] = value;
    }

    void siftDown(std::size_t parent) {
        const std::size_t n = data_.size();
        const int value = data_[parent];
        std::size_t child = parent * 2 + 1;

        while (child < n) {
            const std::size_t right = child + 1;
            if (right < n && data_[right] < data_[child]) {
                child = right;
            }

            if (value <= data_[child]) {
                break;
            }

            data_[parent] = data_[child];
            parent = child;
            child = parent * 2 + 1;
        }

        data_[parent] = value;
    }

public:
    MinHeap() = default;

    explicit MinHeap(std::vector<int> values)
        : data_(std::move(values)) {
        for (std::size_t i = data_.size() / 2; i > 0; --i) {
            siftDown(i - 1);
        }
    }

    [[nodiscard]] bool empty() const noexcept {
        return data_.empty();
    }

    [[nodiscard]] std::size_t size() const noexcept {
        return data_.size();
    }

    [[nodiscard]] int top() const {
        if (empty()) {
            throw std::out_of_range("top() called on an empty heap");
        }
        return data_.front();
    }

    void push(int value) {
        data_.push_back(value);
        siftUp(data_.size() - 1);
    }

    void pop() {
        if (empty()) {
            throw std::out_of_range("pop() called on an empty heap");
        }

        if (data_.size() == 1) {
            data_.pop_back();
            return;
        }

        data_.front() = data_.back();
        data_.pop_back();
        siftDown(0);
    }
};

int main() {
    MinHeap heap({53, 17, 23, 45, 78, 65, 87, 9});
    assert(heap.size() == 8);
    assert(heap.top() == 9);

    heap.push(11);
    assert(heap.size() == 9);
    assert(heap.top() == 9);

    const std::vector<int> expected{
        9, 11, 17, 23, 45, 53, 65, 78, 87
    };
    for (int value : expected) {
        assert(heap.top() == value);
        heap.pop();
    }
    assert(heap.empty());

    MinHeap duplicates({2, 2, 1, 1});
    assert(duplicates.top() == 1);

    MinHeap single;
    single.push(42);
    assert(single.top() == 42);
    single.pop();
    assert(single.empty());

    bool topThrew = false;
    try {
        (void)single.top();
    } catch (const std::out_of_range&) {
        topThrew = true;
    }
    assert(topThrew);

    bool popThrew = false;
    try {
        single.pop();
    } catch (const std::out_of_range&) {
        popThrew = true;
    }
    assert(popThrew);

    std::priority_queue<int> maxHeap;
    std::priority_queue<
        int,
        std::vector<int>,
        std::greater<int>
    > minHeap;
    maxHeap.push(3);
    minHeap.push(3);
    assert(maxHeap.top() == 3 && minHeap.top() == 3);

    std::cout << "heap example: PASS\n";
}
```
<!-- heap-example:end -->

### 实现中的三个关键细节

1. `siftUp` 和 `siftDown` 先保存待移动值，再移动路径上的结点，最后只写回一次。
2. `pop()` 必须在调用 `siftDown(0)` 前处理单元素堆，否则数组清空后下标 `0` 不存在。
3. 批量建堆使用 `i > 0` 和 `i - 1`，避免 `std::size_t` 下溢。

## 7. C++ 标准库 priority_queue

`std::priority_queue` 默认使用 `std::vector` 作为底层容器，默认是最大堆。

```cpp
#include <functional>
#include <queue>
#include <vector>

std::priority_queue<int> maxHeap;

std::priority_queue<
    int,
    std::vector<int>,
    std::greater<int>
> minHeap;
```

常用接口：

| 接口 | 含义 | 复杂度 |
|------|------|--------|
| `top()` | 读取堆顶，不删除 | `O(1)` |
| `push(x)` / `emplace(...)` | 插入元素 | `O(log n)` |
| `pop()` | 删除堆顶，不返回值 | `O(log n)` |
| `empty()` | 是否为空 | `O(1)` |
| `size()` | 元素数量 | `O(1)` |

> [!warning] `pop()` 没有返回值
> 需要先保存 `top()`，再调用 `pop()`。对空优先队列调用 `top()` 或 `pop()` 不安全，应先检查 `empty()`。

### 自定义类型比较器

假设任务包含 `{priority, name}`，数字越小优先级越高：

```cpp
#include <string>

struct Task {
    int priority;
    std::string name;
};

struct Earlier {
    bool operator()(const Task& a, const Task& b) const {
        return a.priority > b.priority;
    }
};

std::priority_queue<Task, std::vector<Task>, Earlier> tasks;
```

记忆方法：比较器返回 `true` 表示 `a` 的优先级应排在 `b` 后面。这个方向经常与直觉相反。

## 8. 典型应用

### 8.1 求前 K 大元素

维护一个容量不超过 `k` 的**最小堆**：

1. 前 `k` 个元素直接入堆；
2. 后续元素若不大于堆顶，忽略；
3. 若大于堆顶，删除堆顶并插入新元素；
4. 扫描结束后，堆中就是最大的 `k` 个元素。

```cpp
std::vector<int> topKLargest(const std::vector<int>& nums, std::size_t k) {
    if (k == 0) {
        return {};
    }

    std::priority_queue<
        int,
        std::vector<int>,
        std::greater<int>
    > candidates;

    for (int value : nums) {
        if (candidates.size() < k) {
            candidates.push(value);
        } else if (value > candidates.top()) {
            candidates.pop();
            candidates.push(value);
        }
    }

    std::vector<int> result;
    while (!candidates.empty()) {
        result.push_back(candidates.top());
        candidates.pop();
    }
    return result;  // 当前为升序
}
```

- 时间：`O(n log k)`
- 空间：`O(k)`

当 `k` 远小于 `n` 时，它通常比把全部元素排序的 `O(n log n)` 更合适。

### 8.2 求第 K 大元素

使用同样的容量为 `k` 的最小堆。扫描结束后：

- 堆中保留最大的 `k` 个元素；
- 堆顶是这 `k` 个元素中最小的；
- 因此堆顶就是整个数组的第 `k` 大元素。

需要先验证 `1 <= k <= n`。

### 8.3 合并 K 个有序序列

把每个序列的当前最小候选放入最小堆。每取出一个元素，就把它所在序列的下一个元素加入堆。

若总元素数为 `N`，堆大小最多为 `K`：

- 时间：`O(N log K)`
- 空间：`O(K)`

### 8.4 任务调度与事件模拟

用堆顶维护“下一项要执行的任务”：

- 操作系统按优先级选择任务；
- 定时器按触发时间选择最近事件；
- Dijkstra 算法按当前最短距离取结点；
- 仿真系统按事件发生时间处理事件。

## 9. 堆排序

若要得到**升序数组**，使用最大堆：

1. 将整个数组建成最大堆，最大值位于下标 `0`；
2. 交换堆顶与当前未排序区间的最后一个元素；
3. 缩小堆的有效范围；
4. 对新的堆顶执行 `siftDown`；
5. 重复直到堆中只剩一个元素。

```cpp
void siftDownMax(
    std::vector<int>& values,
    std::size_t root,
    std::size_t end
) {
    const int value = values[root];
    std::size_t child = root * 2 + 1;

    while (child < end) {
        const std::size_t right = child + 1;
        if (right < end && values[child] < values[right]) {
            child = right;
        }
        if (value >= values[child]) {
            break;
        }
        values[root] = values[child];
        root = child;
        child = root * 2 + 1;
    }
    values[root] = value;
}

void heapSort(std::vector<int>& values) {
    for (std::size_t i = values.size() / 2; i > 0; --i) {
        siftDownMax(values, i - 1, values.size());
    }

    for (std::size_t end = values.size(); end > 1; --end) {
        std::swap(values[0], values[end - 1]);
        siftDownMax(values, 0, end - 1);
    }
}
```

| 指标 | 结论 |
|------|------|
| 建堆 | `O(n)` |
| n - 1 次取最大值并调整 | `O(n log n)` |
| 总时间 | 最好、平均、最坏均为 `O(n log n)` |
| 额外空间 | `O(1)`，原地排序 |
| 稳定性 | **不稳定** |

堆排序的优势是最坏时间有保证且额外空间小；缺点是缓存局部性通常不如快速排序，而且不稳定。参见 [[排序算法综合比较]]。

## 10. 操作复杂度总表

| 操作 | 时间复杂度 | 原因 |
|------|------------|------|
| 读取堆顶 | `O(1)` | 根固定在数组下标 `0` |
| 插入 | `O(log n)` | 最多沿父链走到根 |
| 删除堆顶 | `O(log n)` | 最多沿孩子链走到叶 |
| Floyd 建堆 | `O(n)` | 各高度结点调整成本的加权和收敛 |
| 逐个插入建堆 | `O(n log n)` | 执行 n 次插入 |
| 搜索任意元素 | `O(n)` | 堆不是全序，通常不能二分 |
| 堆排序 | `O(n log n)` | 建堆后执行 n 次堆顶调整 |
| Top K（容量 k 的堆） | `O(n log k)` | 每个元素至多触发一次 `log k` 调整 |

## 11. 高频易错点

1. **把堆当成有序数组**：只能直接确定堆顶，不能确定第二小元素一定在固定下标。
2. **混用 0 基与 1 基公式**：0 基左孩子为 `2i + 1`；1 基左孩子才是 `2i`。
3. **最小堆向下调整时选较大孩子**：应选较小孩子，否则无法恢复最小堆。
4. **认为建堆总是 `O(n log n)`**：逐个插入是该复杂度，Floyd 建堆是 `O(n)`。
5. **忘记单元素删除**：移除末尾后数组为空，不能继续访问根。
6. **无符号下标写 `i >= 0`**：`std::size_t` 会下溢，循环可能永不结束。
7. **以为堆排序稳定**：堆顶与末尾的远距离交换会改变相等元素的相对次序。
8. **Top K 选错堆**：求最大的 K 个元素通常维护容量为 K 的最小堆；求最小的 K 个元素则反过来。
9. **忽略重复值**：堆允许重复元素，比较条件应避免相等时无意义地继续移动。
10. **把 `priority_queue::pop()` 当成返回堆顶**：C++ 中要先 `top()`，再 `pop()`。

## 12. 考试/面试常见模式

| 问法 | 关键答案 |
|------|----------|
| 最小堆的根是什么 | 全局最小值 |
| 最小堆中第二小元素在哪里 | 若元素不少于 2 个，只可能是根的左孩子或右孩子 |
| 0 基数组中父结点下标 | `(i - 1) / 2`，前提是 `i > 0` |
| 最后一个非叶结点 | `n / 2 - 1`，前提是 `n >= 2` |
| Floyd 建堆从哪里开始 | 最后一个非叶结点，自底向上 |
| Floyd 建堆复杂度 | `O(n)` |
| 插入、删除堆顶复杂度 | `O(log n)` |
| 求前 K 大使用什么堆 | 容量为 K 的最小堆 |
| 升序堆排序使用什么堆 | 最大堆 |
| 堆排序是否稳定 | 不稳定 |

## 13. 自测题

### 题 1：判断堆

数组 `[2, 5, 3, 9, 7, 4, 8]` 是否为最小堆？

> [!answer]- 答案
> 是。`2 <= 5, 3`，`5 <= 9, 7`，`3 <= 4, 8`，所有实际存在的父子关系都满足最小堆性质。

### 题 2：插入

向最小堆 `[4, 10, 7, 15, 20, 9]` 插入 `5`，最终数组是什么？

> [!answer]- 答案
> `5` 先放到下标 `6`，父结点为下标 `2` 的 `7`，交换；新父结点为根 `4`，此时 `5 >= 4`，停止。结果是 `[4, 10, 5, 15, 20, 9, 7]`。

### 题 3：Floyd 建堆

有 `n = 10` 个元素，0 基数组中第一次执行 `siftDown` 的下标是多少？

> [!answer]- 答案
> `n / 2 - 1 = 10 / 2 - 1 = 4`。

### 题 4：Top K

从一亿个整数中找最大的 100 个，内存只允许保存少量候选，应使用什么结构，复杂度是多少？

> [!answer]- 答案
> 使用容量为 100 的最小堆。堆顶是当前候选中最小的元素，新元素只有更大时才替换堆顶。时间 `O(n log 100)`，额外空间 `O(100)`。

### 题 5：堆排序

为什么升序堆排序使用最大堆，而不是最小堆？

> [!answer]- 答案
> 每轮把堆顶交换到未排序区间末尾。最大堆能把当前最大值依次放到数组右侧，从而原地得到升序结果；若使用最小堆，同样操作会得到降序结果。

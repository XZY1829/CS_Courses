# Huffman 树与编码（★★★）

#data-structure #tree #huffman #binary-tree #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **扩充二叉树** | 仅度 2 内结点 + 度 0 外结点（叶）；n 外结点 → n-1 内结点 |
| **WPL** | Σ wᵢ×lᵢ（外结点到根路径长度×权值） |
| **Huffman 树** | WPL 最小的扩充二叉树（最优二叉树） |
| **构造** | 反复合并权值最小的两棵树（用最小堆） |
| **Huffman 编码** | 左 0 右 1；变长、**前缀编码**；总码长 = WPL |

## 路径长度与 WPL

| 概念 | 定义 |
|------|------|
| **路径长度 PL** | 两结点间分支数 |
| **内部路径长度 IPL** | 各非叶结点到根路径长度之和 |
| **外部路径长度 EPL** | 各叶结点到根路径长度之和 |
| **PL** | IPL + EPL |

n 个结点二叉树 PL ≥ Σ⌊log₂ i⌋（i=1..n），**完全二叉树**取等。

### 带权路径长度 WPL

**扩充二叉树**：叶为外结点（权 wᵢ），非叶为内结点。n 个外结点 → n-1 个内结点，总 2n-1 个结点。

```
WPL = Σ(i=1 to n) wᵢ × lᵢ
```
lᵢ 为第 i 个外结点到根的路径长度。同一组权值，结构不同 WPL 不同。

**示例**（权 {2,4,5,7}）：
```
结构1 WPL=36    结构2 WPL=46    最优 WPL=35
  2                7              18
 / \              / \             / \
4  5 7           4  5 7          7  11
                                      / \
                                     5   6
                                    / \
                                   2   4
```

## Huffman 树定义

**Huffman 树（最优二叉树）**：WPL 达到最小的扩充二叉树。
- **权值大的结点离根近**
- 构造结果**不唯一**，但 WPL 相同

---

## Huffman 树构造算法

**输入**：n 个权值 {w₀, w₁, …, wₙ₋₁}

**步骤**：
1. 初始化森林 F = {T₀,…,Tₙ₋₁}，每棵 Ti 仅含权 wᵢ 的根
2. 重复直到 F 只剩一棵树：
   a. 取 F 中**权值最小**的两棵树 T₁, T₂
   b. 新建根，权 = w(T₁)+w(T₂)，左=T₁，右=T₂
   c. 删 T₁,T₂，新树加入 F

**实现**：用**最小堆**维护森林，n-1 次合并。

### 构造过程 ASCII 图

权值 {7, 5, 2, 4}：

```
Step 0:  F = {7} {5} {2} {4}

Step 1:  合并 {2} {4} → {6}
         F = {7} {5} {6}
              6
             / \
            2   4

Step 2:  合并 {5} {6} → {11}
         F = {7} {11}
              11
             /  \
            5    6
                / \
               2   4

Step 3:  合并 {7} {11} → {18}
         F = {18}
              18
             /  \
            7   11
               /  \
              5    6
                  / \
                 2   4
```

**WPL** = 7×1 + 5×2 + 2×3 + 4×3 = 7+10+6+12 = **35**

## Huffman 编码

### 编码规则

1. 以各字符频度/概率为权建 Huffman 树
2. **左分支标 0，右分支标 1**（或反之，需统一）
3. 从根到叶的路径即为该字符编码

### 示例

报文 "CAST CAST SAT AT A TASA"，字符频度 W={C:2, A:7, S:4, T:5}

```
        18
       /  \
      7    11
     A    /  \
        5    6
       T   / \
          S   C
         (2) (4)
```

| 字符 | 等长码(2位) | Huffman 码 | 频度×码长 |
|------|-------------|------------|-----------|
| A | 00 | **0** | 7×1=7 |
| T | 10 | **10** | 5×2=10 |
| C | 01 | **110** | 2×3=6 |
| S | 11 | **111** | 4×3=12 |

- 等长总长度：(2+7+4+5)×2 = **36**
- Huffman 总长度：**35** = WPL

### 前缀编码

**Huffman 编码是前缀编码**：任一码字不是其他码字的前缀，解码无歧义。

> [!warning] 译码方向
> 从左到右扫描比特流，在 Huffman 树上从根出发，0 走左 1 走右，到叶输出字符并回根。

---

## 平均码长

对字符集 D 及概率 P={p₁,…,pₙ}，Huffman 编码**平均码长**：
```
L_avg = Σ pᵢ × lᵢ = WPL / Σwᵢ（若 wᵢ 为频度）
```
理论上接近信源熵 H = -Σ pᵢ log₂ pᵢ。

**作业示例** D={a,b,c,d,e}，P={0.12,0.40,0.15,0.08,0.25}：按 Huffman 算法合并 0.08+0.12=0.20，再与 0.15、0.25、0.40 逐步合并得最优码。

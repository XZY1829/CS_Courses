# 树与森林（★★★）

#data-structure #tree #binary-tree #traversal #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **子女-兄弟表示** | firstChild + nextSibling，即树的二叉树表示 |
| **树→二叉树** | 左指针=第一个孩子，右指针=下一个兄弟 |
| **森林→二叉树** | 各树二叉树化后，前一棵树根右链连接下一棵树 |
| **遍历对应** | 树先根 ≡ 二叉树前序；树后根 ≡ 二叉树中序 |
| **存储方式** | 广义表、双亲、子女链表、子女指针、子女-兄弟 |

## 树的存储表示

| 方式 | 特点 |
|------|------|
| **广义表** | 直观，类似括号表示 A(B(E,F), C, D(G)) |
| **双亲表示** | parent[i] 存父下标；找父 O(1)，找子女需扫描 |
| **子女链表** | 每结点链其子女 |
| **子女指针** | 指针数=树的度，可能大量空指针 |
| **子女-兄弟** | firstChild + nextSibling，最常用 |

### 子女-兄弟表示

```cpp
struct TreeNode {
    T data;
    TreeNode *firstChild;   // 第一个子女
    TreeNode *nextSibling;  // 下一个兄弟
};
```

找某结点所有子女：先 firstChild，再反复 nextSibling。

```
树:        A              存储:
          /|\             A → B → C → D
         B C D             B → E → F
        /|   |            E, F, G 各自 nextSibling=∧
       E F   G
```

## 树与二叉树的转换

**规则**（子女-兄弟 = 二叉树表示）：
- **左指针** → 该结点**第一个孩子**
- **右指针** → 该结点**下一个兄弟**

```
树 A(B(E,F), C, D(G))     二叉树:
        A                    A
       /|\                  /
      B C D                B
     /|   |               / \
    E F   G              E   C
                          \   \
                           F   D
                                \
                                 G
```

---

## 森林与二叉树的转换

### 森林 → 二叉树

1. F 为空 → 空二叉树
2. F 非空：B 的根 = T₁ 的根
3. B 的**左子树** = T₁ 各子树构成的森林的二叉树
4. B 的**右子树** = {T₂,…,Tₙ} 构成的森林的二叉树

```
森林 T1(A,B,C,D,G,E), T2(F), T3(H,I,J,K)
→ 二叉树: A 为根，左链 B-C-D-E-G，右链 F，再右链 H-I-J-K
```

### 二叉树 → 森林

逆过程：根 = 第一棵树根；左子树 → 第一棵树的子树森林；右子树 → 其余树森林。

## 树和森林的遍历

### 树的遍历

| 方式 | 规则 | 示例树 ABEFCDG |
|------|------|----------------|
| **先根** | 访问根 → 依次先根遍历各子树 | ABEFCDG |
| **后根** | 依次后根遍历各子树 → 访问根 | EFBCGDA |
| **层次序** | 广度优先，用队列 | ABCDEFG |

### 与二叉树遍历的对应关系

```
树先根遍历  ≡  对应二叉树前序遍历
树后根遍历  ≡  对应二叉树中序遍历
```

**证明思路**：子女-兄弟表示中，先根"根→各子树"对应前序"根→左子树(第一个孩子及其兄弟链)→…"；后根"各子树→根"对应中序"左(孩子链)→根→右(兄弟链)"。

### 森林的遍历

**先根次序**（F = {T₁, T₂, …, Tₘ}）：
1. 访问 T₁ 的根 r₁
2. 先根遍历 T₁ 的子树森林 {T₁₁,…,T₁ₖ}
3. 先根遍历 {T₂,…,Tₘ}

**后根次序**：
1. 后根遍历 T₁ 的子树森林
2. 访问 r₁
3. 后根遍历 {T₂,…,Tₘ}

**对应关系**：
- 森林先根 ≡ 对应二叉树**前序**
- 森林后根 ≡ 对应二叉树**中序**

**示例**（三棵树森林）先根：**ABCDE FG HIKJ**；后根：**BCEDA GF KIJH**

### 层次序遍历森林

依次遍历各树根 → 各树根的所有子女 → 这些子女的子女 → …

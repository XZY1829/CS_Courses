# 二叉树遍历与线索化（★★★）

#data-structure #tree #binary-tree #traversal #threaded-tree #recursion #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **前序 VLR** | 根 → 左 → 右 |
| **中序 LVR** | 左 → 根 → 右 |
| **后序 LRV** | 左 → 右 → 根 |
| **层次序** | 逐层从左到右，用**队列** |
| **非递归** | 前/中/后序用**栈**；后序可用 tag 标记结点的处理状态 |
| **重建二叉树** | 前序+中序 或 后序+中序 可唯一确定 |
| **线索化** | 利用 n+1 空指针存前驱/后继；ltag/rtag 标志 |

## 四种遍历

对任意非空二叉树，先把整棵树看成“根结点（V）+ 左子树（L）+ 右子树（R）”。前序、中序和后序的名称，取决于**根结点 V 在左、右子树之前、之间还是之后被访问**。

| 遍历 | 访问次序 | 含义 |
|------|----------|------|
| **前序遍历** | VLR | 访问根 → 前序遍历左子树 → 前序遍历右子树 |
| **中序遍历** | LVR | 中序遍历左子树 → 访问根 → 中序遍历右子树 |
| **后序遍历** | LRV | 后序遍历左子树 → 后序遍历右子树 → 访问根 |
| **层次序遍历** | 从上到下、同层从左到右 | 按层访问，通常用队列实现；不属于 V、L、R 的递归排列 |

> 注意：VRL、RVL、RLV 是先右后左的变体，不是通常所说的前序、中序、后序遍历。

**示例树**：

```
        -
       / \
      +     /
     / \   / \
    a   * d   f
       / \   /
      b   c e
```

- **前序** VLR：`- + a * b c / d f e`（根最先出现）
- **中序** LVR：`a + b * c - d / e f`（对 BST 来说就是升序！）
- **后序** LRV：`a b c * + d e f / -`（根最后出现，适合求值）
- **层次序**：`- + / a * d f b c e`（逐层从左到右）

### 遍历的实际用途 — 为什么需要三种？

| 遍历 | 思维模式 | 典型应用 |
|------|---------|---------|
| **前序** | 自顶向下，先确定根再处理子树 | 复制树、序列化、前缀表达式、路径问题（携带状态向下传递） |
| **中序** | 左→根→右 = 有序输出 | BST 的有序遍历、中缀表达式、验证 BST 合法性 |
| **后序** | 自底向上，先解决子问题再汇总 | 计算高度/大小、删除树、后缀表达式求值、释放内存 |
| **层次序** | 按距离根的远近逐层处理 | 求最大宽度、最短路径（BFS）、按层打印、判断完全二叉树 |

**两种递归思维视角（面试核心）**：

```
自顶向下（前序风格）:            自底向上（后序风格）:
  "我现在在根，把信息往下传"        "先让左右子树各自算好，我再汇总"
  
  maxDepth(node, depth):          maxDepth(node):
    if null: ans=max(ans,depth)      if null: return 0
    maxDepth(left, depth+1)          L = maxDepth(left)
    maxDepth(right, depth+1)         R = maxDepth(right)
                                     return max(L, R) + 1
```

### 递归实现框架

```cpp
void PreOrder(Node* p) {
    if (p == nullptr) return;
    visit(p);                    // ← 前序：先访问根
    PreOrder(p->leftChild);
    PreOrder(p->rightChild);
}

void InOrder(Node* p) {
    if (p == nullptr) return;
    InOrder(p->leftChild);
    visit(p);                    // ← 中序：左子树处理完才访问根
    InOrder(p->rightChild);
}

void PostOrder(Node* p) {
    if (p == nullptr) return;
    PostOrder(p->leftChild);
    PostOrder(p->rightChild);
    visit(p);                    // ← 后序：最后才访问根
}
```

**递归调用栈的可视化**（以中序遍历 `[3, 9, 20, null, null, 15, 7]` 为例）：

```
树结构:       3
            /   \
           9    20
               /  \
             15    7

中序遍历递归展开:
InOrder(3)
├── InOrder(9)
│   ├── InOrder(null) → return
│   ├── visit(9)  ← 输出 9
│   └── InOrder(null) → return
├── visit(3)  ← 输出 3
└── InOrder(20)
    ├── InOrder(15)
    │   ├── InOrder(null) → return
    │   ├── visit(15)  ← 输出 15
    │   └── InOrder(null) → return
    ├── visit(20)  ← 输出 20
    └── InOrder(7)
        ├── InOrder(null) → return
        ├── visit(7)  ← 输出 7
        └── InOrder(null) → return

中序结果: 9, 3, 15, 20, 7
```

**关键观察**：递归自动帮我们管理了"回到哪里继续"的问题。非递归遍历需要用栈手动模拟这个过程。

**应用**：后序遍历求 **Size**（1+左+右）、**Height**（max(左,右)+1）——因为需要先知道子树信息才能算出根的信息。

## 非递归遍历

### 前序 — 栈

```
if root == NULL: return

S = 空栈
Push(S, root)
while S 非空:
    p = Pop(S)
    visit(p)
    if p->rightChild != NULL:
        Push(S, p->rightChild)
    if p->leftChild != NULL:
        Push(S, p->leftChild)
```

> 栈是后进先出，因此先压入右孩子、再压入左孩子，才能先访问左子树。

### 中序 — 栈

```
p = root
S = 空栈
while p != NULL 或 S 非空:
    while p != NULL:
        Push(S, p)
        p = p->leftChild
    p = Pop(S)
    visit(p)
    p = p->rightChild
```

### 后序 — 栈 + tag

```cpp
enum Tag { L, R };
struct StackNode {
    BinTreeNode* ptr;
    Tag tag;
};
```

- `L`：该结点的右子树尚未处理；下一步应转向右子树。
- `R`：该结点的右子树已经处理完；下一步可以访问该结点。

```
p = root
S = 空栈
while p != NULL 或 S 非空:
    // 沿左链下降；新入栈结点先记为 L
    while p != NULL:
        Push(S, {p, L})
        p = p->leftChild

    top = Top(S)
    if top.tag == L:
        // 左子树已经处理完，接下来处理右子树
        SetTopTag(S, R)
        p = top.ptr->rightChild
    else:
        // 左、右子树都已处理完，最后访问根
        top = Pop(S)
        visit(top.ptr)
        p = NULL
```

> tag 记录的是栈中结点“下一步该做什么”。也可以用 `lastVisited` 指针实现后序非递归遍历。

### 层次序 — 队列

```
if root == NULL: return

Q = 空队列
EnQueue(Q, root)
while Q 非空:
    p = DeQueue(Q)
    visit(p)
    if p->leftChild != NULL:
        EnQueue(Q, p->leftChild)
    if p->rightChild != NULL:
        EnQueue(Q, p->rightChild)
```

> 参见 [[队列与优先级队列]] 中队列的 FIFO 特性。

## 由遍历序列重建二叉树

### 哪些组合可以唯一确定？

| 组合 | 能否唯一确定 | 原因 |
|------|-------------|------|
| **前序 + 中序** | ✅ 可以 | 前序确定根，中序把剩余分为左右 |
| **后序 + 中序** | ✅ 可以 | 后序确定根（最后一个），中序分左右 |
| **前序 + 后序** | ❌ 一般不可以 | 无法确定左右子树的分界 |
| **仅前序或仅后序** | ❌ 不可以 | 无法区分左右 |

**核心原理**：中序序列的作用是"告诉你哪些结点在根的左边、哪些在右边"。没有中序信息，就无法分割左右子树。

### 前序+中序重建步骤（详细图解）

前序 `EBADCFHGIK`，中序 `ABCDEFGHIK`：

```
步骤1: 前序首字符 E 为根
       在中序中找到 E：左侧 ABCD(4个) 为左子树，右侧 FGHIK(5个) 为右子树
       
步骤2: 左子树——前序中 E 之后的4个字符 BADC 的首字符 B 为左子树根
       在中序左部 ABCD 中找 B：左侧 A(1个) 为 B 的左子树，右侧 CD(2个) 为 B 的右子树

步骤3: B 的右子树——前序对应 DC，首字符 D 为根
       在中序 CD 中找 D：左侧 C 为 D 的左子树，右侧为空

... 递归处理右子树类似 ...
```

**重建结果**：
```
        E
       / \
      B   F
     / \   \
    A   D   H
       /   / \
      C   G   I
               \
                K
```

**重建的递归模板**（面试必会）：

```cpp
Node* build(preorder, inorder, preL, preR, inL, inR) {
    if (preL > preR) return null;
    root = new Node(preorder[preL]);        // 前序第一个是根
    k = 在 inorder[inL..inR] 中找到 root 的位置
    leftSize = k - inL;                     // 左子树结点数
    root->left = build(..., preL+1, preL+leftSize, inL, k-1);
    root->right = build(..., preL+leftSize+1, preR, k+1, inR);
    return root;
}
```

## 线索化二叉树

### 动机

n 个结点二叉链表有 **n+1** 个空指针。线索化将空指针用于存放**遍历顺序**下的前驱/后继。

### 方法二（常用）：ltag / rtag

| 标志 | 含义 |
|------|------|
| ltag=0 | leftChild 指向**左子女** |
| ltag=1 | leftChild 为**前驱线索** |
| rtag=0 | rightChild 指向**右子女** |
| rtag=1 | rightChild 为**后继线索** |

### 中序线索化

按中序遍历，维护 `pre` 指针：
```
1. 递归左子树
2. 若 current->leftChild==NULL: 建前驱线索，ltag=1
3. 若 pre!=NULL 且 pre->rightChild==NULL: 建后继线索，rtag=1
4. pre = current
5. 递归右子树
6. 后处理最后一个结点 rtag=1
```

### 找中序后继

```
if (rtag==1) 后继 = rightChild
else 后继 = 右子树中序第一个结点（沿 left 走到底，遇 ltag=1 停）
```

### 找中序前驱

```
if (ltag==1) 前驱 = leftChild
else 前驱 = 左子树中序最后一个结点
```

### 前序/后序线索化找后继

- **前序**：ltag=1 → leftChild；否则 left 非空 → left，否则 → right
- **后序**：需 parent 指针；rtag=1 → rightChild；否则找 parent 的右子树中后序第一个

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "层次序用什么辅助结构" | **队列（FIFO）** |
| "中序非递归用什么" | **栈** |

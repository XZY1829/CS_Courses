# 二叉树遍历与线索化（★★★）

#data-structure #tree #binary-tree #traversal #threaded-tree #recursion #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **前序 VLR** | 根 → 左 → 右 |
| **中序 LVR** | 左 → 根 → 右 |
| **后序 LRV** | 左 → 右 → 根 |
| **层次序** | 逐层从左到右，用**队列** |
| **非递归** | 前/中/后序用**栈**；后序可用 tag 标记结点的处理状态 |
| **重建二叉树** | 前序+中序 或 后序+中序 可唯一确定 |
| **线索化** | 利用 n+1 空指针存前驱/后继；ltag/rtag 标志 |

## 四种遍历

对任意非空二叉树，先把整棵树看成“根结点（V）+ 左子树（L）+ 右子树（R）”。前序、中序和后序的名称，取决于**根结点 V 在左、右子树之前、之间还是之后被访问**。

| 遍历 | 访问次序 | 含义 |
|------|----------|------|
| **前序遍历** | VLR | 访问根 → 前序遍历左子树 → 前序遍历右子树 |
| **中序遍历** | LVR | 中序遍历左子树 → 访问根 → 中序遍历右子树 |
| **后序遍历** | LRV | 后序遍历左子树 → 后序遍历右子树 → 访问根 |
| **层次序遍历** | 从上到下、同层从左到右 | 按层访问，通常用队列实现；不属于 V、L、R 的递归排列 |

> 注意：VRL、RVL、RLV 是先右后左的变体，不是通常所说的前序、中序、后序遍历。

**示例树**：

```
        -
       / \
      +     /
     / \   / \
    a   * d   f
       / \   /
      b   c e
```

- **前序** VLR：`- + a * b c / d f e`
- **中序** LVR：`a + b * c - d / e f`
- **后序** LRV：`a b c * + d e f / -`
- **层次序**：`- + / a * d f b c e`

### 递归实现框架

```cpp
void PreOrder(Node* p) {
    if (p == nullptr) return;
    visit(p);
    PreOrder(p->leftChild);
    PreOrder(p->rightChild);
}

void InOrder(Node* p) {
    if (p == nullptr) return;
    InOrder(p->leftChild);
    visit(p);
    InOrder(p->rightChild);
}

void PostOrder(Node* p) {
    if (p == nullptr) return;
    PostOrder(p->leftChild);
    PostOrder(p->rightChild);
    visit(p);
}
```

**应用**：后序遍历求 **Size**（1+左+右）、**Height**（max(左,右)+1）。

## 非递归遍历

### 前序 — 栈

```
if root == NULL: return

S = 空栈
Push(S, root)
while S 非空:
    p = Pop(S)
    visit(p)
    if p->rightChild != NULL:
        Push(S, p->rightChild)
    if p->leftChild != NULL:
        Push(S, p->leftChild)
```

> 栈是后进先出，因此先压入右孩子、再压入左孩子，才能先访问左子树。

### 中序 — 栈

```
p = root
S = 空栈
while p != NULL 或 S 非空:
    while p != NULL:
        Push(S, p)
        p = p->leftChild
    p = Pop(S)
    visit(p)
    p = p->rightChild
```

### 后序 — 栈 + tag

```cpp
enum Tag { L, R };
struct StackNode {
    BinTreeNode* ptr;
    Tag tag;
};
```

- `L`：该结点的右子树尚未处理；下一步应转向右子树。
- `R`：该结点的右子树已经处理完；下一步可以访问该结点。

```
p = root
S = 空栈
while p != NULL 或 S 非空:
    // 沿左链下降；新入栈结点先记为 L
    while p != NULL:
        Push(S, {p, L})
        p = p->leftChild

    top = Top(S)
    if top.tag == L:
        // 左子树已经处理完，接下来处理右子树
        SetTopTag(S, R)
        p = top.ptr->rightChild
    else:
        // 左、右子树都已处理完，最后访问根
        top = Pop(S)
        visit(top.ptr)
        p = NULL
```

> tag 记录的是栈中结点“下一步该做什么”。也可以用 `lastVisited` 指针实现后序非递归遍历。

### 层次序 — 队列

```
if root == NULL: return

Q = 空队列
EnQueue(Q, root)
while Q 非空:
    p = DeQueue(Q)
    visit(p)
    if p->leftChild != NULL:
        EnQueue(Q, p->leftChild)
    if p->rightChild != NULL:
        EnQueue(Q, p->rightChild)
```

> 参见 [[队列与优先级队列]] 中队列的 FIFO 特性。

## 由遍历序列重建二叉树

| 组合 | 能否唯一确定 |
|------|-------------|
| **前序 + 中序** | ✅ 可以 |
| **后序 + 中序** | ✅ 可以 |
| **前序 + 后序** | ❌ 一般不可以 |
| **仅前序或仅后序** | ❌ 不可以 |

**前序+中序重建步骤**（前序 EBADCFHG，中序 ABCDEFGH）：
```
1. 前序首字符 E 为根
2. 在中序中找到 E，左侧 ABCD 为左子树，FGH 为右子树
3. 递归：左子树前序 BAD…，中序 ABCD…
4. 递归：右子树前序 CFHG…，中序 FGH…
```

```
        E
       / \
      B   G
     / \ / \
    A  D F H
      / \
     C   (空)
```

## 线索化二叉树

### 动机

n 个结点二叉链表有 **n+1** 个空指针。线索化将空指针用于存放**遍历顺序**下的前驱/后继。

### 方法二（常用）：ltag / rtag

| 标志 | 含义 |
|------|------|
| ltag=0 | leftChild 指向**左子女** |
| ltag=1 | leftChild 为**前驱线索** |
| rtag=0 | rightChild 指向**右子女** |
| rtag=1 | rightChild 为**后继线索** |

### 中序线索化

按中序遍历，维护 `pre` 指针：
```
1. 递归左子树
2. 若 current->leftChild==NULL: 建前驱线索，ltag=1
3. 若 pre!=NULL 且 pre->rightChild==NULL: 建后继线索，rtag=1
4. pre = current
5. 递归右子树
6. 后处理最后一个结点 rtag=1
```

### 找中序后继

```
if (rtag==1) 后继 = rightChild
else 后继 = 右子树中序第一个结点（沿 left 走到底，遇 ltag=1 停）
```

### 找中序前驱

```
if (ltag==1) 前驱 = leftChild
else 前驱 = 左子树中序最后一个结点
```

### 前序/后序线索化找后继

- **前序**：ltag=1 → leftChild；否则 left 非空 → left，否则 → right
- **后序**：需 parent 指针；rtag=1 → rightChild；否则找 parent 的右子树中后序第一个

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "层次序用什么辅助结构" | **队列（FIFO）** |
| "中序非递归用什么" | **栈** |
| "前序+中序能否确定二叉树" | **能，唯一确定** |
| "线索化 n 个结点空指针数" | **n+1 个，线索化可部分利用** |
| "中序线索化 ltag=1 含义" | **leftChild 指向前驱** |

# B树与B+树（★★★）

#data-structure #index #tree #b-tree #time-complexity #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **索引** | 映射 Y: Z→D，关键码域 Z 到存储地址域 D |
| **多级索引** | 索引太大放不下内存 → 建"索引的索引"，访问外存次数 = 读索引次数 + 1 |
| **m 路搜索树** | 分支结点最多 m 个索引项；叶结点指向数据记录 |
| **B 树（m 阶）** | 平衡的动态 m 路搜索树；所有叶在同一层；结点关键字数 ∈ [⌈m/2⌉−1, m−1] |
| **B+ 树** | 数据全在叶结点；叶结点链表；非叶仅作索引 |
| **搜索代价** | 树高 h → 需 h 次磁盘读（自顶向下到叶） |

## 索引与多级索引

**索引**：建造一个由整数域 **Z** 映射到存储地址域 **D** 的函数 **Y: Z→D**，使按关键码快速定位记录。

当数据量极大、**索引表本身也放不下内存**时，需分批多次读外存才能搜完索引表。解决方案是建立**二级索引**：
- 二级索引可常驻内存
- 每个索引项对应一个**索引块**，登记该块**最大关键码**及**存储地址**
- 若二级索引仍放不下 → 建**三级索引**……

**访问外存次数** = 读入各级索引的次数 **+ 1 次**读记录。

```
四级索引 ──→ 三级索引 ──→ 二级索引 ──→ 一级索引 ──→ 数据区
     root
(23,·) (49,·) (95,·)
   │       │       │
(06,·)(15,·)(23,·) ... (32,·)(41,·)(49,·) ... (60,·)(95,·)
   │                       │                       │
 02 06 11 15 18 23      29 32 38 41 45 49      52 60 77 95  ← 数据
```

多级索引形成 **m 叉树**：每个分支结点 = 一个索引块，最多 **m** 个索引项；叶结点给出记录关键码与地址。这就是 **m 路搜索树**。

| 类型 | 特点 |
|------|------|
| **静态 m 路搜索树** | 创建时装入数据后结构固定 |
| **动态 m 路搜索树** | 随增删动态调整，保持搜索效率 |

---

## m 路搜索树（递归定义）

空树，或满足：
- 根最多 **m** 棵子树，结构 `(n, P₀, K₁, P₁, K₂, P₂, …, Kₙ, Pₙ)`
- **Pᵢ** 指向子树，**Kᵢ** 为关键码，Kᵢ < Kᵢ₊₁，0 ≤ i ≤ n < m
- **Pᵢ** 中所有关键码 ∈ (Kᵢ, Kᵢ₊₁)；**P₀** 中关键码 < K₁；**Pₙ** 中关键码 > Kₙ
- 各子树 **Pᵢ** 也是 m 路搜索树

**搜索示例**（3 路搜索树，搜 35）：从根 a(20,40) 出发 → 35∈(30,40) 走 c(25,30) → 35>30 走 e(35) → 找到。

## B 树

### 定义（m 阶 B 树）

空树，或满足：

| # | 性质 |
|---|------|
| ① | 根至少有 **2** 个子女（非空时） |
| ② | 非根结点至少有 **⌈m/2⌉** 个子女 |
| ③ | 非根结点最多 **m** 个子女 |
| ④ | 结点结构 `(n, P₀, K₁, P₁, …, Kₙ, Pₙ)`，关键码有序，指针域满足 m 路搜索树规则 |
| ⑤ | **所有叶结点在同一层** |
| ⑥ | 所有子树满足 B 树定义 |

**阶 m** 决定每个结点最多 m 个指针、最多 m−1 个关键码。

> [!warning] 根结点例外
> 空树时无根；仅含一个结点时该结点即为根也是叶，关键码个数可少于 ⌈m/2⌉−1。

### 结点关键码个数约束

每个非失败结点关键码个数 **n ∈ [⌈m/2⌉−1, m−1]**。

### 搜索

自根向下，每层比较关键码确定下一指针，直到叶结点。**树高 h → h 次读盘**。

### 插入

从空树起逐个插入；**总是在叶结点**插入。

```
插入流程：
  1. 自顶向下找到目标叶结点
  2. 插入关键码
  3. 若 n ≤ m−1 → 完成
  4. 若 n > m−1 → 结点分裂，中间关键码上推
  5. 分裂可能沿路径向上传播至根
```

**分裂示例**（m=3，插入 139）：

```
插入前:  [53 | 75]          溢出: [53 | 75 | 139]
                ↓ 分裂
        [53]  ←上推→  [75 | 139]
```

**自空树建 3 阶 B 树**（插入 53,75,139,49,145,36,101）：

```
n=1: 53          n=2: 53 75       n=3: 分裂 → 75 为根
n=5: 49,145      n=6: 36          n=7: 101 → 可能再次分裂
```

最坏情况：从被插叶到根路径上**所有结点都分裂**。

### 删除

**非叶结点删除**：用**后继**（比它大的最小数）或**前驱**（比它小的最大数）替换，转化为**叶结点删除**。

**叶结点删除 4 种情况**：

| 情况 | 条件 | 操作 |
|------|------|------|
| ① | 叶即根，删除前 n≥2 | 直接删除 |
| ② | 非根叶，删除前 n≥⌈m/2⌉ | 直接删除 |
| ③ | 删除后 n=⌈m/2⌉−1，兄弟 n≥⌈m/2⌉ | **借位**：双亲关键码下移，兄弟最小/最大关键码上移 |
| ④ | 删除后 n=⌈m/2⌉−1，兄弟 n=⌈m/2⌉−1 | **合并**：与兄弟合并，双亲关键码下压 |

**借位示意**（删除 55，右兄弟有多余）：
```
双亲 a(50)          →    双亲 a(50)
  f(55,58)  g(65)         f(58)  g(65)    （58 从 g 借上，50 下压）
```

**合并示意**（删除 65，兄弟也不足）：
```
a(50)                →    a(50)
c(60,70) f(55,58) g(65)     c(60,75) f(55,58)  （50 下压，f 与 g 合并）
```

## B+ 树

### 与 B 树的区别

| 对比项 | B 树 | B+ 树 |
|--------|------|-------|
| **数据存储** | 每个结点可存 key+data | **仅叶结点**存全部关键码+记录指针 |
| **非叶结点** | 存关键码作搜索路标 | 仅**索引**，存子树最小关键码 |
| **叶结点链接** | 无 | **按关键码大小链成链表** |
| **等值查找** | 找到关键码即可停 | 非叶命中仍**继续向下**到叶 |
| **范围查询** | 需中序遍历 | 沿叶链表**顺序扫描** |
| **树高** | 较高 | 非叶不存 data，**fanout 更大、树更矮** |

### 定义要点（m 阶，叶容量 m₁）

- 叶结点子树棵数 **n ∈ [⌈m₁/2⌉, m₁]**；根若同时为叶，最少 1 棵子树
- 非叶结点：索引项 **(Kᵢ, Pᵢ)**，Kᵢ 为子树**最小**关键码；P₀ 子树全 < K₁
- 叶结点存实际数据对象索引，关键码对应对象地址指针

> [!warning] 叶结点容量
> 叶结点最大关键码数由 **m₁** 决定，可以不同于非叶的 m；叶结点子树棵数可多于或少于 m。

### 搜索

两种模式：
1. 从 **sqt**（叶链表头）沿叶链**顺序搜索**
2. 从 **root** 自顶向下**随机搜索**——即使非叶关键码等于目标值，也**不停止**，继续沿右指针到叶

每次查找都走一条**根到叶**的路径。

### 插入

**仅在叶结点**插入。插入后 n > m₁ 时分裂为两个叶结点，关键码分别为 **⌈(m₁+1)/2⌉** 和 **⌊(m₁+1)/2⌋** 个；双亲加入两个叶结点的**最小关键码**和地址。

```
插入 33（m=3, m₁=3）:
  [10|12|23]  →  [10|12] [23|33]  + 双亲索引更新
```

### 删除

**仅在叶结点**删除。
- 删除叶中**最大关键码**时，非叶中的"分界关键码"可保留
- 删除后子树棵数 < ⌈m₁/2⌉ → 借位或合并（同 B 树）
- 合并可能向上传播至根，导致**树高减 1**

## B 树 vs B+ 树 性能对比

| 场景 | B 树 | B+ 树 |
|------|------|-------|
| 随机查找 | 靠近根的键更快 | 均需走根→叶，时间**基本一致** |
| 范围查询 | 中序遍历 | 叶链表顺序扫描，**更优** |
| 实际应用 | 文件系统常用 | **数据库索引主流**（InnoDB 等） |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "m 阶 B 树结点最多/最少关键码" | 最多 **m−1**；非根最少 **⌈m/2⌉−1** |
| "B 树所有叶在同一层" | B 树**平衡**的核心性质 |
| "插入导致溢出" | 结点**分裂**，中间关键码**上推**至双亲 |
| "删除后关键码不够" | 先尝试**借位**，兄弟也不足则**合并** |
| "非叶结点删除关键码" | 用**后继/前驱**替换，转叶结点删除 |
| "B+ 树非叶命中仍继续" | 必须查到**叶结点**才算完成 |
| "B+ 树范围查询优势" | 叶结点**链表**顺序扫描 |
| "访问外存次数（多级索引）" | 读索引层数 **+ 1** 次读记录 |
| "提高 m 的作用" | 降低树高，减少**磁盘 I/O** |

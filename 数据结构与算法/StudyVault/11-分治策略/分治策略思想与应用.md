# 分治策略思想与应用（★★★）

#algorithm-design #divide-conquer #quick-sort #merge-sort #strassen #recursion #time-complexity #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **核心思想** | 分解 → 递归求解 → 合并 |
| **递推方程** | T(n) = aT(n/b) + s(n)，n > n₀ |
| **快速排序** | SPLIT 划分；理想 Θ(n log n)；最坏 Θ(n²) |
| **归并排序** | MERGE 合并；稳定 Θ(n log n)；需 Θ(n) 辅助空间 |
| **矩阵乘法** | 直接/分块 Θ(n³)；Strassen Θ(n^2.81) |
| **适用条件** | 4 条：可分解、同类子问题、可合并、子问题独立 |

## 分治策略的核心思想

**分治法**（Divide and Conquer）三步骤：

```
        原问题 P（规模 n）
              │
         ┌────┴────┐
      分解(Divide)   将 P 拆为 a 个规模 n/b 的同类子问题 P₁…Pₐ
              │
         ┌────┴────┐
      求解(Conquer)  递归（或直接）求解各子问题 → y₁…yₐ
              │
         ┌────┴────┐
      合并(Merge)   将 y₁…yₐ 组合为原问题的解
```

- 子问题**相互独立**且与原问题**同类**
- 规模减小到一定程度可**直接求解**（递归基）
- 子问题与原问题同类 → 自然用**递归**实现

---

## 分治设计模式

```
divide_and_conquer(P) {
    if (|P| <= n₀)
        direct_process(P);          // 直接求解
    else {
        divide P into P₁, P₂, …, Pₐ;
        for i = 1 to a
            yᵢ = divide_and_conquer(Pᵢ);
        merge(y₁, y₂, …, yₐ);     // 合并
    }
}
```

**时间复杂度递推方程**：

```
T(n) = { c,                    n ≤ n₀
       { aT(n/b) + s(n),       n > n₀
```

- **a**：子问题个数（a ≥ 1）
- **b**：规模缩减因子（b > 1）
- **s(n)**：分解 + 合并的代价

## 快速排序（Quicksort）

### SPLIT 算法

以 **A[low]** 为基准 x，原地划分：

```
SPLIT(A[low…high]):
  x ← A[low]
  while low < high:
    while low < high && A[high] > x: --high
    A[low] ← A[high]
    while low < high && A[low] ≤ x: ++low
    A[high] ← A[low]
  A[low] ← x
  return low    // 基准最终位置 w
```

**示例** `[4,6,3,1,8,7,2,5]`，基准 4：
```
4 6 3 1 8 7 2 5 → 2 6 3 1 8 7 Φ5 → 2 Φ3 1 8 7 6 5 → 2 1 3 4 8 7 6 5
```

### QUICKSORT

```
QUICKSORT(A, low, high):
  if low < high:
    w ← SPLIT(A, low, high)
    QUICKSORT(A, low, w-1)
    QUICKSORT(A, w+1, high)
```

### 复杂度分析

| 情形 | 划分结果 | 递推方程 | 复杂度 |
|------|----------|----------|--------|
| **最好/平均** | 左右规模相当 | T(n)=2T(n/2)+Θ(n) | **Θ(n log n)** |
| **最坏** | 已排序/逆序，一侧为空 | T(n)=T(n−1)+Θ(n) | **Θ(n²)** |

- **优点**：原地排序，平均性能优秀，实际常数小
- **缺点**：最坏 O(n²)；不稳定

## 归并排序（Merge Sort）

### 思想

```
[8 4 3 1 | 6 2 9 7]  →  分两半
[8 4 3 1] + [6 2 9 7]  →  各自排序
[1 3 4 8] + [2 6 7 9]  →  MERGE 合并
[1 2 3 4 6 7 8 9]
```

### MERGE 算法

合并已排序的 A[p…q] 与 A[q+1…r]：

```
MERGE(A, p, q, r):
  s←p; t←q+1; k←p
  while s≤q and t≤r:
    if A[s] ≤ A[t]: B[k]←A[s]; s++
    else:           B[k]←A[t]; t++
    k++
  拷贝剩余段到 B
  A[p…r] ← B[p…r]
```

### MERGESORT 与复杂度

```
MERGESORT(A, low, high):
  if low < high:
    mid ← ⌊(low+high)/2⌋
    MERGESORT(A, low, mid)
    MERGESORT(A, mid+1, high)
    MERGE(A, low, mid, high)
```

| 项目 | 结果 |
|------|------|
| 递推 | T(n) = 2T(n/2) + Θ(n) |
| 时间 | **Θ(n log n)**（最好/最坏/平均一致） |
| 空间 | **Θ(n)** 辅助数组 |
| 稳定性 | **稳定** |

> [!warning] 与快速排序对比
> 归并排序保证 Θ(n log n) 但需额外空间；快排原地但最坏 Θ(n²)。

## 矩阵乘法

设 A、B 为 n×n 矩阵，C = AB。

### 方法 1：直接相乘

cᵢⱼ = Σₖ aᵢₖ·bₖⱼ，共 n² 个元素，每个 n 次乘加：

```
T(n) = n² × n × m + n² × (n−1) × a = Θ(n³)
```

### 方法 2：分块矩阵法

将矩阵分为 4 个 (n/2)×(n/2) 子块：

```
C₁₁ = A₁₁B₁₁ + A₁₂B₂₁    C₁₂ = A₁₁B₁₂ + A₁₂B₂₂
C₂₁ = A₂₁B₁₁ + A₂₂B₂₁    C₂₂ = A₂₁B₁₂ + A₂₂B₂₂
```

```
T(n) = 8T(n/2) + 4(n/2)²a = Θ(n³)    // 8 次子问题，合并 Θ(n²)
```

> [!warning] 分块未改进渐近阶
> 朴素分块仍是 **Θ(n³)**，因 8 次子问题过多。

### 方法 3：Strassen 算法

通过巧妙的 7 次 (n/2)×(n/2) 乘法代替 8 次：

```
T(n) = 7T(n/2) + 18(n/2)²a
```

由主定理：T(n) = Θ(n^log₂7) = **Θ(n^2.807)** ≈ **Θ(n^2.81)**

```
log₂7 ≈ 2.807 > 2 < 3  →  介于 O(n²) 与 O(n³) 之间
```

## 分治法适用条件（4 条）

| # | 条件 | 说明 |
|---|------|------|
| 1 | **规模缩小可易解** | 减到 n₀ 可直接处理 |
| 2 | **可分解为同类子问题** | 子问题结构与原问题相同 |
| 3 | **子问题解可合并** | 合并代价可接受 |
| 4 | **子问题相互独立** | 无重叠子问题 |

> [!warning] 第 4 条例外
> 若子问题**不独立**（大量重叠），分治会重复计算；此时应优先考虑**动态规划**（如斐波那契、矩阵链）。

## 递推方程求解速查

| 递推式 | 典型算法 | 结果 |
|--------|----------|------|
| T(n)=2T(n/2)+Θ(n) | 归并排序、快排（理想） | Θ(n log n) |
| T(n)=T(n−1)+Θ(n) | 快排（最坏） | Θ(n²) |
| T(n)=8T(n/2)+Θ(n²) | 分块矩阵乘 | Θ(n³) |
| T(n)=7T(n/2)+Θ(n²) | Strassen | Θ(n^2.81) |

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "分治三步骤" | **分解 → 求解 → 合并** |
| "T(n)=aT(n/b)+s(n)" | 主定理 / 展开法求渐近阶 |
| "快排最坏复杂度" | **Θ(n²)**（划分极度不均） |
| "快排平均/理想" | **Θ(n log n)** |
| "归并排序复杂度" | 时间 **Θ(n log n)**，空间 **Θ(n)** |
| "Strassen 复杂度" | **Θ(n^log₂7) ≈ Θ(n^2.81)** |
| "分块矩阵乘为何仍是 O(n³)" | **8** 个子问题，主定理得 n^log₂8 = n³ |
| "子问题重叠" | 用**动态规划**而非分治 |
| "SPLIT 基准位置" | 划分后基准左侧 ≤ x，右侧 > x |

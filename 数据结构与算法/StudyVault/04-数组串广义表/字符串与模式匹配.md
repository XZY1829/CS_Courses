## 字符串基本概念

**字符串（串）**是 n(n≥0) 个字符的有限序列，记作 S : "c₁c₂…cₙ"。
- S 为**串名**，"c₁…cₙ" 为**串值**，n 为**串长**
- n = 0 → **空串** ""；含空格 " " 是长度为 1 的**空白串**，≠ 空串

**子串**：串中任意连续字符组成的子序列。**主串**包含子串。
- 空串是任意串的子串；任意串是其自身子串
- 子串 B 在主串 A 中**首次出现位置**（从 0 计）称为 B 在 A 中的位置

## 朴素模式匹配（B-F 算法）

从主串第 k 个字符起，逐字符与模式 P 比较；失配则 k++，模式从头再比。

```cpp
for (i = k; i <= n-m; i++)
    for (j = 0; j < m; j++)
        if (T[i+j] != P[j]) break;
    if (j == m) return i;  // 匹配成功
return -1;
```

**匹配过程示意**（T="abbaba", P="aba"）：
```
第1趟 i=0: abb vs aba → j=2 失配
第2趟 i=1: bba vs aba → j=0 失配
第3趟 i=2: bab vs aba → j=2 失配
第4趟 i=3: aba vs aba → 成功，返回 3
```

- **最坏时间**：O((n-m+1)×m) ≈ **O(n×m)**
- **低效原因**：每趟失配后目标指针**回退**

## KMP 算法

**核心思想**：失配时模式串右移，**目标串指针不回溯**。

设第 j 位失配（P[j] ≠ T[i]）：
- 若 j > 0：下一趟从 P[next[j]] 与 T[i] 继续比较
- 若 j = 0：T 指针进 1，P 从 p₀ 重新开始

```
目标 T:  t₀ t₁ … tₛ … tₛ₊ⱼ …
模式 P:  p₀ p₁ … pⱼ …
失配于 j → 利用 P[0..j-1] 的前缀/后缀信息，P 右移到 next[j]
```

**时间复杂度**：字符比较最多 O(n)，无回溯。

### next 数组定义（教材版）

设模式 P = p₀p₁…pₘ₋₁：
```
next(0) = -1
next(j) = k+1，其中 0≤k<j-1 且 p₀…pₖ = pⱼ₋ₖ₋₁…pⱼ₋₁ 的最大 k
         否则为 0
```

**示例** P = "abaabcac"：
| j | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| P | a | b | a | a | b | c | a | c |
| next | -1 | 0 | 0 | 1 | 1 | 2 | 0 | 1 |

### next 数组递推计算

```
next[0] = -1
j=0, k=-1
while (j < m) {
    if (k==-1 || P[j]==P[k]) { j++; k++; next[j]=k; }
    else k = next[k];
}
```

### KMP 匹配主算法

```cpp
posP = 0, posT = k;
while (posP < m && posT < n) {
    if (posP==-1 || P[posP]==T[posT]) { posP++; posT++; }
    else posP = next[posP];
}
return (posP < m) ? -1 : posT - m;
```

> [!warning] next 数组变体
> 部分教材定义 next[j] 为**最长相等前后缀长度**（不含 +1），或 next[0]=0。做题前先确认题目采用的定义。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "空串与空白串区别" | **"" 长度 0；" " 长度 1** |

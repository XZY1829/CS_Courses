## 一维与多维数组

**数组**是相同类型数据元素的集合。一维数组每个元素是一个**序对 (index, value)**，高级语言中按下标直接存取。

- **静态数组**：编译时分配，维界不变，空间不可扩充
- **动态数组**：运行时 `new` 分配，`delete` 释放

**一维地址公式**（基址 a，元素长度 l）：
```
LOC(i) = a + i×l    (i≥0)
LOC(i) = LOC(i-1)+l (递推)
```

**多维数组**是一维数组的推广，每个元素可有多个直接前驱和直接后继，但下界/上界固定，比复杂非线性结构简单。

**二维数组 A[n][m]** 可视为 n 个行向量或 m 个列向量：
```c
typedef T array2[n][m];  // 等价于
typedef T array1[m];
typedef array1 array2[n];
```

**三维数组**（各维 m₁, m₂, m₃，页/行/列优先）：
```
LOC(i₁,i₂,i₃) = a + (i₁×m₂×m₃ + i₂×m₃ + i₃) × l
```

**n 维数组**通用公式：
```
LOC(i₁,…,iₙ) = a + (Σⱼ₌₁ⁿ⁻¹ iⱼ × Πₖ₌ⱼ₊₁ⁿ mₖ + iₙ) × l
```

## 行优先与列优先存储

```
行优先 (C/Java 默认):  a₁₁ a₁₂ … a₁ₘ | a₂₁ … a₂ₘ | … | aₙ₁ … aₙₘ
列优先 (Fortran):      a₁₁ a₂₁ … aₙ₁ | a₁₂ … aₙ₂ | … | a₁ₘ … aₙₘ
```

| 存储方式 | 地址公式（A[n][m]，下标 j 行、k 列，从 0 起） |
|----------|-----------------------------------------------|
| **行优先** | LOC(j,k) = a + (j×m + k) × l |
| **列优先** | LOC(j,k) = a + (k×n + j) × l |

> [!warning] 下标约定
> 教材公式中 j 为行号、k 为列号。若题目从 1 开始编号，需先转换为 0 基或调整公式。

## 对称矩阵压缩存储

n×n **对称矩阵**满足 aᵢⱼ = aⱼᵢ。只存**下三角**或**上三角**，按行压入一维数组 B，共 **n(n+1)/2** 个元素。

**下三角矩阵**（i ≥ j）：
```
k = (i+1)×i/2 + j
```
若 i < j，取对称元素 A[j][i]，位置 k = (j+1)×j/2 + i。

**已知 B 中第 k 个位置反求 (i,j)**：
- 找满足 i(i+1)/2 ≤ k < (i+1)(i+2)/2 的 i
- j = k - i(i+1)/2

**上三角矩阵**（i ≤ j）：
```
k = (2n-i-1)×i/2 + j
```
若 i > j，取对称元素 A[j][i]。

## 三对角矩阵压缩存储

仅主对角线及上下各一条对角线非零，共 **3n-2** 个非零元素。元素 aᵢⱼ 满足 0≤i≤n-1，i-1≤j≤i+1。

按行存入 B，a₀₀ 在 B[0]：
```
k = 2i + j
```

**反求**：i = ⌊(k+1)/3⌋，j = k - 2i

```
     a₀₀ a₀₁
a₁₀ a₁₁ a₁₂
      …
        aₙ₋₁,ₙ₋₂ aₙ₋₁,ₙ₋₁
→ B: a₀₀ a₀₁ a₁₀ a₁₁ a₁₂ …
```

## 稀疏矩阵

**稀疏矩阵**：s 个非零元素，s ≪ m×n。**稀疏因子** e = s/(m×n)，通常 e ≤ 0.05 视为稀疏。

### 三元组表示

```cpp
struct Triple { int row, col; E value; };
// smArray 按行存放，同行按列号递增
```

| 操作 | 朴素转置 | 快速转置 |
|------|----------|----------|
| **思想** | 扫描 Cols 次，每次找列号为 k 的项 | 一次扫描 + rowSize/rowStart 辅助数组 |
| **时间** | O(n×t)，t 为非零元个数 | O(Cols + Terms) |

**快速转置步骤**：
1. rowSize[j] = 原矩阵第 j 列非零元个数
2. rowStart[0]=0；rowStart[i]=rowStart[i-1]+rowSize[i-1]
3. 扫描三元组表，按 rowStart[col] 直接定位写入转置表

### 带行指针的二元组

行指针数组 row[i] 指向第 i 行第一个非零元在二元组表中的位置；二元组只存 (col, value)。

### 正交链表（十字链表）

行链表与列链表交叉链接，每个非零元结点含 `right`（同行）和 `down`（同列）指针，另有表头结点。适应矩阵运算中**非零元动态变化**。

```
head → [row,col] → right/down → 非零元结点
```

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "二维 A[5][8] 行优先，LOC(0,0)=100，l=4，求 LOC(3,5)" | **100 + (3×8+5)×4 = 212** |
| "对称矩阵下三角，A[3][2] 在 B 中位置" | **k=(3+1)×3/2+2=8** |
| "三对角矩阵 A[3][2] 在 B 中位置" | **k=2×3+2=8** |
| "稀疏矩阵转置 O(n×t) 如何优化" | **快速转置：rowSize + rowStart，O(Cols+Terms)** |
| "稀疏矩阵哪种表示适合频繁插入删除" | **正交链表** |

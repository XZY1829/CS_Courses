# 广义表（★★）

#data-structure #linear #generalized-list #recursion #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| **定义** | n(n≥0) 个表元素组成的有限序列 LS=(a₁,…,aₙ)；元素可为原子或子表 |
| **表头/表尾** | head = 第一个元素；tail = 除表头外其余元素组成的表 |
| **深度** | 空表深度 1；原子深度 0；表深度 = 1 + max(各元素深度) |
| **存储** | 头尾链表 / 扩展线性链表；结点 utype=0/1/2 |
| **纯表/再入表/递归表** | 无共享 / 共享子表 / 含自引用 |

## 广义表定义

**广义表**是 n(n≥0) 个**表元素**组成的有限序列：
```
LS = (a₁, a₂, …, aₙ)
```
- LS 为表名；aᵢ 为表元素，可以是**原子**（数据元素）或**子表**
- n 为表长；n = 0 为**空表**

**示例**：G = ('a', (5, 3, 'x'), …)

### 特性

| 特性 | 说明 |
|------|------|
| **有次序性** | 元素顺序有意义 |
| **有长度** | 顶层元素个数 |
| **有深度** | 嵌套层数 |
| **可共享** | 同一子表可被多处引用 |
| **可递归** | 如 F = (4, F) |

### 表头与表尾

n > 0 时：
- **表头 head(LS)** = 第一个表元素
- **表尾 tail(LS)** = 除表头外其余元素组成的表（**仍是广义表**）

```
C = ('a', (5, 3, 'x'))
head(C) = 'a'
tail(C) = ((5, 3, 'x'))    ← 注意：表尾是表，外层还有括号

head(((5,3,'x'))) = (5,3,'x')
tail(((5,3,'x'))) = ()    ← 空表
```

> [!warning] 空表
> 空表 A=() 的 head 和 tail **均不存在**（未定义）。

### 表的分类

| 类型 | 特征 | 示例 |
|------|------|------|
| **线性表** | 所有元素为原子 | (a, b, c, d, e) |
| **纯表** | 无共享、无递归 | 各子表独立 |
| **再入表** | 共享子表 | 同一子表被多处引用 |
| **递归表** | 含自引用 | F = (4, F) |

## 存储表示

### 结点结构

```cpp
struct GenListNode {
    int utype;   // 0=表头结点, 1=原子, 2=子表
    union { int ref; T value; GenListNode *hlink; } info;
    GenListNode *tlink;  // 同层下一结点
};
```

| utype | info | tlink |
|-------|------|-------|
| **0** | ref（引用计数） | 指向第一个元素 |
| **1** | value（原子值） | 同层下一结点 |
| **2** | hlink（子表头指针） | 同层下一结点 |

**头尾链表**：每个子表有附加头结点（utype=0），元素通过 tlink 串联。

**扩展线性链表**：类似，子表通过 hlink 指向子表头结点。

## 核心操作

### 取表头 Head(x)

```cpp
if (first->tlink == NULL) return false;  // 空表
x = first->tlink 的值;  // 复制 utype 和 info
```

### 取表尾 Tail(lt)

```cpp
lt.first->tlink = Copy(first->tlink->tlink);  // 复制除表头外的链表
```

### 复制 Copy(ls) — 递归

```
Copy(ls):
  if ls == NULL: return NULL
  创建结点 q，复制 utype 和 info
  if utype==2: q->hlink = Copy(ls->hlink)
  q->tlink = Copy(ls->tlink)
  return q
```

### 求深度 depth(ls) — 递归

```
Depth(LS) =
  1,                    当 LS 为空表
  0,                    当 LS 为原子
  1 + max Depth(αᵢ),    其他 (n≥1)
```

**示例** E(B(a,b), D(B(a,b), C(u,(x,y,z)), A()))：
- A 深度 1，B 深度 1，C 深度 2，D 深度 3，E 深度 4

### 删除

- **结点删除 delvalue(ls, x)**：同层连续删值为 x 的原子；遇子表递归进入
- **表删除 Remove(ls)**：共享表先 **ref--**，ref≤0 才真正释放

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "tail((a,b,c))" | **(b,c)**，表尾仍是广义表 |
| "head(tail((a,(b,c))))" | **b** |
| "空表 () 的 head" | **不存在/未定义** |
| "广义表深度 E=(B(a,b),D(...))" | **顶层子表深度最大值 + 1** |
| "共享表删除为何用 ref" | **防止其他引用处失效，ref 减到 0 才释放** |

# 二分图匹配（★★）

#algorithm #graph-theory #bipartite-matching #hungarian #topological-sort #concept

## 概览表：匈牙利算法关键概念

| 概念 | 含义 | 作用 |
|------|------|------|
| **二分图** | 顶点分两组，边只连不同组 | 匹配问题的前提 |
| **匹配** | 无两条边共享顶点 | 合法分配方案 |
| **交错路径** | 边交替在匹配内/外 | 寻找改进方向 |
| **增广路径** | 两端未匹配的交错路径 | 匹配 +1 的关键 |
| **最大匹配** | 边数最多的匹配 | 匈牙利算法目标 |

---

## 二分图匹配定义

- **二分图**：顶点可分为两组 U、V，每条边连接 **U 中一点与 V 中一点**
- **匹配**：边集 M，M 中任意两条边**不共享顶点**
- **最大匹配**：包含**边数最多**的匹配（大小唯一，方案可不唯一）

---

## 关键概念

### 交错路径

给定匹配 M，若路径上的边**交替**出现在 M 中和不在 M 中，称为 **M-交错路径**。

### 增广路径

一条 M-交错路径，其**两个端点都不与 M 中的边关联**。

### Berge 定理

> **存在增广路径 ⟺ 当前匹配非最大**

每找到一条增广路径，匹配边数 +1，直到找不到增广路径为止。

---

## 匈牙利算法

**流程**：对左部每个点 i，尝试找增广路径并增广。

```cpp
bool dfs(int i) {
    for (int j = 1; j <= m; j++)
        if (neighbour[i][j] && !visited[j]) {
            visited[j] = true;
            if (connect[j] == -1 || dfs(connect[j])) {
                connect[j] = i;
                return true;
            }
        }
    return false;
}

// 主循环
for (int i = 1; i <= n; i++) {
    memset(visited, false, sizeof(visited));  // 每轮重置！
    if (dfs(i)) match_count++;
}
```

**时间复杂度**：O(V · E)（邻接矩阵实现）。

> [!warning] 匈牙利算法中 visited 数组必须每轮（每个左部节点）开始前重置为 false
> `visited[j]` 标记的是**本轮 DFS** 中右部点 j 是否已被尝试，而非全局永久访问。不重置会导致合法增广路径被误判为不存在。

## 地鼠一家问题

**建模**：

- **左部** = n 只地鼠，**右部** = m 个地洞
- 地鼠 i 与地洞 j 连边 ⟺ 距离 ≤ **s × v**（s 秒内能跑到）
- 求**最大匹配** → 最多能救的地鼠数

**答案**：

```
易受攻击的地鼠数 = n - 最大匹配数
```

**样例**：2 只地鼠、2 个洞，仅 1 只能匹配 → 输出 **1**。

## 拓扑排序

**问题**：有向无环图（DAG）的线性排序，使每条边 u→v 中 u 排在 v 前面。

**算法**：

1. 维护 `indegree[]` 入度数组
2. 每次找**入度为 0** 的点输出并删除（入度 −1 传给后继）
3. 重复直到全部输出或无法继续

**判定规则**：

| 情况 | 含义 |
|------|------|
| 某步**无**入度为 0 的点 | 存在**环**（关系不一致） |
| 某步**多个**入度为 0 的点 | 无法确定**唯一**顺序 |
| 每步恰好 1 个入度为 0 的点 | 顺序**唯一** |

```cpp
int TopoSort(int n) {
    int t = 0, flag = 1;  // flag=1 有序, flag=-1 不确定
    for (int i = 1; i <= n; i++) temp[i] = indegree[i];
    for (int i = 1; i <= n; i++) {
        int m = 0, p = 0;
        for (int j = 1; j <= n; j++)
            if (temp[j] == 0) { m++; p = j; }
        if (m == 0) return 0;       // 有环
        if (m > 1) flag = -1;         // 无法唯一确定
        q[++t] = p;
        temp[p] = -1;
        for (int j = 1; j <= n; j++)
            if (map[p][j]) temp[j]--;
    }
    return flag;
}
```

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "分配/配对/一对一" | 建二分图 → **匈牙利算法** |
| "最多能匹配几个" | 最大匹配数 |
| "最少无法匹配" | n − 最大匹配数 |
| "依赖关系/先后顺序" | **拓扑排序** |
| "关系冲突/矛盾" | 拓扑排序某步无入度 0 → **有环** |
| "能否唯一确定顺序" | 每步入度 0 的点是否唯一 |

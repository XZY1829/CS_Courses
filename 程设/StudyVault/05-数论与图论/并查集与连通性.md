# 并查集与连通性（★★）

#algorithm #graph-theory #union-find #connectivity #concept

## 概览表（一目了然）

| 操作 | 功能 | 均摊复杂度 |
|------|------|------------|
| **Find(x)** | 查找 x 所属集合的根 | O(α(n)) ≈ O(1) |
| **Union(x, y)** | 合并 x、y 所在集合 | O(α(n)) |
| **连通分支数** | 初始 n 个集合，每次合并 n-- | O(m·α(n)) |

---

## 并查集原理

- **树形数据结构**，用于处理**不相交集合**的合并与查询
- 每个集合用一棵树表示，**根节点**代表该集合
- **应用**：判断连通分支数、判断两节点是否同组、Kruskal 最小生成树

```
初始:  {1} {2} {3} {4} {5}

Union(1,2):     Union(3,4):
   2                4
   |                |
   1                3

Union(2,4):
       4
      / \
     2   3
     |
     1
```

## 核心操作

### Find(x) — 查找根

```cpp
int find(int x) {
    if (father[x] == -1) return x;
    return father[x] = find(father[x]); // 路径压缩
}
```

### Union(x, y) — 合并集合

```cpp
void merge(int a, int b) {  // union 是 C++ 关键字
    int fa = find(a), fb = find(b);
    if (fa != fb) father[fa] = fb;
}
```

> [!warning] 合并操作不需要修改所有节点的 father，只需修改根节点
> 将一棵树的根指向另一棵树的根即可，不必沿路径更新每个节点。

---

## 路径压缩

Find 时**直接将节点指向根**，降低树高，使后续查询接近 O(1)。

| | 无路径压缩 | 有路径压缩 |
|---|-----------|-----------|
| 树高 | 可能退化为链 O(n) | 均摊 O(α(n)) |
| 实现 | `return find(father[x])` | `return father[x] = find(father[x])` |

## 宗教信仰问题

**问题**：n 名学生，m 对"信仰相同"关系，求不同宗教数目的**上限**（即连通分支数）。

**思路**：

1. 初始化 `father[i] = -1`，计数 `n` 表示当前集合数
2. 每读入一对 `(a, b)`，若 `find(a) != find(b)`，则 `merge(a, b)` 且 **`n--`**
3. 最终 `n` 即为连通分支数（不同宗教上限）

```cpp
memset(father, -1, sizeof(father));
int n; cin >> n >> m;
for (int i = 1; i <= m; i++) {
    int a, b; cin >> a >> b;
    int fa = find(a), fb = find(b);
    if (fa != fb) { father[fa] = fb; n--; }
}
cout << n << endl;
```

## Kruskal 算法中的并查集应用

Kruskal 按边权从小到大选边，需判断两端是否已在同一连通分量：

```cpp
sort(edges, edges + m, cmp);  // 按权值升序
int cnt = 0;
for (int i = 0; i < m && cnt < n - 1; i++) {
    int x = edges[i].u, y = edges[i].v;
    if (find(x) != find(y)) {
        merge(x, y);
        ans += edges[i].w;
        cnt++;
    }
}
```

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "同组/同类/连通" | 并查集 merge + find |
| "有多少个不同的…" | 初始 n，合并一次 n-- |
| "判断是否在同一集合" | `find(a) == find(b)` |
| "最小生成树/Kruskal" | 排序边 + 并查集判环 |
| "运输重物/最大瓶颈路" | Kruskal 降序 + 连通即停 |

# 最小生成树（★★★）

#algorithm #graph-theory #mst #prim #kruskal #concept

> [!important] 最小生成树 ≠ 最短路径！
> MST 是**全局边权和最小**的连通子图，不保证任意两点间路径最短。

## 概览表（一目了然）

| | Prim | Kruskal |
|---|---|---|
| **策略** | 加点法 | 加边法 |
| **适用** | 稠密图 | 稀疏图 |
| **时间** | O(V²) / O(E log V)（堆优化） | O(E log E) |
| **辅助结构** | 距离数组 `dis[]` | 并查集 |

---

## Prim 算法（加点法）

**思想**：从任意起点出发，每次选**离当前生成树最近**的点加入，更新各点到生成树的最短边。

**维护**：一维数组 `dis[j]` = 生成树到点 j 的最短边权。

**丛林中的路示例**（从 A 开始）：

| 步骤 | 加入 | dis 更新 |
|------|------|----------|
| 初始 | A | B=12, I=25, 其余 ∞ |
| 1 | B（dis 最小 12） | I=25→8, C=10 |
| 2 | I（dis 最小 8） | — |
| 3 | C（dis 最小 10） | 继续扩展… |

```
     A ──12── B ──10── C
      \        /
      25     8
        \   /
          I
```

**模板要点**：

```cpp
dis[0] = 0;  // 起点
for (int i = 0; i < n; i++) {
    int k = -1;
    for (int j = 0; j < n; j++)
        if (!vis[j] && (k == -1 || dis[j] < dis[k])) k = j;
    vis[k] = true; ans += dis[k];
    for (int j = 0; j < n; j++)
        dis[j] = min(dis[j], graph[k][j]);
}
```

## Kruskal 算法（加边法）

**思想**：

1. 所有边按权值**升序**排序
2. 依次选最小边，若两端**不在同一集合**则加入 MST 并合并
3. 选够 n−1 条边即完成

**并查集模板**：

```cpp
int find(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);
}
void merge(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) fa[fy] = fx;
}

sort(edges, edges + m, cmp);
int cnt = 0;
for (int i = 0; i < m && cnt < n - 1; i++) {
    int u = edges[i].u, v = edges[i].v;
    if (find(u) != find(v)) {
        merge(u, v);
        ans += edges[i].w;
        cnt++;
    }
}
```

## 运输重物变体 — 最大生成树

**问题**：从 1 到 n 的所有路径中，求**路径上最小边权的最大值**（瓶颈路）。

**Kruskal 变体**：

1. 边按权值**从大到小**排序
2. 依次加边合并，当 `find(1) == find(n)` 时**立即停止**
3. 最后加入的边权即为答案

```cpp
sort(edges + 1, edges + 1 + m, cmp_desc);  // 降序
for (int i = 1; i <= m; i++) {
    merge(edges[i].from, edges[i].to);
    if (find(1) == find(n)) {
        ans = edges[i].w;
        break;
    }
}
```

> 等价解法：修改 Dijkstra 求"最大瓶颈"，见 [[最短路径]]。

# 最短路径（★★★）

#algorithm #graph-theory #shortest-path #dijkstra #concept

> [!warning] Dijkstra 不能处理负权边！
> 负权图应使用 Bellman-Ford 或 SPFA。

## 概览表（一目了然）

| 算法 | 适用 | 时间复杂度 | 负权边 |
|------|------|------------|--------|
| **Dijkstra** | 单源最短路，非负权 | O(V²) / O(E log V) | ✗ |
| **BFS** | 边权均为 1 | O(V + E) | — |
| **Bellman-Ford** | 可有负权 | O(VE) | ✓ |
| **Floyd** | 全源最短路 | O(V³) | ✓（无负环） |

---

## Dijkstra 算法

**核心思想**："**最短路径的子路径也是最短路**"。

**流程**：

1. 维护 `dis[i]`：起点到 i 的当前最短距离
2. 维护 `vis[i]`：是否已确定最短路
3. 每次选**未访问**中 `dis` **最小**的点 k，用 k **松弛**其邻接点
4. 重复 n 次，所有点最短路确定

```
dis 数组演化（起点 1）:
初始: dis[1]=0, dis[2..n]=∞
选 k=1 → 更新邻居
选 k=2 → 更新邻居
...
```

**不适用负权边**：负权边可能使已确定的"最短"被后续更新，算法失效。

## Dijkstra 代码模板

```cpp
void Dijkstra() {
    for (int i = 1; i <= n; i++) dis[i] = graph[1][i];
    vis[1] = 1;
    for (int i = 0; i < n; i++) {
        int min_ = inf, k = start;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && dis[j] < min_) { min_ = dis[j]; k = j; }
        vis[k] = 1;
        for (int j = 1; j <= n; j++)
            dis[j] = min(dis[j], dis[k] + graph[k][j]);
    }
}
```

**优先队列优化**：用 `priority_queue` 维护 (dis, node)，均摊 O(E log V)。

## 运输重物（Dijkstra 变体）

**问题**：求 1→n 所有路径中，**路径上最小边权的最大值**（瓶颈容量）。

**修改规则**：

| 标准 Dijkstra | 瓶颈路变体 |
|---------------|-----------|
| 选 `dis` **最小** 的点 | 选 `dis` **最大** 的点 |
| `dis[j] = min(dis[j], dis[k]+w)` | `dis[j] = max(dis[j], min(dis[k], w))` |

```cpp
void Dijkstra() {
    for (int i = 1; i <= n; i++) dis[i] = graph[1][i];
    vis[1] = 1;
    for (int i = 0; i < n; i++) {
        int max_ = -inf, k = start;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && dis[j] > max_) { max_ = dis[j]; k = j; }
        vis[k] = 1;
        for (int j = 1; j <= n; j++)
            dis[j] = max(dis[j], min(dis[k], graph[k][j]));
    }
}
```

**样例**：1—2(3), 1—3(4), 2—3(5) → 路径 1→3 瓶颈为 **4**。

> 等价解法：Kruskal **降序**加边至 1 与 n 连通，见 [[最小生成树]]。

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "单源最短路、非负权" | Dijkstra |
| "边权均为 1" | BFS 更简单 |
| "负权边" | Bellman-Ford / SPFA，**不用** Dijkstra |
| "任意两点最短路" | Floyd O(V³) |
| "路径最小边权最大" | Dijkstra 变体 或 Kruskal 降序 |
| "最少转换步数" | BFS（见 [[BFS广度优先搜索]]） |

# BFS广度优先搜索（★★★）

#algorithm #search #bfs #state-compression #flood-fill #concept

## 概览表（一目了然）

| | BFS | DFS |
|---|---|---|
| **数据结构** | 队列 | 栈 / 递归 |
| **最优性** | **保证最短路**（边权均为 1） | 不保证 |
| **空间** | O(宽度) | O(深度) |
| **扩展顺序** | 按层次，距离 1 → 2 → 3 → ... | 沿一条路径深入 |
| **适用** | 最短路 / 层次遍历 | 连通性 / 全部方案枚举 |

---

## BFS 核心思想

- **按层次扩展**：先扩展距离为 1 的节点，再距离为 2，依此类推
- **第一次到达目标 = 最短路**（无权图或边权均为 1）
- 用队列保证"先进先出"的层次顺序

```
层次 0:  S
层次 1:  ● ● ●
层次 2:  ● ● ● ● ●
         ↑ 第一次到达 T 时的距离即最短
```

> [!important] BFS 最优性前提
> 仅当所有边权相等（通常为 1）时，BFS 保证最短步数。带权图需 Dijkstra 等算法。

## BFS 模板代码

```cpp
queue.push(start);
visited[start] = true;
while (!queue.empty()) {
    Node cur = queue.front(); queue.pop();
    if (cur == goal) return cur.dist;
    for (each neighbor of cur) {
        if (!visited[neighbor]) {
            visited[neighbor] = true;
            neighbor.dist = cur.dist + 1;
            queue.push(neighbor);
        }
    }
}
```

**要点**：

- 入队时立即标记 `visited`，避免重复入队
- 记录 `dist` 或在入队时传递层数
- 需要路径时记录 `parent[]` 回溯还原

## 抓住那头牛

**问题**：牛在 X，农夫在 Y，每步可 X-1、X+1 或 2×X，求最少步数到达。

**建模**：一维坐标 BFS，三种转移：

```
next = { X-1, X+1, 2*X }
```

**注意**：坐标可能为负或超过上界，需设置合理 `visited` 范围（如 `[0, 2*target]`）。

## 单词序列

**问题**：从 beginWord 到 endWord，每次只改一个字母，每步必须是字典中的词，求最短变换序列。

**建模**：

1. 两词"相邻"= 恰好差一个字母
2. BFS 逐层扩展，记录当前步数
3. 可用哈希表预处理邻接关系，或每次与词典中所有词比较

**第一次到达 endWord 的层数即为答案**。

## 迷宫问题

**问题**：网格迷宫中从起点到终点的最短路径。

**实现要点**：

- 四方向扩展 + 边界检查 + 墙/障碍判断
- `parent[x][y]` 记录父节点坐标，到达终点后回溯还原路径
- BFS 保证第一次到达终点为最短步数

```
parent 回溯：end → ... → start → 反转得路径
```

## 拯救公主（BFS + 状态压缩）

**问题**：网格中收集宝石、通过传送门，求最短路径。

**状态**：`(x, y, gem_state)` — 位置 + 已收集宝石集合

**三维判重**：

```
visited[x][y][gem_state]   // gem_state 用二进制表示各宝石是否已取
```

**传送门处理**：踏入传送门时，将**所有其他传送门位置**入队（同一层距离 +1）。

> [!tip] 状态压缩 + BFS
> 当位置不足以区分状态时，增加 bitmask 维度；状态数 = 网格大小 × 2^宝石种类。

## 寻找 NEMO

**问题**：网格中有墙、需穿过的门、空白区域，求最少穿门数到达目标。

**关键设计**：

| 要素 | 处理方式 |
|------|----------|
| 格子类型 | 墙 / 门 / 空白 三种状态 |
| 判重数组 | `walked[i][j]` 记录**最少穿门数**（非 bool） |
| 更新规则 | 仅当新穿门数 < walked[i][j] 时入队 |
| 搜索边界 | 优化 BFS 范围，避免无效扩展 |

**注意**：这里 `walked` 存的是数值而非布尔值，类似 Dijkstra 的松弛思想，因为同一格子可能需要不同穿门数的状态。

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "最少步数/最短路径" | BFS（边权为 1） |
| "三种移动/变换操作" | 一维或二维 BFS |
| "改一个字母/单词接龙" | BFS 层次扩展 |
| "迷宫最短路+还原路径" | BFS + parent 回溯 |
| "收集物品/传送门" | BFS + 状态压缩 visited[x][y][state] |
| "穿门数最少/多重代价" | walked 存最优值而非 bool |
| "层次遍历/按距离分层" | BFS 天然按层处理 |

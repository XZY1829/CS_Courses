# DFS深度优先搜索（★★★）

#algorithm #search #dfs #connected-component #pruning #concept

## 概览表（一目了然）

| 特点 | 说明 |
|------|------|
| **数据结构** | 隐式栈（递归）或显式栈 |
| **搜索策略** | 沿一条路走到底，走不通则回溯 |
| **最优性** | **不保证**最优解，需遍历所有可能 |
| **空间复杂度** | O(深度) |
| **适用场景** | 连通块计数、全排列/组合枚举、路径存在性、回溯求方案数 |

---

## DFS 核心思想

- **深度优先**：选定一个方向后不断深入，直到无法继续
- **回溯**：撤销当前选择，尝试其他分支
- **隐式栈**：递归调用天然维护搜索栈
- **不保证最优**：第一次找到的路径不一定最短或最优

```
        A
       / \
      B   C
     /     \
    D       E    ← 先走 A→B→D，回溯后再走 A→C→E
```

> [!tip] 何时选 DFS
> 需要**枚举所有方案**、**统计连通块**、或**深度不大的回溯**时优先 DFS；求最短路应选 BFS。

## DFS 模板代码

```cpp
void dfs(State state) {
    if (is_goal(state)) { update_answer(); return; }
    for (each next_state from state) {
        if (is_valid(next_state)) {
            mark_visited(next_state);
            dfs(next_state);
            unmark_visited(next_state); // 回溯
        }
    }
}
```

**要点**：

- `mark_visited` / `unmark_visited` 成对出现（回溯型 DFS）
- 连通块类问题可只 mark 不 unmark
- 剪枝：`is_valid` 中提前排除无效分支

## 连通块问题 — 城堡

**问题**：网格地图中统计房间数和最大房间面积，墙用数字编码。

**位运算解析墙体**（val 为格子值）：

| 方向 | 判断方式 |
|------|----------|
| 西墙 | `val % 2 == 1` |
| 北墙 | `(val / 2) % 2 == 1` |
| 东墙 | `(val / 4) % 2 == 1` |
| 南墙 | `(val / 8) % 2 == 1` |

**DFS 流程**：

1. 从未访问格子出发 DFS
2. 向四个方向扩展，检查对应墙是否存在
3. 累计连通格子数，更新最大面积

## 单词接龙（DFS + 回溯）

**问题**：给定单词序列，每次拼接有重合部分的单词，每个单词最多用两次，求最长序列。

**思路**：

1. 预处理任意两词的重合长度（枚举所有重合部分）
2. DFS 枚举拼接顺序，记录每个单词已用次数
3. **剪枝**：若当前词包含关系（如 "cat" 包含于 "category"），不可拼接

**状态**：`(当前词, 已用次数数组, 当前长度)`

---

## 碎纸机（DFS 枚举断点）

**问题**：将数字字符串在任意位置切割，使各段之和等于目标值，求最少段数。

**DFS 定义**：

```
dfs(start, sum, cnt)  // 从 start 位置开始切割，当前和为 sum，已用 cnt 段
```

**剪枝**：

- `sum > target` → 直接返回（和已超限）
- `sum == target && start == n` → 更新最少段数
- 枚举下一个断点 `i`，递归 `dfs(i, sum + num(start..i-1), cnt+1)`

## 生日蛋糕（DFS + 多重剪枝）

**问题**：N 层蛋糕，每层半径高度递减，求最小表面积。

**DFS 框架**：从底层向上枚举每层的半径 r 和高 h。

**五种剪枝策略**：

| # | 剪枝 | 说明 |
|---|------|------|
| 1 | 体积剪枝 | 剩余体积不足 → 剪枝 |
| 2 | 表面积剪枝 | 当前面积 + 理论最小剩余 > 最优 → 剪枝 |
| 3 | 半径单调 | 上层半径 < 下层 |
| 4 | 高度单调 | 上层高度 < 下层 |
| 5 | 最小半径/高度预处理 | 保证剩余层有合法方案 |

> [!important] 剪枝顺序
> 廉价剪枝（体积、边界）放前面，昂贵计算放后面，能大幅减少搜索树规模。

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "房间/连通区域/岛屿" | DFS 四方向/八方向 flood fill |
| "墙用数字编码" | 位运算 `%2`、`/2` 解析四方向墙 |
| "拼接/接龙/排列" | DFS + 回溯，注意重复使用限制 |
| "切割/分段/和为定值" | DFS 枚举断点 + sum 剪枝 |
| "求所有方案/计数" | DFS 枚举，回溯恢复状态 |
| "层数递减/组合优化" | 多重剪枝 DFS，预处理上下界 |

# 搜索剪枝技巧（★★）

#algorithm #search #pruning #optimization #concept

## 概览表（一目了然）

| 剪枝类型 | 判断依据 | 典型场景 |
|----------|----------|----------|
| **可行性剪枝** | 当前状态已不可能到达目标 | 体积不足、越界、非法前置条件 |
| **最优性剪枝** | 当前代价已超过已知最优解 | 表面积、路径长度、组合和 |
| **对称性剪枝** | 排除等价的搜索分支 | 跳过相同长度的失败尝试 |
| **排序优化** | 先搜索"可能性大"的分支 | 步长小的优先、长棍先拼 |

---

## 剪枝的本质

**提前排除不可能产生最优解的分支**，在不改变正确性的前提下缩小搜索空间。

```
完整搜索树                    剪枝后
      A                           A
    / | \                       / \
   B  C  D                     B   C
  /|\ |  |                     |
 ... ... ...                   ...
（指数级节点）              （大量子树被砍掉）
```

> [!tip] 剪枝顺序
> 廉价剪枝（边界、可行性）放前面，昂贵计算（最优性估计）放后面，能大幅减少无效递归。

---

## 常见剪枝策略

### 可行性剪枝

当前状态**已不可能**到达目标时立即返回。

- 剩余资源不足以完成目标（如生日蛋糕剩余体积 < 所需体积）
- 前置条件不满足（如青蛙前两步无法从稻田外跳入）
- 枚举范围本身不合法（如木棒目标长度 S 不是总长因子）

### 最优性剪枝

当前代价**已超过**已知最优解时，无需继续深入。

- 当前表面积 + 理论最小剩余 > 当前最优 → 返回
- 当前路径长度 + 剩余最大可能 ≤ 已知最长路径 → 返回

### 对称性剪枝

排除**等价**的搜索分支，避免重复计算同一状态空间。

- 木棒问题：相同长度的木棒在某位置拼接失败后，跳过其余同长度木棒
- 组合枚举：按固定顺序选取，避免 (A,B) 与 (B,A) 重复

### 排序优化

调整搜索顺序，**优先探索更可能产生优解的分支**，使最优性剪枝更早生效。

- 步长小的青蛙路径优先枚举
- 木棒从长到短排序，先拼长棍，短棍灵活补位

## 恼人的青蛙（穷举搜索 + 剪枝）

**问题**：稻田中被踩倒的水稻构成若干点，青蛙沿直线等距跳跃穿越稻田，求单条路径最多踩倒多少棵水稻。

**核心思路**：一条直线由两点确定 → **枚举每个可能路径的前两个点**，再沿方向延伸计数。

**剪枝策略**：

| # | 剪枝 | 说明 |
|---|------|------|
| 1 | 前两点合法性 | 判断能否从稻田**外面一步**跳到第一个点：`outside(p[start] - dx, p[start] - dy)` |
| 2 | 步长过大 | 若 `outside(p[start] + ans * dx, p[start] + ans * dy)`，则此方向最多跳不到当前最大值 |
| 3 | 排序优化 | 对所有被踩点按步长（或坐标）排序，**步长小的优先**考虑 |

```cpp
void count(int start, int next) {
    int dx = p[next].x - p[start].x;
    int dy = p[next].y - p[start].y;
    if (!outside(p[start].x - dx, p[start].y - dy)) return;  // 剪枝1
    if (outside(p[start].x + ans * dx, p[start].y + ans * dy)) return;  // 剪枝2
    int k = 2, x1 = p[next].x + dx, y1 = p[next].y + dy;
    while (!outside(x1, y1) && flags[x1][y1]) { k++; x1 += dx; y1 += dy; }
    if (outside(x1, y1) && k > ans) ans = k;
}
```

## 木棒问题（DFS + 多重剪枝）

**问题**：若干截断后的木棍，恢复为若干等长原始木棒，求**可能的最小原始长度**。

**抽象**：是否存在分组方案，使每组和均为 S → 枚举 S，对每个 S 做 DFS 组合。

**剪枝策略**：

| # | 剪枝 | 说明 |
|---|------|------|
| 1 | 只枚举因子 | S 必须是所有木棍长度**之和的因子** |
| 2 | 从大到小排序 | DFS 前按长度降序，**优先拼长棍**，短棍灵活补位 |
| 3 | 二分查找 | 在剩余木棒中二分找第一个 ≤ `rest` 的位置，缩小候选 |
| 4 | 跳过相同失败 | 某长度木棒在某位置拼接失败后，跳过其余同长度木棒 |

```cpp
void dfs(int tot, int last, int rest) {
    if (rest == 0) { /* 当前棍拼满，开下一根 */ ... return; }
    // 二分找第一个 a[mid] <= rest 的位置
    int l = last + 1, r = cnt;
    while (l < r) { int mid = (l + r) / 2; ... }
    for (int i = l; i <= cnt; i++) {
        if (vis[i]) continue;
        vis[i] = 1;
        dfs(tot, i, rest - a[i]);
        vis[i] = 0;
        if (flag) return;           // 已找到解
        while (i + 1 <= cnt && a[i + 1] == a[i]) i++;  // 剪枝4
    }
}
```

## 生日蛋糕（DFS + 5 重剪枝）

**问题**：M 层圆柱蛋糕，总体积 Nπ，半径/高度逐层递减，求最小外表面积 S（不含最底层下底面）。

**DFS 框架**：从底层向上枚举每层的半径 r 和高 h。

**五种剪枝**：

| # | 剪枝 | 条件 |
|---|------|------|
| 1 | 体积下界 | `sumV + leftMinV[curr] > N` → 即使最小体积也超了 |
| 2 | 体积上界 | `sumV + MaxVforNRH(curr, r, h) < N` → 最大体积也不够 |
| 3 | 尺寸不可安排 | 高度/半径为整数且下一层必须更小，无法继续 |
| 4 | 表面积剪枝 | `sumS > best` → 当前已劣于最优 |
| 5 | 单圆柱下界 | 剩余全部做成一个圆柱的最小面积 + 当前 > 最优 → 返回 |

```cpp
void dfs(int curr, int sumS, int sumV, int r, int h) {
    if (curr == 0) { /* 更新 best */ return; }
    if (sumV + leftMinV[curr] > N) return;                    // 剪枝1
    if (sumV + MaxVforNRH(curr, r, h) < N) return;            // 剪枝2
    if (sumS + leftMinS[curr] > best) return;                 // 剪枝4
    if (2 * (N - sumV) / r + sumS >= best) return;            // 剪枝5
    for (int i = r - 1; i >= curr; i--)
        for (int j = h - 1; j >= curr; j--)
            dfs(curr - 1, sumS + i * j * 2, sumV + i * i * j, i, j);
}
```

## 考试/测试常见模式

| 场景/关键词 | 剪枝思路 |
|-------------|----------|
| "等距/共线/直线" | 枚举前两点定方向 + 步长/合法性剪枝 |
| "分组/拼合/等长" | 枚举目标和 + 排序 + 对称性跳过 |
| "层数递减/体积约束" | 预处理上下界 + 当前最优剪枝 |
| "求最小/最大方案" | 维护当前 best，超界即剪 |
| "搜索超时/TLE" | 检查是否缺少排序优化或对称性剪枝 |

## 第 1 题 - 枚举三要素 [recall]

> 枚举法三个要点是什么？

> [!answer]- 查看答案
> 1. **枚举的内容**：建立数学模型，明确需要遍历哪些要素
> 2. **枚举的范围**：分析上下界，判断能否缩小解空间
> 3. **枚举的顺序**：根据题目要求选择（如求最大则从大往小）

## 第 2 题 - GCD 递归 [recall]

> 辗转相除法求 GCD 的递归代码？终止条件是什么？

> [!answer]- 查看答案
> ```cpp
> int gcd(int a, int b) {
>     if (b == 0) return a;   // 终止条件：b 为 0 时，a 即为 GCD
>     return gcd(b, a % b);
> }
> ```
> 互质时返回 1；`gcd(a, b) == 1` 表示 a、b 无公约数，可组成最简真分数。

## 第 3 题 - 密码锁优化 [recall]

> 特殊密码锁问题为什么只需枚举第一个灯的状态？

> [!answer]- 查看答案
> 1. 每个灯按**两次**效果抵消 → 每个位置只有"按/不按"两种有效状态
> 2. 第一个灯状态确定后，为满足目标状态，**第二个灯是否必须按**是唯一确定的
> 3. 依此类推，后续所有灯的状态均可推导 → 只需枚举第一个灯的 2 种情况

## 第 4 题 - 画家问题降维 [recall]

> 画家问题的枚举量从 2^(N×N) 如何降为 2^N？

> [!answer]- 查看答案
> 1. 涂两次 = 不涂，每块砖只有涂/不涂两种状态
> 2. 第一行某位置涂色后，**下一行对应位置是否必须涂**由第一行状态唯一决定（第一行仍为白 → 第二行必须涂）
> 3. 第一行 N 块砖各有涂/不涂 → **2^N** 种方案，每种方案可推导全部 N 行
> 4. 暴力枚举 2^(N×N) 会 TLE；2^N（N≤15）可接受

---

## 第 5 题 - 猴子吃桃数学解 [recall]

> 猴子吃桃数学解法的核心思路是什么？（补 N-1 个）

> [!answer]- 查看答案
> **补 N-1 个桃子**：给整堆补上 N-1 个后，每只猴子分走恰好总数的 1/N，不再有多余丢弃，过程变为均匀分割。
> - 补后总数 X 最小为 **N^N**（N 与 N-1 互质时）
> - 原最少桃子数 = **N^N - (N-1)**
> - 例：N=2 → 2² - 1 = **7**

---

## 第 6 题 - 火柴棒上界 [recall]

> 火柴棒等式中枚举上界如何确定？

> [!answer]- 查看答案
> 1. 数字 **1** 最省火柴（2 根）
> 2. 考虑 `1111 + 1 = 1112`，该等式需 **25** 根火柴
> 3. 当 n ≤ 24 时，两个加数都不可能 ≥ 1111
> 4. 因此 **A, B 均枚举 [0, 1111]**，C = A+B 由计算得出，再检查总火柴数是否等于 n

## 第 7 题 - 棋盘翻转 [application]

> 给定一个 N×N 的棋盘，每个格子有亮/暗两种状态，按一个格子会翻转上下左右和自身。如何用枚举法找到最少操作次数使所有格子亮？描述思路。

> [!answer]- 查看答案
> 与**画家问题**同型：
> 1. 按两次 = 不按 → 每格只有按/不按
> 2. **枚举第一行** N 个格子的按/不按（2^N 种）
> 3. 对每种第一行方案：若第 i 行第 j 列仍为暗，则第 i+1 行第 j 列**必须**按；逐行推导
> 4. 检查最后一行是否全亮；统计操作次数，取最小值
> 5. 若所有 2^N 方案均无法使全亮，则无解

## 第 8 题 - 最简真分数 [application]

> 有 5 个不同整数，判断能组成多少个最简真分数。写出关键枚举逻辑。

> [!answer]- 查看答案
> ```cpp
> int a[] = { /* 5 个不同整数 */ };
> int n = 5, count = 0;
> for (int i = 0; i < n; i++)
>     for (int j = i + 1; j < n; j++)      // 两两组合，避免重复
>         if (gcd(a[i], a[j]) == 1)         // 互质 → 最简真分数
>             count++;
> ```
> 5 个数共 C(5,2)=10 对，逐一检查 gcd 是否为 1。

## 第 9 题 - 复杂度比较 [analysis]

> 比较"枚举第一行→推导后续行"与"枚举所有状态"的时间复杂度差异，解释为什么前者更优。

> [!answer]- 查看答案
> | 方法 | 枚举量 | N=15 时 |
> |------|--------|---------|
> | 枚举所有状态 | 2^(N×N) | 2^225 ≈ 不可行 |
> | 枚举第一行+推导 | N · 2^N | 15 · 2^15 ≈ 49 万 |
>
> **原因**：翻转操作的**局部确定性**——第一行确定后，为满足目标，下一行每格是否必须操作是唯一确定的，不存在额外自由度。因此 N 行 N 列的问题实际只有第一行 N 个二进制选择，维度从 N² 降为 N。

## 第 10 题 - 猴子吃桃双解法 [analysis]

> 猴子吃桃的两种解法（逆向枚举 vs 数学解）各自的优缺点是什么？在什么情况下数学解不适用？

> [!answer]- 查看答案
> **逆向枚举**：
> - 优点：思路直观，易编程验证；适用于任意 N
> - 缺点：需枚举 m 直到找到解，最坏情况较慢；需逐层检查整除条件
>
> **数学解（N^N - (N-1)）**：
> - 优点：O(1) 直接出答案；代码极简
> - 缺点：需理解"补 N-1 个"的转化；**N=2 等边界**需单独验证；若题目条件变化（如猴子数不固定、分法不同），公式可能失效
>
> **数学解不适用的情况**：分桃规则改变、需输出中间过程、N 与 N-1 不互质且需最小正整数解的额外约束时，应使用逆向枚举。

## 枚举法核心思想

枚举法（穷举法）的本质：**在确定的解空间中，逐一检查每个候选解是否满足条件**。

解题流程可概括为三步：

```
确定解空间 → 减少枚举范围 → 选择枚举顺序
     ↓              ↓                ↓
  建立数学模型    上下界分析        根据题目要求
```

> [!tip] 核心原则
> 先想清楚"枚举什么"，再想办法"少枚举"，最后决定"怎么枚举"。

## 解题框架

### 1. 确定枚举内容（建立数学模型）

- 将题目条件转化为**可遍历的变量**（如十进制数、两数组合、第二站上车人数等）
- 建立简洁的数学模型，明确哪些要素需要枚举、哪些可以推导

**示例**：求特殊自然数 → 枚举十进制数，检查其七进制与九进制表示是否满足条件

### 2. 确定枚举范围（上下界分析）

- 利用题目约束推导**上下界**（如七进制/九进制均为三位数 → 范围 [49, 728]）
- 判断是否存在**无需枚举的维度**（如密码锁只需枚举第一个按钮）

### 3. 确定枚举顺序（根据题目要求）

- 求**最小**满足条件的解 → 通常从小到大
- 求**最大**满足条件的解 → 通常从大到小
- 求**所有**解 → 按题意决定顺序，不影响正确性

## 关键优化技巧

### 减少枚举空间（数学推导缩小范围）

利用题目条件推导 tighter 的上下界，避免无效遍历。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 进制/位数约束 | 由表示形式反推数值范围 | 七进制三位数 → 49 ~ 728 |
| 火柴棒上界 | 用最"省"火柴的等式估算最大值 | `1111+1=1112` 需 25 根 → 加数 < 1111 |
| 递推关系 | 由末态反推参数范围 | 火车上的人数：`a2 ∈ [0, m-1]`（n>4） |

### 选择合适的枚举变量

**按钮/开关类问题**：按两次 = 不按，每个位置只有"按/不按"两种有效状态。

- 特殊密码锁：只需枚举**第一个灯**是否按下，后续灯的状态可依次推导
- 画家问题：只需枚举**第一行**砖块的涂色方案，后续行可推导

### 从后往前枚举（逆向枚举）

当正向递推关系复杂时，从**末态**反推初态往往更简单。

- **猴子吃桃**：设最后一只猴子拿走 m 个，则 `b_{i-1} = (b_i - 1) * (N-1) / N`，需满足整除条件
- 枚举 m 从 1 开始，逆向递推至第一只猴子，找到最小合法初值

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "七进制/九进制""进制转换" | 确定范围后逐一枚举，检查转换结果 |
| "最简真分数""互质" | 两两组合 + `gcd(a,b)==1` |
| "按钮/开关""按两次抵消" | 只枚举第一个，后续推导 |
| "最少桃子数""N只猴子分桃" | 逆向枚举，或补 N-1 个桃子的数学巧解 |
| "N×N 棋盘翻转" | 枚举第一行（2^N），推导后续行 |
| "火柴棒等式" | 预处理数字耗棒数，分析枚举上界 |
| "递推+未知参数" | 枚举关键参数（如第二站上车人数），递推验证 |

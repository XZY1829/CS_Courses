## 1. 求特殊自然数

**题意**：一个十进制自然数，其七进制与九进制表示均为三位数，且两种进制下的三位数码**顺序正好相反**。求此数并输出三种进制表示。

**思路**：
1. 七进制、九进制均为三位数 → 十进制范围 **[49, 728]**
2. 枚举每个候选数，转换为七进制和九进制
3. 检查两种表示的数码是否反序相等

**关键代码**：

```cpp
for (int i = 49; i <= 728; i++) {
    string base7 = toBase(i, 7);  // 三位
    string base9 = toBase(i, 9);  // 三位
    if (base7 == reverse(base9))
        // 找到答案
}
```

**复杂度**：O(680 × 转换开销)，常数级，可接受

## 2. 最简真分数

**题意**：给定 n 个不同正整数，任取两个分别作分子、分母组成真分数，求最简真分数（分子分母互质）的组合个数。

**思路**：
1. 枚举所有两两组合 `(i, j)`，i < j
2. 用辗转相除法判断 `gcd(a[i], a[j]) == 1`

**关键代码**：

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

int total = 0;
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (gcd(a[i], a[j]) == 1)
            total++;
```

**复杂度**：O(n² · log(max(a)))，n ≤ 600 可接受

## 3. 猴子吃桃

**题意**：N 只猴子依次分桃，每次均分 N 份多 1 个，扔掉多的 1 个后拿走 1 份。求最少初始桃子数。

### 解法 A：逆向枚举

设倒数第 i 只猴子面对 b_i 个桃，最后一只：`b_1 = m·N + 1`

递推：`b_{i-1} = (b_i - 1) * (N-1) / N`，要求 `(b_i - 1) % (N-1) == 0`

枚举 m = 1, 2, 3, …，逆向递推 N 步，首个全程合法的 b_N 即为答案。

```cpp
for (int m = 1; ; m++) {
    int b = m * N + 1;
    bool ok = true;
    for (int i = 1; i < N; i++) {
        if ((b - 1) % (N - 1) != 0) { ok = false; break; }
        b = (b - 1) / N * (N - 1);
    }
    if (ok) { cout << b; break; }
}
```

### 解法 B：数学巧解（补 N-1 个桃子）

> [!important] 核心思路
> 给整堆桃子**补上 N-1 个**，则每只猴子分走恰好 1/N，不再有多余丢弃。
> 补后总数 X 最小为 **N^N**，原答案 = **N^N - (N-1)**。

> [!warning] 边界条件
> 需 N > 2 时 N 与 N-1 互质，公式才严格成立；N=2 时答案为 7，仍可用逆向枚举验证。

**复杂度**：逆向 O(答案/N)，数学解 O(1)

## 4. 特殊密码锁 / 画家问题

### 特殊密码锁

**题意**：n 个相连按钮，按一个会翻转自身及相邻按钮。求最少按键次数使当前状态变为目标状态。

**思路**：
1. 每个按钮按两次 = 不按 → 只需考虑按/不按
2. **只枚举第一个按钮**是否按下
3. 第一个确定后，为满足目标，后续每个按钮是否按下唯一确定

```cpp

for (int first = 0; first <= 1; first++) {
    int presses = first;

}
```

**复杂度**：O(n)，枚举量从 2^n 降为 **2**

### 画家问题（N×N 墙）

**题意**：N×N 砖墙，涂一块会翻转上下左右及自身，求最少涂画次数使全黄。

**思路**：
1. 涂两次 = 不涂 → 每块砖只有涂/不涂
2. 暴力枚举 2^(N×N) 会 TLE
3. **枚举第一行** 2^N 种涂法 → 第一行白砖对应位置，第二行**必须**涂；推导至最后一行并验证

**复杂度**：O(N · 2^N)，N ≤ 15 可接受；相比 2^(N²) 大幅优化

## 5. 火柴棒等式

**题意**：n 根火柴拼 `A+B=C` 等式，A、B、C 为非负整数（非零数最高位不为 0），必须用完所有火柴。

**思路**：
1. **预处理**：`stick[0..9]` 存每个数字所需火柴数
2. **上界分析**：数字 1 最省（2 根）；`1111+1=1112` 需 25 根 → **A, B < 1111**
3. 枚举 A, B ∈ [0, 1111]，计算 C = A+B，检查 `stick[A]+stick[B]+stick[C]+4 == n`（+4 为加号、等号各 2 根）

```cpp
int stick[10] = {6,2,5,5,4,5,6,3,7,6}; // 0-9 所需火柴数
for (int A = 0; A <= 1111; A++)
    for (int B = 0; B <= 1111; B++) {
        int C = A + B;
        if (stick[A]+stick[B]+stick[C]+4 == n) count++;
    }
```

**复杂度**：O(1111²)

## 6. 火车上的人数

**题意**：n 个车站，第 1 站上车 a 人；第 2 站上下人数相同；从第 3 站起上车 = 上两站上车之和，下车 = 上一站上车。已知第 n-1 站下车 m 人，求第 x 站开出时人数。

**递推规律**（i ≥ 3）：
- a_i = a_{i-1} + a_{i-2}
- b_i = a_{i-1}
- c_i = c_{i-1} + a_i - b_i

**思路**：第 2 站上车人数 a₂ 未知 → **枚举 a₂**，递推至 c_{n-1}，若等于 m 则找到合法 a₂，输出 c_x。

**枚举范围**：
- n = 4：m = 2a，与 a₂ 无关
- n > 4：m > a₂ → a₂ ∈ **[0, m-1]**

**复杂度**：O(m · n)

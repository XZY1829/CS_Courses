# 线性DP（★★★）

#algorithm #dynamic-programming #concept #lis #edit-distance #bottom-up

## 概览表：线性DP题型一览

| 题型 | 状态定义 | 转移核心 | 复杂度 |
|------|----------|----------|--------|
| 拦截导弹（LDS/LIS） | maxlen(k) = 以 aₖ 为终点的最长下降子序列 | max{maxlen(i): i<k 且 a[i]≥a[k]} + 1 | O(n²) |
| 编辑距离 | distance[i][j] = s1[1:i] 与 s2[1:j] 的最小距离 | 匹配/删/改 取 min | O(mn) |
| 最佳加法表达式 | V(m,n) = n 个数插 m 个加号的最小值 | min{V(m−1,i) + Num(i+1,n)} | O(mn²) |
| 滑雪 | L(i,j) = 从 (i,j) 出发的最长滑行 | max{周围更低点的 L} + 1 | O(RC log RC) |

## 1. 拦截导弹 — 最长不上升子序列（#lis）

**问题**：导弹依次飞来，拦截系统每发炮弹不能高于前一发，求最多拦截多少枚。

### 错误状态（不满足无后效性）

> "前 n 个元素的最长下降子序列长度"

达到状态 n 的具体序列不同——有的末尾比 a_{n+1} 大（可接上），有的不行。**如何到达状态 n 会影响后续转移**。

### 正确状态

**maxlen(k)** = 以 aₖ 为**终点**的最长下降（不上升）子序列长度。

满足无后效性：状态演变只取决于 aₖ 的值。

### 转移方程

```
maxlen(1) = 1
maxlen(k) = max{ maxlen(i) : 1 ≤ i < k 且 a[i] ≥ a[k] } + 1
            （找不到这样的 i 时，maxlen(k) = 1）
```

### 关键代码

```cpp
for (int i = 2; i <= N; i++)
    for (int j = 1; j < i; j++)
        if (a[i] <= a[j])
            maxlen[i] = max(maxlen[i], maxlen[j] + 1);
// 答案: max(maxlen[1..N])
```

**时间复杂度**：O(n²)，**空间复杂度**：O(n)。

## 2. 编辑距离（#edit-distance）

**问题**：通过**修改**、**删除**字符（等价于增删），使两个字符串相同，求最少操作次数。

### 状态定义

`distance[i][j]` = 字符串 s1[1:i] 与 s2[1:j] 的最小编辑距离

### 边界

```
distance[i][0] = i    // 删除 s1 的 i 个字符
distance[0][j] = j    // 删除 s2 的 j 个字符
```

### 转移方程

```
若 s1[i] == s2[j]:
    distance[i][j] = distance[i-1][j-1]

否则:
    distance[i][j] = min(
        distance[i-1][j],      // 删除 s1[i]
        distance[i][j-1],      // 删除 s2[j]
        distance[i-1][j-1]     // 修改 s1[i] 为 s2[j]
    ) + 1
```

**时间复杂度**：O(mn)，**空间复杂度**：O(mn)。

## 3. 最佳加法表达式

**问题**：在数字串（如 "1234"）中插入 m 个加号，使表达式值最小。

### 状态定义

**V(m, n)** = 在 n 个数字中插入 m 个加号所能形成的表达式最小值

### 转移方程

最后一个加号加在第 i 个数字后面：

```
V(m, n) = min{ V(m-1, i) + Num(i+1, n) }    i = m, ..., n-1
```

**边界**：

| 条件 | 值 |
|------|-----|
| m = 0 | Num(1, n) — 整个数 |
| n < m + 1 | ∞ — 加号太多 |

**Num(i,j)** = 第 i 到第 j 个数字组成的整数，可**预处理**存储，避免 O(j−i) 重复计算。

**时间复杂度**：O(m · n²)（预处理 Num 后）。

## 4. 滑雪（二维 DP）

**问题**：R×C 区域，每格有高度，只能滑向相邻且更低的格，求最长滑坡长度。

### 状态定义

**L(i, j)** = 从点 (i,j) 出发的最长滑行长度

### 转移方程

```
L(i, j) = 1                                    // 周围无更低点
L(i, j) = max{ L(周围比(i,j)低的点) } + 1     // 否则
```

### 解法 1：按高度排序后递推

1. 将所有点按高度**从小到大**排序
2. L 值初始化为 1
3. 遍历每个点 (i,j)，用递推公式更新 L(i,j)

保证处理 (i,j) 时，所有比它低的点的 L 值已计算完毕。

### 解法 2：遍历时更新周围更高点

从小到大遍历点 (i,j) 时，**反向更新**周围比它高的点：

```cpp
if (H(i+1, j) > H(i, j))
    L(i+1, j) = max(L(i+1, j), L(i, j) + 1);
// 对四个方向同理
```

**时间复杂度**：O(RC log RC)（排序），**空间复杂度**：O(RC)。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "最长上升/下降子序列" | 状态 = **以 aₖ 为终点**，O(n²) 双重循环 |
| "两个字符串最小编辑" | **distance[i][j]** 三维决策（匹配/删/改） |
| "插入符号使表达式最优" | **V(m,n) 区间 DP**，枚举最后分割点 |
| "网格最长路径（有方向约束）" | **按拓扑序递推**（高度排序） |
| "状态无后效性不满足" | **重新定义状态** — 加上"终点"信息 |
| "前 n 个元素的最优" | ⚠️ 常见陷阱，检查是否影响后续转移 |

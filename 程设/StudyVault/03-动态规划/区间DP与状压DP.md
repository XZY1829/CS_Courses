# 区间DP与状压DP（★★★）

#algorithm #dynamic-programming #interval-dp #state-compression #monotone-stack #bit-manipulation #concept

## 概览表（一目了然）

| 维度 | 区间 DP | 状压 DP |
|------|---------|---------|
| **状态含义** | 区间 `[i, j]` 上的最优解 | 集合 `s`（已选/已访问元素）+ 附加维度 |
| **状态规模** | O(n²) 或 O(n³) | O(2^n × n) |
| **典型场景** | 合并、消除、括号匹配 | TSP、棋盘行布局、子集枚举 |
| **转移方向** | 按区间长度递增 | 按集合大小（popcount）递增 |
| **编码方式** | 下标 `(i, j)` | 二进制 bitmask 表示集合 |

---

## 状态压缩 DP 原理

### 何时使用

当 DP 状态中需要记录**一个集合**（哪些元素已被选择/访问/占用）时，若集合规模 n ≤ 20 左右，可用**状态压缩**将集合编码为一个整数。

### 二进制编码集合

用 n 位二进制数 `s` 表示集合：第 `i` 位为 1 表示第 `i` 个元素已选。

```
集合 {0, 2, 4}  →  s = 10101₂ = 21
```

### 常用位运算

| 操作 | 表达式 | 含义 |
|------|--------|------|
| 添加元素 i | `s \| (1 << i)` | 将第 i 位置 1 |
| 删除元素 i | `s & ~(1 << i)` | 将第 i 位置 0 |
| 查询元素 i | `(s >> i) & 1` | 第 i 位是否为 1 |
| 集合大小 | `__builtin_popcount(s)` | 已选元素个数 |

> [!warning] 状压 DP 中位运算优先级
> `(s >> i) & 1` **必须加括号**，否则 `&` 会先于 `>>` 计算，导致结果错误。

## 海贼王（TSP 问题）

**问题**：从起点出发，访问所有岛屿各一次，求最短时间（旅行商问题）。

**状态定义**：

```
dp[s][l] = 从起点出发，已访问集合 s 中所有岛屿，当前位于岛屿 l 的最短时间
```

**转移方程**：

```
dp[s][l] = min{ dp[s & ~(1<<i)][i] + dis[i][l] }   （i ∈ s, i ≠ l）
```

**边界**：`dp[1<<start][start] = 0`（仅起点在集合中）

**时间复杂度**：O(2^n × n²)

```
状态按 popcount(s) 递增枚举：
  s=001 → s=011,101,110 → s=111 → ...
```

## 炮兵阵地

**特殊状压**：每行宽度 ≤ 10，每行最多 **60 种**合法布局（炮不能相邻，包括斜对角）。

**状态定义**：

```
dp[i][j][k] = 第 i 行采用布局 status[j]，第 i-1 行采用布局 status[k] 时的最大炮兵数
```

**关键约束**：

- 同一列上，两行炮的**行间距 ≥ 2**（即 j 与 k 在每一列上不能冲突）
- 预处理所有行的合法布局 `status[]`
- 预处理任意两种布局 `(j, k)` 是否相容

**转移**：枚举第 i-2 行的布局 p，若 `(p, k)` 相容则：

```
dp[i][j][k] = max(dp[i][j][k], dp[i-1][k][p] + count(status[j]))
```

## 区间 DP — 棋子消除（方盒游戏）

**问题**：一行同色方块，点击消除连续同色块得 `(长度)²` 分，求最高分。

**状态定义**（三维区间 DP）：

```
click(i, j, ex_len) = 将大块 [i, j] 连同右侧 ex_len 个与 j 同色的块一起消除的最高分
```

**两种策略**：

1. **直接消除**：先消除 `[i, j-1]`，再消除 j 及右侧同色块
2. **与左侧同色块合并**：找到 k 使 `color[k] == color[j]`，先消除中间段，再合并消除

**转移方程**：

```
click(i, j, ex_len) = max(
    click(i, j-1, 0) + (len[j] + ex_len)²,
    max_{k: color[k]=color[j]} { click(k+1, j-1, 0) + click(i, k, len[j]+ex_len) }
)
```

**枚举顺序**：区间长度从小到大，保证子问题已计算。

## 接雨水（单调栈解法）

**问题**：给定柱子高度数组，求能接多少雨水。

**单调栈**：栈底到栈顶对应柱子**高度递减**。

**核心逻辑**：遇到比栈顶更高的柱子 `h[i]` 时，栈顶 `top` 是"洼地"，计算以 `top` 为底的积水：

```
width  = i - next - 1        （next 为栈中 top 下面的元素）
height = min(h[i], h[next]) - h[top]
ans   += width × height
```

```
     |     |
  |  |#|   |     ← h[i] 更高，弹出 top 计算积水
  |#|#|#|   |
```

> [!tip] 与 DP 的关系
> 接雨水也可用双指针或前缀最值 O(n) 解决；单调栈是同一类"维护候选边界"思想的典型应用，常出现在 DP 优化章节。

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "访问所有点/岛屿""最短回路" | 状压 TSP：`dp[s][l]`，O(2^n × n²) |
| "每行放炮/不能相邻" | 行状压 + 行间相容性检查 |
| "消除/合并/括号" | 区间 DP，按长度递增枚举 |
| "同色块消除得平方分" | 三维区间 `click(i,j,ex_len)`，合并策略 |
| "接雨水/柱状图蓄水" | 单调栈维护递减高度 |
| "集合 ≤ 20""子集" | 优先考虑状压，用 bitmask 编码 |

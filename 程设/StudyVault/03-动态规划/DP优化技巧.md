## 空间优化

### 滚动数组

当 `dp[i][j]` **只依赖** `dp[i-1][...]` 时，用一维数组代替二维，复用同一层存储。

**数字三角形案例**：

```cpp
// 原：dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + tri[i][j]
// 优化：自底向上，直接复用 D[n] 数组
for (int i = n-1; i >= 0; i--)
    for (int j = 0; j <= i; j++)
        D[j] = max(D[j], D[j+1]) + tri[i][j];
```

### 遍历方向

| 依赖关系 | 遍历方向 | 原因 |
|----------|----------|------|
| `dp[i][j]` 依赖 `dp[i-1][j]` 和 `dp[i-1][j-1]` | **从左→右** | 避免覆盖尚未使用的值 |
| `dp[i][j]` 依赖 `dp[i][j-1]` | **从右→左** | 避免同一行左侧被提前覆盖 |
| 0-1 背包 | **从右→左** | 每种物品只用一次 |

> [!warning] 方向错误 = 答案错误
> 滚动数组优化后，必须根据依赖关系确定遍历方向，不能随意选择。

## 单调栈 / 单调队列优化

### 适用场景

求**滑动窗口**内的最值，或维护"下一个更大/更小元素"类信息。

### 接雨水 — 单调栈详解

维护**递减栈**（栈底到栈顶高度递减）：

1. 遍历每根柱子 `h[i]`
2. 若 `h[i] > h[top]`，弹出 `top` 并计算以 `top` 为底的积水
3. 将 `i` 入栈

```
width  = i - stack[top-1] - 1
height = min(h[i], h[stack[top-1]]) - h[top]
```

### 手动优先队列（单调队列）

维护窗口最小值时，每次新元素入队前：

- **删除队尾**所有比新元素**大**的元素（它们不可能成为最小值）
- 队头超出窗口范围时**弹出**

均摊时间复杂度 O(n)。

## 优先队列优化 — 灌溉草场

**问题**：在位置 X 灌溉需 `f(X) = 1 + min{ f(Y) : Y ∈ [X-2B, X-2A] }` 天，求 `f(L)`。

**暴力**：对每个 X 扫描窗口 `[X-2B, X-2A]` → O(L × B)，超时。

**优化**：用**单调队列**维护窗口内的最小 `f(Y)`：

```
for X from 2A+1 to L:
    将 f[X-2A] 入队（删除队尾更大者）
    弹出队头 < X-2B 的元素（超出窗口）
    f[X] = 1 + queue.front()
```

**关键**：新元素入队时清理队尾，为后续 X 的最值查询做准备；队头维护当前窗口最小值。

## 美妙的栅栏（排列计数 DP）

**问题**：n 根不同长度的木棒组成 UP/DOWN 交替的"栅栏"排列，求字典序第 C 个排列。

**状态定义**：

```
M[i][k][UP]   = 前 i 根木棒、以第 k 短木棒开头、最后一段为 UP 的方案数
M[i][k][DOWN] = 前 i 根木棒、以第 k 短木棒开头、最后一段为 DOWN 的方案数
```

**转移方程**：

```
M[i][k][UP]   = Σ M[i-1][j][DOWN]   (j = k, k+1, ..., i-1)
M[i][k][DOWN] = Σ M[i-1][j][UP]     (j = 1, 2, ..., k-1)
```

**定位第 C 个排列**：

1. 用前缀和预处理转移中的区间求和
2. 从 i = n 到 1 逐位确定：比较 UP/DOWN 分支的方案数与 C 的大小
3. 选定分支后更新 C，继续确定下一根木棒

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "只依赖上一行/层" | 滚动数组，注意遍历方向 |
| "滑动窗口最小/最大值" | 单调队列或手动 deque |
| "接雨水/柱状图" | 单调栈维护递减高度 |
| "区间依赖 f(X-2A)...f(X-2B)" | 单调队列维护窗口最值 |
| "计数排列/字典序第 K 个" | DP 计数 + 前缀和定位 |
| "O(n²) 空间超限" | 检查是否可滚动优化到 O(n) |

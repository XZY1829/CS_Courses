# DP基础与方法论（★★★）

#algorithm #dynamic-programming #concept #memoization #bottom-up #space-optimization

## 概览表：DP vs 递归 vs 贪心

| 特征 | 递归 | 动态规划 | 贪心 |
|------|------|----------|------|
| 子问题 | 自顶向下分解 | 自顶向下或自底向上 | 每步局部最优 |
| 重复计算 | 可能大量重复 | 每个子问题只算一次 | 不涉及子问题表 |
| 最优性 | 不一定全局最优 | **保证全局最优**（满足条件时） | 仅当贪心选择性质成立 |
| 适用条件 | 问题可分解 | 最优子结构 + **无后效性** | 贪心选择性质 + 最优子结构 |
| 典型复杂度 | O(2^n)（无优化） | O(n²) 等多项式 | 通常 O(n log n) 或 O(n) |
| 空间 | O(n) 递归栈 | O(n) ~ O(n²) DP 表 | O(1) ~ O(n) |

---

## 1. DP 解题四步法

| 步骤 | 内容 | 示例（数字三角形） |
|------|------|-------------------|
| ① 分解子问题 | 将原问题拆成更小的同类问题 | 从 (i,j) 到底边的最大路径和 |
| ② 定义状态 | 用变量描述子问题的解 | MaxSum(i,j) = 从 D(i,j) 出发的最大和 |
| ③ 确定边界 | 最小子问题的已知值 | MaxSum(N,j) = D(N,j) |
| ④ 推导转移方程 | 大状态由小状态组合 | MaxSum(i,j) = max(MaxSum(i+1,j), MaxSum(i+1,j+1)) + D(i,j) |

---

## 2. DP 适用条件

### 最优子结构

问题的**最优解**包含其子问题的**最优解**。例如数字三角形：从 (i,j) 出发的最优路径，必然包含从 (i+1,j) 或 (i+1,j+1) 出发的最优路径之一。

### 无后效性

当前若干个状态值一旦确定，此后过程的演变**只与这些状态值有关**，与"如何到达当前状态"无关。

> [!warning] 定义状态时必须验证"无后效性"——如果"如何达到当前状态"会影响后续决策，说明状态定义有误。

**反例**：拦截导弹中"前 n 个元素的最长下降子序列长度"不满足无后效性——达到状态 n 的具体序列会影响能否接上 a_{n+1}。

## 3. 从递归到 DP 的三步优化

以数字三角形为例：

```
MaxSum(i,j) = max(MaxSum(i+1,j), MaxSum(i+1,j+1)) + D(i,j)
边界: MaxSum(N,j) = D(N,j)
```

| 阶段 | 方法 | 时间复杂度 | 特点 |
|------|------|------------|------|
| ① 纯递归 | 深度优先，重复计算 | **O(2^n)** | 每条路径都走一遍 |
| ② 记忆化递归（#memoization） | 保存已计算的 MaxSum(i,j) | **O(n²)** | 每个 (i,j) 只算一次 |
| ③ 递推自底向上（#bottom-up） | 从第 n 行往上填表 | **O(n²)** | 消除递归开销 |

**记忆化递归代码**：

```cpp
int maxsum[MAX][MAX];
int MaxSum(int i, int j) {
    if (maxsum[i][j] != -1) return maxsum[i][j];
    if (i == n) maxsum[i][j] = D[i][j];
    else {
        int x = MaxSum(i+1, j);
        int y = MaxSum(i+1, j+1);
        maxsum[i][j] = max(x, y) + D[i][j];
    }
    return maxsum[i][j];
}
```

## 4. 空间优化（#space-optimization）

**核心观察**：计算第 i 行时，只需要第 i+1 行的结果 → 二维可压缩为一维。

**滚动数组技巧**：

```cpp
// 初始化最后一行
for (int j = 1; j <= n; j++) maxsum[j] = D[n][j];

// 自底向上递推
for (int i = n-1; i >= 1; i--)
    for (int j = 1; j <= i; j++)
        maxsum[j] = max(maxsum[j], maxsum[j+1]) + D[i][j];
// 等价于: maxsum[i][j] = max(maxsum[i+1][j], maxsum[i+1][j+1]) + D[i][j]
```

**进一步优化**：直接用 D 数组第 n 行代替 maxsum，原地覆盖，空间 O(n)。

| 优化 | 空间 | 条件 |
|------|------|------|
| 二维 DP 表 | O(n²) | 通用 |
| 滚动数组 | O(n) | dp[i] 只依赖 dp[i−1] |
| 原地覆盖 | O(n) 或 O(1) | 不再需要保留原始数据 |

## 5. 数字三角形完整案例

**问题**：从顶部到底边，每步只能往左下或右下，求路径数字之和的最大值。

**状态定义**：MaxSum(i,j) = 从 D(i,j) 到底边的最佳路径数字和

**转移方程**：

```
MaxSum(i,j) = max( MaxSum(i+1, j), MaxSum(i+1, j+1) ) + D(i,j)
```

**递推代码**（自底向上）：

```cpp
for (int i = n-1; i >= 1; i--)
    for (int j = 1; j <= i; j++)
        maxsum[i][j] = max(maxsum[i+1][j], maxsum[i+1][j+1]) + D[i][j];
// 答案: maxsum[1][1]
```

**复杂度**：时间 O(n²)，空间 O(n²) → 可优化至 O(n)。

**递推过程示意**（5 行三角形）：

```
第5行:  4  5  2  6  5        → 边界
第4行:  7  12 10 10  ...     → 逐行向上填
...
第1行:  30                    → 答案
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "求最大/最小路径和" | **定义状态 + 转移方程**，数字三角形模型 |
| "递归 TLE / 重复子问题" | 加 **记忆化** 或改 **自底向上递推** |
| "状态怎么定义" | 验证 **无后效性** — 到达方式不影响后续 |
| "空间太大" | **滚动数组** — 二维压一维 |
| "O(2^n) → O(n²)" | 纯递归 → 记忆化 → 递推，三步优化 |
| "不满足无后效性" | **重新定义状态**（如 LIS 改为"以 aₖ 为终点"） |

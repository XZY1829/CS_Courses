## 1. 全排列

**思路**：求 S = {a₁, …, aₙ} 的全排列，等价于：

1. 选定 aᵢ 放在排列首位
2. 求 S\{aᵢ} 的全排列
3. 遍历所有 aᵢ

**递归公式**：

```
permute(S) = 对每个 aᵢ ∈ S:  aᵢ + permute(S \ {aᵢ})
```

**终止条件**：|S| = 1 时直接返回该元素。

**关键代码**：

```cpp
void permute(vector<int>& nums, int start, vector<vector<int>>& result) {
    if (start == nums.size()) {
        result.push_back(nums);
        return;
    }
    for (int i = start; i < nums.size(); i++) {
        swap(nums[start], nums[i]);
        permute(nums, start + 1, result);
        swap(nums[start], nums[i]);  // 回溯
    }
}
```

**时间复杂度**：O(n!) — 共 n! 种排列，每种生成 O(n) 开销。

> [!tip] 对比"插入法"
> 笨办法是先求 n-1 的全排列，再把第 n 个数字插入各位置；递归写法则是"选一个放首位"的分治思路。

## 2. 波兰表达式求值

**问题**：运算符前置的算术表达式，如 `(2+3)*4` 写作 `* + 2 3 4`。

### 递归解法

读入一个符号：若是运算符，则**递归**求两个子表达式的值；若是数字，直接返回。

```cpp
double exp() {
    char s[n];
    scanf("%s", s);
    switch (s[0]) {
        case '+': return exp() + exp();
        case '-': return exp() - exp();
        case '*': return exp() * exp();
        case '/': return exp() / exp();
        default:  return atof(s);
    }
}
```

**时间复杂度**：O(n)，每个 token 处理一次。

### 栈解法（#stack-simulation）

模仿波兰表达式的展开顺序：**从右往左**扫描，遇数字入栈，遇运算符弹出两个操作数计算后压回。

```
* + 11.0 12.0 + 24.0 35.0
→ 35.0 → 24.0 → 59.0 → 12.0 → 11.0 → 23.0 → 1357.0
```

**时间复杂度**：O(n)，**空间复杂度**：O(n)。

## 3. 汉诺塔（#divide-and-conquer）

**问题**：将 n 个大小不等的盘从 src 移到 dest，借助 tmp，每次只移一个，且大盘不能压小盘。

### 递归解法

```
Hanoi(n, src, tmp, dest)
  = Hanoi(n-1, src, dest, tmp)   // 上面 n-1 个移到 tmp
  + move(src → dest)              // 最大盘移到 dest
  + Hanoi(n-1, tmp, src, dest)   // tmp 上 n-1 个移到 dest
```

```cpp
void Hanoi(int n, char src, char tmp, char dest) {
    if (n == 1) {
        cout << src << "->" << dest << endl;
        return;
    }
    Hanoi(n-1, src, dest, tmp);
    cout << src << "->" << dest << endl;
    Hanoi(n-1, tmp, src, dest);
}
```

**时间复杂度**：O(2^n) — 移动次数为 2^n − 1。

### 非递归解法（#stack-simulation）

用栈存储子问题结构体，**模仿递归展开顺序，从后向前入栈**：

```cpp
struct Problem {
    int n;
    char src, tmp, dest;
};
stack<Problem> stk;
stk.push(Problem(n, 'A', 'B', 'C'));
while (!stk.empty()) {
    Problem cur = stk.top(); stk.pop();
    if (cur.n == 1)
        cout << cur.src << "->" << cur.dest << endl;
    else {
        stk.push(Problem(cur.n-1, cur.tmp, cur.src, cur.dest));  // ③ 最后执行
        stk.push(Problem(1,       cur.src, cur.tmp, cur.dest));  // ②
        stk.push(Problem(cur.n-1, cur.src, cur.dest, cur.tmp));  // ① 最先执行
    }
}
```

> 入栈顺序与递归调用顺序**相反**，栈顶元素最先被处理。

## 4. 整数划分（放肉饼）

**问题**：M 个肉饼分给 N 个导师，允许有人没分到，(5,1,1) 与 (1,5,1) 视为同一种。求分法总数。

**函数**：`Allocate(m, n)` — m 个物品分给 n 个人。

**递归关系**：

```
Allocate(m, n) = Allocate(m, n-1)        // 至少有一人没分到
               + Allocate(m-n, n)         // 每人至少分 1 个
```

**终止条件**：

| 条件 | 返回值 | 含义 |
|------|--------|------|
| m == 0 | 1 | 没肉饼了，唯一分法（全 0） |
| n == 0 | 0 | 没人可分 |
| n > m | Allocate(m, m) | 导师多于肉饼，等价于 m 人 |

```cpp
int Allocate(int m, int n) {
    if (m == 0) return 1;
    if (n == 0) return 0;
    if (n > m)  return Allocate(m, m);
    return Allocate(m, n-1) + Allocate(m-n, n);
}
```

## 5. 棋盘分割（#memoization #prefix-sum）

**问题**：8×8 棋盘沿格线切 (n−1) 刀，得到 n 块矩形，使各块总分的**均方差**最小。均方差公式中 Σ(xᵢ − x̄)² 可化简为 **Σxᵢ² − (Σxᵢ)²/n**，固定棋盘时只需最小化 **Σxᵢ²**。

**递归思路**（穷举型递归）：每一步只能**横切**或**竖切**贯穿一刀。

```
f(n, x1, y1, x2, y2) = min(
    横切: f(k, ...)² + f(n-k, ...)²,   k = 1..n-1
    竖切: f(k, ...)² + f(n-k, ...)²
)
```

- **边界**：f(1, x1, y1, x2, y2) = smallSum(x1,y1,x2,y2)²
- **不可行**：当 (x2−x1) + (y2−y1) < n−1 时，返回 +∞

**记忆化**：`val[n][x1][y1][x2][y2]`，避免重复计算导致 TLE。

**前缀和优化**（#prefix-sum）：

```cpp
// sum[x][y] = 从 (1,1) 到 (x,y) 的累计分值
int smallSum(int x1, int y1, int x2, int y2) {
    return sum[x2][y2] - sum[x1-1][y2]
         - sum[x2][y1-1] + sum[x1-1][y1-1];
}
```

## 6. 切割回文（#backtracking）

**问题**（LeetCode 131）：将字符串切割成若干子串，使每个子串都是回文，求所有方案数。

**思路**：

- **纵向**：递归表示"从 start 开始继续切"
- **横向**：for 循环枚举切割点 i（子串 s[start..i]）

**回溯模板**：

```cpp
void calcString(string s, int start) {
    if (start >= s.size()) { result.push_back(path); return; }
    for (int i = start; i < s.size(); i++) {
        if (!isPalindrome(s, start, i)) continue;
        path.push_back(s.substr(start, i - start + 1));  // 做选择
        calcString(s, i + 1);                             // 递归
        path.pop_back();                                  // 撤销选择
    }
}
```

**样例 "aab"**：合法方案为 `(a, a, b)` 和 `(aa, b)` 两种。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "全排列 / 枚举所有顺序" | **选一个放首位 + 递归剩余**，O(n!) |
| "前缀表达式 / 波兰表达式" | **递归读子表达式** 或 **栈从右往左** |
| "汉诺塔 / 搬运问题" | **三分递归**：上(n−1) → 移最大 → 下(n−1) |
| "分配 / 划分 / 放肉饼" | **Allocate(m,n) = Allocate(m,n−1) + Allocate(m−n,n)** |
| "切割字符串 / 回文分割" | **回溯**：push → 递归 → pop |
| "递归 TLE / 重复子问题" | 加 **记忆化** 或转 **DP** |
| "递归转非递归" | 用 **栈** 模拟子问题展开 |

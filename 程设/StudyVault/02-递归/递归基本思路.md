# 递归基本思路（★★）

#algorithm #recursion #concept #divide-and-conquer #stack-simulation #permutation

## 概览表：递归三要素

| 要素 | 含义 | 示例（全排列） |
|------|------|----------------|
| **函数定义** | 明确 f(x) 的含义 | f(n) = n 个元素的全排列 |
| **递推关系** | f(x) = g(f(x-1)) | 固定 ai，对剩余 n-1 个元素递归求排列，再将 ai 插入各位置 |
| **终止条件** | f(0) 或最小规模 | n=1 时，排列就是元素本身 |

---

## 递归总体思想

将大问题分解为**规模更小、结构相同**的子问题：

1. **确定输入变量 x 的函数 f(x)** — 明确递归函数"算什么"
2. **寻找函数 g(x)，使得 f(x) = g(f(x-1))** — 建立当前规模与更小规模的关系
3. **确定 f(0)（基准情况）** — 递归出口，迭代/调用至最小规模即得 f(x)

**波兰表达式**示例：`exp()` 遇到运算符则递归求两个子表达式，遇到数字则直接返回 — 结构自相似。

---

## 递归 vs 循环

| 对比 | 递归 | 循环 |
|------|------|------|
| 适用场景 | 问题具有**自相似子结构** | 线性、迭代式过程 |
| 典型用途 | 全排列、汉诺塔、树遍历 | 简单计数、数组遍历 |
| 空间 | 函数调用栈 O(深度) | 通常 O(1) |
| 形象理解 | **纵向深入** — 一层层拆子问题 | **横向遍历** — 同一层枚举所有选择 |

> [!tip] 用递归代替多层嵌套循环
> **全排列**：n 层嵌套 for 难以写通用代码；递归固定一个元素，对 n-1 个元素递归，自然得到所有排列。

**切割回文**中的理解：
- **递归** = 纵向截取（确定前缀后，递归处理剩余串）
- **for 循环** = 横向遍历（枚举所有可能的前缀长度）

## 递归转非递归

### 使用栈模拟递归调用（汉诺塔为例）

递归版汉诺塔 `(n, src, tmp, dest)` 每次分解为三个子问题。非递归版将子问题**逆序入栈**，模拟调用栈的后进先出：

```cpp
struct Problem { int n; char src, tmp, dest; };
stack<Problem> stk;
stk.push(Problem(n, 'A', 'B', 'C'));

while (!stk.empty()) {
    Problem cur = stk.top(); stk.pop();
    if (cur.n == 1)
        cout << cur.src << "->" << cur.dest << endl;
    else {
        // 注意入栈顺序与递归调用顺序相反
        stk.push(Problem(cur.n-1, cur.tmp, cur.src, cur.dest));
        stk.push(Problem(1, cur.src, cur.tmp, cur.dest));
        stk.push(Problem(cur.n-1, cur.src, cur.dest, cur.tmp));
    }
}
```

### 使用队列做 BFS（层次遍历）

树的**层序遍历**天然适合队列：先访问根，再依次处理每一层节点 — 广度优先，与递归的深度优先相对。

## ASCII 图：递归调用树示意

以 `Hanoi(3, A, B, C)` 为例：

```
                    Hanoi(3,A,B,C)
                   /       |       \
                  /        |        \
         Hanoi(2,A,C,B)  A→C  Hanoi(2,B,A,C)
          /    |    \          /    |    \
    H(1,A,B,C) B→C H(1,C,A,B)  ...  ...  ...
      |              |
     A→B            C→B
```

- 向下：问题规模减小（n → n-1 → 1）
- 叶子节点（n=1）：直接输出移动，不再递归
- 返回：子问题完成后，当前层继续执行后续语句

**全排列**调用树：每层固定一个元素位置，分支数为剩余可选元素个数。

## 考试/测试常见模式

| 场景/关键词 | 解题思路 |
|-------------|----------|
| "全排列""组合" | 固定/选取一个元素，递归处理剩余；for 循环横向枚举 |
| "波兰/逆波兰表达式" | 遇运算符递归求子表达式；或用栈自底向上 |
| "汉诺塔" | 经典三分：`H(n-1,src,dest,tmp)` → 移动最大盘 → `H(n-1,tmp,src,dest)` |
| "递归转非递归" | 用栈保存 (参数, 状态)，逆序入栈模拟调用 |
| "树/图层次遍历" | BFS + 队列 |
| "f(n,x1,y1,x2,y2)" | 定义状态函数 + 终止条件 + 记忆化防重复 |

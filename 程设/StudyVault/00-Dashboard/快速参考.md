## 枚举法 → [[枚举法基础]]

| 概念 | 公式/要点 |
|------|----------|
| 枚举的内容 | 建立数学模型，明确需要枚举的要素（如猴子吃桃中枚举最后一只猴子拿走的份数 m） |
| 枚举的范围 | 缩小搜索空间，排除不可能的情况（如 n=1 时猴子吃桃需单独处理边界） |
| 枚举的顺序 | 按题目需求选择正向/逆向/从大到小（如求最大素数则从大到小枚举） |

## 递归 → [[递归基本思路]]

| 概念 | 公式/要点 |
|------|----------|
| 基本公式 | f(x) = g(f(x−1))，先确定 f(0) 边界，再迭代求 f(x) |
| 三要素 | 确定 f(x) → 找 g(x) 使 f(x)=g(f(x−1)) → 确定终止条件 f(0) |
| 典型模式 | 全排列：求 S/{ai} 的排列，再将 ai 插入各位置 |

## 动态规划 → [[DP基础与方法论]]

| 概念 | 公式/要点 |
|------|----------|
| 四步法 | ① 分解子问题 → ② 定义状态 → ③ 确定边界 → ④ 推导转移方程 |
| 最优子结构 | 问题的最优解包含的子问题解也必须是最优的 |
| 无后效性 | 当前状态确定后，后续演变只与当前状态值有关，与到达路径无关 |
| 反例 | LIS 中 F(n)=前 n 个元素的最长子序列长度 — 不满足无后效性；应改为「以 ak 为终点」 |

## DFS 与 BFS → [[DFS深度优先搜索]]、[[BFS广度优先搜索]]

| 对比项 | DFS（深度优先） | BFS（广度优先） |
|--------|----------------|----------------|
| 数据结构 | 栈 / 递归 | 队列 |
| 搜索策略 | 沿一条路径深入到底再回溯 | 按层扩展，先访问近处节点 |
| 最优解 | 不保证（需剪枝） | 无权图最短路保证最优 |
| 空间 | 递归深度 O(h) | 队列可能 O(V) |
| 典型场景 | 全排列、回溯、连通性 | 迷宫最短路、层序遍历 |
| 关键操作 | 进入时标记 + **回溯时撤销** | 入队时标记 + **判重** |

## GCD 辗转相除法 → [[枚举经典题型]]

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
// 互质判定：gcd(a, b) == 1
```

## 并查集模板 → [[并查集与连通性]]

```cpp
int find(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);  // 路径压缩
}
void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) fa[fy] = fx;   // 按秩合并更优
}
```

## 图算法关键步骤

### Dijkstra → [[最短路径]]

| 步骤 | 要点 |
|------|------|
| 1 | 初始化 dis[s]=0，其余为 ∞ |
| 2 | 每次选未访问且 dis 最小的点 u |
| 3 | 标记 u 已访问，松弛 u 的所有邻边 |
| 4 | 重复直到终点被访问或所有点确定 |
| 限制 | **不能处理负权边** |

### Prim → [[最小生成树]]

| 步骤 | 要点 |
|------|------|
| 1 | 任选起点加入生成树 |
| 2 | 维护各点到生成树的最小距离 |
| 3 | 每次选距离最小的未加入点 |
| 4 | 更新其邻点到生成树的距离 |
| 复杂度 | O(V²) 或 O(E log V)（堆优化） |

### Kruskal → [[最小生成树]]

| 步骤 | 要点 |
|------|------|
| 1 | 所有边按权值升序排序 |
| 2 | 依次选边，两端不在同一连通分量则加入 |
| 3 | 用并查集判断/合并连通性 |
| 4 | 选够 V−1 条边即完成 |

## 匈牙利算法 → [[二分图匹配]]

| 步骤 | 要点 |
|------|------|
| 1 | 对每个左部点 i，DFS 找增广路径 |
| 2 | 对右部点 j：若未匹配或 connect[j] 有增广路 |
| 3 | 找到则 connect[j]=i，匹配数 +1 |
| 4 | 每次 DFS 前重置 visited 数组 |
| 核心 | M-增广路径：交替出现在匹配内/外的路径 |

## 拓扑排序 → [[并查集与连通性]]

| 步骤 | 要点 |
|------|------|
| 1 | 统计各点入度 |
| 2 | 将入度为 0 的点入队 |
| 3 | 出队时将其邻点入度 −1，新入度为 0 则入队 |
| 4 | 出队数 < n → 有环（冲突）；出队时入度为 0 的点 >1 → 序不确定 |

## 常用复杂度对比

| 算法/操作 | 时间复杂度 | 空间复杂度 |
|-----------|-----------|-----------|
| 暴力枚举 | O(n!) ~ O(2ⁿ) | O(n) |
| 递归（无记忆化） | O(2ⁿ) 典型 | O(n) 栈深 |
| 记忆化 DP | O(状态数 × 转移) | O(状态数) |
| 递推 DP | O(状态数 × 转移) | O(状态数) 或 O(1) 滚动 |
| DFS/BFS | O(V + E) | O(V) |
| Dijkstra | O(V²) 或 O(E log V) | O(V) |
| Prim | O(V²) 或 O(E log V) | O(V) |
| Kruskal | O(E log E) | O(V) |
| 并查集 | 近似 O(α(n)) 均摊 | O(n) |
| 匈牙利 | O(V × E) | O(V) |

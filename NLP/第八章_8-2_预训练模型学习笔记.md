## 一、预训练的核心思想

### 1.1 什么是自监督学习？

自监督学习是**监督学习和无监督学习的结合**：

- **训练方式**：监督式的（有输入有标签）
- **训练数据**：由**无标注数据自动构建**（标签从数据本身产生）

典型的自监督任务：

| 任务 | 做法 | 代表模型 |
|------|------|---------|
| Language Modeling (LM) | 根据前文预测下一个词 | GPT 系列 |
| CBoW | 根据上下文预测中间词 | Word2Vec |
| Skip-Gram | 根据中间词预测上下文 | Word2Vec |
| GloVe | 基于共现矩阵分解 | GloVe |
| Masked LM (MLM) | 遮住某些词，预测被遮住的词 | BERT |
| Next Sentence Prediction (NSP) | 判断两个句子是否相邻 | BERT |
| Masked Span Prediction | 遮住一个连续片段，预测整个片段 | SpanBERT, T5 |

### 1.2 早期神经语言模型回顾

#### 前馈神经网络语言模型（Bengio et al., 2003）

```
输入：前 n-1 个词 → 查表得到词向量 → 拼接 → 多层前馈网络 → Softmax → 预测第 t 个词

x = (LT(w_{t-n+1}), ..., LT(w_{t-2}), LT(w_{t-1}))
p(wt | context) = Softmax(f(W3·f(W2·f(W1·x + b1) + b2) + b3))
```

- LT 是查找表（Look-up Table），即词嵌入矩阵
- 大量计算集中在 Softmax 层

#### 循环神经网络语言模型

```
ht = f(U·ht-1 + W·wt)
p(wj) = Softmax(ht)
```

通过反向传播更新参数 θ = {U, W, wt, ...}

### 1.3 早期模型的根本缺陷

**无法解决一词多义问题**！

例如 "bank" 这个词：
- "money in the **bank**" → 银行
- "the river **bank**" → 河岸
- "own blood **bank**" → 血库

传统词嵌入（Word2Vec、GloVe）给每个词**只有一个固定向量**，无法区分不同语义。

**解决方案**：上下文化词嵌入（Contextualized Word Embedding）——同一个词在不同上下文中有不同的表示。

## 二、ELMo：上下文化词嵌入的先驱

> Embeddings from Language Models (ELMo)
>
> Peters et al., NAACL 2018 **Best Paper**

### 2.1 核心思想

用**双向多层 RNN 语言模型**生成上下文化的词表示：

```
前向 RNN：<BOS> → 潮水 → 退了 → 就 → 知道 → ...
                ↓      ↓      ↓     ↓
反向 RNN：... → 知道 → 就 → 退了 → 潮水
                ↓      ↓     ↓      ↓
```

### 2.2 多层 RNN 结构

ELMo 使用**多层**双向 RNN，每层捕获不同粒度的信息：

- **底层**：更多捕获**语法信息**（词性、句法结构）
- **高层**：更多捕获**语义信息**（词义消歧、语义角色）

### 2.3 ELMo 向量的计算

ELMo 向量是各层表示的**加权和**：

```
ELMo = α1 · h1 + α2 · h2 + ...
```

其中权重 α1, α2, ... 是在**下游任务中学习**的（不同任务可能需要不同层的信息）。

### 2.4 ELMo 的局限

- 基于 RNN，**无法并行**，训练效率低
- 双向信息的融合比较浅（只是拼接前向和反向的隐藏状态）

## 三、基于 Transformer 编码器的预训练模型（BERT）

> Bidirectional Encoder Representations from Transformers (BERT)
>
> Devlin et al., NAACL 2019 **Best Paper**

### 3.1 预训练任务

#### 3.1.1 Masked Language Modeling (MLM)

BERT 的核心预训练任务：

```
输入：  "我 爱 [MASK] 语 处理"
目标：  预测 [MASK] 位置的词 → "自然"
```

具体做法：
1. 随机选择输入中 **15%** 的 token
2. 对于被选中的 token：
   - **80%** 的概率替换为 `[MASK]`
   - **10%** 的概率替换为**随机词**
   - **10%** 的概率**保持不变**
3. 模型需要预测这些位置的原始 token

**为什么不全用 [MASK]？** 因为在下游任务微调时，输入中不会有 [MASK] token。混合策略让模型更鲁棒。

**为什么用 Encoder（双向）而不是 Decoder（单向）？** MLM 需要**同时看到左右两侧的上下文**才能准确预测，这正是 Transformer Encoder（双向注意力）的优势。

#### 3.1.2 Next Sentence Prediction (NSP)

判断两个句子是否在原文中相邻：

```
输入：[CLS] 句子A [SEP] 句子B [SEP]
输出：IsNext / NotNext（二分类）
```

- 50% 正样本：B 确实是 A 的下一句
- 50% 负样本：B 是随机抽取的句子

**作用**：帮助模型理解句子间的关系，对问答、自然语言推理等任务有帮助。

#### 3.1.3 SpanBERT

改进版本：不再 mask 单个 token，而是 **mask 一个连续的 span（片段）**：

```
输入：  "自然语言处理是 [MASK][MASK][MASK] 的重要方向"
目标：  预测整个 span → "人工智能"
```

参考论文：Joshi et al., "SpanBERT: Improving Pre-training by Representing and Predicting Spans" (TACL 2020)

### 3.2 预训练 + 微调范式（Pre-train + Fine-tune）

```
┌──────────────────────────────────────────────────────────┐
│  阶段1：预训练                                            │
│                                                          │
│  大规模无标注文本 → Transformer → 预训练模型 (PTMs)         │
│  （维基百科、书籍等）     (MLM + NSP)                      │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  阶段2：微调                                              │
│                                                          │
│  预训练模型 → 迁移学习 → 下游任务数据 → 精调后的模型        │
│                         （少量标注数据）                    │
└──────────────────────────────────────────────────────────┘
```

### 3.3 BERT 在下游任务中的应用

BERT 通过简单的输入格式变化和少量任务特定层，可以适配多种 NLP 任务：

| 任务类型 | 输入格式 | 使用方式 |
|---------|---------|---------|
| **单句分类**（情感分析） | [CLS] 句子 [SEP] | 取 [CLS] 的输出 → 分类层 |
| **句对分类**（自然语言推理） | [CLS] 句子A [SEP] 句子B [SEP] | 取 [CLS] 的输出 → 分类层 |
| **问答** | [CLS] 问题 [SEP] 段落 [SEP] | 预测答案在段落中的起止位置 |
| **序列标注**（NER） | [CLS] token序列 [SEP] | 每个 token 的输出 → 标签分类 |

### 3.4 BERT 模型规模

| 模型 | 层数 | d_model | 注意力头数 | 参数量 |
|------|------|---------|-----------|-------|
| BERT-base | 12 | 768 | 12 | ~110M |
| BERT-large | 24 | 1,024 | 16 | ~340M |

### 3.5 GLUE Benchmark

General Language Understanding Evaluation (GLUE) 是 NLP 领域的综合评估基准，包含 9 个子任务：

| 任务 | 全称 | 类型 |
|------|------|------|
| CoLA | Corpus of Linguistic Acceptability | 语法可接受性判断 |
| SST-2 | Stanford Sentiment Treebank | 情感分类 |
| MRPC | Microsoft Research Paraphrase Corpus | 释义检测 |
| QQP | Quora Question Pairs | 问题对重复检测 |
| STS-B | Semantic Textual Similarity Benchmark | 语义相似度 |
| MNLI | Multi-Genre Natural Language Inference | 自然语言推理 |
| QNLI | Question-answering NLI | 问答推理 |
| RTE | Recognizing Textual Entailment | 文本蕴含 |
| WNLI | Winograd NLI | 代词消歧推理 |

BERT 在发布时在 GLUE 的多个任务上**大幅超越**了之前的最优方法。

## 四、基于 Transformer 的预训练 Seq2Seq 模型

### 4.1 T5：Text-to-Text Transfer Transformer

> Raffel et al., "Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer" (JMLR 2020)

#### 核心思想

**将所有 NLP 任务统一建模为文本到文本（Text-to-Text）格式**：

```
翻译：   "translate English to German: That is good" → "Das ist gut"
摘要：   "summarize: 一大段文本..." → "摘要文本"
分类：   "cola sentence: The course is jumping well" → "not acceptable"
问答：   "question: Who is the president? context: ..." → "Joe Biden"
```

不管什么任务，输入都是文本，输出也是文本。模型架构就是标准的 Encoder-Decoder Transformer。

#### 预训练任务

T5 使用 **Masked Span Prediction** 作为预训练任务：

```
原文：    "Thank you for inviting me to your party last week"
输入：    "Thank you <X> me to your party <Y> week"
目标输出：  "<X> for inviting <Y> last <Z>"
```

将连续的 token span 替换为特殊标记，模型需要生成被遮住的内容。

#### 模型规模

| 模型 | 层数 | d_model | d_ff | 注意力头 | 参数量 |
|------|------|---------|------|---------|-------|
| T5-small | 6 | 512 | 2,048 | 8 | ~60M |
| T5-base | 12 | 768 | 3,072 | 12 | ~220M |
| T5-large | 24 | 1,024 | 4,096 | 16 | ~770M |
| T5-3B | 24 | 1,024 | 16,384 | 32 | ~3B |
| T5-11B | 24 | 1,024 | 65,536 | 128 | ~11B |

### 4.2 BART：去噪序列到序列预训练

> Lewis et al., "BART: Denoising Sequence-to-Sequence Pre-training for Natural Language Generation, Translation, and Comprehension" (ACL 2020)

#### 核心思想

BART 的预训练本质是**去噪自编码器（Denoising Autoencoder）**：

```
原始文本 → 加噪声（document corruption）→ Encoder → Decoder → 重建原始文本
```

#### 噪声类型（corruption 方法）

| 噪声方法 | 说明 |
|---------|------|
| Token Masking | 随机 mask 若干 token（类似 BERT） |
| Token Deletion | 随机删除若干 token |
| Text Infilling | 用单个 [MASK] 替换一段文本（span 长度可变） |
| Sentence Permutation | 打乱句子顺序 |
| Document Rotation | 随机选一个 token 作为文档开头 |

#### 下游任务应用

- **序列分类**：将完整输入送入 Encoder 和 Decoder，取 Decoder 最后一个 token 的输出做分类（使用 masked attention）
- **机器翻译**：将 Encoder 的嵌入层替换为新的随机初始化 Encoder（处理源语言），BART 的 Encoder-Decoder 处理目标语言

## 五、基于 Transformer 解码器的预训练模型（GPT 系列）

### 5.1 GPT 的预训练：自回归语言模型

GPT（Generative Pre-Training）使用 **Transformer Decoder**，通过**自回归语言建模**预训练：

```
输入：  <BOS> 潮水 退了 就
目标：  潮水 退了 就 知道

每一步根据前面的所有词预测下一个词：
  P(潮水 | <BOS>)
  P(退了 | <BOS>, 潮水)
  P(就 | <BOS>, 潮水, 退了)
  P(知道 | <BOS>, 潮水, 退了, 就)
```

使用 **Masked Self-Attention**（因果注意力），确保每个位置只能看到之前的位置。

### 5.2 GPT 的三个阶段演进

| 模型 | 参数量 | 关键特点 |
|------|-------|---------|
| GPT-1 | ~117M | 首次提出预训练+微调范式 |
| GPT-2 | ~1.5B | 更大模型 + 零样本学习能力 |
| GPT-3 | **175B** | 大规模涌现能力 + In-context Learning |

GPT-3 比 BERT-large (340M) 大了 **500 倍**。

### 5.3 GPT 的微调与使用范式演变

#### GPT-1/2 时代：预训练 + 微调

```
大量无标注文本 → 预训练 → 通用语言模型
                              ↓
                任务数据（少量标注） → 微调 → 任务专用模型
```

#### GPT-3 时代：In-context Learning（上下文学习）

GPT-3 的突破在于**不再需要微调**！通过在输入中提供少量示例，模型就能完成新任务：

| 学习方式 | 说明 | 示例 |
|---------|------|------|
| **Zero-shot** | 只给任务描述，不给示例 | "Translate to French: cheese →" |
| **One-shot** | 给一个示例 | "sea otter → loutre de mer. cheese →" |
| **Few-shot** | 给几个示例 | "sea otter → loutre de mer. peppermint → menthe poivrée. cheese →" |

**关键点**：Few-shot Learning **不需要梯度更新**，模型参数不变，完全通过「理解」提示来完成任务。

#### In-context Learning 在阅读理解上的应用

以 CoQA 数据集为例：

```
输入格式：d1, d2, ..., dN,      ← N 个文档-问答示例
         "Q:", q1, q2, ..., qN,  ← 问题
         "A:"                     ← 模型接着生成答案
```

### 5.4 从 GPT-3 到 ChatGPT：RLHF

ChatGPT 的训练过程（与 InstructGPT 类似）采用了**人类反馈强化学习（RLHF）**：

#### 三阶段训练过程

```
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│  阶段1：有监督微调 (SFT)                                        │
│  ┌─────────────┐                                               │
│  │ 基础大模型    │ + 标注人员构造的(指令, 回答)数据                  │
│  │ (预训练)     │ → 有监督微调大模型                               │
│  └─────────────┘                                               │
│  数据规模：~十万条用户指令                                        │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  阶段2：训练奖励模型 (Reward Model)                               │
│  ┌─────────────┐                                               │
│  │ 同一个问题    │ → 模型生成多个回答(A,B,C,D)                     │
│  │             │ → 标注人员排序(如 C>A>B=D)                       │
│  │             │ → 训练奖励函数                                  │
│  └─────────────┘                                               │
│  数据规模：~百万条用户指令                                        │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  阶段3：强化学习优化 (PPO)                                       │
│  ┌─────────────┐                                               │
│  │ 用户指令     │ → 大模型生成回答 → 奖励函数打分(rk)              │
│  │             │ → 基于奖励信号更新模型参数                        │
│  └─────────────┘                                               │
│  数据规模：~十万条用户指令                                        │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

**核心思想**：

1. **SFT**：让模型学会按照指令格式回答（能力注入）
2. **奖励模型**：将人类偏好「编码」成一个打分函数
3. **PPO**：让模型生成的回答获得更高的人类偏好分数

### 5.5 GPT-4

GPT-4 是 OpenAI 发布的多模态大模型，支持文本和图像输入，在各种基准测试上大幅领先前代。

## 七、大语言模型的能力与边界

### 7.1 LLM 擅长什么（记忆能力）

| 能力 | 说明 |
|------|------|
| 存储与检索 | 能够存储和检索大量事实知识 |
| 模式识别 | 能够识别训练数据中的统计模式 |
| 上下文关联 | 能够关联相似上下文中的信息 |
| 语言生成 | 能够生成流畅、连贯的文本 |

应用举例：文本摘要、辅助写作、辅助诊疗、起草方案、理论解释

### 7.2 LLM 不擅长什么（理解能力）

| 局限 | 说明 |
|------|------|
| 因果推理 | 难以进行真正的因果关系推理 |
| 抽象思维 | 难以形成抽象概念和原理 |
| 逻辑一致性 | 难以保持复杂推理中的逻辑一致 |
| 知识迁移 | 难以将知识迁移到全新领域 |

### 7.3 知识利用层次图

```
层次5：推理（基于已知推导未知）          ← 最难，目前表现差
层次4：逆向搜索（根据属性找实体）        ← 较难
层次3：比较（对比不同知识）              ← 中等
层次2：分类（判断知识属性）              ← 较易
层次1：记忆（存储和检索事实知识）          ← 目前主要停留在这里
```

**核心结论**：目前大模型主要停留在**记忆层次**，在深层理解和推理方面仍有明显局限。

### 7.4 能力边界实证

- **高考数学**：最好约 70%，最差约 25%，填空题成绩更差
- **逻辑推理**：基准数据集效果较好，分布外数据集表现差
- **规划能力**：在 PlanBench 上表现不佳（如积木世界问题）

## 八、基于 Transformer 的文本-视觉预训练模型

### 8.1 预训练数据

文本-视觉预训练使用**图文对**数据，如：(图片, "man with his dog on a couch")

### 8.2 预训练任务（以 UNITER 为例）

> Chen et al., "UNITER: Universal Image-Text Representation Learning" (ECCV 2020)

#### 8.2.1 Masked Language Modeling (MLM)

和 BERT 一样，遮住文本中的词，但模型可以利用**图像信息**辅助预测：

```
图像区域：[狗的图片] [人的图片] [沙发的图片]
文本输入：man with his [MASK] ...
预测目标：dog
```

#### 8.2.2 Masked Region Modeling (MRM)

遮住图像中的某些区域，预测被遮住的区域信息：

```
图像区域：[被遮住的区域] [人的图片] [沙发的图片]
文本输入：man with his dog ...
预测目标：被遮住区域的特征/类别
```

MRM 有三种变体：
- **MRFR**（Masked Region Feature Regression）：回归区域特征向量
- **MRC**（Masked Region Classification）：分类区域所属类别
- **MRC-kl**（MRC with KL Divergence）：用 KL 散度匹配预测和真实分布

#### 8.2.3 Image-Text Matching (ITM)

判断图片和文本是否**匹配**（二分类）：

```
输入：[CLS] + 图像区域 + 文本 tokens
输出：0（不匹配）或 1（匹配）
```

### 8.3 CLIP：图文对比学习

> Radford et al., "Learning Transferable Visual Models From Natural Language Supervision" (ICML 2021)

CLIP 的核心是**对比学习**：

```
     图像编码器              文本编码器
        ↓                      ↓
    图像特征 ─────对比───── 文本特征
```

训练目标：
- 匹配的图文对 → 相似度**最大化**
- 不匹配的图文对 → 相似度**最小化**

CLIP 的强大之处：训练后可以做**零样本图像分类**（不需要任何标注数据微调）。

### 8.4 多模态大模型

#### 三类范式

| 范式 | 特点 | 代表模型 |
|------|------|---------|
| **多模态大语言模型** | 以 LLM 为基座，对齐其他模态到语言空间 | BLIP-2, LLaVA |
| **多任务多模态大模型** | 单一架构，多个跨模态任务同时训练 | SAM, BEiT-3 |
| **特定任务多模态大模型** | 面向检索/生成等特定任务 | CLIP, DALL-E, Stable Diffusion |

| 对比维度 | 多模态LLM | 多任务多模态 | 特定任务多模态 |
|---------|----------|------------|--------------|
| 数据类型 | 自监督+有监督，数据量大 | 多为监督数据 | 训练任务单一 |
| 参数规模 | 百亿~千亿 | 十亿级 | 千万~亿级 |
| 通用能力 | 强 | 弱 | 下游任务受限 |

## 九、全景图：预训练模型分类总结

```
                        Transformer 预训练模型
                    ┌───────────┼───────────┐
                    ↓           ↓           ↓
              Encoder-only   Encoder-       Decoder-only
              (双向注意力)    Decoder        (因果注意力)
                    │         (交叉注意力)        │
                    ↓           ↓                ↓
                  BERT        T5, BART         GPT 系列
                SpanBERT                     ChatGPT, GPT-4
                    │           │                │
                    ↓           ↓                ↓
               理解类任务     生成+理解        生成类任务
              (分类、NER     (翻译、摘要      (对话、写作
               问答等)        问答等)         代码生成等)
```

### 三种架构对比

| 架构 | 注意力类型 | 预训练任务 | 典型应用 | 代表模型 |
|------|-----------|-----------|---------|---------|
| Encoder-only | 双向 | MLM, NSP | 分类、NER、问答 | BERT |
| Encoder-Decoder | 双向+因果 | Span Corruption | 翻译、摘要 | T5, BART |
| Decoder-only | 因果（单向） | 自回归 LM | 文本生成、对话 | GPT, ChatGPT |

## 十、核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| 自监督学习 | 用无标注数据自动构建监督信号 |
| MLM | 遮住部分词，预测被遮住的词（BERT 核心） |
| NSP | 判断两句话是否相邻（BERT 辅助任务） |
| 上下文化词嵌入 | 同一个词在不同上下文中有不同向量表示 |
| 预训练+微调 | 先在大数据上学通用知识，再在小数据上适配具体任务 |
| In-context Learning | 通过提示中的示例让模型完成任务，无需更新参数 |
| RLHF | 用人类反馈训练奖励模型，再用强化学习优化生成质量 |
| CLIP | 通过对比学习对齐图像和文本的表示空间 |

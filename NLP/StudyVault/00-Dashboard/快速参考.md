## 第3章 文本分类 → [[core-concepts]] §1 ⭐⭐⭐

| 概念 | 核心公式/要点 |
|------|---------------|
| TF-IDF | $\text{tf\_idf}_i = tf_i \cdot \log(N/df_i)$ |
| 信息增益 | $IG(t_i) = H(C) - H(C\|T_i)$ |
| NB决策 | $c^* = \arg\max_j P(c_j)\prod_i P(w_i\|c_j)^{N(w_i)}$ |
| NB条件概率(平滑) | $P(w_i\|c_j) = \frac{1+N(w_i,c_j)}{M+\sum N(w_{i'},c_j)}$ |
| Precision | $P_i = TP_i/(TP_i+FP_i)$ |
| Recall | $R_i = TP_i/(TP_i+FN_i)$ |
| F1 | $F_1 = 2PR/(P+R)$ |
| Macro | 各类P/R/F1取平均 |
| Micro | 先合并TP/FP/FN再算 |

## 第4章 语言模型 → [[core-concepts]] §2

| 概念 | 核心公式/要点 |
|------|---------------|
| N-gram MLE | $p(w_i\|w_{i-n+1}^{i-1}) = c(w_{i-n+1}^i) / \sum c(w_{i-n+1}^i)$ |
| 加1平滑 | $p(w_i\|w_{i-1}) = (1+c(w_{i-1}w_i))/(|V|+\sum c(w_{i-1}w_i))$ |

| 概念 | 核心公式/要点 |

## 第8章 Transformer与预训练 → [[自注意力机制]]、[[Transformer架构]]、[[ELMo与BERT]]、[[T5_BART与GPT系列]]

| 概念 | 核心公式/要点 |
|------|---------------|
| Self-Attention | $Q=W^qI$, $K=W^kI$, $V=W^vI$ |
| 注意力输出 | $O=V\cdot\text{softmax}(K^\top Q/\sqrt{d_k})$ |

## BLEU（机器翻译评估）⭐⭐⭐

| 概念 | 核心公式/要点 |
|------|---------------|
| BLEU | $\text{BLEU} = BP \cdot \exp(\sum w_n \log p_n)$ |
| $p_n$ | n-gram精确率（候选中匹配参考的比例，需clip） |
| $w_n$ | 通常 $1/N$，$N=4$ |
| BP | $c \leq r$时 $\exp(1-r/c)$；$c>r$时 $1$ |

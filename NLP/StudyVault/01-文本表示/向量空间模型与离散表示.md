# 向量空间模型与离散表示（★★）

#text-representation #vsm #one-hot #distributed-repr #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 向量空间模型 | 文本表示为特征项加权向量 (t₁:w₁, t₂:w₂, ..., tₙ:wₙ) |
| 提出者 | G. Salton 等人，1960s末期，信息检索领域 |
| 离散符号表示 | One-hot表示，每个词对应唯一下标的高维稀疏向量 |
| 核心问题 | 任意两个词的相似度都为0，无法表示语义关系 |
| 解决方案 | 分布式表示：低维、稠密的连续实数空间 |

## 向量空间模型 (VSM)

- **核心思想**：将文本视为特征项的集合
- **特征项**：VSM中最小的语言单元（字、词、短语等）
- **文本表示**：(t₁, t₂, ..., tₙ) 或加权形式 (t₁:w₁, t₂:w₂, ..., tₙ:wₙ)
- **特征项权重**：反映每个特征项在文本中的重要性

> [!tip] 权重确定方法
> 常用方法包括：布尔权重（0/1）、词频（TF）、TF-IDF 等

## 离散符号表示及其问题

- **One-hot 表示法**：每个词用一个 V 维向量表示，仅对应位置为1，其余为0
- **词表规模** V 决定了向量维度

> [!important] 核心缺陷
> One-hot向量之间的内积（点积）恒为0：
> - 任意两个不同词的相似度 = 0
> - 无法捕捉词语间的语义关系（如"枯燥"与"无聊"）

## 分布式表示

- 使用**低维、稠密的连续实数向量**表示词语
- 语义相似的词在向量空间中距离接近
- 向量维度远小于词表规模（几十到几百 vs 几万到几十万）

# 短语与句子表示学习（★★）

#text-representation #phrase-repr #sentence-repr #document-repr #concept

## 概览表（一目了然）
| 粒度 | 方法 | 特点 |
|------|------|------|
| 短语 | 词袋平均 | 简单但忽略词序("猫吃鱼"="鱼吃猫") |
| 短语 | 递归自动编码器(RAE) | 基于二叉树结构递归编码 |
| 短语 | 双语约束(BRAE) | 翻译对齐，语义误差+重构误差 |
| 句子 | PV-DM | CBOW扩展，加入句子ID作为记忆 |
| 句子 | PV-DBOW | Skip-Gram扩展，句子预测句中词 |
| 句子 | Skip-Thought | 用当前句预测前后句 |
| 句子 | CNN | 卷积+池化提取全局特征 |
| 文档 | 层次化模型 | 词→句→文档的分层表示 |

## 短语表示学习

### 词袋方法
- 简单平均：e(phᵢ) = (1/i) × Σ e(wₖ)
- 加权平均：e(phᵢ) = Σ vₖ · e(wₖ)

> [!warning] 词袋方法致命缺陷
> "猫吃鱼" 和 "鱼吃猫" 得到相同表示！

### 递归自动编码器 (RAE)
- 两个相邻向量通过编码函数合并：x₁₂ = f(W⁽¹⁾[x₁;x₂] + b⁽¹⁾)
- 解码器重构：[x'₁;x'₂] = f(W⁽²⁾x₁₂ + b⁽²⁾)
- 目标：最小化所有二叉树结构的重构误差

### 双语约束模型 (BRAE)
- 利用翻译对提供跨语言语义监督
- 损失 = α·重构误差 + (1-α)·语义误差
- 语义误差：平行短语的向量距离最小化

## 句子表示学习

### PV-DM (Paragraph Vector - Distributed Memory)
- CBOW扩展：将**句子ID**也作为输入
- h = (1/(2C+1)) × (e(SenId) + Σ e(wₖ))
- 句子向量矩阵 $PV \in \mathbb{R}^{M \times p}$

### PV-DBOW (Distributed Bag-of-Words)
- Skip-Gram扩展：句子 → 句中随机词
- 不使用上下文词，只用句子ID预测

### Skip-Thought
- 用当前句 sₖ 预测前句 sₖ₋₁ 和后句 sₖ₊₁
- 基于 Encoder-Decoder 架构
- 假设连续句子表达相近语义

### CNN模型
- 词向量 → 卷积(局部特征) → 池化(全局) → 句子向量

## 文档表示学习

### 层次化模型
- 词级：CNN/LSTM 得到句子表示 eₛᵢ
- 句级：BiLSTM 得到文档表示 e_D = Σ vᵢ·hᵢ
- 加入注意力机制确定每句权重

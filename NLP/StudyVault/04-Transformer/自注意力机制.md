| 条目 | 要点 |

## 动机：从 RNN/CNN 到 Self-Attention

序列建模长期依赖 RNN 和 CNN，但两者各有明显瓶颈：

| 架构 | 优势 | 局限 |
|------|------|------|
| **RNN/SRNN** | 逐步建模序列，天然处理变长输入 | 时间步**串行计算**，无法充分并行；长程依赖受梯度问题制约 |
| **CNN** | 局部卷积可并行，捕获 n-gram 模式 | 感受野有限，需堆叠多层才能扩大上下文，**仍偏局部** |
| **Self-Attention** | 任意两位置**直接交互**，单层即可建模全局依赖；矩阵运算**高度并行** | 计算复杂度 O(n²)；本身不编码位置信息 |

```
RNN:  x₁ → x₂ → x₃ → x₄   (串行，h 逐步传递)
CNN:  [局部窗口] → [局部窗口] → ...  (堆叠扩大感受野)
SA:   每个 token 与所有 token 直接计算关联  (并行矩阵运算)
```

> [!important] 核心思想
> Self-Attention 让序列中**每个位置**通过注意力权重，直接从**所有位置**聚合信息，一步建立全局依赖关系。

---

## Self-Attention 核心：Query、Key、Value

给定输入序列的表示矩阵 **I**（每行/列对应一个 token 的 d 维向量），通过三个可学习投影矩阵生成 Q、K、V：

$Q = W^q I$  
$K = W^k I$  
$V = W^v I$

| 符号 | 含义 | 直觉 |
|------|------|------|
| **Q (Query)** | "我在找什么信息？" | 当前位置发出的查询 |
| **K (Key)** | "我能提供什么信息？" | 各位置用于被匹配的索引 |
| **V (Value)** | "我的实际内容是什么？" | 被加权聚合的信息载体 |

> [!tip] 类比
> Q 像搜索关键词，K 像文档标题/索引，V 像文档正文；匹配度由 Q 与 K 的相似度决定，最终按匹配度对 V 加权求和。

---

## 注意力矩阵与输出

### 基本步骤

1. **计算关联分数**：**A = KᵀQ**（维度：序列长度 × 序列长度）
2. **归一化为权重**：**A' = softmax(A)**（按列或按行 softmax，实现中通常对最后一维）
3. **加权聚合 Value**：**O = V · A'**

```
I ──W^q──→ Q ─┐
I ──W^k──→ K ─┼→ A = KᵀQ → softmax → A' ──→ O = V·A'
I ──W^v──→ V ─┘
```

注意力矩阵 **A** 的第 (i, j) 元素表示：位置 i 的 Query 与位置 j 的 Key 的匹配程度。

---

## 缩放点积注意力（Scaled Dot-Product Attention）

当 Key 维度 **dₖ** 较大时，点积 **KᵀQ** 的数值方差会增大，导致 softmax 进入极端区域（梯度很小）。因此引入缩放因子：

**Attention(Q, K, V) = softmax(KᵀQ / √dₖ) · V**

| 组件 | 作用 |
|------|------|
| **KᵀQ** | 点积相似度，衡量 Query-Key 匹配 |
| **/ √dₖ** | 缩放，稳定 softmax 输入分布 |
| **softmax** | 转为概率权重（和为 1） |
| **· V** | 按权重对 Value 加权求和 |

> [!warning] 常见混淆
> 缩放因子是 **√dₖ**（Key 的维度），不是 dₖ 或 √d_model。考试常考此细节。

---

## 多头注意力（Multi-Head Attention）

单一注意力头只在一个子空间中建模关联。多头机制将 Q/K/V **投影到 h 个不同子空间**，分别计算注意力后再融合：

对每个头 j（j = 1, …, h）：

- $q_{i,j} = W^{q,j} q_i$
- $k_{i,j} = W^{k,j} k_i$
- $v_{i,j} = W^{v,j} v_i$
- **headⱼ = Attention(Qⱼ, Kⱼ, Vⱼ)**

拼接所有头并线性投影：

$b_i = W^O \cdot \text{concat}(b_{i,1}, b_{i,2}, \ldots, b_{i,h})$

```
        ┌─ Head 1: Attn(Q₁,K₁,V₁) ─┐
Q,K,V ──┼─ Head 2: Attn(Q₂,K₂,V₂) ─┼→ Concat → W^O → 输出
        └─ Head h: Attn(Qₕ,Kₕ,Vₕ) ─┘
```

| 设计目的 | 说明 |
|----------|------|
| **多子空间** | 不同头可关注不同关系（语法、共指、语义等） |
| **低维 per-head** | 每头维度 dₖ = d_model / h，总计算量可控 |
| $W^O$ 融合 | 将多头信息整合回 d_model 维 |

## 位置编码（Positional Encoding）

Self-Attention 对输入做**集合式**处理：打乱 token 顺序，若不加位置信息，输出不变（**置换等变/不变**）。因此必须注入位置信号 **eᵢ**。

常见两种方式：

| 方式 | 做法 | 特点 |
|------|------|------|
| **固定正弦编码** | 用 sin/cos 函数构造 eᵢ，按维度交替 | 原论文方案，可外推一定长度 |
| **可学习编码** | eᵢ 作为参数矩阵直接学习 | BERT 等模型常用，灵活但受训练长度限制 |

实际输入为：**xᵢ = token_embedding(i) + positional_encoding(i)**

```
无位置编码:  [我 爱 NLP] ≡ [NLP 爱 我]  (对 SA 而言)
有位置编码:  每个 token = 词向量 + 位置向量 eᵢ
```

> [!important] 为什么需要
> 语言中**词序**承载语法和语义（如"狗咬人" vs "人咬狗"），Self-Attention 本身无法区分顺序，位置编码是必要补充。

## 课堂练习：手算 Self-Attention

**题目设定**：给定输入 **I**、投影矩阵 $W^q$, $W^k$, $W^v$，求注意力输出。

**解题步骤**：

1. 计算 $Q = W^q I$, $K = W^k I$, $V = W^v I$
2. 计算分数矩阵 **S = KᵀQ / √dₖ**
3. 对 S 每列（或指定维度）做 **softmax** 得 **A'**
4. 输出 **O = V A'**

**示例（简化 2×2）**：

设 dₖ=2，某步得到：

```
KᵀQ = [[2, 1],
       [1, 3]]

softmax 按列:
A' = [[0.73, 0.27],
      [0.27, 0.73]]   (近似值)

O = V · A'  →  每列是对 V 的加权组合
```

> [!tip] 手算技巧
> 先算 **KᵀQ**，注意 softmax 的**归一化维度**（通常对 Query 所在维度）；再矩阵乘 **V**。维度对齐是常见失分点。

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "Self-Attention 动机" | RNN 难并行；CNN 局部感受野 → 全局依赖 + 并行 |
| "Q/K/V 公式" | $Q=W^q I$, $K=W^k I$, $V=W^v I$ |
| "缩放点积公式" | softmax(KᵀQ/√dₖ)V |
| "为何除以 √dₖ" | 防止 dₖ 大时点积过大，softmax 梯度消失 |
| "多头注意力目的" | 多子空间捕获不同关系，concat 后 $W^O$ 融合 |
| "位置编码原因" | SA 置换不变，必须注入顺序信息 |
| "注意力矩阵含义" | A[i,j] = 位置 i 对位置 j 的注意力权重 |

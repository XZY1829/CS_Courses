## 动机

### 人脑注意力

人类在处理信息时不会均等对待所有输入，而是**选择性关注**与当前任务最相关的部分——这就是注意力的生物学灵感。

### 信息超载问题

在 Encoder-Decoder 架构中，Encoder 将整个输入序列压缩为**单一固定长度向量**，存在严重瓶颈：

- 长序列信息丢失
- 解码每个词时无法"回看"输入的不同部分
- 翻译、问答等任务需要**动态对齐**输入与输出

**注意力机制**允许模型在每一步**动态地、软性地**关注输入的不同位置。

```
无注意力 vs 有注意力:
无: Encoder → [固定向量 c] → Decoder (所有解码步共享同一 c)
有: Encoder → [h₁,h₂,...,hₙ] → Decoder 每步动态加权关注不同 hᵢ
```

## 软性注意力机制（Soft Attention）

**#soft-attention** 通过可微的加权平均实现，两步完成：

### 步骤 1：计算注意力分布

**αₙ = softmax(s(xₙ, q))**

- **X = {x₁, ..., xₙ}**：输入序列（如 Encoder 各时刻隐状态）
- **q**：查询向量（Query，如 Decoder 当前状态）
- **s(·, ·)**：#scoring-function（打分函数）
- **αₙ**：第 n 个位置的注意力权重，Σαₙ = 1

### 步骤 2：加权求和得到上下文向量

$\text{att}(X, q) = \sum_{n=1}^{N} \alpha_n \cdot x_n$

```
Soft Attention 流程:
x₁ x₂ x₃ x₄  ──→ s(·,q) ──→ [0.1, 0.6, 0.2, 0.1] ──→ softmax ──→ α
                                                              ↓
q (query) ─────────────────────────────────────────→ att = Σ αₙxₙ
```

## 四种打分函数

| 类型 | 公式 | 标签 | 特点 |
|------|------|------|------|
| **加性注意力** | s(x, q) = **vᵀ tanh(Wx + b)** | #additive-attention | 通用，维度不同时可用 |
| **点积注意力** | s(x, q) = **xᵀq** | #dot-product-attention | 无参数，计算快 |
| **缩放点积** | s(x, q) = **xᵀq / √D** | #scaled-dot-product | 防止 D 大时点积过大；Transformer 采用 |
| **双线性注意力** | s(x, q) = **xᵀWq** | — | 学习 x 与 q 的交互矩阵 |

> [!important] 缩放点积的必要性
> 当向量维度 D 较大时，xᵀq 的方差随 D 增大，softmax 进入饱和区、梯度消失。#scaled-dot-product 除以 √D 稳定方差。

## 注意力应用

### 句子分类（Self-Attention for Pooling）

- 用**自身**作为 query：q = 可学习向量或序列表示
- 对词级隐状态加权池化，替代简单的最后隐状态或 max pooling
- 自动聚焦关键词（如情感词、否定词）

### 文档分类（Hierarchical Attention Network, HAN）

```
HAN 两层注意力:
词级: 每个句子内 → 词注意力 → 句子向量
句级: 文档内     → 句注意力 → 文档向量 → 分类
```

### 机器翻译（Encoder-Decoder Attention）

- Encoder 输出 **{h₁, ..., hₘ}** 作为 attention 的 key/value
- Decoder 每步生成时，用当前隐状态作 query
- 实现**源-目标动态对齐**（如翻译时对齐对应词）

## 序列标注应用

**#seq-labeling** 任务中，BiLSTM + CRF 是经典基线；加入注意力可强化关键上下文：

| 任务 | 说明 | 注意力作用 |
|------|------|------------|
| **CWS（中文分词）** | 字级标注 B/M/E/S | 关注构词边界上下文 |
| **POS（词性标注）** | 为每个词分配词性 | 关注歧义消解线索 |
| **NER（命名实体识别）** | 识别 PER/ORG/LOC 等 | 关注实体边界与类型线索 |

### NER 标注方案

常用 **BIO / BIOES** 标注体系：
- **B**-TAG：实体开始
- **I**-TAG：实体内部
- **O**：非实体

### NER 评估指标

在**实体级别**评估（非 token 级别）：

| 指标 | 定义 |
|------|------|
| **Precision** | 预测实体中正确的比例 |
| **Recall** | 真实实体中被找到的比例 |
| **F1** | 2PR / (P + R) |

> [!warning] 精确匹配要求
> NER 的"正确"要求**边界完全匹配**且**类型完全匹配**。多一个或少一个 token 都算错误。

## 机器阅读理解应用

**#reading-comprehension**：给定段落 P 和问题 Q，从 P 中抽取/定位答案。

| 模型 | 核心思想 |
|------|----------|
| **Match-LSTM** | 问题与段落逐词匹配，BiLSTM 编码 |
| **BiDAF** | 双向注意力流：query-to-context + context-to-query |
| **R-Net** | 自匹配 + 指针网络，多层 attention 精炼表示 |

### SQuAD 评估指标

**SQuAD**（Stanford Question Answering Dataset）是英文阅读理解标准 benchmark：

| 指标 | 定义 |
|------|------|
| **Exact Match (EM)** | 预测答案与标准答案**字符串完全一致**的比例 |
| **F1** | 预测与标准答案 token 集合的 F1（部分匹配也给分） |

```
SQuAD 评估示例:
标准答案: "the American Civil War"
预测1: "the American Civil War"  → EM=1, F1=1.0
预测2: "American Civil War"        → EM=0, F1=0.857 (缺 the)
预测3: "Civil War"                 → EM=0, F1=0.667
```

> [!tip] EM vs F1
> EM 更严格（完全匹配）；F1 允许部分重叠，更能反映"接近正确"的预测。

## 卷积层（Convolution Layer）

卷积层是 CNN 的核心构建块，通过多个**卷积核（Filter）**并行扫描输入，生成多张**特征映射（Feature Map）**。

**单个特征映射的计算**：

- **Z_p = W_p ⊗ X + b_p**（⊗ 表示卷积运算，b_p 为偏置）
- **Y_p = f(Z_p)**（f 为激活函数，常用 ReLU）

其中：
- **X**：输入（单通道或多通道特征图）
- **W_p**：第 p 个卷积核的权重
- **Y_p**：第 p 个特征映射

```
卷积层数据流:
输入 X (C_in 通道)
    │
    ├─ 核 W₁ → Z₁ = W₁⊗X+b₁ → ReLU → Y₁ (特征图 1)
    ├─ 核 W₂ → Z₂ = W₂⊗X+b₂ → ReLU → Y₂ (特征图 2)
    └─ 核 W_P → ...              → Y_P (特征图 P)
输出: P 个特征映射 (C_out = P)
```

> [!important] 多核的意义
> 不同卷积核学习不同的局部模式（如边缘、n-gram 短语等），**核的数量 = 输出通道数**。

---

## 汇聚层（Pooling Layer）

汇聚层（池化层）对特征映射进行**下采样**，主要作用：

1. **降维**：减少后续层参数量与计算量
2. **提取重要特征**：保留局部区域内最显著或代表性的响应
3. **增强平移不变性**：对小范围位置偏移更鲁棒

### 最大汇聚 vs 平均汇聚

| 类型 | 操作 | 特点 | 标签 |
|------|------|------|------|
| **最大汇聚** Max Pooling | 窗口内取最大值 | 保留最强激活，常用于 TextCNN | #max-pooling |
| **平均汇聚** Average Pooling | 窗口内取平均值 | 更平滑，保留整体趋势 | #avg-pooling |

```
Max Pooling (窗口=2, stride=2):
特征图: [1, 3, 2, 4]
         [5, 6, 1, 2]
池化后: [6, 4]   (每 2×2 窗口取 max)
```

> [!warning] 池化层无可学习参数
> 池化仅做固定聚合运算，不包含权重；与卷积层的参数学习不同。

## 典型 CNN 结构

经典 CNN 由以下部分组成：

```
输入
  ↓
[Conv → Activation → Pool] × b   ← 交叉堆叠 b 次
  ↓
[Conv → Activation] × (M−b)      ← 剩余卷积层
  ↓
Flatten / Global Pooling
  ↓
全连接层 (FC)
  ↓
Softmax / 分类输出
```

**结构要点**：
- **M 个卷积层 + b 个汇聚层**：卷积与池化**交叉堆叠**（Conv-Pool-Conv-Pool…）
- 浅层捕获低级特征，深层组合为高级语义
- 末端接**全连接层**完成分类或回归

## 设计趋势

### 小卷积、大深度（Small Filter, Deep Network）

- 使用 **3×3**（或 1D 中 K=3）等小核替代大核（如 5×5、7×7）
- 堆叠更多层以扩大**有效感受野**，同时参数量更少
- 代表：VGG 系列思想

### 全卷积（Fully Convolutional）

- 将传统全连接层替换为 **1×1 卷积**
- 优势：任意输入尺寸、参数共享、便于密集预测（分割、序列标注）
- 文本任务中 Global Max Pooling + 线性层也属常见变体

```
趋势对比:
┌────────────────┬─────────────────┬─────────────────┐
│                │  传统大核浅层   │  小核深层       │
├────────────────┼─────────────────┼─────────────────┤
│ 核大小         │ 5×5, 7×7        │ 3×3, 1×1        │
│ 层数           │ 较少            │ 较多            │
│ 参数量         │ 单层多          │ 单层少、总计可控│
│ 感受野         │ 单层大          │ 多层累积        │
└────────────────┴─────────────────┴─────────────────┘
```

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "卷积层公式" | Z_p = W_p⊗X + b_p，Y_p = f(Z_p) |
| "特征映射数量" | 等于卷积核个数（out_channels） |
| "池化层作用" | 降维、提取重要特征、增强平移不变性 |
| "Max vs Avg Pooling" | Max 取最大激活；Avg 取平均 |
| "典型 CNN 堆叠" | Conv 与 Pool 交叉 → FC 分类 |
| "小卷积大深度" | 3×3 小核 + 更深网络，扩大感受野 |
| "池化层有无参数" | 无（固定运算） |

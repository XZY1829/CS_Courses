# 文本卷积神经网络（★★★）

#nlp-deep-learning #cnn #textcnn #sentiment-classification #nli #feature-map #concept

## 概览表（一目了然）
| 条目 | 要点 |
|------|------|
| 核心思想 | 用卷积核滑动窗口提取 **N-gram 级局部特征**，类似可学习的 n-gram 检测器 |
| Kim (2014) | 词向量矩阵 → 多尺度 Conv1d → Max-pooling → 全连接分类 |
| 特征公式 | yᵢᵗ = Fₜ(W·x_{i:i+h−1} + b)，ŷᵗ = max(yᵗ) |
| PyTorch | `Conv1d(in_channels=embed_dim, out_channels=num_filters, kernel_size=h)` |
| 典型应用 | #sentiment-classification 情感分类、#nli 自然语言推断（BCNN、Pyramid） |

## N-gram 特征与卷积的关系

传统 NLP 中，**N-gram** 特征通过统计共现捕获局部词序模式（如 bigram "not good"）。

TextCNN 将这一思想**参数化**：
- 卷积核大小 h 对应 **h-gram** 感受野
- 核权重 W 在训练中自动学习哪些 n-gram 模式对任务有用
- 不同窗口大小的核并行使用 → 同时捕获 unigram、bigram、trigram 等级别特征

```
N-gram 与卷积核对应:
kernel_size=1 → 类似 unigram（单词级）
kernel_size=2 → 类似 bigram
kernel_size=3 → 类似 trigram
kernel_size=h → h-gram 局部模式
```

> [!tip] 与词袋的区别
> TextCNN **保留局部词序**（窗口内有序），且通过 Max-pooling 从全句中选取最显著模式，比简单词袋更强大。

## TextCNN 架构（Kim, 2014）

**整体流程**：

句子 → 词向量矩阵 $X \in \mathbb{R}^{L \times d}$
         ↓
多种 kernel_size 的 Conv1d（如 3, 4, 5）
         ↓
ReLU 激活
         ↓
Global Max-pooling（每条特征映射取全局最大）
         ↓
拼接所有尺度的特征向量
         ↓
Dropout + 全连接 + Softmax → 类别

**关键设计**：
1. **输入**：长度为 L 的句子，每词 d 维嵌入，排列为 (batch, d, L) 供 Conv1d 使用
2. **多尺度卷积核**：同一 embed_dim，不同 kernel_size（如 3/4/5），每种若干 filter
3. **Max-pooling**：对每个特征映射取 **全局最大值**，得到固定长度表示（与句子长度无关）
4. **分类**：拼接后接全连接层

---

## 特征提取公式

对第 t 种卷积核（窗口高度 h），在位置 i 的特征：

**yᵢᵗ = F(W · x_{i:i+h−1} + b)**

- **x_{i:i+h−1}**：从第 i 个词开始的 h 个词向量拼接/堆叠
- **W, b**：该卷积核的权重与偏置
- **F**：非线性激活（通常为 ReLU）

对整条句子在该核下产生特征序列 **yᵗ = (y₁ᵗ, y₂ᵗ, …, y_{L−h+1}ᵗ)**，再经**最大池化**：

**ŷᵗ = max(yᵗ)**

保留该 n-gram 检测器在全句中**最强的响应**，作为该 filter 的句子级特征。

## PyTorch 代码示例

```python
import torch.nn as nn

# 词向量维度 = in_channels，filter 数量 = out_channels
conv3 = nn.Conv1d(
    in_channels=word_embed_size,   # 如 300
    out_channels=num_filters,      # 如 100
    kernel_size=3                  # trigram 窗口
)

# 输入 x: (batch, embed_dim, seq_len)
# 输出: (batch, num_filters, seq_len - 3 + 1)
```

**多尺度并行示例**：

```python
self.convs = nn.ModuleList([
    nn.Conv1d(embed_dim, num_filters, k)
    for k in [3, 4, 5]  # trigram, 4-gram, 5-gram
])

def forward(self, x):
    # x: (batch, embed_dim, seq_len)
    features = []
    for conv in self.convs:
        h = torch.relu(conv(x))           # (batch, num_filters, L')
        h = torch.max(h, dim=2)[0]         # Global max-pooling
        features.append(h)
    return torch.cat(features, dim=1)      # 拼接多尺度特征
```

> [!important] Conv1d 通道约定
> PyTorch `Conv1d` 输入形状为 **(N, C_in, L)**，C_in = 词向量维度，L = 序列长度；与 `(N, L, C)` 需 transpose。

## 应用场景

### 情感分类（Sentiment Classification）

- 任务：判断文本情感极性（正/负/中性）
- TextCNN 优势：自动学习 "not good"、"very happy" 等关键 n-gram
- Kim (2014) 在 MR、SST 等数据集上取得 competitive 结果

### 自然语言推断（NLI）

| 模型 | 思路 |
|------|------|
| **BCNN** | 双句分别用 CNN 编码，交互后判断蕴含/矛盾/中性 |
| **Pyramid** | 金字塔式多层 CNN，逐层抽象句子表示用于 NLI |

NLI 需建模两句语义关系；CNN 提供高效局部特征，可与 attention、RNN 等组合。

```
TextCNN 适用任务:
┌─────────────────────┬──────────────────────────────┐
│ 任务                │ 为何适合                     │
├─────────────────────┼──────────────────────────────┤
│ 情感分类            │ 关键短语（n-gram）决定极性   │
│ 句子分类            │ 局部模式 + 全局 max 足够     │
│ NLI（BCNN/Pyramid） │ 高效句编码 + 语义匹配        │
└─────────────────────┴──────────────────────────────┘
```

## 考试/测试常见模式
| 场景/关键词 | 答案 |
|-------------|------|
| "TextCNN 输入形式" | 词向量矩阵，Conv1d 为 (batch, embed_dim, seq_len) |
| "kernel_size=3 含义" | 3-gram 局部窗口 |
| "Max-pooling 作用" | ŷᵗ=max(yᵗ)，取全句最重要特征，固定输出维 |
| "多尺度卷积" | 并行 k=3,4,5 等，拼接特征 |
| "Kim 2014 核心结构" | Embed → Multi Conv1d → ReLU → MaxPool → FC |
| "Conv1d 参数量" | K×C_in×C_out + C_out（K=kernel_size） |
| "NLI 中的 CNN 模型" | BCNN、Pyramid |

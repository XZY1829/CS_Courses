## CNN 的动机：为何不用全连接网络？

前馈神经网络（FFN）处理序列/图像时存在两大缺点：

1. **参数量过大**：若输入维度为 M、隐藏层为 N，单层权重参数量为 M×N，随输入规模线性甚至平方增长，易过拟合且计算昂贵。
2. **无法捕获局部不变性**：FFN 将输入展平为向量，每个输出神经元与**所有**输入位置相连，既忽略**局部结构**（相邻元素往往相关），也无法共享对平移/局部模式的不变性。

卷积神经网络通过**局部连接**与**参数共享**（同一卷积核在输入上滑动复用）缓解上述问题。

```
FFN vs CNN 对比:
┌──────────────┬────────────────────┬────────────────────┐
│              │       FFN          │       CNN          │
├──────────────┼────────────────────┼────────────────────┤
│ 连接方式     │ 全连接             │ 局部感受野         │
│ 参数共享     │ 无                 │ 同一核权重共享     │
│ 平移不变性   │ 弱                 │ 较强（池化进一步） │
│ 典型应用     │ 表格/低维特征      │ 图像、文本序列     │
└──────────────┴────────────────────┴────────────────────┘
```

## 一维卷积（1D Convolution）

给定长度为 M 的一维输入序列 **x** = (x₁, x₂, …, x_M) 和长度为 K 的卷积核 **w** = (w₁, w₂, …, w_K)，在位置 t 的输出为：

$y_t = \sum_{u=1}^{K} w_{K-u+1} \times x_{t-u+1}$

- 核在输入上**从左向右滑动**，每次计算 K 个元素的加权和。
- 索引约定：w_{K−u+1} 与 x_{t−u+1} 对齐；t 从 1 到输出长度 L。
- NLP 中常用 **1D 卷积**处理词向量序列，每个时间步对应一个词的多维嵌入。

```
一维卷积滑动示意 (K=3):
输入:  x₁  x₂  x₃  x₄  x₅  x₆
         [---核---]
              [---核---]
                   [---核---]
输出:  y₁  y₂  y₃  y₄ ...
```

## 步长（Stride）与填充（Padding）

| 超参数 | 符号 | 含义 |
|--------|------|------|
| **步长** Stride | S | 卷积核每次滑动的距离；S=1 逐位滑动，S>1 降采样 |
| **填充** Padding | P | 在输入两端补 P 个元素（常为 0），控制输出尺寸 |

**卷积输出长度公式**（一维，输入长度 M，核大小 K，填充 P，步长 S）：

**L = ⌊(M + 2P − K) / S + 1⌋**

> [!important] 公式使用场景
> 考试常给 M、K、P、S 求 L；注意向下取整 ⌊·⌋，且 P、K、S 必须使分子 M+2P−K ≥ 0。

---

## 三种卷积类型

| 类型 | 填充 P | 输出长度特点 | 标签 |
|------|--------|--------------|------|
| **窄卷积** Narrow Conv | P = 0 | L < M，序列变短 | #narrow-conv |
| **等宽卷积** Equal Conv | P = (K−1)/2（K 为奇数） | L ≈ M，保持长度 | #equal-conv |
| **宽卷积** Wide Conv | P = K−1 | L > M，序列变长 | #wide-conv |

```
三种卷积输出长度对比 (M=6, K=3, S=1):
窄卷积 P=0:     L = 6-3+1 = 4
等宽卷积 P=1:   L = (6+2-3)/1+1 = 6
宽卷积 P=2:     L = (6+4-3)/1+1 = 8
```

> [!tip] 等宽卷积前提
> 等宽卷积要求 **K 为奇数**，此时 P = (K−1)/2 为整数；K 为偶数时需额外处理（如 asymmetric padding）。

## 二维卷积（2D Convolution）与扩展

**二维卷积**将一维思想推广到矩阵/张量：

- 输入特征图 $X \in \mathbb{R}^{H \times W}$（或 H×W×C 多通道）
- 卷积核 $W \in \mathbb{R}^{K_h \times K_w}$ 在 H、W 两个维度上滑动
- 每个输出位置：核覆盖区域内的元素与核权重逐元素乘加

**输出尺寸**（高 H、宽 W，核 K_h×K_w，填充 P_h/P_w，步长 S_h/S_w）：

- H_out = ⌊(H + 2P_h − K_h) / S_h + 1⌋
- W_out = ⌊(W + 2P_w − K_w) / S_w + 1⌋

**扩展关系**：

| 维度 | 输入形态 | 典型场景 |
|------|----------|----------|
| 1D | 序列 (M, C) | 文本、时间序列 |
| 2D | 图像 (H, W, C) | 图像分类、视觉 NLP |
| 3D | 视频/体数据 | 时空建模 |

NLP 中文本 CNN 主要使用 **1D 卷积**；若将词向量矩阵视为「高=词数、宽=嵌入维」，也可用 2D 卷积，但 Kim (2014) 经典 TextCNN 以 **Conv1d** 为主。

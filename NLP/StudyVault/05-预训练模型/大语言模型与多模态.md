## 大语言模型（LLM）能力边界

### 擅长的能力 ✓

| 能力 | 说明 |
|------|------|
| **存储与检索** | 参数中编码大量事实性知识 |
| **模式识别** | 识别语言模式、格式、风格 |
| **上下文关联** | 利用 prompt 中上下文做连贯响应 |
| **语言生成** | 流畅、多样的文本产出 |

### 局限 ✗

| 局限 | 说明 |
|------|------|
| **因果推理** | 难以真正理解因果链，易混淆相关与因果 |
| **抽象思维** | 复杂抽象概念推理能力有限 |
| **逻辑一致性** | 长链推理中易出现前后矛盾 |
| **知识迁移** | 跨领域深层迁移不如人类灵活 |

> [!warning] 能力边界
> LLM 的"理解"很大程度是**统计模式匹配**，而非真正的符号推理或世界模型。考试需区分"能做什么"与"不能做什么"。

### 知识层次模型

```
Level 5: 推理 (Reasoning)        ← LLM 最弱
Level 4: 逆向搜索 (Backward Search)
Level 3: 比较 (Comparison)
Level 2: 分类 (Classification)
Level 1: 记忆 (Memory)           ← LLM 最强
```

LLM 在**低层次**（记忆、分类）表现强劲，在**高层次**（推理、抽象）仍有明显差距。

## 文本-视觉预训练

### 数据形式

**(图片, 描述文本)** 配对数据：

```
(IMAGE: 🐱照片, TEXT: "A cat sitting on a sofa")
(IMAGE: 🌆照片, TEXT: "City skyline at sunset")
```

常见来源：网页图文对、COCO Captions、Conceptual Captions 等。

### 预训练任务

| 任务 | 全称 | 说明 |
|------|------|------|
| **MLM** | Masked Language Modeling | 结合图像上下文预测被 mask 的文本 token |
| **MRM** | Masked Region Modeling | 预测被 mask 的图像区域特征 |
| **ITM** | Image-Text Matching | 判断图文对是否匹配（二分类） |

```
图文输入 ──→ 视觉编码器 + 文本编码器
                ↓
         联合 Transformer
                ↓
    MLM / MRM / ITM 多任务预训练
```

## CLIP（Contrastive Language-Image Pre-training）

**CLIP** — Radford et al., OpenAI 2021

### 核心方法：图文对比学习

- 图像编码器（ViT/CNN）+ 文本编码器（Transformer）
- 在 batch 内做**对比学习**：匹配图文对相似度最大化，不匹配最小化

```
Batch 内 N 个图文对:
  对角线 = 正样本（匹配）
  非对角线 = 负样本（不匹配）

Loss: InfoNCE / 对比交叉熵
```

| 特点 | 说明 |
|------|------|
| **零样本迁移** | 无需微调，用 prompt 模板即可分类 |
| **共享嵌入空间** | 图像和文本映射到同一向量空间 |
| **大规模训练** | 4 亿图文对 |

> [!tip] 应用
> 以 "A photo of a {label}" 为文本 prompt，选与图像余弦相似度最高的标签 → 零样本分类。

## UNITER

**UNITER** — UNiversal Image-TExt Representation

- 统一视觉和文本的 **Transformer** 表示
- 使用 [CLS]、图像 region features、文本 token 联合输入
- 预训练任务：MLM + MRM + **MRFR** + ITM

与 CLIP 对比：UNITER 更侧重**细粒度融合**（region-token 级别交互），CLIP 侧重**全局对比对齐**。

## 多模态大模型三类范式

| 范式 | 代表模型 | 特点 |
|------|----------|------|
| **特定任务型** | CLIP, DALL-E | 专注单一能力（对齐/生成） |
| **多任务型** | SAM, BEiT-3 | 统一架构处理多种视觉/多模态任务 |
| **LLM 基座型** | BLIP-2, LLaVA | **冻结/轻调 LLM**，接入视觉模块 |

```
LLM 基座型架构:
  图像 ──→ Vision Encoder ──→ Q-Former/Projection ──→ LLM ──→ 文本输出
                                                          ↑
                                                    预训练 LLM 权重
```

| 模型 | 思路 |
|------|------|
| **BLIP-2** | Q-Former 桥接冻结视觉编码器与 LLM |
| **LLaVA** | 视觉指令微调，让 LLM 理解图像并对话 |
| **GPT-4V** | 原生多模态 LLM |

> [!important] 趋势
> 当前主流方向是将**视觉感知模块**接入已有 **LLM 基座**，而非从头训练多模态模型。

## 多模态 vs 纯文本 LLM

| 维度 | 纯文本 LLM | 多模态 LLM |
|------|-----------|-----------|
| 输入 | 仅文本 | 文本 + 图像（+ 音频等） |
| 预训练数据 | 文本语料 | 图文对 + 文本语料 |
| 核心挑战 | 推理、幻觉 | 视觉-语言对齐、细粒度理解 |
| 代表 | GPT-3/4（文本） | GPT-4V, LLaVA, BLIP-2 |

## 二、引言：为什么会有规则方法

### 1) NLP 方法演进（时间脉络）

- 1950s：基于模板
- 1960s~1980s：基于规则
- 1990~2013：统计方法
- 2013~至今：深度学习方法

### 2) 规则方法仍然有价值的场景

- 标注数据缺乏（难以训练可靠统计/神经模型）
- 任务需要强可解释性与可控性
- 领域知识强、边界较清晰（如医疗、法律、金融的实体抽取）
- 需求是“高精度、可审计”的子模块

### 3) 课堂案例提示

- Text2SQL 这类任务中，自然语言与目标形式语言（SQL）对应关系复杂。
- 当数据不足时，人为编码规则可作为“先验知识”提供强约束。

## 三、规则方法的核心思想

### 1) 本质定义

- 用**规则**显式表示语言知识，并基于规则进行推理。
- 强调知识工程：依赖专家总结语言学知识。
- “规则（数据）”与“程序（解释器）”分离。

### 2) 规则方法覆盖层次

- 词法分析
- 句法分析
- 语义分析
- 以及对应任务中的规则消歧

### 3) 典型系统形态（可画图记忆）

- 输入文本 -> 规则库/词典库匹配 -> 推理与消歧 -> 输出结构化结果

## 四、应用一：形态还原（Lemmatization）

### 1) 任务目标

- 将词的各种形态还原为原形，便于检索词典与后续处理。

### 2) 构词变化类型（英语）

- 曲折变化：词性通常不变（如 `study/studied/studying`）
- 派生变化：前后缀导致词性可能变化（`friend/friendly/friendship`）
- 复合变化：多个词组合形成新词

### 3) 规则类别

- 通用规则：有规律的词形变化
- 个性规则：不规则变化（如 `went -> go`）

### 4) 常见规则示例

- `*s -> *`，`*es -> *`，`*ies -> *y`
- `*ing -> *`，`*ing -> *e`，`*ying -> *ie`
- `*ed -> *`，`*ed -> *e`，`*ied -> *y`

### 5) 基本算法（高频考点）

1. 输入单词  
2. 若原型词典存在该词：直接输出词及属性  
3. 否则应用还原规则；若还原后词在词典中，输出还原词及属性  
4. 若仍失败，交给未登录词模块  
5. 继续处理下一个词

## 五、应用二：中文分词

### 1) 基本概念

- 分词：按规范把“字串”切分为“词串”。
- 分词规范不同会导致结果差异（工程落地要先定规范）。

### 2) 歧义类型（重点）

- **交集型歧义**：`AB/C` vs `A/BC`（例：“和平等”）
- **组合型歧义**：`AB` vs `A/B`（例：“马上”）
- **混合型歧义**：交集型与组合型交叉嵌套（例：“得到达”）

### 3) 真歧义 vs 伪歧义

- 伪歧义：任何语境下只有一种切分
- 真歧义：不同语境可有不同切分，需要上下文消歧

### 4) 经典分词策略

- 正向最大匹配（FMM）
- 逆向最大匹配（RMM）
- 双向最大匹配（FMM+RMM）
- 正向最大 + 逆向最小
- 逐词遍历匹配
- 设立切分标记
- 全切分 + 选择最优切分

### 5) 规则消歧依据

- 句法信息（如数词搭配）
- 语义信息（词义选择偏好）
- 语用信息（场景/上下文）
- 规则粒度可从“具体词规则”到“词类/语义类规则”

### 6) 分词的代价与问题

- 字级信息可能丢失
- 错误会级联影响后续任务
- 规范不统一导致系统间结果不一致

## 六、应用三：词性标注（POS Tagging）

### 1) 定义与目标

- 给每个词分配预定义词性类别
- 为句法/语义分析提供基础输入

### 2) 词类体系（英文学术常识）

- 开放类：Nouns/Verbs/Adjectives/Adverbs
- 封闭类：Determiners/Pronouns/Prepositions/Conjunctions/Auxiliary verbs 等

### 3) 主要挑战

- 兼类词（同形词多词性）普遍存在
- 汉语因词形变化弱，兼类词问题更突出

### 4) 方法比较

- 规则方法：词典给候选词性 + 消歧规则定最终词性
- 统计方法：利用已标注语料选择最可能序列
- 混合方法：规则与统计结合（工程中常见）

---

## 七、应用四：命名实体识别（NER）

### 1) 任务定义

- 找实体边界 + 判实体类型

### 2) 类型体系（课件）

- 三大类：实体类、时间类、数字类
- 七大类：人名、地名、机构名、时间、日期、货币量、百分数

### 3) 基于规则的核心

- 匹配驱动：依赖词典、模板、正则表达式
- 常见线索：身份词、指界词、标点触发等

### 4) 两种典型规则路径

- **实体词表匹配**  
  - 优点：速度快、精度高（在封闭领域）  
  - 缺点：覆盖有限、维护成本高
- **规则模板（正则）匹配**  
  - 适合邮箱、日期等形态稳定模式  
  - 常作为词表法补充，提升召回率

## 八、应用五：基于规则的机器翻译（RBMT）

### 1) 任务定义

- 源语言句子 `x` -> 目标语言句子 `y`
- 目标可写作：选择最优译文 `argmax P(y|x)`（概念性表达）

### 2) 基本流程（必记）

1. **分析**：把源语解析为深层表示（词法/句法/语义）
2. **转换**：把源语深层表示映射到目标语深层表示
3. **生成**：由目标语深层表示生成目标句子

### 3) 规则翻译主要层次

- 词汇转换
- 句法结构转换（树到树）
- 语义转换
- 中间语（Interlingua）转换

### 4) 四类典型方法

- 基于词的转换翻译
- 基于句法结构转换翻译
- 基于语义转换翻译
- 基于中间语言翻译

### 5) Interlingua 的工程意义（易考）

- 若有 `n` 种语言：  
  - 两两转换需 `n(n-1)` 模块  
  - 中间语方案仅需 `2n` 模块
- 优势：多语扩展性更好  
- 难点：需要统一、跨语言适配的概念本体，且分析/消歧难度大

## 九、规则方法总体优缺点（总论）

### 优点

- 可解释、可控、可审计
- 小数据场景可快速起步
- 在垂直领域可获得高精度

### 缺点

- 规则构建高度依赖专家经验，成本高
- 规则冲突频发，维护复杂
- 覆盖难做大，迁移性弱
- 大规模系统演化困难

## 十、考试/面试高频问答（速背）

### Q1：什么是规则方法？核心思想是什么？

- 以规则显式编码语言知识，程序通过解释器执行规则完成分析与推理。

### Q2：中文分词的三类歧义分别是什么？

- 交集型、组合型、混合型；真歧义需上下文消歧。

### Q3：规则分词常用哪些方法？

- FMM、RMM、双向最大匹配、全切分选优等。

### Q4：规则NER常见实现方式？

- 实体词表匹配 + 模板/正则匹配的组合。

### Q5：Interlingua 为什么常被提及？

- 多语场景下模块数从 `n(n-1)` 降至 `2n`，但对统一语义本体要求极高。

## 十一、30秒复习清单（考前看）

- 规则方法 = **词典/规则库 + 解释器 + 消歧**
- 分词歧义三件套：**交集 / 组合 / 混合**
- POS 难点：**兼类词**（汉语更明显）
- NER 规则法：**词表快但窄，模板广但脆**
- RBMT 三步：**分析 -> 转换 -> 生成**
- Interlingua 模块量：**`n(n-1)` vs `2n`**
- 总体判断：**可解释强，扩展维护弱**

---

## 十二、和后续章节的衔接理解

- 规则方法强调“**专家知识先验**”，统计/深度方法强调“**数据驱动学习**”。
- 现代系统常是混合范式：  
  - 用规则做高精度约束（术语、格式、合规）  
  - 用学习模型补覆盖与鲁棒性
- 这也是从“规则时代”过渡到“统计/神经时代”的核心逻辑。

# 1-2分钟程序演示视频脚本（可直接照读）

## 总时长建议：90秒

### 0-10秒：开场

大家好，我的课程实践题目是“基于循环神经网络的命名实体识别”。  
本项目使用 CoNLL-2003 数据集，基于 PyTorch 实现了 BiLSTM-CRF，并加入了字符级CNN改进。

### 10-30秒：项目结构展示

现在展示项目结构：  
`train.py` 用于训练，`evaluate.py` 用于评估，`predict.py` 用于单句预测。  
`src/model.py` 是模型定义，`src/crf.py` 是CRF层实现，`configs/` 中有基线和改进模型配置。

### 30-55秒：训练命令展示

我先运行基线模型训练命令：

```bash
python train.py --config configs/bilstm_crf.yaml --output_dir outputs/bilstm_crf
```

再运行加入CharCNN的改进模型：

```bash
python train.py --config configs/bilstm_crf_charcnn.yaml --output_dir outputs/bilstm_crf_charcnn
```

训练结束后会自动保存最佳模型和测试集指标。

### 55-75秒：评估结果展示

我用下面命令评估改进模型：

```bash
python evaluate.py --model_dir outputs/bilstm_crf_charcnn --split test
```

终端会输出 Precision、Recall、F1，以及各实体类别详细结果。  
本次实测中，改进模型在测试集上达到 `P=84.38 / R=83.96 / F1=84.17`。  
（这里停顿1-2秒，让结果画面停留）

### 75-90秒：预测案例与总结

最后进行单句预测：

```bash
python predict.py --model_dir outputs/bilstm_crf_charcnn --sentence "EU rejects German call to boycott British lamb ."
```

可以看到模型输出了 token 级标签和实体片段。  
总结：本项目完整实现了RNN-NER流程，并通过CharCNN改进将F1从78.25提升到84.17，提升5.91个百分点。

# 从零掌握 UE 与 D5 开发

## 目标

从 UE 零基础出发，最终能够：

- 读懂常见 UE C++ 代码；
- 正确处理 UObject、Actor、Component、资源和生命周期；
- 理解材质、模型、坐标、相机等三维业务；
- 沿真实调用链阅读 D5 Render 功能；
- 独立完成小范围修改、构建、调试和验证。

这里的“从零”指从 UE 开发零基础开始。学习者仍需具备基本 C++ 能力，包括类、继承、虚函数、模板、智能指针、Lambda 和常用 STL 容器。

## 总体路线

### 第一阶段：建立 UE 心智模型

学习内容：

- Unreal Editor、World、Level；
- `UObject`、`AActor`、`UActorComponent`；
- `USceneComponent`、`UPrimitiveComponent`；
- Transform 与组件附着关系；
- 创建一个最小 C++ Actor 并在编辑器中观察。

阶段验收：能够解释“一个 D5 点光源为什么是 Actor 加多个 Component”。

### 第二阶段：UE C++ 基础设施

学习内容：

- `FString`、`FName`、`FText`；
- `TArray`、`TMap`、`TSet`；
- 普通 C++ 对象与 UObject 的两套指针体系；
- `UCLASS`、`USTRUCT`、`UENUM`、`UPROPERTY`、`UFUNCTION`；
- Unreal Header Tool、模块与构建文件；
- 单播、多播、动态委托。

阶段验收：能够根据所有权、GC、序列化和按需加载需求选择正确的指针类型。

### 第三阶段：对象生命周期

学习内容：

- CDO 与普通实例；
- 构造函数、`PostInitProperties`、`BeginPlay`、`EndPlay`；
- UObject GC 引用图；
- Actor 的 Spawn、注册、Tick、Destroy；
- Component 的创建、注册、激活与销毁；
- 弱引用、软引用和资源加载。

阶段验收：能够解释对象为什么存活、何时失效，以及为什么不应在 UObject 构造函数中执行场景业务。

### 第四阶段：三维与渲染业务

学习内容：

- 左右手系、世界/局部/相机空间；
- 平移、旋转、缩放和矩阵；
- Static Mesh、材质、材质实例和纹理；
- Camera、Spline、植被；
- 模型格式、导入与资源依赖；
- 图形学基础与 GAMES101 核心章节。

阶段验收：能够定位一次模型位置、朝向、缩放或材质参数异常。

### 第五阶段：D5 业务专题

按功能分别建立闭环：

- 素材库与资源列表；
- 保存与加载；
- Actor 和模型加载；
- 参数调节；
- 模型操作与成组；
- 材质、植被、相机和视频；
- 模型数据处理。

每个专题都要回答：谁发起、谁拥有数据、如何传输、在哪个线程执行、返回值表示什么、什么才算真正完成。

### 第六阶段：工程与底层

学习内容：

- Qt 与 UE 的职责边界；
- Windows 桌面应用基础；
- 进程间通信、线程切换和异步任务；
- UnrealBuildTool、Module、Plugin 和构建配置；
- 日志、断点、崩溃栈、性能分析；
- UE 对象、渲染和任务系统的底层实现。

阶段验收：能够沿跨模块链路定位问题，并区分“请求已接收”和“最终业务完成”。

## 建议节奏

| 周次 | 重点 | 产出 |
|---|---|---|
| 第 1 周 | 编辑器、Actor、Component、Transform | 一个可放入场景的自定义 Actor |
| 第 2 周 | UE 类型、容器和指针 | 类型与选择规则速查表 |
| 第 3 周 | 反射、CDO、GC、生命周期 | 生命周期图与错误案例 |
| 第 4 周 | 委托、Tick、资源加载 | 一个事件驱动的小功能 |
| 第 5 周 | 坐标、模型、材质 | 一个可调参数的模型 Actor |
| 第 6 周 | Camera、Spline、植被、视频 | 两个 D5 业务功能拆解 |
| 第 7 周 | Qt+UE、线程和通信 | 一条跨模块调用链图 |
| 第 8 周起 | D5 源码与真实任务 | 修改、构建和运行验证记录 |

## 学习循环

每个主题按下面的顺序推进：

```text
概念讲解 → 最小代码 → 主动复述 → 小题练习 → D5 源码定位 → 错误案例 → 验收
```

不要把“看完文档”当作掌握，也不要把“函数返回成功”直接当作业务完成。最终结论需要与对应层级的源码、日志、产物或运行状态匹配。

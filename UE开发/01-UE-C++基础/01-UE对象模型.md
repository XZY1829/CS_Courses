# UE 对象模型

## 30 秒版

`UObject` 是 UE 反射与对象管理体系的基础；`AActor` 是可以进入 `World` 的实体；Component 为 Actor 组合行为、空间关系、渲染和碰撞能力。Actor 的 Transform 实际来自它的根 `USceneComponent`。

## 核心关系

```text
UObject
└── AActor：能够被放入或生成到 World
    └── Components
        ├── UActorComponent：可复用行为，本身没有 Transform
        └── USceneComponent：拥有 Transform，可形成附着树
            └── UPrimitiveComponent：通常参与渲染、碰撞或空间查询
```

## 五个基础概念

| 类型 | 作用 | 是否有 Transform | 能否直接渲染 |
|---|---|---:|---:|
| `UObject` | 反射、序列化、GC 等对象能力的基础 | 否 | 否 |
| `AActor` | World 中的业务实体和组件容器 | 由根组件提供 | 不直接渲染 |
| `UActorComponent` | 为 Actor 提供可复用行为 | 否 | 否 |
| `USceneComponent` | 提供位置、旋转、缩放和附着关系 | 是 | 不一定 |
| `UPrimitiveComponent` | 提供可渲染或可碰撞的空间表示 | 是 | 通常可以 |

## D5 点光源示例

```text
APurePointLightActor
├── UPointLightComponent：产生点光源效果
└── UBillboardComponent：在编辑器中显示二维图标
```

这个例子体现了 UE 的组合思想：

- Actor 表示“这是一个 D5 点光源”的业务身份；
- PointLightComponent 提供光照能力；
- BillboardComponent 提供编辑器可视化能力；
- 根 SceneComponent 决定 Actor 的世界 Transform；
- 其他 SceneComponent 相对于父组件进行定位。

## 常见误区

### Actor 自己存储 Transform

不准确。Actor 的位置、旋转和缩放最终由根 `USceneComponent` 提供。更换根组件或修改附着关系时，需要重新检查世界 Transform 与相对 Transform。

### 所有 Component 都可以渲染

不正确。`UActorComponent` 可以只是逻辑组件；`USceneComponent` 只保证具有空间关系；通常到 `UPrimitiveComponent` 才具有几何、渲染或碰撞表示。

### UObject 可以完全按照普通 C++ 对象管理

不正确。UObject 进入了 UE 的反射、序列化和 GC 体系，创建、引用和销毁规则都与普通 `new/delete` 对象不同。

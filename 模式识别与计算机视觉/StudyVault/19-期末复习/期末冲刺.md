## 总原则

- 先背会输出模板，再回头理解细节。
- 每个小问默认 2 分钟：第一句写定义，第二句写公式，第三句解释变量/原因。

## 最后一天安排

### 第 1 轮：90 分钟，把公式写成肌肉记忆

按顺序默写，不会就看 `期末复习要点.md`：

1. 混淆矩阵：TP/TN/FP/FN、P/N/TOTAL。
2. `FPR/FNR/TPR/ACC/PRE/REC/F1`。
3. ROC/PR 坐标轴、AUC、PR 对不平衡更敏感。
4. FLD：`J(w)`、`SW/SB`、`SBw=lambda SWw`、`w ∝ SW^{-1}(mu2-mu1)`。
5. 多分类：`SW`、`ST`、`SB`、最多 `C-1` 方向。
6. Metric 四性质、Norm 三性质、范数诱导度量证明。
7. `Lp`、L1 vs L2、马氏距离、白化。
8. 卷积定理、空域/频域滤波、Gaussian vs Box、Nyquist。
9. Harris：流程、`M`、特征值、响应函数。
10. Hough：accumulator、法线式。
11. 2D 变换自由度表、仿射三性质。
12. 单应 8 DOF、DLT、RANSAC。
13. 标定、三角测量、对极几何、E/F 矩阵。

### 第 2 轮：120 分钟，做 `练习题.md`

- 每题先限时写答案，再打开折叠答案对照。
- 错题只标三类：公式忘了、变量混了、解释说不顺。
- 同一个错误出现两次，马上回到要点笔记重背。

### 第 3 轮：120 分钟，做 `模拟试卷.md`

- 必须限时。
- 9 道大题不要恋战：每道题最多 13 分钟，剩余时间回查。
- 简答题能写表格就写表格，能写流程就编号。

### 第 4 轮：45 分钟，只背高频问法

| 高频问法 | 必须写出的关键词 |
|---|---|
| PR 和 ROC 谁对类别不平衡更敏感 | PR；Precision 和 Recall 聚焦正例；ROC 用 FPR，负样本多时不敏感 |
| 阳性漏检看哪条曲线 | PR；FN 影响 Recall |
| 为什么 F1 用调和平均 | 对短板敏感 |
| FLD 为什么比 PCA 更适合分类 | FLD 类间大、类内小；PCA 只看总体方差 |
| FLD 为什么二分类不用完整广义特征值 | `SBw` 方向与 `mu2-mu1` 成比例 |
| 多分类最多几个方向 | `C-1`，因为 `SB` 秩最多 `C-1` |
| 范数诱导度量怎么证明 | 四性质逐条写 |
| L1 为什么比 L2 鲁棒 | L1 线性，L2 二次，离群点影响更大 |
| 马氏距离物理意义 | 白化后欧氏距离 |
| Gaussian pyramid 为什么先模糊 | 低通去高频，避免下采样 aliasing |
| Harris 角点如何判断 | 两个特征值都大 |
| Hough 为什么用法线式 | 参数空间有限，避免斜率无穷 |
| 单应为什么 8 DOF | 9 元素减 1 个尺度不变 |
| DLT 怎么求 H | 每点两行，堆叠 `Ah=0`，SVD 最小奇异值向量 |
| RANSAC 流程 | 随机取样、估计、数内点、保最优、全内点重算 |
| 张正友标定 | 平面棋盘格、多角度、角点、单应、内外参、非线性优化 |
| E 和 F 区别 | E 用相机归一化坐标，F 用像素坐标；`F=K'^{-T}EK^{-1}` |

## 考场写法模板

### 计算题

```text
先列已知量 -> 写公式 -> 代入 -> 给结果 -> 用一句话解释。
```

### 证明题

```text
先写要证明的性质 -> 引用定义 -> 逐条验证 -> 最后一行总结。
```

### 流程题

```text
编号写 4-6 步，每步一个动词：计算、构造、求解、统计、重算。
```

### 比较题

```text
先给结论 -> 用表格比较指标/坐标/适用场景 -> 写为什么。
```

FPR=FP/N, FNR=FN/P, TPR=TP/P, ACC=(TP+TN)/TOTAL

J(w)=w^T SB w / w^T SW w
SW=S1+S2
SB=(mu2-mu1)(mu2-mu1)^T
w ∝ SW^{-1}(mu2-mu1)
SB_multi=sum_i Ni(mui-mu)(mui-mu)^T

dA^2(x,y)=(x-y)^T A (x-y)
||x||p=(sum_i |xi|^p)^(1/p), p>=1

F{f*g}=F{f}F{g}
E(u,v)≈[u v]M[u v]^T
M=sum w [[Ix^2,IxIy],[IxIy,Iy^2]]
R=det(M)-k trace(M)^2
x cos(theta)+y sin(theta)=rho

H has 8 DOF
Ah=0 -> SVD -> smallest singular vector -> reshape H
RANSAC: sample 4 -> DLT -> count inliers -> keep best -> recompute

x'^T E x=0
l'=Ex, l=E^T x'
F=K'^{-T} E K^{-1}
x'^T F x=0

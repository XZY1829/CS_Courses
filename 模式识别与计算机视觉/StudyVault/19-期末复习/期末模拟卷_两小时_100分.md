# 参考答案要点

## 第一题

1. TP：真实正且预测正；FP：真实负但预测正；FN：真实正但预测负；TN：真实负且预测负。
2. $TP=30$，$FN=10$，$FP=20$，$TN=140$。
3. $FPR=20/160=0.125$，$FNR=10/40=0.25$，$TPR=30/40=0.75$，$ACC=(30+140)/200=0.85$。
4. $\text{Precision}=30/(30+20)=0.6$，$\text{Recall}=30/40=0.75=TPR$，$F_1=2PR/(P+R)=2\times0.6\times0.75/(0.6+0.75)\approx0.667$。
5. ROC：横轴 $FPR$，纵轴 $TPR$；PR：横轴 Recall，纵轴 Precision；ROC 对角线代表随机分类器。
6. 类别不平衡时 $FPR=FP/N$ 的大分母会稀释误报，PR 更关注正例质量；漏检是 FN，会降低 Recall，而 PR 同时呈现 Recall 与 Precision。

## 第二题

1. PCA 最大化总体方差；FLD 最大化类间分离、最小化类内分散。总体方差大的方向可能让两类投影重叠。
2. $J(\mathbf{w})=(m_2-m_1)^2/(s_1^2+s_2^2)$；分子是类间距离，分母是类内分散。
3. $S_W=S_1+S_2$，$S_B=(\boldsymbol{\mu}_2-\boldsymbol{\mu}_1)(\boldsymbol{\mu}_2-\boldsymbol{\mu}_1)^T$。
4. $J(\mathbf{w})=\mathbf{w}^TS_B\mathbf{w}/\mathbf{w}^TS_W\mathbf{w}$，是 generalized Rayleigh quotient。
5. $S_B\mathbf{w}=\lambda S_W\mathbf{w}$；二分类 $\mathbf{w}\propto S_W^{-1}(\boldsymbol{\mu}_2-\boldsymbol{\mu}_1)$。
6. $S_B=\sum_i N_i(\boldsymbol{\mu}_i-\boldsymbol{\mu})(\boldsymbol{\mu}_i-\boldsymbol{\mu})^T$；$\operatorname{rank}(S_B)\le C-1$，所以最多 $C-1$ 个方向。

## 第三题

1. 参数化估计假设固定分布形式并估计有限参数；非参数估计不预设固定有限参数模型，更多依赖样本本身。
2. $P(\omega_i|\mathbf{x})=P(\mathbf{x}|\omega_i)P(\omega_i)/P(\mathbf{x})$；先验 $P(\omega_i)$，似然 $P(\mathbf{x}|\omega_i)$，后验 $P(\omega_i|\mathbf{x})$。
3. 非负性、对称性、同一性、三角不等式。
4. 范数性质：齐次性、正定性、三角不等式。三角不等式证明：$d(\mathbf{x},\mathbf{z})=f((\mathbf{x}-\mathbf{y})+(\mathbf{y}-\mathbf{z}))\le f(\mathbf{x}-\mathbf{y})+f(\mathbf{y}-\mathbf{z})$。
5. $\|\mathbf{x}\|_p=(\sum_i |x_i|^p)^{1/p}$，$p\ge1$；$L_1$ 线性增长，$L_2$ 二次增长，离群点对 $L_2$ 影响更大。
6. $d_A^2=(\mathbf{x}-\mathbf{y})^TA(\mathbf{x}-\mathbf{y})$；当 $A=\Sigma^{-1}$ 时相当于白化后计算欧氏距离。

## 第四题

1. $g[m,n]=\sum_i\sum_j f[m-i,n-j]h[i,j]$；可分离核可拆成一维横向和纵向卷积，减少乘加次数。
2. $\mathcal{F}\{f*g\}=\mathcal{F}\{f\}\mathcal{F}\{g\}$；空域卷积等价于频域乘法。
3. 小核适合空域直接卷积，约 $O(N^2K^2)$；大核/频域分析适合 FFT，约 $O(N^2\log N)$。
4. 空域越窄频域越宽，空域越宽频域越窄。
5. Gaussian 的频域也平滑，Box 的频域有 sinc 旁瓣，容易带来振铃。
6. $f_s\ge 2f_{\max}$；Gaussian pyramid 先低通去高频，再下采样以减少 aliasing。

## 第五题

1. 计算局部梯度；构造结构张量；分析特征值或响应函数；阈值检测；非极大值抑制/定位角点。
2. $E(u,v)\approx [u\ v]M[u\ v]^T$，$M=\sum w\begin{bmatrix}I_x^2&I_xI_y\\I_xI_y&I_y^2\end{bmatrix}$。
3. 两个都小是 flat；一大一小是 edge；两个都大是 corner。
4. $R=\det(M)-k\operatorname{trace}(M)^2$；用 det 和 trace 由矩阵元素直接计算，无需显式求特征值。
5. 量化参数空间；建立 accumulator；对每个边缘点投票；找局部最大值。
6. $x\cos\theta+y\sin\theta=\rho$；避免斜率无穷，使参数空间有限。

## 第六题

1. Translation 2，Euclidean 3，Similarity 4，Affine 6，Projective 8。
2. Affine 保共线性、平行性、比例分割；Projective 不保平行性和比例分割，但保直线。
3. $\mathbf{x}'\sim H\mathbf{x}$；$H$ 有 9 个元素，但整体尺度不变，实际 8 DOF。
4. 每对点 2 条方程；至少 4 对点，因为 $H$ 有 8 DOF。
5. 每对点建 $2\times9$ 方程；堆叠 $A\mathbf{h}=0$；SVD；取最小奇异值对应右奇异向量；reshape 成 $H$。
6. 随机取最小样本；估计模型；统计 inliers；保留最优；用所有 inliers 重算。Outlier 不容易进入最终 inlier 集，因此鲁棒。

## 第七题

1. $\mathbf{x}=P\mathbf{X}$，$P=K[R|t]$；$K$ 是内参，$R,t$ 是外参。
2. $K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}$；$f_x,f_y$ 是像素焦距，$c_x,c_y$ 是主点。
3. 世界坐标经 $R,t$ 到相机坐标，经透视除法到归一化图像坐标，再经 $K$ 到像素坐标。
4. $r'=r(1+k_1r^2+k_2r^4)$；常见记法下 $k_1<0$ 桶形，$k_1>0$ 枕形。
5. 棋盘格；多视角拍摄；检测角点；估计单应；求内外参初值；非线性优化。优点是只需平面且不必知道精确位姿；缺点是需要优化。

## 第八题

1. 由两视图对应点恢复 3D 点；噪声和匹配误差会使两条射线不精确相交。
2. 找相机中心，再用 $P$ 的 pseudo-inverse 得到射线上一点，连接二者形成 3D ray。
3. Baseline 是两相机中心连线；epipolar plane 是两中心和空间点构成的平面；epipolar line 是该平面与像平面的交线；epipole 是另一相机中心在本图像中的投影。
4. $\mathbf{x}'^TE\mathbf{x}=0$；$E$ 作用于归一化相机坐标。
5. $F=K'^{-T}EK^{-1}$；$F$ 作用于像素/图像坐标。
6. 每对点提供一个线性约束，$F$ 至少需 8 个线性约束；步骤：归一化、建 $A\mathbf{f}=0$、SVD、reshape、强制秩 2、反归一化。

## 第九题

1. Stereo rectification 是把两幅图重投影到公共平面，使对极线水平；匹配从沿任意对极线搜索变成同一扫描线上的一维搜索。
2. $Z=fB/d$；视差越大，深度越小，物体越近。
3. SAD/SSD 不抗亮度变化；Zero-mean 抗亮度偏移；NCC 减均值并除标准差，抗亮度和对比度变化，但计算局部均值和标准差更慢。
4. 失败场景：无纹理、重复纹理、镜面高光。Data term 衡量匹配代价；smoothness term 鼓励相邻像素视差平滑。

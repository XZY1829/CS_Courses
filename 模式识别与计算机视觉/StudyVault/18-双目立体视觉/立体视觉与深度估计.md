## 视差与深度

### 视差公式

对于平行相机（校正后），3D 点 (X, Y, Z) 在左右相机上的投影：

```
左相机：x  = f·X/Z
右相机：x' = f·(X−B)/Z

视差：d = x − x' = f·B/Z
```

| 符号 | 含义 |
|------|------|
| B | **基线**（两相机中心距离） |
| f | 焦距 |
| Z | 深度 |
| d | 视差 |

> [!important] 视差与深度的反比关系
> **d = Bf/Z** → Z = Bf/d
> - 近处物体：视差**大**
> - 远处物体：视差**小**
> - d = 0：物体在**无穷远**处

> [!warning] 零视差是可能的
> 当 Z → ∞ 时，d → 0。这是合法情况（物体在极远处）。

## 立体校正（Stereo Rectification）

### 为什么需要校正

一般双目系统中对极线**不一定水平** → 匹配搜索是 2D 的。
校正后对极线**变为水平** → 匹配搜索降为沿扫描线的 **1D** 搜索。

### 何时对极线水平

```
条件：R = I（两相机平行），t = (T, 0, 0)（仅水平平移）
→ 对极点在无穷远 → 所有对极线水平
```

### 校正算法

```
立体校正流程
━━━━━━━━━━━━━
  ① 8点法求 E        ← SVD
  ② SVD 分解 E → R, t
  ③ 从 e 构建 R_rect   ← 使对极点移到无穷远
  ④ 设 R₁ = R_rect（左相机旋转）
  ⑤ 设 R₂ = R·R_rect（右相机旋转）
  ⑥ 对左图所有点：[x',y',z'] = R₁·[x,y,z]，再投影 p = f/z'·[x',y',z']
  ⑦ 对右图重复，使用 R₂
```

### 构建 R_rect

目标：旋转使对极点 e 移到 (1,0,0)^T（x 方向无穷远）。

```
e₁ = e/‖e‖             （平移方向，即对极点方向）
e₂ = (-e_y, e_x, 0)^T / ‖·‖  （e × 光轴方向 → 垂直于 e₁）
e₃ = e₁ × e₂           （第三个正交方向）

R_rect = [e₁; e₂; e₃]  （行向量组成旋转矩阵）
```

应用 R_rect 后，对极点变为 R_rect · e = (‖e‖, 0, 0)^T → 齐次坐标下在 x 方向无穷远。

> [!tip] 四种分解的歧义性
> E = [t]_× · R 的 SVD 分解给出 **4 种** (R, t) 组合。
> 选择标准：找使 3D 点在**两个相机前方**的那组解。

## 模板匹配方法

立体匹配的核心问题：给定左图中的一个窗口，在右图对应扫描线上找到最匹配的位置。

### 四种方法比较

| 方法 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| 直接互相关 | ΣI·T | 最快 | 受高亮度区域影响 |
| 零均值互相关 | Σ(I−μ_I)(T−μ_T) | 消除亮度偏置 | 受高对比度区域影响 |
| SSD | Σ(I−T)² | 中等速度 | 受局部亮度变化影响 |
| **NCC** | Σ(I−μ_I)(T−μ_T)/(σ_I·σ_T) | **不变于亮度+对比度** | 最慢 |

> [!important] 关键理解
> - 减去均值 → 消除亮度偏置（brightness bias）
> - 除以标准差 → 消除对比度偏置（contrast bias）
> - NCC 同时做了两者 → **最鲁棒**

### 其他相似度度量

| 度量 | 公式形式 |
|------|---------|
| SAD | Σ\|I − T\| |
| SSD | Σ(I − T)² |
| Zero-mean SAD | Σ\|（I−μ_I）−（T−μ_T）\| |
| Locally scaled SAD | Σ\|I/σ_I − T/σ_T\| |
| NCC | Σ(I−μ_I)(T−μ_T) / (N·σ_I·σ_T) |

## 立体块匹配（Stereo Block Matching）

### 算法

```
对每个左图像素 (x, y):
  1. 取以 (x,y) 为中心的 W×W 窗口
  2. 沿右图同一扫描线（y 行）滑动窗口
  3. 计算每个位移 d 的匹配代价（SSD 或 NCC）
  4. 取代价最小（SSD）或最大（NCC）的位移作为视差 d(x,y)
  5. 深度 Z(x,y) = Bf / d(x,y)
```

### 窗口大小的权衡

| | 小窗口 (W=3) | 大窗口 (W=20) |
|---|---|---|
| 优点 | 更多细节 | 更平滑的视差图 |
| 缺点 | 更多噪声 | 丢失细节；边界处失败 |

### 块匹配失败的场景

| 场景 | 原因 |
|------|------|
| **无纹理区域** | 所有窗口内容相似，无法区分 |
| **重复纹理** | 多个位置给出相似的匹配代价 |
| **镜面反射** | 左右图中反射不一致 |

## 能量最小化改进

块匹配结果有太多不连续。假设：**深度应平滑变化**。

### 能量函数

```
E(d) = Σ_p E_data(p, d_p) + λ · Σ_{(p,q)∈N} E_smooth(d_p, d_q)
```

| 项 | 含义 | 具体形式 |
|----|------|---------|
| 数据项 E_data | 希望每个像素找到好的匹配 | SSD(I(x,y), J(x+d,y)) |
| 平滑项 E_smooth | 相邻像素的视差应接近 | L1: \|d_p − d_q\| 或 Potts: [d_p ≠ d_q] |

### 邻域定义

| 类型 | 邻居数 |
|------|--------|
| 4-连通 | 上下左右 |
| 8-连通 | 上下左右 + 四个对角 |

### 优化方法

| 方法 | 思路 | 效果 |
|------|------|------|
| **动态规划(DP)** | 每条扫描线独立求解最优视差 | 中等（扫描线间不连续） |
| **图割(Graph Cut)** | 全局能量最小化 | 最佳（平滑且保留边缘） |

> [!tip] 效果对比
> 仅块匹配 → 噪声多、不连续
> 块匹配+平滑(Graph Cut) → 接近真值(Ground Truth)

## 结构光（Structured Light）

用受控光源替代"被动"匹配，简化对应问题。

### 两种配置

```
配置一：结构光 + 两个相机
  ┌──激光/投影仪──┐
  │               │
  相机I         相机J
  → 激光点提供确定的对应

配置二：结构光 + 一个相机
  投影仪（充当"反向相机"）+ 相机
  → 投影仪替代第二个相机
  → 已知投影图案 = 已知一侧的"图像"
```

> [!tip] 实例：数字米开朗基罗项目
> 斯坦福大学用激光扫描仪对米开朗基罗雕塑进行高精度 3D 重建。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "视差与深度的关系" | **反比**：d = Bf/Z |
| "为什么要立体校正" | 使对极线水平 → 匹配从 2D 降为 **1D** 搜索 |
| "平行相机的对极点" | 在**无穷远**，对极线全部水平 |
| "哪种匹配方法最鲁棒" | **NCC**（不变于亮度和对比度变化） |
| "SSD vs NCC" | SSD 更快但受亮度影响；NCC 更慢但更鲁棒 |
| "大窗口的问题" | 平滑但丢失细节，**边界处失败** |
| "块匹配什么时候失败" | 无纹理、重复纹理、镜面反射 |
| "能量函数两项" | 数据项（匹配质量）+ 平滑项（相邻视差接近） |
| "结构光的优势" | 主动光源简化对应匹配问题 |
| "投影仪的角色" | 充当"**反向相机**" |

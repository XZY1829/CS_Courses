# Harris 角点检测（★★★）

#prcv #harris-corner #feature-detection #structure-tensor

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 角点定义 | 小窗口在**任意方向**移动都产生显著强度变化 |
| 结构张量 M | M = Σ w(x,y)·[Ix²  IxIy; IxIy  Iy²]；梯度分布的协方差矩阵 |
| 特征值解读 | λ₁≈λ₂大→角点；λ₁>>λ₂→边缘；两个都小→平坦 |
| Harris 响应 R | R = det(M) − κ·tr(M)² = λ₁λ₂ − κ(λ₁+λ₂)²；避免显式求特征值 |
| κ 经验值 | 通常取 **0.04-0.06** |
| 不变性 | ✓ 旋转不变 ✓ 亮度平移不变 △ 亮度缩放部分不变 ✗ **尺度不变** |
| 多尺度检测 | 在金字塔每层计算特征响应 → 位置+尺度的联合极大值 |
| 特征尺度 | LoG/DoG 响应峰值对应 blob 的**特征尺度** |

## 为什么检测角点？

角点是图像中**高度可辨识的局部特征**，广泛用于：
- 图像对齐 / 单应性估计
- 3D 重建 / 运动追踪
- 物体识别 / 位置识别
- 机器人导航

> [!tip] 为什么选角点而非边缘？
> 边缘沿边缘方向无法唯一定位（滑动模糊性），角点在**所有方向**都可定位。

## 角点直觉（Moravec 1980）

在图像上取小窗口，向各方向滑动：

| 区域类型 | 滑动效果 | 窗口内强度变化 |
|---------|---------|--------------|
| **平坦** | 任何方向滑动都无变化 | E ≈ 0 所有方向 |
| **边缘** | 沿边缘方向无变化，垂直方向有变化 | 一个方向 E 大 |
| **角点** | **任何方向**滑动都有显著变化 | **所有方向** E 大 |

## 数学推导

### 误差函数

窗口移动 [u,v] 后的强度变化：

```
E(u,v) = Σ w(x,y) · [I(x+u, y+v) − I(x,y)]²
```

w(x,y) 为窗口函数（可为方形或高斯加权）。

### Taylor 展开近似

对 I(x+u,y+v) 做一阶 Taylor 展开（小位移近似）：

```
E(u,v) ≈ [u,v] · M · [u;v]
```

其中 **M** 是 **结构张量（Structure Tensor / Second Moment Matrix）**：

```
M = Σ w(x,y) · [Ix²    IxIy]
                [IxIy   Iy² ]
```

### 结构张量的几何意义

M 是梯度分布的（加权）**协方差矩阵**。对 M 做特征值分解：

```
M = R [λ₁  0 ] R^T
      [0   λ₂]
```

- **特征值** λ₁, λ₂：椭圆轴长的**倒数平方**（1/√λ）
- **特征向量**：椭圆轴**方向**
- λ_max 方向 = 变化最快的方向
- λ_min 方向 = 变化最慢的方向

### 特征值分类

```
        λ₂
         ↑
    边缘  │  角点
  (λ₁>>λ₂)│ (λ₁≈λ₂, 都大)
  ─────────┼─────────→ λ₁
    平坦   │  边缘
  (两个小) │ (λ₂>>λ₁)
```

## Harris 角点响应函数

直接计算特征值较慢。Harris 提出用 **det** 和 **trace** 代替：

```
R = det(M) − κ · [tr(M)]²
  = λ₁·λ₂ − κ·(λ₁+λ₂)²
```

| R 的值 | 含义 |
|--------|------|
| R >> 0 | **角点**（两个特征值都大） |
| R << 0 | **边缘**（一个大一个小，乘积远小于平方和） |
| \|R\| ≈ 0 | **平坦区域** |

> [!important] κ 的典型值
> κ = **0.04 ~ 0.06**（经验值）。κ 越大，角点检测越保守。

### Harris 检测器完整流程

```
1. 计算图像梯度 Ix, Iy
2. 计算 M 的各元素：Ix², Iy², IxIy
3. 对各元素做高斯加权平均（窗口函数 w）
4. 计算 R = det(M) − κ·tr(M)²
5. 对 R 做阈值化 + 非极大值抑制（NMS）→ 角点位置
```

## Harris 不变性分析

| 变换 | Harris 是否不变 | 原因 |
|------|----------------|------|
| **旋转** | ✓ 不变 | 椭圆旋转但形状（特征值）不变 |
| **亮度平移** I→I+b | ✓ 不变 | 梯度 = 导数，常数平移不影响导数 |
| **亮度缩放** I→aI | △ 部分不变 | 梯度缩放 → R 缩放 → 阈值需调整 |
| **尺度变化** | ✗ **不不变** | 放大后角点可能变成边缘！ |

> [!warning] 尺度不变性缺失
> 同一结构在不同尺度下可能被分类为不同类型（角点↔边缘）。这是 Harris 检测器最大的局限。

## 多尺度检测

### 目标

使特征检测器**尺度不变**：同一特征在不同大小的图像中都能被检测到。

### 核心思想

在**位置+尺度**的联合空间中寻找极大值：
- 位置 (x,y)：空间极大值
- 尺度 σ：跨尺度极大值

### Blob 检测与 LoG

**Laplacian of Gaussian (LoG)** 在特征的**特征尺度**处产生峰值响应。

```
特征尺度 = 滤波器尺度与特征大小匹配时的 σ
```

### 实现

```
对高斯金字塔的每层：
  计算特征响应（如 Harris + LoG）
对高斯金字塔的每层：
  if 该点是局部极大值 AND 跨尺度极大值：
    保存 (位置, 尺度) 作为特征点
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "结构张量是什么" | 梯度分布的加权协方差矩阵 M |
| "λ₁≈λ₂ 且都大" | **角点** |
| "λ₁>>λ₂" | **边缘** |
| "R 的公式" | det(M) − κ·tr(M)² |
| "κ 典型值" | 0.04-0.06 |
| "Harris 对旋转不变吗" | ✓ 不变（椭圆旋转但特征值不变） |
| "Harris 对尺度不变吗" | ✗ 不不变（需要多尺度检测） |
| "特征尺度" | LoG 响应峰值对应的 σ |
| "为何用 R 而非直接求特征值" | R 用 det 和 trace 计算更高效（避免求特征值） |
| "窗口函数选高斯还是方形" | **高斯**更好（平滑加权，旋转不变性更好） |

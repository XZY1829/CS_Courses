# 决策方法与判别函数（★★★）

#prcv #decision #probability

## 概览表（一目了然）

| 决策方式 | 方法 | 输出 |
|----------|------|------|
| 点估计决策 | argmax p(y=i\|x; θ) | 确定的类别 |
| 贝叶斯决策 | 计算预测分布 | 分布（期望+方差） |

## 决策/预测

当推理（inference）完成后，给定输入 x：

- **点估计**：根据参数得到后验 p(y|x; θ)，选择概率最大的类别
- **贝叶斯决策**：输出也是随机变量，称为**预测分布（predictive distribution）**
  - 结果根据期望决定，同时可以给出方差（不确定性度量）

## 点估计下的决策

在 0-1 风险（0-1 loss）下：

```
ŷ = argmax p(y=i|x; θ)
       i
```

### 判别函数的三种等价形式

| 形式 | 公式 | 说明 |
|------|------|------|
| 后验形式 | gᵢ(x) = p(y=i\|x; θ) | 后验概率 |
| 联合形式 | gᵢ(x) = p(x\|y=i; θ)p(y=i) | 省略分母 p(x)，不影响 argmax |
| 对数形式 | gᵢ(x) = ln p(x\|y=i; θ) + ln p(y=i) | 对数变换，方便计算 |

> [!tip] 为什么可以省略 p(x)？
> 因为 p(x) 对所有类别 i 相同，不影响 argmax 的结果。

## 高斯条件下的判别函数

**假设**：p(x|y=i) = N(μᵢ, Σ)（各类高斯分布，协方差矩阵相同），先验 p(y=1) = p(y=2) = 0.5

### 简化推导

将高斯代入对数判别函数：

```
gᵢ(x) = ln p(x|y=i) + ln p(y=i)
       = −(1/2)(x−μᵢ)ᵀΣ⁻¹(x−μᵢ) + const
```

两类分类的**单判别函数**：

```
g(x) = g₁(x) − g₂(x)
     = (μ₁−μ₂)ᵀΣ⁻¹x − (1/2)(μ₁ᵀΣ⁻¹μ₁ − μ₂ᵀΣ⁻¹μ₂)
     ∝ wᵀx + b
```

其中 w = Σ⁻¹(μ₁−μ₂)

> [!important] 与 FLD 的关系
> 高斯等协方差条件下的贝叶斯最优判别方向 w = Σ⁻¹(μ₁−μ₂)，与 FLD 的解 w = Sᵥ⁻¹(μ₂−μ₁) 形式一致（方向相同）。说明 FLD 在高斯等协方差假设下是贝叶斯最优的。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "0-1 风险下的最优决策" | **选后验概率最大的类** |
| "判别函数省略 p(x) 可以吗" | **可以**，p(x) 对所有类相同 |
| "高斯等协方差+等先验的判别函数" | **线性判别函数** w = Σ⁻¹(μ₁−μ₂) |
| "此时与 FLD 什么关系" | **等价**（方向一致） |
| "贝叶斯决策输出什么" | **预测分布**（含期望和方差） |
| "预测分布 vs 点估计" | 预测分布给出**不确定性**信息 |

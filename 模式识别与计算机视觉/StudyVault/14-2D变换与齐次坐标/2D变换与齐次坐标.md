## 齐次坐标（Homogeneous Coordinates）

### 为什么需要齐次坐标？

平移 (x',y') = (x+tx, y+ty) **无法**用 2×2 矩阵乘法表示（加法不是线性变换）。

齐次坐标通过升维解决：在 3×3 矩阵框架下统一表示所有 2D 变换。

### 定义

```
异构坐标 (x, y) → 齐次坐标 (x, y, 1)
```

关键性质：**尺度不变** — (x,y,w) 和 (kx,ky,kw) 表示同一点。

```
齐次 → 异构：(X, Y, W) → (X/W, Y/W)  （除以第三个分量）
异构 → 齐次：(x, y) → (x, y, 1)       （追加 1）
```

> [!important] 特殊情况
> - **(x, y, 0)**：**无穷远点**，表示一个方向而非位置
> - **(0, 0, 0)**：未定义

## 2D 变换层次

### 从简到繁

| 变换 | 矩阵形式 | DOF | 保持性质 |
|------|---------|-----|---------|
| **平移** | `[1,0,tx; 0,1,ty; 0,0,1]` | **2** | 方向、长度、角度、平行 |
| **刚体/欧几里得** | `[cosθ,-sinθ,tx; sinθ,cosθ,ty; 0,0,1]` | **3** | 长度、角度、平行 |
| **相似** | `[s·cosθ,-s·sinθ,tx; s·sinθ,s·cosθ,ty; 0,0,1]` | **4** | 角度、平行、比例 |
| **仿射** | `[a,b,tx; c,d,ty; 0,0,1]` | **6** | 直线、**平行线**、面积比 |
| **射影(单应)** | `[a,b,c; d,e,f; g,h,1]` | **8** | 仅直线（共线性） |

> [!tip] DOF 记忆
> 平移(2) → +旋转=刚体(3) → +缩放=相似(4) → +剪切=仿射(6) → +透视=射影(8)

### 仿射变换的性质

- **直线映射为直线** ✓
- **平行线映射为平行线** ✓
- **比例保持** ✓（线段上点的比例不变）
- 原点**不一定映射到原点**
- 仿射变换的复合**仍是仿射变换**

> [!important] 仿射 = 线性(4DOF) + 平移(2DOF)
> 齐次矩阵的最后一行**永远是 [0,0,1]** → w 坐标不变 → 不会产生透视效果。

### 射影变换（单应）的性质

- **直线映射为直线** ✓
- **平行线不一定平行** ✗
- **比例不一定保持** ✗
- 最后一行**不是 [0,0,1]** → w 坐标改变 → 产生**透视效果**
- 射影变换的复合**仍是射影变换**

## 矩阵组合（Composition）

变换可通过**矩阵乘法**组合：

```
p' = T · R · S · p
```

> [!warning] 乘法顺序很重要！
> 矩阵乘法不满足交换律。上式先缩放(S)，再旋转(R)，最后平移(T)。
> 从右向左读：先作用 S，再 R，再 T。

## 求解未知仿射变换

### 问题设置

给定 n 对点对应 (xᵢ, yᵢ) → (x'ᵢ, y'ᵢ)，求 6 个仿射参数。

### 每个点提供几个方程？

每对点对应给出 **2 个方程**（x' 和 y' 各一个）：

```
x'ᵢ = a·xᵢ + b·yᵢ + tx
y'ᵢ = c·xᵢ + d·yᵢ + ty
```

### 最少需要几对点？

6 未知数 / 2 方程/点 = **3 对点**。

### 线性最小二乘解

向量化参数 θ = [a,b,tx,c,d,ty]^T，构建系统 Aθ = b'：

```
min ‖Aθ − b'‖²  →  θ = (A^TA)^{-1} A^T b'
```

> [!tip] 为什么仿射可用普通最小二乘？
> 仿射变换是参数的**线性函数**（x' 是 a,b,tx 的线性组合）。射影变换不是线性的（因为除以 w），需要不同的求解方法（→ DLT/SVD）。

> [!warning] 最小二乘的局限
> (1) 只在变换是**线性**时适用 → 仿射 ✓，射影 ✗
> (2) 对 **outlier 极度敏感**（平方误差放大异常值）→ 需要 RANSAC

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "平移无法用 2×2 矩阵" | 需要**齐次坐标**（3×3） |
| "齐次坐标尺度不变" | (kx,ky,kw) 与 (x,y,w) 表示同一点 |
| "仿射 DOF" | **6**（4 线性 + 2 平移） |
| "射影 DOF" | **8**（3×3 矩阵 9 元素 − 1 尺度） |
| "仿射最少几对点" | **3 对**（6 方程 6 未知） |
| "射影最少几对点" | **4 对**（8 方程 8 未知） |
| "仿射保持平行线" | ✓ |
| "射影保持平行线" | ✗ |
| "矩阵乘法顺序" | **从右到左**作用 |
| "最小二乘公式" | θ = (A^TA)^{-1}A^Tb |
| "最后一行 [0,0,1]" | **仿射**（w 不变） |
| "最后一行不是 [0,0,1]" | **射影/单应** |

# 概率方法与统计框架（★★★）

#prcv #probability #inference

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 核心工具 | 贝叶斯定理 p(y\|x) = p(x\|y)p(y) / p(x) |
| 参数估计 | 假设 PDF 服从某种函数形式，估计其参数 |
| 非参数估计 | 不假设函数形式，直接从数据估计密度 |
| 生成模型 | 估计 p(x\|y) 和 p(x)，再求后验 |
| 判别模型 | 直接估计 p(y\|x) |

## 概率方法 vs 非概率方法

| 类型 | 代表方法 |
|------|----------|
| **非概率** | SVM、FLD、最近邻、神经网络、决策树 |
| **概率** | 贝叶斯分类器、逻辑回归、HMM、深度生成模型 |

概率方法的优势：
- 处理**不确定性**
- 灵活表达复杂关系
- 结合**先验知识**
- 模型可解释、可扩展
- 处理缺失数据与部分观测

## 统计学关键概念

| 术语 | 符号 | 含义 |
|------|------|------|
| 数据分布 | p(X) | 数据本身的分布 |
| 先验分布 | p(Y) | 不依赖数据的类别先验 |
| 联合分布 | p(X, Y) | 数据和标签的联合 |
| 类条件分布 | p(X\|y=i) | 给定类别后数据的分布 |
| 后验分布 | p(y=i\|x) | 给定数据后对类别的判断 |

> [!important] "先验" 的特殊含义
> a priori = "不依赖特定经验即可知的"。在统计中 prior distribution 有特定含义，不可滥用。

## 参数估计 vs 非参数估计

| | 参数估计 | 非参数估计 |
|---|----------|------------|
| 假设 | PDF 服从已知函数形式（如高斯） | 不假设函数形式 |
| 参数数目 | 有限个 | 可以无穷多 |
| 估计对象 | 参数值 | 空间中任意点的密度 |
| 例子 | MLE, MAP, Bayes | 直方图, KDE |

> [!warning] "非参数" ≠ "无参数"
> 非参数估计实际上允许无穷多参数，而参数估计的参数数目有限。更准确的说法是"非参数化估计"。

## 生成模型 vs 判别模型

```
生成模型（Generative）：
  估计 p(x|y=i), p(x) → 贝叶斯定理 → p(y=i|x)

判别模型（Discriminative）：
  直接估计 p(y=i|x)
```

| | 生成模型 | 判别模型 |
|---|----------|----------|
| 估计对象 | p(x\|y) 类条件 + p(y) 先验 | p(y\|x) 后验 |
| 优势 | 可生成新样本、处理缺失数据 | 分类准确率通常更高 |
| 例子 | 朴素贝叶斯、GMM | 逻辑回归、SVM |

## 推理与决策两阶段

```
推理（Inference）          决策（Decision）
估计各种密度函数    →    根据 PDF 对输入 x 给出输出
```

## 考试/测试常见模式

| 场景/关键词            | 答案                         |
| ----------------- | -------------------------- |
| "p(y=i\|x) 是什么分布" | **后验分布**                   |
| "p(x\|y=i) 是什么分布" | **类条件分布**                  |
| "先估计类条件再用贝叶斯"     | **生成模型**                   |
| "直接估计后验"          | **判别模型**                   |
| "非参数估计有参数吗"       | 有，允许**无穷多**参数              |
| "概率方法的两步骤"        | **推理**（估计密度）+ **决策**（给出输出） |

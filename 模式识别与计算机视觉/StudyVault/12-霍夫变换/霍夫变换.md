# 霍夫变换（★★★）

#prcv #hough-transform #line-detection #parameter-space

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 核心思想 | 边缘点在参数空间中**投票**，峰值对应检测到的几何模型 |
| 直线参数化 | 法线形式 ρ = x·cosθ + y·sinθ（θ∈[0,180°], ρ 有界） |
| 点→线 | 图像空间一点 → 参数空间一条**正弦曲线** |
| 线→点 | 图像空间共线点 → 参数空间正弦曲线交于**同一点** |
| 累加器 | (θ, ρ) 离散化网格，统计投票数 |
| 圆检测 | 已知半径: 2D 参数 (a,b)，点映射为圆；未知半径: 3D 参数 (a,b,r) |
| 梯度优化 | 已知梯度方向 → 仅需在一个点投票（大幅减少计算） |
| 优缺点 | ✓ 抗遮挡、多实例、鲁棒 ✗ 高维参数空间计算量大 |

## 背景：边缘检测后的线段拟合

边缘检测 → 得到边缘点集合，但：
- 边缘可能**不连续**（遮挡、噪声）
- 存在**杂散点**（outliers）
- 同一图像中可能有**多条**线

> [!tip] 为什么不用最小二乘拟合？
> 最小二乘 (1) 只能拟合一个模型（多线混合时失败），(2) 对 outlier 极度敏感（平方误差放大），(3) y=mx+b 参数化无法表示垂直线（m→∞）。

## 直线参数化

### 斜截式 y = mx + b 的问题

- 无法表示**垂直线**（m = ∞）
- 参数空间 (m, b) **无界**

### 法线形式（Normal Form）

```
ρ = x·cosθ + y·sinθ
```

| 参数 | 含义 | 范围 |
|------|------|------|
| ρ | 原点到直线的**垂直距离**（有符号） | 有界（≤图像对角线） |
| θ | 法线与 x 轴的**夹角** | [0°, 180°) |

> [!important] 法线形式的优势
> - 参数空间 (θ, ρ) **有界** → 累加器数组大小可控
> - 可以表示**任意方向**的直线（包括垂直线）
> - 每条直线**唯一对应**一个 (θ, ρ) 对（θ∈[0,180°) 时）

## 霍夫变换核心思想

**边缘点在参数空间中投票，票数最多的位置即为检测到的直线参数。**

### 图像空间 ↔ 参数空间的对偶关系

| 图像空间 | 参数空间 |
|---------|---------|
| 一个**点** (x₀, y₀) | 一条**正弦曲线** ρ = x₀cosθ + y₀sinθ |
| 一条**直线** | 一个**峰值点** (θ₀, ρ₀) |
| **共线**的多个点 | 多条正弦曲线交于**同一点** |

### 算法流程

```
1. 量化参数空间 (θ, ρ) → 创建累加器数组 H[θ][ρ]，初始化为 0
2. 对每个边缘点 (x, y)：
     对 θ = 0° 到 180°：
       ρ = x·cosθ + y·sinθ
       H[θ][ρ] += 1
3. 找 H 中的局部极大值 → 对应检测到的直线
4. 从 (θ, ρ) 恢复直线方程
```

> [!warning] 坐标系注意
> 图像坐标原点在**左上角**！向下为 y 正方向。ρ 可以为负值（表示法线方向翻转）。同一条直线有两种 (θ, ρ) 表示：(θ, ρ) 和 (θ+180°, −ρ)。

## 噪声对霍夫变换的影响

| 噪声类型 | 效果 |
|---------|------|
| **测量噪声**（边缘位置不准） | 正确 bin 的票数↓（投票分散） |
| **杂散噪声点** | 错误 bin 的票数↑（产生假峰值） |

> [!tip] 应对噪声
> - 增加边缘点数量（更多投票超越噪声）
> - 累加器做平滑（容忍量化误差）
> - 设置合理阈值

## 霍夫圆检测（Hough Circles）

### 已知半径 r

参数空间 2D：圆心 (a, b)。

```
(x−a)² + (y−b)² = r²
```

图像中一点 (x₀, y₀) → 参数空间中以 (x₀, y₀) 为圆心、半径 r 的**圆**。

### 未知半径

参数空间 3D：(a, b, r) → 累加器变为**三维数组**，计算量大幅增加。

### 梯度信息优化

若已知边缘点的**梯度方向**（即法线方向），圆心必在梯度方向上 → 每个边缘点只需在**一个方向**投票（而非整个圆）→ **大幅减少计算**。

## 霍夫变换的性质

| 属性 | 评价 |
|------|------|
| 抗遮挡 | ✓ 线段不完整也能检测 |
| 多实例 | ✓ 同时检测多条线/圆 |
| 鲁棒性 | ✓ 对噪声和 outlier 有一定容忍 |
| 计算复杂度 | ✗ 参数维度增加时指数增长 |
| 量化精度 | ✗ 参数量化过粗则定位不准，过细则累加器稀疏 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "为什么不用 y=mx+b" | m→∞ 时无法表示垂直线；参数空间无界 |
| "点在参数空间的映射" | 正弦曲线 ρ = x₀cosθ + y₀sinθ |
| "共线点在参数空间" | 正弦曲线**交于同一点** |
| "累加器峰值含义" | 对应一条被检测到的直线 |
| "已知半径圆检测维度" | **2D**（圆心 a,b） |
| "未知半径圆检测维度" | **3D**（a,b,r）→ 计算量大 |
| "梯度优化圆检测" | 只在梯度方向投票 → 每点仅 1 票 |
| "霍夫变换优势" | 抗遮挡+多实例+鲁棒 |
| "霍夫变换劣势" | 高维参数空间计算量指数增长 |

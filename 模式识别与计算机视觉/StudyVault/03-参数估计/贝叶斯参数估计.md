# 贝叶斯参数估计（★★★）

#prcv #estimation #bayesian

## 概览表（一目了然）

| 条目     | 要点                         |
| ------ | -------------------------- |
| 核心区别   | 输出是完整的分布 p(θ\|D)，而非一个点     |
| θ 的身份  | 随机变量（有自己的分布）               |
| 高斯估计结果 | 后验均值 = 先验均值和 MLE 的**加权组合** |
| 共轭先验   | 使后验与先验函数形式相同               |

## 贝叶斯 vs 点估计

| | MLE | MAP | 贝叶斯 |
|---|-----|-----|--------|
| θ 的性质 | 固定常数 | 有先验的变量 | **随机变量** |
| 输出 | 一个值 θ* | 一个值 θ* | **完整分布 p(θ\|D)** |
| 目标 | 最大化似然 | 最大化后验 | 计算后验分布 |

## 高斯均值的贝叶斯估计

**设定**：x ~ N(μ, σ²)，σ 已知，估计 μ

- **先验**：p(μ) = N(μ₀, σ₀²)，μ₀ 和 σ₀² 已知
- **贝叶斯定理**：

```
p(μ|D) = α · p(D|μ) · p(μ) = α · ∏ p(xᵢ|μ) · p(μ)
```

- **结果**：p(μ|D) = N(μₙ, σₙ²)

### 后验均值

```
μₙ = [σ² / (nσ₀² + σ²)] · μ₀ + [nσ₀² / (nσ₀² + σ²)] · μ_ML
```

- μ_ML = (1/n)Σxᵢ（MLE 估计值）
- **μₙ 是先验均值 μ₀ 和 MLE 估计值 μ_ML 的加权组合**

### 后验方差

```
1/σₙ² = 1/σ₀² + n/σ²

σₙ² = σ₀² · σ²/(σ² + nσ₀²)
```

> [!important] 关键性质
> - n → 0 时：μₙ → μ₀（先验主导）
> - n → ∞ 时：μₙ → μ_ML（数据主导），σₙ² → 0（完全确定）
> - σₙ² 随 n 增大而**单调递减**

## 共轭先验（Conjugate Prior）

- 若似然 p(x|θ) 存在先验 p(θ)，使得后验 p(θ|D) 和 p(θ) 有**相同函数形式**
- 大大简化推导和计算

| 似然分布 | 共轭先验 |
|----------|----------|
| 高斯 | **高斯** |
| 伯努利/二项 | **Beta** |
| 多项式 | **Dirichlet** |
| 泊松 | **Gamma** |

## 贝叶斯方法的优缺点

| 优点 | 缺点 |
|------|------|
| 理论完备，数学优美 | 推导困难（任意分布的共轭？） |
| 给出完整的不确定性信息 | 计算量极大（需要很多积分） |
| 自然融合先验知识 | 数据多时效果常不如判别函数 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "贝叶斯估计输出什么" | 完整的**后验分布** p(θ\|D) |
| "μₙ 和 μ₀、μ_ML 的关系" | **加权组合**（先验和数据的综合） |
| "n→∞ 时贝叶斯估计结果" | μₙ → μ_ML，σₙ² → 0 |
| "高斯分布的共轭先验" | **高斯分布** |
| "什么是共轭先验" | 使后验和先验**函数形式相同**的先验 |
| "贝叶斯方法最大缺点" | 计算量大（积分困难） |

# 点估计方法：MLE 与 MAP（★★★）

#prcv #estimation #parametric

## 概览表（一目了然）

| 方法 | 公式 | 对 θ 的看法 | 输出 |
|------|------|-------------|------|
| MLE | argmax ℓℓ(θ) | 固定未知常数 | 一个点 θ* |
| MAP | argmax ℓ(θ)p(θ) | 有先验分布的变量 | 一个点 θ* |
| 贝叶斯估计 | 计算 p(θ\|D) | 随机变量 | 完整分布 |

## 似然函数

- **似然函数**：ℓ(θ) = p(D|θ) = ∏ᵢ p(xᵢ|θ)
- 注意：p(D|θ) **不是条件分布**，θ 不是随机变量！
  - D 固定，θ 是变量 → ℓ(θ) 是 θ 的函数，不是 PDF
  - 写成 p(xᵢ|θ) 只是习惯，表示分布依赖于参数 θ

- **对数似然函数**：ℓℓ(θ) = ln p(D|θ) = Σᵢ ln p(xᵢ|θ)

> [!warning] 易混淆
> p(D|θ) 中的 "|" 不表示条件概率，因为 θ 不是随机变量。这只是表示分布依赖于参数值。

## 最大似然估计（MLE）

```
θ* = argmax ℓℓ(θ) = argmax Σᵢ ln p(xᵢ|θ)
              θ                θ
```

- 高斯分布的 MLE：对 ℓℓ(θ) 关于 (μ, Σ) 求导令为零
- 直觉：选择使观测数据出现概率最大的参数

## 最大后验估计（MAP）

```
θ* = argmax ℓ(θ) · p(θ)
        θ
```

- 相比 MLE 多考虑了参数自身的先验分布 p(θ)

**MAP 与 MLE 的关系**：
- 当 p(θ) = const（noninformative prior）时，MAP 等价于 MLE
- 离散均匀：p(θ) = 1/N
- 有限区间 [a,b] 连续均匀：p(θ) = 1/(b−a)
- (−∞,+∞) 上：p(θ) = const → **improper prior**

## MAP 与正则化

| 先验分布 | 对应正则化 | 回归名称 |
|----------|------------|----------|
| 高斯分布 p(θ) ∝ exp(−θ²/2σ²) | **L2 正则化** | Ridge 回归 |
| 拉普拉斯分布 p(θ) ∝ exp(−\|θ\|/b) | **L1 正则化** | Lasso 回归 |

> [!tip] 核心联系
> MAP = MLE + 正则化项。先验分布的选择决定了正则化的类型。

## 估计量的性质

| 性质 | 含义 |
|------|------|
| 一致性（consistency） | n → ∞ 时估计量依概率收敛到真值 |
| 无偏性（unbiased） | 估计量的期望等于被估计量的真值 |

- 样例越多，估计越准
- 只有一个样本时，估计很不可靠
- 一致性和无偏性是不同的概念

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "p(D\|θ) 是条件分布吗" | **不是**，θ 不是随机变量，是似然函数 |
| "noninformative prior 时 MAP 等于" | **MLE** |
| "高斯先验对应什么正则化" | **L2 正则化**（Ridge） |
| "拉普拉斯先验对应什么正则化" | **L1 正则化**（Lasso） |
| "MLE 和 MAP 输出什么" | 一个**点**（点估计） |
| "估计量的期望=真值" | **无偏估计** |
| "n→∞ 收敛到真值" | **一致性** |

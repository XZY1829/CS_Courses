## Part I：模式识别基础

### FLD 线性判别 → [[FLD原理与求解]]

| 概念 | 公式/要点 |
|------|----------|
| 目标函数 | J(w) = w^T S_B w / w^T S_W w |
| 最优投影 | w = S_W^{-1}(μ₁−μ₂) |
| 多类 FLD | 广义特征值问题 S_B w = λ S_W w |

### 概率推理 → [[概率方法与统计框架]]

| 概念 | 公式/要点 |
|------|----------|
| 贝叶斯公式 | P(ω|x) = P(x|ω)P(ω)/P(x) |
| MAP 决策 | 选择使后验最大的类 |
| 贝叶斯风险 | R = Σ λ(α_i|ω_j)P(ω_j|x) |

### 参数估计 → [[点估计方法]]、[[贝叶斯参数估计]]

| 概念 | 公式/要点 |
|------|----------|
| MLE | θ_ML = argmax Π P(x_i|θ) |
| MAP 估计 | θ_MAP = argmax P(θ|D) ∝ P(D|θ)P(θ) |
| MAP = 正则化 | 高斯先验→L2正则化 |

### 距离度量 → [[度量范数与距离]]

| 概念 | 公式/要点 |
|------|----------|
| Lp 范数 | ‖x‖_p = (Σ|x_i|^p)^{1/p} |
| Mahalanobis | d = √((x−μ)^T Σ^{-1} (x−μ)) |
| 余弦相似度 | cos(θ) = x^T y / (‖x‖‖y‖) |

## Part II：图像处理基础

### 图像滤波 → [[图像滤波与卷积]]

| 概念 | 公式/要点 |
|------|----------|
| 2D 卷积 | g[m,n] = Σ_i Σ_j f[m-i,n-j]·h[i,j] |
| 可分离判断 | 核矩阵**秩=1** → 可分解为行×列 |
| 复杂度 | 非可分离 O(M²N²) → 可分离 O(2NM²) |
| 3×3 高斯核 | (1/16)·[1,2,1; 2,4,2; 1,2,1] |
| 锐化 | 2×原图 − 模糊图 |

### 图像梯度 → [[图像梯度与边缘检测]]

| 概念 | 公式/要点 |
|------|----------|
| 中心差分核 | [-1, 0, 1] |
| 水平 Sobel | [1,0,-1; 2,0,-2; 1,0,-1] = [1;2;1]×[1,0,-1] |
| 梯度幅值 | \|∇f\| = √(Ix² + Iy²) |
| 梯度方向 | θ = atan2(Iy, Ix)，**垂直于边缘** |

### 采样与金字塔 → [[采样混叠与图像金字塔]]

| 概念 | 公式/要点 |
|------|----------|
| Nyquist 定理 | f_s ≥ 2·f_max（避免混叠） |
| 高斯金字塔 | 模糊→下采样→重复 |
| 金字塔总大小 | 原图的 **4/3** 倍 |
| 拉普拉斯金字塔 | 存残差 = 原图−模糊图，**可逆** |

### 频域分析 → [[傅里叶变换与频域滤波]]

| 概念 | 公式/要点 |
|------|----------|
| 傅里叶变换 | F(ω) = ∫f(x)·e^{-iωx}dx |
| 欧拉公式 | e^{iθ} = cosθ + i·sinθ |
| **卷积定理** | **空域卷积 = 频域乘法** |
| 零频率 | DC 分量 = 图像均值 |
| 相位 > 幅度 | 相位对视觉感知更重要 |

## Part III：特征检测与拟合

### 霍夫变换 → [[霍夫变换]]

| 概念 | 公式/要点 |
|------|----------|
| 法线形式 | ρ = x·cosθ + y·sinθ |
| 点→参数空间 | 一条正弦曲线 |
| 共线点 | 正弦曲线交于一点 |
| 霍夫圆（已知r） | 2D 参数空间 (a,b) |
| 霍夫圆（未知r） | 3D 参数空间 (a,b,r) |

### Harris 角点检测 → [[Harris角点检测]]

| 概念 | 公式/要点 |
|------|----------|
| 结构张量 M | Σw·[Ix²,IxIy; IxIy,Iy²] |
| Harris 响应 | R = det(M) − k·trace(M)²，k≈0.04-0.06 |
| λ1≈λ2 大 | **角点** |
| λ1>>λ2 | 边缘 |
| 旋转不变 | ✓ |
| 尺度不变 | ✗（需多尺度检测） |

## Part IV：几何变换与相机

### 2D 变换 → [[2D变换与齐次坐标]]

| 变换 | DOF | 保持性质 |
|------|-----|----------|
| 平移 | 2 | 方向、长度、平行 |
| 欧氏 | 3 | 长度、角度、平行 |
| 相似 | 4 | 角度、平行、比例 |
| 仿射 | 6 | 平行线、比例 |
| 射影 | 8 | 直线（不保平行） |

| 概念 | 公式/要点 |
|------|----------|
| 齐次→普通 | (x,y,w) → (x/w, y/w) |
| 无穷远点 | (x,y,0) |

### 单应性 → [[单应性变换与RANSAC]]

| 概念 | 公式/要点 |
|------|----------|
| DLT | Ah=0 → SVD，取 V 最后一列 |
| 最少点数 | **4 对**（每对 2 方程，共 8） |
| RANSAC 迭代 | N = log(1−p)/log(1−(1−e)^s) |
| 适用条件 | 平面/远景/纯旋转 |

### 相机模型 → [[相机模型与标定]]

| 概念 | 公式/要点 |
|------|----------|
| 相机矩阵 | x = PX_w，P = K[R\|t]（3×4） |
| 内参 K | [fx,0,cx; 0,fy,cy; 0,0,1] |
| 标定分解 | SVD 求相机中心；RQ 分解求 K 和 R |
| 径向畸变 | r' = r(1 + k₁r² + k₂r⁴) |

### 双目几何 → [[双目几何与基础矩阵]]

| 概念 | 公式/要点 |
|------|----------|
| 对极约束 | x'^T F x = 0 |
| 本质矩阵 | E = [t]× · R（相机坐标） |
| 基础矩阵 | F = K'^{-T} E K^{-1}（图像坐标） |
| 8 点算法 | 每对 1 方程，SVD + 秩 2 约束 |
| 极线 | l' = Fx，l = F^T x' |

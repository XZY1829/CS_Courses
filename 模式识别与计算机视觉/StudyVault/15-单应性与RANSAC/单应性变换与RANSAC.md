# 单应性变换与 RANSAC（★★★）

#prcv #homography #DLT #RANSAC #image-stitching

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 单应性 | 3×3 射影变换矩阵 H，8 DOF；p' ~ H·p |
| 适用条件 | (1) 场景**平面** (2) 场景很远/深度变化小 (3) **纯旋转**拍摄 |
| DLT 算法 | 每对点 → 2 行方程，4 对点 → 8×9 矩阵 A，SVD 取最小奇异值对应列 |
| 齐次 vs 普通最小二乘 | 仿射: Ax=b（普通 LS）；单应: Ah=0（齐次/总最小二乘，用 SVD） |
| RANSAC | 随机采样→拟合模型→数 inlier→迭代→选最多 inlier 的模型 |
| RANSAC 参数 | s=最少点数(单应=4)，N=迭代次数（由置信度 p 和 outlier 比 e 决定） |
| 对应管线 | 特征检测(Harris) → 特征描述(MOPS/SIFT) → 特征匹配+RANSAC |

## 单应性变换（Homography）

### 定义

3×3 矩阵 H，将图像 1 中的点映射到图像 2：

```
p' ~ H · p     （~ 表示差一个尺度因子）

[x']   [h₁ h₂ h₃] [x]       x' = (h₁x+h₂y+h₃)/(h₇x+h₈y+h₉)
[y'] ~ [h₄ h₅ h₆] [y]  →    y' = (h₄x+h₅y+h₆)/(h₇x+h₈y+h₉)
[w']   [h₇ h₈ h₉] [1]
```

**8 DOF**（9 个元素 − 1 个尺度约束）。

### 何时可以使用单应性？

1. 场景是一个**平面**（如地面、墙壁、文档）
2. 场景**非常远**或深度变化相对很小（近似平面）
3. 相机做**纯旋转**（无平移），此时对任何场景都适用

## DLT（Direct Linear Transform）

### 推导

对每对对应 p = (x,y,1) → p' = (x',y',1)：

```
p' × (H·p) = 0    （叉积为零 ⟺ 同方向）
```

展开并消除尺度因子后，每对点得到 **2 个线性方程**：

```
[-x, -y, -1, 0, 0, 0, x'x, x'y, x'] [h₁]   [0]
[0, 0, 0, -x, -y, -1, y'x, y'y, y'] [...]  = [0]
                                       [h₉]
```

### 求解

n 对点 → 2n×9 矩阵 A，求 **Ah = 0** 的非平凡解：

```
1. 对每对对应构建 2×9 矩阵 Aᵢ
2. 堆叠成 2n×9 矩阵 A
3. 对 A 做 SVD: A = UΣV^T
4. h = V 的最后一列（最小奇异值对应的列）
5. 将 h 重塑为 3×3 矩阵 H
```

> [!important] 齐次最小二乘 vs 普通最小二乘
> | | 仿射变换 | 单应性变换 |
> |---|---------|-----------|
> | 方程形式 | Ax = b | **Ah = 0** |
> | 求解方法 | θ = (A^TA)⁻¹A^Tb | **SVD 最小奇异值** |
> | 约束 | 无 | ‖h‖=1（尺度） |
> | 名称 | 普通最小二乘 | **总最小二乘/齐次最小二乘** |

> [!tip] 为什么单应是齐次方程？
> 因为消除尺度因子后，方程变为 Ah=0 的形式。解不唯一（kh 也是解），需要添加 ‖h‖=1 约束。这正是 SVD 最小奇异值解的含义。

## RANSAC（Random Sample Consensus）

### 动机

DLT + 最小二乘对 **outlier 非常敏感**。实际的特征匹配中总有错误对应。

### 算法

```
重复 N 次：
  1. 随机采样 s 对点对应（单应 s=4）
  2. 用 DLT 计算 H
  3. 对所有对应计算投影误差，统计 inlier 数量
     (inlier: 误差 < 阈值 δ)
  4. 若 inlier 数 > 当前最佳，更新最佳 H

用最佳 H 的所有 inlier 重新计算 H（DLT refine）
```

### 参数选择

| 参数 | 选择方法 |
|------|---------|
| **s**（采样点数） | 拟合模型的**最少点数**（平移=1, 仿射=3, 单应=4） |
| **N**（迭代次数） | N = log(1−p) / log(1−(1−e)^s)，p=置信度(0.99), e=outlier比 |
| **δ**（距离阈值） | 使好点有 95% 概率落在阈值内 |

> [!tip] N 的直觉
> (1−e)^s = 一次采样全是 inlier 的概率。
> 1−(1−e)^s = 至少一个 outlier 的概率。
> [1−(1−e)^s]^N = N 次都没采到全 inlier 的概率 = 1−p。

### 单应估计的 RANSAC 流程

```
RANSAC loop:
  1. 随机取 4 对点
  2. DLT 计算 H
  3. 数 inlier
  4. 保留 inlier 最多的 H
最终用所有 inlier 重新 DLT → 精确 H
```

## 图像对应管线（Image Correspondence Pipeline）

```
1. 特征点检测 ─── Harris 角点检测器
2. 特征点描述 ─── MOPS / SIFT 描述子
3. 特征匹配 + 单应估计 ─── RANSAC + DLT 同时完成
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "单应 DOF" | **8**（9−1 尺度） |
| "单应需几对点" | **4 对**（每对 2 方程 → 8 方程/8 未知） |
| "DLT 用什么分解" | **SVD**，取最小奇异值的右奇异向量 |
| "仿射 vs 单应求解区别" | 仿射 Ax=b 普通 LS；单应 Ah=0 用 SVD |
| "RANSAC 核心思想" | 随机采样+投票，选 inlier 最多的模型 |
| "RANSAC 单应采样几个点" | **4 个**（最少拟合点数） |
| "单应适用条件" | 平面场景 / 纯旋转 / 远景 |
| "为什么不直接最小二乘" | outlier 会严重污染结果 |
| "N 的计算公式" | N = log(1−p)/log(1−(1−e)^s) |
| "RANSAC 最后一步" | 用所有 inlier **重新拟合**（refine） |

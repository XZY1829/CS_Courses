# 稀疏表示与字典学习（★★★）

#prcv #sparse #dictionary-learning

## 概览表（一目了然）

| 概念 | 要点 |
|------|------|
| 稀疏性 | 向量中大部分元素为零 |
| l0 vs l1 | l0 不连续不可微；l1 是凸的、连续的最佳替代 |
| RIP 条件 | l0 与 l1 最小化等价的充分条件 |
| 过完备字典 | 列数 > 行数（k > p），冗余表示 |
| 字典学习 | 同时学习字典 D 和稀疏系数 α |

## 稀疏性的含义

- ‖x‖₀ = 非零元素个数
- 图像（如人脸）在**原始像素空间不稀疏**
- 但在某种更有效的表达方式上是稀疏的：
  - 人脸在光照变化下处于**低维子空间**
  - 监控视频：背景低频、前景高频
  - 语音：语音和噪声处于不同频段

> [!important] "稀疏" 不是指原始数据
> 稀疏性通常指数据在某种**变换/字典表示**下的稀疏性，而非原始空间。

## 稀疏 PCA

### 基本想法

在 PCA 表示 yᵢ = Eᵈᵀ(xᵢ − x̄) 上鼓励稀疏：

```
min  ‖yᵢ − Eᵈᵀ(xᵢ − x̄)‖² + λ‖yᵢ‖₀
 yᵢ
```

### l0 的问题

| 性质 | l0 | l1 |
|------|-----|-----|
| 连续性 | ✗ 不连续 | ✓ 连续 |
| 可微性 | ✗ 不可微 | ✓ 除0外可微 |
| 凸性 | ✗ 非凸 | ✓ 凸函数 |
| 优化难度 | NP-hard | 可高效求解 |

→ **用 l1 替代 l0** 是标准做法

## RIP 条件（受限等距性）

- 测量矩阵 A：m×n，m ≪ n
- s 稀疏信号：‖x‖₀ ≤ s
- 若存在 δₛ ∈ (0,1) 使得对所有 s 稀疏向量 x：

```
(1−δₛ)‖x‖² ≤ ‖Ax‖² ≤ (1+δₛ)‖x‖²
```

则称 A 满足 s 阶 RIP 条件

> [!tip] RIP 的意义
> 当 A 满足 RIP 条件时，**l0 最小化与 l1 最小化等价**。这是压缩感知的理论基础。

## 过完备字典

给定 p×k 矩阵 D，线性表示：x ≈ Dα

| 类型 | 条件 | 特点 |
|------|------|------|
| 欠完备字典 | p > k | 列数少于行数 |
| **过完备字典** | p < k | 列数多于行数，冗余表示 |

### 稀疏编码目标

```
min  ‖xᵢ − Dαᵢ‖² + λ‖αᵢ‖₁
 αᵢ
```

## 人脸识别应用

**场景**：150 人，每人 100 张，分辨率 100×100

```
每张图片 → 向量 p = 10000 维
全部排列 → 字典 D: 10000 × 15000（过完备）
```

### 识别流程

```
测试图像 xᵢ → 求解 min ‖xᵢ − Dαᵢ‖² + λ‖αᵢ‖₁
                      αᵢ
→ 检查 αᵢ 中非零系数集中在哪个 ID → 分类结果
```

**核心假设**：**同 ID 一致性** — 同一人的不同图像可以被该人的训练样本稀疏线性表示

> [!important] 为什么 l1 稀疏可以做识别？
> 非零系数在某个 ID 内明显最多 → 测试图像属于该类。稀疏性确保只有少数训练样本参与表示。

## 字典学习（Dictionary Learning）

- 从数据集中学习字典 D，使所有样本能被字典原子稀疏表示
- 需要**联合优化**字典 D 和系数 α
- 通常采用交替优化：固定 D 更新 α → 固定 α 更新 D

## 应用场景

| 应用 | 方法 |
|------|------|
| 图像压缩 | JPEG 用 DCT 基；学习字典可以更好 |
| 图像去噪/修复 | 学习干净图像的字典，用稀疏表示抑制噪声 |
| 特征提取 | 替代 SIFT 等手工特征 |
| MRI 加速成像 | 压缩感知 + 稀疏字典快速重建 |

## 低秩矩阵（稀疏性的二维推广）

- 向量稀疏 → 矩阵低秩
- **RPCA（鲁棒主成分分析）**：将矩阵分解为低秩部分 + 稀疏部分

```
给定 M = L + S
L: 低秩（如人脸在不同光照下的主要成分）
S: 稀疏（如镜面高光、自阴影）
```

- 应用：人脸图像光照处理（低秩 = 面部特征，稀疏 = 光照异常）

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "l0 为什么不好用" | **不连续、不可微、NP-hard** |
| "l1 替代 l0 的理论基础" | **RIP 条件**下两者等价 |
| "过完备字典的条件" | **p < k**（列数 > 行数） |
| "稀疏人脸识别的核心假设" | **同 ID 一致性** |
| "字典学习优化什么" | **联合优化 D 和 α** |
| "RPCA 分解成什么" | **低秩 + 稀疏** |
| "稀疏性指原始空间吗" | **不是**，指某种变换/字典下的表示 |
| "MAP + 拉普拉斯先验 = ?" | **l1 正则化 = Lasso**（与稀疏相关） |

# 傅里叶变换与频域滤波（★★★）

#prcv #fourier #frequency-domain #convolution-theorem

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 傅里叶级数 | 任何周期信号 = **正弦波的无穷级数和**（不同振幅、频率、相位） |
| 傅里叶变换(FT) | 将信号从空域/时域变换到频域；输出为**复数**（幅值+相位） |
| 卷积定理 | 空域卷积 ⟺ 频域**逐点相乘**（核心！） |
| DFT / FFT | 离散傅里叶变换用矩阵乘法实现，FFT 将 O(N²) 加速到 O(N log N) |
| 幅值 vs 相位 | 相位编码结构/位置信息，幅值编码能量；**相位比幅值重要** |
| 高斯频谱 | 高斯的 FT 仍是高斯（自对偶），**无旁瓣** |
| Box 频谱 | Box 的 FT 是 **sinc**（有旁瓣）→ 振铃伪影 |
| 混合图像 | 近看=高频图 A，远看=低频图 B（人眼对中频最敏感） |

## 傅里叶级数（Fourier Series）

**傅里叶宣称**：加上足够多的正弦波，可以合成**任意周期信号**。

### 正弦波构建块

每个正弦波有三个参数：
- **振幅 A**：波的高度
- **频率 ω**（角频率）：每单位时间/空间的振荡次数
- **相位 φ**：波的起始偏移

```
f(t) = Σ_k A_k · sin(ω_k · t + φ_k)
```

### 方波的傅里叶展开

```
方波 = sin(x) + (1/3)sin(3x) + (1/5)sin(5x) + (1/7)sin(7x) + ...
     = Σ_{k=0}^∞ [1/(2k+1)] · sin((2k+1)x)
```

频谱特征：仅含**奇数次谐波**，幅值按 1/k 衰减。

## 复数基础（为理解 FT 准备）

| 表示 | 形式 | 关系 |
|------|------|------|
| 直角坐标 | z = a + bi | a=实部, b=虚部 |
| 极坐标 | z = r·e^{iθ} | r=幅值=√(a²+b²), θ=相位=arctan(b/a) |
| 欧拉公式 | e^{iθ} = cos(θ) + i·sin(θ) | 连接指数与三角函数 |

> [!important] 欧拉公式
> **e^{iθ} = cos(θ) + i·sin(θ)**
> 这是理解傅里叶变换的关键：正弦波可以用复指数表示。

## 傅里叶变换（Fourier Transform）

### 连续形式

```
正变换:  F(ω) = ∫ f(t) · e^{-iωt} dt     (空域 → 频域)
逆变换:  f(t) = ∫ F(ω) · e^{iωt} dω      (频域 → 空域)
```

- 输出 F(ω) 是**复数**：幅值 |F(ω)| + 相位 ∠F(ω)
- **对偶性**：FT{FT{f}} ∝ f（变换两次回到原域）

### 离散傅里叶变换 (DFT)

```
F[k] = Σ_{n=0}^{N-1} f[n] · e^{-i2πkn/N}
```

本质是一个**矩阵乘法**：F = W · f，其中 W 是 DFT 矩阵。

> [!tip] FFT
> 快速傅里叶变换（FFT）利用蝶形运算将 DFT 的 O(N²) 复杂度降为 **O(N log N)**。这是数值算法中最重要的加速之一。

## 2D 频域分析

### 频域可视化

| 空域 | 频域 | 解释 |
|------|------|------|
| 水平条纹 | 垂直轴上的点 | 仅含垂直方向频率 |
| 垂直条纹 | 水平轴上的点 | 仅含水平方向频率 |
| 斜条纹 | 垂直于条纹方向的轴上的点 | 频率方向⊥空域条纹方向 |
| 零频率（中心） | **DC 分量** = 图像平均灰度 | 直流偏置 |

### 自然图像的频谱特征

- 幅值谱大致呈 **1/f 衰减**（低频能量大，高频能量小）
- 通常无明显的主导频率（不像条纹图像有离散峰值）
- 频谱中心（低频）最亮

## 相位 vs 幅值的重要性

> [!important] 相位比幅值更重要！
> 经典实验：将图像 A 的**幅值谱**与图像 B 的**相位谱**组合：
> - 结果看起来像图像 **B**（提供相位的那个）
> - 反之（A 的相位 + B 的幅值）→ 看起来像 A
>
> 结论：**相位编码了图像的结构信息**（边缘位置、纹理排列），幅值主要编码能量分布。

## 卷积定理

> [!important] 卷积定理（最核心）
> 空域的**卷积**等价于频域的**逐点相乘**：
>
> **f * g ⟺ F · G**
>
> 反之：空域的**逐点相乘**等价于频域的**卷积**：
>
> **f · g ⟺ F * G**

### 频域滤波流程

```
空域滤波:  输入 → 卷积核 → 输出
           等价于
频域滤波:  FT(输入) × FT(核) → IFT → 输出
```

当核很大时，频域滤波更高效：
- 空域卷积 O(N²M²)（N=图像大小，M=核大小）
- 频域：FFT O(N²logN²) + 逐点乘法 O(N²) + IFFT O(N²logN²)
- 当 M > O(logN) 时频域更快

## 频域滤波器类型

| 类型 | 频域操作 | 效果 |
|------|---------|------|
| **低通** | 保留低频，抑制高频 | 模糊（去除细节/噪声） |
| **高通** | 保留高频，抑制低频 | 边缘增强（去除平坦区域） |
| **带通** | 保留中间频率 | 提取特定尺度的特征 |
| **带阻** | 抑制中间频率 | 去除特定频率的噪声 |

### Gaussian vs Box 的频域解释

| 滤波器 | 空域 | 频域 | 效果 |
|--------|------|------|------|
| **Gaussian** | 高斯钟形 | 高斯（平滑衰减，**无旁瓣**） | 自然平滑 |
| **Box** | 矩形均匀 | **sinc**（有旁瓣/振荡） | 块状伪影、振铃 |

> [!tip] 为什么高斯优于 Box？
> Box 频谱的 sinc 旁瓣意味着某些高频分量没有被完全抑制，反而被放大 → 产生**振铃效应**（ringing）。高斯频谱平滑单调衰减 → 无此问题。

## 混合图像（Hybrid Image）

利用人眼对不同距离的频率敏感性不同：

```
混合图像 = 低通(图A) + 高通(图B)

近看 → 看到高频细节 → 图B
远看 → 高频被视觉系统衰减 → 看到图A（低频轮廓）
```

> [!tip] Campbell-Robson 对比敏感度曲线
> 人眼对**中频**最敏感（约 3-5 cycles/degree），对极低频和极高频的对比度感知较弱。这解释了混合图像效果和 Mach band 错觉。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "空域卷积等价于..." | 频域**逐点相乘** |
| "频域滤波何时更快" | 当核很大时（M > O(log N)） |
| "相位 vs 幅值哪个重要" | **相位**更重要（编码结构信息） |
| "高斯 FT 是什么" | **高斯**（自对偶） |
| "Box FT 是什么" | **sinc**（有旁瓣） |
| "零频率分量" | 图像的**平均灰度**（DC 分量） |
| "混合图像原理" | 低通+高通；人眼近看高频远看低频 |
| "FFT 复杂度" | O(N log N) vs DFT 的 O(N²) |
| "低通滤波效果" | 模糊（保留大结构，去除细节） |
| "高通滤波效果" | 边缘检测（保留细节，去除平坦区域） |

# 非参数密度估计（★★★）

#prcv #estimation #non-parametric

## 概览表（一目了然）

| 方法 | 核心思想 | 优势 | 劣势 |
|------|----------|------|------|
| 直方图 | 分 bin 计数 | 直观简单 | 维数灾难、不连续 |
| KDE | 核函数加权求和 | 连续、灵活 | 需保存数据、计算量大 |

## 为什么需要非参数估计？

- 常用参数形式（如高斯）基本都是**单模（single modal）**的
- 不足以描述复杂的多模态数据分布
- 非参数方法直接从训练数据估计密度

## 直方图（Histogram）

- 基于计数：将数据空间分成 bin，统计每个 bin 中的样本数
- 问题：
  - 多维怎么办？
  - 如何确定 bin 的数量/宽度？
  - 结果不连续
  - 需要保存计数信息

### 维数灾难（Curse of Dimensionality）

- 每维 n 个 bin，d 维需要保存 **n^d** 个参数
- 例：n=4, d=100 → 4¹⁰⁰ = 2²⁰⁰ ≈ 10⁶⁰ 个参数！

> [!danger] 维数灾难不限于直方图
> 在参数估计、以及很多其他统计学习方法中都存在维数灾难问题。

## 核密度估计（KDE）

### 基本形式

```
p(x) = (1/n) Σᵢ (1/h) K((x − xᵢ) / h)
```

| 组件 | 要求 | 作用 |
|------|------|------|
| 核函数 K | 非负、积分为1、对称 | 定义每个样本点的贡献形状 |
| 带宽 h | h > 0 | 控制核的宽度，决定平滑程度 |

### Parzen 窗（高斯核 KDE）

```
p(x) = (1/n) Σᵢ [1/(√(2π)h)] exp(−|x − xᵢ|² / (2h²))
```

### 带宽 h 的影响

```
h 太小 → 过拟合（锯齿状）    h 太大 → 过度平滑（丢失细节）
     ╱╲╱╲╱╲                      ╱‾‾‾‾‾‾‾‾╲
    ╱      ╲                    ╱              ╲
```

### KDE 的特点

| 问题 | 回答 |
|------|------|
| 连续吗？ | **是**（使用连续核函数时） |
| 多维怎么办？ | 多个维度的核函数**乘积** |
| 需要保存数据吗？ | **是**，需要保存全部训练数据 |
| 参数个数？ | **无穷多**（非参数方法） |
| 如何确定 h？ | 交叉验证等方法 |

> [!warning] KDE 的 kernel ≠ SVM 的 kernel
> 两者要求的条件不完全一致。KDE 核要求非负、积分为1、对称；SVM 核要求满足 Mercer 条件（半正定）。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "n=4, d=100 直方图需要多少参数" | **4¹⁰⁰ ≈ 10⁶⁰** |
| "KDE 核函数的三个条件" | **非负、积分为1、对称** |
| "KDE 需要保存训练数据吗" | **需要**（全部训练数据） |
| "h 太小会怎样" | **过拟合**（锯齿状） |
| "h 太大会怎样" | **过度平滑**（丢失细节） |
| "KDE 和 SVM 的 kernel 一样吗" | **不完全一样**，要求条件不同 |
| "Parzen 窗用什么核" | **高斯核** |

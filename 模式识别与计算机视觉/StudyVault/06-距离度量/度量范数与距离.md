# 距离度量、范数与度量学习（★★★）

#prcv #metric #distance

## 概览表（一目了然）

| 概念 | 核心 | 性质数量 |
|------|------|----------|
| 度量（metric） | 不相似度函数 | 4 个性质 |
| 向量范数 | 向量的"长度" | 3 个性质 |
| lp 范数 | 一族范数 | p ≥ 1 时成立 |
| 马氏距离 | 加权欧氏距离 | 考虑数据相关性 |

## 距离度量 vs 相似度

| | 距离（不相似度） | 相似度 |
|---|------------------|--------|
| 使用者 | KNN、PCA、FLD | KDE（核函数） |
| 关系 | 相似度高 ↔ 距离低 | |
| 例子 | 欧氏距离 | RBF 核 K(x,y) = exp(−γ‖x−y‖²) |

## 度量（Metric）的四个性质

| 编号 | 性质 | 公式 |
|------|------|------|
| i | 非负性 | d(x,y) ≥ 0 |
| ii | 对称性 | d(x,y) = d(y,x) |
| iii | 同一性 | d(x,y) = 0 ⇔ x = y |
| iv | 三角不等式 | d(x,z) ≤ d(x,y) + d(y,z) |

## 向量范数的三个性质

| 编号 | 性质 | 公式 |
|------|------|------|
| i | 齐次性 | f(cx) = \|c\| f(x) |
| ii | 非负性 | f(x) = 0 ⇔ x = 0 |
| iii | 三角不等式 | f(x+y) ≤ f(x) + f(y) |

由此可推出：f(0)=0, f(−x)=f(x), f(x)≥0

> [!tip] 范数诱导度量
> 向量范数 f 可以诱导出度量：d(x,y) = f(x−y)，自动满足度量的四个性质。

## lp 范数

```
‖x‖ₚ = (Σᵢ |xᵢ|ᵖ)^(1/p)    p ≥ 1 时有定义
```

| p 值 | 名称 | 公式/含义 |
|------|------|-----------|
| p=0 | "l0 范数" | 非零元素个数（**不是合法范数**） |
| p=1 | l1 范数 | Σ\|xᵢ\|，对应**曼哈顿距离** |
| p=2 | l2 范数 | √(Σxᵢ²)，对应**欧氏距离** |
| p→∞ | l∞ 范数 | max\|xᵢ\|，**最大分量** |

### 关键不等式

- **闵可夫斯基不等式**（保证三角不等式成立）：(Σ|xᵢ+yᵢ|ᵖ)^(1/p) ≤ (Σ|xᵢ|ᵖ)^(1/p) + (Σ|yᵢ|ᵖ)^(1/p)，**仅 p ≥ 1 时成立**
- **范数单调性**：当 p > q > 0 时，‖x‖ₚ ≤ ‖x‖_q

> [!danger] p < 1 时的问题
> p < 1 时**不满足三角不等式**（闵可夫斯基不等式不成立），因此 lp "范数" 不是合法的范数，也无法诱导合法的度量。

## 马氏距离（Mahalanobis Distance）

- 令 G 为 d×d 正定矩阵，则 f(x) = ‖Gx‖ 定义有效的向量范数
- **马氏距离的平方形式**：

```
d²_A(x,y) = (x−y)ᵀ A (x−y),    A = GᵀG（半正定）
```

- **动机**：假设数据服从高斯分布，白化变换 Σ^(−1/2)(x−x̄) 消除各维度相关性和尺度差异
- 当 A = I 时退化为欧氏距离

## 度量学习（Metric Learning）

学习一个好的矩阵 A：‖x−y‖²_A = (x−y)ᵀA(x−y)

### 三元组损失（Triplet Loss）

```
anchor ──── positive（同类，应该近）
  │
  └──── negative（异类，应该远）

目标：d(anchor, positive) + margin < d(anchor, negative)
```

### 深度度量学习

- 使用 **Siamese Network**（孪生网络）
- 两个共享权重的网络提取特征，然后计算距离

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "度量的四个性质" | **非负、对称、同一、三角不等式** |
| "范数的三个性质" | **齐次、非负、三角不等式** |
| "l1 距离别名" | **曼哈顿距离** |
| "l∞ 距离含义" | **各维最大差值** max\|xᵢ−yᵢ\| |
| "p<1 时 lp 为什么不是范数" | **不满足三角不等式** |
| "p>q>0 时 ‖x‖ₚ 和 ‖x‖_q 谁大" | **‖x‖ₚ ≤ ‖x‖_q** |
| "马氏距离的动机" | **消除维度相关性和尺度差异**（白化） |
| "度量学习常用损失函数" | **三元组损失（Triplet Loss）** |
| "深度度量学习用什么网络" | **Siamese Network** |

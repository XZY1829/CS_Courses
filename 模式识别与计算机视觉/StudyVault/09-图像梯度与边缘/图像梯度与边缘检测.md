# 图像梯度与边缘检测（★★★）

#prcv #edge-detection #gradient #sobel

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 边缘 | 图像强度的**急剧不连续**；对应物体边界、阴影、纹理变化 |
| 检测原理 | 对离散图像取**导数**（有限差分）→ 不连续处导数大 |
| 1D 前向差分 | f'(x) ≈ f(x+1)−f(x)，核 `[-1, 1]` |
| 1D 中心差分 | f'(x) ≈ (f(x+1)−f(x−1))/2，核 `[-1, 0, 1]`（更精确） |
| Sobel 水平 | 先垂直平滑 `[1;2;1]`，再水平求导 `[1,0,-1]` → 检测**垂直边缘** |
| Sobel 垂直 | 先水平平滑 `[1,2,1]`，再垂直求导 `[1;0;-1]` → 检测**水平边缘** |
| 梯度幅值 | ‖∇f‖ = √(f_x² + f_y²)，表示边缘强度 |
| 梯度方向 | θ = arctan(f_y / f_x)，与边缘方向**垂直** |

## 什么是边缘？

图像中强度值的**急剧变化**区域。数学上，边缘对应于图像函数的**大梯度**位置。

检测策略：**求导数** → 导数大的位置就是边缘。

## 有限差分（Finite Differences）

连续函数导数的定义：

```
f'(x) = lim_{h→0} [f(x+h) − f(x)] / h
```

对离散信号，去掉极限，令 h = 1（或 h = 2）：

### 三种差分方案

| 方案 | 公式 | 对应核 | 精度 |
|------|------|--------|------|
| **前向差分** | f'(x) ≈ f(x+1) − f(x) | `[-1, 1]` | 一阶 |
| **后向差分** | f'(x) ≈ f(x) − f(x−1) | `[1, -1]` | 一阶 |
| **中心差分** | f'(x) ≈ [f(x+1) − f(x−1)] / 2 | `[-1, 0, 1]` (÷2) | 二阶 |

> [!important] 为什么使用中心差分？
> 中心差分精度更高（二阶精度 vs 一阶），且对称，导数估计在 x 处而非 x+0.5 处。这就是 Sobel 等滤波器中使用 `[-1, 0, 1]` 的原因。

## Sobel 滤波器

### 构造原理

**核心思想**：先沿一个方向**平滑**（抑制噪声），再沿另一个方向**求导**（检测边缘）。

```
Sobel_x = smoothing_y × derivative_x

[1]       [1 0 -1]     [1  0  -1]
[2]   ×   (none)    =   [2  0  -2]    ← 检测水平方向梯度（垂直边缘）
[1]                     [1  0  -1]

Sobel_y = derivative_y × smoothing_x

[1 ]                    [1   2   1]
[0 ]  ×  [1 2 1]   =   [0   0   0]    ← 检测垂直方向梯度（水平边缘）
[-1]                    [-1  -2  -1]
```

> [!warning] Sobel 方向易混淆
> - **Sobel_x**（水平核 `[1,0,-1;2,0,-2;1,0,-1]`）检测 **x 方向梯度** = **垂直边缘**（亮度在水平方向变化）
> - **Sobel_y**（垂直核 `[1,2,1;0,0,0;-1,-2,-1]`）检测 **y 方向梯度** = **水平边缘**（亮度在垂直方向变化）
>
> 滤波器名称指的是**梯度方向**，而非边缘方向。

### 其他导数滤波器对比

| 名称 | 水平核 Gx | 垂直核 Gy | 特点 |
|------|----------|----------|------|
| **Prewitt** | `[1,0,-1; 1,0,-1; 1,0,-1]` | `[1,1,1; 0,0,0; -1,-1,-1]` | 均匀平滑（box）|
| **Sobel** | `[1,0,-1; 2,0,-2; 1,0,-1]` | `[1,2,1; 0,0,0; -1,-2,-1]` | 高斯近似平滑 |
| **Scharr** | `[3,0,-3; 10,0,-10; 3,0,-3]` | `[3,10,3; 0,0,0; -3,-10,-3]` | 更强的旋转不变性 |
| **Roberts** | `[0,1; -1,0]` / `[1,0; 0,-1]` | 2×2 对角方向 | 简单但噪声敏感 |

> [!tip] 推导其他滤波器
> 所有 3×3 导数滤波器的结构相同：平滑列 × 导数行。区别仅在于**平滑列**的选择：
> - Prewitt: `[1;1;1]`（均匀）
> - Sobel: `[1;2;1]`（高斯近似）
> - Scharr: `[3;10;3]`（优化旋转不变性）

## 图像梯度的计算流程

```
1. 选择导数滤波器 (如 Sobel)
     ┌─────────┐       ┌──────────┐
     │ Sobel_x │       │ Sobel_y  │
     └────┬────┘       └────┬─────┘
          │                  │
2. 对图像卷积得到偏导
          ↓                  ↓
        f_x(x,y)          f_y(x,y)
          │                  │
3. 组合为梯度向量
          └──────┐    ┌──────┘
                 ↓    ↓
        ∇f = [f_x, f_y]
                 │
4. 计算幅值和方向
         ┌───────┴───────┐
         ↓               ↓
  幅值: ‖∇f‖          方向: θ
  = √(f_x²+f_y²)    = arctan(f_y/f_x)
```

### 梯度幅值与方向

| 量 | 公式 | 物理意义 |
|----|------|----------|
| **梯度幅值** | ‖∇f‖ = √(f_x² + f_y²) | 边缘**强度**（变化幅度） |
| **梯度方向** | θ = arctan(f_y / f_x) | 强度增长最快的方向 |

> [!important] 梯度方向 vs 边缘方向
> 梯度方向**垂直于**边缘方向。如果图像中有一条垂直边缘（从左暗到右亮），梯度方向为**水平向右**。

## Sobel 可分离性

所有上述导数滤波器都是**可分离**的（秩=1）：

```
Sobel_x = [1;2;1] × [-1,0,1]    (平滑列 × 导数行)
Sobel_y = [-1;0;1] × [1,2,1]    (导数列 × 平滑行)
```

这意味着 3×3 Sobel 的 9 次乘法可降为 6 次（2 次 1D 卷积各 3 次）。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "中心差分核" | `[-1, 0, 1]`（÷2 可选） |
| "Sobel 检测什么方向" | Sobel_x 检测**垂直边缘**，Sobel_y 检测**水平边缘** |
| "Sobel 分解" | 平滑向量 × 导数向量 |
| "梯度方向与边缘关系" | **垂直**（正交） |
| "为何先平滑再求导" | 抑制噪声。导数对噪声**极度敏感**（放大高频），平滑起到低通滤波作用 |
| "Prewitt vs Sobel" | 平滑列不同：均匀 vs 高斯近似 |
| "Roberts 缺点" | 2×2 太小，噪声敏感；对角方向，不直觉 |
| "梯度幅值公式" | √(f_x² + f_y²) |

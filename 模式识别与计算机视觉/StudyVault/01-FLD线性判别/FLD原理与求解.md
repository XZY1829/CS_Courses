# Fisher 线性判别（FLD）原理与求解（★★★）

#prcv #fld #dimensionality-reduction

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 目标 | 找到投影方向 w 使类间距离最大、类内方差最小 |
| 准则 | 广义瑞利商 J(w) = wᵀSᵦw / wᵀSᵥw |
| 求解 | w = Sᵥ⁻¹(μ₂ − μ₁)（两类情况直接求解） |
| 多类 | 最多 C−1 个有效投影方向 |
| 前提 | PCA 适合单高斯数据的表示，但与分类无关 |

## 为什么需要 FLD？

- PCA 在**单个高斯分布**时是最佳的表示方法，但目标是表示数据而非分类
- 分类问题中不同类别的分布 p(x|y=i) 不同
- FLD 是某些假设下的**最优线性特征提取方法**

> [!important] FLD vs PCA
> PCA 最大化数据方差（重构），FLD 最大化类间可分性（分类）。

## 数学形式化

- 两类 y ∈ {1,2}，各有 N₁、N₂ 个样本
- 类均值：μ₁ = (1/N₁)Σ xᵢ（y=1），μ₂ 同理
- 投影后：u = wᵀx，投影均值 m₁ = wᵀμ₁，m₂ = wᵀμ₂

## 散度矩阵

| 矩阵 | 定义 | 含义 |
|------|------|------|
| Sₖ | Σ(xᵢ−μₖ)(xᵢ−μₖ)ᵀ（y=k） | 第 k 类的散度 |
| **Sᵥ**（类内） | S₁ + S₂ | 各类内部的离散程度之和 |
| **Sᵦ**（类间） | (μ₂−μ₁)(μ₂−μ₁)ᵀ | 类中心之间的距离 |
| **Sₜ**（总散度） | Σ(x−μ)(x−μ)ᵀ | 所有数据的总离散程度 |

> [!tip] 关键关系
> 当 C=2 时：Sₜ = Sᵥ + Sᵦ

## Fisher 准则

最大化广义瑞利商（Generalized Rayleigh Quotient）：

```
max J(w) = wᵀSᵦw / wᵀSᵥw,  s.t. wᵀw = 1
```

用拉格朗日乘子法得到广义特征值问题：Sᵦw = λSᵥw

## FLD 求解步骤（两类）

```
1. 计算 μ₁, μ₂
2. 计算 Sᵥ = S₁ + S₂
3. 计算 w = Sᵥ⁻¹(μ₂ − μ₁)
4. 归一化 w ← w / ‖w‖
```

> [!warning] 关键简化
> 两类时无需解广义特征值问题，因为 Sᵦw ∝ (μ₂−μ₁)，直接代入即可。

## Sᵥ 不可逆的处理

当样本少或维度高时，Sᵥ 可能不可逆。

- Sᵥ 是实对称、至少半正定的：Sᵥ = EΛEᵀ, λᵢᵢ ≥ 0
- **Moore-Penrose 伪逆**：
  - 若 λᵢᵢ > 0，则 λ⁺ᵢᵢ = 1/λᵢᵢ；否则 λ⁺ᵢᵢ = 0
  - Sᵥ⁺ = EΛ⁺Eᵀ

## 多类 FLD（C 类）

- Sᵥ = Σᵢ Sᵢ（直接从两类推广）
- 总均值：μ = (1/N)Σᵢ Nᵢμᵢ
- 多类 Sᵦ = Σᵢ Nᵢ(μᵢ−μ)(μᵢ−μ)ᵀ
- 解广义特征值问题 Sᵦwᵢ = λᵢSᵥwᵢ
- **最多得到 C−1 个有效投影方向**（因为 Sᵦ 的秩最多为 C−1）

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "最优线性特征提取" | **FLD** |
| "广义瑞利商" | Fisher 准则 J(w) = wᵀSᵦw / wᵀSᵥw |
| "Sᵥ 不可逆怎么办" | **Moore-Penrose 伪逆** 或 正则化 Sᵥ′ = Sᵥ + εI |
| "C 类最多几个投影方向" | **C−1 个**（Sᵦ 秩最多 C−1） |
| "Sₜ = ?" | **Sᵥ + Sᵦ**（两类时成立） |
| "两类 FLD 的 w" | **Sᵥ⁻¹(μ₂−μ₁)** |

# FLD 变体与 Fisherfaces（★★☆）

#prcv #fld #fld-variants

## 概览表（一目了然）

| 变体 | 核心思想 | 优势 | 劣势 |
|------|----------|------|------|
| 正则化 FLD | Sᵥ′ = Sᵥ + εI | 提高数值稳定性 | 需手动调参 |
| Kernel FLD | 核函数映射到高维 | 处理非线性可分 | 计算复杂度高 |
| 2D-FLD | 行/列投影矩阵 U, V | 保留空间结构，计算快 | 交替迭代非凸 |
| 稀疏 FLD | 加 ‖w‖₁ ≤ τ 约束 | 可解释性强，特征筛选 | 可能损失判别信息 |
| 鲁棒 FLD | 中位数 + 鲁棒协方差 | 抗噪声和离群点 | 小样本下不可靠 |
| 增量 FLD | 增量更新 Sᵥ, Sᵦ | 适用于流式数据 | 累计误差 |
| PCA+FLD | PCA 降维后再 FLD | 解决 Sᵥ 不可逆 | 两阶段，可能丢信息 |

## 正则化 FLD

- Sᵥ′ = Sᵥ + εI
- 使 Sᵥ 变为可逆，提高数值稳定性
- 适用于样本数少于特征维度的场景
- ε 需要手动调整

## Kernel FLD

- 通过核函数将数据映射到高维特征空间
- 在高维空间中执行 FLD，处理原空间中非线性可分的数据
- 需要选择核函数和调参，计算复杂度高

## 2D-FLD

- 输入为图像矩阵 Xₖ，找行投影矩阵 U 和列投影矩阵 V
- 分别定义行/列方向的类内和类间散度矩阵
- 同时优化 U 和 V 是**耦合的非凸问题**，采用**交替迭代法**
- ORL 数据集：识别率从传统 FLD 的 89% 提升至 **96%**，计算时间减少 **60%**

## 稀疏 FLD

```
max J(w) = wᵀSᵦw / wᵀSᵥw,  s.t. ‖w‖₁ ≤ τ
```

- 目标：使投影方向稀疏，提高模型可解释性
- 适用于高维数据特征筛选
- 用**近端梯度下降**迭代求解
- 可能损失部分判别信息

## 鲁棒 FLD

- 用**中位数**替代均值，用**鲁棒协方差**替代普通协方差
- MCD（最小协方差行列式）：找包含 h 个样本（h > n/2）的子集，使协方差行列式最小，排除离群点

> [!warning] 局限性
> 鲁棒协方差估计在小样本下不可靠。

## 增量 FLD

- 均值增量更新：μₙₑw = (Nμₒₗd + xₙₑw) / (N+1)
- 增量更新 Sᵥ 和 Sᵦ，无需重算全部历史数据
- 适用于实时/流式数据（监控、网络）
- 长期更新会导致累计误差

## PCA + FLD（Fisherfaces）

```
高维数据 --PCA--> 低维(k维) --FLD--> 投影方向
```

- **动机**：当 n < d 时 Sᵥ 不可逆
- **PCA 阶段**：保留前 k = n−C 个主成分，确保 Sᵥ 可逆
- **FLD 阶段**：在 PCA 降维后的低维空间求解
- 人脸识别场景：图像 100×100 = 10000 维，样本远少于维度
- ORL 数据集上 Fisherfaces 比纯 PCA（Eigenfaces）分类准确率**显著提升**

> [!tip] Fisherfaces 核心步骤
> 1. PCA 降至 n−C 维（保留足够主成分使 Sᵥ 可逆）
> 2. 在降维空间做 FLD 得到最终投影方向

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "如何处理 Sᵥ 不可逆（非伪逆方法）" | **正则化 FLD** (Sᵥ+εI) 或 **PCA+FLD** |
| "非线性可分数据用什么 FLD" | **Kernel FLD** |
| "2D-FLD 优化方法" | **交替迭代法**（非凸耦合问题） |
| "Fisherfaces 的 PCA 保留几个主成分" | **n−C 个**（n=样本数, C=类数） |
| "提高 FLD 可解释性" | **稀疏 FLD**（L1 约束） |
| "对离群点鲁棒的 FLD" | **鲁棒 FLD**（MCD 方法） |

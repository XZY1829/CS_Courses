# 采样、混叠与图像金字塔（★★★）

#prcv #sampling #aliasing #pyramid #nyquist

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 混叠（Aliasing） | 采样率不足 → 高频信号"伪装"为低频 |
| Nyquist 频率 | f_s/2；采样定理：f_s ≥ 2f_max 才能无失真重建 |
| 抗混叠策略 | (1) 提高采样率（过采样）或 (2) **低通滤波**后再降采样 |
| 朴素降采样 | 直接丢弃偶数行/列 → 严重混叠（锯齿、摩尔纹） |
| 正确降采样 | **先高斯模糊**（低通滤波）→ 再丢行列 |
| 高斯金字塔 | 反复 "模糊→降采样" → 多分辨率表示；总大小仅 4/3 原图 |
| 拉普拉斯金字塔 | 存储每层**残差**（原图−模糊图）；**无损可重建** |
| 应用 | 多尺度检测、图像融合、压缩、纹理映射、去噪 |

## 朴素降采样的问题

直接丢弃偶数行列：

```
原图 (M×M) → 丢偶数行列 → 1/2 (M/2 × M/2) → ... → 1/8
```

问题：**混叠（Aliasing）**——低分辨率图像出现锯齿状边缘、摩尔纹、像素化。

## 混叠（Aliasing）

### 定义

采样率低于信号最高频率的两倍时，**高频分量被错误地"伪装"为低频分量**。

### 正弦波示例

```
高频正弦波 ──── 稀疏采样 ──── 重建为低频正弦波
    ~~~~~~~~         • • • •         ~~~~
    (原始)          (采样点)        (混叠后)
```

- **不可逆**：混叠一旦发生，原始高频信息不可恢复
- **方向性**：只能误认为更低频率，不能误认为更高频率

> [!tip] 混叠的常见表现
> - **图像**：摩尔纹（Moiré）——规则纹理在降采样后出现干涉条纹
> - **纹理**：远处棋盘格变为灰色闪烁
> - **时间**（帧率混叠）：高速旋转车轮看起来倒转（电影中常见）

## Nyquist-Shannon 采样定理

> [!important] 采样定理
> 连续信号可从离散采样中**完美重建**，当且仅当采样频率满足：
>
> **f_s ≥ 2 × f_max**
>
> 其中 f_max 是信号最高频率分量，f_s/2 称为 **Nyquist 频率**。

等价表述：降采样时，若采样频率达到 Nyquist 频率或更高，就**不会发生混叠**。

### 与高斯金字塔的关系

- 高斯模糊 = **低通滤波**
- 模糊后信号的 f_max 降低
- 降采样 2× → 需要 f_max ≤ f_s/4（原采样率的 1/4）
- 高斯模糊的 σ 越大 → 截止频率越低 → 抗混叠效果越好

> [!warning] 高斯模糊的程度
> 模糊不足 → 仍有混叠；模糊过度 → 丢失太多细节。
> 理想目标：使模糊后信号的最高频率**恰好等于** Nyquist 频率。

## 抗混叠（Anti-aliasing）

两种策略：

| 策略 | 方法 | 代价 |
|------|------|------|
| **过采样** | 提高采样率 | 存储和计算增加 |
| **低通滤波** | 降采样前先模糊 | 损失部分细节（但优于混叠伪影） |

### 正确的降采样流程

```
原图 → 高斯模糊（低通） → 丢弃偶数行列 → 1/2 大小
```

## 高斯金字塔（Gaussian Pyramid）

### 构建算法

```
重复：
  1. 高斯滤波（模糊）
  2. 降采样（丢偶数行列）
直到达到最小分辨率
```

```
Level 0: 原图 (M×M)
         ↓ 模糊 + 降采样
Level 1: M/2 × M/2
         ↓ 模糊 + 降采样
Level 2: M/4 × M/4
         ↓ ...
Level k: M/2^k × M/2^k
```

### 存储大小

> [!tip] 高斯金字塔总大小 = 原图的 4/3
> 几何级数：1 + 1/4 + 1/16 + 1/64 + ... = 1/(1−1/4) = **4/3**。
> 推导：每层面积是上一层的 1/4（长宽各半），无穷等比级数求和。

### 性质

| 层级 | 内容 |
|------|------|
| 低层（Level 0） | 全部细节，高频+低频 |
| 高层（Level k） | 仅保留**大尺度结构**（低频），细节被平滑 |

> [!warning] 高斯金字塔是有损的
> 无法从高层图像重建低层图像——高频信息已被模糊丢弃。

## 拉普拉斯金字塔（Laplacian Pyramid）

### 动机

模糊会丢失信息。**残差（residual）** = 原图 − 模糊图 保存了被丢弃的高频细节。

### 构建

```
Level 0 残差 = Level 0 原图 − upsample(Level 1)
Level 1 残差 = Level 1 − upsample(Level 2)
...
最顶层 = 高斯金字塔最高层（直接保存）
```

每层存储的是**该分辨率下丢失的细节**（带通信息）。

### 重建

```
Level 0 = Level 0 残差 + upsample(Level 1)
Level 1 = Level 1 残差 + upsample(Level 2)
...
从最高层开始逐层加回残差 → 完美重建原图
```

> [!important] 拉普拉斯金字塔是无损的
> 存储所有残差 + 最顶层高斯图 → 可以**完美重建**原图。
> 与高斯金字塔同样的存储空间，但信息**无损**。

### 高斯 vs 拉普拉斯对比

| 属性 | 高斯金字塔 | 拉普拉斯金字塔 |
|------|-----------|--------------|
| 每层存储 | 模糊后的图像（低通） | 残差/细节（带通） |
| 可重建原图 | ✗（有损） | ✓（无损） |
| 总存储 | 4/3 原图 | 4/3 原图 |
| 用途 | 多尺度检测、抗混叠 | 图像融合、压缩、编辑 |
| 像素值特点 | 非负（正常图像） | 有正有负（残差可能为负） |

## 其他金字塔类型

| 类型 | 特点 |
|------|------|
| **可控金字塔**（Steerable） | 每层保存多个方向版本 |
| **小波**（Wavelets） | 正交基分解，图像处理经典工具 |

## 图像金字塔的应用

| 应用 | 如何使用 |
|------|---------|
| 多尺度检测 | 在不同金字塔层检测特征（如角点、blob） |
| 图像融合/拼接 | 拉普拉斯金字塔逐层融合，避免拼接缝 |
| 图像压缩 | 拉普拉斯残差稀疏，易于压缩 |
| 纹理映射（Mipmapping） | GPU 存储多级纹理，避免远距离纹理混叠 |
| 去噪 | 分层处理不同频率的噪声 |
| 多尺度配准 | 粗到精的图像对齐策略 |
| 焦点堆叠（Focus Stacking） | 不同焦距图像在金字塔中融合 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "直接丢行列的问题" | **混叠**——高频伪装为低频 |
| "Nyquist 条件" | f_s ≥ 2f_max |
| "正确降采样" | **先高斯模糊再降采样** |
| "金字塔总大小" | 4/3 原图（等比级数 1 + 1/4 + 1/16 + ...） |
| "无损重建" | **拉普拉斯金字塔**（高斯不行） |
| "拉普拉斯金字塔重建" | 从最高层开始，逐层上采样+加残差 |
| "摩尔纹" | 混叠在纹理中的表现 |
| "车轮倒转" | **时间混叠**（帧率低于转速的 2 倍） |
| "模糊程度选择" | 使 f_max 降到 Nyquist 频率以下 |
| "高斯金字塔高层保留什么" | 大尺度结构（低频分量） |

## 三角化（Triangulation）

### 问题

已知两个相机 P₁, P₂ 和对应 2D 点 x₁, x₂，求 3D 点 X。

### 方法

```
x ~ P·X  →  x × (P·X) = 0  （叉积消除尺度因子）
```

每个 2D 点给出 **2 个独立方程**（第 3 个是前两个的线性组合）。

两个视图 → 4 方程 4 未知 → 齐次方程 AX = 0 → **SVD 解**。

> [!important] 叉积消除尺度因子
> x ~ PX 意味着 x 和 PX 方向相同但差一个尺度。
> x × (PX) = 0 消除了尺度因子，转为线性方程。
> **叉积可用反对称矩阵 [x]_× 表示**：x×y = [x]_× · y。

### 实际中的问题

由于噪声，两条反投影射线**不一定精确相交** → 需要最小二乘意义下的最优解（SVD 最小奇异值向量）。

## 对极几何（Epipolar Geometry）

### 核心概念

```
          对极平面(Epipolar Plane)
          ╱         |         ╲
         ╱    3D点X  |          ╲
        ╱      ●     |           ╲
       ╱      ╱ ╲    |            ╲
      ╱      ╱   ╲   |             ╲
  O₁ ●─────────────●─O₂
  相机1  基线(Baseline)  相机2
     |              |
  像平面1         像平面2
  x₁●──对极线──●e₁   e₂●──对极线──●x₂
```

| 术语 | 定义 |
|------|------|
| **基线** | 连接两个相机中心 O₁O₂ 的线段 |
| **对极点 e** | 另一个相机中心在本相机像平面上的投影 |
| **对极平面** | 由 O₁、O₂ 和 3D 点 X 构成的平面 |
| **对极线** | 对极平面与像平面的**交线** |

### 对极约束

> [!important] 对极约束的核心作用
> 已知图像 1 中的点 x₁，它在图像 2 中的对应点 x₂ **一定在对极线上**。
> 搜索空间：**2D → 1D**（从整个图像缩减到一条线）。

### 特殊情况

| 配置 | 对极点位置 | 对极线方向 |
|------|-----------|-----------|
| **汇聚相机** | 图像内某处 | 辐射状 |
| **平行相机** | 无穷远（不在图像内） | **水平线**（最简情况） |

## 本质矩阵（Essential Matrix）

### 推导

两个相机坐标系间的关系：X₂ = R·X₁ + t。

三个向量 X₁, X₂, t **共面** → 共面条件：

```
X₂^T · (t × (R·X₁)) = 0
X₂^T · [t]_× · R · X₁ = 0
```

定义 **E = [t]_× · R**（本质矩阵）：

```
x₂^T · E · x₁ = 0    （Longuet-Higgins 方程）
```

> [!warning] x₁, x₂ 是相机坐标
> 本质矩阵 E 操作的是**相机坐标系**中的点（假设内参为单位矩阵）。

### 性质

| 性质 | 说明 |
|------|------|
| 大小 | 3×3 |
| DOF | **5**（3 旋转 + 3 平移 − 1 尺度） |
| 秩 | **2**（因为 [t]_× 秩为 2） |
| 对极线 | l₂ = E·x₁；l₁ = E^T·x₂ |
| 对极点 | E·e₁ = 0；E^T·e₂ = 0 |

## 基础矩阵（Fundamental Matrix）

### 从 E 推广到 F

E 假设内参为 I。实际图像坐标与相机坐标的关系：x_cam = K⁻¹·x_img。

代入 Longuet-Higgins 方程：

```
(K₂⁻¹x₂')^T · E · (K₁⁻¹x₁') = 0
x₂'^T · K₂^{-T} · E · K₁^{-1} · x₁' = 0
x₂'^T · F · x₁' = 0
```

**F = K₂^{-T} · E · K₁^{-1}**

### 性质

| 性质 | 说明 |
|------|------|
| 大小 | 3×3 |
| DOF | **7**（9 元素 − 1 尺度 − 1 秩约束） |
| 秩 | **2**（继承自 E） |
| 映射 | **点 → 线**（不同于单应性的点→点） |
| 对极线 | l₂ = F·x₁（像素坐标） |
| 对极点 | F·e₁ = 0 → SVD 求 F 的右零空间 |

> [!important] E vs H
> | | 本质/基础矩阵 | 单应矩阵 |
> |---|---|---|
> | 映射 | 点 → **线** | 点 → **点** |
> | 约束 | x₂^T·F·x₁ = 0 | x₂ ~ H·x₁ |
> | 秩 | 2 | 3 |
> | 场景 | 任意（3D→3D） | 平面 |

## 8 点算法（Eight-Point Algorithm）

### 核心方程

```
x₂^T · F · x₁ = 0
```

展开后，每对对应给出 **1 个方程**（注意：单应每对给 2 个方程！）：

```
x₁'x₂'f₁₁ + x₁'y₂'f₂₁ + x₁'f₃₁ + y₁'x₂'f₁₂ + y₁'y₂'f₂₂ + y₁'f₃₂ + x₂'f₁₃ + y₂'f₂₃ + f₃₃ = 0
```

### 算法步骤

```
1. [归一化点坐标]（提高数值稳定性）
2. 构建 M×9 矩阵 A（每行 1 个对应的 9 个系数）
3. SVD(A) = UΣV^T
4. f = V 的最后一列 → 重塑为 3×3 矩阵 F̃
5. [强制秩 2 约束]：SVD(F̃) = U'Σ'V'^T，令 Σ' 最小奇异值=0 → F = U'Σ"V'^T
6. [反归一化 F]
```

> [!important] 为什么是 8 点？
> F 有 9 个元素、1 个尺度约束、1 个秩约束 → 7 DOF。
> 但 Af=0 是齐次方程，**每对对应仅 1 个方程**（不是 2 个！因为 F 映射点→线，只有一个标量约束）。
> 需要至少 **8 对对应**（8 方程/9 未知/1 尺度约束）。
>
> 对比单应：每对 2 方程，4 对 = 8 方程/8 DOF。

### 强制秩 2

直接 SVD 求出的 F̃ 通常秩为 3（噪声导致）。**必须**强制秩 2：

```
F̃ = UΣV^T，其中 Σ = diag(σ₁, σ₂, σ₃)
令 Σ' = diag(σ₁, σ₂, 0)
F = UΣ'V^T
```

这是 **Eckart-Young 定理**的应用：秩 k 最佳近似 = 保留最大的 k 个奇异值。

## SVD 在本课中的多次使用

| 用途 | 方程 | SVD 的角色 |
|------|------|-----------|
| DLT（单应/标定） | Ah=0 | 最小奇异值向量=解 |
| 三角化 | AX=0 | 最小奇异值向量=3D 点 |
| 求 F | Af=0 | 最小奇异值向量=F 的元素 |
| 强制秩 2 | F̃→F | 截断奇异值 |
| 求对极点 | Fe=0 | 最小奇异值向量=e |
| 求相机中心 | Pc=0 | 最小奇异值向量=C |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "对极约束的作用" | 搜索空间 **2D → 1D** |
| "E vs F 的区别" | E 在相机坐标，F 在像素坐标（F 包含内参 K） |
| "F 的秩" | **2**（不是 3） |
| "8 点算法每对几个方程" | **1 个**（不是 2 个！与单应的 2 个不同） |
| "为什么需要强制秩 2" | SVD 解出的 F 通常秩=3（噪声），需截断 |
| "E 映射什么到什么" | 点 → **线**（与 H 的点→点不同） |
| "平行相机的对极点" | 在**无穷远** |
| "三角化用什么解" | 叉积消尺度 → AX=0 → **SVD** |
| "F 的 DOF" | **7**（9−1 尺度−1 秩约束） |
| "求对极点" | Fe=0 → SVD 的右零空间 |
| "归一化 8 点算法" | 先归一化坐标 → 求 F → 反归一化 → 提高数值稳定性 |

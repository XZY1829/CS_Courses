## 1. Multi-plane Calibration（多平面标定）

> 对应课件第26-35页

### 1.1 背景：为什么需要替代方法？

传统的相机标定方法（如 DLT）需要：
- 一个精确已知的三维标定物体
- 精确知道 3D 点在世界坐标系中的位置
- 精确的 3D→2D 对应关系

这些要求在实际中很难满足。

### 1.2 多平面标定的核心思想

**只需要一个已知图案的平面**（如棋盘格），从**不同角度拍摄多张照片**即可完成标定。

这就是著名的**张正友标定法（Zhang's Method, 1998）**。

### 1.3 优点

| 优点 | 说明 |
|------|------|
| 只需要一个平面 | 不需要复杂的三维标定物 |
| 不需要知道位置/朝向 | 标定板放在哪里都行，不需要精密定位 |
| 开源代码丰富 | MATLAB Bouguet 工具箱、OpenCV 都有实现 |

### 1.4 缺点

- 需要求解**非线性优化问题**（相比 DLT 的解析解更复杂）
- 需要多张图像（通常 10-20 张）

### 1.5 标定步骤演示（第27-31页）

1. 准备棋盘格标定板（已知格子大小）
2. 从不同角度、不同距离拍摄多张照片
3. 检测每张图中棋盘格角点的像素坐标
4. 对每张图计算单应性矩阵 H（平面点 → 图像点）
5. 从多个 H 中通过约束关系提取内参 K
6. 利用 K 和 H 计算每张图对应的外参 R, t
7. 考虑径向畸变，进行非线性优化精化所有参数

### 1.6 相机标定的多种含义（第32-33页）

"标定相机"可以指很多方面：

| 类型 | 目标 |
|------|------|
| 辐射标定（Radiometric） | 亮度响应函数 |
| 颜色标定（Color） | 色彩准确还原 |
| **几何标定（Geometric）** | **内参、外参** ← 本课重点 |
| 噪声标定（Noise） | 噪声特性 |
| 镜头标定（Lens） | 畸变系数 |

### 1.7 应用示例：简单AR程序（第34-35页）

利用标定结果可以实现增强现实：

1. 计算已知 AR 标记的 2D-3D 对应关系
2. 通过 PnP 算法估计相机位姿 P
3. 将 3D 虚拟物体通过 P 投影到图像平面

## 2. Triangulation（三角化）

> 对应课件第38-60页

### 2.1 问题定义（第38-39页）

**三角化问题：**
- **已知：** 两个相机的投影矩阵 P₁ 和 P₂，以及一对匹配点 x 和 x'
- **求解：** 对应的三维空间点 X

```
图示：
        X (3D点)
       / \
      /   \
     /     \
    O₁      O₂    （两个相机中心）
    |       |
    x       x'    （图像上的匹配点）
```

### 2.2 反投影（Backprojection）（第40-42页）

**核心问题：** 一个 2D 图像点 x 对应三维空间中的哪些 3D 点？

**答案：一条射线（ray）。**

图像上的一个点无法确定深度，所以对应一条从相机中心出发的射线。

**如何构造这条射线？** 找射线上的两个点：

1. **相机中心 C：** 满足 PC = 0，通过对 P 做 SVD 求零空间得到
2. **伪逆点 P⁺x：** 其中 P⁺ 是 P 的伪逆矩阵

验证：P(P⁺x) = x ✓，所以 P⁺x 确实投影到 x。

连接 C 和 P⁺x 就得到了反投影射线。

### 2.3 两条射线求交点（第43-45页）

理想情况：两条反投影射线交于三维点 X。

**但实际中，由于噪声，两条射线通常不会精确相交！**

原因：
- 图像点的测量有噪声
- 相机参数的估计有误差

因此需要用最优化方法求**最佳近似解**。

### 2.4 数学建模（第46-48页）

投影关系（齐次坐标下）：

$$\lambda \mathbf{x} = P\mathbf{X}$$

- x 和 PX 方向相同，但差一个未知的尺度因子 λ
- 这是一个**相似关系（similarity relation）**
- 由于 λ 未知，不能直接解

**目标：** 消除尺度因子 λ，将问题转化为可解的线性方程组。

### 2.5 数学工具：叉乘（Cross Product）（第49-51页）

#### 叉乘的定义和性质

向量叉乘 a × b：
- 结果是一个**垂直于** a 和 b 的向量
- **关键性质：同方向的两个向量叉乘为零向量**

$$\mathbf{a} \times \mathbf{b} = \mathbf{0} \iff \mathbf{a} \parallel \mathbf{b}$$

#### 矩阵形式

叉乘可以写成矩阵乘法：

$$\mathbf{a} \times \mathbf{b} = [\mathbf{a}]_\times \mathbf{b}$$

其中 $[\mathbf{a}]_\times$ 是**反对称矩阵（skew-symmetric matrix）**：

对于 a = (a₁, a₂, a₃)ᵀ：

$$[\mathbf{a}]_\times = \begin{bmatrix} 0 & -a_3 & a_2 \\ a_3 & 0 & -a_1 \\ -a_2 & a_1 & 0 \end{bmatrix}$$

#### 对比：点乘

- 点乘：正交向量的点乘为**标量零**
- 叉乘：平行向量的叉乘为**零向量**

### 2.6 消除尺度因子（第52-56页）

**核心推导：**

由 λx = PX，可知 x 和 PX 方向相同，因此：

$$\mathbf{x} \times (P\mathbf{X}) = \mathbf{0}$$

设相机矩阵 P 的三行为 p₁ᵀ, p₂ᵀ, p₃ᵀ，图像点 x = (u, v, 1)ᵀ，则：

$$PX = \begin{bmatrix} p_1^T X \\ p_2^T X \\ p_3^T X \end{bmatrix}$$

展开叉乘：

$$\mathbf{x} \times (P\mathbf{X}) = \begin{bmatrix} v \cdot p_3^T X - p_2^T X \\ p_1^T X - u \cdot p_3^T X \\ u \cdot p_2^T X - v \cdot p_1^T X \end{bmatrix} = \mathbf{0}$$

即：

$$\begin{cases} v \cdot p_3^T X - p_2^T X = 0 \\ p_1^T X - u \cdot p_3^T X = 0 \\ u \cdot p_2^T X - v \cdot p_1^T X = 0 \end{cases}$$

**重要：** 第三个方程 = u × (第一个方程) + v × (第二个方程)，是线性相关的！

因此**每个 2D-3D 点对应只提供 2 个独立方程**。

### 2.7 构造线性方程组并求解（第57-59页）

将两个相机的方程合并：

$$A\mathbf{X} = \mathbf{0}$$

其中 A 是 4×4 矩阵：

$$A = \begin{bmatrix} u \cdot p_3^T - p_1^T \\ v \cdot p_3^T - p_2^T \\ u' \cdot p_3'^T - p_1'^T \\ v' \cdot p_3'^T - p_2'^T \end{bmatrix}$$

- 前两行来自相机1
- 后两行来自相机2
- X 是 4×1 的齐次坐标向量

**求解：对 A 做 SVD，X 是 V 中对应最小奇异值的列向量。**

### 2.8 特殊情况讨论（第60页）

**问题：** 当两个匹配点对应平行的 3D 射线时，系统是否有唯一解？

**答：没有。** 平行射线永远不交于有限远点，此时 3D 点在无穷远处，矩阵 A 退化（近似奇异），解不稳定。

## 3. Epipolar Geometry（对极几何）

> 对应课件第61-73页

### 3.1 基本概念图解（第62-66页）

对极几何描述了**两个相机之间的内在几何关系**，不依赖于场景结构。

```
                    X (3D点)
                   /|\
                  / | \
                 /  |  \
                /   |   \
               O----+----O'    ← 基线(Baseline)
              /|    |    |\
             / |    |    | \
            /  |    |    |  \
     ------/---|----|----|---\------
     |    x    |  极线  |    x'   |
     |    •    e         e'   •    |
     |  左图像平面  |     右图像平面  |
     ---------------------------------
```

### 3.2 五个核心概念

| 概念 | 英文 | 定义 |
|------|------|------|
| 基线 | Baseline | 连接两个相机中心 O 和 O' 的线段 |
| 极点 | Epipole | 一个相机中心在另一个相机成像平面上的**投影** |
| 极平面 | Epipolar Plane | 由 3D 点 X、O、O' 三点确定的平面 |
| 极线 | Epipolar Line | 极平面与成像平面的**交线** |
| 对极约束 | Epipolar Constraint | 匹配点必然在对应的极线上 |

### 3.3 重要性质

1. **所有极线都经过极点** e（因为所有极平面都包含基线）
2. **极点可以在图像内，也可以在图像外**
3. 对于每个 3D 点 X，有一个对应的极平面和一对极线

### 3.4 会聚相机（Converging cameras）（第69-71页）

两个相机光轴相交的情况：
- 极点可能在图像范围**外面**
- 极线从图像外的极点发散

### 3.5 平行相机（Parallel cameras）（第72-73页）

两个相机光轴平行时：
- **极点在无穷远处！**
- 所有极线互相**平行**（水平线）
- 这是双目立体匹配的理想配置

**实际意义：** 这就是为什么立体匹配前要做**图像矫正（Rectification）**——将两个相机变换到平行配置，使极线变为水平线，极大简化匹配搜索。

## 4. Epipolar Constraint（对极约束）

> 对应课件第67-77页

### 4.1 对极约束的构造（第67页）

给定左图像中一个点 x：

1. 将 x **反投影**为 3D 空间中的一条射线
2. 这条射线与**基线**一起确定了极平面
3. 极平面与**右图像平面**的交线就是右图中的**极线**

### 4.2 约束的核心含义（第68页）

> **x 的潜在匹配点一定位于对应的极线上！**

这是对极约束最重要的结论。

### 4.3 填空练习（第68页，考试可能出现）

- 左图中的点 x 映射到右图中的一条**极线（epipolar line）**
- 基线连接两个**相机中心（camera centers）**
- 左图中的极线映射到右图中的一个**点（point）**
- 极点 e 是另一个**相机中心**在本图像平面上的投影
- 图像中所有极线都相交于**极点（epipole）**

### 4.4 对极约束在立体视觉中的作用（第74-77页）

**问题：** 给定左图一个点，如何在右图中找到它的匹配点？

| 方法 | 搜索范围 | 复杂度 |
|------|---------|--------|
| 暴力搜索 | 整个图像（2D） | O(W × H) |
| **利用对极约束** | **一条线（1D）** | **O(W)** |

**对极约束将 2D 搜索问题降维为 1D 搜索问题！**

这是立体匹配效率提升的核心原因。

### 4.5 关键问题

> 如何计算极线？→ 需要本质矩阵或基础矩阵

## 5. The Essential Matrix（本质矩阵）

> 对应课件第78-107页

### 5.1 动机与定义（第79-81页）

**本质矩阵 E 是一个 3×3 矩阵，用数学方式编码了对极几何。**

**核心功能：**

$$l' = E\mathbf{x}$$

给定左图中一个点 x（相机坐标），乘以 E 就得到右图中对应的极线 l'。

### 5.2 Longuet-Higgins 方程（第82-84页）

如果 x' 在极线 l' = Ex 上，则 x' 与 l' 的点乘为零：

$$\mathbf{x'}^T (E\mathbf{x}) = 0$$

即：

$$\boxed{\mathbf{x'}^T E \mathbf{x} = 0}$$

这就是著名的 **Longuet-Higgins 方程**（对极约束的代数形式）。

**前提假设：x 和 x' 在相机坐标系中表示（内参矩阵为单位阵 K = I）。**

### 5.3 本质矩阵 vs 单应性矩阵（第85-87页）

| | 本质矩阵 E | 单应性矩阵 H |
|---|---|---|
| 矩阵大小 | 3×3 | 3×3 |
| 映射关系 | 点 → **线** | 点 → **点** |
| 数学表达 | x'ᵀEx = 0 | x' ≈ Hx |
| 几何意义 | 对极几何（任意场景） | 平面到平面的变换 |
| 适用条件 | 两视图间的一般运动 | 场景为平面或纯旋转 |

### 5.4 推导：坐标变换（第88-91页）

两个相机之间的刚体变换（类比世界坐标到相机坐标的变换 $\mathbf{X}_{cam} = R(\mathbf{X}_{world} - \mathbf{C})$）：

$$\mathbf{x'} = R(\mathbf{x} - \mathbf{t})$$

其中：
- x：3D 点在左相机坐标系中的坐标（与归一化图像点同方向）
- x'：同一 3D 点在右相机坐标系中的坐标
- R：3×3 旋转矩阵（从左相机坐标系到右相机坐标系的旋转）
- t：3×1 平移向量（右相机中心 O' 在左相机坐标系中的位置，即基线向量 O→O'）

类比：左相机扮演"世界坐标系"角色，右相机扮演"相机坐标系"角色，t 扮演相机中心 C 的角色。

### 5.5 推导：共面性条件（Coplanarity）（第92-96页）

**关键几何直觉：**

X（3D 点）、O（左相机中心）、O'（右相机中心）三点确定一个极平面。在左相机坐标系中，三个方向向量共面：

- **x**：O → X 方向（左相机射线）
- **t**：O → O' 方向（基线）
- **x − t**：O' → X 方向（右相机射线在左坐标系中的表示）

**共面条件的数学表达（均在左相机坐标系中）：**

课件第92-93页首先展示：

$$\mathbf{x}^T (\mathbf{t} \times \mathbf{x}) = 0$$

> **注意**：这个公式恒成立（$\mathbf{a} \cdot (\mathbf{b} \times \mathbf{a}) \equiv 0$），是课件的教学铺垫步骤，用于说明叉乘产生平面法向量、面内向量与法向量点乘为零的机制。课件标题写"三个共面向量 x, t, x'"但公式未涉及 x'，存在表述瑕疵。

课件第94-95页给出真正有用的表达式——用 (x − t) 替换 x：

$$(\mathbf{x} - \mathbf{t})^T (\mathbf{t} \times \mathbf{x}) = 0$$

直觉解释：
- t × x：叉乘得到一个**垂直于极平面**的法向量
- (x − t) 在极平面**内**（它是 O'→X 的方向）
- 面内向量与法向量点乘 = 0 ✓

**第96页 "Putting it together"——代入刚体变换：**

由 $\mathbf{x'} = R(\mathbf{x} - \mathbf{t})$ 得 $(\mathbf{x} - \mathbf{t}) = R^T\mathbf{x'}$，因此 $(\mathbf{x} - \mathbf{t})^T = \mathbf{x'}^T R$。

代入共面条件：

$$\mathbf{x'}^T R (\mathbf{t} \times \mathbf{x}) = 0$$

这就是**对极约束**——对图像点对 (x, x') 的非平凡约束。

### 5.6 推导：用反对称矩阵表示叉乘（第97-99页）

$$\mathbf{t} \times \mathbf{x} = [\mathbf{t}]_\times \mathbf{x}$$

其中 $[\mathbf{t}]_\times$ 是 t 的反对称矩阵（skew-symmetric matrix）：

$$\text{若 } \mathbf{t} = \begin{pmatrix} t_1 \\ t_2 \\ t_3 \end{pmatrix}, \text{ 则 } [\mathbf{t}]_\times = \begin{bmatrix} 0 & -t_3 & t_2 \\ t_3 & 0 & -t_1 \\ -t_2 & t_1 & 0 \end{bmatrix}$$

将此应用到对极约束 $\mathbf{x'}^T R (\mathbf{t} \times \mathbf{x}) = 0$：

$$\mathbf{x'}^T R [\mathbf{t}]_\times \mathbf{x} = 0$$

### 5.7 推导：最终结果（第100-102页）

定义**本质矩阵**：

$$\boxed{E = R[\mathbf{t}]_\times}$$

**Longuet-Higgins, 1981**

于是对极约束写为：

$$\mathbf{x'}^T E \mathbf{x} = 0$$

### 5.8 尺度不变性（第103页）

**问：对极约束是否对 t 的尺度不变？**

**答：是的！**

如果 t → λt，则 E → λE，而 x'ᵀ(λE)x = λ(x'ᵀEx) = 0 仍然成立。

**重要推论：** 从本质矩阵只能恢复平移方向，不能恢复绝对尺度。这就是为什么单目 SLAM 有**尺度漂移**问题。

### 5.9 本质矩阵的性质（第104-106页）

#### 极线计算

| 极线 | 公式 | 说明 |
|------|------|------|
| 右图中的极线 | l' = Ex | 左图的点 → 右图的极线 |
| 左图中的极线 | l = Eᵀx' | 右图的点 → 左图的极线 |

#### 极点计算

| 极点 | 公式 | 说明 |
|------|------|------|
| 右图极点 e' | Eᵀe' = 0 | e' 在 Eᵀ 的零空间中 |
| 左图极点 e | Ee = 0 | e 在 E 的零空间中 |

验证：所有极线过极点，即 l'ᵀe' = (Ex)ᵀe' = xᵀEᵀe' = xᵀ · 0 = 0 ✓

#### E 矩阵的其他性质

- **秩为 2**（rank(E) = 2），因为 [t]× 的秩为 2
- **自由度为 5**（3 个旋转参数 + 3 个平移参数 - 1 个尺度 = 5）
- 两个非零奇异值相等：σ₁ = σ₂ ≠ 0, σ₃ = 0

### 5.10 局限性（第107页）

本质矩阵的假设：**2D 点在相机坐标系中表示**。

即假设内参矩阵 K = I（单位阵）。

实际中我们得到的是**像素坐标**，不是相机坐标。

→ 如何处理？→ 引出基础矩阵 F

## 6. The Fundamental Matrix（基础矩阵）

> 对应课件第108-116页

### 6.1 从本质矩阵到基础矩阵（第109-110页）

**基础矩阵 F 是本质矩阵 E 的推广：**

| | 本质矩阵 E | 基础矩阵 F |
|---|---|---|
| 输入点的坐标 | 相机坐标（归一化坐标） | **像素坐标** |
| 对内参的假设 | K = I | **无需已知 K** |
| 包含的参数 | 仅外参 (R, t) | 内参 + 外参 |

### 6.2 推导过程（第111-112页）

**图像像素坐标**与**相机坐标**的关系：

$$\mathbf{x}_{cam} = K^{-1}\mathbf{x}_{pixel}$$

将其代入 Longuet-Higgins 方程 $\mathbf{x'}_{cam}^T E \mathbf{x}_{cam} = 0$：

$$(K'^{-1}\mathbf{x'})^T E (K^{-1}\mathbf{x}) = 0$$

$$\mathbf{x'}^T \underbrace{K'^{-T} E K^{-1}}_{= F} \mathbf{x} = 0$$

因此：

$$\boxed{F = K'^{-T} E K^{-1} = K'^{-T} R [\mathbf{t}]_\times K^{-1}}$$

### 6.3 基础矩阵的对极约束（第112-113页）

$$\boxed{\mathbf{x'}^T F \mathbf{x} = 0}$$

其中 x 和 x' 是**像素坐标**（不需要知道内参！）。

F 直接将**像素**映射到**极线**。

### 6.4 F 的性质（第113-114页）

与 E 完全类似，但操作对象是像素坐标：

| 性质 | 公式 |
|------|------|
| 对极约束 | x'ᵀFx = 0 |
| 右图极线 | l' = Fx |
| 左图极线 | l = Fᵀx' |
| 右图极点 | Fᵀe' = 0 |
| 左图极点 | Fe = 0 |
| 秩 | rank(F) = 2 |
| 自由度 | 7（9个元素 - 1尺度 - 1秩约束 = 7） |

### 6.5 F 的参数依赖（第114-116页）

$$F = K'^{-T} [\mathbf{t}]_\times R \, K^{-1}$$

F 同时依赖于：
- 内参：K, K'
- 外参：R, t

**关键优势：** 虽然 F 包含所有参数，但我们可以**直接从匹配点对估计 F**，而**完全不需要事先知道内参或外参**！

## 7. The 8-Point Algorithm（8点算法）

> 对应课件第117-140页

### 7.1 问题设定（第118-120页）

**已知：** M 对匹配的图像点 {(xᵢ, x'ᵢ)}，i = 1, ..., M

**目标：** 估计 3×3 基础矩阵 F

**每对对应点满足：**

$$\mathbf{x'}_i^T F \mathbf{x}_i = 0$$

### 7.2 展开为线性方程（第120-122页）

设 $\mathbf{x} = (u, v, 1)^T$，$\mathbf{x'} = (u', v', 1)^T$，$F = \begin{bmatrix} f_{11} & f_{12} & f_{13} \\ f_{21} & f_{22} & f_{23} \\ f_{31} & f_{32} & f_{33} \end{bmatrix}$

展开 x'ᵀFx = 0：

$$u'u \cdot f_{11} + u'v \cdot f_{12} + u' \cdot f_{13} + v'u \cdot f_{21} + v'v \cdot f_{22} + v' \cdot f_{23} + u \cdot f_{31} + v \cdot f_{32} + 1 \cdot f_{33} = 0$$

这是关于 F 的 9 个未知元素 $f_{ij}$ 的**一个线性方程**。

### 7.3 需要多少对点？（第123-124页）

**每对对应点贡献 1 个方程**（不是 2 个！）

对比：
| 问题 | 每对点贡献的方程数 | 原因 |
|------|-------------------|------|
| 单应性估计 | 2 个方程 | x' = Hx 有 2 个分量约束 |
| **基础矩阵估计** | **1 个方程** | x'ᵀFx = 0 是标量等式 |

F 有 9 个未知数，尺度不确定性消去 1 个自由度 → **需要至少 8 对点**。

这就是**"8 点算法"**名称的由来！

### 7.4 构造齐次线性方程组（第125-127页）

将 F 展平为 9×1 向量：

$$\mathbf{f} = (f_{11}, f_{12}, f_{13}, f_{21}, f_{22}, f_{23}, f_{31}, f_{32}, f_{33})^T$$

则每对点的方程可以写为：

$$\mathbf{a}_i^T \mathbf{f} = 0$$

其中：

$$\mathbf{a}_i = (u_i'u_i, \; u_i'v_i, \; u_i', \; v_i'u_i, \; v_i'v_i, \; v_i', \; u_i, \; v_i, \; 1)^T$$

堆叠 M 个方程：

$$A\mathbf{f} = \mathbf{0}$$

其中 A 是 M×9 矩阵。

### 7.5 求解：总体最小二乘 + SVD（第125-127页）

由于噪声，Af = 0 不能精确满足。改为求：

$$\min_{\mathbf{f}} \|A\mathbf{f}\|^2 \quad \text{subject to} \quad \|\mathbf{f}\| = 1$$

**解法：对 A 做 SVD，f 是 V 中对应最小奇异值的列向量。**

### 7.6 完整算法步骤（第128-133页）

#### 8 点算法的完整流程：

```
输入：M ≥ 8 对匹配点 {(xᵢ, x'ᵢ)}
输出：基础矩阵 F

步骤：
1. 归一化点坐标（Normalize points）
   - 平移使质心在原点
   - 缩放使平均距离为 √2
   - 得到变换矩阵 T 和 T'
   - x̂ᵢ = Txᵢ，x̂'ᵢ = T'x'ᵢ

2. 构造 M×9 矩阵 A
   - 每对归一化点贡献一行

3. 对 A 做 SVD：A = UΣV^T

4. F̂ 的元素 = V 中对应最小奇异值的列
   - 将 9 维向量重排为 3×3 矩阵

5. 强制 rank-2 约束（Enforce rank-2 constraint）
   - 对 F̂ 做 SVD：F̂ = UfΣfVf^T
   - 令 Σf' = diag(σ₁, σ₂, 0)（置零最小奇异值）
   - F̂' = UfΣf'Vf^T

6. 反归一化（Un-normalize）
   - F = T'^T F̂' T
```

### 7.7 为什么要归一化？（Hartley 的贡献）

**不归一化会怎样？**

像素坐标的数值范围通常是 [0, 1000+]，直接使用会导致：
- A 矩阵的列之间数值差异很大
- SVD 的数值不稳定
- 结果对噪声极其敏感

**归一化的效果：**
- 数值稳定性大幅提高
- 对噪声的鲁棒性增强
- 这是 Hartley (1997) 的重要贡献

### 7.8 为什么要强制 rank-2 约束？（第131-132页）

**理论上 F 的秩为 2**（因为 det(F) = 0）。

原因：F = K'⁻ᵀ[t]×RK⁻¹ 中，[t]× 是秩为 2 的矩阵。

但 SVD 直接求出的 F 通常**满秩**（rank = 3），因为噪声打破了秩约束。

**强制方法（最优秩-2 近似）：**

$$\text{问题：} \min_{F'} \|F - F'\|_F \quad \text{s.t.} \quad \text{rank}(F') = 2$$

$$\text{解法：} F = U\Sigma V^T, \quad \Sigma = \text{diag}(\sigma_1, \sigma_2, \sigma_3)$$

$$F' = U \cdot \text{diag}(\sigma_1, \sigma_2, 0) \cdot V^T$$

这是 **Eckart-Young-Mirsky 定理** 的应用——SVD 截断是最优低秩近似。

### 7.9 反归一化

由于我们对输入点做了归一化变换 x̂ = Tx，所以估计得到的 F̂ 对应的是归一化后的坐标。

原始坐标下的 F：

$$F = T'^T \hat{F} T$$

### 7.10 求解极点（第138-140页）

求出 F 后，如何找极点？

极点 e 满足：

$$F\mathbf{e} = \mathbf{0}$$

即 e 在 F 的**右零空间**中。

**求解方法：对 F 做 SVD，e 就是 V 中对应零奇异值（最小奇异值）的列。**

（由于已经强制了 rank-2，F 确实有一个零奇异值）

## 8. 总结与考试重点

### 8.1 核心公式速查表

| 概念 | 核心公式 | 求解方法 |
|------|---------|---------|
| 三角化 | x × (PX) = 0 → AX = 0 | SVD（最小奇异值对应列） |
| 本质矩阵定义 | E = [t]×R | 由外参构造 |
| 本质矩阵约束 | x'ᵀEx = 0 | 相机坐标系 |
| 基础矩阵定义 | F = K'⁻ᵀ E K⁻¹ | 包含内参 |
| 基础矩阵约束 | x'ᵀFx = 0 | 像素坐标系 |
| 极线（右图） | l' = Fx 或 l' = Ex | 矩阵乘法 |
| 极线（左图） | l = Fᵀx' 或 l = Eᵀx' | 转置矩阵乘法 |
| 极点 | Fe = 0 | SVD 求零空间 |
| 秩约束 | rank(E) = rank(F) = 2 | SVD 截断 |
| 8点算法 | Af = 0, ‖f‖=1 | SVD + rank-2 强制 |

### 8.2 高频考点

#### 考点1：E 和 F 的区别

| 比较维度 | 本质矩阵 E | 基础矩阵 F |
|---------|-----------|-----------|
| 坐标系 | 相机坐标（归一化） | 像素坐标 |
| 内参假设 | 需要已知 K（K=I） | 不需要已知 K |
| 参数依赖 | 仅 R, t | K, K', R, t |
| 自由度 | 5 | 7 |
| 关系 | E = K'ᵀFK | F = K'⁻ᵀEK⁻¹ |

#### 考点2：为什么叫"8点"算法？

- F 有 9 个元素
- 由于尺度不确定性（λF 与 F 等价），实际自由度为 8
- 每对匹配点只提供 1 个方程（x'ᵀFx = 0 是标量）
- 因此需要 **至少 8 对点**

#### 考点3：SVD 在本课中的全部应用

| 场景 | SVD 的作用 |
|------|-----------|
| 求相机矩阵 P | Ax = 0 最小二乘解 |
| 求相机中心 C | P 的零空间 |
| 三角化求 3D 点 | AX = 0 最小二乘解 |
| 求基础矩阵 F | Af = 0 最小二乘解 |
| 强制 rank-2 约束 | 最优低秩近似 |
| 求极点 e | F 的零空间 |

> **SVD 是本课最核心的计算工具，几乎所有问题最终都用 SVD 求解！**

#### 考点4：对极约束的几何意义

- **几何意义：** 匹配点一定在极线上
- **实际作用：** 将立体匹配从 2D 搜索降为 1D 搜索
- **代数表达：** x'ᵀFx = 0

#### 考点5：rank-2 约束的来源

- E = [t]×R 中，[t]× 是秩为 2 的反对称矩阵
- 所以 E 的秩最多为 2
- F = K'⁻ᵀEK⁻¹ 是 E 左右乘可逆矩阵，秩不变
- 所以 F 的秩也是 2
- 几何含义：所有极线交于一点（极点），所以 F 必须奇异

#### 考点6：推导链路（务必记住逻辑脉络）

```
共面性条件
    ↓
x'ᵀ(t × Rx) = 0     （三向量共面，混合积为零）
    ↓
x'ᵀ[t]×Rx = 0       （用反对称矩阵表示叉乘）
    ↓
x'ᵀEx = 0, E=[t]×R  （定义本质矩阵）
    ↓
(K'⁻¹x')ᵀE(K⁻¹x)=0 （用像素坐标代替相机坐标）
    ↓
x'ᵀFx = 0, F=K'⁻ᵀEK⁻¹  （定义基础矩阵）
    ↓
8点算法求解 F        （从匹配点直接估计）
```

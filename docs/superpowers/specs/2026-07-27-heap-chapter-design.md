## 示例设计

插入、删除和建堆使用一致的最小堆数组，确保每一步都能在树形结构和数组表示之间对应。修正现有“插入 11 后与根结点 09 交换”的错误示例：当父结点为 09 时，11 已满足最小堆性质，不应继续上浮。

所有伪代码和 C++ 代码统一采用 0 基数组：

- 父结点：`(i - 1) / 2`
- 左孩子：`2 * i + 1`
- 右孩子：`2 * i + 2`
- 最后一个非叶结点：`n / 2 - 1`

## 边界与错误处理

C++ 示例明确处理以下情况：

- 空堆查询或删除；
- 单元素堆删除；
- 结点只有左孩子；
- 插入后一路上浮到根；
- 删除后一路下沉到叶结点；
- 重复元素；
- 已有数组为空时建堆。

不扩展到索引堆、二项堆、斐波那契堆和任意位置修改键值等高级内容。

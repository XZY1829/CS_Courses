## 第 1 题 - 栈实现 [application]

> 使用数组实现一个支持泛型的栈类（Stack），包含push、pop、top、empty方法，并处理空栈异常。

> [!answer]- 查看答案
> ```cpp
> template<class T, int MaxSize=100>
> class Stack {
>     T data[MaxSize];
>     int topIdx;
> public:
>     Stack() : topIdx(-1) {}
>     bool empty() const { return topIdx == -1; }
>     bool full() const { return topIdx == MaxSize - 1; }
>     void push(const T& val) {
>         if (full()) throw runtime_error("Stack overflow");
>         data[++topIdx] = val;
>     }
>     T pop() {
>         if (empty()) throw runtime_error("Stack underflow");
>         return data[topIdx--];
>     }
>     T top() const {
>         if (empty()) throw runtime_error("Empty stack");
>         return data[topIdx];
>     }
> };
> ```
> 核心知识点：类模板、非类型模板参数、异常处理。

## 第 2 题 - 迭代器设计 [application]

> 为链表类实现一个前向迭代器，使其可以用在range-for循环中。需要哪些接口？

> [!answer]- 查看答案
> 最低要求的接口：
> ```cpp
> class Iterator {
>     Node* current;
> public:
>     Iterator(Node* p) : current(p) {}
>     int& operator*() { return current->data; }
>     Iterator& operator++() {    // 前缀++
>         current = current->next;
>         return *this;
>     }
>     bool operator!=(const Iterator& other) const {
>         return current != other.current;
>     }
> };
> // 链表类需要提供：
> Iterator begin() { return Iterator(head); }
> Iterator end() { return Iterator(nullptr); }
> ```
> 有了`begin()`和`end()`，就可以使用`for(auto& x : list)`语法。

## 第 3 题 - 深拷贝 String [application]

> 实现String类的拷贝构造函数和赋值运算符，确保深拷贝。为什么浅拷贝会出问题？

> [!answer]- 查看答案
> ```cpp
> class String {
>     char* data;
>     int len;
> public:
>     // 拷贝构造
>     String(const String& other) : len(other.len) {
>         data = new char[len + 1];
>         strcpy(data, other.data);
>     }
>     // 赋值运算符
>     String& operator=(const String& other) {
>         if (this != &other) {  // 自赋值保护
>             delete[] data;
>             len = other.len;
>             data = new char[len + 1];
>             strcpy(data, other.data);
>         }
>         return *this;
>     }
> };
> ```
> **浅拷贝问题**：两个对象指向同一块内存，一个析构后另一个成为悬垂指针（double-free）。

## 第 4 题 - 多态应用 [application]

> 设计一个Vehicle继承体系：基类Vehicle有虚函数display()，派生类Car和Truck各自重写。用基类指针数组管理一组对象并调用display()。

> [!answer]- 查看答案
> ```cpp
> class Vehicle {
> protected:
>     string brand;
>     int year;

>     Vehicle(string b, int y) : brand(b), year(y) {}

>     int seats;
> public:
>     Car(string b, int y, int s) : Vehicle(b,y), seats(s) {}

> };

> vector<Vehicle*> fleet;
> fleet.push_back(new Car("Toyota", 2024, 5));
> for (auto v : fleet) v->display();  // 动态绑定
> ```

## 第 5 题 - 操作符重载综合 [application]

> 为Vector类重载 `+`、`[]`、`<<` 操作符。`+`实现向量加法，`[]`实现元素访问。

> [!answer]- 查看答案
> ```cpp
> class Vector {
>     double* elem;
>     int size;
> public:
>     double& operator[](int i) { return elem[i]; }
>     const double& operator[](int i) const { return elem[i]; }
>     
>     Vector operator+(const Vector& v) const {
>         Vector result(size);
>         for (int i = 0; i < size; i++)
>             result.elem[i] = elem[i] + v.elem[i];
>         return result;
>     }
>     
>     friend ostream& operator<<(ostream& os, const Vector& v) {
>         os << "(";
>         for (int i = 0; i < v.size; i++) {
>             if (i > 0) os << ", ";
>             os << v.elem[i];
>         }
>         return os << ")";
>     }
> };
> ```

## 第 6 题 - 智能指针实现 [application]

> 实现一个简单的SmartPointer类模板，支持自动释放内存、`*`和`->`操作符。

> [!answer]- 查看答案
> ```cpp
> template<class T>
> class SmartPointer {
>     T* ptr;
> public:
>     explicit SmartPointer(T* p = nullptr) : ptr(p) {}
>     ~SmartPointer() { delete ptr; }
>     
>     T& operator*() { return *ptr; }
>     T* operator->() { return ptr; }
>     
>     // 禁止拷贝（独占语义）
>     SmartPointer(const SmartPointer&) = delete;
>     SmartPointer& operator=(const SmartPointer&) = delete;
>     
>     // 移动语义
>     SmartPointer(SmartPointer&& other) : ptr(other.ptr) {
>         other.ptr = nullptr;
>     }
> };
> ```
> 体现RAII思想：构造时获取资源，析构时释放资源。

## 第 7 题 - 静态成员应用 [application]

> 设计一个Plant类，用静态成员统计已创建的对象数量。要求在构造和析构时正确维护计数。

> [!answer]- 查看答案
> ```cpp
> class Plant {
>     string name;
>     static int count;  // 声明
> public:
>     Plant(string n) : name(n) { ++count; }
>     Plant(const Plant& p) : name(p.name) { ++count; }
>     ~Plant() { --count; }
>     static int getCount() { return count; }
> };
> int Plant::count = 0;  // 定义并初始化
> ```
> **注意**：拷贝构造函数中也要递增计数！否则拷贝出的对象不被统计。

## 第 8 题 - Map容器实现 [analysis]

> 用键值对数组实现一个简单的Map类，支持`operator[]`实现查找/插入、`remove`删除。分析时间复杂度。

> [!answer]- 查看答案
> ```cpp
> template<class K, class V>
> class Map {
>     struct Pair { K key; V value; };
>     vector<Pair> data;
>     int findIndex(const K& key) const {
>         for (int i = 0; i < data.size(); i++)
>             if (data[i].key == key) return i;
>         return -1;
>     }
> public:
>     V& operator[](const K& key) {
>         int idx = findIndex(key);
>         if (idx == -1) {
>             data.push_back({key, V()});
>             return data.back().value;
>         }
>         return data[idx].value;
>     }
>     void remove(const K& key) {
>         int idx = findIndex(key);
>         if (idx != -1)
>             data.erase(data.begin() + idx);
>     }
> };
> ```
> **时间复杂度**：查找O(n)、插入O(n)（需先查重）、删除O(n)。相比std::map的O(log n)效率低，但实现简单。

## 第 9 题 - 表达式求值 [analysis]

> 用栈实现一个简单的整数四则运算计算器（支持括号）。描述算法思路并写出关键代码。

> [!answer]- 查看答案
> **算法思路（调度场算法/双栈法）**：
> 1. 使用数值栈和运算符栈
> 2. 遇到数字入数值栈
> 3. 遇到运算符：若栈顶优先级 >= 当前，先计算栈顶
> 4. 遇到`(`直接入栈，遇到`)`弹出计算直到`(`
> 
> ```cpp
> int calculate(const string& expr) {
>     stack<int> nums;
>     stack<char> ops;
>     for (int i = 0; i < expr.size(); i++) {
>         if (isdigit(expr[i])) {
>             int n = 0;
>             while (i < expr.size() && isdigit(expr[i]))
>                 n = n*10 + (expr[i++]-'0');
>             i--;
>             nums.push(n);
>         } else if (expr[i] == '(') {
>             ops.push('(');
>         } else if (expr[i] == ')') {
>             while (ops.top() != '(') eval(nums, ops);
>             ops.pop();
>         } else if (isOp(expr[i])) {
>             while (!ops.empty() && priority(ops.top()) >= priority(expr[i]))
>                 eval(nums, ops);
>             ops.push(expr[i]);
>         }
>     }
>     while (!ops.empty()) eval(nums, ops);
>     return nums.top();
> }
> ```

## 第 10 题 - 综合设计 [analysis]

> 机试中要求"用面向对象方法"设计程序，你需要满足哪些设计原则？以多项式(Polynomial)类为例说明。

> [!answer]- 查看答案
> **设计原则**：
> 1. **封装**：数据(系数数组)私有，通过接口访问
> 2. **操作符重载**：`+`、`-`、`*`、`=`、`[]`、`<<`
> 3. **资源管理**：动态数组需要深拷贝（Rule of Three）
> 4. **可复用**：模板化或提供清晰接口
> 
> ```cpp
> class Polynomial {
>     double* coeff;  // coeff[i] = x^i的系数
>     int degree;
> public:
>     Polynomial(int deg=0);         // 构造
>     Polynomial(const Polynomial&); // 拷贝构造（深拷贝）
>     ~Polynomial();                 // 析构
>     Polynomial& operator=(const Polynomial&); // 赋值
>     Polynomial operator+(const Polynomial&) const;
>     double evaluate(double x) const; // 求值
>     friend ostream& operator<<(ostream&, const Polynomial&);
> };
> ```
> 关键考点：动态内存管理 + 操作符重载 + const正确性。

## 重点题目解析

### String类（综合考点最多）

**考查**：深拷贝、Rule of Three、操作符重载

关键实现要点：
- 构造函数：`new char[len+1]` + `strcpy`
- **拷贝构造**：深拷贝（重新分配+复制）
- **赋值操作符**：自赋值检查 → 释放旧空间 → 深拷贝 → 返回*this
- **析构函数**：`delete[] str`
- `operator+`：拼接，创建新String返回
- `operator[]`：返回字符引用
- `operator<<`：友元，输出str内容

### Vector类（动态数组+迭代器）

**考查**：动态内存管理、迭代器设计、模板

关键实现要点：
- 动态扩容（capacity vs size）
- push_back时容量不足需realloc
- 迭代器 = 指针的封装（`T*`）
- `begin()` 返回第一个元素地址
- `end()` 返回最后一个元素后一个位置

### SmartPointer（引用计数）

**考查**：RAII、操作符重载、引用计数

```cpp
template<class T>
class SmartPointer {
    T *ptr;
    int *ref_count;  // 共享的引用计数
public:
    SmartPointer(T *p) : ptr(p), ref_count(new int(1)) {}
    SmartPointer(const SmartPointer& sp) : ptr(sp.ptr), ref_count(sp.ref_count) {
        (*ref_count)++;
    }
    ~SmartPointer() {
        if (--(*ref_count) == 0) {
            delete ptr;
            delete ref_count;
        }
    }
    T& operator*() { return *ptr; }
    T* operator->() { return ptr; }
};
```

### Plant静态成员

**考查**：静态数据成员、对象计数

```cpp
class Plant {
    static int total;  // 存活对象总数
    string name;
public:
    Plant(string n) : name(n) { total++; }
    Plant(const Plant& p) : name(p.name) { total++; }
    ~Plant() { total--; }
    static int getTotal() { return total; }
};
int Plant::total = 0;
```

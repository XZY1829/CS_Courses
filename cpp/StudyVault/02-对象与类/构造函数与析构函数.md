# 构造函数与析构函数（★★★）

#cpp #class #constructor #destructor

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 构造函数 | 与类同名、无返回类型、对象创建时自动调用 |
| 默认构造函数 | 无参数或所有参数有默认值的构造函数 |
| 析构函数 | `~ClassName()`、对象消亡时自动调用、不可重载 |
| 成员初始化表 | 构造函数头与函数体之间的初始化列表 |
| 调用时机 | 构造：对象创建时 / 析构：对象生命周期结束时 |

## 构造函数 (Constructor)

### 基本特征

- 名字与类名相同
- 无返回值类型（连void都不写）
- 可以重载（多个构造函数）
- 对象创建时**自动调用**，之后不可再手动调用

### 构造函数重载

```cpp
class A {
    int x, y;
public:
    A()             { x = 0; y = 0; }       // 默认构造函数
    A(int x1)       { x = x1; y = 0; }      // 带一个参数
    A(int x1, int y1) { x = x1; y = y1; }   // 带两个参数
};
```

等价的带默认参数写法：
```cpp
A(int x1 = 0, int y1 = 0) { x = x1; y = y1; }
```

### 对象创建时指定构造函数

```cpp
A a1;            // 调用默认构造函数 A()
A a2(1);         // 调用 A(int)
A a3(1, 2);      // 调用 A(int, int)
A a4{1, 2};      // C++11 统一初始化语法
A *p = new A(3); // 动态对象，调用 A(int)
A arr[4];        // 数组中每个元素调用默认构造函数
```

> [!warning] 易错点
> - `A a1();` 这不是创建对象！这是**函数声明**。应写成 `A a1;` 或 `A a1{};`
> - 对象创建后，不能再调用构造函数：`a.A(1);` → Error!

### 成员初始化表 (Member Initializer List)

**何时必须使用**：
- **const 成员**：不能用赋值初始化
- **引用成员**：必须初始化时绑定
- **没有默认构造函数的成员对象**

```cpp
class A {
    int x;
    const int y;
    int &z;
public:
    A() : y(1), z(x) {   // 成员初始化表
        x = 0;            // 普通赋值
    }
};
```

> [!important] 初始化顺序
> 初始化表中的书写顺序不决定初始化顺序！
> 真正的初始化顺序由**成员在类定义中的声明顺序**决定。

### 临时对象

```cpp
void f(A a) { ... }
f(A(10));  // 创建临时对象作为实参
```

## 析构函数 (Destructor)

### 基本特征

- 名字为 `~ClassName`
- 无返回类型、无参数
- **不可重载**（一个类只有一个析构函数）
- 对象消亡时**自动调用**

### 何时需要自定义析构函数

当对象额外申请了资源（如动态内存）时：

```cpp
class String {
    int len;
    char *str;
public:
    String(const char *s) {
        len = strlen(s);
        str = new char[len + 1];  // 额外申请内存
        strcpy(str, s);
    }
    ~String() {
        delete[] str;  // 归还额外申请的内存
    }
};
```

> [!tip] RAII 思想
> "资源获取即初始化" — 构造时获取资源，析构时释放资源。
> 这是C++管理资源的核心模式。

### 对象消亡的顺序

```
构造顺序：先基类 → 成员对象 → 自身
析构顺序：先自身 → 成员对象 → 基类（与构造相反）
```

- 局部对象：离开作用域时消亡
- 全局对象：程序结束时消亡
- 动态对象：执行 `delete` 时消亡
- 临时对象：表达式结束时消亡

## 构造与析构的完整流程

```
对象创建                        对象消亡
   │                              │
   ├─ 分配内存空间                 ├─ 调用析构函数
   ├─ 执行成员初始化表              │   ├─ 执行析构函数体
   ├─ 执行构造函数体                │   └─ 成员对象析构
   └─ 对象可用                     └─ 释放内存空间
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "默认构造函数" | 无参或所有参数有默认值 |
| "A a(); 是什么" | 函数声明，不是对象创建！ |
| "初始化表的顺序" | 按声明顺序，非书写顺序 |
| "何时必须用初始化表" | const成员、引用成员、无默认构造的成员对象 |
| "析构函数能重载吗" | 不能，一个类只有一个析构函数 |
| "何时需要自定义析构" | 对象额外申请了资源（如new的内存） |
| "析构顺序" | 与构造相反 |

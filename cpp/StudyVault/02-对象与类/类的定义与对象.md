# 类的定义与对象（★★★）

#cpp #oop #class #object

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 类 | 用户自定义类型，由数据成员+成员函数组成 |
| 对象 | 类的实例，程序运行时的基本计算单位 |
| 数据成员 | 描述对象的属性/状态 |
| 成员函数 | 描述对象的行为/操作 |
| 访问控制 | public/private/protected |
| 创建方式 | 直接方式(变量) / 间接方式(new) |

## 类的定义

```cpp
class ClassName {
public:      // 外部可访问
    void method();
private:     // 仅本类可访问（默认）
    int data;
protected:   // 本类+派生类可访问
    int helper;
};
```

**关键规则**：
- class默认访问控制是 **private**，struct默认是 **public**
- 数据成员类型如果是未完成定义的类，只能用**指针或引用**（编译器需要知道对象大小）
- 成员函数可以放在类内（建议内联）或类外（用 `ClassName::` 受限）
- 类内前面的成员可以使用后面定义的成员名

## 对象的创建

### 直接方式（栈上/全局）

```cpp
A a1;          // 单个对象，调用默认构造函数
A a2[100];     // 对象数组
```

生命周期由变量作用域决定。

### 间接方式（堆上，动态对象）

```cpp
A *p = new A;       // 单个动态对象
A *q = new A[100];  // 动态对象数组
delete p;           // 撤销单个
delete[] q;         // 撤销数组
```

> [!important] 不要用malloc/free创建/销毁对象
> 它们不会调用构造函数和析构函数。

## 对象的操作

```cpp
A a;
a.f();        // 通过对象名调用

A *p = new A;
p->f();       // 通过指针调用（等价于 (*p).f()）
```

**对象作为参数**：
- `void f(A a)` — 传值，复制一份（调用拷贝构造函数）
- `void f(A &a)` — 传引用，操作原对象
- `void f(const A &a)` — const引用，只读访问

**对象作为返回值**：
- `A f()` — 返回副本（创建临时对象）
- `A& f()` — 返回引用（不创建新对象，但注意不要返回局部对象的引用！）

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "class与struct区别" | 仅默认访问控制不同(private vs public) |
| "不完整类型成员" | 只能用指针或引用 |
| "对象数组创建" | 每个元素都调用默认构造函数 |
| "动态对象" | new创建，delete销毁，通过指针访问 |
| "返回引用vs返回值" | 引用不创建临时对象，但不能返回局部量 |

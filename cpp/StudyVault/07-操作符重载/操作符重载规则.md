# 操作符重载规则（★★★）

#cpp #oop #operator-overload

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 本质 | 为自定义类型赋予操作符新含义 |
| 语法 | `返回类型 operator符号(参数)` |
| 实现方式 | 成员函数 或 友元/全局函数 |
| 不可重载 | `::` `.` `.*` `?:` `sizeof` `typeid` |
| 不可改变 | 操作数个数、优先级、结合性 |

## 为什么需要操作符重载

```cpp
class Complex {
    double real, imag;
public:
    Complex add(const Complex& c) const;  // 不直观
};
Complex a, b, c;
c = a.add(b);     // 丑陋
c = a + b;        // 操作符重载后：直观！
```

## 基本语法

### 成员函数方式

```cpp
class Complex {
    double real, imag;
public:
    Complex operator+(const Complex& c) const {
        return Complex(real + c.real, imag + c.imag);
    }
};
// a + b 等价于 a.operator+(b)
```

左操作数是this（调用对象），右操作数是参数。

### 友元/全局函数方式

```cpp
class Complex {
    double real, imag;
    friend Complex operator+(const Complex& a, const Complex& b);
};
Complex operator+(const Complex& a, const Complex& b) {
    return Complex(a.real + b.real, a.imag + b.imag);
}
// a + b 等价于 operator+(a, b)
```

两个操作数都是参数。

## 成员函数 vs 友元函数

| 维度 | 成员函数 | 友元/全局函数 |
|------|----------|-------------|
| 左操作数 | 必须是本类对象 | 可以是任意类型 |
| 隐式转换 | 左操作数不能隐式转换 | 两个操作数都可以 |
| 访问private | 天然可以 | 需要friend声明 |
| 适用场景 | 修改自身状态（+=、++） | 对称操作（+、==） |

> [!important] 必须用成员函数的操作符
> `=`（赋值）、`[]`（下标）、`()`（函数调用）、`->`（指针访问）、`类型转换`

> [!important] 必须用友元/全局的典型场景
> `<<`（输出流）、`>>`（输入流）— 左操作数是ostream/istream，不是本类

## 重载规则

1. **不能创造新操作符**
2. **不能改变操作数个数**
3. **不能改变优先级和结合性**
4. **至少有一个操作数是自定义类型**
5. **不可重载的操作符**：`::` `.` `.*` `?:` `sizeof`

## 常见操作符重载模式

| 操作符 | 推荐方式 | 返回类型 | 说明 |
|--------|----------|----------|------|
| `+` `-` `*` `/` | 友元 | 值(新对象) | 不修改操作数 |
| `+=` `-=` | 成员 | `A&`(引用) | 修改自身 |
| `==` `!=` `<` | 友元 | bool | 对称比较 |
| `++`(前缀) | 成员 | `A&` | 修改后返回自身 |
| `++`(后缀) | 成员 | `A`(值) | 返回旧值副本 |
| `<<` `>>` | 友元 | `ostream&`/`istream&` | 链式输出 |
| `[]` | 成员 | 引用 | 下标访问 |
| `=` | 成员 | `A&` | 赋值 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "哪些不能重载" | `::` `.` `.*` `?:` `sizeof` |
| "<<为什么用友元" | 左操作数是ostream，不是本类 |
| "=为什么必须成员" | 编译器规定，防止全局赋值干扰 |
| "+推荐返回什么" | 值（新对象），不修改操作数 |
| "+=推荐返回什么" | 引用（*this），修改了自身 |

# 常见操作符重载（★★★）

#cpp #oop #operator-overload

## 算术操作符 (+, -, *, /)

```cpp
class Complex {
    double real, imag;
public:
    Complex(double r=0, double i=0) : real(r), imag(i) {}
    friend Complex operator+(const Complex& a, const Complex& b) {
        return Complex(a.real + b.real, a.imag + b.imag);
    }
    Complex& operator+=(const Complex& c) {
        real += c.real; imag += c.imag;
        return *this;
    }
};
```

**设计模式**：先实现 `+=`（成员），再用它实现 `+`（友元）：
```cpp
Complex operator+(const Complex& a, const Complex& b) {
    Complex temp(a);
    temp += b;
    return temp;
}
```

## 比较操作符 (==, !=, <)

```cpp
friend bool operator==(const Complex& a, const Complex& b) {
    return a.real == b.real && a.imag == b.imag;
}
friend bool operator!=(const Complex& a, const Complex& b) {
    return !(a == b);
}
```

## 前缀/后缀递增 (++/--)

```cpp
class Counter {
    int n;
public:
    Counter& operator++() {        // 前缀 ++c
        n++;
        return *this;              // 返回修改后的自身
    }
    Counter operator++(int) {      // 后缀 c++（int是哑参数，用于区分）
        Counter old = *this;       // 保存旧值
        n++;
        return old;                // 返回旧值
    }
};
```

> [!important] 前缀vs后缀的区别
> - 前缀`++c`：先增后用，返回**引用**（高效）
> - 后缀`c++`：先用后增，返回**旧值副本**（需要额外复制）
> - 优先使用前缀（效率更高）

## 下标操作符 ([])

```cpp
class Vector {
    int *data;
    int size;
public:
    int& operator[](int index) {              // 非const版本
        return data[index];                    // 可读可写
    }
    const int& operator[](int index) const {  // const版本
        return data[index];                    // 只读
    }
};
```

## 流操作符 (<<, >>)

```cpp
class Point {
    int x, y;
    friend ostream& operator<<(ostream& os, const Point& p);
    friend istream& operator>>(istream& is, Point& p);
};

ostream& operator<<(ostream& os, const Point& p) {
    os << "(" << p.x << "," << p.y << ")";
    return os;  // 支持链式输出 cout << p1 << p2
}
istream& operator>>(istream& is, Point& p) {
    is >> p.x >> p.y;
    return is;
}
```

## 类型转换操作符

```cpp
class Fraction {
    int num, den;
public:
    operator double() const {  // 隐式转换为double
        return (double)num / den;
    }
};
Fraction f(3, 4);
double d = f;  // 自动调用 operator double()，d = 0.75
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "前缀vs后缀++区别" | 前缀返回引用，后缀返回旧值副本 |
| "后缀++的哑参数" | `int`参数仅用于区分，无实际意义 |
| "<<返回什么" | `ostream&`以支持链式输出 |
| "[]为何两个版本" | const和非const对象分别调用 |
| "operator double()" | 类型转换操作符，无返回类型声明 |

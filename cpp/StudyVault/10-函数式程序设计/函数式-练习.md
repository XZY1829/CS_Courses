## 第 1 题 - 范式区分 [recall]

> 命令式编程和声明式编程的核心区别是什么？各举一个C++中的例子。

> [!answer]- 查看答案
> - **命令式**：描述"怎么做"（操作步骤）。例：`for(int i=0;i<n;i++) sum+=a[i];`
> - **声明式**：描述"做什么"（目标/映射）。例：`accumulate(v.begin(), v.end(), 0);`
> 
> 命令式关注控制流（循环、条件），声明式关注数据变换（函数组合）。

## 第 2 题 - 纯函数特征 [recall]

> "纯函数"需要满足哪两个条件？为什么纯函数有利于并行计算？

> [!answer]- 查看答案
> 两个条件：
> 1. **引用透明**：相同输入永远产生相同输出
> 2. **无副作用**：不改变任何外部状态
> 
> 有利于并行的原因：纯函数之间没有共享状态和数据依赖，可以安全地并行执行而无需加锁或同步。

## 第 3 题 - Lambda捕获 [application]

> 分析以下代码的输出：
> ```cpp
> int x = 10;
> auto f = [x]() mutable { return ++x; };
> cout << f() << " " << f() << " " << x;
> ```

> [!answer]- 查看答案
> 输出：`11 12 10`（注意：参数求值顺序未定义，但分别调用的结果是确定的）
> - `[x]` 值捕获x，lambda内部有自己的x副本（初始值10）
> - `mutable` 允许修改捕获的副本
> - 第一次f()：内部x变11，返回11
> - 第二次f()：内部x变12，返回12
> - 外部x始终为10（值捕获不影响原变量）

## 第 4 题 - 高阶函数实现 [application]

> 实现一个filter函数，接受数组和谓词函数，返回满足条件的元素。

> [!answer]- 查看答案
> ```cpp
> template<class Pred>
> vector<int> filter(const vector<int>& v, Pred pred) {
>     vector<int> result;
>     for (int x : v)
>         if (pred(x))
>             result.push_back(x);
>     return result;
> }
> // 使用
> auto evens = filter(v, [](int x){ return x%2==0; });
> ```

## 第 5 题 - 递归vs迭代 [application]

> 用函数式风格（递归、不使用循环）计算n的阶乘。

> [!answer]- 查看答案
> ```cpp
> int factorial(int n) {
>     if (n <= 1) return 1;
>     return n * factorial(n - 1);
> }
> ```
> 函数式特征：无循环、无赋值、无可变状态，纯粹的递归定义。

## 第 6 题 - std::function使用 [recall]

> std::function<int(int,int)> 表示什么？它比函数指针有什么优势？

> [!answer]- 查看答案
> 表示：任何接受两个int参数、返回int的可调用对象。
> 
> 优势：可以存储函数指针、Lambda、函数对象等任何可调用类型：
> ```cpp
> function<int(int,int)> op;
> op = [](int a,int b){ return a+b; };  // Lambda
> op = add;                               // 普通函数
> op = Add();                             // 函数对象
> ```

## 第 7 题 - 闭包概念 [recall]

> 什么是闭包(Closure)？C++中Lambda如何实现闭包？

> [!answer]- 查看答案
> **闭包**：一个函数加上它所引用的外部环境（变量）的组合体。
> 
> C++实现：Lambda通过捕获列表形成闭包：
> ```cpp
> int factor = 3;
> auto multiply = [factor](int x) { return x * factor; };
> // multiply就是一个闭包：函数体 + 捕获的factor
> ```
> 底层：编译器生成一个匿名类，捕获的变量作为数据成员。

## 第 8 题 - 函数组合 [analysis]

> 如何在C++中实现两个函数的组合（compose(f,g)返回一个新函数h，使得h(x)=f(g(x))）？

> [!answer]- 查看答案
> ```cpp
> template<class F, class G>
> auto compose(F f, G g) {
>     return [f, g](auto x) { return f(g(x)); };
> }
> // 使用
> auto doubleIt = [](int x){ return x*2; };
> auto addOne = [](int x){ return x+1; };
> auto doubleThenAdd = compose(addOne, doubleIt);
> cout << doubleThenAdd(3);  // addOne(doubleIt(3)) = addOne(6) = 7
> ```
> 这体现了函数式编程的核心：函数是一等公民，可以像数据一样组合。

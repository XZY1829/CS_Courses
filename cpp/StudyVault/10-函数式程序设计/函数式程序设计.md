## 函数式编程基本特征

### 1. 纯函数（引用透明）

相同输入 → 永远相同输出，无副作用：

```cpp
// 纯函数
int add(int a, int b) { return a + b; }

// 非纯函数（有副作用）
int counter = 0;
int next() { return counter++; }  // 修改了外部状态
```

### 2. 无状态（不可变）

不改变已有数据，产生新数据：

```cpp
// 命令式（修改数据）
void reverse(char str[]) {
    for (int i=0, j=strlen(str)-1; i<j; i++,j--)
        swap(str[i], str[j]);
}

// 函数式（不修改，产生新数据）
string reverse(string s) {
    if (s.length() <= 1) return s;
    return reverse(s.substr(1)) + s[0];
}
```

### 3. 函数是一等公民

函数可以作为参数传递、作为返回值：

```cpp
// 高阶函数：接收函数作为参数
template<class F>
void apply(int arr[], int n, F func) {
    for (int i = 0; i < n; i++)
        arr[i] = func(arr[i]);
}
apply(arr, 10, [](int x){ return x*2; });  // 每个元素翻倍
```

### 4. 递归代替循环

```cpp
// 循环（命令式）
int sum_loop(int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}

// 递归（函数式）
int sum_rec(int a[], int n) {
    if (n == 1) return a[0];
    return a[n-1] + sum_rec(a, n-1);
}
```

## C++中的函数式工具

### Lambda表达式 (C++11)

```cpp
auto add = [](int a, int b) { return a + b; };
cout << add(3, 4);  // 7

// 捕获外部变量
int base = 10;
auto addBase = [base](int x) { return x + base; };
// [=] 值捕获所有  [&] 引用捕获所有
// [base] 值捕获base  [&base] 引用捕获base
```

### STL高阶函数

```cpp
vector<int> v = {1, 2, 3, 4, 5};

// transform (map)
transform(v.begin(), v.end(), v.begin(), [](int x){ return x*2; });

// for_each
for_each(v.begin(), v.end(), [](int x){ cout << x << " "; });

// count_if (filter + count)
int n = count_if(v.begin(), v.end(), [](int x){ return x > 3; });

// accumulate (reduce/fold)
int sum = accumulate(v.begin(), v.end(), 0);
```

| 场景/关键词 | 答案 |
|-------------|------|

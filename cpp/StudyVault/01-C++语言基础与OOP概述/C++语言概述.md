## C++对C的基本扩充

### 1. 类型安全增强

| 扩充点 | C的做法 | C++的做法 | 好处 |
|--------|---------|-----------|------|
| 常量定义 | `#define PI 3.14` | `const double PI=3.14;` | 编译时类型检查 |
| 布尔类型 | 非0为真，0为假 | `bool`类型：`true`/`false` | 语义更清晰 |
| 字符串常量 | `char *p="abc"` 允许 | 必须用 `const char *p="abc"` | 防止修改只读数据 |
| I/O | `printf/scanf` (格式串) | `cout/cin` (自动类型推断) | 类型安全 |

### 2. 内联函数 (inline)

```cpp
inline int max(int x, int y) {
    return x > y ? x : y;
}
```

**目的**：消除小函数调用开销（保留返回地址、分配参数空间等）

**vs 宏定义的优势**：
- 进行参数类型检查和转换
- 不会出现参数重复计算问题
- 支持调试工具处理

> [!warning] 注意事项
> - 不是所有函数都能内联（如某些递归函数）
> - inline 只是建议，编译器可能忽略
> - 内联函数名具有文件作用域

### 3. 带缺省值的形参

```cpp
void print(int value, int base = 10);
print(32, 2);  // base=2
print(28);     // base=10（缺省值）
```

**规则**：有默认值的形参必须位于形参表的**右部**。

### 4. 名空间 (namespace)

解决多模块程序中全局标识符的**名冲突**问题。

```cpp
namespace NS1 { int x = 1; void f() {...} }
namespace NS2 { int x = 0; void f() {...} }

NS1::x;    // 使用NS1中的x
NS2::f();  // 调用NS2中的f
```

- C++标准库全局实体定义在 `std` 名空间中
- 无名名空间可替代 `static` 实现文件作用域限定

### 5. 动态变量 (new/delete)

| 操作 | C语言 | C++ |
|------|-------|-----|
| 创建单变量 | `(int*)malloc(sizeof(int))` | `new int` |
| 创建数组 | `(int*)calloc(n,sizeof(int))` | `new int[n]` |
| 销毁单变量 | `free(p)` | `delete p` |
| 销毁数组 | `free(p)` | `delete []p` |

> [!important] new/delete vs malloc/free 的关键区别
> - `new` 会调用**构造函数**，`malloc` 不会
> - `delete` 会调用**析构函数**，`free` 不会
> - 不要混用！new配delete，malloc配free

**内存区域分布**：

```
┌─────────────┐
│  代码区      │ ← 存放函数代码
├─────────────┤
│  静态数据区  │ ← 全局变量、static局部变量、常量
├─────────────┤
│  栈区        │ ← 自动局部变量、形参、返回地址
├─────────────┤
│  堆区        │ ← 动态变量 (new/malloc创建)
└─────────────┘
```

> [!warning] 内存泄漏
> C++没有自动垃圾回收。用new创建的动态变量如果丢失指针就无法释放。
> 解决方案：**智能指针**（后续章节介绍）

### 6. 引用类型 (Reference)

引用是变量的**别名**，底层通常实现为隐藏的指针。

```cpp
int x = 10;
int &y = x;  // y是x的别名
y = 20;      // 等价于 x = 20
```

**主要用途**：

| 用途 | 说明 | 示例 |
|------|------|------|
| 高效传参 | 避免大对象复制 | `void f(A &x)` |
| 修改实参 | 函数内修改调用者变量 | `void swap(int &a, int &b)` |
| 返回左值 | 函数返回可修改的引用 | `int& operator[]()` |

**引用 vs 指针**：

| 特性 | 引用 | 指针 |
|------|------|------|
| 初始化 | 必须初始化 | 可以不初始化 |
| 重绑定 | 不可改变指向 | 可改变指向 |
| 空值 | 不能为null | 可以为nullptr |
| 语法 | 直接使用 | 需要`*`解引用 |
| 安全性 | 更安全 | 可能野指针 |

**const引用防止修改**：
```cpp
void f(const int &x) {
    x = 30;  // Error! 不可修改
}
```

> [!warning] 不要返回局部变量的引用
> 函数返回后局部变量空间无效，引用悬空！

### 7. 函数名重载 (Overloading)

同一作用域内，**同名但参数不同**的多个函数。

```cpp
void print(int i)    { ... }
void print(double d) { ... }
void print(char c)   { ... }
```

**绑定规则**（编译时确定）：
1. **精确匹配** — 类型完全相同
2. **提升匹配** — char→int, float→double
3. **标准转换匹配** — 任意算术类型互转
4. **自定义转换匹配**
5. **匹配失败** — 歧义或无匹配

> [!tip] 与缺省参数的冲突
> 重载函数与带默认参数的函数可能产生歧义，编译器报错。

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "inline vs 宏" | inline有类型检查、无重复计算、可调试 |
| "new vs malloc" | new调用构造函数、类型安全、返回正确类型指针 |
| "引用与指针的区别" | 引用不可重绑定、不可为null、更安全 |
| "函数重载绑定顺序" | 精确→提升→标准转换→自定义→失败 |
| "const引用的作用" | 防止函数通过引用修改实参，且允许传临时量 |
| "内存泄漏原因" | 指针丢失但动态变量未delete |

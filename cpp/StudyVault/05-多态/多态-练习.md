## 第 1 题 - 动态绑定输出 [application]

> 写出以下代码的输出：
> ```cpp
> class A {
> public:
>     virtual void f() { cout << "A"; }
>     void g() { cout << "a"; }
> };
> class B : public A {
> public:
>     void f() { cout << "B"; }
>     void g() { cout << "b"; }
> };
> A *p = new B;
> p->f();  p->g();
> ```

> [!answer]- 查看答案
> **输出**：`Ba`
> - `p->f()`：f是虚函数，动态绑定，p实际指向B对象 → 调用 B::f → 输出"B"
> - `p->g()`：g是非虚函数，静态绑定，p的声明类型是A* → 调用 A::g → 输出"a"

## 第 2 题 - 虚析构必要性 [recall]

> 为什么含有虚函数的类必须声明虚析构函数？不声明会怎样？

> [!answer]- 查看答案
> **原因**：通过基类指针delete派生类对象时，需要动态绑定析构函数。
> 
> **不声明的后果**：
> ```cpp
> Base *p = new Derived;
> delete p;  // 只调用Base的析构函数！
>            // Derived的析构函数不执行
>            // Derived中额外申请的资源泄漏
> ```
> 
> **规则**：只要类有虚函数（说明可能被通过基类指针使用），就必须声明虚析构函数。

## 第 3 题 - 重写条件辨析 [application]

> 以下哪些是正确的重写？哪些只是隐藏？
> ```cpp
> class Base {
> public:
>     virtual void f(int x);
>     virtual void g() const;
>     virtual Base* clone();
> };
> class Derived : public Base {
> public:
>     void f(int x);           // (1)
>     void f(double x);        // (2)
>     void g();                // (3)
>     Derived* clone();        // (4)
> };
> ```

> [!answer]- 查看答案
> - (1) `f(int x)` — **正确重写** ✓（同名同参同返回）
> - (2) `f(double x)` — **隐藏**，不是重写（参数类型不同）
> - (3) `g()` — **隐藏**，不是重写！const不一致（基类有const，派生类没有）
> - (4) `Derived* clone()` — **正确重写** ✓（协变返回：Derived*是Base*的派生类指针）

## 第 4 题 - 抽象类使用 [application]

> 以下代码哪些行会编译错误？
> ```cpp
> class Shape {
> public:
>     virtual void draw() = 0;
>     virtual ~Shape() {}
> };
> class Circle : public Shape {
> public:
>     void draw() override { cout << "O"; }
> };
> Shape s;           // (1)
> Shape *p;          // (2)
> Circle c;          // (3)
> p = &c;            // (4)
> p->draw();         // (5)
> ```

> [!answer]- 查看答案
> - (1) **Error！** Shape是抽象类，不能创建对象
> - (2) **OK** — 可以声明抽象类的指针
> - (3) **OK** — Circle实现了所有纯虚函数，是具体类
> - (4) **OK** — 基类指针指向派生类对象
> - (5) **OK** — 动态绑定调用Circle::draw，输出"O"

## 第 5 题 - 虚函数表理解 [recall]

> 简述C++虚函数表(vtable)的工作机制。为什么虚函数调用比普通函数慢？

> [!answer]- 查看答案
> **机制**：
> 1. 编译器为每个含虚函数的类生成一张虚函数表(vtable)，表中存放虚函数的地址
> 2. 每个对象有一个隐藏的vptr指针，指向所属类的vtable
> 3. 调用虚函数时：对象→vptr→vtable→函数地址→调用
> 
> **为什么慢**：
> - 多一次指针间接寻址（通过vptr找vtable，再找函数地址）
> - 无法内联优化（编译时不知道调用目标）
> - 可能导致缓存不命中

## 第 6 题 - 多态设计实践（机试相关） [application]

> 设计一个Vehicle类层次：基类Vehicle有纯虚函数describe()，派生类Car和Truck分别实现。写出完整代码。

> [!answer]- 查看答案
> ```cpp
> class Vehicle {
> protected:
>     string brand;
> public:
>     Vehicle(string b) : brand(b) {}
>     virtual void describe() const = 0;
>     virtual ~Vehicle() {}
> };
> 
> class Car : public Vehicle {
>     int seats;
> public:
>     Car(string b, int s) : Vehicle(b), seats(s) {}
>     void describe() const override {
>         cout << "Car: " << brand << ", " << seats << " seats" << endl;
>     }
> };
> 
> class Truck : public Vehicle {
>     double payload;
> public:
>     Truck(string b, double p) : Vehicle(b), payload(p) {}
>     void describe() const override {
>         cout << "Truck: " << brand << ", " << payload << "t" << endl;
>     }
> };
> ```

## 第 7 题 - 构造函数中调虚函数 [analysis]

> 在构造函数中调用虚函数会发生什么？是动态绑定吗？

> [!answer]- 查看答案
> **不是动态绑定！** 在构造函数中调用虚函数，使用的是**当前正在构造的类**的版本。
> 
> ```cpp
> class Base {
> public:
>     Base() { f(); }  // 调用Base::f，即使实际对象是Derived
>     virtual void f() { cout << "Base"; }
> };
> class Derived : public Base {
> public:
>     void f() { cout << "Derived"; }
> };
> Derived d;  // 输出"Base"而非"Derived"!
> ```
> 
> **原因**：构造Base部分时，Derived部分尚未构造，vptr还指向Base的vtable。此时调用Derived::f可能访问未初始化的成员，所以语言规定在构造函数中用静态绑定。

## 第 8 题 - override关键字 [recall]

> C++11的override关键字有什么作用？不加会怎样？

> [!answer]- 查看答案
> **作用**：显式告诉编译器"我意图重写基类的虚函数"，如果实际没有正确重写，编译器报错。
> 
> **不加的问题**：
> ```cpp
> class Base { virtual void f(int); };
> class Derived : public Base {
>     void f(double);  // 本想重写，实际是隐藏（参数不同）
>                      // 没有override时编译器不报错，bug很隐蔽
>     void f(double) override;  // 加了override → 编译错误！及时发现
> };
> ```

## 第 9 题 - 接口vs实现继承 [analysis]

> 比较"纯虚函数"、"虚函数（有默认实现）"和"非虚函数"在设计意图上的区别。

> [!answer]- 查看答案
> | 类型 | 设计意图 | 派生类责任 |
> |------|---------|-----------|
> | 纯虚函数 `=0` | 定义接口，强制派生类提供实现 | **必须**实现 |
> | 虚函数（有实现） | 提供默认行为，允许定制 | 可重写可不重写 |
> | 非虚函数 | 规定不可改变的行为 | 不应重写（隐藏不是重写） |
> 
> 这三种形成了一个"定制自由度"的光谱：
> 纯虚(必须定制) ← 虚函数(可选定制) ← 非虚(禁止定制)

## 第 10 题 - 多态数组设计 [analysis]

> 为什么 `Shape shapes[100]` 不能实现多态，而 `Shape* shapes[100]` 可以？

> [!answer]- 查看答案
> **`Shape shapes[100]`**：
> - 如果Shape是抽象类 → 直接编译错误
> - 如果Shape不是抽象类 → 对象切片！赋值时只保留Base部分
> - 数组元素大小固定为sizeof(Shape)，无法容纳更大的派生类
> 
> **`Shape* shapes[100]`**：
> - 每个元素是指针（大小固定，与对象无关）
> - 可以指向任何Shape的派生类对象
> - 通过指针调用虚函数 → 动态绑定 → 多态生效
> 
> **结论**：多态需要通过指针或引用实现，不能通过值类型。

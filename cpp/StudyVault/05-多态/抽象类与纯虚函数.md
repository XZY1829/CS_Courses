# 抽象类与纯虚函数（★★★）

#cpp #oop #abstract-class #pure-virtual #interface

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 纯虚函数 | `virtual void f() = 0;`，无实现，派生类必须实现 |
| 抽象类 | 含有纯虚函数的类，不能创建对象 |
| 作用1 | 提供公共框架（抽象公共特征） |
| 作用2 | 定义接口（纯接口类只含纯虚函数） |
| 使用方式 | 通过基类指针/引用操作派生类对象 |

## 纯虚函数

```cpp
class Shape {
public:
    virtual void draw() const = 0;    // 纯虚函数：必须由派生类实现
    virtual double area() const = 0;  // 纯虚函数
    virtual ~Shape() {}
};
```

- 函数体写 `= 0` 表示"没有实现"
- 派生类**必须**给出实现，否则派生类也是抽象类
- 纯虚函数可以有函数体（少见，提供默认实现，派生类可选调用）

## 抽象类

### 特点

- **不能创建对象**：`Shape s;` → Error!
- **可以创建指针和引用**：`Shape *p;` → OK!
- 可以包含三种成员函数：

| 函数类型 | 派生类的责任 |
|----------|-------------|
| 纯虚函数 | **必须**实现 |
| 虚函数（有实现） | 可用基类的，也可自己重写 |
| 非虚函数 | 只能用基类的 |

### 典型设计模式：Figure 框架

```cpp
class Figure {
    int id;
public:
    Figure(int i) : id(i) {}
    virtual void draw() const = 0;       // 必须实现
    virtual void input_data() = 0;       // 必须实现
    virtual double area() const { return 0; }  // 可选重写
    int get_id() { return id; }          // 不可重写
};

class Circle : public Figure {
    double x, y, r;
public:
    Circle(int i) : Figure(i) {}
    void draw() const override { /* 画圆 */ }
    void input_data() override { cin >> x >> y >> r; }
    double area() const override { return 3.14159 * r * r; }
};
```

### 通过基类指针操作（多态的核心）

```cpp
Figure *figures[100];
int count = 0;

// 添加各种图形
figures[count++] = new Circle(1);
figures[count++] = new Rectangle(2);
figures[count++] = new Line(3);

// 统一操作 — 不关心具体类型
for (int i = 0; i < count; i++) {
    figures[i]->draw();  // 动态绑定到正确的draw
}
```

## 抽象类的两大用途

### 用途1：抽象公共特征（框架）

为一族相关类型提取公共框架，具体类在此框架上实现细节。

```
      Figure（框架）
     ┌────┼────┐
  Circle  Rect  Line
```

### 用途2：定义接口

```cpp
class IStack {  // 纯接口
public:
    virtual void push(int x) = 0;
    virtual void pop(int &x) = 0;
    virtual bool empty() const = 0;
    virtual ~IStack() {}
};

class ArrayStack : public IStack { /* 数组实现 */ };
class LinkedStack : public IStack { /* 链表实现 */ };

void useStack(IStack &s) {  // 面向接口编程
    s.push(42);
}
```

> [!tip] 面向接口编程
> 函数参数使用抽象类（接口）类型 → 可以接受任何实现该接口的具体类
> 新增实现类时，使用者代码无需修改 → **开闭原则**

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "抽象类能否创建对象" | 不能，但可以创建指针和引用 |
| "纯虚函数=0含义" | 没有实现，派生类必须给出 |
| "派生类不实现纯虚" | 派生类也变成抽象类 |
| "抽象类两大用途" | 抽象公共框架 + 定义接口 |
| "面向接口编程的好处" | 解耦+可扩展+符合开闭原则 |
| "虚析构为何必要" | 通过基类指针delete时正确析构 |

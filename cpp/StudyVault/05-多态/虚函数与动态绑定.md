# 虚函数与动态绑定（★★★）

#cpp #oop #polymorphism #virtual-function #dynamic-binding

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 虚函数 | `virtual` 修饰的成员函数，支持动态绑定 |
| 动态绑定 | 运行时根据对象实际类型决定调用哪个函数 |
| 触发条件 | 通过基类指针/引用调用虚函数 |
| 重写(Override) | 派生类定义与基类同型构的虚函数 |
| 虚函数表(vtable) | 每个含虚函数的类有一张函数指针表 |
| override关键字 | C++11，显式标记重写，编译器检查 |

## 静态绑定 vs 动态绑定

```cpp
class A {
public:
    virtual void f() { cout << "A::f"; }  // 虚函数
    void g() { cout << "A::g"; }          // 非虚函数
};
class B : public A {
public:
    void f() { cout << "B::f"; }  // 重写虚函数
    void g() { cout << "B::g"; }  // 隐藏（非重写）
};

A *p = new B;
p->f();  // 动态绑定 → B::f（看实际对象类型）
p->g();  // 静态绑定 → A::g（看指针声明类型）
```

| 绑定方式 | 时机 | 依据 | 适用 |
|----------|------|------|------|
| 静态绑定 | 编译时 | 指针/引用的声明类型 | 非虚函数 |
| 动态绑定 | 运行时 | 对象的实际类型 | 虚函数 |

## 虚函数 (Virtual Function)

### 声明

```cpp
class Base {
public:
    virtual void f();        // 虚函数
    virtual int g(int x);   // 虚函数
};
```

### 重写规则（同型构）

派生类中**覆盖**基类虚函数的条件：
1. **函数名相同**
2. **参数列表完全相同**
3. 返回类型相同（或为基类返回类型的public派生类——协变返回）
4. const修饰一致

```cpp
class Base {
public:
    virtual void f(int x);
};
class Derived : public Base {
public:
    void f(int x) override;  // ✓ 正确重写（推荐加override）
    void f(double x);        // ✗ 这不是重写，是隐藏！参数不同
};
```

> [!important] virtual的传递性
> 基类中声明为virtual的函数，在所有派生类中自动是virtual的，无需重复写virtual。

## 虚函数表 (vtable) 机制

```
对象内存布局:
┌──────────┐
│ vptr ────┼──→ vtable
│ 数据成员  │    ┌─────────────┐
└──────────┘    │ &A::f       │ (或 &B::f 如果被重写)
                │ &A::g       │
                └─────────────┘
```

- 每个含虚函数的类有一个虚函数表
- 每个对象有一个隐藏的 vptr 指向所属类的vtable
- 动态绑定 = 通过 vptr → vtable → 函数指针 调用

> [!warning] 虚函数的代价
> - 每个对象多一个指针（vptr）
> - 每次虚函数调用多一次间接寻址
> - 虚函数不能内联（运行时才确定调用目标）

## 虚析构函数

```cpp
class Base {
public:
    virtual ~Base() {}  // 虚析构函数
};
class Derived : public Base {
    int *data;
public:
    ~Derived() { delete[] data; }
};

Base *p = new Derived;
delete p;  // 如果~Base不是virtual → 只调用~Base，内存泄漏！
           // 是virtual → 动态绑定调用~Derived → 正确释放
```

> [!important] 规则
> 只要类有虚函数，就应该把析构函数也声明为virtual。
> 否则通过基类指针delete派生类对象时，派生类析构函数不会被调用。

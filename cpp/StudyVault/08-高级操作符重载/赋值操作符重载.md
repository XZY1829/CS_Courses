# 赋值操作符重载（★★★）

#cpp #oop #operator-overload #assignment #deep-copy

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 赋值vs初始化 | 赋值=对已有对象修改；初始化=创建时设置 |
| 默认行为 | 逐成员赋值（浅赋值），类似隐式拷贝构造 |
| 自定义时机 | 类有指针成员管理动态资源时 |
| 关键步骤 | ①自赋值检查 ②释放旧资源 ③深复制 ④返回*this |
| 返回类型 | `ClassName&`（支持链式赋值） |

## 赋值 vs 初始化

```cpp
String s1("hello");
String s2(s1);      // 初始化 → 调用拷贝构造函数
String s3;
s3 = s1;            // 赋值 → 调用赋值操作符
```

## 自定义赋值操作符

```cpp
class String {
    char *str;
    int len;
public:
    String& operator=(const String& s) {
        if (this == &s) return *this;   // ① 自赋值检查
        delete[] str;                    // ② 释放旧资源
        len = s.len;                     // ③ 深复制
        str = new char[len + 1];
        strcpy(str, s.str);
        return *this;                    // ④ 返回*this
    }
};
```

> [!warning] 自赋值检查为什么必要
> 如果 `a = a`，不检查就先 `delete[] str`，然后从已释放的内存复制 → 崩溃！

> [!important] Rule of Three（重要！）
> 如果自定义了以下任一，通常三个都要自定义：
> 1. 拷贝构造函数
> 2. **赋值操作符**
> 3. 析构函数

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "赋值vs拷贝构造" | 赋值=已有对象；拷贝=创建新对象 |
| "自赋值检查" | 防止释放后从已释放内存复制 |
| "返回*this的原因" | 支持链式赋值 `a=b=c` |
| "Rule of Three" | 析构+拷贝构造+赋值操作符 |

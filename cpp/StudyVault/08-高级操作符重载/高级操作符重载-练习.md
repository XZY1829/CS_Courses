## 第 1 题 - 赋值操作符完整实现 [application]

> 为一个管理动态数组的IntArray类实现完整的赋值操作符。

> [!answer]- 查看答案
> ```cpp
> IntArray& operator=(const IntArray& other) {
>     if (this == &other) return *this;  // 自赋值检查
>     delete[] data;                      // 释放旧资源
>     size = other.size;                  // 复制大小
>     data = new int[size];              // 分配新空间
>     for (int i=0; i<size; i++)
>         data[i] = other.data[i];       // 深复制
>     return *this;                       // 支持链式
> }
> ```

## 第 2 题 - copy-and-swap惯用法 [analysis]

> 什么是copy-and-swap惯用法？它如何简化赋值操作符的实现？

> [!answer]- 查看答案
> ```cpp
> // 1. 参数按值传递（自动调用拷贝构造）
> IntArray& operator=(IntArray other) {  // 注意：按值传递
>     swap(data, other.data);            // 交换资源
>     swap(size, other.size);
>     return *this;                       
> }   // other（持有旧资源）在此析构
> ```
> **好处**：自动处理自赋值、异常安全、代码简洁。

## 第 3 题 - 函数对象vs Lambda [recall]

> 函数对象（仿函数）和Lambda表达式在功能上有什么异同？

> [!answer]- 查看答案
> | 维度 | 函数对象 | Lambda |
> |------|----------|--------|
> | 本质 | 重载operator()的类对象 | 编译器生成的匿名函数对象 |
> | 状态 | 通过数据成员保存 | 通过捕获列表保存 |
> | 可复用 | 有名字，可多处使用 | 通常一次性使用 |
> | 语法 | 需要定义完整类 | 简洁的一行表达式 |
> | 底层 | 就是类 | 编译器转换为匿名类 |
> 
> **相同**：都是可调用对象，都可作为STL算法参数。

## 第 4 题 - 智能指针选型 [application]

> 以下场景分别应该用哪种智能指针？
> 1. 函数内部创建临时资源，函数结束时释放
> 2. 多个对象共享一个缓存
> 3. 缓存的观察者（不影响缓存生命周期）

> [!answer]- 查看答案
> 1. **unique_ptr** — 独占所有权，函数结束自动释放
> 2. **shared_ptr** — 多个持有者共享，最后一个释放时清理
> 3. **weak_ptr** — 观察shared_ptr管理的资源而不增加引用计数

## 第 5 题 - 引用计数实现 [application]

> 实现SmartPtr的拷贝赋值操作符（引用计数版本）。

> [!answer]- 查看答案
> ```cpp
> SmartPtr& operator=(const SmartPtr& other) {
>     if (this == &other) return *this;
>     // 减少自己对旧资源的引用
>     if (--(*ref_count) == 0) {
>         delete ptr;
>         delete ref_count;
>     }
>     // 共享新资源
>     ptr = other.ptr;
>     ref_count = other.ref_count;
>     (*ref_count)++;
>     return *this;
> }
> ```

## 第 6 题 - unique_ptr不可复制 [recall]

> 为什么unique_ptr禁止复制？如何实现"禁止复制"？

> [!answer]- 查看答案
> **为什么禁止**：unique_ptr表示独占所有权，如果允许复制，两个指针指向同一资源，delete时会双重释放。
> 
> **实现方法**：删除拷贝构造和拷贝赋值：
> ```cpp
> unique_ptr(const unique_ptr&) = delete;
> unique_ptr& operator=(const unique_ptr&) = delete;
> ```
> 但允许移动：`unique_ptr(unique_ptr&& other)` 转移所有权。

## 第 7 题 - 函数对象携带状态 [application]

> 设计一个Counter函数对象，每次调用返回递增的数（从指定起始值开始）。

> [!answer]- 查看答案
> ```cpp
> class Counter {
>     int current;
> public:
>     Counter(int start = 0) : current(start) {}
>     int operator()() { return current++; }
> };
> Counter c(10);
> cout << c() << c() << c();  // 10 11 12
> ```
> 这展示了函数对象相比普通函数的优势：可以维护调用间的状态。

## 第 8 题 - 循环引用问题 [analysis]

> 解释shared_ptr的循环引用问题并给出解决方案。

> [!answer]- 查看答案
> ```cpp
> struct Node {
>     shared_ptr<Node> next;  // 互相持有shared_ptr
>     shared_ptr<Node> prev;
> };
> auto a = make_shared<Node>();
> auto b = make_shared<Node>();
> a->next = b;  // a引用b，b的ref_count=2
> b->prev = a;  // b引用a，a的ref_count=2
> // a,b离开作用域后ref_count各减1变为1，永远不会归0！→内存泄漏
> ```
> **解决**：将一个方向改为weak_ptr：
> ```cpp
> struct Node {
>     shared_ptr<Node> next;
>     weak_ptr<Node> prev;   // 不增加引用计数
> };
> ```

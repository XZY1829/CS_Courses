# 函数对象（★★★）

#cpp #oop #functor #function-object #operator-overload

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 定义 | 重载了 `operator()` 的类的对象 |
| 别名 | 仿函数 (Functor) |
| 调用方式 | 像函数一样使用：`obj(args)` |
| vs函数指针 | 可携带状态、可内联优化、类型安全 |
| 应用 | STL算法的策略参数、回调 |

## 函数对象的定义

```cpp
class Add {
    int base;
public:
    Add(int b) : base(b) {}
    int operator()(int x) const {  // 重载()
        return x + base;
    }
};

Add add5(5);        // 创建函数对象，携带状态base=5
cout << add5(3);    // 输出8，调用operator()(3)
cout << add5(10);   // 输出15
```

## 函数对象 vs 函数指针

| 维度 | 函数对象 | 函数指针 |
|------|----------|----------|
| 携带状态 | ✓（数据成员） | ✗ |
| 内联优化 | ✓（编译器知道类型） | ✗（间接调用） |
| 类型安全 | ✓ | 较弱 |
| 语法 | `obj(args)` | `(*fp)(args)` |
| STL兼容 | 优秀 | 可以但不如函数对象 |

## 典型应用

### 作为STL算法的比较策略

```cpp
class Greater {
public:
    bool operator()(int a, int b) const {
        return a > b;
    }
};

vector<int> v = {3, 1, 4, 1, 5};
sort(v.begin(), v.end(), Greater());  // 降序排列
```

### 累加器

```cpp
class Accumulator {
    int sum;
public:
    Accumulator() : sum(0) {}
    void operator()(int x) { sum += x; }
    int getSum() const { return sum; }
};
```

# 继承机制（★★★）

#cpp #oop #inheritance #code-reuse

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 继承 | 新类（派生类）包含已有类（基类）的所有功能，再添加/修改 |
| 分类 | 单继承（一个基类）/ 多继承（多个基类） |
| 三种继承方式 | public / protected / private |
| protected成员 | 派生类可访问，外部不可访问 |
| 子类型 | public继承时，派生类对象可当基类对象使用 |
| 代码复用 | 目标代码复用，不需要基类源代码 |

## 继承的基本语法

```cpp
class Base {
    int x;
protected:
    int y;
public:
    void f();
};

class Derived : public Base {  // public继承
    int z;                      // 新增成员
public:
    void h();                   // 新增函数
    void f();                   // 重定义基类函数
};
```

**派生类包含什么**：
- 基类的所有成员（构造函数、析构函数、赋值操作除外）
- 派生类新定义的成员
- 派生类对象内存中包含一个"基类子对象"

## protected 访问控制

解决**继承与封装的矛盾**：

| 访问者 | private | protected | public |
|--------|---------|-----------|--------|
| 本类成员函数 | ✓ | ✓ | ✓ |
| 友元 | ✓ | ✓ | ✓ |
| **派生类** | **✗** | **✓** | ✓ |
| 外部代码 | ✗ | ✗ | ✓ |

> [!important] protected 的设计意图
> - private：对外和对派生类都隐藏
> - protected：对外隐藏，但对派生类开放
> - 当派生类需要直接操作基类数据时使用 protected

## 三种继承方式

控制基类成员在派生类中**对外**的访问权限：

| 基类成员 | public继承后 | protected继承后 | private继承后 |
|----------|-------------|----------------|--------------|
| public | public | protected | private |
| protected | protected | protected | private |
| private | 不可访问 | 不可访问 | 不可访问 |

> [!tip] 记忆规则
> 继承方式是一个"天花板"：基类成员的访问权限不会超过继承方式指定的级别。

**实际使用**：
- **public继承**（最常用）：IS-A关系，派生类是基类的一种
- **protected继承**（少用）：实现继承
- **private继承**（少用）：实现继承，完全隐藏基类接口

## 子类型 (Subtype)

**public继承**建立了子类型关系：

```cpp
class Animal { public: void eat(); };
class Dog : public Animal { public: void bark(); };

Animal *p = new Dog;  // OK! Dog是Animal的子类型
p->eat();             // OK
// p->bark();         // Error! 通过基类指针只能访问基类接口
```

**子类型的核心**：派生类对象可以用在任何需要基类对象的地方。

## 派生类的构造与析构

### 构造顺序

```
1. 基类子对象构造（调用基类构造函数）
2. 成员对象构造
3. 派生类构造函数体执行
```

```cpp
class Derived : public Base {
    MemberClass m;
public:
    Derived(int a, int b) : Base(a), m(b) {
        // 派生类自己的初始化
    }
};
```

### 析构顺序（与构造相反）

```
1. 派生类析构函数体执行
2. 成员对象析构
3. 基类子对象析构
```

> [!important] 基类构造函数的调用
> - 在派生类构造函数的**成员初始化表**中指定调用基类的哪个构造函数
> - 如果不指定，默认调用基类的**默认构造函数**
> - 如果基类没有默认构造函数且派生类未显式调用 → **编译错误**

## 名字隐藏 (Name Hiding)

派生类中定义了与基类**同名**的成员，基类成员被隐藏：

```cpp
class A { public: void f(); void f(int x); };
class B : public A {
public:
    void f();  // 隐藏了A中所有的f（包括f(int)！）
};

B b;
b.f();      // 调用B::f()
b.f(1);     // Error! A::f(int)被隐藏了
b.A::f(1);  // OK，用基类名限定来访问
```

> [!warning] 隐藏 vs 重写
> - **隐藏**：派生类同名函数隐藏基类所有同名函数（不论参数）
> - **重写/覆盖**：虚函数机制，运行时多态（见多态章节）

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "protected的作用" | 对外隐藏，对派生类开放 |
| "public继承的含义" | IS-A关系，建立子类型 |
| "继承方式是天花板" | 基类成员权限不超过继承方式 |
| "派生类构造顺序" | 基类→成员对象→自身 |
| "名字隐藏" | 同名即隐藏所有基类同名函数 |
| "private成员能继承吗" | 继承了但不可直接访问 |

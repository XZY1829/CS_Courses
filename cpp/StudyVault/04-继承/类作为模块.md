# 类作为模块（★★☆）

#cpp #oop #module #encapsulation

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 模块 | 可单独编写和编译的程序单位，含接口+实现 |
| 类作为模块 | .h文件（接口/类定义）+ .cpp文件（实现/成员函数） |
| 划分准则 | 内聚性最大 + 耦合度最小 |
| OOP优势 | 类是自然的模块单位，边界清晰 |

## 模块的组织

```
模块结构:
┌─────────────────────────┐
│  A.h（接口）             │ ← 类定义 + public声明
├─────────────────────────┤
│  A.cpp（实现）           │ ← 成员函数定义
└─────────────────────────┘

使用者:
┌─────────────┐
│  main.cpp    │
│  #include "A.h"  ← 只看接口，不关心实现
└─────────────┘
```

**过程式 vs 面向对象的模块划分**：
- 过程式：按功能/数据集分组 → 边界模糊
- OOP：一个类一个模块 → 边界清晰

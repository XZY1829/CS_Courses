# 流操作符重载（★★★）

#cpp #oop #io #operator-overload

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| `<<` | 插入操作符（输出），返回 `ostream&` |
| `>>` | 提取操作符（输入），返回 `istream&` |
| 重载方式 | 必须用友元函数（左操作数是流对象） |
| 链式调用 | 返回引用实现 `cout << a << b` |
| 类型转换 | `<<` 自动将数据转为字符串输出 |

## 为什么需要重载流操作符

标准库的 `<<` 和 `>>` 只支持基本数据类型。要输出自定义类：

```cpp
Complex c(3, 4);
cout << c;  // 编译错误！ostream不知道如何输出Complex
```

解决方案：为自定义类重载这两个操作符。

## 重载 `<<`（输出）

### 函数签名

```cpp
ostream& operator<<(ostream& os, const MyClass& obj);
```

- **返回 `ostream&`**：支持链式调用 `cout << a << b`
- **第一个参数 `ostream&`**：不能是const（输出会改变流状态）
- **第二个参数 `const MyClass&`**：读取对象，不修改

### 为什么必须用友元

```cpp
class Complex {
    double real, imag;  // 私有
    friend ostream& operator<<(ostream& os, const Complex& c);
};
ostream& operator<<(ostream& os, const Complex& c) {
    os << c.real << "+" << c.imag << "i";
    return os;  // 关键：返回os以支持链式
}
```

不能定义为成员函数，因为左操作数是 `ostream` 而不是 `Complex`：
- 成员函数：`c << cout`（语义颠倒，不自然）
- 友元函数：`cout << c`（自然语义）

## 重载 `>>`（输入）

### 函数签名

```cpp
istream& operator>>(istream& is, MyClass& obj);
```

- **第二个参数不能是const**：需要写入数据

### 完整示例

```cpp
class Point {
    int x, y;
    friend istream& operator>>(istream& is, Point& p);
    friend ostream& operator<<(ostream& os, const Point& p);
};

istream& operator>>(istream& is, Point& p) {
    is >> p.x >> p.y;
    return is;
}

ostream& operator<<(ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}

// 使用
Point p;
cin >> p;                // 输入：3 5
cout << p << endl;       // 输出：(3, 5)
```

## 链式调用原理

```cpp
cout << a << b << endl;
// 等价于：
((cout.operator<<(a)).operator<<(b)).operator<<(endl);
// 或对自定义类型：
operator<<(operator<<(operator<<(cout, a), b), endl);
```

每次返回 `ostream&` 使得下一个 `<<` 能继续操作同一个流。

## 格式化输出操纵符

```cpp
#include <iomanip>

cout << hex << 255;           // ff（十六进制）
cout << setw(10) << x;       // 宽度10
cout << setprecision(3) << 3.14159;  // 精度控制
cout << fixed << 3.14159;    // 固定小数点
cout << left << setw(10) << "hi";    // 左对齐
```

| 操纵符 | 功能 |
|--------|------|
| `hex/oct/dec` | 进制 |
| `setw(n)` | 输出宽度 |
| `setprecision(n)` | 精度 |
| `fixed/scientific` | 浮点格式 |
| `left/right` | 对齐方式 |
| `endl` | 换行并刷新缓冲 |

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "为什么用友元不用成员" | 左操作数是ostream，不是自定义类 |
| "<<返回什么" | `ostream&`（支持链式） |
| ">>的第二个参数" | 非const引用（要写入数据） |
| "输入时需要错误处理吗" | 建议判断 `is.fail()` |

## 类定义模板 → [[类的定义与对象]] · [[构造函数与析构函数]]

```cpp
class ClassName {
private:
    int data;
public:
    ClassName();                              // 默认构造
    ClassName(int d);                         // 带参构造
    ClassName(const ClassName& other);        // 拷贝构造
    ClassName(ClassName&& other);             // 移动构造
    ~ClassName();                             // 析构
    ClassName& operator=(const ClassName& other);  // 赋值
    ClassName& operator=(ClassName&& other);       // 移动赋值
};
```

## 构造/析构顺序 → [[派生类构造与析构]]

```
构造：基类 → 成员对象(声明序) → 自身
析构：自身 → 成员对象(声明逆序) → 基类
```

## 操作符重载速查 → [[操作符重载规则]] · [[常见操作符重载]]

| 操作符 | 方式 | 返回类型 | 备注 |
|--------|------|----------|------|
| `+` `-` `*` `/` | 友元 | 值 | 不修改操作数 |
| `+=` `-=` | 成员 | `T&` | 修改自身 |
| `==` `!=` `<` | 友元 | bool | 对称 |
| `++`前缀 | 成员 | `T&` | 先增后返回 |
| `++`后缀 | 成员(int) | `T` | 返回旧值副本 |
| `<<` `>>` | 友元 | `ostream&`/`istream&` | 链式 |
| `[]` | 成员 | `T&` | 需const版本 |
| `=` | 成员 | `T&` | 自赋值检查 |
| `()` | 成员 | 任意 | 函数对象 |
| `*` `->` | 成员 | `T&`/`T*` | 智能指针 |

## 虚函数规则 → [[虚函数与动态绑定]] · [[抽象类与纯虚函数]]

- `virtual` 声明 → 动态绑定
- 触发条件：基类指针/引用 + 虚函数调用
- 重写条件：同名 + 同参 + 同返回(或协变) + 同const
- 虚析构：有虚函数的类必须声明
- 纯虚函数：`= 0`，类变抽象类，不可实例化

## Lambda语法 → [[函数式程序设计]]

```cpp
[捕获列表](参数列表) -> 返回类型 { 函数体 }
// 常见形式
[](int x) { return x * 2; }        // 无捕获
[=](int x) { return x + base; }    // 值捕获所有
[&](int x) { total += x; }         // 引用捕获所有
[base, &total](int x) { ... }      // 混合捕获
```

## Rule of Three/Five → [[拷贝构造函数]] · [[赋值操作符重载]]

如果自定义了任一，考虑全部自定义：
- **Three**：析构函数、拷贝构造、拷贝赋值
- **Five** (C++11)：+ 移动构造、移动赋值

# 拷贝构造函数（★★★）

#cpp #class #copy-constructor #deep-copy

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 定义 | 参数为 `const ClassName&` 的构造函数 |
| 调用时机 | 用同类对象初始化、传值参数、返回值 |
| 隐式拷贝 | 编译器自动生成，逐成员浅拷贝 |
| 浅拷贝风险 | 指针成员共享内存 → 双重释放/互相影响 |
| 深拷贝 | 自定义拷贝构造，重新分配+复制内容 |
| 转移构造 | 参数为右值引用 `A&&`，转移而非复制资源 |

## 拷贝构造函数的调用时机

```cpp
class A {
public:
    A(const A& a);  // 拷贝构造函数
};
```

**三种触发场景**：

| 场景 | 示例 |
|------|------|
| 用同类对象初始化 | `A a2(a1);` 或 `A a2 = a1;` |
| 对象作为值参数传给函数 | `void f(A x); f(a);` |
| 对象作为函数返回值 | `A f() { A a; return a; }` |

## 浅拷贝 vs 深拷贝

### 浅拷贝 (Shallow Copy) — 隐式拷贝构造的行为

```
对象s1:           对象s2(隐式拷贝):
┌─────┐          ┌─────┐
│ len=4│          │ len=4│
│ str ─┼───┐     │ str ─┼───┐
└─────┘   │     └─────┘   │
           └──→ "abcd" ←──┘  ← 共享同一块内存！
```

**问题**：
1. 修改一个对象影响另一个
2. 两个析构函数释放同一块内存 → **双重释放崩溃**
3. 一个消亡后另一个访问已释放内存 → **悬空指针**

### 深拷贝 (Deep Copy) — 自定义拷贝构造

```cpp
String::String(const String& s) {
    len = s.len;
    str = new char[len + 1];  // 申请新空间
    strcpy(str, s.str);        // 复制内容
}
```

```
对象s1:           对象s2(深拷贝):
┌─────┐          ┌─────┐
│ len=4│          │ len=4│
│ str ─┼──→"abcd" │ str ─┼──→"abcd"  ← 各自独立！
└─────┘          └─────┘
```

> [!important] 何时必须自定义拷贝构造函数
> 当类中有**指针成员指向动态分配的资源**时，必须自定义深拷贝！
> 否则隐式拷贝构造会导致浅拷贝问题。

## 转移构造函数 (Move Constructor)

C++11 引入，参数为**右值引用** `A&&`：

```cpp
A(A&& x) {         // 转移构造函数
    p = x.p;       // 窃取资源
    x.p = nullptr; // 源对象放弃资源
}
```

**与拷贝构造的对比**：

| 维度 | 拷贝构造 | 转移构造 |
|------|----------|----------|
| 参数 | `const A&`（左值引用） | `A&&`（右值引用） |
| 操作 | 复制资源（新申请+复制） | 转移资源（窃取+置空） |
| 效率 | 低（需要复制） | 高（只是指针交换） |
| 适用 | 源对象继续使用 | 源对象即将消亡 |

**std::move**：将左值强制转换为右值，触发转移构造：
```cpp
A a;
A b(std::move(a));  // a的资源被转移给b，a不再可用
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "拷贝构造三个时机" | 初始化、传值参数、函数返回值 |
| "浅拷贝的危害" | 共享内存→双重释放/互相影响/悬空指针 |
| "何时需要深拷贝" | 类中有指向动态分配资源的指针 |
| "转移构造的优势" | 避免复制，直接转移资源 |
| "std::move的作用" | 将左值转为右值，触发转移语义 |
| "隐式拷贝是什么" | 逐成员浅拷贝 |

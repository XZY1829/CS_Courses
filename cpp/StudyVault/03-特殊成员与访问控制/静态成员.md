# 静态成员（★★★）

#cpp #class #static-member

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 静态数据成员 | 所有对象共享一份，属于类而非对象 |
| 静态成员函数 | 没有this指针，只能访问静态成员 |
| 存储位置 | 静态数据区（不占对象内存） |
| 初始化 | 必须在类外单独初始化 |
| 访问方式 | `ClassName::member` 或 `obj.member` |

## 静态数据成员

### 为什么需要

同类对象需要**共享数据**时，用全局变量有两个问题：
1. 数据与类缺乏显式联系
2. 数据缺乏保护（任何代码都能访问）

静态数据成员 = 属于类的共享数据 + 受访问控制保护

### 声明与初始化

```cpp
class A {
    static int count;       // 声明（类内）
    int x;
public:
    A() { count++; }
    ~A() { count--; }
    static int getCount() { return count; }
};

int A::count = 0;  // 定义+初始化（类外，必须！）
```

> [!important] 静态数据成员必须在类外初始化
> 声明只是告诉编译器存在这个成员，定义（分配内存+初始化）必须在类外的一个.cpp文件中完成。
> 格式：`类型 类名::成员名 = 初始值;`

### 静态成员 vs 普通成员

| 维度 | 静态数据成员 | 普通数据成员 |
|------|-------------|-------------|
| 数量 | 全类共享一份 | 每个对象一份 |
| 存储 | 静态数据区 | 对象内存中 |
| 生存期 | 程序整个运行期 | 随对象创建/消亡 |
| 初始化 | 类外单独初始化 | 构造函数中 |
| sizeof | 不计入对象大小 | 计入对象大小 |

## 静态成员函数

```cpp
class A {
    static int count;
    int x;
public:
    static int getCount() { return count; }  // 静态成员函数
};
```

**特点**：
- **没有 this 指针**（不属于任何对象）
- 只能访问静态数据成员和其他静态成员函数
- 不能访问非静态成员（因为没有this，不知道是哪个对象的）
- 可以通过类名直接调用：`A::getCount()`

> [!warning] 静态成员函数不能是const的
> const修饰的是this指向的对象，而静态成员函数没有this。

## 典型应用：对象计数器

```cpp
class Widget {
    static int total;
public:
    Widget() { total++; }
    ~Widget() { total--; }
    static int count() { return total; }
};
int Widget::total = 0;

// 使用
Widget a, b, c;
cout << Widget::count();  // 输出 3
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "静态成员在哪初始化" | 类外（且只在一个.cpp文件中） |
| "静态函数能访问什么" | 只能访问静态成员 |
| "静态函数有this吗" | 没有 |
| "sizeof包含静态成员吗" | 不包含 |
| "对象计数器怎么实现" | static count + 构造++、析构-- |
| "如何调用静态函数" | `ClassName::func()` 或 `obj.func()` |

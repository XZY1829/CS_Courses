# 虚继承（★★★）

#cpp #oop #virtual-inheritance #diamond-problem

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 问题 | 菱形继承导致基类数据重复 |
| 解决方案 | `virtual public Base` 虚继承 |
| 共享子对象 | 所有虚继承路径共享一份基类子对象 |
| 构造规则 | 最终派生类直接调用虚基类构造函数 |
| 构造顺序 | 虚基类优先于非虚基类 |
| 性能代价 | 额外指针 + 间接访问 |

## 菱形继承问题回顾

```
    Animal (name)
   /      \
 Cat      Pet       ← 都继承Animal
   \      /
  CatPet            ← 有两份Animal::name!
```

```cpp
class Animal { string name; };
class Cat : public Animal {};
class Pet : public Animal {};
class CatPet : public Cat, public Pet {};
// CatPet中有 Cat::Animal::name 和 Pet::Animal::name 两份！
```

访问时必须指定路径：`cp.Cat::name` 或 `cp.Pet::name`

## 虚继承的语法

在**中间层**声明虚继承：

```cpp
class Animal { string name; };
class Cat : virtual public Animal {};   // 虚继承
class Pet : virtual public Animal {};   // 虚继承
class CatPet : public Cat, public Pet {};
// CatPet中只有一份Animal::name！
```

- `virtual` 位于 `public/protected/private` 前或后均可
- 关键是所有"汇聚"路径的中间类都要声明虚继承

## 虚基类构造函数的调用规则

**核心规则**：虚基类的构造函数由**最终派生类**直接调用。

```cpp
class A {
public:
    A(int x) { }
};
class B : virtual public A {
public:
    B(int x) : A(x) { }  // B自己用时会调
};
class C : virtual public A {
public:
    C(int x) : A(x) { }  // C自己用时会调
};
class D : public B, public C {
public:
    D(int x, int y, int z) : A(x), B(y), C(z) { }
    //                        ↑ 必须直接调A的构造函数！
    // B和C初始化列表中的A(...)会被忽略
};
```

> [!important] 初始化列表中的虚基类
> 当创建D对象时，D的初始化列表中的`A(x)`生效，B和C初始化列表中的`A(...)`被忽略。
> 这是因为虚基类只构造一次，由最终派生类负责。

## 构造与析构顺序

对于 `class D : public B, public C`（B和C虚继承A）：

**构造顺序**：
1. 虚基类 A（优先）
2. 非虚基类按声明顺序：B → C
3. D 自身

**析构顺序**：与构造完全相反。

```cpp
D d(1, 2, 3);
// 构造顺序：A(1) → B(2) → C(3) → D(...)
// 析构顺序：~D() → ~C() → ~B() → ~A()
```

## 虚继承的底层实现

```
普通继承的对象布局:          虚继承的对象布局:
┌─────────────┐            ┌─────────────┐
│ Cat::Animal │            │ Cat部分      │
│ Cat的成员    │            │ (含vbptr→A)  │
├─────────────┤            ├─────────────┤
│ Pet::Animal │            │ Pet部分      │
│ Pet的成员    │            │ (含vbptr→A)  │
└─────────────┘            ├─────────────┤
  两份Animal!               │ Animal部分   │ ← 共享一份
                           └─────────────┘
```

- **vbptr** (virtual base pointer)：指向虚基类偏移表
- 访问虚基类成员需通过vbptr间接寻址

## 何时使用虚继承

| 场景 | 是否使用虚继承 |
|------|---------------|
| 菱形继承 | ✓ 必须使用 |
| 普通多继承（无公共基类） | ✗ 不需要 |
| 单继承 | ✗ 不适用 |
| 接口类（无数据成员） | 一般不需要（无重复数据） |

> [!warning] 注意事项
> - 虚继承有运行时代价，只在需要时使用
> - 标准库中 iostream 使用了虚继承（istream和ostream虚继承ios）
> - 如果基类只有纯虚函数（接口），通常不需要虚继承

# 组合与聚合（★★★）

#cpp #oop #composition #aggregation #object-relationship

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 整体-部分关系 | 一个对象包含另一个对象（HAS-A） |
| 组合(Composition) | 部分随整体创建/消亡，不能独立存在 |
| 聚合(Aggregation) | 部分独立于整体，可以脱离存在 |
| 实现区别 | 组合=直接包含成员对象；聚合=包含指针 |
| vs继承 | 继承=IS-A；组合/聚合=HAS-A |

## 继承 vs 组合

| 维度 | 继承 (IS-A) | 组合/聚合 (HAS-A) |
|------|------------|-------------------|
| 关系 | "是一种" | "拥有/包含" |
| 耦合度 | 高（访问protected） | 低（只用public接口） |
| 封装性 | 可能破坏 | 保持完好 |
| 维护性 | 基类修改影响派生类 | 影响小 |
| 灵活性 | 编译时确定 | 可运行时替换（聚合） |

> [!tip] 设计原则
> **优先使用组合，而非继承**（Composition over Inheritance）
> 只在确实存在IS-A关系时才用继承。

## 组合 (Composition) — 强拥有

部分对象的生命周期由整体控制：

```cpp
class Engine { /* ... */ };
class Car {
    Engine engine;  // 直接成员对象：随Car创建/销毁
public:
    Car() { /* engine自动构造 */ }
    // ~Car() { /* engine自动析构 */ }
};
```

- Engine在Car内部创建
- Car消亡时Engine自动消亡
- Engine不能独立于Car存在

## 聚合 (Aggregation) — 弱拥有

部分对象独立于整体，通过指针关联：

```cpp
class Employee { /* ... */ };
class Company {
    Employee *staff[100];  // 指针：不拥有对象
    int count;
public:
    void add(Employee *e) { staff[count++] = e; }
    void remove(Employee *e) { /* 从数组移除 */ }
    ~Company() { count = 0; }  // 不delete员工！
};

// 使用
Employee *jack = new Employee("Jack");
Company c1("Tech"), c2("Finance");
c1.add(jack);      // Jack加入c1
c1.remove(jack);   // Jack离开c1
c2.add(jack);      // Jack加入c2（员工独立于公司存在）
```

## 对比图

```
组合 (Composition):                聚合 (Aggregation):
┌─────────────────┐               ┌─────────────────┐
│ Car             │               │ Company          │
│ ┌─────────────┐ │               │  staff ──────┐  │
│ │ Engine      │ │               └──────────────┼──┘
│ │ (直接包含)   │ │                              │
│ └─────────────┘ │                              ↓
└─────────────────┘               ┌──────────────────┐
Engine随Car同生共死                 │ Employee         │
                                  │ (独立存在)        │
                                  └──────────────────┘
```

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "组合vs聚合" | 生命周期：组合=同步，聚合=独立 |
| "实现区别" | 组合=直接成员，聚合=指针成员 |
| "继承vs组合" | IS-A用继承，HAS-A用组合 |
| "优先组合原则" | 降低耦合，保持封装 |
| "聚合的析构" | 整体消亡时不销毁部分对象 |

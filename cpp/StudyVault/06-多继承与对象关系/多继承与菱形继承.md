# 多继承与菱形继承（★★★）

#cpp #oop #multiple-inheritance #virtual-inheritance #diamond-problem

## 概览表（一目了然）

| 条目 | 要点 |
|------|------|
| 多继承 | 一个类有多个直接基类 |
| 菱形继承 | 两条路径从同一基类继承 → 数据重复 |
| 虚继承 | `virtual public Base` 解决菱形继承的数据重复 |
| 名冲突 | 多个基类有同名成员 → 用基类名受限 |
| 构造顺序 | 按基类声明顺序 |

## 多继承语法

```cpp
class C : public A, public B {
    int r;
public:
    void fc();
};
```

- C拥有A和B的所有成员 + 自己新增的
- 构造顺序：按**声明顺序**先A()再B()最后C()
- C的对象同时是A和B的子类型

## 多继承的问题

### 问题1：名冲突

```cpp
class A { public: void f(); };
class B { public: void f(); };
class C : public A, public B {};

C c;
c.f();     // Error! 歧义
c.A::f();  // OK，指定调用A的f
c.B::f();  // OK，指定调用B的f
```

### 问题2：菱形继承（重复继承）

```
    A (int x)
   / \
  B   C        ← B和C都继承自A
   \ /
    D          ← D中有两份A::x！
```

```cpp
class A { int x; };
class B : public A {};
class C : public A {};
class D : public B, public C {};  // D中有B::x和C::x两份！
```

## 虚继承 (Virtual Inheritance)

解决菱形继承中数据重复的问题：

```cpp
class A { int x; };
class B : virtual public A {};  // 虚继承
class C : virtual public A {};  // 虚继承
class D : public B, public C {};  // D中只有一份A::x！
```

### 虚基类构造函数调用规则

- 虚基类由**最终派生类**直接调用构造函数
- 虚基类优先于非虚基类构造

```cpp
class D : public B, public C {
public:
    D(int i, int j, int k) : A(3), B(i), C(j) { }
    //                        ↑ 直接调用虚基类A的构造函数
};
```

构造顺序：`A(3)` → `B(i)` → `C(j)` → `D(...)`

> [!warning] 虚继承的代价
> - 对象增加额外指针（指向虚基类偏移表）
> - 访问虚基类成员多一次间接寻址
> - 只在确实需要时使用（菱形继承场景）

## 考试/测试常见模式

| 场景/关键词 | 答案 |
|-------------|------|
| "菱形继承问题" | 同一基类的数据在派生类中有两份 |

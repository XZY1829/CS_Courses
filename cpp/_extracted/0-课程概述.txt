课程主要内容
本课程主要介绍以下的程序设计思想：
面向对象程序设计（数据抽象与封装、对象与类、类作为模块、继承与代码复用、子类型、消息的多态与动态绑定、聚合与组合）
文件处理（永久性保留数据）
异常处理（处理环境因素导致的程序错误，提高程序的鲁棒性）
泛型（类属）程序设计（编写适合多种数据类型的通用代码）以及面向序列数据的抽象编程（隐藏底层实现）
函数式与逻辑式程序设计（声明式程序设计范式）
事件（消息）驱动的程序设计（交互式环境下的程序流程控制）以及基于应用框架的程序设计（更高层次的软件复用）
编程语言：
C++（语言运用的基本原则是为上述的程序设计思想服务，不要求面面俱到，够用即可！）

课程主要内容
三个建议：
不要“只看不练”： 编程是一门手艺活，不是一门阅读课。看书半小时，不如自己动手 Debug 十分钟。编译器（Compiler）才是你最好的老师。
学会提问与搜索，善于使用大模型，但是手撕代码打基础也是必要的： 遇到报错不要抓狂。学会去 Stack Overflow 或 GitHub 搜索错误信息。记住，你现在踩到的坑，大概率十年前就有人踩过并给出答案了。
代码风格重于逻辑： 逻辑对了程序能跑，但风格乱了程序会死。请从第一行代码开始，养成良好的缩进和命名习惯。

课程预备知识
本课程需要具备以下程序设计基础知识：
基本数据类型、常量、变量、操作符、表达式
程序的流程控制（顺序/分支/循环等）、结构化程序设计
基于功能分解与复合的过程式程序设计、过程抽象（子程序）、参数传递、局部变量与全局变量、标识符作用域与变量的生存期、程序的多模块结构
递归函数与“分而治之”的程序设计技术
枚举、数组、结构、联合等构造数据类型
指针类型、指针作为函数参数、动态变量（可变大小的数组、链表）、函数指针（向函数传递函数）
熟悉C语言
